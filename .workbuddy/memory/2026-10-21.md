### 术语必须跟课本走的几处

- $A^TAx=A^Tb$ → 课本叫**正则化方程组**（也说**法方程组**，式 (3.1.5)），算法叫**正则化方法**
- QR 解法 → 课本叫**正交变换法**（§3.3 节名）
- Cholesky → 课本叫**平方根法**
- 例 3.3.1 里的 **NC = Cholesky 解法方程**、**NG = 列主元 Gauss 解法方程**、**QR = 正交变换法**

### 课本里与笔记对得上的硬信息（都已写进 3.2）

- **定理 3.3.1**：$Q\in\mathbb R^{m\times m}$、$R\in\mathbb R^{m\times n}$ 上梯形，$R$ 对角元取非负；$m=n$ 且 $A$ 非奇异时唯一。（完全形式；3.1 写的是薄形式，已加注互指）
- **算法 3.3.1**：`for j=1:n` / `if j<m` / `[v,β]=house(A(j:m,j))` / `A(j:m,j:n)=(I-βvvᵀ)A(j:m,j:n)` / `d(j)=β` / `A(j+1:m,j)=v(2:m-j+1)`。`if j<m` 正是"方阵少做一步"的落地；最后一行印证 $v$ 首分量 1 省略、与 $R$ 共用存储。
- **运算量** $2n^2(m-n/3)$ = $2mn^2-\frac23n^3$，与笔记一致。
- **例 3.3.1**：构造 $\kappa_2(A)=k$ 的矩阵，最小二乘残差恒为 $\sqrt6$、与 $k$ 无关。$\kappa=10^5$ 三法误差均 0；$10^7$ 时 NC/NG 误差 0.001955、QR 仍 0；$10^9$ 时 NC/NG 误差 2.000651 且残差涨到 3.742、QR 仍 0 且残差 2.449。**NC 与 NG 结果完全相同**（课本明说），说明误差在形成 $A^TA$ 时就进去了。
- 课本原话结论："随着系数矩阵条件数的增大，正则化方法得到的计算解误差越来越大，而正交变换法得到的计算解就没有受到任何影响。"
