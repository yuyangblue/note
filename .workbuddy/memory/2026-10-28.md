## 数据结构：「度」概念答疑（05a §二.2 术语补写）

她问"度是什么"。讲了：结点的度 = 直接孩子个数（数"往下一层分几支"），与所在层无关；树的度 = 各结点度的最大值。

- 三者区分表：度（往下分支）/ 层次深度（往上层数）/ 路径长度（边数）。
- 二叉树度只能 0、1、2，按度分类即 n0/n1/n2，n0=n2+1 就是"按度计数"的产物（上下双向数边相等）。
- 推论：满二叉树无度为 1 的结点；完全二叉树度为 1 的至多一个（只有"有左没右"一种，出现在最后一层收尾处，n 偶时编号 ⌊n/2⌋）；哈夫曼树无度为 1 的结点故 2n-1 个总结点。

## 数据结构：AVL「最少结点数」公式 n_h = n_{h-1}+n_{h-2}+1 答疑（05b §二.1 扩写）

她截图陈越 4.2.1 那页（高度 h 的平衡二叉树最少结点数，画了两个方框子树 h-2 / h-1 "或" 对称），问"这是什么鬼公式"。

讲法：
- **三步推**：根占 1 → 左右高差 ≤1，要最少就让差**恰好取 1**（同高则更多、差 2 就失衡）→ 高侧 h-1、矮侧 h-2 各取最少。
- **初值坑**：$n_0=1$、$n_1=2$（单结点高 0，高 1 必须是根+一个孩子）。初值错会整表错位。
- 数列 1,2,4,7,12,20,33,54,88… 与斐波那契 $F_1=F_2=1$ 有 **$n_h=F_{h+3}-1$**（即 $n_h+1$ 是标准项），脚本验过 h=0..10 全一致。
- 结论：$n_h=\Theta(\phi^h)$，$\phi=1.618$ → $h=O(\log n)$，系数 $1/\log_2\phi=1.44$，即约 $1.44\log_2 n$，比完全二叉树只差常数因子。
- **应试反问题**：给 n 求 AVL 最高几层 = 找 $n_h\le n$ 的最大 h，查表即可（n=12 → h=4，即 5 层；n_5=20）。
- 对比：高 h 满二叉树 $2^{h+1}-1$ 是**最多**，$n_h$ 是**最少**，h=2 时 7 vs 4。

画的图：h=0..3 四棵"最瘦"AVL 树并排（teal = 高 h-1 那侧、amber = 高 h-2 那侧、灰 = 根），下方标 n_h 与"左+右+根 1"。

笔记：`05b` §二.1 原来只有一行结论（$N(h)=N(h-1)+N(h-2)+1$ + $\Theta(\phi^h)$），现扩成"设定义 → 三步推 → 公式+初值 → 数列与斐波那契 → 复杂度 → 规则（反问题）→ 注意（别与满二叉树混）"，151→274 行那轮之后本文件 258→274 行。未新增小标题，编号未动。
