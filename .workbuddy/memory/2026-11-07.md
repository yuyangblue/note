## 数据结构：「森林是什么，怎么转化成二叉树」（05a §三 补 30 行）

她问森林的定义与转二叉树的规则。笔记 §二.1 有森林定义（$m$ 棵互不相交的树；删根得森林、加虚拟根得树；$n=k+m$），§三 只有一句「旋转 45° 得到二叉树」，**森林多出来的那一步（各棵树的根串成右链）完全没写**，遍历对应也没写。

讲的四层：

1. **森林**：$m$ 棵互不相交的树；与树只差一个根——删去树根即得森林，给森林接虚拟根即得树。
2. **转换三步**：每棵树内部按「左孩子右兄弟」连线 → 各棵树的根用 `NextSibling` 串成右链 → 顺时针转 45°。森林比单棵树只多第二步。
3. **逆过程**：根无右孩子 ⇒ 原是一棵树；根有右孩子 ⇒ 原为森林，沿根右链断开即可。依据是"右指针表示兄弟，而树根没有兄弟"。
4. **遍历对应**（最常考）：树先根 = 先序、树后根 = 中序、森林先序 = 先序、森林后根 = 中序。树没有"中根遍历"，因为孩子只论排列不分左右。

例：森林 $\{A(B(D),C), E(F)\}$ → 二叉树 $A$(左 $B$(左 $D$, 右 $C$), 右 $E$(左 $F$))。脚本验证：森林先根 `A B D C E F` = 二叉树先序；森林后根 `D B C A F E` = 二叉树中序。
