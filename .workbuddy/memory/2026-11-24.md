## markmap 离线思维导图工具链（11-24）

- 鱼汤问 markmap 是不是 mind map、GitHub 下不了。概念：mind map 是思维导图这类图，markmap 是把 Markdown 大纲转成可折叠交互思维导图的工具（MIT，主仓 `github.com/markmap/markmap`，2026-11 重构为 scoped 包 @markmap/*，v1.1.1）。Obsidian 插件仓：`noraj/obsidian-mindmap-nextgen`（活跃，支持 inline ```markmap 代码块、frontmatter、PNG 导出）、`hypc/obsidian-markmap`（旧）。
- **她下不了 GitHub 的解法**：本机 node/npm 可用，`npm i @markmap/cli@1.1.0 --registry=https://registry.npmmirror.com` 装到临时目录（34s），写 Markdown 大纲后 `./node_modules/.bin/markmap outline.md` 生成**单文件离线 HTML**（JS/CSS 全内嵌，无 script src/link href 外链，只有注释里的 URL），双击即开、可折叠缩放。
- 已产出 `第12章_并发编程/并发编程_思维导图.md`（大纲源，1.6K）+ `.html`（570K 离线成品）。以后改大纲重跑 markmap 即可。
