## 一、接上一讲：非线性方程组的牛顿法

这一讲先把非线性方程组的牛顿法收个尾，再讲拟牛顿法，然后转到矩阵特征值的计算。

上一讲我们已经把非线性方程组的迭代写成了迭代格式。它和一元非线性方程的不动点迭代是很像的，唯一区别在于：一元那边，分母上写的是导数 $f'(x_k)$；到了方程组，那一项就变成了导数的矩阵，也就是雅可比矩阵 $F'(x_k)$。所以要做的事情是先把非线性方程组写出来，写出这个导数矩阵的定义，然后想办法把它放到"分母"上——严格说不是分母，是乘它的逆。

推导用的还是切线那个概念，只不过这里的展开是多变量的泰勒展开。展开之前要先把这个导数矩阵的写法定下来；定下来之后，怎么把它搬到迭代格式里，就是上一讲做过的那套推导。

有一点要说明：在这个过程中，我们写出来的式子看起来是要解一个线性方程组，但实际计算的时候，我们不会真的去把 $F'(x_k)$ 的逆求出来再乘。我们会把这个逆"放到下面"，也就是每一步解一个以 $F'(x_k)$ 为系数矩阵的线性方程组。这样反而很快：解一次线性方程组、走一步迭代，再解、再走，反复做下去，运算量是可控的。

接下来是理论上更重要的一段：分析牛顿法的局部收敛性。

## 二、牛顿法的局部收敛性

定理的条件这样写：$F$ 定义在 $\mathbb{R}^n$ 的一个区域 $D$ 里，取值也在 $\mathbb{R}^n$；$x^* \in D$ 是方程组的解，即 $F(x^*)=0$；$F$ 在 $x^*$ 的一个开邻域 $S \subset D$ 上可导，$F'(x^*)$ 连续，并且 $F'(x^*)$ 可逆。

在这些条件下，结论有两条：

第一，存在 $\delta>0$，使得 $S_0 = U(x^*,\delta)$ 内每一点的 $F'(x)$ 都可逆。这一条是为后面服务的——迭代里每一步都要用 $F'(x_k)$ 的逆，所以首先得保证这个逆在 $x^*$ 附近处处存在。

第二，牛顿迭代产生的向量序列 $\{x^{(k)}\}$ 收敛到 $x^*$，而且是**超线性收敛**。

这里要把"超线性"这个词说准。既然叫超线性，它就不是平方收敛；它比线性收敛快，但比平方收敛慢。上一讲在标量情形说过，牛顿法在单根处是平方收敛；那是加了更强条件（$f''$ 有界）才得到的结论。这里只假设 $F'$ 连续，得到的就是超线性这个较弱的结论。

下面看证明。取 $\alpha = \big\|[F'(x^*)]^{-1}\big\|$，它大于零，因为 $F'(x^*)$ 可逆。

由于 $F'$ 在 $x^*$ 处连续，对任意给定的 $\varepsilon>0$，都存在 $\delta>0$，使得当 $x \in U(x^*,\delta) \subset S$ 时，

$$\big\|F'(x) - F'(x^*)\big\| < \varepsilon .$$

这句话的意思是：不管你要多小的 $\varepsilon$，我总能在 $x^*$ 附近找到一个小邻域，使得这个邻域里每一点的雅可比矩阵，和 $x^*$ 处的雅可比矩阵，范数上的差别都小于 $\varepsilon$。$F'$ 虽然是导数，但作为矩阵函数它本身是连续的，所以这件事成立。

现在估计迭代误差。由迭代格式 $x^{(k+1)} = x^{(k)} - [F'(x^{(k)})]^{-1}F(x^{(k)})$，两边减去 $x^*$：

$$x^{(k+1)} - x^* = x^{(k)} - x^* - [F'(x^{(k)})]^{-1}F(x^{(k)}).$$

这里用了一个技巧：把 $F(x^{(k)})$ 写成 $F(x^{(k)}) - F(x^*)$，因为 $F(x^*)=0$，减一下不影响。于是

$$x^{(k+1)} - x^* = [F'(x^{(k)})]^{-1}\Big\{F'(x^{(k)})(x^{(k)}-x^*) - \big(F(x^{(k)}) - F(x^*)\big)\Big\}.$$

再拆一次：在大括号里先减掉 $F'(x^*)(x^{(k)}-x^*)$、再加回来，凑成两项：

$$x^{(k+1)} - x^* = [F'(x^{(k)})]^{-1}\Big\{\big[F(x^{(k)}) - F(x^*) - F'(x^*)(x^{(k)}-x^*)\big] - \big[F'(x^{(k)}) - F'(x^*)\big](x^{(k)}-x^*)\Big\}$$
（第二项带负号，是从"减去 $F'(x^*)$ 那一项"里拆出来的）。

取范数，用三角不等式把它拆成两部分：

$$\big\|x^{(k+1)}-x^*\big\| \le \big\|[F'(x^{(k)})]^{-1}\big\|\cdot\Big\{\big\|F(x^{(k)}) - F(x^*) - F'(x^*)(x^{(k)}-x^*)\big\| + \big\|\big[F'(x^{(k)})-F'(x^*)\big](x^{(k)}-x^*)\big\|\Big\}.$$

两部分分别看。第一部分是 $F$ 在 $x^*$ 处展开到一阶的余项，由可微性它是 $o\big(\|x^{(k)}-x^*\|\big)$，比一阶还小；第二部分由连续性小于 $\varepsilon\|x^{(k)}-x^*\|$。合起来，

$$\big\|x^{(k+1)}-x^*\big\| \le \big\|[F'(x^{(k)})]^{-1}\big\|\cdot\Big(o\big(\|x^{(k)}-x^*\|\big) + \varepsilon\big\|x^{(k)}-x^*\big\|\Big).$$

还剩前面那个 $\big\|[F'(x^{(k)})]^{-1}\big\|$ 要处理。思路是把它和 $[F'(x^*)]^{-1}$ 联系起来。写成

$$[F'(x^{(k)})]^{-1} = [F'(x^*)]^{-1}\cdot\Big(I - \big(I - [F'(x^*)]^{-1}F'(x^{(k)})\big)\Big)^{-1},$$

再对后面那个逆用一次展开（$\|(I-T)^{-1}\| \le \dfrac{1}{1-\|T\|}$，只要 $\|T\|<1$），得到

$$\big\|[F'(x^{(k)})]^{-1}\big\| \le \frac{\big\|[F'(x^*)]^{-1}\big\|}{1 - \varepsilon\big\|[F'(x^*)]^{-1}\big\|} \le M .$$

这里要求 $\varepsilon < \dfrac{1}{2\alpha}$，也就是 $\varepsilon$ 取得足够小，分母就至少是 $1/2$，于是这个量被一个常数 $M$ 控制住。这就是为什么前面要"取一个非常小的 $\varepsilon$"——它的作用正是让这个界成立。

代回去：

$$\big\|x^{(k+1)}-x^*\big\| \le M\Big(o\big(\|x^{(k)}-x^*\|\big) + \varepsilon\big\|x^{(k)}-x^*\big\|\Big).$$

两边除以 $\|x^{(k)}-x^*\|$：

$$\frac{\big\|x^{(k+1)}-x^*\big\|}{\big\|x^{(k)}-x^*\big\|} \le M\Big(\frac{o(\|x^{(k)}-x^*\|)}{\|x^{(k)}-x^*\|} + \varepsilon\Big).$$

右端当 $x^{(k)} \to x^*$ 时趋于 $M\varepsilon$。而 $\varepsilon$ 是任意给定的，所以这个比值趋于零——

$$\lim_{k\to\infty}\frac{\big\|x^{(k+1)}-x^*\big\|}{\big\|x^{(k)}-x^*\big\|} = 0,$$

这正是超线性收敛的定义。

这个证明确实繁琐。但想说明的是：一方面它用了很多放缩技巧，另一方面它用了很多假设。所以有时候一个算法本身看起来很简单，你要在理论上说明"它一定在某种条件下成立"，却是一件很技术性的工作。算法写出来就一个表达式，能算就行；但要做收敛性分析，反倒更复杂，甚至需要更高级的工具。我们现在没有那些工具，只能这样比较朴素地一步步放缩。

## 三、实际计算中的麻烦：雅可比矩阵算不出来

有了非线性方程组的牛顿法，接下来要讨论拟牛顿法。先说动机：实际计算里，拟牛顿法用得反而比牛顿法更多。

原因很直接：牛顿法每一步都要算一个雅可比矩阵 $F'(x^{(k)})$。这个矩阵在很多情况下不好算，更糟的是有时候根本算不出来——你既不知道这个雅可比矩阵是否存在，也不知道它能不能写成显式形式。比如函数本身是"黑箱"，只能给函数值，那导数就无从谈起。

拟牛顿法的做法，就是把牛顿法里的 $F'(x^{(k)})$ 换掉。牛顿法的迭代是

$$x^{(k+1)} = x^{(k)} - \big[F'(x^{(k)})\big]^{-1}F(x^{(k)}),$$

拟牛顿法把它写成

$$x^{(k+1)} = x^{(k)} - A_k^{-1}F(x^{(k)}),$$

用某个矩阵 $A_k$ 去替代 $F'(x^{(k)})$，希望它起到类似的效果，同时又要好算。这和一元的思路一致：牛顿法用切线，弦截法用割线，割线就是用差商替代导数。

## 四、替代什么？——拟牛顿条件

但这里有个本质困难。一元的时候，要替代的是一个数（导数），用差商 $[f(x_k)-f(x_{k-1})]/(x_k-x_{k-1})$ 就完了。现在要替代的是 $n^2$ 个数（矩阵的元素），怎么用"已知信息"去定它们？

回到一元的做法。弦截法里，导数的替代方式是

$$f'(x_k) \approx \frac{f(x_k)-f(x_{k-1})}{x_k-x_{k-1}},$$

写成乘积形式就是

$$f'(x_k)(x_k - x_{k-1}) = f(x_k) - f(x_{k-1}).$$

这就是割线斜率的定义式：它的斜率要让它过 $(x_{k-1}, f(x_{k-1}))$ 和 $(x_k, f(x_k))$ 两点。

照搬到方程组：我们希望第 $k$ 步用的近似矩阵 $A_k$ 满足

$$A_k\big(x^{(k)} - x^{(k-1)}\big) = F(x^{(k)}) - F(x^{(k-1)}).$$

这个式子是可以写出来的：$A_k$ 是 $n\times n$ 的，$x^{(k)}-x^{(k-1)}$ 是 $n$ 维列向量，右端也是 $n$ 维列向量，形状对得上。

但问题在于，当我们已经算出 $x^{(k)}$、$x^{(k-1)}$ 和对应的函数值时，这个方程**解不出来**：它只有 $n$ 个方程，而未知量是 $A_k$ 里的 $n^2$ 个元素。严格意义上，这个方程没法直接算。

所以只能采取近似、逼近，或者说"凑"的办法，去把 $A_k$ 构造出来。这里的思路是：不要凭空给一个 $A_k$，而是在上一步的 $A_{k-1}$ 基础上做一点修正，

$$A_k = A_{k-1} + \Delta A_{k-1},$$

把问题变成"如何定这个修正量 $\Delta A_{k-1}$"。修正量越小、越简单，计算就越省。

## 五、一个引理：对仿射函数，秩一修正恰好补齐

先考虑一个最简单的情形——仿射函数。设

$$F(x) = Dx + b,$$

其中 $D$ 是 $n\times n$ 矩阵，$b$ 是常向量。这当然是线性的，但它可以看作非线性函数的一阶近似：任何一个非线性函数在小邻域里做泰勒展开，取一阶部分，就长这个样子；非线性部分（二次以上的项）被扔掉了。所以研究仿射情形，就是在研究"牛顿法眼里的那个线性模型"。

对仿射函数，$F$ 的雅可比矩阵处处等于 $D$。取两点 $x$、$x'$，记

$$p = x' - x,\qquad q = F(x') - F(x),$$

那么由仿射性有 $q = Dp$。

现在的问题是：随便给一个矩阵 $A$（它是 $D$ 的一个不太准的近似），能不能用一个最小的修正，让它至少把 $p$ 这个方向"对"上？

**引理** 设 $A \in \mathbb{R}^{n\times n}$，$p \ne 0$，令

$$A' = A + \frac{(q - Ap)p^T}{\|p\|_2^2}.$$

则

（1）$A'p = q$，即 $A'p = Dp$；
（2）$\|A' - D\|_2 \le \|A - D\|_2$。

第一条直接代进去验证：

$$A'p = Ap + \frac{(q-Ap)\,p^Tp}{\|p\|_2^2} = Ap + (q - Ap) = q .$$

第二条说明：修正之后，新矩阵离 $D$ 至少不会比原来更远。这一点是"秩一修正"这个做法的正当性所在——它不是随便凑的，而是在所有满足 $A'p=q$ 的矩阵里，取一个不增加与 $D$ 距离的。

板书上这个定理的证明没有展开。它本质上是正交投影的性质：$A'-D$ 相当于把 $A-D$ 在 $p$ 的正交补方向上"切"了一下，而正交投影不会把范数放大。所以距离只会变小或不变。

这个定理要表达的事情，可以这样理解：我们有一个非线性函数 $F$，在局部用线性函数去近似它（这就是牛顿法的出发点），于是要拿到那个 $D$。但 $D$ 常常不好求，那就退一步，要一个 $D$ 的近似矩阵 $A$。我们未必能一次拿到很好的 $A$，但希望**在迭代过程中一步步把它改进**。

具体怎么改进：手里有一个向量 $p$ 和一个由线性变换算出来的 $q$，它们通过要逼近的那个 $D$ 联系起来（$q = Dp$）。随便给一个 $A$，它不一定是好的近似，可以把它看成前一步对导数矩阵的估计；按上面那条公式修正得到 $A'$，则 $A'$ 一定满足 $A'p = q$（这正是拟牛顿条件），并且 $A'$ 与 $D$ 的距离比 $A$ 与 $D$ 的距离更近。

## 六、Broyden 秩一方法

把这个引理用到迭代的每一步。假设第 $k-1$ 步已经有一个近似矩阵 $A_{k-1}$，第 $k$ 步取

$$p = x^{(k)} - x^{(k-1)},\qquad q = F(x^{(k)}) - F(x^{(k-1)}),$$

然后

$$A_k = A_{k-1} + \frac{\big(q - A_{k-1}p\big)p^T}{\|p\|_2^2}.$$

这就是 Broyden 秩一方法的核心更新式。

之所以叫"秩一"，是因为加上的那个矩阵 $(q - A_{k-1}p)p^T/\|p\|_2^2$ 是一个列向量乘一个行向量，秩为 1。相当于我们在前一步的矩阵上修了一个规模很小的东西，而不是把整个矩阵重算一遍。

整个算法就是三步循环：

1. 算 $p = x^{(k)} - x^{(k-1)}$，$q = F(x^{(k)}) - F(x^{(k-1)})$；
2. 更新矩阵 $A_k = A_{k-1} + \dfrac{(q - A_{k-1}p)p^T}{\|p\|_2^2}$；
3. 走一步迭代 $x^{(k+1)} = x^{(k)} - A_k^{-1}F(x^{(k)})$。

有两点要提。

第一，它**需要两个初始点**才能启动。因为第一步就要算 $p = x^{(1)}-x^{(0)}$ 和 $q = F(x^{(1)})-F(x^{(0)})$，所以必须给出 $x^{(0)}$、$x^{(1)}$ 两个初值（可以取很近），还要给一个初始矩阵 $A_0$。$A_0$ 最省事的取法就是直接算 $F'(x^{(0)})$，当然也可以用别的办法给。这一点跟弦截法一样，弦截法也要两个初值。

第二，第 3 步里要算 $A_k^{-1}$。这个运算量是 $O(n^3)$ 的，和直接求逆一样贵。这就把秩一修正好处抵消掉了一部分：矩阵更新本身很便宜（$O(n^2)$），但每步求逆还是 $O(n^3)$。

另外要说一句方法论上的话：数值算法不要求每一步都精确。迭代过程中用到的东西很多都是近似，只要这个近似是合理的、最后结果能达到目标，算法就可以继续。

## 七、Sherman–Morrison 公式：把求逆也变成秩一更新

既然瓶颈在求逆，自然想：能不能利用"新矩阵是从老矩阵秩一修正来的"这一点，把新矩阵的逆也用老矩阵的逆表示出来？

**Sherman–Morrison 公式** 设 $A \in \mathbb{R}^{n\times n}$，$\det(A) \ne 0$，$u, v \in \mathbb{R}^n$。若 $1 + v^T A^{-1} u \ne 0$，则 $A + uv^T$ 可逆，且

$$\big(A + uv^T\big)^{-1} = A^{-1} - \frac{A^{-1}uv^TA^{-1}}{1 + v^TA^{-1}u}.$$

这个公式最重要的性质是：**只要已知 $A^{-1}$，那么 $A + uv^T$ 的逆完全可以用 $A^{-1}$ 表示出来**。右端只用到了 $A^{-1}$、$u$、$v$，而 $v^TA^{-1}u$ 只是一个数（行向量乘矩阵乘列向量），不涉及任何求逆。所以整个运算就变成了矩阵和向量相乘，$O(n^2)$。

把 Broyden 的更新式套进去。取

$$u = \frac{q - A_{k-1}p}{\|p\|_2},\qquad v = \frac{p}{\|p\|_2},$$

于是 $uv^T = \dfrac{(q-A_{k-1}p)p^T}{\|p\|_2^2}$，正是我们的修正项。代入公式，把分母里的 $\|p\|_2$ 逐步提出来、约掉，最后整理成

$$A_k^{-1} = A_{k-1}^{-1} - \frac{\big(A_{k-1}^{-1}q - p\big)p^TA_{k-1}^{-1}}{p^TA_{k-1}^{-1}q}.$$

这就是 Broyden 逆更新式。右端只用到 $A_{k-1}^{-1}$、$p$、$q$。所以每步都省掉了 $O(n^3)$ 的求逆。

于是有第二种写法：干脆不存 $A_k$，直接存 $B_k = A_k^{-1}$。迭代改成

1. 算 $p = x^{(k)} - x^{(k-1)}$，$q = F(x^{(k)}) - F(x^{(k-1)})$；
2. 更新逆矩阵 $B_k = B_{k-1} - \dfrac{(B_{k-1}q - p)p^TB_{k-1}}{p^TB_{k-1}q}$；
3. 走一步 $x^{(k+1)} = x^{(k)} - B_kF(x^{(k)})$。

这样整个迭代里**不出现任何解线性方程组**，只有矩阵乘向量。唯一的例外是开头：初始的 $B_0$ 需要真的算一次逆（或者用别的方式给一个近似）。

这就是拟牛顿法在计算上比牛顿法便宜的地方：牛顿法每步解一个线性方程组（$O(n^3)$），拟牛顿法每步只做 $O(n^2)$ 的矩阵向量乘法。

板书这里还有一句旁注：另有一类更复杂的公式，形式上与此非常像，只是写得更复杂，那是 Woodbury 公式（处理 $A + UBV^T$ 的情形）。对我们考虑的这类比较简单的问题，直接用经典的 Sherman–Morrison 就够了。

## 八、阶段小结：非线性方程这一块

到这里，非线性方程和非线性方程组的方法就基本讲完了。回头看一下这一整块：

对非线性方程，最重要的处理方式就是迭代：只要写出一个迭代格式，它就是一种迭代方法。但写出格式并不保证收敛——收敛性要靠实际计算去判断，先试几十次、看相邻两步的差别是不是越来越小；如果是，就让它继续；如果不是朝着收敛的方向走，就停下来换方法。

牛顿法以及由它演化出来的一批方法（拟牛顿法、Broyden 法等）也是这个道理。迭代几次之后看趋势，趋势不对就换初值，或者先用别的方法拿到一个更好的初值，再切回牛顿法。

对非线性方程组，迭代法的表现形式几乎一样，只是牛顿法里多了一个新概念——雅可比矩阵。把这个矩阵吃透，后面所有表达都只是把它代进去，步骤和过程是统一的。

从整体上讲，方程求解这一块我们考虑过两大类问题：一类是线性方程组（$n$ 个未知数 $n$ 个方程，以及 $m$ 个方程 $n$ 个未知数的超定情形，分别对应直接法、迭代法和最小二乘法）；另一类是非线性方程与非线性方程组，主要工具是迭代，附带讨论了收敛速度的定义、怎么让收敛更快、以及怎么减少计算量。

这一块讲完，下面转到另一个问题：矩阵的特征值。
