## 一、 核心概念：连续型为什么麻烦

离散型（p16）直接列表合并就行；连续型的密度函数是一个**函数**，不能一个个取值去代，得推导出 $Y$ 的密度表达式，所以要绕一个弯。核心工具是**分布函数**：

$$F_Y(y) = P\{Y \le y\}$$

先把 $Y \le y$ 改写为关于 $X$ 的事件（解不等式），再借助 $X$ 的分布函数 / 密度函数算出来，最后求导得到 $Y$ 的密度函数。

**贯穿全集的记号提醒**：$X$ 和 $Y$ 是两个不同的随机变量，密度函数、分布函数都要**加下标区分**：$F_Y(y)$ 是 $Y$ 的分布函数（自变量 $y$），$f_X(x)$ 是 $X$ 的密度函数，别混。

## 二、 三种方法总览

| 方法 | 思路 | 优点 | 缺点 |
|------|------|------|------|
| **① 分布函数法** | $F_Y(y) = P\{Y \le y\}$，按 $Y$ 落在哪个区间分段算定积分 | 定义出发，最本质 | 要分段讨论积分区间，**最麻烦** |
| **② 分布函数 + 链式求导** | $F_Y(y) = F_X\big(h(y)\big)$，两边对 $y$ 求导 | 步骤固定、快，**最推荐** | 需要 $g$ 单调可解反函数 |
| **③ 公式法** | 套 $f_Y(y) = f_X(h(y)) \cdot \lvert h'(y) \rvert$ | 最快 | 公式要死记，容易记错 |

## 三、 方法一：分布函数法（先求 F 再求导）

**例三**：设 $X \sim U(1,5)$（均匀分布），$Y = 2X + 3$，求 $Y$ 的密度函数。

**Step 1**：先定 $Y$ 的取值范围。$X \in [1,5] \Rightarrow Y = 2X+3 \in [5, 13]$。

**Step 2**：写分布函数定义，并把事件改写为 $X$ 的事件：

$$F_Y(y) = P\{Y \le y\} = P\{2X + 3 \le y\} = P\left\{X \le \frac{y-3}{2}\right\}$$

**Step 3**：按 $\frac{y-3}{2}$ 落在哪个区间分段积分（$X \sim U(1,5)$，密度 $f_X(x) = \frac14,\ 1\le x \le 5$，其余为 0）：

- **$\frac{y-3}{2} < 1$，即 $y < 5$**：积分上限在 1 左边，密度全为 0：

$$F_Y(y) = \int_{-\infty}^{(y-3)/2} 0 \, dx = 0$$

- **$1 \le \frac{y-3}{2} < 5$，即 $5 \le y < 13$**：只有 $[1, \frac{y-3}{2}]$ 段密度为 $\frac14$：

$$F_Y(y) = \int_{1}^{(y-3)/2} \frac14 \, dx = \frac14 \left(\frac{y-3}{2} - 1\right) = \frac{y-5}{8}$$

- **$\frac{y-3}{2} \ge 5$，即 $y \ge 13$**：超过 5 的部分密度为 0，整个区间积分为 1：

$$F_Y(y) = 1$$

**Step 4**：分布函数求导得密度函数（对 $y$ 求导，不是对 $x$）：

$$f_Y(y) = F_Y'(y) = \begin{cases} \dfrac18, & 5 \le y \le 13 \\[6pt] 0, & \text{其他} \end{cases}$$

**结论**：$Y \sim U(5, 13)$——**均匀分布做线性变换还是均匀分布**，新区间直接把端点代进去：$X \in [a,b]$，$Y = cX + d$（$c \ne 0$）$\Rightarrow Y \sim U(ac+d,\, bc+d)$。本例 $2 \times 1 + 3 = 5$，$2 \times 5 + 3 = 13$。

> ⚠️ 必须是**线性变换**才保持均匀分布；非线性（如例七的 $e^X$）一般不是均匀分布。

## 四、 方法二：分布函数 + 链式求导（推荐）

**核心公式**：若 $Y = g(X)$ 且 $X = h(Y)$ 是它的反函数（$g$ 单调），则

$$F_Y(y) = P\{Y \le y\} = P\{g(X) \le y\} = P\{X \le h(y)\} = F_X\big(h(y)\big)$$

**两边同时对 $y$ 求导**（左边：$F_Y' = f_Y$；右边：复合函数链式法则）：

$$f_Y(y) = f_X\big(h(y)\big) \cdot h'(y)$$

**例三（续）**：$Y = 2X+3$，反函数 $X = \frac{y-3}{2}$，$h'(y) = \frac12$：

$$f_Y(y) = f_X\left(\frac{y-3}{2}\right) \cdot \frac12 = \frac14 \times \frac12 = \frac18, \qquad 5 \le y \le 13$$

和分布函数法结果一致，但**不用分段讨论积分**，快很多。

**写法的两个关键点**：
1. 把 $f_X$ 里的 $x$ 全部换成 $h(y)$，同时**取值范围**也要跟着换：$1 \le x \le 5 \Rightarrow 1 \le \frac{y-3}{2} \le 5 \Rightarrow 5 \le y \le 13$；
2. **别忘了乘 $h'(y)$**（例三的 $\frac12$），这是链式法则，漏乘答案直接错一倍。

### 例四：正态的线性变换仍是正态

**问题**：设 $X \sim N(\mu, \sigma^2)$，$Y = aX + b$（$a \ne 0$），求 $Y$ 的密度函数。

**解答**：反函数 $X = \frac{y-b}{a}$，$h'(y) = \frac1a$。但 $a$ 的正负影响不等号方向，分两种情况：

**（1）$a > 0$**：除以正数，不等号不变：

$$F_Y(y) = P\{aX + b \le y\} = P\left\{X \le \frac{y-b}{a}\right\} = F_X\left(\frac{y-b}{a}\right)$$

两边对 $y$ 求导：

$$f_Y(y) = f_X\left(\frac{y-b}{a}\right) \cdot \frac1a = \frac{1}{\sqrt{2\pi}\,\sigma} e^{-\frac{(y-b-a\mu)^2}{2a^2\sigma^2}} \cdot \frac1a$$

整理后可见 $Y \sim N(a\mu + b,\, a^2\sigma^2)$。

**（2）$a < 0$**：除以负数，**不等号反向**，不是分布函数的定义形式，要先转成"小于等于"：

$$P\{aX + b \le y\} = P\left\{X \ge \frac{y-b}{a}\right\} = 1 - P\left\{X \le \frac{y-b}{a}\right\} = 1 - F_X\left(\frac{y-b}{a}\right)$$

两边对 $y$ 求导（注意负号）：

$$f_Y(y) = -\,f_X\left(\frac{y-b}{a}\right) \cdot \frac1a = f_X\left(\frac{y-b}{a}\right) \cdot \left(-\frac1a\right)$$

因为 $a < 0$，$-\frac1a > 0$，所以密度非负，结果同样是 $Y \sim N(a\mu + b,\, a^2\sigma^2)$。

> **易错点**：正态分布的 $\sigma$ 必须为正。$a<0$ 时不要写成"$\sigma$ 变成 $a\sigma$"（负的），要写成 $-\frac1a$ 吸收负号，保证系数为正。

**结论（课本常用）**：正态分布经**线性变换仍是正态分布**，参数变化规则：

$$X \sim N(\mu, \sigma^2) \quad\Longrightarrow\quad Y = aX + b \sim N(a\mu + b,\ a^2\sigma^2)$$

直观理解：$\mu$ 是对称轴位置，$aX+b$ 把对称轴挪到 $a\mu+b$；$\sigma^2$ 反映波动程度，乘以 $a$ 后波动放大 $a^2$ 倍。

### 标准化：Z = (X-μ)/σ ~ N(0,1)

这是例四最重要的推论：令 $a = \frac1\sigma$，$b = -\frac{\mu}{\sigma}$，则

$$Z = \frac{X - \mu}{\sigma} \sim N(0, 1)$$

即**任何正态分布减均值、除标准差后变成标准正态分布**（"标准化"）。验证：$a\mu + b = \frac{\mu}{\sigma} - \frac{\mu}{\sigma} = 0$，$a^2\sigma^2 = \frac{1}{\sigma^2}\cdot\sigma^2 = 1$。后面所有查表求概率都要靠它。

### 例五：标准正态的平方 → χ²(1)

**问题**：设 $X \sim N(0,1)$，$Y = X^2$，求 $Y$ 的密度函数。

**解答**：$Y = X^2 \ge 0$，分两段。

- **$y \le 0$**：$P\{Y \le y\} = 0$（$Y$ 不可能为负）。

- **$y > 0$**：

$$F_Y(y) = P\{X^2 \le y\} = P\{-\sqrt{y} \le X \le \sqrt{y}\} = \Phi(\sqrt{y}) - \Phi(-\sqrt{y})$$

两边对 $y$ 求导（两项都是复合函数，注意负号）：

$$f_Y(y) = \varphi(\sqrt{y})\cdot\frac{1}{2\sqrt{y}} - \varphi(-\sqrt{y})\cdot\left(-\frac{1}{2\sqrt{y}}\right) = \frac{\varphi(\sqrt{y})}{\sqrt{y}}$$

（最后一步用到标准正态密度是偶函数：$\varphi(-\sqrt{y}) = \varphi(\sqrt{y})$，两项相加。）

代入 $\varphi(t) = \frac{1}{\sqrt{2\pi}}e^{-t^2/2}$：

$$f_Y(y) = \frac{1}{\sqrt{2\pi}} y^{-1/2} e^{-y/2}, \qquad y > 0$$

**结论**：$Y = X^2$ 服从**自由度为 1 的卡方分布** $\chi^2(1)$（这是第一次出现 $\chi^2$ 分布，在 6.3 抽样分布会正式讲）。注意它**不再是正态分布**——因为平方是非线性变换。

## 五、 方法三：公式法

把方法二提炼成通用公式（**$g$ 单调、可导，$g'(x) \ne 0$**，值域 $[\alpha, \beta]$，反函数 $X = h(Y)$）：

$$\boxed{\,f_Y(y) = f_X\big(h(y)\big) \cdot \big|h'(y)\big|, \qquad \alpha \le y \le \beta\,}$$

**为什么乘 $h'(y)$**：复合函数链式求导（方法二里"里面还得再求导"的那一步）。

**为什么加绝对值**：密度函数必须非负；$h'(y)$ 可能为负（如例四 $a<0$ 时），加绝对值保证 $f_Y \ge 0$。

**注意**：$Y$ 的取值区间 $[\alpha, \beta]$ 是 $g$ 的**值域**，由 $X$ 的取值范围代入 $g$ 得到，不是随便写的。

### 例六：一般密度的线性变换

**问题**：设 $X$ 的密度为一般函数 $f_X(x)$（没说是什么分布），$Y = aX + b$（$a \ne 0$），求 $f_Y(y)$。

**解答**：直接用公式法。反函数 $X = \frac{y-b}{a}$，$h'(y) = \frac1a$：

$$f_Y(y) = f_X\left(\frac{y-b}{a}\right) \cdot \left|\frac1a\right|, \qquad -\infty < y < +\infty$$

（$X$ 取值范围无限制时，$Y$ 也是全实数，$\alpha = -\infty$，$\beta = +\infty$，区间不用写。）

### 例七：X~U(0,1), Y = e^X（三方法对比）

**问题**：设 $X \sim U(0,1)$，$Y = e^X$，求 $Y$ 的密度函数。

**方法一（分布函数法，最麻烦）**：$X \in [0,1] \Rightarrow Y \in [1, e]$。

$$F_Y(y) = P\{e^X \le y\} = P\{X \le \ln y\}$$

- $y < 1$：$F_Y(y) = 0$（$Y \ge 1$ 不可能小于 $y$）；
- $1 \le y < e$：$F_Y(y) = \int_0^{\ln y} 1 \, dx = \ln y$；
- $y \ge e$：$F_Y(y) = 1$。

求导：$f_Y(y) = \frac1y,\quad 1 \le y \le e$。

**方法二（分布函数 + 链式，推荐）**：

$$F_Y(y) = P\{X \le \ln y\} = F_X(\ln y)$$

两边对 $y$ 求导：

$$f_Y(y) = f_X(\ln y) \cdot \frac1y = 1 \times \frac1y = \frac1y, \qquad 1 \le y \le e$$

（其中 $f_X(\ln y) = 1$ 当 $1 \le y \le e$，即 $0 \le \ln y \le 1$。）

**方法三（公式法）**：反函数 $X = \ln y$，$h'(y) = \frac1y$：

$$f_Y(y) = f_X(\ln y) \cdot \left|\frac1y\right| = \frac1y, \qquad 1 \le y \le e$$

三种方法殊途同归：$f_Y(y) = \dfrac1y,\ 1 \le y \le e$。

## 六、 三种方法对比与总结

1. **离散型**（p16）：列表代入 + 合并，最简单。
2. **连续型**三方法本质相同——都是"分布函数 + 求导"：
   - 方法一从定义出发分段积分，最本质但最繁琐（要讨论 $Y$ 落在哪个区间）；
   - 方法二把 $F_Y(y)$ 直接写成 $F_X(h(y))$ 再链式求导，**步骤固定，推荐**；
   - 方法三套公式 $f_Y(y) = f_X(h(y))|h'(y)|$，最快但公式要记牢。
3. **两个重要结论**：
   - 均匀分布的线性变换仍是均匀分布（例三）；
   - 正态分布的线性变换仍是正态分布，$N(\mu,\sigma^2) \xrightarrow{Y=aX+b} N(a\mu+b, a^2\sigma^2)$（例四），由此得到标准化 $Z = \frac{X-\mu}{\sigma} \sim N(0,1)$。
4. **非线性变换会改变分布类型**：标准正态的平方变成 $\chi^2(1)$（例五），均匀分布的指数变换也不是均匀分布（例七）。

## 本节重点

> - **通用套路**：先写 $F_Y(y) = P\{Y \le y\}$，把事件改写为 $X$ 的不等式，再借助 $X$ 的分布函数，最后对 $y$ 求导得密度。
> - **推荐方法**：方法二（$F_Y(y) = F_X(h(y))$ + 链式求导），省去分段积分；公式法记得加绝对值。
> - **两条黄金结论**：线性变换下均匀→均匀、正态→正态（参数 $a\mu+b,\ a^2\sigma^2$）。
> - **常见坑**：① 漏乘 $h'(y)$（链式法则）；② 取值范围忘记跟着换；③ $a<0$ 时不等号方向、负号处理（例四）；④ 非线性变换（平方、指数）后分布类型会变，不能想当然。
> - $\chi^2$ 分布详见后续 **6.3 抽样分布**。
