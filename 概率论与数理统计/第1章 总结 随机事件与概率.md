## 二、各节要点回顾

### p01 预备知识（加法原理、乘法原理、排列与组合）
- 计数两大支柱：**加法原理**（一步完成、各类互斥，方案数相加）；**乘法原理**（分步完成、每步连续，方案数相乘）。一道题常是「步与步之间乘、每步内部加」。
- 排列与顺序有关：$P_n^m=n(n-1)\cdots(n-m+1)$；组合与顺序无关：$C_n^m=\frac{P_n^m}{m!}$，即「排列数除以内部全排列 $m!$」。
- 常用技巧：插板法（$n$ 个相同物分 $k$ 个非空盒 $=C_{n-1}^{k-1}$）、捆绑法、插空法。（详见 **p01 预备知识**）

### p02 1.1 随机试验与随机事件
- 随机试验三特点：**可重复、多结果、不确定**。样本空间 $\Omega$ 是所有可能结果的集合，事件是 $\Omega$ 的子集。
- 事件关系与运算：包含 $\subseteq$、并（至少一个发生）、交（同时发生）、差 $A-B=A\bar{B}$、互斥（$AB=\emptyset$）、对立（$A\cup B=\Omega$ 且 $AB=\emptyset$）、完备事件组（两两互斥且并为全集，即样本空间的一个「划分」）。
- 运算律核心是**德摩根律**：$\overline{A\cup B}=\bar{A}\cap\bar{B}$，$\overline{A\cap B}=\bar{A}\cup\bar{B}$（长杠变短杠，开口换方向）。（详见 **p02 1.1 随机试验与随机事件**）

### p03 1.2 频率与概率
- 频率 $f_n(A)=\frac{n_A}{n}$，具有非负性、规范性、可加性；大量重复下频率稳定在常数附近，这就是概率的客观基础（伯努利大数定律）。
- 柯尔莫哥洛夫公理化定义三公理：非负性、规范性 $P(\Omega)=1$、可列可加性。
- 由公理推出常用性质：$P(\emptyset)=0$、$P(\bar{A})=1-P(A)$、减法公式、加法公式（两个、三个事件）。（详见 **p03 1.2 频率与概率**）

### p04 1.3 古典概型与几何概型
- 古典概型两条件：**有限性** + **等可能性**，公式 $P(A)=\frac{M}{N}$（分子是有利样本点，分母是总样本点），难点全在排列组合计数。
- 几何概型：样本点是某区域上的均匀分布，$P(A)=\frac{\mu(A)}{\mu(\Omega)}$（长度/面积/体积之比），关键是**画图建模**。
- 经典模型：抽签公平性、生日问题、配对问题、等车问题、约会问题。（详见 **p04 1.3 古典概型与几何概型**）

### p05 1.4 条件概率与乘法公式
- 条件概率 $P(B\mid A)=\frac{P(AB)}{P(A)}$（要求 $P(A)>0$），本质是「样本空间缩小到 A」。
- 乘法公式：$P(AB)=P(A)P(B\mid A)$，可链式推广 $P(ABC)=P(A)P(B\mid A)P(C\mid AB)$。
- 牢记：条件概率 $P(B\mid A)$ 与联合概率 $P(AB)$ 是两码事。（详见 **p05 1.4 条件概率与乘法公式**）

### p06 1.5 全概率公式与贝叶斯公式
- **全概率公式** $P(B)=\sum_{i=1}^{n}P(A_i)P(B\mid A_i)$（$A_i$ 为完备事件组）：**由因溯果**，把复杂事件按原因拆开求和。
- **贝叶斯公式** $P(A_k\mid B)=\frac{P(A_k)P(B\mid A_k)}{\sum_{i=1}^{n}P(A_i)P(B\mid A_i)}$：**由果溯因**，已知结果反推各原因的概率（后验概率）。分母就是全概率，分子是分母中的第 $k$ 项。
- 反直觉提醒：疾病诊断中「检测阳性 ≠ 患病」，因为健康人群基数大，低误诊率也会产生大量假阳性。（详见 **p06 1.5 全概率公式与贝叶斯公式**）

### p07 1.6 事件的独立性和伯努利实验
- 相互独立的实用判据：$P(AB)=P(A)P(B)$（做题几乎只用它）。独立与互斥是两回事：独立看「概率相乘」，互斥看「不能同时发生」。
- 两两独立 $\neq$ 相互独立，三个事件须额外满足 $P(ABC)=P(A)P(B)P(C)$。
- n 重伯努利实验（每次成功概率 $p$，独立重复 $n$ 次，恰成功 $k$ 次）：$P_n(k)=C_n^k p^k(1-p)^{n-k}$，即二项分布。（详见 **p07 1.6 事件的独立性和伯努利实验**）

## 三、核心公式速查表

| 公式名称 | 公式 | 白话解释 |
| --- | --- | --- |
| 加法公式（两个事件） | $P(A\cup B)=P(A)+P(B)-P(AB)$ | 至少一个发生，先各自相加，再减去重叠部分 |
| 加法公式（三个事件） | $P(A\cup B\cup C)=P(A)+P(B)+P(C)-P(AB)-P(AC)-P(BC)+P(ABC)$ | 加单、减双、加三，容斥原理 |
| 对立事件 | $P(\bar{A})=1-P(A)$ | 反面概率 = 1 减正面概率 |
| 减法公式（$A\subseteq B$） | $P(B-A)=P(B)-P(A)$ | 大的减小的 |
| 条件概率 | $P(B\mid A)=\frac{P(AB)}{P(A)}$ | 已知 A 发生，B 的概率 = 同时发生概率 ÷ A 的概率 |
| 乘法公式 | $P(AB)=P(A)P(B\mid A)$ | 先 A 再 B，链式相乘 |
| 乘法公式（三个事件） | $P(ABC)=P(A)P(B\mid A)P(C\mid AB)$ | 一步步缩着算 |
| 全概率公式 | $P(B)=\sum_{i=1}^{n}P(A_i)P(B\mid A_i)$ | 按完备原因分组求和 |
| 贝叶斯公式 | $P(A_k\mid B)=\frac{P(A_k)P(B\mid A_k)}{\sum_{i=1}^{n}P(A_i)P(B\mid A_i)}$ | 分母是全概率，分子取其中一项 |
| 独立性判据 | $P(AB)=P(A)P(B)$ | 同时发生概率 = 各自概率相乘 |
| n 重伯努利公式 | $P_n(k)=C_n^k p^k(1-p)^{n-k}$ | 选位置 × 成功 k 次 × 失败 n-k 次 |

## 四、常考题型与易错点

| 类型 | 题目特征 / 易错点 | 解题套路 / 提醒 |
| --- | --- | --- |
| 计数：排列 vs 组合 | 从 n 中取 m，交换顺序是否算不同结果 | 看「顺序/位置/等级」：有差别用 $P_n^m$，无差别用 $C_n^m$ |
| 加法 vs 乘法原理 | 事件是「一步选一种」还是「分步全做」 | 一步加、分步乘；步间乘、步内加 |
| 对立事件求反面 | 「至少一个」「都不」等否定表述 | 先算对立事件概率再用 $1-P$，常比正面算更快 |
| 互斥 vs 对立 | $AB=\emptyset$ vs 还需 $A\cup B=\Omega$ | 对立必互斥，互斥不一定对立 |
| 零概率事件 | $P(A)=0$ 的事件 | 零概率 $\neq$ 不可能事件（几何概型中的单点概率为 0 但可能发生） |
| 条件概率 vs 联合概率 | 题目问「已知…求…」还是「同时发生」 | $P(B\mid A)$ 缩样本空间；$P(AB)$ 是整体概率，别混 |
| 全概率 vs 贝叶斯 | 求结果概率 vs 已知结果反推原因 | 由因溯果用全概率，由果溯因用贝叶斯 |
| 独立 vs 互斥 | 判断 $P(AB)=P(A)P(B)$ 还是 $P(AB)=0$ | $P(A),P(B)>0$ 时独立必相容、互斥必不独立 |
| 两两独立 vs 相互独立 | 三个事件 | 两两独立不够，还要 $P(ABC)=P(A)P(B)P(C)$ |
| 伯努利「至少 k 次」 | $P(k\ge1)$ 类 | 用 $1-P(k=0)$ 等对立事件简化，别逐项硬加 |

## 五、补充

- **完备事件组（划分）** 是全概率公式和贝叶斯公式的前提：把样本空间切成互不重叠的几块，每一块是一个「原因」。全概率公式其实就是「每块里 B 的概率 × 该块的权重」再相加。
- **频率与概率的对照**：频率随试验变化（随机），概率是客观常数（确定）；频率是估计值，概率是极限值。
- **抽签公平性** 贯穿全章：无论古典概型（排列法）还是全概率公式都能证明「先抽后抽概率相同」，是常考结论。

## 本章重点

> **要点**：
> - 计数是地基：加法/乘法原理、排列 $P_n^m$ 与组合 $C_n^m$，是古典概型计数的工具。
> - 事件语言：样本空间、事件运算、德摩根律，是「把文字题翻译成集合」的基本功。
> - 概率计算四大核心公式：加法公式、乘法公式、全概率公式、贝叶斯公式，外加独立性判据 $P(AB)=P(A)P(B)$ 与伯努利公式 $P_n(k)=C_n^k p^k(1-p)^{n-k}$。
> - 两条主线：古典概型（数格子）与几何概型（量面积）；由因溯果（全概率）与由果溯因（贝叶斯）。

> **常见坑**：
> - 互斥 $\neq$ 对立；独立 $\neq$ 互斥；两两独立 $\neq$ 相互独立。
> - 条件概率 $P(B\mid A)$ 与联合概率 $P(AB)$ 分不清；$P(A\mid B)$ 中分母是谁容易写反。
> - 零概率事件不一定是空集（连续情形 $P(X=x_0)=0$）。
> - 全概率/贝叶斯忘了先验证「完备事件组」这一前提，或把先验、后验、似然张冠李戴。
