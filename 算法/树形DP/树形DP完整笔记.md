## 1. 树形 DP 概述

树形 DP 就是在**树**这种数据结构上进行的动态规划。由于树的特殊拓扑结构，树形 DP 通常有两个转移方向：

| 方向 | 含义 | 使用频率 |
| --- | --- | --- |
| 自底向上（叶子→根） | 叶子的信息向根传递 | 最常用 |
| 自顶向下（根→叶子） | 根的信息向叶子传递 | 较少 |

实现方式：由于树的递归性质，树形 DP 一般通过 **DFS 递归**实现。

### 分析树形 DP 题目的四步法

1. **分析需求**：父节点要得到答案，需要子节点的哪些信息？
2. **递归返回**：子节点的信息在 DFS 时递归返回
3. **子树全集**：通过递归让每棵子树返回完整信息
4. **整合信息**：父节点整合所有子树的信息，得到自己的答案

> 树形 DP 的依赖关系比一般 DP 简单（基本就是父依赖子），但**题目不一定简单**。

## 2. 基础树形 DP

### 2.1 没有上司的舞会（洛谷 P1352）

**题意**：$N$ 个职员组成以校长为根的有根树，父节点是子节点的直接上司。举办舞会，如果某职员的直接上司来了，该职员就不会来。每个职员有快乐指数 $w_i$，求最大快乐指数总和。

**核心约束**：选了父节点就不能选子节点（相邻节点不能同时选）。

**状态设计**：

$$f[u][0] = \text{以 } u \text{ 为根的子树，} u \text{ 不选时的最大愉悦指数}$$

$$f[u][1] = \text{以 } u \text{ 为根的子树，} u \text{ 选时的最大愉悦指数}$$

**转移方程**：

- $u$ 选 → 所有子节点 $v$ 都**不能选**：

$$f[u][1] = w_u + \sum_{v} f[v][0]$$

- $u$ 不选 → 每个子节点 $v$ **可选可不选**，取 max：

$$f[u][0] = \sum_{v} \max(f[v][0],\ f[v][1])$$

**答案**：$\max(f[root][0],\ f[root][1])$

**代码框架**：

```cpp
void dfs(int u, int fa) {
    f[u][1] = w[u];  // 自己先加上
    for (int v : adj[u]) {
        if (v == fa) continue;
        dfs(v, u);
        f[u][1] += f[v][0];                    // u选，v不能选
        f[u][0] += max(f[v][0], f[v][1]);      // u不选，v随意
    }
}
// 答案 = max(f[1][0], f[1][1])
```

> **关键理解**：每个节点只有"取/不取"两种状态，取不取会影响父子节点的决策——这是树形 DP 最经典的套路。

### 2.2 最大子树和（洛谷 P1122）

**题意**：一棵树 $N$ 个节点，每个节点有权值 $w_i$（可能为负）。每次操作可以剪掉一条边，把树分成两棵，扔掉其中一棵。问最后剩余连通块的最大权值和。

**直觉**：如果一棵子树的权值和为负，剪掉它反而更好。

**状态设计**：

$$f[u] = \text{以 } u \text{ 为根的子树中，包含 } u \text{ 的最大连通块权值和}$$

**转移方程**：对每棵子树 $v$，如果 $f[v] > 0$ 就保留（合并进来），否则剪掉（相当于加 0）：

$$f[u] = w_u + \sum_{v} \max(0,\ f[v])$$

**答案**：$\max_{i=1}^{N} f[i]$（每个点都可能是最终连通块的"最高点"）

**代码框架**：

```cpp
int ans = -INF;
void dfs(int u, int fa) {
    f[u] = w[u];
    for (int v : adj[u]) {
        if (v == fa) continue;
        dfs(v, u);
        f[u] += max(0, f[v]);  // 正的才合并
    }
    ans = max(ans, f[u]);
}
```

> **注意**：答案不是 $f[root]$，而是所有 $f[i]$ 的最大值——因为最终连通块的根可以是任意节点。本题需要开 `long long`。

### 2.3 战略游戏（最小点覆盖）（洛谷 P2016）

**题意**：一棵无根树，在节点上放置最少数量的士兵。一个士兵在节点 $u$ 上可以瞭望所有与 $u$ 相连的边。求覆盖所有边的最少士兵数。

**本质**：经典的**最小点覆盖**问题——每条边至少有一个端点被选中。

**状态设计**：

$$f[u][0] = \text{以 } u \text{ 为根的子树，} u \text{ 不放士兵时覆盖子树的最少士兵数}$$

$$f[u][1] = \text{以 } u \text{ 为根的子树，} u \text{ 放士兵时覆盖子树的最少士兵数}$$

**转移方程**：

- $u$ 不放 → 所有与子节点的边只能靠子节点覆盖 → 子节点**必须放**：

$$f[u][0] = \sum_{v} f[v][1]$$

- $u$ 放 → 与子节点的边已被覆盖 → 子节点**可放可不放**：

$$f[u][1] = 1 + \sum_{v} \min(f[v][0],\ f[v][1])$$

**答案**：$\min(f[root][0],\ f[root][1])$

> **发现**：虽然题目形式和"没有上司的舞会"不同，但推出来的方程结构几乎一样——都是"自己选/不选 → 子节点受限/自由"的模式。
>
> **升级版**：消防局的建立（覆盖距离为 2），状态数会激增，课后练习做。

## 3. 树上背包

### 什么是树上背包

普通背包里物品是独立的，可以随意挑选。树上背包中物品组织成**树**，存在依赖关系：**选子节点必须先选父节点**。

思路：站在父节点 $u$ 的视角，把每棵子树 $v$ 看作一个**物品组**，给子树分配容量（名额）。

---

### 3.1 基础写法 O(n³)

**简单例题**：给定一棵树，选最多 $M$ 个节点使总权值最大。

**状态设计**：

$$f[u][j] = \text{以 } u \text{ 为根的子树，用了 } j \text{ 个容量时的最大权值}$$

**初始化**：$f[u][1] = w_u$（自己必须选，占一个体积）

**转移**：倒序枚举容量（和 01 背包一样防覆盖），对每棵子树 $v$ 分配 $k$ 个容量：

$$f[u][j] = \max_{k} \{ f[u][j-k] + f[v][k] \}$$

其中 $k$ 的范围是 $0$ 到 $j-1$（$u$ 自己占了 1 个，所以最多分 $j-1$ 给子树）。

**复杂度**：三层循环（节点 × 容量 × 分配），$O(n^3)$，只能处理 $N \le 300$ 左右。

---

### 3.2 上下界优化 O(n²)

基础写法中大量枚举是无效的——比如子树 $v$ 只有 2 个节点，你却枚举 $k$ 从 0 到 99，其中 $k > 2$ 的部分全是浪费。

**优化思路**：维护 $size[u]$（子树节点数），卡住枚举的上下界。

| 变量 | 上界 | 下界 | 解释 |
| --- | --- | --- | --- |
| $j$ | $\min(M,\ size[u]+size[v])$ | — | 整棵子树最多就这么大 |
| $k$ | $\min(j-1,\ size[v])$ | $\max(0,\ j-size[u])$ | 子树 $v$ 最多 $size[v]$；老部分至少要凑出 $j-k$ |

> $k$ 的下界比较难理解：总共要分配 $j$ 个名额，给儿子 $k$ 个，老部分要凑出 $j-k$ 个。但老部分最多只有 $size[u]$ 个节点，所以 $size[u] \ge j - k$，即 $k \ge j - size[u]$。

优化后复杂度严格 $O(n^2)$（有数学证明）。

### 3.3 选课（洛谷 P2014）

**题意**：$N$ 门课，每门课有或没有先修课（先修课是它的父节点），选 $M$ 门课使学分最大。选子课必须先选父课。

**关键处理**：题目给的可能是**森林**（多棵树），不是单棵树。

**森林转树**：加一个虚拟原点 $0$，所有没有先修课的节点连到 $0$。最后容量变为 $M+1$（因为原点也占一个位置，但原点学分为 0 不影响答案）。

**状态设计**：

$$f[u][j] = \text{以 } u \text{ 为根的子树，选 } u \text{ 且选了 } j \text{ 门课的最大学分}$$

**转移**：和树上背包一样，倒序枚举 $j$，对每棵子树分配 $k$：

$$f[u][j] = \max_{k} \{ f[u][j-k] + f[v][k] \}$$

**答案**：$f[0][M+1]$

**代码框架**（带上下界优化）：

```cpp
void dfs(int u) {
    size[u] = 1;
    f[u][1] = w[u];  // 自己占一个
    for (int v : adj[u]) {
        dfs(v);
        int maxj = min(M + 1, size[u] + size[v]);
        for (int j = maxj; j >= 1; j--) {
            int mink = max(0, j - size[u]);
            int maxk = min(j - 1, size[v]);
            for (int k = mink; k <= maxk; k++) {
                f[u][j] = max(f[u][j], f[u][j - k] + f[v][k]);
            }
        }
        size[u] += size[v];
    }
}
// 答案 = f[0][M+1]
```

## 4. 换根 DP（二次扫描）

### 什么是换根 DP

换根 DP 又叫**二次扫描**，适用于：
- 题目不指定根节点
- 根节点的变化会影响某些值（如深度、子树大小等）

**暴力**：枚举每个点为根，各跑一次 DFS → $O(n^2)$

**换根**：先任选一个根跑一次 DFS 预处理，再通过第二次 DFS 把根"换"到每个点上，利用已有信息 $O(1)$ 转移 → 总共 $O(n)$

---

### 4.1 深度之和

**题意**：给定 $N$ 个点的树，求以哪个点为根时，所有节点的深度之和最大。

**第一次 DFS**（以 1 为根）：
- 预处理 $size[u]$、$dep[u]$
- 算出 $f[1] = \sum dep[i]$

**第二次 DFS**（换根）：
当根从 $u$ 换到子节点 $v$ 时：
- $v$ 的子树（$size[v]$ 个点）深度各 $-1$
- 其余（$n - size[v]$ 个点）深度各 $+1$

$$f[v] = f[u] - size[v] + (n - size[v])$$

**答案**：$\arg\max f[i]$

**代码框架**：

```cpp
// 第一次 DFS
void dfs1(int u, int fa, int d) {
    size[u] = 1;
    dep[u] = d;
    f[1] += d;
    for (int v : adj[u]) {
        if (v == fa) continue;
        dfs1(v, u, d + 1);
        size[u] += size[v];
    }
}

// 第二次 DFS（换根）
void dfs2(int u, int fa) {
    for (int v : adj[u]) {
        if (v == fa) continue;
        f[v] = f[u] - size[v] + (n - size[v]);
        dfs2(v, u);
    }
}

// 找最大值
int ans = 1;
for (int i = 2; i <= n; i++)
    if (f[i] > f[ans]) ans = i;
```

### 4.2 破坏通信（2024 成都 ICPC 银牌题）

**题意**：给定一棵 $N$ 个节点的树，$Q$ 次查询。每次给 $U, V$，求有多少种**连通子图**（子树），使得 $U$-$V$ 路径上至少有一个节点被包含在子图中（即通信被破坏）。答案对 $998244353$ 取模。

**关键观察**：
- $U$-$V$ 路径经过 LCA
- 路径上的点被破坏 → 通信中断
- 答案 = 路径上所有点的"包含该点的连通子图数"之和（去重）

**状态设计**：

$$dp1[u] = \text{以 } u \text{ 为根的子树中，必须包含 } u \text{ 的连通子图方案数}$$

$$dp2[u] = \text{全局视角下，包含 } u \text{ 的连通子图总数（可以向上延伸）}$$

**$dp1$ 转移**（一次 DFS）：每个子节点 $v$ 可选可不选，选的话方案数是 $dp1[v]$，不选是 1 种：

$$dp1[u] = \prod_{v} (dp1[v] + 1)$$

**答案**：

$$\text{ans}(U, V) = \left(\sum_{x \in path(U,V),\ x \neq LCA} dp1[x]\right) + dp2[LCA]$$

用**树上差分**快速统计路径和。

**$dp2$ 转移**（换根）：

$$dp2[v] = dp1[v] \times \left(\frac{dp2[u]}{dp1[v] + 1} + 1\right)$$

其中 $u$ 是 $v$ 的父节点。$\frac{dp2[u]}{dp1[v]+1}$ 是从 $dp2[u]$ 中剥离 $v$ 的贡献后得到的"上方贡献"，$+1$ 是上方可以不选。

**坑**：取模下 $dp1[v]+1$ 可能等于 $0$（模后为 0），此时逆元不存在！

**解决方案**：用**前后缀积**代替除法。维护子节点的前缀积和后缀积，算 $v$ 的上方贡献时 = 前缀积 × 后缀积，完全避免除法。

> **总结**：这道题综合了 LCA + 树形 DP + 换根 DP + 树上差分 + 前后缀积，细节极多，是标准的 ICPC 银牌题。注意本题有**多组测试数据**。

## 5. 本节重点

> **本节重点**：
> - **树形 DP 核心套路**：每个节点"选/不选"两种状态，父子依赖关系决定转移方向
> - **三种经典模型**：
>   - 选/不选（相邻约束）→ $f[u][0/1]$
>   - 连通块权值和 → $f[u]$ + $\max(0, f[v])$
>   - 最小点覆盖 → $f[u][0/1]$ + $\min/\max$
> - **树上背包**：把子树当物品组分配容量，上下界优化从 $O(n^3)$ → $O(n^2)$
> - **换根 DP**：两次 DFS，第一次预处理，第二次 $O(1)$ 转移换根
> - **常见坑**：
>   - 森林要加虚拟原点转树
>   - 取模下除法要先判 0，用前后缀积替代
>   - 答案不一定在根节点，可能是任意节点
>   - 注意 `long long` 和取模
