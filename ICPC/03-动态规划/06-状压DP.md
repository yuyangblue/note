# 06 状压 DP

> 状压 DP（状态压缩 DP）：当状态里需要记录**一个集合**（哪些选了、哪些没选）时，用**二进制位**来表示集合。
> 每个 bit = 一个元素在不在集合里。n ≤ 20 左右的题目是它的主场（2^n 个状态）。
> 经典问题：TSP（旅行商）、铺砖方案数、互不攻击的国王、按子集分组的装箱。
> 整理自 B站《2026集训 - 状压DP》（up：水货Cookie），笔记按 C++17 规范重写并验证。

## 大白话引入

一个外卖小哥要送 n 个订单（n ≤ 20），从店里出发，每个订单送一次，最后回店里，问最短路线。

暴力枚举所有送餐顺序是 n! 种（20! ≈ 2.4×10¹⁸，天文数字）。但你会发现：**"已经送过哪些订单" + "现在在哪" 这两个信息，就足够决定未来的最优路线了**。至于先送谁后送谁的历史顺序，根本不重要（无后效性）！

"已经送过哪些订单"是一个集合——用 n 个 bit 表示：第 i 位是 1 就代表第 i 个订单已送。这就是状态压缩。

> 类比：手里的订单清单就是一张"已送/未送"的打勾表，n 个订单 = n 个勾选框。打勾表本身就能当状态用（每个勾选框两种状态），根本不用记"我按什么顺序打的勾"。

**注意位序**：二进制里**最右边是第 0 位**（视频强调：这很反直觉）。`01101` 表示第 0、2、3 位是 1（选了物品 0、2、3），对应十进制 13。写位运算时下标从 0 开始，很容易和题目里从 1 编号的节点搞混。

## 思维启发 & 思考流程

1. **看到 n ≤ 20（或 ≤ 22）** → 立刻想到 2^n 是 1e6 级别，状压可行
2. **问自己：状态里要不要记"一个集合"？** 如"哪些点访问过""哪些格子占了""哪些物品选了"
3. **设计状态**：`dp[mask]` 或 `dp[mask][i]`——mask 是集合的位表示，i 是额外信息（当前在哪个点、最后一格是什么）
4. **确定转移**：在 mask 基础上加一个元素 → 新 mask = `mask | (1 << k)`
5. **答案**：全 1 的 mask，或枚举全 1 mask 的最后一格取 min

**为什么 n 大就不行？** 状态数 2^n 个，n=20 → 1e6，n=25 → 3e7 内存就爆炸了，n=30 → 10 亿直接死。所以 n ≤ 20 是硬条件。

### 位运算集合操作速查（背下来）

| 操作 | 写法 | 含义 |
|------|------|------|
| 第 k 位是否为 1 | `(mask >> k) & 1` | 结果保证是 0/1，推荐这种 |
| 把第 k 位变 1 | `mask \| (1 << k)` | 加入元素 k |
| 把第 k 位变 0 | `mask & ~(1 << k)` | 移除元素 k |
| 全集 | `(1 << n) - 1` | 所有元素都在 |
| T 是 S 的子集 | `(S \| T) == S` 或 `(S & T) == T` | 两种写法等价 |
| S 的补集（相对全集） | `((1 << n) - 1) ^ S` | 不能直接 `~S`！int 会把 32 位全取反 |
| 枚举 S 的非空子集 | `for (T = S; T; T = (T - 1) & S)` | 要含空集：循环外先处理 T=0 |
| 集合元素个数 | `__builtin_popcount(S)` | 数 1 的个数（popcount） |

**几个易错点（视频重点强调）**：
- **补集必须用全集异或**：直接 `~S` 会把 int 的全部 32 位取反（S=0 时 ~S = -1，不是全集），必须 `((1<<n)-1) ^ S`
- **枚举子集为什么这样写**：`T-1` 把 T 最低位的 1 变成 0、后面的 0 全变 1，再 `& S` 把不属于 S 的位删掉——不重不漏枚举所有子集，结束条件是 T 变成 0（所以默认不含空集）
- **位运算优先级极低**：`1 << n - 1` 会被解析成 `1 << (n-1)` 吗？不会！`<<` 比 `-` 优先级低，实际是 `1 << (n - 1)`？不对——`-` 比 `<<` 高，所以 `1 << n - 1` = `1 << (n-1)`，看起来对但容易和 `(1 << n) - 1` 混。**统一加括号**，别赌优先级
- **下标从 0 开始**：题目节点从 1 编号时，记得 `i-1` 再移位

### 枚举子集的子集：O(3^n)

```cpp
#include <bits/stdc++.h>
using namespace std;

// 枚举子集的子集示意（最小声明 + 空 main 只是为了能编译验证）
// 复杂度 O(3^n)：Σ C(n,k)·2^k = (1+2)^n，推导见上文
int main() {
    int n = 3, FULL = (1 << n) - 1;
    for (int S = 1; S <= FULL; S++)            // 枚举大集合
        for (int T = S; T; T = (T - 1) & S)    // 枚举 S 的子集
            ;                                  // 这里放子集 DP 的转移
    return 0;
}
```

复杂度不是 O(2^n × 2^n) = O(4^n)，而是 **O(3^n)**。推导（视频用二项式定理）：假设 S 有 k 个元素，它的子集有 2^k 个；有 k 个元素的 S 有 C(n,k) 个，所以总枚举次数 = Σ C(n,k)·2^k = (1+2)^n = 3^n。n=15 时 3^15 ≈ 1400 万，能跑。

## 核心讲解

### 1. TSP（旅行商问题）

**是什么**：n 个城市，两两之间有距离，从城市 0 出发每个城市恰好访问一次，最后回到 0，求最短总距离。

**思考路径 & 状态设计为什么必须是两维**（视频重点讲的失败案例）：

先试只记集合：`dp[s]` = 访问完集合 s 的最短路。转移时从 `s\{u}` 加一个点 u——但**不知道当前停在哪**！比如 dp[{1,2,3}] 从 dp[{2,3}] 转移，我们不知道 {2,3} 的最后终点是 2 还是 3，就没法加 dist[终点][1]。贪心取最小的 dp[{1,2}] 和 dp[{1,3}] 也不行——终点对不上。**状态缺信息 → 加一维补上**：

**状态设计**：`dp[mask][i]` = 已经访问了 mask 里的城市、当前停在城市 i 的最短距离。

**转移**：从 i 走到没访问过的 j：
```
dp[mask | (1<<j)][j] = min(dp[mask | (1<<j)][j], dp[mask][i] + dist[i][j])
```

**答案**：全部城市访问完（mask = FULL）后，最后回起点：`min(dp[FULL][i] + dist[i][0])`。

**枚举顺序**：mask 必须从小到大（1 → FULL）。因为转移总是从"小集合"推到"大集合"，小集合先算完，大集合才能用。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<vector<int>> dist(n, vector<int>(n));
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            cin >> dist[i][j];        // 注意：距离不一定对称！dist[i][j] ≠ dist[j][i]

    int FULL = (1 << n) - 1;          // 全集：n 个城市全访问
    // dp[mask][i] = 访问了 mask 集合、当前在 i 的最短距离
    vector<vector<int>> dp(1 << n, vector<int>(n, INT_MAX));
    dp[1][0] = 0;                     // 起点：只访问了城市 0（mask=1 只有第 0 位是 1）

    for (int mask = 1; mask <= FULL; mask++) {       // 集合从小到大，保证转移顺序正确
        for (int i = 0; i < n; i++) {
            if (!(mask >> i & 1)) continue;          // i 不在集合里，跳过
            if (dp[mask][i] == INT_MAX) continue;    // 不可达的状态
            for (int j = 0; j < n; j++) {
                if (mask >> j & 1) continue;         // j 已访问过，跳过
                int nmask = mask | (1 << j);         // 加入 j
                dp[nmask][j] = min(dp[nmask][j], dp[mask][i] + dist[i][j]);
            }
        }
    }

    int ans = INT_MAX;
    for (int i = 1; i < n; i++)                      // 全部访问完，从 i 回起点 0
        ans = min(ans, dp[FULL][i] + dist[i][0]);
    cout << ans << endl;
    return 0;
}
```

**坑**：
- 起点初始化为 `dp[1][0] = 0`（mask=1 表示只访问了城市 0），不是 `dp[0][0]`
- 枚举 mask 必须从小到大，否则用到的 `dp[mask]` 可能还没算
- 不判 `dp[mask][i] == INT_MAX` 时，INT_MAX 加距离会**溢出 int 变负数**，答案错得离谱
- 下标：题目节点从 1 编号时（P1171 售货员的难题），位运算要 i-1（视频代码就是这么处理的）

**复杂度分析**：状态 O(2^n · n)，每个状态转移 O(n)，总 O(2^n · n²)。n=16 → 约 1600 万次，秒过；n=20 → 约 4 亿，理论勉强（洛谷机子能过，视频原话）。

### 2. 铺砖问题（插头 DP 入门版）

**是什么**：用 1×2 的骨牌铺满 n×m 的棋盘，求方案数。n 或 m 取较小的一维做状态（如 n ≤ 11）。

**思考路径**：逐行铺。铺到第 row 行时，唯一需要记住的"历史信息"是：**上一行有哪些列伸了一根竖骨牌下来**（这些列当前行必须接着放竖骨牌的下半截）。这就是一个集合 → 用 mask 表示。

**状态设计**：`dp[row][mask]` = 铺完前 row-1 行、第 row 行有 mask 这些列被"伸下来的竖骨牌"占住的方案数。

**转移**：对上一行的每个 mask，DFS 枚举当前行的放置方式（竖骨牌 → 伸到下一行；横骨牌 → 占当前行两列），把方案数累加到下一行状态。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// dp[row][mask] = 铺完前 row-1 行，第 row 行被竖骨牌占了 mask 这些列
// 例：n=3, m=2 时 1×2 骨牌铺满的方案数 = 3
// 代码把 n 固定为"行数"（较小的一维做状态），m 固定为"列数"（逐行推进）

int main() {
    int n, m;
    while (cin >> n >> m && (n || m)) {
        if (n * m % 2) { cout << 0 << endl; continue; }  // 面积是奇数，不可能铺满
        if (n > m) swap(n, m);                           // 让 n 是较小的一维，状态数 2^n 才小
        int FULL = (1 << n) - 1;
        vector<vector<ll>> dp(m + 1, vector<ll>(1 << n, 0));
        dp[0][0] = 1;                       // 第 0 行（哨兵行）没有伸下来的竖骨牌

        for (int row = 1; row <= m; row++) {
            for (int mask = 0; mask <= FULL; mask++) {   // 枚举上一行伸下来的占用情况
                if (!dp[row - 1][mask]) continue;        // 剪枝：上一行这个状态不可达
                // 从 mask 出发，DFS 生成当前行所有合法放置方式
                function<void(int, int)> dfs = [&](int col, int nmask) {
                    if (col == n) {          // 当前行铺满了，累加到这一行的状态
                        dp[row][nmask] += dp[row - 1][mask];
                        return;
                    }
                    if (mask >> col & 1) {   // 这列被上一行竖骨牌占了：只能放竖骨牌的下半截
                        dfs(col + 1, nmask); // 不往下一行伸，nmask 该位保持 0
                    } else {
                        dfs(col + 1, nmask | (1 << col));        // 放竖骨牌：上半截在这行，伸到下一行
                        if (col + 1 < n && !(mask >> (col + 1) & 1))
                            dfs(col + 2, nmask);                 // 放横骨牌：占当前行 col 和 col+1 两列
                    }
                };
                dfs(0, 0);
            }
        }
        cout << dp[m][0] << endl;            // 最后一行不能有伸出去的竖骨牌 → mask 必须全 0
    }
    return 0;
}
```

**坑**：`mask` 是**上一行**的占用情况，`nmask` 是当前行要伸到**下一行**的情况——两者别搞混。横骨牌要检查 `col+1` 列也没被占（`!(mask >> (col+1) & 1)`），且 `col+2` 不越界。

**复杂度分析**：状态 O(m · 2^n)，每个状态 DFS 生成转移。n ≤ 11 时 2^11 = 2048，轻松过。

### 3. 互不攻击（国王，P1896）

**是什么**：n×n 棋盘放 k 个国王，任意两个国王不能相邻（国王攻击周围 8 格：上下左右 + 4 个斜角），求方案数。

**思考路径**：逐行放。第 row 行的放置只受两件事影响：**上一行怎么放的**（8 格攻击范围）和 **还剩几个国王要放**。上一行的放置是一个集合 → mask 表示；还剩几个国王 → cnt 维度。

**状态设计**：`dp[row][mask][c]` = 前 row 行、第 row 行的放置状态是 mask、一共放了 c 个国王的方案数。

**位运算判断合法性**（视频的核心 trick，比模拟优雅）：
- **行内合法**：`mask & (mask << 1) == 0`——存在相邻 1 就是行内打架
- **相邻两行合法**：上一行 t 的每个 1 会封锁下一行的 i-1、i、i+1 三个位置，封锁集合 = `t | (t<<1) | (t>>1)`，下一行 s 要满足 `s & (t | (t<<1) | (t>>1)) == 0`

**转移**：`dp[i][s][k] += dp[i-1][t][k - popcount(s)]`（前一行凑出 k-popcount(s) 个国王）。

**预处理优化**：把行内合法的 mask 提前筛出来（视频：合法行数量是**斐波那契数列**——开头是 0 则有 F(n-1) 种、开头是 1 则第二位必须是 0 有 F(n-2) 种），再把合法相邻对也预处理，能省一大截。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

int n, k;
bool ok[1 << 10];             // ok[mask] = 这一行自身合法（行内无相邻国王）
int cnt[1 << 10];             // cnt[mask] = 这个 mask 里有多少个国王（1 的个数）
ll dp[10][1 << 10][100];      // dp[row][mask][c] = 前 row 行、第 row 行状态 mask、共放了 c 个国王

int main() {
    cin >> n >> k;
    // 预处理：筛出所有行内合法的放置状态
    for (int mask = 0; mask < (1 << n); mask++) {
        // mask & (mask << 1) != 0 说明存在相邻的 1（比如 0110），行内打架，非法
        if (!(mask & (mask << 1))) {
            ok[mask] = true;
            cnt[mask] = __builtin_popcount(mask);   // 数 1 的个数
        }
    }
    dp[0][0][0] = 1;                      // 哨兵行：第 0 行不放国王
    for (int row = 1; row <= n; row++) {
        for (int cur = 0; cur < (1 << n); cur++) {
            if (!ok[cur]) continue;       // 当前行自身非法，跳过
            for (int pre = 0; pre < (1 << n); pre++) {
                if (!ok[pre]) continue;   // 上一行自身非法，跳过
                if (cur & pre) continue;              // 上下相邻 → 冲突
                if (cur & (pre << 1)) continue;       // 左斜对角相邻 → 冲突
                if (cur & (pre >> 1)) continue;       // 右斜对角相邻 → 冲突
                int ccur = cnt[cur];
                for (int c = ccur; c <= k; c++)       // 累计国王数
                    dp[row][cur][c] += dp[row - 1][pre][c - ccur];
            }
        }
    }
    ll ans = 0;
    for (int mask = 0; mask < (1 << n); mask++)       // 第 n 行任意合法状态都行
        ans += dp[n][mask][k];
    cout << ans << endl;
    return 0;
}
```

**坑**：
- `__builtin_popcount` 只对 int 有效，结果直接当国王数用没问题
- 斜角冲突用 `cur & (pre << 1)` 和 `cur & (pre >> 1)` 两个方向分别查，缺一个都会漏算（国王的 4 个斜角 = 左上/右上对上一行各偏一位）
- 三方向冲突检查等价于视频里的一行 `s & (t | t<<1 | t>>1) == 0`，两种写法都对
- dp 第三维开 k+1 以上（这里 100），别开成 `[k]`——转移里要访问 `c - ccur`，c 从 ccur 开始
- **答案开 long long**：n=9 方案数很大，int 会爆（视频特意强调）

**复杂度分析**：预处理 O(2^n)，转移 O(n · 4^n · k)。n ≤ 9 时 4^9 = 262144，乘上 k 维度也能过；预处理合法行后更快。

### 4. 枚举子集 DP：背单词（CCPC 题）

**是什么**：有 n 种长度的单词，学了长度 K 就会把该长度的全背下来（体积 c[i]），每天最多学 W 个，求背完所有单词的最小天数。n 很小（≤ 13），W 较大。

**思考路径**：长度数量 ≤ 13 → 状压。两种思路（视频讲了两种）：

**解法 1：TSP 变体**（按顺序转移）。把"背单词的顺序"看作一个排列，DP 值是一个数对 `(已用背包数, 当前背包剩余体积)`——因为只知道"用了几个背包"不够，还得知道当前背包还能装多少才能决定下一个要不要开新背包。贪心"放得下就放"正确。复杂度 O(n²·2^n)，和 TSP 一样。

**解法 2：按天转移**（枚举子集，更直观，视频推荐）。`dp[S]` = 已经背完集合 S 的最小天数。枚举 S 的真子集 T 作为"之前的天"，`S - T`（差集）作为"最后一天背的"，如果差集的体积和 ≤ W，就能一天背完：

```
dp[S] = min(dp[S], dp[T] + 1)    // T ⊂ S，且 S^T 的体积和 <= W
```

```cpp
#include <bits/stdc++.h>
using namespace std;

// 背单词/分组装箱：n 种物品体积 c[i]，每组容量 W，求最小分组数（每组体积和 <= W）
// 按天转移：dp[S] = 已背完集合 S 的最小天数
int main() {
    int n, W;
    cin >> n >> W;
    vector<int> c(n);
    for (int i = 0; i < n; i++) cin >> c[i];        // 每种长度的单词数量（体积）

    int FULL = (1 << n) - 1;
    vector<int> dp(FULL + 1, 1e9);
    dp[0] = 0;                                      // 什么都没背，0 天
    for (int S = 1; S <= FULL; S++) {
        // 情况 1：S 全部一天背完（T = 空集）
        int sum0 = 0;
        for (int i = 0; i < n; i++)
            if (S >> i & 1) sum0 += c[i];
        if (sum0 <= W) dp[S] = 1;
        // 情况 2：枚举 S 的非空真子集 T 作为"之前的天"
        // (S-1)&S 跳过 S 自己；循环条件 T!=0 保证 T 非空，T=0 已由情况 1 处理
        for (int T = (S - 1) & S; T; T = (T - 1) & S) {
            int diff = S ^ T;                       // 差集 = 最后一天背的集合
            int sum = 0;
            for (int i = 0; i < n; i++)
                if (diff >> i & 1) sum += c[i];
            if (sum <= W) dp[S] = min(dp[S], dp[T] + 1);
        }
    }
    cout << dp[FULL] << endl;
    return 0;
}
```

**坑**：
- 枚举子集时**空集要单独处理**（`T = (S-1)&S` 开始保证 T 非空，空集对应"S 一天全背完"要提前判断），否则 `dp[0] + 1 = 1` 这个转移会漏
- 差集用 `S ^ T` 求（T ⊆ S 时异或就是差集），比 `S & ~T` 简洁
- 算 sum 是 O(n)，可以预处理每个子集的体积和（`sum[S] = sum[S 去掉最低位] + c[最低位]`）优化到 O(3^n)

**复杂度分析**：外层 2^n，内层枚举子集共 O(3^n)，每个算 sum O(n) → O(n·3^n)。n=13 时 3^13 ≈ 160 万，秒过。

> 等价洛谷题：**P5911 [POI2004] PRZ**（一群人过桥，每组重量 ≤ W、时间取组内最大值）——同一套"枚举子集分组"模板，把"天数 +1"换成"组时间取 max"即可。

---

### 5. 进阶：从大到小安排的状压（产线检查，2024 集训压轴）

**是什么**：N（≤ 20）条产线，K 条不合格（第 i 条罚款 a_i），M 条质量检查员各查一个区间 [L,R]，检查员会找到区间内罚款最高的不合格产线并罚款。可以**重新排列产线**，最小化总罚款。

**难点**：一个区间的代价是"区间内最大值"——普通的"按访问顺序转移"（TSP 式）**没法算区间代价**：填下一个数时不知道它是不是区间最大值。

**关键观察（视频的核心 trick）**：**从大到小安排数字**（K → 1）。已经填的数字都比后填的大，所以"某个位置填下数字 x 后，凡是被 x 夹住的区间，最大值就确定为 x 了，之后不会再变"。

**状态设计**：`S` 的第 i 位 = 1 表示位置 i 已经安排了数字。当前要填的数字是 `K - popcount(S) + 1`（已经填了 popcount(S) 个更大的数）。

**转移**：在位置 i 填当前数字 x 时，x 左边第一个已填位置 L、右边第一个已填位置 R——所有 `L < l <= i <= r < R` 的区间 [l,r] 的最大值都是 x。这些区间的个数 count 用**二维前缀和**快速求（预处理桶 c[L][R] 存区间 [L,R] 出现次数）：

```
dp[S] = min(dp[S], dp[S ^ (1<<i)] + count * x)
```

这个题的套路总结：**"取最大值"类代价问题，按从大到小填数字，把"区间最大值是谁"这个未来信息变成"已经确定"的当下信息**——比 TSP 直接排列高一个段位，等基础状压熟了再啃。
