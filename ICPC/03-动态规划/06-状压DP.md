# 06 状压 DP

> 状压 DP（状态压缩 DP）：当状态里需要记录**一个集合**（哪些选了、哪些没选）时，用**二进制位**来表示集合。
> 每个 bit = 一个元素在不在集合里。n ≤ 20 左右的题目是它的主场（2^n 个状态）。
> 经典问题：TSP（旅行商）、铺砖方案数、互不攻击的国王/皇后。

## 大白话引入

一个外卖小哥要送 n 个订单（n ≤ 20），从店里出发，每个订单送一次，最后回店里，问最短路线。

暴力枚举所有送餐顺序是 n! 种（20! 天文数字）。但你会发现：**"已经送过哪些订单" + "现在在哪" 这两个信息，就足够决定未来的最优路线了**。至于先送谁后送谁的历史顺序，根本不重要（无后效性）！

"已经送过哪些订单"是一个集合——用 n 个 bit 表示：第 i 位是 1 就代表第 i 个订单已送。这就是状态压缩。

## 思维启发 & 思考流程

1. **看到 n ≤ 20（或 ≤ 22）** → 立刻想到 2^n 是 1e6 级别，状压可行
2. **问自己：状态里要不要记"一个集合"？** 如"哪些点访问过""哪些格子占了""哪些物品选了"
3. **设计状态**：`dp[mask]` 或 `dp[mask][i]`——mask 是集合的位表示，i 是额外信息（当前在哪个点、最后一格是什么）
4. **确定转移**：在 mask 基础上加一个元素 → 新 mask = mask | (1 << k)
5. **答案**：全 1 的 mask，或枚举全 1 mask 的最后一格取 min

**为什么 n 大就不行？** 状态数 2^n 个，n=20 → 1e6，n=25 → 3e7 内存就爆炸了，n=30 → 10 亿直接死。所以 n ≤ 20 是硬条件。

### 常用位运算（背下来）

| 操作 | 写法 | 含义 |
|------|------|------|
| 第 k 位是否为 1 | `mask >> k & 1` | 判断元素 k 在不在集合 |
| 把第 k 位变 1 | `mask \| (1 << k)` | 加入元素 k |
| 把第 k 位变 0 | `mask & ~(1 << k)` | 移除元素 k |
| 全集 | `(1 << n) - 1` | 所有元素都在 |
| 枚举子集 | `for (sub = mask; sub; sub = (sub-1) & mask)` | 遍历 mask 的所有非空子集 |

## 核心讲解

### 1. TSP（旅行商问题）

- **状态**：`dp[mask][i]` = 已经访问了 mask 里的城市，当前在 i 城市的最短距离
- **转移**：从 i 走到没访问过的 j → `dp[mask|(1<<j)][j] = min(dp[mask|(1<<j)][j], dp[mask][i] + dist[i][j])`
- **答案**：`min(dp[全1][i] + dist[i][0])`（最后回起点）
- O(2^n · n²)，n=16 轻松，n=20 勉强

### 2. 铺砖问题（插头 DP 入门版）

- 例：用 1×2 的骨牌铺满 n×m 的棋盘（n 或 m 较小，如 n ≤ 10），求方案数
- **状态**：`dp[row][mask]` = 铺到第 row 行，当前行哪些列被"伸上来的竖骨牌"占了（mask 的位表示）
- **转移**：从上一行的 mask 推出当前行所有可能的放置方式，逐行累加方案数
- 需要**预处理好所有合法行的转移**，避免每行都暴力枚举（O(2^n) 行状态 × 转移）

### 3. 互不攻击（国王/皇后）

- 例：n×n 棋盘放 k 个国王，任意两个不能相邻（8 方向），求方案数
- **状态**：`dp[row][mask][cnt]` = 前 row 行、当前行放置状态 mask、共放了 cnt 个国王的方案数
- **转移**：检查 mask 自身合法（无相邻 1）+ 与上一行 mask2 不冲突（上下、斜对角不相邻）

## C++ 代码

### 例 1：TSP（完整可运行）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<vector<int>> dist(n, vector<int>(n));
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            cin >> dist[i][j];

    int FULL = (1 << n) - 1;
    // dp[mask][i] = 访问了 mask 集合、当前在 i 的最短距离
    vector<vector<int>> dp(1 << n, vector<int>(n, INT_MAX));
    dp[1][0] = 0;                    // 从城市 0 出发，mask=1 表示只访问了 0

    for (int mask = 1; mask <= FULL; mask++) {       // 枚举集合（从小到大，保证转移顺序）
        for (int i = 0; i < n; i++) {
            if (!(mask >> i & 1)) continue;          // i 不在集合里，跳过
            if (dp[mask][i] == INT_MAX) continue;    // 不可达
            for (int j = 0; j < n; j++) {
                if (mask >> j & 1) continue;         // j 已访问，跳过
                int nmask = mask | (1 << j);         // 加入 j
                dp[nmask][j] = min(dp[nmask][j], dp[mask][i] + dist[i][j]);
            }
        }
    }

    int ans = INT_MAX;
    for (int i = 1; i < n; i++)                      // 全访问完，回到起点 0
        ans = min(ans, dp[FULL][i] + dist[i][0]);
    cout << ans << endl;
    return 0;
}
```

**坑**：
- 起点城市 0 初始化为 `dp[1][0] = 0`（mask=1 只有第 0 位是 1）
- 枚举 mask 必须从小到大（1→FULL），因为转移是从小集合到大集合
- 不判 `dp[mask][i] == INT_MAX` 会做无用转移，但更危险的是 INT_MAX 加距离会溢出 int

**复杂度分析**：O(2^n · n²)。n=16 → 1600 万状态转移，秒过；n=20 → 4 亿，优化后勉强。

### 例 2：铺砖（P1437? 经典骨牌覆盖，n ≤ 11）

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// dp[row][mask] = 铺完前 row-1 行，第 row 行被竖骨牌占了 mask 这些列
// 例：n=3, m=2 时 1×2 骨牌铺满的方案数 = 3

int main() {
    int n, m;
    while (cin >> n >> m && (n || m)) {
        if (n * m % 2) { cout << 0 << endl; continue; }  // 面积奇数不可能铺满
        // 让 n 是行数（较小的一维做状态），m 是列数
        if (n > m) swap(n, m);
        int FULL = (1 << n) - 1;
        vector<vector<ll>> dp(m + 1, vector<ll>(1 << n, 0));
        dp[0][0] = 1;                       // 第 0 行没有"伸上来"的竖骨牌

        for (int row = 1; row <= m; row++) {
            for (int mask = 0; mask <= FULL; mask++) {   // 上一行的 mask
                if (!dp[row - 1][mask]) continue;
                // 从上一行 mask 出发，枚举当前行所有合法放置方式（DFS 生成）
                function<void(int, int)> dfs = [&](int col, int nmask) {
                    if (col == n) {          // 铺满一行，累加到下一行状态
                        dp[row][nmask] += dp[row - 1][mask];
                        return;
                    }
                    if (mask >> col & 1) {   // 该列被竖骨牌占了：跳过（放一个"竖"的延续）
                        dfs(col + 1, nmask);
                    } else {
                        dfs(col + 1, nmask | (1 << col));        // 放竖骨牌：伸到下一行
                        if (col + 1 < n && !(mask >> (col + 1) & 1))
                            dfs(col + 2, nmask);                 // 放横骨牌：占当前行两列
                    }
                };
                dfs(0, 0);
            }
        }
        cout << dp[m][0] << endl;            // 最后一行没有伸出去的竖骨牌
    }
    return 0;
}
```

**坑**：`dfs` 里 `mask` 是**上一行**的占用情况，`nmask` 是当前行被竖骨牌伸下去的情况——两者别搞混。横骨牌要检查 `col+1` 列也没被占，且 `col+2` 不越界。

**复杂度分析**：状态 O(m · 2^n)，每个状态 DFS 生成转移 O(2^n) 内；n ≤ 11 时 2^11 = 2048，轻松过。
