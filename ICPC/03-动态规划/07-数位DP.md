# 07 数位 DP

> 数位 DP：**按数字的每一位来 DP**，解决"统计 [L, R] 范围内满足某条件的数的个数"。
> 经典问题：不含 4 / 不含 62 / 数位和整除 / 回文数位。
> 核心套路：**记忆化搜索 + limit 标记**——从高位到低位逐位填数字，用 limit 判断当前位是否被上界卡住。

## 大白话引入

数一数 1 到 1000 里有多少个数字**不含 4**？

暴力从 1 数到 1000 当然可以，但换成 1 到 10^18 就彻底没戏了。换个思路：**一位一位地构造数字**。第一位可以是 0~9（不含 4），第二位也是 0~9（不含 4）……最后把符合条件的组合数出来。这不就是"按位做选择"嘛——天然适合 DP。

难点只有一个：**不能超过上界 N**。比如 N=345，你第一位填了 3，第二位就只能填 0~4；但如果你第一位填了 2（已经比 3 小了），后面就随便填 0~9。这个"前面是否已经比上界小了"就是 `limit` 标记。

## 思维启发 & 思考流程

1. **看到"统计 [L, R] 内满足条件的数"** → 想到数位 DP，用**前缀和技巧**：`f(R) - f(L-1)`
2. **把数字拆成每一位**：存进数组，从最高位开始逐位填
3. **设计 DFS 参数**（这是数位 DP 的灵魂）：
   - `pos`：当前填到第几位
   - `limit`：前几位是否紧贴上界（1 = 被卡住，这一位有限制；0 = 随便填）
   - 其他按题目加的：`lead`（前导零）、上一位是什么（不含 62）、数位和等
4. **记忆化**：`memo[pos][...]` 只在 `limit == 0` 时才能存/取！
   - 原因：limit=1 的情况每个数字只有一个，缓存了反而错；limit=0 时"后面随便填"的结果对任何前缀都通用
5. **答案**：`f(R) - f(L-1)`

### 为什么必须 [L, R] 拆成 f(R) - f(L-1)？

数位 DP 天然统计的是"0 到 N 的个数"。所以 [L, R] 的答案 = f(R) - f(L-1)，L-1 可以是 0 或 -1，统一转成 f(R) - f(L-1) 处理，注意 L=0 时 L-1 = -1 要特判（f(-1) = 0）。

## 核心讲解

### 模板状态

```cpp
// 例：统计 [0, N] 内不含 4 的数的个数
// dfs(pos, limit)：
//   pos   = 当前填第几位（从最高位 0 开始）
//   limit = 前几位是否贴上界
typedef long long ll;              // 数位 DP 结果可能很大，统一用 long long
ll dfs(int pos, bool limit) {
    if (pos == len) return 1;            // 所有位都填完了，这是一个合法数
    if (!limit && memo[pos] != -1) return memo[pos];  // 只有 limit=0 才能用缓存！
    int up = limit ? digit[pos] : 9;     // 被卡住则只能填到 digit[pos]，否则 0~9
    ll res = 0;
    for (int d = 0; d <= up; d++) {
        if (d == 4) continue;            // 不含 4 的限制
        res += dfs(pos + 1, limit && d == up);
        // 新 limit：之前被卡住 && 这一位又顶到上界 → 继续卡住
    }
    if (!limit) memo[pos] = res;         // 只缓存 limit=0 的结果
    return res;
}
```

### 经典变体

| 题目 | 额外状态 | 说明 |
|------|---------|------|
| 不含 62（P2657） | `pre`（上一位是几） | 当前位是 6 且下一位 2 不合法 |
| 数字和整除（P4124?） | `sum`（数位和） | dp 里带数位和，最后检查 sum % k == 0 |
| 含前导零（P2602） | `lead`（前面是否全 0） | 前导零不计入统计，且 0 本身要特判 |
| 回文数位 | 首尾指针 | 双向构造，比较首尾位 |

### 复杂度

状态数 O(len × 状态数)，转移 O(10)。len 最多 19 位（long long），所以数位 DP 几乎都是"常数级"——无论 N 多大（10^18）都只要几十个状态 × 10 转移。这就是它吊打暴力的原因。

## C++ 代码

### 例 1：不含 4 也不含 62（P2657 windy 数变体，完整可运行）

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

int digit[20];                // N 的每一位（从高到低）
ll memo[20][10][2];           // memo[pos][pre][limit] 记忆化

// 统计 [0, N] 中不含 4、不含连续"62"的个数
// pos: 当前位（0 = 最高位）；pre: 上一位数字（10 表示还没有）
// limit: 是否被上界卡住；lead: 是否还在前导零阶段
ll dfs(int pos, int pre, bool limit, bool lead) {
    if (pos == -1) return 1;                      // 填完了，这个数合法
    if (!limit && !lead && memo[pos][pre][0] != -1)
        return memo[pos][pre][0];                 // 只有 limit=0 且非前导零才能缓存

    int up = limit ? digit[pos] : 9;
    ll res = 0;
    for (int d = 0; d <= up; d++) {
        if (d == 4) continue;                     // 不含 4
        if (!lead && pre == 6 && d == 2) continue; // 前一位 6 后一位 2 → 不含 62
        // 新 limit：原来被卡 && 这一位顶到上界
        res += dfs(pos - 1, d, limit && d == up, lead && d == 0);
    }
    if (!limit && !lead) memo[pos][pre][0] = res; // 缓存通用结果
    return res;
}

ll solve(ll x) {
    if (x < 0) return 0;
    int len = 0;
    while (x) { digit[len++] = x % 10; x /= 10; } // 拆位（低位在前，dfs 从高位走）
    memset(memo, -1, sizeof(memo));
    return dfs(len - 1, 10, true, true);          // 最高位：limit=1（被 x 卡住），lead=1（前导零）
}

int main() {
    ll l, r;
    cin >> l >> r;
    cout << solve(r) - solve(l - 1) << endl;      // 前缀和技巧
    return 0;
}
```

**坑**：
- `pre` 初始化为 10（表示"没有上一位"），因为数字 0~9 里没有 10，不会误触发 62 判断
- `lead` 前导零必须处理：`000062` 里那个 62 不该算（它其实是数 62），所以只有 `!lead` 时才检查 62
- 记忆化数组下标要包含所有"影响结果的参数"：pos、pre、limit——limit 用 `[2]` 维度而不是放进 memo key，是因为 limit=1 的结果不该缓存

**复杂度分析**：状态 O(len × 10 × 2) ≈ 400 个，每个 10 种转移 → O(len × 10²) = O(4000)，无论 N 是 1e9 还是 1e18 都是瞬间出结果。

### 例 2：数字出现次数（P2602，数位和/出现次数类）

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// 统计 1 到 N 中数字 x 出现多少次（x = 0..9）
// 用"逐位贡献"思路：枚举每一位，算这一位上出现 x 的次数
ll countDigit(ll n, int x) {
    if (n <= 0) return 0;
    ll ans = 0;
    for (ll base = 1; base <= n; base *= 10) {
        ll higher = n / (base * 10);     // 高位部分
        ll cur = (n / base) % 10;        // 当前位
        ll lower = n % base;             // 低位部分

        if (x == 0) {                    // 0 要特判：不能有前导零
            if (higher == 0) break;      // 最高位不可能是 0
            ans += (higher - 1) * base + (cur == 0 ? lower + 1 : base);
        } else {
            ans += higher * base;        // 高位 0..higher-1 时，当前位取 x 都有 base 种
            if (cur > x) ans += base;    // 当前位 > x，多一组 higher 情况
            else if (cur == x) ans += lower + 1;   // 当前位 == x，低位 0..lower
        }
    }
    return ans;
}

int main() {
    ll l, r;
    cin >> l >> r;
    for (int x = 0; x <= 9; x++)
        cout << countDigit(r, x) - countDigit(l - 1, x) << " ";
    cout << endl;
    return 0;
}
```

**坑**：数字 0 的出现次数要单独处理前导零（`higher == 0` 直接 break，且用 `higher - 1`）。如果直接套 x>0 的公式，0 会被多算一整个最高位。

**复杂度分析**：O(log₁₀ n) 逐位算，n=1e18 只需 19 轮，比数位 DP 模板还快。
