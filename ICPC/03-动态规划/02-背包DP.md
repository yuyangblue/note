# 02 背包 DP

> 背包问题是动态规划里最经典的模型：**给定容量，选物品使价值最大**。

## 大白话引入

去自助餐厅：每道菜有"占肚子的体积"和"好吃程度（价值）"，你的胃容量有限。怎么点才能让总好吃程度最大？

- 每道菜**只能拿一次** → 0/1 背包
- 每道菜**可以无限续盘** → 完全背包
- 每道菜**限拿 k 盘** → 多重背包
- 菜品**分区域，每区只能拿一盘** → 分组背包

进阶玩法（对应进阶篇）：
- 不同菜区规则混在一起（有的只能拿一次、有的无限续、有的限购）→ 混合背包
- 既要考虑体积又要考虑重量（两个限制）→ 二维费用背包
- 不问"最多好吃"而是问"恰好凑满胃有多少种点法" → 方案数背包
- 先全点一遍，然后问"去掉某道菜还能不能凑满" → 可撤销背包
- 不光要最大好吃值，还要知道具体点了哪几道 → 输出最优方案

## 思维启发 & 思考流程

拿到背包题，别急着写代码。按下面的顺序走一遍，每一步都有"为什么"。

### 第一步：认出这是背包问题

一道题是背包，通常有三个特征：

1. 有一堆**物品**，每个物品有"代价"（重量 / 体积 / 时间）和"收益"（价值 / 分数）
2. 有一个**总容量限制**（背包容量 / 总时间 / 总钱数）
3. 问：怎么选，让总收益最大（或恰好凑出某个值）

### 第二步：确定是哪种背包

问自己：**每个物品能用几次？**

| 能用几次 | 类型 |
|---------|------|
| 一次 | 0/1 背包 |
| 无限次 | 完全背包 |
| 有限 k 次 | 多重背包 |
| 每组最多选一个 | 分组背包 |

### 第三步：先手算一个最小例子，别急着抽象

很多人的误区是一上来就写 `dp[j] = max(...)`。先拿一个手算都算得过来的例子，把"答案是怎么来的"想清楚：

> 容量 V = 5，两个物品：(重量 2, 价值 3)、(重量 3, 价值 4)。最大价值是多少？

手算：两个都选，2 + 3 = 5 刚好装满，价值 3 + 4 = **7**。比只选一个（3 或 4）都大。

那我是怎么知道"两个都选"最好的？因为我**比较了每种"选/不选"的组合**。这个"比较所有组合"的动作，就是要写进 dp 里的东西。

### 第四步：从二维 dp 出发——先正确，再优化

把"比较"形式化。用 `dp[i][j]` 表示：**考虑前 i 个物品、容量为 j，能装的最大价值**。

对第 i 个物品，只有两种选择，取更好的那个：

```
dp[i][j] = max(
    dp[i-1][j],              // 不选 i：容量 j 留给前 i-1 个物品
    dp[i-1][j - w[i]] + v[i] // 选 i：腾出 w[i] 的空间，加上它的价值
)
```

二维版本**不需要考虑遍历顺序**——`dp[i][j]` 永远只读上一行 `dp[i-1][...]` 的值，天然正确。

### 第五步：滚成一维，为什么必须倒序

观察：`dp[i]` 这一行只依赖 `dp[i-1]` 这一行，更早的行用完就扔。所以可以**只留一行数组**滚动更新，空间从 O(NV) 降到 O(V)。

但一维有个致命问题：`dp[j] = max(dp[j], dp[j-w] + v)` 里的 `dp[j-w]`，到底是**上一行**（没选过当前物品）还是**这一行**（已经选过）的值？

- **正序**（j 从小到大）：`dp[j-w]` 可能已经被本轮更新过 → 同一个物品被反复选 → 变成完全背包了！
- **倒序**（j 从大到小）：更新 `dp[j]` 时，`dp[j-w]` 还是上一行的旧值 → 每个物品最多选一次 ✅

这就是全篇的灵魂，用最小例子看一眼就懂：

```
物品 w=1, v=1
正序:
dp[1] = max(dp[1], dp[0]+1) = 1
dp[2] = max(dp[2], dp[1]+1) = 2   ← 用了刚更新过的 dp[1]，物品被用了两次！
倒序:
dp[2] = max(dp[2], dp[1]+1) = 1   ← dp[1] 还是旧值 0
dp[1] = max(dp[1], dp[0]+1) = 1
```

### 第六步：求什么决定 dp 存什么

- 求最大价值 → `dp[j]` 存最大值
- 求**方案数** → 转移用加法，`dp[0] = 1` 打底（见进阶篇）
- 求**恰好装满** → 初始化全部 `-INF`，只留 `dp[0] = 0`（没装满的状态永远不可达）
- 求**输出方案** → 多开一个 `pre[j]` 记录来源（见进阶篇）

> 小提示：数据范围大（V 或 c 到 1e5 以上）时还要考虑二进制拆分、单调队列等优化，见下文。

## 基础篇：四种经典背包

### 1. 0/1 背包

**状态**：`dp[j]` = 容量为 j 的背包能装的最大价值（一维滚动版）
**转移**：`dp[j] = max(dp[j], dp[j - w[i]] + v[i])`
**遍历**：容量**倒序**，保证每个物品只用一次（理由见思维启发第五步）

```cpp
#include <bits/stdc++.h>
using namespace std;

// 0/1 背包：N 个物品，容量 V，每个物品重量 w[i]、价值 v[i]，最多选一次
int main() {
    int n, V;
    cin >> n >> V;
    vector<int> w(n + 1), v(n + 1);
    for (int i = 1; i <= n; i++) cin >> w[i] >> v[i];

    vector<int> dp(V + 1, 0);
    for (int i = 1; i <= n; i++) {              // 枚举物品
        // 容量倒序！如果用正序，dp[j-w[i]] 可能是本轮已更新的，
        // 会导致同一个物品被反复选取（那就成完全背包了）
        for (int j = V; j >= w[i]; j--) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
            // 不取：dp[j]；取：腾出 w[i] 空间 + 当前价值
        }
    }
    cout << dp[V] << endl;                      // 容量 V 的最大价值
    return 0;
}
```

**复杂度分析**：O(N·V) 时间，O(V) 空间。N、V 到 1e4 级别没问题；1e5 级别要另想办法。

### 2. 完全背包

**和 0/1 唯一区别：容量正序遍历。**

为什么正序就变"无限次"了？正序时 `dp[j-w]` 可能是本轮已更新的值，等于允许"已经选过当前物品"的状态再选一次 → 无限续杯。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, V;
    cin >> n >> V;
    vector<int> w(n + 1), v(n + 1);
    for (int i = 1; i <= n; i++) cin >> w[i] >> v[i];

    vector<int> dp(V + 1, 0);
    for (int i = 1; i <= n; i++) {
        // 正序！让 dp[j-w[i]] 可能是本轮更新过的 → 允许无限取同一个物品
        for (int j = w[i]; j <= V; j++) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    cout << dp[V] << endl;
    return 0;
}
```

**一句话记忆**：0/1 倒序防重复，完全正序求无限。两段代码只有循环方向不同！

### 3. 多重背包（二进制优化）

**问题**：每个物品最多取 c[i] 个。朴素做法是把 c[i] 份复制出来当 0/1 做，O(N·V·c_max) 太慢。

**优化：二进制拆分**——把 c[i] 拆成 1, 2, 4, 8, ... 和余数，这些数能组合出 0~c[i] 任意数量：

- 例：13 = 1 + 2 + 4 + 6，想取 5 个用 1+4，想取 10 个用 4+6
- 物品数从 c[i] 降到 log c[i] 个，O(N·V·log c_max)

拆完的每个"打包物品"当 0/1 做（倒序）。

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Good { int w, v; };        // 拆出来的"打包物品"

int main() {
    int n, V;
    cin >> n >> V;
    vector<Good> goods;

    for (int i = 0; i < n; i++) {
        int w, v, c;
        cin >> w >> v >> c;                        // 重量、价值、数量上限
        // 二进制拆分：把 c 个物品打包成 1,2,4,... 和余数，每个包当 0/1 物品
        for (int k = 1; k <= c; k <<= 1) {         // k = 1,2,4,8,...
            goods.push_back({w * k, v * k});       // k 个捆成一包：重量 k*w，价值 k*v
            c -= k;
        }
        if (c > 0) goods.push_back({w * c, v * c}); // 剩下的余数单独一包
    }

    vector<int> dp(V + 1, 0);
    // 拆完后就是纯 0/1 背包，容量倒序
    for (auto &g : goods) {
        for (int j = V; j >= g.w; j--) {
            dp[j] = max(dp[j], dp[j - g.w] + g.v);
        }
    }
    cout << dp[V] << endl;
    return 0;
}
```

**为什么拆分后能组合出任意数量？** 二进制表示原理：1,2,4,...,2^k 和余数 r，任意 0~c 都能由它们组合而成（就像任何十进制数都能写成二进制）。所以选 x 个原物品 ⇔ 选若干包，DP 时自动找到最优组合，不用我们手动枚举 x。

**复杂度分析**：拆分后物品数 Σ log c[i]，总 O(V · Σ log c[i])，比朴素 O(V · Σ c[i]) 快一个量级。c=1e9 时 log₂c ≈ 30，物品膨胀从 1e9 降到 30 个。

### 4. 分组背包

**问题**：物品分成若干组，**每组最多选一个**。

**遍历顺序很讲究：组外层 → 容量倒序中层 → 组内物品内层**。

为什么组内物品放最内层？同一组内，容量 j 的 dp[j] 只能用**上一组**的值更新，组内多个物品互相竞争同一个 dp[j]，最后保留最优的那个 → 每组最多选一个 ✅。顺序写反（容量在最内层），组内多个物品会被同时选中，就错了。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, V;
    cin >> n >> V;                                 // n 组物品
    vector<vector<pair<int,int>>> groups(n + 1);   // groups[i] = 第 i 组的 (重量, 价值) 列表
    for (int i = 1; i <= n; i++) {
        int cnt;
        cin >> cnt;
        for (int j = 0; j < cnt; j++) {
            int w, v;
            cin >> w >> v;
            groups[i].push_back({w, v});
        }
    }

    vector<int> dp(V + 1, 0);
    for (int i = 1; i <= n; i++) {                 // 外层：枚举组
        // 中层容量倒序：保证用的是上一组的状态，本组物品不会互相叠加
        for (int j = V; j >= 0; j--) {
            // 内层枚举组内物品：同一容量 j 下多个物品做 max，最终只留最优的一个
            for (auto &[w, v] : groups[i]) {
                if (j >= w)
                    dp[j] = max(dp[j], dp[j - w] + v);
            }
        }
    }
    cout << dp[V] << endl;
    return 0;
}
```

**坑**：容量循环要在组内物品循环**外面**。写反了的话，组内第一个物品更新 dp[j] 后，第二个物品再用 dp[j-w] 时可能已经是本组更新过的 → 同组多选，答案错误。

## 进阶篇

> 本部分整理自 B 站《2026武汉联合多校暑期集训-背包》（up：五字的名称），代码已全部重写为 C++17。

### 1. 混合背包

**大白话**：三种背包混在一起：有的物品只能拿一次（0/1），有的能拿无限次（完全），有的最多拿 c 次（多重）。像逛超市：酸奶买一送一只能拿一次、饮料无限拿、鸡蛋限购 3 盒。

**核心思路**：不用新算法，**在 DP 循环里按物品类型分流**：

| 物品类型 | 处理方式 |
|---------|---------|
| 0/1 | 倒序枚举容量 |
| 完全 | 正序枚举容量 |
| 多重 | 先二进制拆分，再当 0/1 做（倒序） |

**坑**：多重物品**必须先拆分再进循环**，不能在循环里边拆边更新，否则拆出来的"同一个物品的多份"互相干扰。

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Good {
    int w, v;
    bool infinite;   // true = 完全背包物品（可无限取），false = 0/1（含拆好的多重包）
};

int main() {
    int n, V;
    cin >> n >> V;

    vector<Good> goods;
    for (int i = 0; i < n; i++) {
        int w, v, c;
        cin >> w >> v >> c;            // c=0 完全背包，c=1 0/1 背包，c>1 多重背包限 c 个
        if (c == 0) {
            goods.push_back({w, v, true});          // 完全物品：保留"无限"标记
        } else {
            // 多重（含 c==1）先二进制拆分，全部转成 0/1 物品
            // 坑：必须拆分完再进 DP 循环，不能边拆边更新
            for (int k = 1; k <= c; k <<= 1) {
                goods.push_back({w * k, v * k, false});
                c -= k;
            }
            if (c > 0) goods.push_back({w * c, v * c, false});
        }
    }

    vector<int> dp(V + 1, 0);
    for (auto &g : goods) {
        if (g.infinite) {
            for (int j = g.w; j <= V; j++)          // 完全：正序
                dp[j] = max(dp[j], dp[j - g.w] + g.v);
        } else {
            for (int j = V; j >= g.w; j--)          // 0/1：倒序
                dp[j] = max(dp[j], dp[j - g.w] + g.v);
        }
    }
    cout << dp[V] << endl;
    return 0;
}
```

**核心**：把三种类型归一化——多重拆成 0/1，完全打标记，循环里按标记分流。没有新算法，只是把前面四种背包组合使用。

### 2. 二维费用背包（多维背包）

**大白话**：每个物品有两个"费用维度"，背包也有两个容量限制。比如物品既占重量又占体积，背包既限重又限体积。像搬家：货车既限重量又限体积，每件家具两个都得塞得下。

**核心思路**：状态多加一维：`dp[j][k]` = 第一个费用总和为 j、第二个费用总和为 k 时的最大价值。

**转移**：`dp[j][k] = max(dp[j][k], dp[j-w1][k-w2] + v)`

**遍历顺序**（和维度数无关，只看物品类型）：
- 0/1 型：两维容量都**倒序**
- 完全型：两维容量都**正序**
- 三维、四维费用同理：多一个限制就多加一维下标

**坑**：完全背包型二维费用要把两个容量循环都改成**正序**，别只改一个。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, V1, V2;
    cin >> n >> V1 >> V2;              // 物品数、两个容量限制（如时间、金钱）
    vector<int> w1(n + 1), w2(n + 1), v(n + 1);
    for (int i = 1; i <= n; i++) cin >> w1[i] >> w2[i] >> v[i];

    // dp[j][k] = 第一个费用恰为 j、第二个恰为 k 的最大价值
    vector<vector<int>> dp(V1 + 1, vector<int>(V2 + 1, 0));
    for (int i = 1; i <= n; i++) {
        // 0/1 型：两维容量都倒序。
        // 坑：如果物品可无限取（完全型），这两个循环都要改正序，别只改一个
        for (int j = V1; j >= w1[i]; j--) {
            for (int k = V2; k >= w2[i]; k--) {
                dp[j][k] = max(dp[j][k], dp[j - w1[i]][k - w2[i]] + v[i]);
            }
        }
    }
    cout << dp[V1][V2] << endl;
    return 0;
}
```

**核心**：多一个限制就多一维。转移、遍历顺序的逻辑和一维完全一样，只是嵌套多一层。

### 3. 方案数背包（恰好装满）

**大白话**：不求最大价值，求**方案数**：用若干物品恰好凑出重量 W，有多少种选法。比如用 1、2、5 块的硬币凑 10 块有几种凑法。

**核心思路**：状态语义从"最大价值"换成"方案数"：

`dp[j]` = 凑出重量恰好为 j 的方案数

**转移**（0/1 型，倒序）：
```
dp[j] += dp[j - w[i]]          # 不选已有的方案数 + 选了当前物品的方案数
```

初始：`dp[0] = 1`（什么都不选，凑出 0，一种方案）。

**坑**：`dp[0] = 1` 是地基，漏了它所有方案数都是 0。完全背包型方案数同样把循环改正序即可。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, V;
    cin >> n >> V;
    vector<int> w(n + 1);
    for (int i = 1; i <= n; i++) cin >> w[i];

    vector<int> dp(V + 1, 0);
    dp[0] = 1;                         // 地基！什么都不选，凑出 0，恰好一种方案
    for (int i = 1; i <= n; i++) {
        for (int j = V; j >= w[i]; j--) {    // 倒序 → 每件最多选一次（0/1）
            dp[j] += dp[j - w[i]];           // 不选当前物品的方案 + 选它的方案
        }
    }
    cout << dp[V] << endl;             // 恰好凑出 V 的方案数
    return 0;
}
```

**坑**：忘写 `dp[0] = 1` 的话所有方案数都是 0。完全背包型方案数把循环改正序即可，其他不动。

### 4. 可撤销背包

**大白话**：场景：先对**全部 N 个物品**跑一遍方案数背包，然后来 Q 个询问——每次**强制不能选第 k 个物品**，问还能不能恰好凑出 W、有多少种方案。

暴力做法是每个询问重新跑一遍 O(NV)，Q 大就超时。可撤销背包的妙处：**把加物品的 DP 反过来操作，把第 k 个物品"退回去"**，O(V) 回答一个询问。

**核心思路**：方案数背包的转移是**加法**：
```
dp_new[j] = dp_old[j] + dp_old[j - w[k]]
```
加法可逆，移项即得**撤销公式**（正向遍历 j）：
```
dp_old[j] = dp_new[j] - dp_new[j - w[k]]      # 注意是 dp_new[j - w[k]]
```

**为什么撤销要正序？** 和 0/1 加物品相反：加物品倒序是为了更新时用的全是"旧值"；撤销时我们手里全是"新值"（全量跑完后的 dp），要求回"旧值"，必须正序遍历，让 `dp[j-w[k]]` 用的是**还没被撤销**（新）的值，才能正确把第 k 个物品的影响逐个扣除。

**注意**：这个方法只对**可逆运算**（加法/方案数）有效。max 不可逆，普通最大价值背包的撤销更麻烦。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, V;
    cin >> n >> V;
    vector<int> w(n + 1);
    for (int i = 1; i <= n; i++) cin >> w[i];

    // 1. 先对全部物品跑一遍 0/1 方案数背包
    vector<int> dp(V + 1, 0);
    dp[0] = 1;
    for (int i = 1; i <= n; i++)
        for (int j = V; j >= w[i]; j--)
            dp[j] += dp[j - w[i]];

    // 2. Q 个询问：强制不选第 k 个物品，问凑 W 的方案数
    int Q;
    cin >> Q;
    while (Q--) {
        int k, W;
        cin >> k >> W;
        vector<int> tmp = dp;          // 拷贝一份再操作，别污染全量 dp（下次询问还要用）
        // 撤销第 k 个物品：加物品是 dp[j] += dp[j-w]，逆运算就是相减。
        // 必须正序！让 dp[j-w[k]] 用的还是"新值"，才能把第 k 个物品的影响逐个扣除。
        // 写成倒序会得到错误答案。
        for (int j = w[k]; j <= V; j++)
            tmp[j] -= tmp[j - w[k]];
        cout << tmp[W] << endl;
    }
    return 0;
}
```

**核心**：只对可逆运算（加法/方案数）有效。max 不可逆，最大价值背包没法这么撤销。

### 5. 输出最优方案

**大白话**：光知道最大价值还不够，题目可能要求你输出**选了哪几个物品**。思路和最短路输出路径一模一样：记录"这个状态是从谁转移来的"，最后倒着还原。

**核心思路**：0/1 背包的 `dp[j]` 只存了一个数字（最大价值）。再开一个数组记录**转移来源**：`pre[j]` = 达到 `dp[j]` 时最后选的是第几个物品。

还原时从 `j = V` 出发：如果 `pre[j]` 有记录（选了物品 i），把 i 加入答案，`j -= w[i]`，继续往前跳。

**坑**：还原时 `pre[j]` 要跟 `dp` **同步更新**，只更新 dp 忘了记 pre，还原出来就是错的。完全背包的路径记录同理，但每个物品可能多次入选，还原时**不跳下标**只跳容量。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, V;
    cin >> n >> V;
    vector<int> w(n + 1), v(n + 1);
    for (int i = 1; i <= n; i++) cin >> w[i] >> v[i];

    vector<int> dp(V + 1, 0), pre(V + 1, -1);   // pre[j] = 达到 dp[j] 最后选中的物品编号
    for (int i = 1; i <= n; i++) {
        for (int j = V; j >= w[i]; j--) {
            if (dp[j - w[i]] + v[i] > dp[j]) {
                dp[j] = dp[j - w[i]] + v[i];
                pre[j] = i;                     // 坑：pre 必须和 dp 同步更新，只更新 dp 忘记 pre 就还原不出来
            }
        }
    }

    // 从容量 V 倒着跳：选了 pre[j]，容量减掉它的重量，继续往前
    vector<int> path;
    for (int j = V; j > 0 && pre[j] != -1; ) {
        path.push_back(pre[j]);
        j -= w[pre[j]];
    }
    cout << dp[V] << "\n选中物品:";
    for (auto it = path.rbegin(); it != path.rend(); ++it) cout << " " << *it;
    cout << endl;
    return 0;
}
```

**核心**：`pre[j]` 记录"这个状态从哪个物品来"，还原时倒着跳。思路和最短路输出路径一模一样。

### 6. 拓展：同余最短路 / 依赖背包

这两个进阶方向课堂上只提了一嘴，作为"自己查"的方向：

**同余最短路（大容量完全背包）**：如果容量 V 巨大（比如 1e15），普通完全背包 O(NV) 直接爆炸。把完全背包转成**图论最短路**：以某个物品重量为模数，跑同余最短路求每个余数类的最小可达重量。形式上和背包很像，但解法完全不同。

**依赖背包**：物品之间有"先选 A 才能选 B"的依赖关系，本质和**树上 DP** 很像（选父节点才能选子节点），放到树形 DP 章节再学更顺（见 **05-树形DP.md**）。
