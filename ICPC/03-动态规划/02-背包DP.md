# 02 背包 DP

> 背包问题是动态规划里最经典的模型：**给定容量，选物品使价值最大**。
> 核心就一句话：**倒序 = 0/1，正序 = 完全**。理解了为什么，四种背包（0/1、完全、多重、分组）全部拿下。

## 大白话引入

去自助餐厅：每道菜有"占肚子的体积"和"好吃程度（价值）"，你的胃容量有限。怎么点才能让总好吃程度最大？

- 每道菜**只能拿一次** → 0/1 背包
- 每道菜**可以无限续盘** → 完全背包
- 每道菜**限拿 k 盘** → 多重背包
- 菜品**分区域，每区只能拿一盘** → 分组背包

## 思维启发 & 思考流程

拿到背包题，先问自己四个问题：

1. **有几个限制条件？** 一个容量 → 一维状态；两个容量（重量+体积）→ 二维状态
2. **每个物品能用几次？** 一次 / 无限 / 有限 k 次 / 每组一个 → 决定用哪种背包
3. **求什么？** 最大价值 / 方案数 / 恰好装满 / 输出方案 → 决定 dp 存什么
4. **数据范围多大？** V 和 N 多大 → 决定要不要优化（二进制拆分、单调队列、同余最短路）

**为什么 0/1 要倒序遍历容量？**

这是整个背包问题的灵魂。`dp[j]` 表示容量 j 的最大价值。如果正序遍历：

```
物品 w=1, v=1
dp[1] = max(dp[1], dp[0]+1) = 1
dp[2] = max(dp[2], dp[1]+1) = 2   ← 用了更新后的 dp[1]！
```

同一个物品被用了两次！倒序遍历时 `dp[j]` 用的 `dp[j-w]` 还是**上一轮**（没选过当前物品）的值，保证每个物品最多选一次。

---

## 核心讲解

### 0/1 背包

- **状态**：`dp[j]` = 容量为 j 的背包能装的最大价值
- **转移**：`dp[j] = max(dp[j], dp[j - w[i]] + v[i])`（取或不取）
- **遍历**：容量**倒序**，保证每个物品只用一次

### 完全背包

- 和 0/1 唯一区别：容量**正序**遍历
- 正序时 `dp[j-w]` 可能是本轮已更新的 → 允许同一个物品被反复取 → 无限次 ✅

### 多重背包（二进制优化）

- 每个物品最多取 c[i] 个。朴素做法：复制 c[i] 份当 0/1 做，O(N·V·c_max) 太慢
- **二进制拆分**：把 c[i] 拆成 1, 2, 4, 8, ... 和余数，这些数能组合出 0~c[i] 任意数量
  - 例：13 = 1 + 2 + 4 + 6，想取 5 个用 1+4，想取 10 个用 4+6
  - 物品数从 c[i] 降到 log c[i] 个，O(N·V·log c_max)
- 拆完的每个"打包物品"当 0/1 做（倒序）

### 分组背包

- 每组最多选一个。**组外层循环 → 容量倒序中层 → 组内物品内层**
- 为什么组内物品放最内层：同一组内，容量 j 的 dp[j] 只能用**上一组**的值更新，组内多个物品互相竞争同一个 dp[j]，最后保留最优的那个 → 每组最多选一个 ✅
- 如果顺序写反（容量在最内层），组内多个物品可能被同时选中，就错了

## C++ 代码

### 例 1：0/1 背包（完整可运行）

```cpp
#include <bits/stdc++.h>
using namespace std;

// 0/1 背包：N 个物品，容量 V，每个物品重量 w[i]、价值 v[i]，最多选一次
int main() {
    int n, V;
    cin >> n >> V;
    vector<int> w(n + 1), v(n + 1);
    for (int i = 1; i <= n; i++) cin >> w[i] >> v[i];

    vector<int> dp(V + 1, 0);
    for (int i = 1; i <= n; i++) {              // 枚举物品
        // 容量倒序！如果用正序，dp[j-w[i]] 可能是本轮已更新的，
        // 会导致同一个物品被反复选取（那就成完全背包了）
        for (int j = V; j >= w[i]; j--) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
            // 不取：dp[j]；取：腾出 w[i] 空间 + 当前价值
        }
    }
    cout << dp[V] << endl;                      // 容量 V 的最大价值
    return 0;
}
```

**复杂度分析**：O(N·V) 时间，O(V) 空间。N、V 到 1e4 级别没问题；1e5 级别要另想办法。

### 例 2：完全背包（唯一区别：正序）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, V;
    cin >> n >> V;
    vector<int> w(n + 1), v(n + 1);
    for (int i = 1; i <= n; i++) cin >> w[i] >> v[i];

    vector<int> dp(V + 1, 0);
    for (int i = 1; i <= n; i++) {
        // 正序！让 dp[j-w[i]] 可能是本轮更新过的 → 允许无限取同一个物品
        for (int j = w[i]; j <= V; j++) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    cout << dp[V] << endl;
    return 0;
}
```

**一句话记忆**：0/1 倒序防重复，完全正序求无限。两段代码只有循环方向不同！

### 例 3：多重背包（二进制优化）

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Good { int w, v; };        // 拆出来的"打包物品"

int main() {
    int n, V;
    cin >> n >> V;
    vector<Good> goods;

    for (int i = 0; i < n; i++) {
        int w, v, c;
        cin >> w >> v >> c;                        // 重量、价值、数量上限
        // 二进制拆分：把 c 个物品打包成 1,2,4,... 和余数，每个包当 0/1 物品
        for (int k = 1; k <= c; k <<= 1) {         // k = 1,2,4,8,...
            goods.push_back({w * k, v * k});       // k 个捆成一包：重量 k*w，价值 k*v
            c -= k;
        }
        if (c > 0) goods.push_back({w * c, v * c}); // 剩下的余数单独一包
    }

    vector<int> dp(V + 1, 0);
    // 拆完后就是纯 0/1 背包，容量倒序
    for (auto &g : goods) {
        for (int j = V; j >= g.w; j--) {
            dp[j] = max(dp[j], dp[j - g.w] + g.v);
        }
    }
    cout << dp[V] << endl;
    return 0;
}
```

**为什么拆分后能组合出任意数量？** 二进制表示原理：1,2,4,...,2^k 和余数 r，任意 0~c 都能由它们组合而成（就像任何十进制数都能写成二进制）。所以选 x 个原物品 ⇔ 选若干包，DP 时自动找到最优组合，不用我们手动枚举 x。

**复杂度分析**：拆分后物品数 Σ log c[i]，总 O(V · Σ log c[i])，比朴素 O(V · Σ c[i]) 快一个量级。c=1e9 时 log₂c ≈ 30，物品膨胀从 1e9 降到 30 个。

### 例 4：分组背包

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, V;
    cin >> n >> V;                                 // n 组物品
    vector<vector<pair<int,int>>> groups(n + 1);   // groups[i] = 第 i 组的 (重量, 价值) 列表
    for (int i = 1; i <= n; i++) {
        int cnt;
        cin >> cnt;
        for (int j = 0; j < cnt; j++) {
            int w, v;
            cin >> w >> v;
            groups[i].push_back({w, v});
        }
    }

    vector<int> dp(V + 1, 0);
    for (int i = 1; i <= n; i++) {                 // 外层：枚举组
        // 中层容量倒序：保证用的是上一组的状态，本组物品不会互相叠加
        for (int j = V; j >= 0; j--) {
            // 内层枚举组内物品：同一容量 j 下多个物品做 max，最终只留最优的一个
            for (auto &[w, v] : groups[i]) {
                if (j >= w)
                    dp[j] = max(dp[j], dp[j - w] + v);
            }
        }
    }
    cout << dp[V] << endl;
    return 0;
}
```

**坑**：容量循环要在组内物品循环**外面**。写反了的话，组内第一个物品更新 dp[j] 后，第二个物品再用 dp[j-w] 时可能已经是本组更新过的 → 同组多选，答案错误。
