# 04 区间 DP

> 区间 DP：状态是**一段区间 [i, j]**，转移靠**枚举断点 k**，把大区间拆成两个小区间合并。
> 经典问题：石子合并、括号匹配、回文串分割。
> 套路固定：**先枚举区间长度，再枚举左端点，再枚举断点**——三层循环。

## 大白话引入

有一排石子，每个石子有个重量。每次只能合并**相邻**的两堆，代价是两堆重量之和。问全部合并成一堆的最小总代价。

关键在"相邻"两个字：如果不是相邻，直接贪心挑最轻的两堆就行；但相邻限制了合并只能在"挨着的两块"之间发生，于是问题自然变成**区间**的——合并 [i, j] 区间，最后一步一定是把某个断点 k 左边和右边分别合并好，再合成一整块。

## 思维启发 & 思考流程

拿到一道题，怎么识别它是区间 DP？

1. **操作对象是"一段连续区间"**（合并相邻、括号匹配、切字符串）
2. **问自己：大区间能不能由两个小区间拼出来？** 合并 [i,j] 的最后一步，是某个断点 k 把 [i,j] 分成 [i,k] 和 [k+1,j] 分别处理
3. **确定状态**：`dp[i][j]` = 区间 [i, j] 的答案
4. **确定转移**：枚举断点 k，`dp[i][j] = min/max(dp[i][k] + dp[k+1][j] + 合并代价)`
5. **确定遍历顺序**：⚠️ 这是最容易错的地方！

**为什么必须按"区间长度从小到大"遍历？**

因为 `dp[i][j]` 依赖的 `dp[i][k]` 和 `dp[k+1][j]` 都是**更短的区间**。如果按 i、j 从小到大普通遍历，算 `dp[1][3]` 时 `dp[2][3]` 可能还没算（因为 2 > 1，外层 i 还没走到 2）。所以外层必须是**区间长度 len**，保证算长区间前所有短区间都算完了。

```
for (len = 2; len <= n; len++)        // 先枚举区间长度
    for (i = 1; i + len - 1 <= n; i++)  // 再枚举左端点
        j = i + len - 1;              // 右端点由长度定
        for (k = i; k < j; k++)       // 最后枚举断点
            dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + cost);
```

## 核心讲解

### 1. 石子合并（线性版）

- **状态**：`dp[i][j]` = 合并区间 [i, j] 的最小代价
- **转移**：`dp[i][j] = min(dp[i][k] + dp[k+1][j]) + sum(i, j)`，k ∈ [i, j-1]
  - `sum(i, j)` 是最后一次合并的代价（区间重量总和），用**前缀和** O(1) 求
- **边界**：`dp[i][i] = 0`（单堆不用合并）
- O(n³)，n ≤ 500 可过（n=1000 需要四边形不等式优化，竞赛少见）

### 2. 石子合并（环形版，P1880）

石子摆成一圈。套路：**破环成链**——把数组复制一遍接在后面，长度 2n，然后做线性石子合并，答案取 `min(dp[i][i+n-1])`。

为什么复制成 2n 就够？环上任意一个"断开点"，在 2n 的链上对应某个长度为 n 的区间；枚举所有起点 i，就覆盖了所有断法。

### 3. 括号匹配 / 回文串

括号匹配：`dp[i][j]` = 区间 [i,j] 内能匹配的最大括号对数。转移分两种：
- 首尾配对：`dp[i][j] = dp[i+1][j-1] + 2`（若 s[i]、s[j] 配对）
- 中间断开：`dp[i][j] = max(dp[i][k] + dp[k+1][j])`

回文串相关（如"分割成最少回文子串"）同理，区间里枚举断点。

### 复杂度与技巧总结

| 技巧 | 作用 |
|------|------|
| 前缀和 | 快速求区间和，把合并代价降到 O(1) |
| 破环成链 | 环形问题复制一倍变线性，O(n³) 不变 |
| 枚举长度优先 | 保证短区间先算，是区间 DP 的**生命线** |
| 四边形不等式 | 优化 O(n³) → O(n²)，仅限满足单调性的转移，竞赛少见 |

## C++ 代码

### 例 1：石子合并（线性版，完整可运行）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n + 1), pre(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        pre[i] = pre[i - 1] + a[i];       // 前缀和：sum(i,j) = pre[j] - pre[i-1]
    }

    // dp[i][j] = 合并 [i,j] 的最小代价；初始化为无穷大
    vector<vector<int>> dp(n + 1, vector<int>(n + 1, INT_MAX));
    for (int i = 1; i <= n; i++) dp[i][i] = 0;   // 单堆不用合并

    for (int len = 2; len <= n; len++) {         // 1. 区间长度从小到大（关键！）
        for (int i = 1; i + len - 1 <= n; i++) { // 2. 左端点
            int j = i + len - 1;                 //    右端点由长度决定
            for (int k = i; k < j; k++) {        // 3. 断点
                dp[i][j] = min(dp[i][j],
                    dp[i][k] + dp[k + 1][j] + (pre[j] - pre[i - 1]));
                // 左边合并好 + 右边合并好 + 最后合并这两块的代价（区间和）
            }
        }
    }
    cout << dp[1][n] << endl;                    // 整个区间合并完的最小代价
    return 0;
}
```

**坑**：
- 初始化必须 `INT_MAX`（求最小值），否则全 0
- 断点 k 的范围是 `[i, j-1]`，不能取到 j（右边为空没意义）
- 如果外层枚举 i、内层枚举 j，`dp[2][3]` 会在 `dp[1][3]` 之后才算 → 用错值。必须长度优先！

**复杂度分析**：三层循环 O(n³)。n=500 → 1.25 亿次，C++ 勉强能过；n=1000 → 10 亿次会超时。

### 例 2：石子合并（环形版，P1880）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(2 * n + 1), pre(2 * n + 1, 0);
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        a[i + n] = a[i];                  // 破环成链：复制一份接后面
    }
    for (int i = 1; i <= 2 * n; i++) pre[i] = pre[i - 1] + a[i];

    // 同时算最大和最小
    vector<vector<int>> dpMin(2 * n + 1, vector<int>(2 * n + 1, INT_MAX));
    vector<vector<int>> dpMax(2 * n + 1, vector<int>(2 * n + 1, 0));
    for (int i = 1; i <= 2 * n; i++) dpMin[i][i] = 0;

    for (int len = 2; len <= n; len++) {         // 最长只算 n（环上区间长度不超过 n）
        for (int i = 1; i + len - 1 <= 2 * n; i++) {
            int j = i + len - 1;
            for (int k = i; k < j; k++) {
                int cost = pre[j] - pre[i - 1];
                dpMin[i][j] = min(dpMin[i][j], dpMin[i][k] + dpMin[k + 1][j] + cost);
                dpMax[i][j] = max(dpMax[i][j], dpMax[i][k] + dpMax[k + 1][j] + cost);
            }
        }
    }

    int ansMin = INT_MAX, ansMax = 0;
    for (int i = 1; i <= n; i++) {               // 枚举环的断开点（起点）
        ansMin = min(ansMin, dpMin[i][i + n - 1]);
        ansMax = max(ansMax, dpMax[i][i + n - 1]);
    }
    cout << ansMin << endl << ansMax << endl;
    return 0;
}
```

**坑**：外层 `len` 最多到 n（不是 2n）——环上我们只需要长度为 n 的区间；枚举到 2n 会算多余区间浪费一倍时间。

### 例 3：括号匹配（最长合法括号子序列）

```cpp
#include <bits/stdc++.h>
using namespace std;

bool match(char a, char b) { return (a == '(' && b == ')') || (a == '[' && b == ']'); }

int main() {
    string s;
    cin >> s;
    int n = s.size();
    // dp[i][j] = 区间 [i,j] 内最多能匹配的括号对（下标 0 基）
    vector<vector<int>> dp(n, vector<int>(n, 0));

    for (int len = 2; len <= n; len++) {                 // 长度为 1 的区间答案是 0
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            if (match(s[i], s[j]))
                dp[i][j] = max(dp[i][j], dp[i + 1][j - 1] + 1);   // 首尾配对
            for (int k = i; k < j; k++)
                dp[i][j] = max(dp[i][j], dp[i][k] + dp[k + 1][j]); // 中间断开拼起来
        }
    }
    cout << dp[0][n - 1] * 2 << endl;    // 括号对数 × 2 = 匹配字符数
    return 0;
}
```

**坑**：首尾配对时别忘了还要和"断开拼起来"取 max——`( [ ] )` 这种，首尾配对是 2 对，但 `[ ]` 内部先匹配再包外层，靠的就是两种转移取最大值。
