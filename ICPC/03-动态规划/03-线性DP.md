# 03 线性 DP

> 线性 DP：在一维/二维数组上**按顺序递推**，每个状态只依赖前面的若干个状态。
> 经典三件套：LIS（最长上升子序列）、LCS（最长公共子序列）、编辑距离。
> 线性 DP 的关键是**想清楚"以谁结尾"**——状态定义对了，转移自然就出来了。

## 大白话引入

- **LIS**：在一排照片里挑一个"越来越好看"的子集（可以跳着挑），挑得越多越好。
- **LCS**：两个人各发了一条弹幕，找两句话里**顺序相同**的最长公共部分（不要求连续）。
- **编辑距离**：把"kitten"改成"sitting"最少要几步？（允许增、删、改一个字符）

## 思维启发 & 思考流程

线性 DP 的状态设计有一个万能套路：**dp[i] = 以第 i 个元素结尾的答案**。

为什么是"以 i 结尾"而不是"前 i 个"？因为：
- 用"前 i 个"：状态之间没法直接递推（不知道上一个选了谁，没法判断递增/相等）
- 用"以 i 结尾"：上一个元素是谁就确定了，转移时只需要枚举"上一个"是谁

拿到线性 DP 题，按这个流程走：

1. **明确序列是什么**、要满足什么约束（递增？相等？连续？）
2. **设计状态**：`dp[i]` 以 i 结尾
3. **枚举转移**：上一个状态 j 满足什么条件才能接到 i 后面？
4. **答案**：不是 dp[n]，而是 `max(dp[i])`（LIS）或 dp[n][m]（LCS）——取决于最优解以谁结尾

---

## 核心讲解

### 1. LIS（最长上升子序列）

- **状态**：`dp[i]` = 以 a[i] 结尾的最长上升子序列长度
- **转移**：`dp[i] = max(dp[j] + 1)`，其中 `j < i 且 a[j] < a[i]`
- **边界**：`dp[i] = 1`（自己单独成序列）
- **答案**：`max(dp[1..n])` —— 最优解可能以任意元素结尾！

**O(n²) 朴素版**：枚举 i 和 j，n=5000 勉强，n=1e5 超时。
**O(n log n) 贪心+二分版**：维护 `tails[k]` = 长度为 k+1 的上升子序列的**最小结尾元素**。tails 数组单调递增，新元素二分找位置：
- 大于所有 tails → 扩展新长度
- 否则替换第一个 ≥ 它的位置（让未来的序列"更容易变长"）

### 2. LCS（最长公共子序列）

- **状态**：`dp[i][j]` = a 的前 i 个和 b 的前 j 个的 LCS 长度
- **转移**：
  - `a[i] == b[j]` → `dp[i][j] = dp[i-1][j-1] + 1`（匹配上，各退一格）
  - 否则 → `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`（不匹配，丢掉 a 的尾巴或 b 的尾巴）
- **边界**：`dp[0][*] = dp[*][0] = 0`
- O(n·m)，n、m 到 5000 就很吃力（1e7 状态）

### 3. 编辑距离

- **状态**：`dp[i][j]` = 把 a 的前 i 个变成 b 的前 j 个的最少操作数
- **转移**（三种操作取 min）：
  - 删除：`dp[i-1][j] + 1`（删掉 a[i]）
  - 插入：`dp[i][j-1] + 1`（在 a 尾部插入 b[j]）
  - 替换：`a[i]==b[j]` ? `dp[i-1][j-1]` : `dp[i-1][j-1] + 1`
- **边界**：`dp[i][0] = i`（全删），`dp[0][j] = j`（全插）

### 复杂度总结

| 算法 | 时间 | 空间 | 适用 |
|------|------|------|------|
| LIS 朴素 | O(n²) | O(n) | n ≤ 5000 |
| LIS 优化 | O(n log n) | O(n) | n ≤ 1e5+ |
| LCS | O(nm) | O(nm)（可滚到 O(m)） | n,m ≤ 5000 |
| 编辑距离 | O(nm) | O(nm)（可滚到 O(m)） | n,m ≤ 5000 |

## C++ 代码

### 例 1：LIS —— O(n log n) 贪心+二分（竞赛必背）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    // tails[k] = 长度为 k+1 的上升子序列的最小结尾元素
    // tails 本身单调递增，可以用二分查找
    vector<int> tails;
    for (int x : a) {
        // 找第一个 >= x 的位置：严格上升用 lower_bound
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end())
            tails.push_back(x);        // x 比所有结尾都大 → 扩展最长长度
        else
            *it = x;                   // 替换：让该长度的结尾变小，方便以后接更多元素
    }
    cout << tails.size() << endl;      // tails 的长度就是 LIS 长度
    return 0;
}
```

**如果不这么写会怎样**：
- 用 `upper_bound` 代替 `lower_bound` 就是**最长不下降子序列**（允许相等），两道题只差一个函数
- 朴素 O(n²) 在 n=1e5 时会超时（1e10 次操作），必须二分优化

**复杂度分析**：每个元素一次二分 O(log n)，总 O(n log n)。

### 例 2：LCS（完整可运行）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string a, b;
    cin >> a >> b;
    int n = a.size(), m = b.size();
    // 用 1 基下标方便处理边界（dp[0][*] 表示空串）
    a = " " + a;
    b = " " + b;

    vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (a[i] == b[j]) {
                // 匹配上了：两边各退一格 + 1
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                // 没匹配上：丢掉 a 的尾或丢掉 b 的尾，取较大的
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    cout << dp[n][m] << endl;
    return 0;
}
```

**坑**：`a = " " + a` 是为了 1 基下标。如果不加，`dp[i-1]` 在 i=0 时会越界，且 `a[i-1]` 下标混乱。

**复杂度分析**：O(n·m) 时间 O(n·m) 空间。n=m=5000 时是 2500 万状态，内存约 100MB，勉强能过；再大要滚动数组压到 O(m)。

### 例 3：编辑距离（完整可运行）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string a, b;
    cin >> a >> b;
    int n = a.size(), m = b.size();

    // dp[i][j] = 把 a 前 i 个字符变成 b 前 j 个字符的最少操作数
    vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));

    // 边界：a 为空 → 全插入；b 为空 → 全删除
    for (int i = 0; i <= n; i++) dp[i][0] = i;
    for (int j = 0; j <= m; j++) dp[0][j] = j;

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            // 三种操作取最小
            int del = dp[i - 1][j] + 1;          // 删掉 a[i]
            int ins = dp[i][j - 1] + 1;          // 插入 b[j]
            int rep = dp[i - 1][j - 1] + (a[i - 1] == b[j - 1] ? 0 : 1);  // 替换（相同则 0 代价）
            dp[i][j] = min({del, ins, rep});
        }
    }
    cout << dp[n][m] << endl;
    return 0;
}
```

**坑**：编辑距离的边界是**全删全插**（不是 0！）。如果边界写成 0，空串变非空串会被算成 0 步，答案全错。

**复杂度分析**：O(n·m) 时间空间。n=m=1e4 时 1e8 状态，内存吃紧，竞赛中常见优化是滚动数组（只保留上一行）降到 O(m)。
