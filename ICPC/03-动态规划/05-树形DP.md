# 05 树形 DP

> 树形 DP：把 DP 状态搬到树上，**先递归算完子树，回溯时向上合并到父节点**。
> 套路固定：DFS 从根往下走，回到 u 时用孩子的 dp 值更新 u 的 dp。
> 经典问题：树的直径、最大独立集（打家劫舍版）、最小点覆盖、树上背包（选课版）、换根 DP（二次扫描）。

## 大白话引入

公司开年会，要选一组人上台表演。规则只有一条：**不能同时选直属上下级**——选了经理，他的直接下属一个都不能上；但选了普通员工，不影响他的上级能不能上（那是另一个决策）。

每个人有一个"欢乐值"，怎么选能让总欢乐值最大？

把公司层级画出来，就是一棵树（根是老板，边是"上下级"关系）。问题的难点在于：**每个节点的选择会牵动它的孩子**。选 u，孩子全得让路；不选 u，孩子才自由。这种"父影响子"的结构，天然适合从下往上算：先把每个子树的最优值算出来，再回到父节点做决策——子树的答案只依赖子树内部，跟子树外面没关系，这就是**最优子结构**，树形 DP 的地基。

---

## 思维启发 & 思考流程

树形 DP 的思考流程非常固定，看到题按这四步走：

1. **把问题画在树上**：谁是根、谁是谁的孩子。输入往往不告诉你根，要自己找（没有父节点的那个；无根树任选一个点当根即可）。
2. **设计状态**：通常 = "节点 u" + "与 u 相关的额外信息"，常见的有：
   - `dp[u][0/1]` = 选/不选 u 时的最优值（最大独立集、最小点覆盖）
   - `dp[u][j]` = u 的子树里选 j 门课（树上背包）
   - `dp[u]` = 从 u 出发向下的最长链（树的直径）/ 包含 u 的最大连通块（最大子树和）
   - 换根题：`f[u]` = 以 u 为根的答案，用两次 DFS 递推
3. **确定 DFS 顺序**：先递归孩子，回溯时算 u。顺序不能反——用孩子结果的时候，孩子必须已经算完。
4. **确定答案在哪**：根节点的 dp，或者所有节点 dp 的 max/min（直径、最大连通块这种全局答案）。

**什么时候用"选/不选"两状态？** 当父节点的选择会**限制**孩子的选择时（选了父就不能选子、父不放士兵孩子就必须放），单靠一个 `dp[u]` 记不住"u 到底选没选"这个关键信息，必须开两维。

> 类比：`dp[u]` 像只记"u 这个格子最好的分数"，但选/不选 u 会改变孩子能拿到的分数——就像打家劫舍，偷了这家，隔壁两家就偷不了，所以每家的状态得区分"偷了/没偷"。

下面按"直径 → 独立集 → 点覆盖 → 最大连通块 → 树上背包 → 换根"由浅入深讲，每个知识点讲完立刻配完整代码。

## 核心讲解

### 1. 树的直径（最长路径）

**是什么**：树上最远两个节点的距离，这条最远路径可能经过任意节点（不一定是根）。

**思考路径**：先想一个笨办法——枚举每一对点求距离，O(n²) 次 BFS，太慢。再想：直径这条路径上一定有个"最高点"（离根最近的点，叫拐点）。如果我能算出"经过每个拐点的最长路径"，取 max 就是直径。

**状态设计**：`dp[u]` = 从 u 出发**向下**走的最长链长度（只往子树方向走）。那么经过 u 的最长路径 = u 的两条不同子树链拼起来。怎么拼？边遍历孩子边拼：

- 看到孩子 v（边权 w），`dp[u] + dp[v] + w` 就是"已经扫过的孩子里选一条最长链 + v 这条链"拼出的路径；
- 更新 `ans = max(ans, dp[u] + dp[v] + w)`；
- 再更新 `dp[u] = max(dp[u], dp[v] + w)`（u 的最长链可能变成经过 v 的这条）。

**关键顺序坑**：`ans` 必须先更新、`dp[u]` 后更新。如果顺序反了，`dp[u]` 已经包含了 v 这条链，再用 `dp[u] + dp[v] + w` 就是把同一条链走了两遍（路径变成 u→v→u），答案偏大。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 10005;
vector<pair<int, int>> g[MAXN];   // g[u] = {(v, w), ...} 邻接表（无向，边权 w）
long long dp[MAXN];               // dp[u] = 从 u 出发向下走的最长链长度
long long ans = 0;                // 全局答案：直径

void dfs(int u, int fa) {
    for (auto &[v, w] : g[u]) {
        if (v == fa) continue;              // 不回走父节点（树无环，但防止递归死循环）
        dfs(v, u);                          // 先算孩子的链长（回溯时才轮到 u 合并）
        // 关键：先更新 ans，再更新 dp[u]！
        // 反了的话 dp[u] 已包含 v 这条链，dp[u]+dp[v]+w 会把同一条链算两遍（u→v→u），答案偏大
        ans = max(ans, dp[u] + dp[v] + w);  // 经过 u 的最长路径 = 之前孩子的最长链 + v 这条链
        dp[u] = max(dp[u], dp[v] + w);      // 更新 u 向下最长链
    }
}

int main() {
    int n;
    cin >> n;
    for (int i = 1; i < n; i++) {           // n 个点 n-1 条边
        int u, v, w;
        cin >> u >> v >> w;
        g[u].push_back({v, w});
        g[v].push_back({u, w});
    }
    dfs(1, 0);                              // 树上任选一点当根都行（直径是全局的）
    cout << ans << endl;
    return 0;
}
```

**复杂度分析**：每个节点、每条边恰好访问一次，O(n)。如果 n=10⁵ 的链，递归深度也是 10⁵，注意栈空间（竞赛里可能要手写栈或加编译参数）。

> 补充：直径还有更简单的"两次 DFS"做法——任选一点找最远点 A，再从 A 找最远点 B，A-B 就是直径。它好写但不是 DP，边权为负时失效，DP 写法更通用，推荐掌握 DP 版。

### 2. 最大独立集（打家劫舍在树上，P1352）

**是什么**：选尽量多的节点，任意两个不相邻（选了父就不能选子）。对应 P1352「没有上司的舞会」：每个人有欢乐值，选人参加舞会，不能同时选上司和直接下属，求最大欢乐值。

**思考路径**：如果只有一个 `dp[u]` = "u 子树的最优值"，问题来了——算 `dp[u]` 的时候需要知道孩子 v 到底选没选（选了 u 的话 v 必须不选）。所以必须拆成两个状态，把"u 选没选"这个信息显式记下来：

**状态设计**：
- `dp[u][0]` = **不选 u** 时，u 子树的最大欢乐值；
- `dp[u][1]` = **选 u** 时，u 子树的最大欢乐值。

**转移**（回溯时合并每个孩子 v）：
- 不选 u：孩子爱选不选 → `dp[u][0] += max(dp[v][0], dp[v][1])`；
- 选 u：孩子全不能选 → `dp[u][1] += dp[v][0]`，且先加上自己的欢乐值 `val[u]`。

**答案**：`max(dp[root][0], dp[root][1])`。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 6005;
vector<int> g[MAXN];              // 有向边：g[k].push_back(l)，k 是 l 的上司
int val[MAXN];                    // 每个人的欢乐值
long long dp[MAXN][2];            // dp[u][0] = 不选 u；dp[u][1] = 选 u
bool hasFa[MAXN];                 // 标记某点有没有父节点，用来找根

void dfs(int u) {
    dp[u][1] = val[u];            // 选 u，至少拿到自己的欢乐值（先垫底，后面累加孩子的贡献）
    for (int v : g[u]) {
        dfs(v);                   // 先算孩子（回溯合并，保证 dp[v] 已就绪）
        dp[u][0] += max(dp[v][0], dp[v][1]); // 不选 u：孩子随便选，取孩子自己的最优
        dp[u][1] += dp[v][0];     // 选 u：孩子全不能选，只能拿"不选孩子"的值
    }
}

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> val[i];
    for (int i = 1; i < n; i++) {
        int l, k;
        cin >> l >> k;            // k 是 l 的上司（输入顺序可能乱序！）
        g[k].push_back(l);
        hasFa[l] = true;
    }
    // 坑：输入乱序 + 根不一定是 1，必须用 hasFa 找真正的根（没有父节点的点）
    int root = 1;
    while (hasFa[root]) root++;
    dfs(root);
    cout << max(dp[root][0], dp[root][1]) << endl;
    return 0;
}
```

**复杂度分析**：每个节点一次，O(n)。欢乐值可为负吗？可以，所以"不选 u"也是合法选择，答案取 max 而不是默认全选。

### 3. 最小点覆盖（战略游戏，P2016）

**是什么**：城堡的路形成一棵无根树，在节点上放士兵，**一个士兵能瞭望到与它相连的所有边**，求覆盖所有边需要的最少士兵数。等价于：选最少的点，使每条边至少有一个端点被选——最小点覆盖。

**思考路径**：这题和舞会**方程长得几乎一样，但含义完全不同**，正好用来体会"状态怎么设计取决于约束是什么"。每个点只有放/不放士兵两种状态：

**状态设计**：
- `dp[u][0]` = u **不放**士兵时，覆盖 u 子树内所有边的最少士兵数；
- `dp[u][1]` = u **放**士兵时，覆盖 u 子树内所有边的最少士兵数。

**转移**（关键在"边由谁覆盖"）：
- u 不放：边 (u,v) 没人看 → **v 必须放** → `dp[u][0] += dp[v][1]`；
- u 放：边 (u,v) 已被 u 覆盖 → v 放不放都行，取更省的 → `dp[u][1] += min(dp[v][0], dp[v][1])`，再加自己 1 个士兵。

**答案**：`min(dp[root][0], dp[root][1])`。

> 对比舞会：舞会是不选 u 时孩子**随便**（max），选 u 时孩子**全不选**；战略游戏是不放 u 时孩子**必须放**，放 u 时孩子**随便**（min）。约束一换，转移就换——每次写题先想清楚"这条边/这个依赖到底由谁负责"。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1505;
vector<int> g[MAXN];      // 无向边（无根树）
int dp[MAXN][2];          // dp[u][0] = u 不放士兵；dp[u][1] = u 放士兵

void dfs(int u, int fa) {
    dp[u][1] = 1;                          // 放士兵：自己先算 1 个
    for (int v : g[u]) {
        if (v == fa) continue;
        dfs(v, u);
        // u 不放：边 (u,v) 没人瞭望，必须由 v 放士兵来覆盖
        dp[u][0] += dp[v][1];
        // u 放：边 (u,v) 已被覆盖，v 放不放都行，取更省的
        dp[u][1] += min(dp[v][0], dp[v][1]);
    }
}

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {          // 节点编号从 0 开始
        int u, k;
        cin >> u >> k;
        for (int j = 0; j < k; j++) {
            int v;
            cin >> v;
            g[u].push_back(v);
            g[v].push_back(u);             // 无根树，建双向边
        }
    }
    dfs(0, -1);                            // 任选 0 为根
    cout << min(dp[0][0], dp[0][1]) << endl;
    return 0;
}
```

**复杂度分析**：O(n)。注意这是树上的最小点覆盖；**一般图的最小点覆盖是 NP 难**的，只有树（和二分图）能多项式做。

> 课后 harder 版：**P2279 消防局的设立**——每个点能覆盖距离 2 的所有点，而不是只覆盖边。状态数暴涨（一个点要区分"距离 1/2 处是否有消防局"），转移非常难推，视频里老师也没细讲，作为进阶挑战题。

### 4. 最大连通块（P1122 最大子树和）

**是什么**：一棵树，每个节点有权值（可负），可以剪掉若干条边丢掉一些子树，最后必须剩下一棵**连通**的树（一个点也算），求剩下这棵树的权值和最大。

**思考路径**：先把所有权值都看成正的——那整棵树肯定全留（剪掉只会变小）。所以要剪，一定是因为**某棵子树的总权值是负的**。于是问题变成：对每条边决策"这棵子树要不要"。

**状态设计**：`dp[u]` = **强制包含 u** 的最大连通块权值和（在 u 的子树内取）。

**转移**（回溯时对每个孩子 v）：
- `dp[v] > 0`：这条链/块是正贡献，保留 → `dp[u] += dp[v]`；
- `dp[v] <= 0`：剪掉，贡献当 0 → `dp[u] += max(0, dp[v])`。

**答案**：最终连通块的"最高点"可能是树上任意一个节点 → `max(dp[1..n])`。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 16005;
vector<int> g[MAXN];
int w[MAXN];
long long dp[MAXN];        // dp[u] = 强制包含 u 的最大连通块权值和
long long ans = -1e18;     // 答案：所有 dp[u] 的最大值

void dfs(int u, int fa) {
    dp[u] = w[u];                       // 强制包含 u，先拿自己的权值
    for (int v : g[u]) {
        if (v == fa) continue;
        dfs(v, u);
        if (dp[v] > 0) dp[u] += dp[v];  // 孩子贡献为正才要；负的剪掉（当 0）
    }
    ans = max(ans, dp[u]);              // 最终连通块的"根"可以是任意节点
}

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> w[i];
    for (int i = 1; i < n; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    dfs(1, 0);
    cout << ans << endl;
    return 0;
}
```

**复杂度分析**：O(n)。这题的"正贡献才合并"思想在树形 DP 里很常见（下面的树上背包、银牌题都用得到）。

### 5. 树上背包（分组背包长在树上，P2014）

**是什么**：P2014「选课」。有 n 门课，每门课有学分，选一门课必须先选它的先修课（形成一棵树，没有先修课的挂在虚拟根 0 下面）。总共最多选 m 门，求最大总学分。

**思考路径**：这和 02-背包DP 的分组背包几乎一样——每个孩子 v 是一"组"，组内选 v 的子树里的课；区别是"组"的候选不是固定的几个物品，而是 v 子树里所有合法的选课组合，正好用 v 子树的 dp 值表示。

**状态设计**：`dp[u][j]` = 在 u 的子树里**选 u 并且**一共选 j 门课的最大学分（隐含 u 必选，因为先修依赖——不选 u 就选不了 u 的任何后代，那这个子树贡献 0，用 `dp[u][0]=0` 表示）。

**转移**（回溯时对每个孩子 v 做分组背包）：
- 外层 j 从 m 倒序到 1（容量，**必须倒序**，否则同一个孩子被多次使用）；
- 内层 k 从 1 到 j-1：给 v 这组分配 k 门课；
- `dp[u][j] = max(dp[u][j], dp[u][j-k] + dp[v][k])`。

**两个关键细节**：
1. **`dp[u][1] = score[u]` 必须先初始化**——u 自己占 1 门。漏掉的话叶子节点的 dp 全是极小值，整棵树转移全废。
2. **k < j 而不是 k <= j**——u 自己已经占了 1 个容量，分给孩子的容量最多 j-1。写 k <= j 会让虚拟根不占容量，多选一门课，答案偏大。

**虚拟根技巧**：把没有先修课的课挂到虚拟根 0 下面，答案在 `dp[0][m]`。但虚拟根 0 也算一门课，所以 `m++`（多选"虚拟根"这门的名额，它学分是 0，不影响答案）。

#### 5.1 朴素写法 O(n·m²)

```cpp
// 核心转移（完整代码见 5.2，这里只看朴素转移）
void dfs(int u) {
    dp[u][1] = score[u];              // 选 u 自己，占 1 门（必须初始化！）
    for (int v : g[u]) {
        dfs(v);
        for (int j = m; j >= 1; j--)          // 容量倒序：防同一个孩子被重复分配
            for (int k = 1; k < j; k++)       // 给 v 分配 k 门（k<j：u 自己已占 1 门）
                dp[u][j] = max(dp[u][j], dp[u][j - k] + dp[v][k]);
    }
}
```

**复杂度**：每个孩子合并 O(m²)，总共 O(n·m²)，n、m ≤ 300 时约 2.7×10⁷，勉强能过（视频原话：N³ 大概只能做 500 以内的题）。

#### 5.2 上下界优化 O(n²)（视频重点，2025 暑期集训周赛考过）

**为什么能优化**：朴素写法里大量枚举是浪费的。假设孩子 v 的子树只有 2 个节点，那 k 枚举到 99 根本不可能发生——**v 最多只能贡献 sz[v] 个名额**。同理 j 也不可能超过"目前 u 这边已有的节点数 + v 的节点数"。

维护 `sz[u]` = u 子树节点数（含 u 自己），合并孩子 v 时：

- **j 的上界**：`min(m, sz[u] + sz[v])`——u 这边合并前有 sz[u] 个点，v 有 sz[v] 个点，一共就这么多，j 再大分配不了；
- **k 的上界**：`min(sz[v], j-1)`——最多全选 v（sz[v] 个），且 u 自己占 1 门只能让出 j-1；
- **k 的下界**：`max(0, j - sz[u])`——要凑 j 门，u 这边（不含 v 的部分，合并前 sz[u] 个点）最多贡献 j-k 个，必须 `j-k <= sz[u]`，所以 `k >= j - sz[u]`。**这个下界最容易漏**：老部分根本凑不出那么多名额时，k 不可能从 0 开始。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 305;
vector<int> g[MAXN];              // g[fa].push_back(i)：先修关系，fa=0 表示无先修
int score[MAXN];                  // 每门课学分
int dp[MAXN][MAXN];               // dp[u][j] = u 子树里选 j 门课（u 必选）的最大学分
int sz[MAXN];                     // sz[u] = u 子树的节点数（含 u 自己）
int n, m;

void dfs(int u) {
    dp[u][1] = score[u];          // 关键初始化：选 u 自己，占 1 门。漏了叶子全是极小值，整棵树废
    sz[u] = 1;
    for (int v : g[u]) {
        dfs(v);                   // 先算孩子子树的 dp 和 sz
        // 上下界优化：j 最多 = 已有节点数 + v 的节点数，再多分配不了
        for (int j = min(m, sz[u] + sz[v]); j >= 1; j--) {
            // k 下界：u 这边（合并前 sz[u] 个点）最多贡献 j-k，必须 j-k <= sz[u] → k >= j-sz[u]
            // k 上界：最多全选 v（sz[v]），且 u 自己占 1 门最多让出 j-1
            for (int k = max(0, j - sz[u]); k <= min(sz[v], j - 1); k++) {
                dp[u][j] = max(dp[u][j], dp[u][j - k] + dp[v][k]);
            }
        }
        sz[u] += sz[v];           // 合并完 v，u 的节点数增加
    }
}

int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        int fa;
        cin >> fa >> score[i];
        g[fa].push_back(i);       // 虚拟根 0：fa=0 表示这门课没有先修
    }
    // 极小值初始化：用 0xc0（约 -1e9），两个相加约 -2.1e9 不溢出 int
    // 千万别用 0x80（-2139062144），两个相加会溢出成正垃圾值
    memset(dp, 0xc0, sizeof(dp));
    for (int i = 0; i <= n; i++) dp[i][0] = 0;   // 一棵子树一门不选 = 0
    m++;                          // 坑：虚拟根 0 也占 1 个名额，多选"虚拟根"这门的容量
    dfs(0);
    cout << dp[0][m] << endl;     // 虚拟根子树里选满 m 门
    return 0;
}
```

**复杂度**：合并 v 的循环次数 = (sz[u]+sz[v]) × (sz[v] 区间长度)，摊还后总共 O(n²)。n=300 时比朴素快一个量级；n=5000 也能跑。

**坑汇总（这题全是细节）**：
- `dp[u][1] = score[u]` 漏掉 → 叶子 dp 全是极小值，整棵树白算；
- 容量循环写成正序 → 同一个孩子被用多次，答案偏大；
- `k <= j` 而不是 `k < j` → 虚拟根不占容量，多选一门课；
- `m++` 漏掉 → 根 0 的学分算不进去；
- `memset(dp, 0x80, ...)` → 两个极小值相加溢出 int 变成正垃圾值，用 `0xc0`；
- 上下界优化里 **k 的下界 `max(0, j-sz[u])` 最容易漏**——只卡上界不卡下界，复杂度不会错但可能引入无效枚举（对正确性无害，但视频强调这是优化完整版）。

> 课后：**P2015 二叉苹果树**——保留树枝数的限制（边权当点权），同样是树上背包模板。

### 6. 换根 DP（二次扫描）

**是什么**：有些题**不指定根**，而且"以哪个点为根"会改变答案（比如深度和、到各点距离和）。朴素做法是枚举每个点当根各跑一遍 DFS，O(n²)；换根 DP 用**两次 DFS** 搞定：第一次随便定个根预处理信息，第二次在树上"挪根"，用父节点的答案 O(1) 推出子节点的答案。

**为什么叫二次扫描**：第一次 DFS 自底向上算出以 1 为根的答案；第二次 DFS 自顶向下把根"旋"到每个点，维护转移。

**核心思想**：把根从 u 换到孩子 v 时，**只有两部分点的深度会变**：
- v 的子树（含 v）：所有点深度 -1（都往上挪了一层），一共 sz[v] 个点，深度和减少 sz[v]；
- 其余部分（含 u）：所有点深度 +1，一共 **n - sz[v]** 个点，深度和增加 n - sz[v]。

所以：`f[v] = f[u] - sz[v] + (n - sz[v])`。注意"其余部分"的点数是 `n - sz[v]`，**不是 `n - sz[u]`**——因为 sz[u] 是以 1 为根时的子树大小，换根后 u 的"父亲方向"那一大块也要算进去（视频里特意强调了这点）。

#### 例：深度和最大（P3478 STA-Station，完整可运行）

**是什么**：n 个点的树，求一个点，使得**以它为根时所有节点的深度之和最大**。n 可达 10⁶，O(n²) 必死。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const int MAXN = 1000005;
vector<int> g[MAXN];
ll sz[MAXN];          // sz[u] = u 子树大小（含 u）
ll f[MAXN];           // f[u] = 以 u 为根时整棵树的深度和
int n;

void dfs1(int u, int fa, int d) {   // 第一次扫描：以 1 为根，预处理 sz 和深度和
    sz[u] = 1;
    f[1] += d;                      // 深度从 0 开始累加
    for (int v : g[u]) {
        if (v == fa) continue;
        dfs1(v, u, d + 1);
        sz[u] += sz[v];
    }
}

void dfs2(int u, int fa) {          // 第二次扫描：换根，自顶向下递推
    for (int v : g[u]) {
        if (v == fa) continue;
        // 根从 u 旋到 v：v 的子树全部深度 -1（sz[v] 个点），其余全部 +1（n-sz[v] 个点）
        f[v] = f[u] - sz[v] + (n - sz[v]);
        dfs2(v, u);
    }
}

int main() {
    scanf("%d", &n);                // n 可达 1e6，用 scanf 快很多
    for (int i = 1; i < n; i++) {
        int u, v;
        scanf("%d%d", &u, &v);
        g[u].push_back(v);
        g[v].push_back(u);
    }
    dfs1(1, 0, 0);
    dfs2(1, 0);
    int root = 1;
    for (int i = 2; i <= n; i++)
        if (f[i] > f[root]) root = i;   // 找深度和最大的根（多个取任意，这里取第一个最大的）
    printf("%d\n", root);
    return 0;
}
```

**复杂度**：两次 DFS 各 O(n)，总 O(n)。n=10⁶ 时注意：① 用 scanf/printf；② 邻接表 vector 也要预留空间或用手写链式前向星，避免频繁扩容。

#### 进阶：连通子图破坏通信（2024 成都站银牌题）

**是什么**（洛谷有重现，多测）：一棵树，每次查询给两个点 u、v，问有多少种"连通子图"选择方案能**破坏 u-v 路径上的通信**——即选出的连通子图至少包含 u-v 简单路径上的一个节点。模数 96844353（**不是质数**，这是本题最大的坑）。u=v 也算（选一个含该点的连通子图即可）。

**思路拆解**（视频讲解，整理）：
1. **答案形式**：设 l = LCA(u,v)，路径上的点（不含 l）的某个值和 + l 的另一个值。
2. **两个状态**：
   - `dp1[i]` = 以 i 为根的子树中，**必须包含 i** 的连通子图方案数。转移：`dp1[u] = Π(dp1[v] + 1)`（对每个孩子 v：要么不选 v 的子树——1 种；要么选 v 子树里一个连通块连到 u——dp1[v] 种）。一次 DFS 搞定。
   - `dp2[i]` = 全局（整棵无根树）视角下，**包含 i** 的连通子图方案数。这就是换根：`dp2[v] = dp1[v] * (dp2[u] / (dp1[v]+1) + 1)`（把 u 里 v 的贡献"剥离"，得到 u 上方部分的方案，+1 表示上方可以不连，再乘 v 自己的 dp1）。
3. **除法陷阱（银牌点）**：模数 96844353 不是质数，`(dp1[v]+1) mod p` 可能为 0，**0 没有逆元**，不能直接除（视频原话：VP 时这题挂了很多人）。解决办法：**维护每个点的孩子前后缀积**，`dp2[v] = dp1[v] * (pre[i-1] * suf[i+1] + 1)`，用乘代替除。
4. **快速回答查询**：路径上所有 dp1 之和用**树上差分/前缀和**维护（`sum1[u] = sum1[fa] + dp1[u]`），查询 `ans = (sum1[u] + sum1[v] - 2*sum1[l]) + dp2[l]`。加 LCA 板子即可。
5. **多测坑**：这题是多测（T 组），老师直播时 debug 半天才发现是把多测删了，读入错位——**多测记得清空全局数组/邻接表**。

这个题的价值：把"换根 + 方案计数 + 取模除法陷阱 + 树上差分"串在一起，是树形 DP 的综合天花板，等基础三件套熟了再啃。
