# 05 树形 DP

> 树形 DP：状态跑到树上，**先递归算完子树，再向上合并到父节点**。
> 套路固定：DFS 从根往下走，回溯时用子树的 dp 值更新父节点的 dp。
> 三大经典：树的直径、树上背包、最大独立集（打家劫舍版）。

## 大白话引入

公司开年会，要选一组人去表演节目。规则是：**不能同时选直属上下级**（选了经理就不能选他的直接下属）。每个人有个"欢乐值"，怎么选让总欢乐值最大？

这就是树上的选择问题：每个节点"选/不选"都会影响它的子节点。因为树天然是"父-子"结构，用 DFS 先算子树最优，再决定父节点，正好和树的形状吻合。

---

## 思维启发 & 思考流程

树形 DP 的思考流程非常固定：

1. **把问题画在树上**：谁是根、谁是谁的孩子
2. **确定状态**：通常按"节点 u + 与 u 相关的额外信息"设计，如：
   - `dp[u][0/1]` = 选/不选 u 时的最优值
   - `dp[u][j]` = u 的子树里分配 j 个容量（树上背包）
   - `dp[u]` = 以 u 为端点的最长链（直径）
3. **确定 DFS 顺序**：先递归孩子，回溯时算 u —— 保证用到子树结果时它们已经算完
4. **确定答案在哪**：根节点的 dp，或者所有节点 dp 的 max/min（直径）

**什么时候用"选/不选"两状态？** 当父节点的选择会**限制**孩子的选择时（最大独立集：选了父就不能选子），就需要 `dp[u][0/1]` 记录两种决策。

---

## 核心讲解

### 1. 树的直径（最长路径）

- 直径 = 树上最远两个节点的距离（可能经过任意节点）
- **做法 1（两次 DFS）**：任选一点 DFS 找最远点 A，再从 A DFS 找最远点 B，A-B 就是直径。证明略，记住结论。
- **做法 2（树形 DP）**：`dp[u]` = 从 u 出发向下的最长链。对每个孩子 v：
  - `ans = max(ans, dp[u] + dp[v] + w)`（经过 u 的最长路径 = 两条最长子链拼接）
  - `dp[u] = max(dp[u], dp[v] + w)`（更新 u 的最长链）
  - 关键：**先更新 ans 再更新 dp[u]**，否则会把同一条链算两次

### 2. 树上背包（分组背包在树上）

- 例：选课。选一门课必须先选它的先修课（树形依赖），每门课有学分，容量是能选的总门数
- **状态**：`dp[u][j]` = 在 u 的子树里选 j 门课的最大学分
- **转移**：把每个孩子 v 当成"一组"，在容量 j 里给每组分配 k 门（组内选 v 的孩子），这就是**分组背包**——外层容量倒序，内层枚举分配数量
- 常用套路：虚拟根节点 0 连所有"没有先修课"的课，答案在 `dp[0][m]`

### 3. 最大独立集（打家劫舍在树上）

- 选尽量多的节点，任意两个不相邻（选了父不选子）
- **状态**：`dp[u][0]` = 不选 u 时子树最大值；`dp[u][1]` = 选 u 时子树最大值
- **转移**：
  - 不选 u：孩子随便选 → `dp[u][0] += max(dp[v][0], dp[v][1])`
  - 选 u：孩子全不能选 → `dp[u][1] += dp[v][0]`
- 答案：`max(dp[root][0], dp[root][1])`

## C++ 代码

### 例 1：树的直径（树形 DP 写法，完整可运行）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 10005;
vector<pair<int, int>> g[MAXN];   // g[u] = {(v, w), ...} 邻接表
long long dp[MAXN];               // dp[u] = 从 u 出发向下的最长链
long long ans = 0;

void dfs(int u, int fa) {
    for (auto &[v, w] : g[u]) {
        if (v == fa) continue;                 // 不回走父节点（树没有环，但防止走回去）
        dfs(v, u);                             // 先算孩子的链长
        // 关键顺序：先更新 ans，再更新 dp[u]
        // 如果先更新 dp[u]，ans 会用到 dp[u]+dp[v] 里包含同一条 v 链 → 算重
        ans = max(ans, dp[u] + dp[v] + w);     // 经过 u 的最长路径 = 两条最长子链拼接
        dp[u] = max(dp[u], dp[v] + w);         // 更新 u 的最长链
    }
}

int main() {
    int n;
    cin >> n;
    for (int i = 1; i < n; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        g[u].push_back({v, w});
        g[v].push_back({u, w});
    }
    dfs(1, 0);                                 // 任选一个根
    cout << ans << endl;                       // 直径
    return 0;
}
```

**坑**：`ans = max(ans, dp[u] + dp[v] + w)` 必须在 `dp[u] = max(...)` **之前**。否则 dp[u] 已经包含了 v 这条链，再加 dp[v]+w 就是把同一条链算了两次（路径变成 u→v→u），答案偏大。

**复杂度分析**：每个节点遍历一次所有边，O(n)。

### 例 2：最大独立集（P1352 没有上司的舞会，完整可运行）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 6005;
vector<int> g[MAXN];
int val[MAXN];
long long dp[MAXN][2];   // dp[u][0] = 不选 u；dp[u][1] = 选 u
bool hasFa[MAXN];        // 找根用

void dfs(int u) {
    dp[u][1] = val[u];                       // 选 u 至少拿到自己的欢乐值
    for (int v : g[u]) {
        dfs(v);                              // 先算孩子
        dp[u][0] += max(dp[v][0], dp[v][1]); // 不选 u：孩子随便选
        dp[u][1] += dp[v][0];                // 选 u：孩子全不能选
    }
}

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> val[i];
    for (int i = 1; i < n; i++) {
        int l, k;
        cin >> l >> k;                       // k 是 l 的上司
        g[k].push_back(l);
        hasFa[l] = true;
    }
    int root = 1;
    while (hasFa[root]) root++;              // 找到没有上司的根
    dfs(root);
    cout << max(dp[root][0], dp[root][1]) << endl;
    return 0;
}
```

**坑**：树可能不连通输入顺序乱序，必须用 `hasFa` 数组找真正的根（没有父节点的那个）。直接假设 1 是根在"输入乱序 + 非 1 根"时会算错子树归属。

### 例 3：树上背包（P2014 选课，完整可运行）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 305;
vector<int> g[MAXN];
int score[MAXN];
int dp[MAXN][MAXN];   // dp[u][j] = u 子树里选 j 门课的最大学分
int n, m;

void dfs(int u) {
    dp[u][0] = 0;                                // 不选课
    dp[u][1] = score[u];                         // 选 u 自己，占 1 门（必须初始化！否则叶子节点全是极小值）
    // 把每个孩子 v 当成"一组"，容量倒序做分组背包
    for (int v : g[u]) {
        dfs(v);                                  // 先算孩子的 dp
        for (int j = m; j >= 1; j--) {           // 容量倒序：每组最多贡献若干门，防重复
            for (int k = 1; k < j; k++) {        // 给这个孩子分配 k 门（k<j：u 自己已占 1 门）
                // 选 u 自己占 1 门，剩下 j-1 门里分 k 门给 v
                dp[u][j] = max(dp[u][j], dp[u][j - k] + dp[v][k]);
            }
        }
    }
}

int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        int fa;
        cin >> fa >> score[i];
        g[fa].push_back(i);                      // 虚拟根 0：fa=0 表示无先修
    }
    memset(dp, 0xc0, sizeof(dp));                // 初始化为极小值（0xc0 = -1e9 级别，两个相加不会溢出 int；用 0x80 会溢出成垃圾值）
    for (int i = 0; i <= n; i++) dp[i][0] = 0;
    m++;                                         // 多选"虚拟根 0"这一门（不占学分）
    dfs(0);
    cout << dp[0][m] << endl;                    // 虚拟根子树里选 m 门
    return 0;
}
```

**坑**：
- 虚拟根 0 自己也要占一个名额，所以 `m++`；否则根 0 的学分算不进去
- `dp[u][j]` 初始化为极小值，`dp[u][0] = 0` 单独设置——因为选课必须从 0 门递推上来
- 容量循环必须倒序（分组背包特性），正序会导致同一个孩子被分配多次
