## 1. 大白话引入

想象你要在 n 个城市之间修路，每条路有修建成本。你的目标是：
- 让所有城市都能互相到达（连通）
- 总成本最小

这就是**最小生成树（Minimum Spanning Tree, MST）**问题。

**关键性质**：
- n 个点的图，最小生成树恰好有 n-1 条边
- 最小生成树可能不唯一，但总权值一定唯一
- 最小生成树一定是**瓶颈生成树**（最大边权最小的生成树）

**前置知识**：
- 并查集（Kruskal 算法）
- 优先队列（Prim 算法）
- 树上倍增、LCA（次小生成树）

## 2. Kruskal 算法

### 核心思想

**贪心策略**：每次选权值最小的边，如果不形成环就加入。

**判断环**：用并查集。如果边的两端已经在同一集合，加这条边会形成环。

**步骤**：
1. 把所有边按权值从小到大排序
2. 依次考虑每条边，如果两端不在同一集合，就加入并查集
3. 直到选了 n-1 条边，或所有边都考虑完

**复杂度**：O(m log m) 排序 + O(m α(n)) 并查集操作

### 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 5005;
const int M = 200005;

struct Edge {
    int u, v, w;
    bool operator<(const Edge& o) const {
        return w < o.w;
    }
} e[M];

int f[N];

int find(int x) {
    if (x == f[x]) return x;
    return f[x] = find(f[x]);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n, m;
    cin >> n >> m;
    
    for (int i = 1; i <= n; i++) {
        f[i] = i;
    }
    
    for (int i = 1; i <= m; i++) {
        cin >> e[i].u >> e[i].v >> e[i].w;
    }
    
    sort(e + 1, e + 1 + m);
    
    long long total = 0;
    int cnt = 0;
    
    for (int i = 1; i <= m; i++) {
        int fu = find(e[i].u), fv = find(e[i].v);
        if (fu != fv) {
            f[fu] = fv;
            total += e[i].w;
            cnt++;
            if (cnt == n - 1) break;
        }
    }
    
    if (cnt == n - 1) {
        cout << total << "\n";
    } else {
        cout << "orz\n";
    }
    
    return 0;
}
```

**关键点**：
- 边按权值排序，贪心选择
- 并查集判断是否形成环
- 选够 n-1 条边就停

## 3. Prim 算法

### 核心思想

**贪心策略**：从任意起点开始，每次选连接已选集合和未选集合的最小边。

**实现**：用小根堆维护"到达每个未选节点的最小代价"。

**步骤**：
1. 从节点 1 开始，把 (1, 0) 加入堆
2. 弹出堆顶 (u, w)，如果 u 已访问过就跳过
3. 标记 u 为已访问，累加 w 到总权值
4. 遍历 u 的所有边 (u, v, cost)，如果 v 未访问，加入 (v, cost)
5. 重复直到堆空

**复杂度**：O((n+m) log n)

### 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 5005;
const int M = 200005;

struct Edge {
    int to, w;
};

vector<Edge> adj[N];
bool vis[N];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n, m;
    cin >> n >> m;
    
    for (int i = 1; i <= m; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        adj[u].push_back({v, w});
        adj[v].push_back({u, w});
    }
    
    // 小根堆：(代价, 节点)
    priority_queue<pair<int, int>, vector<pair<int, int>>, greater<>> pq;
    pq.push({0, 1});
    
    long long total = 0;
    int cnt = 0;
    
    while (!pq.empty()) {
        auto [w, u] = pq.top();
        pq.pop();
        
        if (vis[u]) continue;
        vis[u] = true;
        total += w;
        cnt++;
        
        if (cnt == n) break;
        
        for (auto& [v, cost] : adj[u]) {
            if (!vis[v]) {
                pq.push({cost, v});
            }
        }
    }
    
    if (cnt == n) {
        cout << total << "\n";
    } else {
        cout << "orz\n";
    }
    
    return 0;
}
```

**Kruskal vs Prim**：
| 算法 | 适用场景 | 复杂度 |
|------|---------|--------|
| Kruskal | 稀疏图（边少） | O(m log m) |
| Prim | 稠密图（边多） | O((n+m) log n) |

## 4. 最小瓶颈树

### 定义

无向图 G 的**瓶颈生成树**：最大边权在所有生成树中最小的生成树。

**性质**：最小生成树一定是瓶颈生成树（但反之不成立）。

**证明思路**：反证法。如果最小生成树不是瓶颈生成树，删去最长边后用瓶颈生成树的边替换，会得到更小的生成树，矛盾。

### 应用：POJ-2395 Out of Hay

**题意**：求从农场 1 出发能到达所有农场时，所需经过的最长道路的最小可能长度。

**解法**：最小生成树的最大边就是答案。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 2005;
const int M = 10005;

struct Edge {
    int u, v, w;
    bool operator<(const Edge& o) const {
        return w < o.w;
    }
} e[M];

int f[N];

int find(int x) {
    if (x == f[x]) return x;
    return f[x] = find(f[x]);
}

int main() {
    int n, m;
    cin >> n >> m;
    
    for (int i = 1; i <= n; i++) {
        f[i] = i;
    }
    
    for (int i = 1; i <= m; i++) {
        cin >> e[i].u >> e[i].v >> e[i].w;
    }
    
    sort(e + 1, e + 1 + m);
    
    int max_edge = 0;
    int cnt = 0;
    
    for (int i = 1; i <= m; i++) {
        int fu = find(e[i].u), fv = find(e[i].v);
        if (fu != fv) {
            f[fu] = fv;
            max_edge = max(max_edge, e[i].w);
            cnt++;
            if (cnt == n - 1) break;
        }
    }
    
    cout << max_edge << "\n";
    return 0;
}
```

## 5. 次小生成树

### 非严格次小生成树

**定义**：边权和 ≥ 最小生成树边权和的生成树中，边权和最小的。

**思路**：
1. 求出最小生成树 T，权值和为 M
2. 枚举每条不在 T 中的边 e=(u,v,w)
3. 在 T 中找到 u 到 v 路径上权值最大的边 e'
4. 用 e 替换 e'，得到新生成树权值 M + w - w'
5. 取所有替换方案的最小值

**关键**：用**树上倍增**快速求 u 到 v 路径上的最大边权。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
const int M = 300005;
const int LOG = 17;

struct Edge {
    int u, v, w;
    bool used;
    bool operator<(const Edge& o) const {
        return w < o.w;
    }
} e[M];

struct TreeEdge {
    int to, w;
};

vector<TreeEdge> adj[N];
int f[N];
int depth[N];
int fa[N][LOG];
int maxw[N][LOG];  // 到 2^i 祖先路径上的最大边权

int find(int x) {
    if (x == f[x]) return x;
    return f[x] = find(f[x]);
}

void dfs(int u, int p, int d, int w) {
    depth[u] = d;
    fa[u][0] = p;
    maxw[u][0] = w;
    
    for (int i = 1; i < LOG; i++) {
        fa[u][i] = fa[fa[u][i-1]][i-1];
        maxw[u][i] = max(maxw[u][i-1], maxw[fa[u][i-1]][i-1]);
    }
    
    for (auto& [v, weight] : adj[u]) {
        if (v != p) {
            dfs(v, u, d + 1, weight);
        }
    }
}

int query_max(int u, int v) {
    int res = 0;
    if (depth[u] < depth[v]) swap(u, v);
    
    for (int i = LOG - 1; i >= 0; i--) {
        if (depth[u] - (1 << i) >= depth[v]) {
            res = max(res, maxw[u][i]);
            u = fa[u][i];
        }
    }
    
    if (u == v) return res;
    
    for (int i = LOG - 1; i >= 0; i--) {
        if (fa[u][i] != fa[v][i]) {
            res = max(res, max(maxw[u][i], maxw[v][i]));
            u = fa[u][i];
            v = fa[v][i];
        }
    }
    
    res = max(res, max(maxw[u][0], maxw[v][0]));
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n, m;
    cin >> n >> m;
    
    for (int i = 1; i <= n; i++) {
        f[i] = i;
    }
    
    for (int i = 1; i <= m; i++) {
        cin >> e[i].u >> e[i].v >> e[i].w;
        e[i].used = false;
    }
    
    sort(e + 1, e + 1 + m);
    
    long long mst = 0;
    int cnt = 0;
    
    for (int i = 1; i <= m; i++) {
        int fu = find(e[i].u), fv = find(e[i].v);
        if (fu != fv) {
            f[fu] = fv;
            mst += e[i].w;
            e[i].used = true;
            adj[e[i].u].push_back({e[i].v, e[i].w});
            adj[e[i].v].push_back({e[i].u, e[i].w});
            cnt++;
            if (cnt == n - 1) break;
        }
    }
    
    dfs(1, 0, 0, 0);
    
    long long ans = 2e18;
    for (int i = 1; i <= m; i++) {
        if (!e[i].used) {
            int max_edge = query_max(e[i].u, e[i].v);
            ans = min(ans, mst + e[i].w - max_edge);
        }
    }
    
    cout << ans << "\n";
    return 0;
}
```

### 严格次小生成树

**定义**：边权和**严格大于**最小生成树边权和的生成树中，边权和最小的。

**区别**：替换时，如果 e 的权值等于路径上的最大边权，替换后权值不变，不是"严格更大"。

**解决**：维护路径上的**最大边权和严格次大边权**。如果 e 的权值等于最大边权，就用次大边权替换。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
const int M = 300005;
const int LOG = 17;
const long long INF = 1e18;

struct Edge {
    int u, v, w;
    bool used;
    bool operator<(const Edge& o) const {
        return w < o.w;
    }
} e[M];

struct TreeEdge {
    int to, w;
};

vector<TreeEdge> adj[N];
int f[N];
int depth[N];
int fa[N][LOG];
int maxw[N][LOG];   // 最大边权
int maxw2[N][LOG];  // 严格次大边权

int find(int x) {
    if (x == f[x]) return x;
    return f[x] = find(f[x]);
}

void dfs(int u, int p, int d, int w) {
    depth[u] = d;
    fa[u][0] = p;
    maxw[u][0] = w;
    maxw2[u][0] = -INF;
    
    for (int i = 1; i < LOG; i++) {
        fa[u][i] = fa[fa[u][i-1]][i-1];
        
        // 合并两个区间的最大值和次大值
        int a = maxw[u][i-1], b = maxw[fa[u][i-1]][i-1];
        int c = maxw2[u][i-1], d2 = maxw2[fa[u][i-1]][i-1];
        
        if (a > b) {
            maxw[u][i] = a;
            maxw2[u][i] = max({b, c, d2});
        } else if (a < b) {
            maxw[u][i] = b;
            maxw2[u][i] = max({a, c, d2});
        } else {
            maxw[u][i] = a;
            maxw2[u][i] = max(c, d2);
        }
    }
    
    for (auto& [v, weight] : adj[u]) {
        if (v != p) {
            dfs(v, u, d + 1, weight);
        }
    }
}

// 返回 (最大值, 严格次大值)
pair<int, int> query(int u, int v) {
    int res1 = 0, res2 = -INF;
    
    if (depth[u] < depth[v]) swap(u, v);
    
    for (int i = LOG - 1; i >= 0; i--) {
        if (depth[u] - (1 << i) >= depth[v]) {
            int a = res1, b = maxw[u][i];
            int c = res2, d = maxw2[u][i];
            if (a > b) {
                res1 = a;
                res2 = max({b, c, d});
            } else if (a < b) {
                res1 = b;
                res2 = max({a, c, d});
            } else {
                res1 = a;
                res2 = max(c, d);
            }
            u = fa[u][i];
        }
    }
    
    if (u == v) return {res1, res2};
    
    for (int i = LOG - 1; i >= 0; i--) {
        if (fa[u][i] != fa[v][i]) {
            // 合并 u 的区间
            int a = res1, b = maxw[u][i];
            int c = res2, d = maxw2[u][i];
            if (a > b) {
                res1 = a;
                res2 = max({b, c, d});
            } else if (a < b) {
                res1 = b;
                res2 = max({a, c, d});
            } else {
                res1 = a;
                res2 = max(c, d);
            }
            
            // 合并 v 的区间
            a = res1; b = maxw[v][i];
            c = res2; d = maxw2[v][i];
            if (a > b) {
                res1 = a;
                res2 = max({b, c, d});
            } else if (a < b) {
                res1 = b;
                res2 = max({a, c, d});
            } else {
                res1 = a;
                res2 = max(c, d);
            }
            
            u = fa[u][i];
            v = fa[v][i];
        }
    }
    
    // 最后一步到 LCA
    int a = res1, b = maxw[u][0];
    int c = res2, d = maxw2[u][0];
    if (a > b) {
        res1 = a;
        res2 = max({b, c, d});
    } else if (a < b) {
        res1 = b;
        res2 = max({a, c, d});
    } else {
        res1 = a;
        res2 = max(c, d);
    }
    
    a = res1; b = maxw[v][0];
    c = res2; d = maxw2[v][0];
    if (a > b) {
        res1 = a;
        res2 = max({b, c, d});
    } else if (a < b) {
        res1 = b;
        res2 = max({a, c, d});
    } else {
        res1 = a;
        res2 = max(c, d);
    }
    
    return {res1, res2};
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n, m;
    cin >> n >> m;
    
    for (int i = 1; i <= n; i++) {
        f[i] = i;
    }
    
    for (int i = 1; i <= m; i++) {
        cin >> e[i].u >> e[i].v >> e[i].w;
        e[i].used = false;
    }
    
    sort(e + 1, e + 1 + m);
    
    long long mst = 0;
    int cnt = 0;
    
    for (int i = 1; i <= m; i++) {
        int fu = find(e[i].u), fv = find(e[i].v);
        if (fu != fv) {
            f[fu] = fv;
            mst += e[i].w;
            e[i].used = true;
            adj[e[i].u].push_back({e[i].v, e[i].w});
            adj[e[i].v].push_back({e[i].u, e[i].w});
            cnt++;
            if (cnt == n - 1) break;
        }
    }
    
    dfs(1, 0, 0, 0);
    
    long long ans = 2e18;
    for (int i = 1; i <= m; i++) {
        if (!e[i].used) {
            auto [mx1, mx2] = query(e[i].u, e[i].v);
            if (e[i].w > mx1) {
                ans = min(ans, mst + e[i].w - mx1);
            } else if (mx2 != -INF) {
                ans = min(ans, mst + e[i].w - mx2);
            }
        }
    }
    
    cout << ans << "\n";
    return 0;
}
```

## 6. Kruskal 重构树

### 核心思想

**构建过程**：
1. 初始时，每个点是独立的树
2. 按边权从小到大考虑每条边
3. 如果边连接两棵不同的树，创建新节点作为这两棵树的父节点，新节点的权值 = 边权

**性质**：
- 原图的点是重构树的叶子节点
- 非叶节点权值从下到上递增
- 两点 u, v 的 LCA 权值 = u, v 连通时的最小瓶颈

### 应用：P2245 网络访问

**题意**：q 次查询，每次问 x 和 y 连通时的最小瓶颈（最大边权的最小值）。

**解法**：建 Kruskal 重构树，查询 LCA 的权值。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
const int M = 300005;
const int LOG = 19;

struct Edge {
    int u, v, w;
    bool operator<(const Edge& o) const {
        return w < o.w;
    }
} e[M];

int f[2 * N];
int val[2 * N];  // 节点权值（叶子为 0）
int cnt;

int find(int x) {
    if (x == f[x]) return x;
    return f[x] = find(f[x]);
}

int depth[2 * N];
int fa[2 * N][LOG];

void dfs(int u, int p, int d) {
    depth[u] = d;
    fa[u][0] = p;
    for (int i = 1; i < LOG; i++) {
        fa[u][i] = fa[fa[u][i-1]][i-1];
    }
    // 注意：重构树可能有多个子节点，需要遍历
    // 这里简化处理，实际需要用邻接表存树
}

int lca(int u, int v) {
    if (depth[u] < depth[v]) swap(u, v);
    for (int i = LOG - 1; i >= 0; i--) {
        if (depth[u] - (1 << i) >= depth[v]) {
            u = fa[u][i];
        }
    }
    if (u == v) return u;
    for (int i = LOG - 1; i >= 0; i--) {
        if (fa[u][i] != fa[v][i]) {
            u = fa[u][i];
            v = fa[v][i];
        }
    }
    return fa[u][0];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n, m, q;
    cin >> n >> m >> q;
    
    cnt = n;
    for (int i = 1; i <= n; i++) {
        f[i] = i;
        val[i] = 0;
    }
    
    for (int i = 1; i <= m; i++) {
        cin >> e[i].u >> e[i].v >> e[i].w;
    }
    
    sort(e + 1, e + 1 + m);
    
    for (int i = 1; i <= m; i++) {
        int fu = find(e[i].u), fv = find(e[i].v);
        if (fu != fv) {
            cnt++;
            f[cnt] = cnt;
            val[cnt] = e[i].w;
            f[fu] = cnt;
            f[fv] = cnt;
        }
    }
    
    // 建倍增表（需要 DFS，这里简化）
    // 实际实现需要存树的邻接表
    
    while (q--) {
        int x, y;
        cin >> x >> y;
        if (find(x) != find(y)) {
            cout << "impossible\n";
        } else {
            cout << val[lca(x, y)] << "\n";
        }
    }
    
    return 0;
}
```

**Kruskal 重构树的用处**：
- 查询两点连通的最小瓶颈
- 结合 DFS 序和数据结构，处理边权受限的树上问题

> **本节重点**：
> - Kruskal：边排序 + 并查集判环，O(m log m)
> - Prim：优先队列 + 贪心扩展，O((n+m) log n)
> - 最小生成树一定是瓶颈生成树
> - 次小生成树：枚举非树边替换树上路径的最大边
> - 严格次小生成树：需要维护严格次大边权
> - Kruskal 重构树：LCA 权值 = 两点连通的最小瓶颈
> - **常见坑**：
>   - 严格次小生成树要维护"严格次大"，不能只维护最大
>   - Kruskal 重构树节点数是 2n-1（n 个叶子 + n-1 个内部节点）
>   - 图不连通时最小生成树不存在，要先判断
