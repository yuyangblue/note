## 1. 引入与定位

**问题**：维护一个数组，支持 ① 单点修改 ② 区间查询（sum / max / gcd）

| 做法 | 单点修改 | 区间查询 | 短板 |
| --- | --- | --- | --- |
| 朴素数组 | $O(1)$ | $O(n)$ | 查询太慢 |
| ST 表 | 不能修改 | $O(1)$ | 不支持修改 |
| 树状数组 | $O(\log n)$ | $O(\log n)$ | 不能维护不可减信息（max、gcd） |

**线段树的定位**：修改和查询都 $O(\log n)$，**不要求可减**，只要求**可合并**（结合律）。

> 树状数组依赖可减性（和、异或可以减回去）；max/gcd/按位或没有逆运算，但满足结合律，线段树照样能维护。

## 2. 结构与基本操作

### 2.1 结构：区间二分

每个节点对应一个区间 $[l, r]$，叶子是单点，父区间 = 左右拼接。层数 $O(\log n)$，任意查询区间都能拆成 $O(\log n)$ 个整段。

### 2.2 存储：完全二叉树

- 节点 $i$ 的左子：$2i$，右子：$2i+1$
- **数组必须开 $4n$**（递归建树节点总数 $< 4n$）

### 2.3 建树 build（$O(n)$）

```cpp
void build(int p, int l, int r) {
    if (l == r) { t[p] = a[l]; return; }
    int m = (l + r) >> 1;
    build(p << 1, l, m);
    build(p << 1 | 1, m + 1, r);
    pushup(p);  // 回溯时合并
}
```

### 2.4 单点修改 update（$O(\log n)$）

只影响根到叶子的一条路径：

```cpp
void update(int p, int l, int r, int pos, long long v) {
    if (l == r) { t[p] = v; return; }
    int m = (l + r) >> 1;
    if (pos <= m) update(p << 1, l, m, pos, v);
    else          update(p << 1 | 1, m + 1, r, pos, v);
    pushup(p);
}
```

### 2.5 区间查询 query（$O(\log n)$）

```cpp
long long query(int p, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return t[p];   // 全覆盖
    if (qr < l || r < ql)   return 0;      // 无交集 → 单位元
    int m = (l + r) >> 1;
    return query(p << 1, l, m, ql, qr)
         + query(p << 1 | 1, m + 1, r, ql, qr);
}
```

> **四个固定件**：build / update / query / pushup。后面的题目只改 pushup 和节点信息，框架不动。

## 3. 只改 pushup，换一种维护

### 3.1 P1531：区间最大值

只需改两处：
- pushup 用 `max`
- 无交集返回 `-INF`（不是 0）

```cpp
void pushup(int p) { t[p] = max(t[p << 1], t[p << 1 | 1]); }
// query 中：if (qr < l || r < ql) return -INF;
```

### 3.2 P5142：区间方差（单点修改版）

**打包思想**：单存 sum 不够，要补 `sum2 = Σx²`

$$D = E(x^2) - E(x)^2 = \frac{\sum x^2}{n} - \left(\frac{\sum x}{n}\right)^2$$

```cpp
struct Node { long long sum, sum2; };
Node pushup(Node L, Node R) {
    return { L.sum + R.sum, L.sum2 + R.sum2 };
}
```

## 4. 结合律：线段树能维护什么

**判定标准**：两个相邻区间的答案能 $O(1)$ 合并成整个区间的答案 → 就能用线段树维护。

| 信息 | 单位元 | 说明 |
| --- | --- | --- |
| 和 / 异或 | 0 / 0 | 可减，树状数组也能做 |
| 积 | 1 | 不可减（含 0 无逆元），但可合并 |
| max / min / gcd / 按位或 | $-\infty$ / $+\infty$ / 0 / 0 | 不可减，但可合并 |
| 最大子段和 | $(0, -\infty, -\infty, -\infty)$ | 要打包四个值 |
| 矩阵乘法 | 单位矩阵 | 合并 = 矩阵乘 |
| 摩尔投票 | $(0, 0)$ | 候选 + 票数 |
| **反例** | — | 中位数、众数、单独的平均值 |

### 4.1 P4513：区间最大子段和

**节点存四元组**：

| 字段 | 含义 |
| --- | --- |
| `sum` | 整个区间的和 |
| `lmax` | 从左端开始的最大连续和 |
| `rmax` | 到右端结束的最大连续和 |
| `best` | 区间内最大子段和（答案） |

**pushup 公式**：

$$\text{sum} = L.\text{sum} + R.\text{sum}$$

$$\text{lmax} = \max(L.\text{lmax},\ L.\text{sum} + R.\text{lmax})$$

$$\text{rmax} = \max(R.\text{rmax},\ R.\text{sum} + L.\text{rmax})$$

$$\text{best} = \max(L.\text{best},\ R.\text{best},\ L.\text{rmax} + R.\text{lmax})$$

```cpp
struct Node { long long sum, lmax, rmax, best; };
Node unit() { return {0, -INF, -INF, -INF}; }

Node merge(Node L, Node R) {
    Node res;
    res.sum  = L.sum + R.sum;
    res.lmax = max(L.lmax, L.sum + R.lmax);
    res.rmax = max(R.rmax, R.sum + L.rmax);
    res.best = max({L.best, R.best, L.rmax + R.lmax});
    return res;
}
```

### 4.2 CF380C：括号序列

给 '(' ')' 组成的字符串，查询 $[l, r]$ 内最长合法括号子序列长度。

**节点存三元组** `{open, close, ans}`：
- `open`：未匹配的左括号数
- `close`：未匹配的右括号数
- `ans`：已配对的括号数

**merge**：

```cpp
struct Node { int open, close, ans; };
Node merge(Node L, Node R) {
    int x = min(L.open, R.close);  // 新增匹配
    return { L.open + R.open - x,
             L.close + R.close - x,
             L.ans + R.ans + x };
}
// 叶子：'(' → {1,0,0}；')' → {0,1,0}
```

## 5. 动态开点

### 动机

值域太大（$10^9$），$4n$ 开不下。离散化能做但不支持在线插入。

**解决**：不预建整棵树，update 访问到哪个节点就现场创建。

### 结构

```cpp
struct Node {
    int lc, rc;       // 左右子下标，0 = 空
    long long sum;
} tr[Q * 30];         // 空间 O(q log V)

void upd(int &p, int l, int r, int pos, int v) {
    if (!p) p = ++tot;   // 访问到哪，建到哪
    tr[p].sum += v;
    if (l == r) return;
    int m = (l + r) >> 1;
    if (pos <= m) upd(tr[p].lc, l, m, pos, v);
    else          upd(tr[p].rc, m + 1, r, pos, v);
}
```

**三个变化**：
1. $2i / 2i+1$ → `lc/rc` 指针
2. 不需要 build，从空树开始
3. query 遇到空节点返回单位元

### P1908：逆序对（值域 $10^9$）

```cpp
long long ans = 0;
for (int i = 1; i <= n; i++) {
    ans += query(root, 1, V, a[i] + 1, V);  // 已插入且比它大
    upd(root, 1, V, a[i], 1);               // 插入值域树
}
```

## 6. 主席树（可持久化线段树）

### 动机：静态区间第 K 小（P3834）

对每个前缀建一棵权值线段树：版本 $i$ = 前 $i$ 个数的值域统计。

区间统计 = 版本 $r$ − 版本 $l-1$

朴素做法 $O(n^2)$ 空间。可持久化把它压到 $O(n \log n)$。

### 核心思想：版本链 + 共享子树

新版本沿修改路径新建一条链（$O(\log V)$ 个节点），其余子树直接指回旧版本。

```cpp
int root[N];
int upd(int pre, int l, int r, int pos) {
    int p = ++tot;
    tr[p] = tr[pre];      // 复制旧节点，左右子树共享
    tr[p].cnt++;
    if (l == r) return p;
    int m = (l + r) >> 1;
    if (pos <= m) tr[p].lc = upd(tr[pre].lc, l, m, pos);
    else          tr[p].rc = upd(tr[pre].rc, m + 1, r, pos);
    return p;
}
// 建版本：root[i] = upd(root[i-1], 1, V, a[i]);
```

### 查询：两版本相减

```cpp
int kth(int u, int v, int l, int r, int k) {
    if (l == r) return l;
    int cnt = tr[tr[v].lc].cnt - tr[tr[u].lc].cnt;
    int m = (l + r) >> 1;
    if (k <= cnt) return kth(tr[u].lc, tr[v].lc, l, m, k);
    return kth(tr[u].rc, tr[v].rc, m + 1, r, k - cnt);
}
// 询问 [l, r]：kth(root[l-1], root[r], 1, V, k)
```

> **易错点**：版本号写错全盘皆错；参数 $(l-1, r)$ 顺序别混；最后把离散化值映射回原值。

## 7. 线段树优化建图

### CF786B：Legacy

三种边：① $u \to v$ ② $u \to [l,r]$ ③ $[l,r] \to u$

暴力连边 $O(n)$ 不可接受。

### 核心思想

任何区间 $[l, r]$ 都能拆成 $O(\log n)$ 个线段树整段。把每个整段对应的节点当"虚拟节点"。

### 两棵树

- **出树**（处理 $u \to [l,r]$）：父 → 子连 0 边，叶子 = 原节点
- **入树**（处理 $[l,r] \to u$）：子 → 父连 0 边，叶子 = 原节点

点数 $O(n)$，边数 $O((n+m) \log n)$，直接跑 Dijkstra。

## 8. 本节重点

> **本节重点**：
> - **线段树 = 区间二分 + 完全二叉树存储**，数组开 $4n$
> - **四个固定件**：build / update / query / pushup，框架不变，只改节点信息和 merge
> - **结合律**：可合并就能维护，不要求可减
> - **打包思想**：不够的信息补全（最大子段和四元组、括号三元组、方差二元组）
> - **动态开点**：值域大时按需建点，空间 $O(q \log V)$
> - **主席树**：前缀版本 + 共享子树，静态区间第 K 小
> - **优化建图**：出树 + 入树，区间连边拆成 $O(\log n)$ 条
> - **常见坑**：
>   - 单位元别写错（max 用 $-\infty$，不是 0）
>   - 主席树版本号 $(l-1, r)$ 顺序
>   - 动态开点 query 要判空节点
