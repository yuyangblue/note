## 1. 懒标记（Lazy Tag）

### 动机

区间修改朴素做法：把 $[l, r]$ 每个元素都改一遍，最坏 $O(n)$，$n$ 次操作 $O(n^2)$ 超时。

**懒标记**：整段统一修改时先记在标记上，只有部分覆盖才下传给儿子。修改/查询仍 $O(\log n)$。

### 核心概念

- 区间修改不逐点改，只对"覆盖整段的节点"动手
- 在节点上挂 `lazy` 标记，记录"这个区间统一被改成了什么样"
- 信息先按整段更新；等将来要访问子区间时，再把标记下传

### push_down 与 push_up

| 方向 | 操作 | 时机 |
| --- | --- | --- |
| push_down（父→子） | 把标记传给左右儿子，自己清零 | 进入部分覆盖的儿子前 |
| push_up（子→父） | 用儿子信息重算父亲 | 递归返回后 |

**口诀**：进入儿子前 pushdown，返回后 pushup。

### P3372：区间加 + 区间求和（模板）

```cpp
// apply：对节点 p 的区间 [l,r] 整体加 v
void apply(int p, int l, int r, long long v) {
    t[p] += (r - l + 1) * v;  // 区间和 += 长度 × v
    lazy[p] += v;             // 打上懒标记，等以后需要时再下传
}

// pushdown：把父节点的懒标记分给左右儿子
void pushdown(int p, int l, int r) {
    if (!lazy[p]) return;      // 没有标记就不用下传
    int m = (l + r) >> 1;
    apply(p << 1, l, m, lazy[p]);         // 左儿子继承标记
    apply(p << 1 | 1, m + 1, r, lazy[p]); // 右儿子继承标记
    lazy[p] = 0;                          // 父节点标记清零
}

void update(int p, int l, int r, int ql, int qr, long long v) {
    if (ql <= l && r <= qr) { apply(p, l, r, v); return; }  // 整段覆盖
    pushdown(p, l, r);  // 进儿子前必须先下传，否则子节点信息过期
    int m = (l + r) >> 1;
    if (ql <= m) update(p << 1, l, m, ql, qr, v);
    if (qr >  m) update(p << 1 | 1, m + 1, r, ql, qr, v);
    pushup(p);  // 回溯时合并
}

long long query(int p, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return t[p];
    pushdown(p, l, r);  // 查询前也要下传，确保子节点信息最新
    long long res = 0;
    int m = (l + r) >> 1;
    if (ql <= m) res += query(p << 1, l, m, ql, qr);
    if (qr >  m) res += query(p << 1 | 1, m + 1, r, ql, qr);
    return res;
}
```

### 懒标记设计框架：三个动词

| 动词 | 作用 |
| --- | --- |
| **apply** | 更新信息 + 打标记（每道题唯一要设计的地方） |
| **pushdown** | 进入部分覆盖的儿子前下传标记 |
| **pushup** | 回溯时用儿子信息重算父亲 |

### 1.1 P3373：区间加 + 区间乘

**节点维护**：`sum`（区间和）、`add`（加标记）、`mul`（乘标记）

**懒标记语义**：先乘后加，实际效果 = $\times mul$ 再 $+ add$

**为什么先乘后加**：如果先加后乘，新来的加法会被乘进去，顺序乱了。统一"先乘后加"才能正确合并标记。

```cpp
ll mod;
struct Node { ll sum, add, mul; } t[N << 2];

// apply：对节点 x 的区间整体"先乘 m 再加 a"
void apply(int x, int l, int r, ll m, ll a) {
    t[x].sum = (t[x].sum * m + (r - l + 1) * a) % mod;  // 区间和：先乘后加
    t[x].add = (t[x].add * m + a) % mod;  // 旧加法标记也要被乘
    t[x].mul = t[x].mul * m % mod;        // 乘法标记累积
}

void pushdown(int x, int l, int r) {
    int m = (l + r) >> 1;
    apply(x << 1, l, m, t[x].mul, t[x].add);         // 把 (mul, add) 一起传给儿子
    apply(x << 1 | 1, m + 1, r, t[x].mul, t[x].add);
    t[x].add = 0; t[x].mul = 1;  // 父节点标记复位（乘法单位元是1）
}
// 区间乘 v：apply(..., v, 0)；区间加 v：apply(..., 1, v)
```

### 1.2 P1471：区间方差

**节点维护**：`sum`（区间和）、`sum2`（区间平方和）

**方差公式**：$D = E(x^2) - E(x)^2$

**apply**（区间加 $v$）：

$$\sum(x+v)^2 = \sum x^2 + 2v\sum x + len \cdot v^2$$

```cpp
struct Node { long long sum, sum2; };
Node t[N << 2]; long long lazy[N << 2];

void apply(int p, int l, int r, long long v) {
    int len = r - l + 1;
    // 关键：sum2 要用旧的 sum 计算！如果先更新 sum 就错了
    t[p].sum2 += 2 * v * t[p].sum + len * v * v;  // 展开 (x+v)²
    t[p].sum  += len * v;
    lazy[p]   += v;
}
```

> **注意**：`sum2` 用旧 `sum` 计算，顺序不能反。

### 1.3 P6327：区间 sin 和

**节点维护**：`s = Σsin(a_i)`、`c = Σcos(a_i)`

**两角和公式**：

$$\sin(x+d) = \sin x \cos d + \cos x \sin d$$

$$\cos(x+d) = \cos x \cos d - \sin x \sin d$$

```cpp
struct Node { double s, c; };
Node t[N << 2]; double lazy[N << 2];

void apply(int p, int d) {
    double s = t[p].s, c = t[p].c;  // 先保存旧值
    t[p].s = s * cos(d) + c * sin(d);  // 整体旋转
    t[p].c = c * cos(d) - s * sin(d);
    lazy[p] += d;
}
```

### 1.4 CF718C：区间加 + 斐波那契和

**节点维护**：每个 $a_i$ 维护行向量 $w_i = [f(a_i), f(a_i+1)]$，节点存 $W = \sum w_i$

**斐波那契转移矩阵**：

$$F = \begin{pmatrix} 0 & 1 \\ 1 & 1 \end{pmatrix}$$

$w_i \cdot F^d = [f(a_i+d), f(a_i+d+1)]$

**懒标记**：$2 \times 2$ 矩阵 $F^d$

```cpp
struct Mat { long long a[2][2]; };
Mat F = {{{0, 1}, {1, 1}}};

void apply(int p, long long d) {
    t[p] = mul(t[p], pow(F, d));       // 向量 × F^d，整体"前进 d 步"
    lazy[p] = mul(lazy[p], pow(F, d)); // 矩阵标记累积
}
```

### 1.5 P2824：区间排序

给出 $1..n$ 的排列，操作：① $[l,r]$ 升序 ② $[l,r]$ 降序，最后问单个位置 $pos$ 的值。

**二分答案 + 0/1 赋值**：

- 二分 $x$：$a[i] \ge x$ 记为 1，否则为 0
- 区间升序 = 数 1 的个数 $cnt$，再把 0 放前面、1 放后面（区间赋值）
- 降序同理，1 放前面、0 放后面
- 最后查询位置是否为 1 决定二分方向，$O(n \log^2 n)$

## 2. 扫描线

### P5490：矩形面积并

$n$ 个矩形（可重叠），求覆盖总面积。坐标绝对值 $\le 10^9$。

### 思路

1. **拆边**：每个矩形拆成两条水平边，下边 $+1$（覆盖开始）、上边 $-1$（覆盖结束）
2. **排序**：$2n$ 条边按 $y$ 从小到大排序
3. **扫描**：相邻两条边之间覆盖不变，面积 $+= \Delta y \times$ 当前覆盖长度
4. **线段树**：维护 $x$ 轴上被至少覆盖一次的总长度 `len`

### 节点维护

- `cnt`：该 $x$ 段被完整覆盖的次数
- `len`：该 $x$ 段当前被覆盖的长度

**push_up**（本题没有懒标记，不 push_down）：

```cpp
void push_up(int p, int l, int r) {
    if (cnt[p] > 0) len[p] = X[r + 1] - X[l];      // 整段被覆盖
    else if (l == r) len[p] = 0;                     // 叶子且无覆盖
    else len[p] = len[p << 1] + len[p << 1 | 1];    // 拼儿子
}

void update(int p, int l, int r, int ql, int qr, int v) {
    if (ql <= l && r <= qr) { cnt[p] += v; }  // 整段覆盖，只改计数
    else {
        int m = (l + r) >> 1;
        if (ql <= m) update(p << 1, l, m, ql, qr, v);
        if (qr >  m) update(p << 1 | 1, m + 1, r, ql, qr, v);
    }
    push_up(p, l, r);  // 每次改完都要重新算 len
}
```

> **为什么不需要 pushdown**：同一矩形的下边 $+1$ 与上边 $-1$ 落在完全相同的节点分解上，一一对应抵消。

## 3. 特殊线段树

### P4198：楼房重建

$n$ 栋楼（位置 $1..n$，高度可变），操作：① 单点修改高度 ② 每次修改后回答从左往右能看到多少栋楼。

**可见条件**：楼顶不被左边任何楼挡住 ⇔ 斜率 $h/i$ 大于左侧所有楼的斜率。

**本质**：从左到右，斜率的前缀最大值一共出现了几次。

### 节点维护

```cpp
struct Node { double mx; int cnt; };  // mx: 最大斜率, cnt: 可见楼数
```

**push_up**：

```cpp
t[p].mx = max(t[p << 1].mx, t[p << 1 | 1].mx);
// 左半边的可见楼数直接继承，右半边要用 calc 算"大于左半边最大斜率"的可见数
t[p].cnt = t[p << 1].cnt + calc(p << 1 | 1, m + 1, r, t[p << 1].mx);
```

**calc(p, lim)**：返回区间内"斜率 > lim 且可见"的个数

```cpp
int calc(int p, int l, int r, double lim) {
    if (l == r) return t[p].mx > lim;  // 叶子：看是否大于阈值
    int m = (l + r) >> 1;
    if (t[p << 1].mx <= lim)
        // 左半边最大斜率都 ≤ lim，整段不可见，只递归右半边
        return calc(p << 1 | 1, m + 1, r, lim);
    // 左半边有 > lim 的，右半边全部可见（cnt - 左.cnt），只递归左半边
    return t[p].cnt - t[p << 1].cnt
         + calc(p << 1, l, m, lim);
}
```

> **calc 复杂度**：每层向下走一步，$O(\log n)$。

## 4. 线段树合并

### 概念

两棵动态开点权值线段树，把对应节点的计数相加；一方为空时直接返回另一方。

每个节点只合并一次 → 均摊 $O(n \log n)$。

### merge 函数

```cpp
int merge(int a, int b, int l, int r) {
    if (!a) return b;  // 空树直接返回另一方
    if (!b) return a;
    if (l == r) { tr[a].cnt += tr[b].cnt; return a; }  // 叶子：计数相加
    int m = (l + r) >> 1;
    tr[a].lc = merge(tr[a].lc, tr[b].lc, l, m);
    tr[a].rc = merge(tr[a].rc, tr[b].rc, m + 1, r);
    pushup(a);  // 回溯时更新
    return a;   // 返回合并后的根
}
```

## 5. 线段树分裂

### 概念

按"位置区间"把一棵动态开点线段树拆成两棵。与合并互逆，复杂度均摊 $O(n \log n)$。

### P5494：线段树分裂模板

```cpp
void split(int &p, int &q, int s, int t, int l, int r) {
    if (t < l || r < s) return;  // 无交集
    if (!p) return;              // 原树为空
    if (l <= s && t <= r) { 
        q = p; p = 0; return;    // 整段拿走，原位置置空
    }
    if (!q) q = New();           // 新树需要节点
    int m = (s + t) >> 1;
    if (l <= m) split(ls[p], ls[q], s, m, l, r);
    if (m < r) split(rs[p], rs[q], m + 1, t, l, r);
    push_up(p);  // 同时维护两棵树
    push_up(q);
}
```

### P2824：区间排序（分裂做法）

序列切成若干已排序段（颜色段）：每段 = 一棵值域线段树 + 方向标记。

- 排序 $[l,r]$：先把两端涉及的段沿边界切割，再把区间内所有段的值域树 merge 成一棵，打升/降序标记
- 切割时按方向标记从值域树里取大/取小
- 配合颜色段均摊 → $O(n \log n)$

| 做法 | 思路 | 复杂度 | 特点 |
| --- | --- | --- | --- |
| 二分 + 0/1 赋值 | 二分答案，排序 = 区间赋值 | $O(n \log^2 n)$ | 好写，单点询问 |
| 线段树分裂 | 值域树 merge + 方向标记 | 均摊 $O(n \log n)$ | 可输出所有位置 |

## 7. 本节重点

> **本节重点**：
> - **懒标记三动词**：apply（设计核心）/ pushdown / pushup
> - **双标记**（P3373）：先乘后加，一次 apply 统一处理
> - **打包 + 懒标记**：方差存 `sum + sum2`，sin 存 `s + c`，斐波那契存向量 + 矩阵标记
> - **扫描线**：矩形拆边 + 按 y 排序 + 线段树维护覆盖长度，**不需要 pushdown**
> - **楼房重建**：calc 函数递归剪枝，$O(\log n)$ 统计可见楼数
> - **线段树合并**：动态开点树对应节点相加，均摊 $O(n \log n)$
> - **线段树分裂**：与合并互逆，配合颜色段均摊
> - **常见坑**：
>   - apply 里用旧值计算新值（sum2 用旧 sum）
>   - 扫描线不需要 pushdown
>   - 合并时一方为空直接返回
>   - 分裂时整段拿走要置空原节点
