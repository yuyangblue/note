## 1. 大白话引入

生活中两种最常见的排队方式：

- **一摞盘子**：洗干净的盘子往上摞，用的时候从最上面拿。**最后放上去的，最先被拿出来**——这就是**栈**（LIFO, Last In First Out）。
- **食堂打饭排队**：先来的人站前面先打饭，后来的人排后面。**最先排队的，最先离开**——这就是**队列**（FIFO, First In First Out）。

栈和队列是最基础的两种数据结构，本身操作很简单（O(1) 插入/删除），但它们是很多高级算法的基石：DFS 用栈、BFS 用队列、表达式求值用栈、操作系统调度用队列……

而**单调栈**和**单调队列**是在栈/队列基础上加了一个约束：**内部元素保持单调（递增或递减）**。这个约束让它们能以 O(n) 的总复杂度解决一类"找下一个更大元素""滑动窗口最值"的问题，是竞赛中非常高频的技巧。

## 2. 栈（Stack）

### 核心思想

栈是一种**只能在一端（栈顶）操作**的线性表：
- `push(x)`：把 x 放到栈顶
- `pop()`：弹出栈顶元素
- `top()`：查看栈顶元素（不弹出）
- `empty()`：栈是否为空
- `size()`：栈中元素个数

因为只能在栈顶操作，所以**最后入栈的元素最先出栈**（LIFO）。

### STL 用法

C++ 标准库提供了 `std::stack`，底层默认用 `deque` 实现：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    stack<int> st;
    st.push(10);        // 入栈
    st.push(20);
    cout << st.top();   // 20（查看栈顶）
    st.pop();           // 弹出 20
    cout << st.size();  // 1
    cout << st.empty(); // 0（非空）
    return 0;
}
```

竞赛中如果只需要简单的栈，直接用 `std::stack` 即可。但理解手写实现有助于掌握原理，且某些场景（如需要遍历栈内元素）手写数组栈更灵活。

### 手写数组栈

用一个数组 `st[]` 和一个栈顶指针 `top`（指向下一个可插入的位置，或栈顶元素的下标，两种约定都行）。下面用 `top` 表示**栈顶元素的下标**，初始为 -1（空栈）。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int st[MAXN];  // 栈的存储空间
int top = -1;  // 栈顶元素下标，-1 表示空栈

// 入栈：把 x 放到栈顶
void push(int x) {
    st[++top] = x;  // 先移动指针，再赋值（top 从 -1 变 0）
}

// 出栈：弹出栈顶元素
void pop() {
    if (top >= 0) top--;  // 栈非空时指针前移即可，不需要真正清除数据
}

// 查看栈顶
int getTop() {
    return st[top];
}

// 栈是否为空
bool empty() {
    return top == -1;
}

// 栈大小
int size() {
    return top + 1;
}

int main() {
    int n;
    scanf("%d", &n);
    while (n--) {
        int op;
        scanf("%d", &op);
        if (op == 1) {
            int x;
            scanf("%d", &x);
            push(x);
        } else if (op == 2) {
            pop();
        } else if (op == 3) {
            printf("%d\n", getTop());
        } else if (op == 4) {
            printf("%d\n", size());
        } else {
            printf("%d\n", empty() ? 1 : 0);
        }
    }
    return 0;
}
```

**关键点**：
- `top` 初始为 -1，`push` 时 `++top` 先加再用，保证第一个元素放在 `st[0]`
- `pop` 只是移动指针，不清除数据——下次 `push` 会覆盖，这是数组栈的标准做法
- 所有操作都是 O(1)，数组栈比 STL stack 略快（无函数调用开销），竞赛大数据时常用

**常见应用**：
- 括号匹配（遇到左括号入栈，右括号时出栈匹配）
- 表达式求值（中缀转后缀 + 后缀求值）
- 模拟递归（函数调用栈）
- 单调栈（见第 4 节）

## 3. 队列（Queue）

### 核心思想

队列是一种**在队尾插入、队首删除**的线性表：
- `push(x)`：把 x 加到队尾
- `pop()`：弹出队首元素
- `front()`：查看队首元素
- `back()`：查看队尾元素
- `empty()` / `size()`

因为队首出、队尾入，所以**最先入队的最先出队**（FIFO）。

### STL 用法

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    queue<int> q;
    q.push(10);       // 入队
    q.push(20);
    cout << q.front(); // 10（队首）
    cout << q.back();  // 20（队尾）
    q.pop();           // 弹出 10
    cout << q.size();  // 1
    return 0;
}
```

### 手写循环队列

如果用普通数组 + 队首指针 `head`、队尾指针 `tail`，会出现一个问题：不断出队后，`head` 往右移，左边的空间就浪费了（"假溢出"——数组后面满了但前面空着）。

解决方法是**循环队列**：把数组看成环形，指针到达数组末尾后绕回开头。用 `(tail + 1) % MAXN` 判断是否满，牺牲一个格子来区分"满"和"空"。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int q[MAXN];   // 队列存储空间
int head = 0;  // 队首元素下标
int tail = 0;  // 下一个可插入位置（队尾的下一位）

// 入队：把 x 加到队尾
void push(int x) {
    q[tail] = x;
    tail = (tail + 1) % MAXN;  // 循环：到末尾绕回开头
}

// 出队：弹出队首
void pop() {
    head = (head + 1) % MAXN;
}

// 查看队首
int front() {
    return q[head];
}

// 查看队尾
int back() {
    return q[(tail - 1 + MAXN) % MAXN];  // tail 指向下一个空位，队尾是 tail-1
}

// 队列大小
int size() {
    return (tail - head + MAXN) % MAXN;  // 循环下的大小计算
}

// 队列是否为空
bool empty() {
    return head == tail;
}

int main() {
    int n;
    scanf("%d", &n);
    while (n--) {
        int op;
        scanf("%d", &op);
        if (op == 1) {
            int x;
            scanf("%d", &x);
            push(x);
        } else if (op == 2) {
            pop();
        } else if (op == 3) {
            printf("%d\n", front());
        } else if (op == 4) {
            printf("%d\n", back());
        } else if (op == 5) {
            printf("%d\n", size());
        } else {
            printf("%d\n", empty() ? 1 : 0);
        }
    }
    return 0;
}
```

**关键点**：
- `tail` 指向**下一个可插入的空位**，不是队尾元素本身；所以 `back()` 要取 `tail-1`
- 循环用 `% MAXN` 实现绕回，`(tail - 1 + MAXN) % MAXN` 避免负数
- 牺牲一个格子区分空和满：空 = `head == tail`，满 = `(tail + 1) % MAXN == head`。本代码没写满判断，竞赛中通常开足够大的数组（MAXN > 最大操作数）就不会满
- 所有操作 O(1)

**常见应用**：
- BFS（广度优先搜索，按层遍历）
- 任务调度（操作系统进程队列）
- 单调队列（见第 5 节）

## 4. 单调栈

### 思维启发：从朴素做法出发

**问题**：给定数组 a，对每个 i，求**右边第一个比 a[i] 大的元素的位置**（不存在则为 0）。这就是洛谷 P5788【模板】单调栈。

**朴素做法**：对每个 i，从 i+1 往右扫，直到找到比 a[i] 大的。最坏 O(n²)（数组单调递减时，每个都要扫到末尾）。

**能不能更快？** 观察一下：如果 a[j] < a[k] 且 j < k，那么对于任何 i < j，a[j] 永远不可能成为"右边第一个更大的"——因为 a[k] 比 a[j] 大且更靠右，会先被选中。所以 a[j] 这种"又小又靠左"的元素可以直接丢掉。

这就是单调栈的核心直觉：**维护一个单调递减的栈**，栈里的元素从栈底到栈顶递减。遇到新元素时，弹出所有比它小的栈顶（这些元素的"右边第一个更大"就是当前元素），然后把当前元素入栈。

### 核心思想

单调栈维护一个**内部元素单调**的栈（递增或递减，依题目而定）。每个元素**入栈一次、出栈一次**，总操作数 O(n)。

以"找右边第一个更大元素"为例，维护**单调递减栈**（栈底 > 栈顶）：

1. 从左到右遍历每个元素 a[i]
2. 当栈不为空且栈顶元素的值 < a[i] 时，弹出栈顶元素 j，记录 `ans[j] = i`（a[i] 就是 j 右边第一个更大的）
3. 把 i 入栈
4. 遍历结束后，栈中剩余元素的 ans 为 0（右边没有更大的）

**手算小例子**：a = [1, 4, 2, 3, 5]

| 步骤 | 当前元素 | 操作 | 栈（存下标，值递减） | ans |
|------|---------|------|---------------------|-----|
| i=1, a=1 | 1 | 入栈 | [1] | - |
| i=2, a=4 | 4 | 弹出1(ans[1]=2)，入栈2 | [2] | ans[1]=2 |
| i=3, a=2 | 2 | 入栈（2<4，递减保持） | [2,3] | - |
| i=4, a=3 | 3 | 弹出3(ans[3]=4)，入栈4 | [2,4] | ans[3]=4 |
| i=5, a=5 | 5 | 弹出4(ans[4]=5)，弹出2(ans[2]=5)，入栈5 | [5] | ans[4]=5, ans[2]=5 |
| 结束 | - | 栈中剩余5，ans[5]=0 | - | ans[5]=0 |

最终 ans = [2, 5, 4, 5, 0]，正确。

### 模板代码（P5788）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 3000005;  // P5788 数据范围 3e6，注意开大
int a[MAXN];
int ans[MAXN];
int st[MAXN];  // 单调栈，存下标
int top = -1;

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
    }

    // 从左到右遍历，维护单调递减栈（栈底值大，栈顶值小）
    for (int i = 1; i <= n; i++) {
        // 弹出所有比 a[i] 小的栈顶：它们的"右边第一个更大"就是 i
        while (top >= 0 && a[st[top]] < a[i]) {
            ans[st[top]] = i;  // 记录答案
            top--;              // 弹出
        }
        // 把 i 入栈（此时栈顶值 >= a[i]，递减性保持）
        st[++top] = i;
    }

    // 栈中剩余元素右边没有更大的，ans 保持 0（全局数组默认 0）

    for (int i = 1; i <= n; i++) {
        printf("%d%c", ans[i], i == n ? '\n' : ' ');
    }
    return 0;
}
```

**关键点**：
- 栈里存的是**下标**，不是值——因为答案要的是位置，且通过下标可以随时取到值 `a[st[top]]`
- 比较条件 `a[st[top]] < a[i]`：找"更大"用 `<`，找"更小"改成 `>`，找"大于等于"改成 `<=`，依题意调整
- 数据范围 3e6 时要用 `scanf/printf`，cin 会 TLE；数组也要开够大
- 时间复杂度 O(n)：每个元素入栈一次、出栈一次，while 循环总次数不超过 n

### 经典应用：柱状图最大矩形

**问题**：给定 n 个柱子的高度，求能构成的最大矩形面积。例如高度 [2,1,5,6,2,3]，最大面积是 10（5 和 6 组成宽 2 高 5 的矩形）。

**思路**：对每个柱子 i，找到它**左边第一个比它矮的位置 L[i]** 和**右边第一个比它矮的位置 R[i]**，那么以 i 为最高柱子的矩形宽度是 `R[i] - L[i] - 1`，面积是 `h[i] * (R[i] - L[i] - 1)`。取所有 i 的最大值。

用单调栈分别从左往右和从右往左扫一遍，求出 L 和 R。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int h[MAXN];
int L[MAXN];  // L[i] = 左边第一个比 h[i] 小的位置
int R[MAXN];  // R[i] = 右边第一个比 h[i] 小的位置
int st[MAXN];
int top;

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &h[i]);
    }

    // 求 L[i]：从左往右，维护单调递增栈（栈底小，栈顶大）
    // 遇到 h[i] 时，弹出 >= h[i] 的栈顶，剩下的栈顶就是左边第一个更小的
    top = -1;
    for (int i = 1; i <= n; i++) {
        while (top >= 0 && h[st[top]] >= h[i]) {
            top--;  // 弹出 >= h[i] 的，它们不可能成为 i 左边的"第一个更小"
        }
        L[i] = (top >= 0) ? st[top] : 0;  // 栈空说明左边没有更小的，用 0 做哨兵
        st[++top] = i;
    }

    // 求 R[i]：从右往左，同样维护单调递增栈
    top = -1;
    for (int i = n; i >= 1; i--) {
        while (top >= 0 && h[st[top]] >= h[i]) {
            top--;
        }
        R[i] = (top >= 0) ? st[top] : n + 1;  // 栈空用 n+1 做哨兵
        st[++top] = i;
    }

    // 对每个柱子，以它为最高的矩形面积 = h[i] * 宽度
    // 宽度 = R[i] - L[i] - 1（L 和 R 都是"比它矮"的位置，中间都是 >= h[i] 的）
    long long ans = 0;
    for (int i = 1; i <= n; i++) {
        long long area = (long long)h[i] * (R[i] - L[i] - 1);
        ans = max(ans, area);
    }

    printf("%lld\n", ans);
    return 0;
}
```

**关键点**：
- 用哨兵位置 0 和 n+1 处理边界（栈空时 L=0 或 R=n+1），避免特判
- 弹出条件用 `>=`（包含相等）：相等的柱子互相不阻挡，宽度计算正确
- 面积可能超 int（h=1e9, n=1e5 时面积 1e14），用 `long long`
- 两遍单调栈，总复杂度 O(n)

### 单调栈常见变体总结

| 问题 | 遍历方向 | 栈单调性 | 弹出条件 |
|------|---------|---------|---------|
| 右边第一个更大 | 左→右 | 递减 | 栈顶值 < 当前值 |
| 右边第一个更小 | 左→右 | 递增 | 栈顶值 > 当前值 |
| 左边第一个更大 | 右→左 | 递减 | 栈顶值 < 当前值 |
| 左边第一个更小 | 右→左 | 递增 | 栈顶值 > 当前值 |

记忆技巧：**找"更大"就维护递减栈**（因为要把小的弹掉，留下大的）；**找"更小"就维护递增栈**。方向决定了是"左边"还是"右边"。

## 5. 单调队列

### 思维启发：滑动窗口最大值

**问题**：给定数组 a 和窗口大小 k，从左到右滑动窗口，输出每个窗口内的最大值。这就是洛谷 P1886 滑动窗口 /【模板】单调队列。

**朴素做法**：每个窗口扫一遍找最大值，O(n·k)，k 大时超时。

**能不能用单调栈？** 单调栈只能在一端操作，但滑动窗口需要**从队首删除过期元素**（窗口滑出左边的元素）+ **从队尾加入新元素**。这需要双端操作——用**单调队列**（双端队列 deque）。

### 核心思想

单调队列维护一个**内部元素单调**的双端队列，支持：
- **队尾入队**：新元素从队尾加入，加入前弹出所有比它小（或大，依题意）的队尾元素
- **队首出队**：窗口滑动时，过期元素从队首移除
- **查询最值**：队首元素就是当前窗口的最值

以"滑动窗口最大值"为例，维护**单调递减队列**（队首最大，队尾最小）：

1. 新元素 a[i] 入队前，从队尾弹出所有 <= a[i] 的元素（它们不可能成为后续窗口的最大值，因为 a[i] 比它们大且更晚过期）
2. 把 a[i]（连同下标 i）从队尾入队
3. 检查队首元素是否已滑出窗口（下标 < i - k + 1），滑出则从队首移除
4. 当 i >= k 时，队首就是当前窗口的最大值

**手算小例子**：a = [1, 3, -1, -3, 5, 3, 6, 7]，k=3

| i | a[i] | 入队前弹出 | 队列（存下标，值递减） | 窗口 | 最大值 |
|---|------|-----------|---------------------|------|--------|
| 1 | 1 | 无 | [1] | - | - |
| 2 | 3 | 弹出1(1<3) | [2] | - | - |
| 3 | -1 | 无 | [2,3] | [1,3] | 3(a[2]) |
| 4 | -3 | 无 | [2,3,4] | [2,4] | 3(a[2]) |
| 5 | 5 | 弹出4,3,2(都<5) | [5] | [3,5] | 5(a[5]) |
| 6 | 3 | 无 | [5,6] | [4,6] | 5(a[5]) |
| 7 | 6 | 弹出6(3<6)，弹出5(5<6) | [7] | [5,7] | 6(a[7]) |
| 8 | 7 | 弹出7(6<7) | [8] | [6,8] | 7(a[8]) |

最大值序列：3, 3, 5, 5, 6, 7，正确。

### 模板代码（P1886）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1000005;
int a[MAXN];
int q[MAXN];   // 单调队列，存下标
int head, tail;

int main() {
    int n, k;
    scanf("%d%d", &n, &k);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
    }

    // ===== 求滑动窗口最小值：维护单调递增队列（队首最小） =====
    head = 0; tail = -1;
    for (int i = 1; i <= n; i++) {
        // 队尾弹出 >= a[i] 的（它们不可能成为后续窗口最小值）
        while (head <= tail && a[q[tail]] >= a[i]) {
            tail--;
        }
        q[++tail] = i;  // 入队
        // 队首过期检查：下标 < i-k+1 说明已滑出窗口
        while (q[head] < i - k + 1) {
            head++;
        }
        // 窗口形成后输出队首（最小值）
        if (i >= k) {
            printf("%d%c", a[q[head]], i == n ? '\n' : ' ');
        }
    }

    // ===== 求滑动窗口最大值：维护单调递减队列（队首最大） =====
    head = 0; tail = -1;
    for (int i = 1; i <= n; i++) {
        // 队尾弹出 <= a[i] 的（它们不可能成为后续窗口最大值）
        while (head <= tail && a[q[tail]] <= a[i]) {
            tail--;
        }
        q[++tail] = i;
        // 队首过期检查
        while (q[head] < i - k + 1) {
            head++;
        }
        if (i >= k) {
            printf("%d%c", a[q[head]], i == n ? '\n' : ' ');
        }
    }

    return 0;
}
```

**关键点**：
- 队列存**下标**，通过 `a[q[head]]` 取值，且用下标判断是否过期
- 最小值用**递增队列**（弹出 `>=`），最大值用**递减队列**（弹出 `<=`）——和单调栈的规律一致
- 过期检查用 `while` 而不是 `if`：理论上每次只可能过期一个，但 while 更安全（防止多个连续过期的边界情况）
- 手写数组模拟双端队列比 STL deque 快，竞赛大数据时常用
- 时间复杂度 O(n)：每个元素入队一次、出队一次

### 单调队列的其他应用

- **单调队列优化 DP**：某些 DP 转移方程形如 `dp[i] = max(dp[j] + val(j))`（j 在某个范围内），可以用单调队列维护最优 j，把 O(n²) 降到 O(n)
- **寻找满足条件的最长子数组**：配合二分或双指针
- **最大子段和**：前缀和 + 单调队列维护最小前缀和

> **本节重点**：
> - 栈 LIFO、队列 FIFO，都是 O(1) 插入/删除；手写数组栈用 `top` 指针，手写循环队列用 `head/tail` + 取模
> - **单调栈**：维护单调栈，每个元素入栈出栈各一次 O(n)，解决"找左右第一个更大/更小"类问题
>   - 找"更大"用递减栈（弹 `<`），找"更小"用递增栈（弹 `>`）
>   - 栈里存下标，答案是位置
> - **单调队列**：双端单调队列，队首是窗口最值，队尾入队时弹出不可能成为最优的元素
>   - 最小值用递增队列（弹 `>=`），最大值用递减队列（弹 `<=`）
>   - 必须检查队首是否过期（滑出窗口）
> - **常见坑**：
>   - 单调栈/队列存下标不存值，因为要判断位置/过期
>   - 比较符号容易写反（`<` vs `<=`），严格大于还是大于等于要看题意
>   - 柱状图面积用 `long long`，边界用哨兵 0 和 n+1
>   - P5788 数据 3e6，必须用 scanf/printf 且数组开大
