## 1. 问题背景

给定一个序列，需要支持两种操作：
1. **单点修改**：把某个位置的数改成另一个值
2. **前缀求和**：计算 $1$ 到 $i$ 的元素之和

| 做法 | 修改 | 查询 |
| --- | --- | --- |
| 朴素 | $O(1)$ | $O(n)$ |
| 前缀和预处理 | $O(n)$ | $O(1)$ |
| **树状数组** | $O(\log n)$ | $O(\log n)$ |

---

## 2. 核心思想

把相邻元素打包成块，块再打包成更大的块（类似线段树但更紧凑）：

- 查询前缀和时，拆成 $O(\log n)$ 个区间
- 单点修改时，只影响 $O(\log n)$ 个区间

> 树状数组本质是**线段树删掉右儿子**的简化版。

---

## 3. lowbit 运算

**定义**：`lowbit(x)` = $x$ 二进制最低位 $1$ 及其后面的 $0$ 组成的数

| $x$ | 二进制 | lowbit |
| --- | --- | --- |
| 6 | 110 | 2 |
| 12 | 1100 | 4 |
| 8 | 1000 | 8 |

**代码**：
```cpp
int lowbit(int x) {
    return x & (-x);  // 补码原理：-x = ~x + 1
}
```

**含义**：节点 $x$ 管辖的区间长度 = `lowbit(x)`，区间为 $[x - \text{lowbit}(x) + 1,\ x]$

---

## 4. 前缀查询

求 $1$ 到 $x$ 的前缀和：

```cpp
int query(int x) {
    int sum = 0;
    while (x > 0) {
        sum += c[x];
        x -= lowbit(x);  // 跳到左边相邻区间
    }
    return sum;
}
```

**原理**：每次跳到一个更大的区间，最多跳 $O(\log n)$ 次。

---

## 5. 单点修改

在位置 $x$ 加上 $v$：

```cpp
void update(int x, int v) {
    while (x <= n) {
        c[x] += v;
        x += lowbit(x);  // 跳到父节点
    }
}
```

**原理**：节点 $x$ 的父节点是 $x + \text{lowbit}(x)$，最多跳 $O(\log n)$ 次。

## 6. O(n) 建树

**方法一**：利用前缀和
```cpp
for (int i = 1; i <= n; i++) {
    s[i] = s[i - 1] + a[i];  // 先求前缀和
    c[i] = s[i] - s[i - lowbit(i)];  // c[i] = 区间和
}
```

**方法二**：儿子贡献给父亲
```cpp
for (int i = 1; i <= n; i++) {
    c[i] += a[i];
    int fa = i + lowbit(i);
    if (fa <= n) c[fa] += c[i];
}
```

## 7. 树状数组一：单点修改 + 区间求和

**题意**：单点修改 + 查询区间 $[l, r]$ 的和

**解法**：区间和 = 前缀和相减
```cpp
int range_query(int l, int r) {
    return query(r) - query(l - 1);
}
```

## 8. 树状数组二：区间加 + 单点查询（差分）

**题意**：区间 $[l, r]$ 加上 $x$ + 查询单点值

**核心思想**：维护**差分数组** $d$，其中 $d[i] = a[i] - a[i-1]$

- 区间加 $[l, r]$ 加 $x$ → $d[l] += x$，$d[r+1] -= x$
- 单点查询 $a[i]$ → 差分数组前缀和 $\sum_{j=1}^{i} d[j]$

```cpp
// 区间加
void range_add(int l, int r, int x) {
    update(l, x);
    update(r + 1, -x);
}

// 单点查询
int point_query(int x) {
    return query(x);  // 差分数组前缀和 = 原数组值
}
```

> **注意**：值可能超 `int`，开 `long long`。

## 9. 应用一：逆序对（值域树状数组）

**题意**：求序列中逆序对数量（$i < j$ 且 $a[i] > a[j]$）

**思路**：从右往左扫，维护已扫过的数的**值域出现次数**，查询比当前数小的有多少个。

```cpp
// 离散化（值域太大时）
vector<int> b(a + 1, a + n + 1);
sort(b.begin(), b.end());
b.erase(unique(b.begin(), b.end()), b.end());
for (int i = 1; i <= n; i++) {
    a[i] = lower_bound(b.begin(), b.end(), a[i]) - b.begin() + 1;
}

// 从右往左扫
long long ans = 0;
for (int i = n; i >= 1; i--) {
    ans += query(a[i] - 1);  // 比 a[i] 小的有多少个
    update(a[i], 1);         // 把 a[i] 加入集合
}
```

## 10. 应用二：最长上升子序列（前缀 max）

**题意**：求 LIS 长度，$n \le 10^5$

**思路**：$dp[i]$ = 以 $a[i]$ 结尾的 LIS 长度。转移：$dp[i] = 1 + \max_{j < i, a[j] < a[i]} dp[j]$

用**值域树状数组维护前缀 max**：

```cpp
// 前缀 max 更新（只能增不能减）
void update_max(int x, int v) {
    while (x <= M) {  // M 是值域
        c[x] = max(c[x], v);
        x += lowbit(x);
    }
}

// 前缀 max 查询
int query_max(int x) {
    int res = 0;
    while (x > 0) {
        res = max(res, c[x]);
        x -= lowbit(x);
    }
    return res;
}

// 求 LIS
for (int i = 1; i <= n; i++) {
    dp[i] = 1 + query_max(a[i] - 1);
    update_max(a[i], dp[i]);
}
int ans = *max_element(dp + 1, dp + n + 1);
```

> **注意**：前缀 max 树状数组**不能做区间 max**（max 不可逆），只能查前缀。

## 11. 应用三：树状数组上二分（第 K 小）

**题意**：动态插入元素，查询第 $K$ 小

**思路**：在值域树状数组上**倍增**，$O(\log n)$ 找到最小的 $x$ 使得前缀和 $\ge K$。

```cpp
int find_kth(int k) {
    int pos = 0;
    for (int j = 20; j >= 0; j--) {  // 2^20 > 10^5
        int nxt = pos + (1 << j);
        if (nxt <= M && c[nxt] < k) {
            pos = nxt;
            k -= c[pos];  // 砍掉左边已有的
        }
    }
    return pos + 1;
}
```

**原理**：从高位到低位贪心，如果加上这一位后前缀和仍 $< K$，说明答案在右边，砍掉左边继续找。

---

## 12. 本节重点

> **本节重点**：
> - **lowbit(x) = x & (-x)**：节点 $x$ 管辖区间长度
> - **单点修改**：`x += lowbit(x)` 跳父节点
> - **前缀查询**：`x -= lowbit(x)` 跳左边区间
> - **两种经典模型**：
>   - 树状数组一：单点修改 + 区间求和
>   - 树状数组二：区间加 + 单点查询（差分）
> - **值域树状数组**：把值作为下标，维护出现次数
> - **前缀 max 树状数组**：只能增不能减，不能做区间 max
> - **树上二分**：倍增找第 K 小，$O(\log n)$
> - **常见坑**：
>   - 值域太大时要**离散化**
>   - 区间加时 $r+1$ 可能超 $n$，要判边界
>   - 前缀 max 不可逆，不能做区间查询
>   - 注意 `long long` 防爆
