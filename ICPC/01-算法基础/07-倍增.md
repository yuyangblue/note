# 07. 倍增（Binary Lifting）

> 🎯 目标：吃透倍增思想——"只预处理 2^k 尺度的状态，查询时按二进制拼"。理解它的两个必要条件（尺度翻倍可构造 / 子结果可组合），掌握快速幂、树上 K 级祖先、ST 表、函数图倍增、LCA 五个经典应用。**倍增不是某个数据结构，而是一种"省事"的递推思路**：把 O(n) 的重复过程压成 O(log n)。
>

## 一、倍增思想 — "只存 2^k 档位"

### 1.1 大白话引入（砝码称重）

> 例题：如何用**尽可能少**的砝码，在天平一端称出 [0, 31] 之间所有整数重量？

答案是 5 个砝码：1、2、4、8、16。任何 0~31 的重量都能用它们的子集拼出来（31 的二进制 = 11111，每个 1 对应一个砝码）。想称到 [0, 1023] 只需要 10 个砝码，[0, 1048575] 只需要 20 个——**目标范围翻倍，砝码只多 1 个**，这就是"对数级"增长。

> 类比：砝码 = 预处理好的 2^k 档位。**不用存每一档（1,2,3,4...），只存翻倍档（1,2,4,8...），用时按二进制拼。**

### 1.2 核心思想

很多问题里，同一个确定性的过程要重复执行很多次（跳很多步、走很多格、查很多次区间）。逐步模拟要 O(n)，太慢。

倍增的做法：

1. **预处理**：只存"2^k 尺度"的状态（跳 2^k 步到哪、长度 2^k 的区间最值是多少……），一共只有 O(log n) 档；
2. **查询**：把目标量二进制展开，用预处理好的档位**拼**出答案，O(log n) 甚至 O(1)。

```
存：   1 步      2 步      4 步      8 步  ...（只有 log n 个）
        ↓        ↓        ↓        ↓
查 13 步 = 8 步 + 4 步 + 1 步   ← 二进制拆分：13 = (1101)₂
```

### 1.3 倍增的两个必要条件（核心中的核心）

用倍增不是万能药，一个过程能用倍增加速，必须同时满足：

**条件 1：已知尺度 X 的状态，能高效构造尺度 2X 的状态（翻倍递推）**

也就是说：知道"跳 2^j 步"的所有答案，要能快速推出"跳 2^(j+1) 步"的答案。这是预处理阶段的引擎。

- 区间最小值：`F[i][j] = min(F[i][j-1], F[i+2^(j-1)][j-1])`（两个 2^(j-1) 长度拼成 2^j）
- 树上跳：`up[x][j] = up[ up[x][j-1] ][j-1]`（先跳 2^(j-1) 步，再跳 2^(j-1) 步）

**条件 2：子结果可以按特定方式组合出大结果（查询阶段的拼法）**

拼法有两种，取决于"贡献能不能重复计算"：

| 拼法 | 适用场景 | 怎么做 | 代表 |
|------|---------|--------|------|
| 覆盖法 | 元素**可重复贡献**（重复算不影响答案） | 取最大 2^k ≤ 区间长度，左右各放一段 2^k 覆盖整个区间 | max / min / gcd |
| 拆分法 | 元素**不可重复贡献**（重复算就错） | 把目标二进制拆分，一段段不重叠地拼 | sum / 计数 |

> 直觉：max 重复算同一个数没关系（max(5,5)=5），所以两段覆盖可以重叠；sum 把一段加两遍就错了，必须拆成互不重叠的段。

## 二、快速幂 — 倍增的第一个例子（P1226）

### 2.1 思考流程

要算 a^b，b 可以到 10^9。for 循环乘 b 次 → O(b) 超时。

**先想数学**：b 是偶数时，a^b = (a^(b/2))²；b 是奇数时，a^b = (a^(b/2))² × a。每次把指数砍半，递归深度只有 O(log b)——这是**递归版**快速幂，规模每次减半。

**再用倍增视角看**：与其递归，不如**预先把 a^1, a^2, a^4, a^8, ... 全算好**（每个都是上一个的平方，档位翻倍），查询时把 b 二进制拆分直接拼：

```
a^13 = a^8 × a^4 × a^1        （13 = 8+4+1）
```

预处理 O(log b) 个档位，查询也 O(log b) 步。

### 2.2 代码（迭代版，竞赛实战写法）

```cpp
#include <bits/stdc++.h>
using namespace std;

// 快速幂：倍增思想的第一课
// 预处理 a^1, a^2, a^4, ...（每次平方），查询时按 b 的二进制位拼
long long qpow(long long a, long long b, long long mod) {
    long long res = 1 % mod;   // 空积：b=0 时返回 1（模意义下写 1%mod 防 mod=1 的坑）
    while (b) {
        if (b & 1) res = res * a % mod;   // b 这一位是 1 → 把当前档位乘进去
        a = a * a % mod;                  // 档位翻倍：a^(2^k) → a^(2^(k+1))
        b >>= 1;                          // 看下一位
    }
    return res;
}

int main() {
    long long a, b, p;
    cin >> a >> b >> p;
    cout << qpow(a, b, p) << endl;
    return 0;
}
```

**复杂度**：O(log b)。b=10^9 时只循环 30 次；暴力要乘 10^9 次。

**坑**：
- `res = 1 % mod` 而不是直接 1：当 mod=1 时任何数模 1 都是 0，直接初始化 1 会错（虽然竞赛很少见，但写对没成本）。
- `a * a % mod` 必须取模，否则 a 指数级增长直接溢出 long long。
- 乘法 `res * a` 用 long long：两个 10^9 量级的数相乘约 10^18，int 必炸。

## 三、树上 K 级祖先

### 3.1 问题 & 定义

给一棵树，问节点 x 往上跳 k 步（k 级祖先）到哪个节点。暴力一步一步跳 O(k)，k 可以到 10^9 级别。

定义 `up[x][j]` = 从 x 往上跳 **2^j 步**到达的节点（0 表示跳出去了/不存在）。

**边界**：`up[x][0]` = x 的父亲。

**递推**（条件 1 的应用）：跳 2^j 步 = 先跳 2^(j-1) 步，再从中间点跳 2^(j-1) 步：

```
up[x][j] = up[ up[x][j-1] ][j-1]
```

### 3.2 查询：从大到小跳

要跳 k 步，把 k 二进制拆分（如 13 = 8+4+1）。**实战习惯从大到小（高位往低位）跳**：先跳最大的 2^j（j 从 LOG 往下枚举），能跳就跳。

> 为什么不从小的开始？其实两种都对，但"从大到小 + 能跳就跳"不用先做显式的二进制拆分：只要剩余步数 ≥ 2^j 就跳，跳完更新剩余步数，代码更简洁，也不会出现"跳过头"。

### 3.3 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 100005;
const int LOG = 20;          // 2^20 > 1e6，够用；深度更大就开 30+

int up[MAXN][LOG];           // up[x][j] = x 向上跳 2^j 步到达的节点，0 表示不存在

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    cin >> n >> q;
    for (int i = 1; i <= n; i++) cin >> up[i][0];   // 1 级祖先（父亲），0 表示根

    // 预处理：跳 2^j 步 = 先跳 2^(j-1) 步，再跳 2^(j-1) 步
    for (int j = 1; j < LOG; j++)
        for (int i = 1; i <= n; i++)
            up[i][j] = up[up[i][j - 1]][j - 1];     // 第一次跳完到 0（空），再跳还是 0，天然处理越界

    while (q--) {
        int x, k;
        cin >> x >> k;
        for (int j = 0; j < LOG; j++)               // 按二进制位跳（写成 j 从 LOG-1 往下也完全等价）
            if (k >> j & 1) x = up[x][j];           // k 的这一位是 1 → 跳 2^j 步
        cout << x << "\n";
    }
    return 0;
}
```

**复杂度**：预处理 O(n log n)，单次查询 O(log n)。

**坑**：
- `up[i][j] = up[up[i][j-1]][j-1]` 里第一维取的是**上一次跳完的落点**，不是 i 本身。写错成 `up[i][j-1]` 就是原地跳，全错。
- 节点编号从 1 开始，0 留作"不存在"哨兵，跳出去自动是 0，不用特判。

## 四、ST 表 — 静态区间最值（P3865）

### 4.1 定义、边界、递推

给定**静态**序列（后面不改了）和 m 次询问 [l, r] 区间最大值。n, m ≤ 10^5，要求单次询问 O(1)。

定义 `F[i][j]` = **以 i 为左端点、长度 2^j 的区间**的最大值，右端点是 i + 2^j − 1。

- **边界**：`F[i][0] = a[i]`（长度 1 的区间最大值就是它自己）
- **递推**（条件 1）：长度 2^j 的区间从中间折半，是两个长度 2^(j-1) 的区间：

```
F[i][j] = max( F[i][j-1],  F[i + 2^(j-1)][j-1] )
           └──左半段──┘    └────右半段────┘
```

J 只需要处理到 log n：因为区间长度不能超过 n，2^j ≤ n 才有意义。

### 4.2 查询：覆盖法（可重复贡献）

查 [l, r]，区间长度 len = r − l + 1。取 `k = ⌊log₂(len)⌋`（最大的 2^k ≤ len），然后**从 l 放一段 2^k，从 r 往左再放一段 2^k**：

```
[l, l+2^k-1]  和  [r-2^k+1, r]   两段覆盖了整个 [l, r]（中间允许重叠）
```

max 是可重复贡献的，重叠部分多算一遍不影响答案，所以答案 = `max(F[l][k], F[r-2^k+1][k])`，O(1)。

**log 数组预处理**：`lg[i] = lg[i/2] + 1`，O(n) 求出每个长度的 ⌊log₂⌋，查询直接查表，不用每次算对数。

### 4.3 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 100005;
const int LOG = 18;          // 2^17 = 131072 > 1e5，够用

int st[MAXN][LOG];           // st[i][j] = 以 i 为左端点、长度 2^j 的区间最大值
int lg[MAXN];                // lg[i] = floor(log2(i))，查询时直接查表

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        cin >> st[i][0];     // 长度 2^0 = 1 的区间，最大值就是它自己
    }
    // 预处理 log 数组：lg[i] = lg[i/2] + 1（i=2 起）
    for (int i = 2; i <= n; i++) lg[i] = lg[i / 2] + 1;
    // 预处理 st：长度翻倍，j 是 2 的幂次
    for (int j = 1; (1 << j) <= n; j++)
        for (int i = 1; i + (1 << j) - 1 <= n; i++)   // 右端点不越界才合法
            st[i][j] = max(st[i][j - 1], st[i + (1 << (j - 1))][j - 1]);
    while (m--) {
        int l, r;
        cin >> l >> r;
        int k = lg[r - l + 1];                        // 最大的 2^k <= 区间长度
        // 可重复贡献：左右两段长度 2^k 覆盖整个区间，max 重复算没关系
        cout << max(st[l][k], st[r - (1 << k) + 1][k]) << "\n";
    }
    return 0;
}
```

**复杂度**：预处理 O(n log n)，单次查询 O(1)（有 lg 表），空间 O(n log n)。

**坑**：
- 预处理循环 `i + (1<<j) - 1 <= n`：右端点越界的格子不填，查询永远不会用到它们（k 是根据区间长度取的，长度 ≤ n）。
- 查询第二段左端点是 `r - (1<<k) + 1`，不是 `r - (1<<k)`——长度 2^k 的区间，左端点 = 右端点 − 长度 + 1。少写 +1 会整体偏一位。
- **ST 表只能静态**：序列一旦修改，整张表作废。要动态修改就用线段树/树状数组（见 06-数据结构）。

## 五、函数图倍增 — 走 K 步（CF702E）

### 5.1 问题
4
n 个点（编号 0~n−1），每个点**有且仅有一条带权出边**。对每个点 i，问从 i 出发**恰好走 k 条边**，经过的边权和 + 边权最小值。n ≤ 10^5，**k ≤ 10^10**。

每个点只有一条出边 → 整个图是若干棵"基环树"（往里走一定会进环），但不需要知道这个概念也能做。**k 这么大，暴力走必然超时——这正是指向倍增的信号。**

### 5.2 三个倍增数组

和树上 K 级祖先同构，只是"跳"从树上变成了图上的边：

| 数组 | 含义 |
|------|------|
| `go[x][j]` | 从 x 走 **2^j 条边**到达的点 |
| `sum[x][j]` | 从 x 走 2^j 条边经过的**边权和** |
| `mn[x][j]` | 从 x 走 2^j 条边经过的边权**最小值** |

**边界**（j=0，走 1 条边）：`go[x][0] = v[x]`（唯一出边终点），`sum[x][0] = mn[x][0] = w[x]`（就一条边）。

**递推**：先走 2^(j-1) 条边到中间点 mid，再走 2^(j-1) 条边：

```
go[x][j]  = go[ mid ][j-1]
sum[x][j] = sum[x][j-1] + sum[mid][j-1]
mn[x][j]  = min(mn[x][j-1], mn[mid][j-1])
其中 mid = go[x][j-1]
```

**查询**：k 二进制拆分（k = 10^10 → 34 位足够），按位跳，边走边累加 sum 和 min。

> 和 ST 表的区别：这里 sum 是**不可重复贡献**的，所以用"二进制拆分一段段接"（方法 B），不是覆盖法。min 虽然可重复，但跟着 sum 一起走，统一用拆分法最省心。

### 5.3 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 100005;
const int LOG = 40;          // k <= 1e10，2^34 就够；开 40 保险

int go[MAXN][LOG];           // go[x][j] = 从 x 走 2^j 条边到达的点
long long sum[MAXN][LOG];   // sum[x][j] = 从 x 走 2^j 条边经过的边权和
long long mn[MAXN][LOG];    // mn[x][j]  = 从 x 走 2^j 条边经过的边权最小值

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long k;
    cin >> n >> k;
    for (int i = 1; i <= n; i++) cin >> go[i][0];   // 跳 1 条边到的点（读入后统一 +1 转 1-indexed）
    for (int i = 1; i <= n; i++) {
        long long w;
        cin >> w;
        sum[i][0] = w;      // 走 1 条边的边权和
        mn[i][0] = w;       // 走 1 条边的边权最小值
    }
    // 倍增递推：走 2^j 条边 = 先走 2^(j-1) 条边，再走 2^(j-1) 条边
    for (int j = 1; j < LOG; j++)
        for (int i = 1; i <= n; i++) {
            int mid = go[i][j - 1];                  // 前半程终点 = 后半程起点
            go[i][j] = go[mid][j - 1];
            sum[i][j] = sum[i][j - 1] + sum[mid][j - 1];   // 两段和直接加（不重叠，不重复）
            mn[i][j] = min(mn[i][j - 1], mn[mid][j - 1]);
        }
    for (int i = 1; i <= n; i++) {
        long long s = 0, m = LLONG_MAX;
        int cur = i;
        long long kk = k;                            // 复制一份，别改掉全局 k
        for (int j = 0; j < LOG; j++)
            if (kk >> j & 1) {                       // k 的这一位是 1 → 走 2^j 条边
                s += sum[cur][j];
                m = min(m, mn[cur][j]);
                cur = go[cur][j];                    // 跳到下一段的起点
            }
        cout << s << " " << m << "\n";
    }
    return 0;
}
```

**复杂度**：预处理 O(n log k)，每个点查询 O(log k)。

**坑**：
- `mid = go[i][j-1]` 必须先取出来再用：`sum[i][j] = sum[i][j-1] + sum[go[i][j-1]][j-1]` 里第二段的起点是**落点**，不是 i。
- 查询时 `cur` 会变，但 `sum[cur][j]` / `mn[cur][j]` 用的都是**当前落点**的档位——这就是"先跳一段，再从落点继续跳"的接力。
- k 用 long long 读入（10^10 超 int），位运算用 `1LL << j`。

## 六、倍增求 LCA（树上应用，详见 07-图论/04-LCA）

倍增在树上最重要的应用是 LCA（最近公共祖先），**07-图论/04-LCA.md 已有完整讲解和模板**，这里只补充视频里的查询细节：

1. **深度对齐**：把深的那个节点往上跳，跳到和浅的同一深度（"从大到小尝试跳，只要跳完深度还 ≥ 对方就跳"——和 K 级祖先同一套逻辑）；
2. **特判**：对齐后如果两个节点重合，说明其中一个就是 LCA，直接返回；
3. **一起跳**：从大到小枚举 j，**只要 up[u][j] ≠ up[v][j] 就一起跳**（保证不跳过 LCA——跳到 LCA 下面最近的公共位置）；
4. **收尾**：最后再跳一步（up[u][0]）就是 LCA。

> 为什么第 3 步判断"跳上去不是同一个点"才跳？因为 up[u][j] = up[v][j] 时，可能是 LCA 也可能是 LCA 的祖先，没法区分；而**跳上去不同**说明还在 LCA 下方，安全。最终落在 LCA 的两个儿子上，再跳一步必到 LCA。

## 七、思维拓展

### 7.1 前缀最大值和（单调栈 + 跳台阶倍增）

> 问题：给序列 a，多次询问 [L, R]，求 Σ max(a[L..i])（i 从 L 到 R），即**每个前缀的最大值之和**。强制在线（xor 答案加密），n, q ~ 5×10^5。

**先暴力想**：前缀最大值长成**阶梯状**——只要某个位置的值比前面都大，它之后的前缀最大值就都是它。用单调栈求出 `nxt[i]` = i **右边第一个比 a[i] 大的位置**，那么 [i, nxt[i]-1] 这一段每个前缀最大值都等于 a[i]，贡献 = a[i] × (nxt[i] - i)。

**暴力跳**：从 L 出发，沿 nxt 一路跳到 > R 为止，每段贡献 `a[cur] × (min(nxt[cur], R+1) - cur)`。最坏一条递增链（1,2,3,...,n）要跳 O(n) 次——**跳的次数不稳定，这正是倍增要优化的对象**（和数据是否随机无关）。

**倍增化**：跳的路径是固定的（nxt 不随查询变），所以：

- `F[i][j]` = 从 i 连续跳 2^j 次 nxt 到达的位置；
- `G[i][j]` = 这 2^j 跳的**完整段**贡献和（不含最后落点所在的那段）。

查询时从大到小跳，只要 `F[cur][j] ≤ R` 就整段跳并累加 G；最后一段 [cur, R] 的前缀最大值全是 a[cur]，补 `a[cur] × (R - cur + 1)`。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 500005;
const int LOG = 20;

int a[MAXN], nxt[MAXN];      // nxt[i] = i 右边第一个 > a[i] 的位置（单调栈求）
int F[MAXN][LOG];            // F[i][j] = 从 i 连续跳 2^j 次 nxt 到达的位置
long long G[MAXN][LOG];      // G[i][j] = 从 i 跳 2^j 次的完整段贡献和（不含最后落点所在段）
int stk[MAXN];               // 单调栈（存下标）

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    cin >> n >> q;
    for (int i = 1; i <= n; i++) cin >> a[i];

    // 单调栈求右边第一个更大的位置：从右往左扫，栈内从底到顶单调递减
    int top = 0;
    for (int i = n; i >= 1; i--) {
        while (top && a[stk[top]] <= a[i]) top--;  // 弹出 <= a[i] 的，剩下的栈顶就是第一个 > a[i] 的
        nxt[i] = top ? stk[top] : n + 1;           // 右边没有更大的 → 哨兵 n+1
        stk[++top] = i;
    }

    // 倍增预处理
    for (int i = 1; i <= n; i++) {
        F[i][0] = nxt[i];
        G[i][0] = 1LL * a[i] * (nxt[i] - i);       // [i, nxt[i]-1] 这段前缀最大值全是 a[i]
    }
    F[n + 1][0] = n + 1;   // 哨兵：跳到 n+1 后不再前进
    G[n + 1][0] = 0;
    for (int j = 1; j < LOG; j++)
        for (int i = 1; i <= n + 1; i++) {
            F[i][j] = F[F[i][j - 1]][j - 1];
            G[i][j] = G[i][j - 1] + G[F[i][j - 1]][j - 1];
        }

    while (q--) {
        int L, R;
        cin >> L >> R;
        long long ans = 0;
        int cur = L;
        for (int j = LOG - 1; j >= 0; j--) {
            if (F[cur][j] <= R) {                  // 整段跳完还在 R 内（或恰好停在 R）
                ans += G[cur][j];
                cur = F[cur][j];
            }
        }
        // 此时 nxt[cur] > R，[cur, R] 是最后一段，前缀最大值全等于 a[cur]
        ans += 1LL * a[cur] * (R - cur + 1);
        cout << ans << "\n";
    }
    return 0;
}
```

**复杂度**：预处理 O(n log n)，单次查询 O(log n)。

**坑**：
- 单调栈从**右往左**扫，弹出条件 `a[stk[top]] <= a[i]`（要严格大于，等于的弹出）——如果写成 `<`，相等的元素会互相指，跳不出递增链。
- 查询循环 `F[cur][j] <= R` 判断的是**整段跳完的落点**还在 R 内，这样才能完整累加 G；跳过头（落点 > R）就退而求其次跳小档位。
- G 是 long long：a[i] × 段长可能到 5×10^5 × 10^9 = 5×10^14，int 必炸。

### 7.2 倍增优化建图（后期技巧，了解即可）

**问题**：要把 [l1, r1] 区间内所有点和 [l2, r2] 区间内所有点**两两连边**，暴力 O(n²) 条边，时空都炸。

**两阶段优化**：

1. **虚点中转**：加一个中转点，左边区间所有点连向它，它连向右边区间所有点——O(n) 条边替代 O(n²)。但每次连边还是 O(n)，m 次就 O(nm)，不够；
2. **倍增建图**：把 ST 表那套"2^k 区间"搬到图上——给**每个倍增区间**建一个代表点（共 O(n log n) 个点），按"大区间 = 两个小区间合并"的方式连边（每个区间代表点指向它的两个子区间代表点，像一棵树）。之后任何区间 [l, r] 都能拆成 O(log n) 个代表点，和外部点连边只花 O(log n)。

```
区间 [1,3] 连向 X：拆成 [1,2] 和 [3,3] 两个代表点，各连一条边到 X
                 （[1,2] 代表点又向下连到 1、2 两个真实点）
```

总点数 O(n log n)，总边数 O(n log n + m log n)。适合配合最短路/网络流处理"区间连边"类问题。视频里只讲了思路，实战遇到再回来看。

## 附录：OI Wiki 补充

> 本节整理自 OI Wiki《倍增》（oi-wiki.org/basic/binary-lifting/），与视频互为补充。

### A. 严格定义

倍增法（binary lifting），顾名思义就是"成倍增长"。递推时如果状态空间很大，线性递推无法满足时空要求，就**只递推状态空间中 k 的整数次幂位置上的值作为代表**（通常 k=2）；需要其他位置的值时，用"任意整数可以表示成若干个 k 的次幂项的和"这一性质，拿代表值拼出来。所以倍增要求：**递推的问题的状态空间关于 k 的次幂具有可划分性**（即视频说的两个必要条件）。

### B. 复杂度视角

用"砝码称重"的结论：目标范围翻倍，档位只多 1 个。所以倍增类算法的预处理和查询几乎都是 O(log n) 级别，把"重复执行很多次的过程"从 O(n) 压到 O(log n)。

### C. 环上跳 m 次（点权和版，与 CF702E 边权版对照）

> 问题：长度为 n 的环，从第 i 个点跳到第 (i+k) mod n + 1 个点，跳 m 次（m ≤ 10^18），求经过**起点**的点权和（左闭右开：每次只记出发点的权值，终点权值留给下一段）。

和 CF702E 同一模型，但这是**点权**且"左闭右开"处理不重不漏，OI Wiki 给的参考代码：

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 1000005;
const int LOG = 65;          // m <= 1e18，2^60 级别，开 65 保险

int go[LOG][MAXN];           // go[i][j] = 从 i 跳 2^j 步到达的位置
long long sum[LOG][MAXN];   // sum[i][j] = 从 i 跳 2^j 步经过的起点权值和（左闭右开）

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    vector<int> a(n + 1);
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = 1; i <= n; i++) {
        go[0][i] = (i + k) % n + 1;   // 跳 1 步：环上顺移 k 格
        sum[0][i] = a[i];              // 左闭右开：跳 1 步只记起点权值，终点权值留给下一段
    }
    int logn = 31 - __builtin_clz(n);  // 快捷取对数（n 非零才安全）
    for (int i = 1; i <= logn; i++)
        for (int j = 1; j <= n; j++) {
            go[i][j] = go[i - 1][go[i - 1][j]];
            sum[i][j] = sum[i - 1][j] + sum[i - 1][go[i - 1][j]];
        }
    long long m;
    cin >> m;
    int cur = 1;
    long long ans = 0;
    for (int i = 0; m; i++) {
        if (m & (1LL << i)) {          // m 的第 i 位是 1 → 跳 2^i 步
            ans += sum[i][cur];
            cur = go[i][cur];
            m ^= 1LL << i;             // 把这一位清零（也可以 m -= 1LL<<i）
        }
    }
    cout << ans << "\n";
    return 0;
}
```

**复杂度**：预处理 Θ(n log m)，查询 Θ(log m)。

**坑（左闭右开为什么省心）**：跳 13 步 = 先跳 8 再跳 4 再跳 1，如果每次把**落点**也算进去，8 步段的终点恰好是 4 步段的起点，会被记两次。约定"只记起点"后，各段贡献直接相加即可，不重不漏。
