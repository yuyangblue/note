## 1. 核心概念

这两章是整本书概率部分的起点：**用数学语言描述不确定性**（第1章概率），再把不确定性**数字化**（第2章随机变量）。

统计推断的核心套路：数据 → 假设来自某个分布 → 用分布的性质做推断。所以概率语言是统计的地基。Wasserman 本人的 CMU 36-705 课也把这部分作为"快速回顾"（Lec1），说明它不是重点，但**必须会用**。

**本笔记建议阅读方式**：如果你已经学过概率论，可以直接用这份笔记查漏（重点看记号约定和"常见坑"）；如果没学过，配合 B 站 MIT 18.600 中英字幕版第 1-9 讲一起看。

## 2. 概率基础

### 2.1 样本空间与事件

**样本空间** $\Omega$ 是某试验所有可能结果的集合，其中的点 $\omega$ 称为样本点。**事件**是 $\Omega$ 的子集。

| 记号 | 含义 |
|------|------|
| $\Omega$ | 样本空间（所有可能结果） |
| $\omega$ | 样本点 / 试验结果 |
| $A \subset \Omega$ | 事件 |
| $A^c$ | $A$ 的余集（"非 A"） |
| $A \cup B$ | 并（"A 或 B"） |
| $A \cap B$（或 $AB$） | 交（"A 和 B"） |
| $A - B$ | 集合差（$\omega \in A$ 但 $\omega \notin B$） |
| $\varnothing$ | 空集（不可能事件） |
| $I_A(\omega)$ | $A$ 的示性函数（$\omega \in A$ 时取 1，否则取 0） |

**直观理解**：$I_A(\omega)$ 就是"这件事发生没发生"的开关，后面写估计量时会频繁用到。

### 2.2 概率公理

**定义 1.5**：函数 $P$ 对每一事件赋值 $P(A)$，若满足下面 3 条公理则称 $P$ 为**概率分布**（概率测度）：

- **公理 1**：对任意事件 $A$，$P(A) \ge 0$；
- **公理 2**：$P(\Omega) = 1$；
- **公理 3**：若 $A_1, A_2, \cdots$ 两两互斥，则 $P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)$。

**由公理推出的常用性质**：

$$P(\varnothing) = 0, \quad A \subset B \Rightarrow P(A) \le P(B), \quad 0 \le P(A) \le 1$$

$$P(A^c) = 1 - P(A), \quad A \cap B = \varnothing \Rightarrow P(A \cup B) = P(A) + P(B)$$

**引理 1.6（两个事件的加法公式）**：

$$P(A \cup B) = P(A) + P(B) - P(AB)$$

**直观理解**：把 A 和 B 的概率相加时，交集 $AB$ 被加了两次，所以要减去一次。

**定理 1.8（概率的连续性）**：若 $A_n \to A$（单调集合序列的极限），则 $P(A_n) \to P(A)$。

### 2.3 有限样本空间与组合计数

如果 $\Omega$ 有限且每个结果等可能，则：

$$P(A) = \frac{|A|}{|\Omega|}$$

从 $n$ 个元素中选 $k$ 个的组合数：

$$\binom{n}{k} = \frac{n!}{k!(n-k)!}$$

性质：$\binom{n}{0} = \binom{n}{n} = 1$，$\binom{n}{k} = \binom{n}{n-k}$。

### 2.4 独立性（本章关键概念）

**定义 1.9**：若 $P(AB) = P(A)P(B)$，则事件 $A$ 和 $B$ **独立**，记为 $A \amalg B$。

事件集 $\{A_i : i \in I\}$ 独立，当且仅当对 $I$ 的所有子集 $J$ 都有：

$$P\left(\bigcap_{i \in J} A_i\right) = \prod_{i \in J} P(A_i)$$

**引理 1.14**：若 $A$ 与 $B$ 独立，则 $P(A|B) = P(A)$。即**知道 B 发生不会改变 A 的概率**——这是独立性的直觉解释。

**独立性小结（课本原话）**：
1. $A$ 和 $B$ 独立当且仅当 $P(AB) = P(A)P(B)$；
2. 独立有时是**假设**（抛硬币"无记忆"），有时需要**推导验证**；
3. **正概率的互斥事件不可能独立**（因为 $P(AB) = 0$ 而 $P(A)P(B) > 0$）。

**常见坑**：把"互斥"和"独立"混为一谈。互斥是"不可能同时发生"（$AB = \varnothing$），独立是"发生与否互不影响"。两者方向相反。

## 3. 条件概率与贝叶斯理论

### 3.1 条件概率

**定义 1.12**：若 $P(B) > 0$，则 $A$ 在 $B$ 下的**条件概率**为：

$$P(A|B) = \frac{P(AB)}{P(B)}$$

**注意（课本重点强调）**：
- 对固定 $B$，$P(\cdot | B)$ 满足概率公理（是一个概率测度）；
- 但 $P(A|\cdot)$ 一般**不**满足概率公理；
- $P(A|B) \ne P(B|A)$ 一般成立——这个错误叫**检察官谬论**。例：得麻疹时身上有斑点的概率是 1，但身上有斑点时得麻疹的概率远不是 1。

**引理 1.14 推论（乘法公式）**：

$$P(AB) = P(A|B)P(B) = P(B|A)P(A)$$

### 3.2 全概率法则与贝叶斯定理

**定理 1.16（全概率法则）**：令 $A_1, \cdots, A_k$ 是 $\Omega$ 的一个划分，则对任意事件 $B$：

$$P(B) = \sum_{i=1}^{k} P(B|A_i)P(A_i)$$

**定理 1.17（贝叶斯定理）**：若 $P(A_i) > 0$ 且 $P(B) > 0$，则：

$$P(A_i|B) = \frac{P(B|A_i)P(A_i)}{\sum_j P(B|A_j)P(A_j)}$$

**术语**：$P(A_i)$ 称为**先验概率**，$P(A_i|B)$ 称为**后验概率**。贝叶斯定理是第 11 章贝叶斯推断的理论基石。

**常见坑**：做题时先写清楚"谁是划分、谁是要更新的先验"，再套公式，不要硬背分子分母。

## 4. 随机变量与分布函数

### 4.1 随机变量的定义

**定义 2.1**：随机变量是映射 $X: \Omega \to \mathbb{R}$，对每个结果 $\omega$ 赋予实值 $X(\omega)$。

**直观理解**：随机变量把"说不清的试验结果"翻译成"能算的实数"。样本空间常在背后"消失"，但严格地说它始终存在。

### 4.2 CDF（累积分布函数）

**定义 2.5**：$X$ 的累积分布函数为：

$$F_X(x) = P(X \le x)$$

**定理 2.8（CDF 的充要条件）**：$F: \mathbb{R} \to [0,1]$ 是某个概率的 CDF，当且仅当：
1. $F$ 非降：$x_1 < x_2 \Rightarrow F(x_1) \le F(x_2)$；
2. $F$ 规范化：$\lim_{x \to -\infty} F(x) = 0$，$\lim_{x \to +\infty} F(x) = 1$；
3. $F$ 右连续：$F(x) = F(x^+)$ 对所有 $x$ 成立。

**CDF 决定分布**：若 $F_X(x) = F_Y(x)$ 对所有 $x$ 成立，则 $X$ 和 $Y$ **同分布**，记为 $X \stackrel{d}{=} Y$。

**逆 CDF（分位数函数）**：

$$F^{-1}(q) = \inf\{x : F(x) > q\}, \quad q \in [0,1]$$

$F^{-1}(1/4)$ 为第一分位数，$F^{-1}(1/2)$ 为**中位数**，$F^{-1}(3/4)$ 为第三分位数。分位数后面在置信区间和假设检验中反复出现（如 $z_{\alpha/2}$）。

### 4.3 PMF 与 PDF

**离散型**：$X$ 取可数值 $\{x_1, x_2, \cdots\}$，概率函数（PMF）为 $f_X(x) = P(X = x)$，满足 $f_X(x) \ge 0$ 且 $\sum_i f_X(x_i) = 1$，且：

$$F_X(x) = \sum_{x_i \le x} f_X(x_i)$$

**连续型**：存在 $f_X \ge 0$ 且 $\int_{-\infty}^{\infty} f_X(x)dx = 1$，使得：

$$P(a < X < b) = \int_a^b f_X(x)dx$$

$$F_X(x) = \int_{-\infty}^{x} f_X(t)dt, \quad f_X(x) = F_X'(x)$$

**常见坑（连续型，课本用"注意！"标出）**：
- 对连续型随机变量，$P(X = x) = 0$ 对任意 $x$ 成立！**不要把 $f(x)$ 当成 $P(X = x)$**——那只对离散型成立；
- PDF 可以大于 1（甚至无界），只要积分为 1 即可。例：$f(x) = 5, x \in [0, 1/5]$ 是合法 PDF；
- 检查 $f(x) = 1/(1+x)$（$x \ge 0$）不是 PDF，因为 $\int_0^\infty dx/(1+x) = \infty$。

**引理 2.15（用 CDF 算概率）**：
1. $P(X = x) = F(x) - F(x^-)$；
2. $P(x < X \le y) = F(y) - F(x)$；
3. $P(X > x) = 1 - F(x)$。

## 5. 重要的离散分布

| 分布 | 记号 | 概率函数 $f(x)$ | 含义 |
|------|------|----------------|------|
| 伯努利 | $X \sim \text{Bernoulli}(p)$ | $p^x(1-p)^{1-x}$，$x \in \{0,1\}$ | 一次"成功/失败"试验 |
| 二项 | $X \sim \text{Binomial}(n,p)$ | $\binom{n}{x}p^x(1-p)^{n-x}$，$x = 0,\cdots,n$ | $n$ 次独立伯努利试验的成功次数 |
| 几何 | $X \sim \text{Geom}(p)$ | $p(1-p)^{k-1}$，$k = 1,2,\cdots$ | 首次成功所需试验次数 |
| 泊松 | $X \sim \text{Poisson}(\lambda)$ | $e^{-\lambda}\lambda^x/x!$，$x \ge 0$ | 罕见事件的计数（放射衰变、交通事故） |

**可加性（后面常用）**：
- $X_1 \sim \text{Binomial}(n_1,p)$、$X_2 \sim \text{Binomial}(n_2,p)$ 独立 $\Rightarrow X_1 + X_2 \sim \text{Binomial}(n_1+n_2, p)$；
- $X_1 \sim \text{Poisson}(\lambda_1)$、$X_2 \sim \text{Poisson}(\lambda_2)$ 独立 $\Rightarrow X_1 + X_2 \sim \text{Poisson}(\lambda_1 + \lambda_2)$。

**记号约定（课本强调）**：$X \sim F$ 读作"$X$ 服从分布 $F$"。$X$ 是随机变量，$x$ 是具体取值，$n$、$p$ 是参数（固定实数）。**参数 $p$ 通常未知，需要从数据估计——这正是统计推断要做的事。**

## 6. 重要的连续分布

### 6.1 均匀分布

$X \sim \text{Uniform}(a,b)$：

$$f(x) = \begin{cases} \dfrac{1}{b-a}, & x \in [a,b], \\ 0, & \text{其他} \end{cases}, \quad F(x) = \begin{cases} 0, & x < a, \\ \dfrac{x-a}{b-a}, & x \in [a,b], \\ 1, & x > b \end{cases}$$

### 6.2 正态（高斯）分布

$X \sim N(\mu, \sigma^2)$：

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left\{-\frac{1}{2\sigma^2}(x-\mu)^2\right\}, \quad x \in \mathbb{R}$$

- $\mu$ 是分布的中心（均值），$\sigma$ 是散布程度（标准差）；
- $\mu = 0, \sigma = 1$ 时称**标准正态** $Z \sim N(0,1)$，其 PDF 记 $\varphi(z)$，CDF 记 $\Phi(z)$（无闭式表达式，查表）；
- **正态性质**：
  1. $X \sim N(\mu,\sigma^2) \Rightarrow Z = (X-\mu)/\sigma \sim N(0,1)$（标准化）；
  2. $Z \sim N(0,1) \Rightarrow X = \mu + \sigma Z \sim N(\mu,\sigma^2)$；
  3. $X_i \sim N(\mu_i, \sigma_i^2)$ 独立 $\Rightarrow \sum_i a_i X_i \sim N(\sum_i a_i \mu_i, \sum_i a_i^2 \sigma_i^2)$（正态可加性）。

**直观理解**：中心极限定理会让"大量独立随机变量的和"近似正态，这是正态分布在统计中无处不在的根本原因（详见 p03 第5章笔记）。

## 7. 例题

**例 1（贝叶斯公式，例 1.13 疾病检验）**：疾病 $D$ 的检验结果 + / -，概率如下：

| | $D$ | $D^c$ |
|---|---|---|
| + | 0.009 | 0.099 |
| - | 0.001 | 0.891 |

- 检验灵敏度 $P(+|D) = 0.009/0.01 = 0.9$，特异度 $P(-|D^c) = 0.891/0.99 = 0.9$——检验本身很准；
- 但拿到阳性结果后，患病的后验概率只有：

$$P(D|+) = \frac{P(+|D)P(D)}{P(+)} = \frac{0.009}{0.009 + 0.099} \approx 0.08$$

**结论**：检验准确 ≠ 阳性就是患病。因为患病先验 $P(D) = 0.01$ 很低，大量假阳性稀释了后验。**计算，别信直觉。**

**例 2（贝叶斯公式，例 1.19 垃圾邮件）**：邮件分三类 $A_1$=垃圾（$P = 0.7$）、$A_2$=低优先级（0.2）、$A_3$=高优先级（0.1）。含单词"free"的概率分别为 0.9、0.01、0.01。收到含 free 的邮件：

$$P(A_1|B) = \frac{0.9 \times 0.7}{(0.9 \times 0.7) + (0.01 \times 0.2) + (0.01 \times 0.1)} = 0.995$$

**例 3（CDF 计算，例 2.6）**：抛均匀硬币两次，$X$ = 正面次数，则 $P(X=0) = P(X=2) = 1/4$，$P(X=1) = 1/2$，其 CDF：

$$F_X(x) = \begin{cases} 0, & x < 0, \\ 1/4, & 0 \le x < 1, \\ 3/4, & 1 \le x < 2, \\ 1, & x \ge 2 \end{cases}$$

**注意**：$F_X(1.4) = 0.75$（右连续、阶梯跳跃在取值点上）。

**例 4（随机变量构造，课本第2章）**：令 $\Omega = [0,1]$，$P([a,b]) = b-a$，固定 $p$，定义 $X(\omega) = 1$（若 $\omega \le p$）、$0$（否则），则 $X \sim \text{Bernoulli}(p)$。说明任何分布都可以这样从"均匀随机数"构造——随机变量本质是 $\Omega \to \mathbb{R}$ 的映射。

## 8. 本节重点

> **本节重点**：
> - 概率三公理 + 加法公式 $P(A \cup B) = P(A) + P(B) - P(AB)$；互斥 ≠ 独立。
> - 条件概率 $P(A|B) = P(AB)/P(B)$；$P(A|B) \ne P(B|A)$（检察官谬论）；贝叶斯定理用于"由果溯因"。
> - 随机变量是 $\Omega \to \mathbb{R}$ 的映射；CDF 三性质（非降、规范化、右连续）完整刻画分布。
> - 离散看 PMF（$P(X=x)$），连续看 PDF（积分得概率）；连续型 $P(X=x)=0$，PDF 可大于 1。
> - 四类常用离散分布（Bernoulli/Binomial/Geom/Poisson）+ 正态分布的性质（标准化、可加性）要熟记。
> - **常见坑**：把 $f(x)$ 当 $P(X=x)$；用直觉替代贝叶斯计算；混淆参数与随机变量。
