## 1. 核心概念

第 3 章把随机变量"浓缩"成少数几个数字（期望、方差、协方差），第 4 章给出估计误差的**尾部概率上界**。这两章是统计推断的"工具箱"：
- 期望/方差用来刻画估计量的"准"和"稳"（见 p04 第6章 的 MSE 分解）；
- 不等式（Markov/Chebyshev/Hoeffding）用来证明大数定律和"样本均值接近期望"的速度（见 p03 第5章）。

**为什么不等式重要（Wasserman 36-705 Lec2 原话）**：我们的目标形式化一个事实——"独立随机变量的平均集中在它们的期望附近"。渐近观点用大数定律/CLT，非渐近（固定有限样本）观点用集中不等式。**不等式给出的是不依赖 $n \to \infty$ 的有限样本保证。**

## 2. 数学期望与方差

### 2.1 期望的定义

$g(X)$ 的期望定义为：

$$E(g(X)) = \int g(x)\,dF(x) = \begin{cases} \int_{-\infty}^{\infty} g(x)p(x)\,dx, & X \text{ 连续}, \\ \sum_j g(x_j)p(x_j), & X \text{ 离散} \end{cases}$$

### 2.2 期望的性质（必须熟记）

1. **线性**：$E\left(\sum_{j=1}^{k} c_j g_j(X)\right) = \sum_{j=1}^{k} c_j E(g_j(X))$；
2. 若 $X_1, \cdots, X_n$ 独立，则 $E\left(\prod_{i=1}^{n} X_i\right) = \prod_{i=1}^{n} E(X_i)$；
3. 记 $\mu = E(X)$ 为均值。

### 2.3 方差与协方差

**方差**：$\sigma^2 = V(X) = E\left((X - \mu)^2\right)$，且 $V(X) = E(X^2) - \mu^2$。

**性质**：若 $X_1, \cdots, X_n$ 独立，则 $V\left(\sum_{i=1}^{n} a_i X_i\right) = \sum_{i=1}^{n} a_i^2 V(X_i)$。

**协方差与相关系数**：

$$Cov(X,Y) = E\left((X - \mu_X)(Y - \mu_Y)\right) = E(XY) - \mu_X \mu_Y$$

$$\rho(X,Y) = \frac{Cov(X,Y)}{\sigma_X \sigma_Y}, \quad -1 \le \rho(X,Y) \le 1$$

**常见坑**：$V(X+Y) = V(X) + V(Y)$ **只有在 $X,Y$ 不相关（或独立）时才成立**；一般有 $V(X+Y) = V(X) + V(Y) + 2Cov(X,Y)$。

### 2.4 抽样分布（为统计铺垫，习题 3.19）

$X_1, \cdots, X_n$ 独立同分布（iid），均值 $\mu$、方差 $\sigma^2$，记 $\bar{X}_n = \frac{1}{n}\sum_{i=1}^{n} X_i$。$\bar{X}_n$ 是**数据的函数（统计量）**，作为随机变量它有自己的分布——**抽样分布**：

$$E(\bar{X}_n) = \mu, \quad V(\bar{X}_n) = \frac{\sigma^2}{n}$$

**不要混淆**：数据的分布 $f_X$ vs 统计量的分布 $f_{\bar{X}_n}$。$n$ 增大时 $\bar{X}_n$ 的分布越来越集中（方差 $\sigma^2/n \to 0$）——这正是大数定律的雏形。

## 3. 条件期望

### 3.1 定义

给定 $Y = y$ 时 $X$ 的条件期望：

$$E(X|Y=y) = \begin{cases} \sum x f_{X|Y}(x|y), & \text{离散}, \\ \int x f_{X|Y}(x|y)\,dx, & \text{连续} \end{cases}$$

**关键区分（课本反复强调）**：
- $E(X|Y = y)$ 是 $y$ 的**函数**（确定性的）；
- $E(X|Y)$ 是**随机变量**（观察 $Y$ 之前不知道取什么值，当 $Y = y$ 时取 $E(X|Y=y)$）。

### 3.2 两个核心法则

**定理 3.24（迭代期望法则）**：

$$E\left[E(Y|X)\right] = E(Y)$$

**定理 3.27（全方差法则）**：

$$V(Y) = E\left[V(Y|X)\right] + V\left[E(Y|X)\right]$$

**白话解读**：$Y$ 的总方差 = "X 内部平均的波动" + "X 分层之间的波动"（组内平均 + 组间）。后面回归、分层模型、经验贝叶斯都会用到。

**例（例 3.28 分层模型）**：$Q \sim \text{Uniform}(0,1)$，$X|Q=q \sim \text{Binomial}(n,q)$，则：

$$E(X) = E\left[E(X|Q)\right] = E(nQ) = n/2$$

$$V(X) = E\left[V(X|Q)\right] + V\left[E(X|Q)\right] = E[nQ(1-Q)] + V(nQ) = \frac{n}{6} + \frac{n^2}{12}$$

## 4. 矩母函数 MGF

### 4.1 定义

$X$ 的矩母函数（MGF）：

$$\phi_X(t) = E(e^{tX}) = \int e^{tx}\,dF(x)$$

（对 $t=0$ 的某个开区间内的 $t$ 存在。）

### 4.2 矩的生成

对 $t$ 求导再取 $t = 0$：

$$\phi^{(k)}(0) = E(X^k)$$

即 MGF 的 $k$ 阶导数在 0 处给出 $X$ 的 $k$ 阶矩。例：$X \sim \text{Exp}(1)$，$\phi_X(t) = 1/(1-t)$（$t<1$），则 $\phi'(0) = 1 = E(X)$，$\phi''(0) = 2 = E(X^2)$，$V(X) = 2 - 1 = 1$。

### 4.3 MGF 的两个性质（引理 3.31）

1. 若 $Y = aX + b$，则 $\phi_Y(t) = e^{bt}\phi_X(at)$；
2. 若 $X_1, \cdots, X_n$ 独立且 $Y = \sum_i X_i$，则 $\phi_Y(t) = \prod_i \phi_i(t)$。

**定理 3.33（MGF 唯一确定分布）**：若对 0 附近所有 $t$ 有 $\phi_X(t) = \phi_Y(t)$，则 $X \stackrel{d}{=} Y$。

**推论（独立和的可加性，用 MGF 证明）**：
- $X_1 \sim \text{Binomial}(n_1,p)$、$X_2 \sim \text{Binomial}(n_2,p)$ 独立 $\Rightarrow X_1 + X_2 \sim \text{Binomial}(n_1+n_2,p)$（因为 $(pe^t+q)^{n_1}(pe^t+q)^{n_2} = (pe^t+q)^{n_1+n_2}$）；
- $Y_1 \sim \text{Poisson}(\lambda_1)$、$Y_2 \sim \text{Poisson}(\lambda_2)$ 独立 $\Rightarrow Y_1 + Y_2 \sim \text{Poisson}(\lambda_1+\lambda_2)$。

**常见 MGF 表（课本表 3.1）**：

| 分布 | MGF $\phi(t)$ |
|------|---------------|
| $\text{Bernoulli}(p)$ | $pe^t + (1-p)$ |
| $\text{Binomial}(n,p)$ | $(pe^t + (1-p))^n$ |
| $\text{Poisson}(\lambda)$ | $e^{\lambda(e^t - 1)}$ |
| $N(\mu,\sigma)$ | $\exp\{\mu t + \sigma^2 t^2/2\}$ |
| $\text{Gamma}(\alpha,\beta)$ | $\left(\frac{1}{1-\beta t}\right)^\alpha$，$t < 1/\beta$ |

**注意**：$\sigma$ 参数版本 MGF 是 $\exp\{\mu t + \sigma^2 t^2/2\}$（课本表格中 $\alpha^2$ 应为 $2$，以 $N(\mu,\sigma^2)$ 记为 $\exp\{\mu t + \frac{\sigma^2 t^2}{2}\}$ 为准）。

**常见坑**：MGF 可能不存在（如柯西分布）；这时可用特征函数 $E(e^{itX})$（对所有 $t$ 都存在）。

## 5. 概率不等式

以下不等式给出了"随机变量偏离期望/均值"的概率上界，全部来自 36-705 Lec2-3 和课本第 4 章。

### 5.1 Markov 不等式

$X \ge 0$ 且均值有限，则对 $t > 0$：

$$P(X \ge t) \le \frac{E(X)}{t}$$

**证明思路**：$E(X) = \int_0^\infty x p(x)dx \ge \int_t^\infty x p(x)dx \ge t P(X \ge t)$。

**白话**：非负随机变量不会"经常"远超它的均值——超出量越大，概率越小。它很粗糙（只用到一阶矩），但是一切更精细尾部界的基础。

### 5.2 Chebyshev 不等式

$V(X) = \sigma^2$，对任意 $t > 0$：

$$P\left(|X - E(X)| \ge t\sigma\right) \le \frac{1}{t^2}$$

**证明**：直接对 $|X - E(X)|^2$ 用 Markov 不等式。

**关键应用（样本均值）**：$\bar{\mu}_n = \frac{1}{n}\sum_i X_i$ 有均值 $\mu$、方差 $\sigma^2/n$，故：

$$P\left(|\bar{\mu}_n - \mu| \ge \frac{t\sigma}{\sqrt{n}}\right) \le \frac{1}{t^2}$$

**白话**：样本均值偏离真值超过 $t\sigma/\sqrt{n}$ 的概率 $\le 1/t^2$。取 $t = 10$：至少 99% 概率均值在 $10\sigma/\sqrt{n}$ 以内。**已经蕴含弱大数定律**（见 p03 第5章）。

### 5.3 Chernoff 方法（矩母函数法）

若 $X$ 的 MGF 在 0 附近存在，对任意 $t > 0$ 用 Markov 不等式处理 $e^{tX}$：

$$P(X - \mu \ge u) \le \inf_{0 \le t \le b} e^{-t(u+\mu)} E(e^{tX})$$

**例（正态尾界）**：$X \sim N(\mu,\sigma^2)$，$\phi_X(t) = e^{t\mu + t^2\sigma^2/2}$，对 $t$ 求最小化得：

$$P(X - \mu \ge u) \le e^{-u^2/(2\sigma^2)}$$

**白话**：正态随机变量偏离均值 $u$ 个单位的概率随 $u^2$ **指数衰减**——这就是"正态分布尾部很薄"的精确版本。

### 5.4 Hoeffding 不等式（有界随机变量）

**引理（有界变量次高斯）**：$X$ 零均值、取值于 $[a,b]$，则 $E(e^{tX}) \le e^{t^2(b-a)^2/2}$。

**Hoeffding 不等式**：$X_1, \cdots, X_n$ 独立且 $a \le X_i \le b$，则：

$$P\left(\left|\frac{1}{n}\sum_{i=1}^{n} X_i - \mu\right| \ge t\right) \le 2\exp\left\{-\frac{2nt^2}{(b-a)^2}\right\}$$

**白话**：有界随机变量的样本均值偏离期望 $t$ 的概率**指数衰减**——比 Chebyshev 的 $1/t^2$ 快得多。这是非渐近集中不等式中最常用的一条（后面第 6 章置信区间、第 8 章 Bootstrap 理论都会用到）。

**无需同分布（Lec3 注记）**：Hoeffding 只需独立、不需要同分布；若各 $X_i$ 分别为 $\sigma_i$-次高斯，则均值是 $\sigma = \frac{1}{n}\sqrt{\sum_i \sigma_i^2}$-次高斯，尾部界 $P(|\bar{\mu} - E| \ge t) \le e^{-t^2/(2\sigma^2)}$。

### 5.5 其他不等式（课本第 4 章）

- **Cauchy-Schwarz**：$|E(XY)| \le \sqrt{E(X^2)E(Y^2)}$（证明 $|\rho| \le 1$ 的基础）；
- **Jensen**：$g$ 凸 $\Rightarrow E(g(X)) \ge g(E(X))$（$g$ 凹则反向）——36-705 Lec3 用它证明有界变量次高斯，证明手法是"取切线 $L_\mu$，凸函数在切线上方"。

## 6. 例题

**例 1（Markov/Chebyshev/Hoeffding 对比，36-705 Lec2）**：$X_1, \cdots, X_n \sim \text{Uniform}(0,1)$（有界 $[0,1]$），$\bar{X}_n$ 偏离期望 $t$ 的概率：

| 方法 | 上界 |
|------|------|
| Markov（粗，只用到一阶矩） | $O(1/t)$ |
| Chebyshev | $1/(t^2 n \cdot \sigma^2)$ 量级（$\le 1/(nt^2 \cdot 12)$） |
| Hoeffding | $2e^{-2nt^2}$（指数衰减，最优） |

**结论**：同样是"均值偏离 $t$"，Chebyshev 给多项式界，Hoeffding 给指数界。样本量 $n$ 越大，指数界优势越明显。

**例 2（MGF 求矩，例 3.30）**：$X \sim \text{Exp}(1)$：

$$\phi_X(t) = \int_0^\infty e^{tx}e^{-x}dx = \frac{1}{1-t} \quad (t < 1)$$

$$\phi'(0) = 1 = E(X), \quad \phi''(0) = 2 = E(X^2), \quad V(X) = 2 - 1 = 1$$

**例 3（分层模型全方差，例 3.28）**：见第 3.2 节，$V(X) = n/6 + n^2/12$。当 $n$ 很大时，$n^2/12$ 项主导——说明分层间差异（$V(E(X|Q))$）远大于组内波动，这是分层数据的典型特征。

## 7. 本节重点

> **本节重点**：
> - 期望线性、$V(X) = E(X^2) - \mu^2$、$V(\bar{X}_n) = \sigma^2/n$——统计推断的"准稳"指标。
> - 迭代期望 $E(Y) = E[E(Y|X)]$ 与全方差 $V(Y) = E[V(Y|X)] + V[E(Y|X)]$——分层/回归模型的看家工具。
> - MGF：$\phi^{(k)}(0) = E(X^k)$；独立和的 MGF 相乘 → 分布可加性；MGF 唯一确定分布。
> - 不等式链：Markov（一阶矩）→ Chebyshev（二阶矩，$1/t^2$）→ Chernoff（MGF，指数）→ Hoeffding（有界变量，$2e^{-2nt^2/(b-a)^2}$）。
> - Hoeffding 不需要同分布、只需独立；有界性是得到指数界的代价。
> - **常见坑**：$V(X+Y) = V(X)+V(Y)$ 忘掉协方差项；把 $E(X|Y=y)$（函数）和 $E(X|Y)$（随机变量）混用；MGF 不存在时硬用（换特征函数）。
