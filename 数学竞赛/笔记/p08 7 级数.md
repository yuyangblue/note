## 1. 基本概念

| 概念 | 含义 |
|------|------|
| 级数 | **数列的无穷项和**：$\sum\limits_{n=1}^{\infty} u_n = \lim\limits_{n\to\infty} S_n$（前 $n$ 项和取极限） |
| 收敛/发散 | 部分和极限存在为收敛，不存在为发散（级数问题归结为极限问题） |
| 必要条件 | 级数收敛 ⟹ $\lim\limits_{n\to\infty} u_n = 0$（**不可逆！**不能由通项趋于零推收敛） |
| 绝对收敛 | $\sum\lvert u_n\rvert$ 收敛（则去掉绝对值也收敛） |
| 条件收敛 | $\sum u_n$ 收敛但 $\sum\lvert u_n\rvert$ 发散 |

> **反例**：调和级数 $\sum\frac{1}{n}$ 通项趋于零但**必发散**——说明"通项→0"不能作为审敛法，只能判发散（通项不趋于零 ⟹ 发散）。

**条件收敛的典型例子**：交错调和级数 $\sum(-1)^{n-1}\frac{1}{n}$——莱布尼茨审敛法可判定它收敛；但加绝对值后变成调和级数，发散。这就是条件收敛。

## 2. 正项级数的比较审敛法

**（以下四种审敛法均针对正项级数）**

**两句话**：**大收则小收；小散则大散**。
- 找到比 $u_n$ 大的级数 $v_n$ 且 $v_n$ 收敛 ⟹ $u_n$ 收敛；
- 找到比 $u_n$ 小的级数且其发散 ⟹ $u_n$ 发散。
- 方向不能反着用（找到比它大的发散，什么也推不出）。

**四个"比较尺度"（必背）**：

| 尺度 | 形式 | 敛散结论 |
|------|------|----------|
| 等比级数 | $\sum aq^{n}$ | $\lvert q\rvert < 1$ 收敛于 $\dfrac{a}{1-q}$；$\lvert q\rvert \ge 1$ 发散 |
| $P$ 级数 | $\sum\dfrac{1}{n^p}$ | $p > 1$ 收敛；$p \le 1$ 发散（$p=1$ 即调和级数） |
| 交错 $P$ 级数 | $\sum\dfrac{(-1)^{n-1}}{n^p}$ | $p > 1$ **绝对**收敛；$0 < p \le 1$ 收敛但**条件**收敛 |
| 广义 $P$ 级数 | $\sum\dfrac{1}{n(\ln n)^p}$ | "底数"是 $\ln n$：与反常积分 $\int\dfrac{dx}{x(\ln x)^p}$ 同敛散（$\frac{dx}{x} = d\ln x$ 凑微分） |

> **易混淆点**：等比级数是**公比**大于 1 发散；$P$ 级数是**参数**大于 1 收敛——正好相反，别记反。

## 3. 比较审敛法的极限形式与等价无穷小

若 $\lim\limits_{n\to\infty}\dfrac{u_n}{v_n} = L$，则：

| $L$ 的情况 | 结论 |
|------------|------|
| $0 < L < \infty$（非零常数） | $u_n$ 与 $v_n$ **同敛散** |
| $L = 0$（$v_n$ 相对高阶） | $v_n$ 收敛 ⟹ $u_n$ 收敛 |
| $L = \infty$（$u_n$ 相对高阶） | $v_n$ 发散 ⟹ $u_n$ 发散 |

> **最重要的推论**：取 $L = 1$ 即**等价无穷小同敛散**——$\sin\frac{1}{n} \sim \frac{1}{n}$、$\arctan\frac{1}{n} \sim \frac{1}{n}$，对应级数都与调和级数同敛散（发散）。**判敛时先用等价无穷小化简**。

## 4. 比值审敛法与根值审敛法

**比值审敛法（达朗贝尔判别法）**：不需要外来级数，自己算极限

$$\lim_{n\to\infty}\frac{u_{n+1}}{u_n} = \rho:\quad \rho < 1 \text{ 收敛},\quad \rho > 1 \text{ 发散},\quad \rho = 1 \text{ 失效}$$

**根值审敛法（柯西判别法）**：通项开 $n$ 次根再取极限 $\lim\sqrt[n]{u_n} = \rho$，结论同上。

> **选法**：通项含 $n$ 次方（如 $a^n$、$n^n$）时用根值法（开根能抵消高次方）；含阶乘、多项式乘积时用比值法。

## 5. 交错级数：莱布尼茨审敛法

**交错级数**：通项带 $(-1)^{n-1}$（正负交替）。

**莱布尼茨审敛法**：满足两个条件则收敛——① $u_n$（**去掉 $(-1)^n$ 后的部分**）**单调递减**；② $\lim\limits_{n\to\infty} u_n = 0$。

> **易错点**：判断单调性和极限时，**看的是去掉 $(-1)^n$ 之后的 $u_n$**，不能带着正负号看。

## 6. 典型例题：三种审敛法的应用

**例 1（比较审敛法 + 放缩）**：判断 $\sum\dfrac{\sqrt{\ln n}}{n^3}$ 的敛散性。

解：对数比幂函数增长慢，放缩 $\ln n < n$ ⟹ $\sqrt{\ln n} < \sqrt{n}$：

$$\frac{\sqrt{\ln n}}{n^3} < \frac{\sqrt{n}}{n^3} = \frac{1}{n^{5/2}}$$

右边是 $P = \frac{5}{2} > 1$ 的 $P$ 级数，收敛 → **大收则小收**，原级数收敛。

（为什么不用比值/根值法：通项带根号和对数，比值的极限难求；根值法再开根只会更复杂。）

**例 2（比值审敛法）**：判断 $\sum\dfrac{3^n}{n^2}$ 的敛散性。

解：

$$\lim_{n\to\infty}\frac{u_{n+1}}{u_n} = \lim_{n\to\infty}\frac{3^{n+1}/(n+1)^2}{3^n/n^2} = 3\lim_{n\to\infty}\left(\frac{n}{n+1}\right)^2 = 3 > 1$$

**发散**。

**例 3（交错级数 + 有理化拆项）**：判断 $\sum\dfrac{(-1)^{n-1}}{\sqrt{n} + (-1)^{n-1}}$ 的敛散性。

解：

1. 直接对 $u_n = \dfrac{1}{\sqrt{n}+(-1)^{n-1}}$ 用莱布尼茨会失败（$u_n$ 不单调）。分母带根号 → **有理化**（$[(\sqrt{n}+(-1)^{n-1})(\sqrt{n}-(-1)^{n-1})] = n - 1$）：

$$\frac{1}{\sqrt{n}+(-1)^{n-1}} = \frac{\sqrt{n}-(-1)^{n-1}}{n-1} = \frac{(-1)^{n-1}\sqrt{n}}{n-1} - \frac{1}{n-1}$$

2. 前一项是交错级数：函数 $\dfrac{\sqrt{x}}{x-1}$ 求导得 $\dfrac{-(x+1)}{2\sqrt{x}(x-1)^2} < 0$ → 单调递减，且 $\dfrac{\sqrt{n}}{n-1} \to 0$ → **莱布尼茨条件满足，收敛**。
3. 后一项 $\sum\dfrac{1}{n-1}$ 是调和级数 → **发散**。
4. 收敛 $+$ 发散 $=$ **发散**。

## 7. 幂级数与收敛域

**幂级数**：$\sum\limits_{n=0}^{\infty} a_n x^n$（通项是一堆幂函数；$a_n$ 是系数）。

**收敛半径**（类似比值审敛法，对系数作比）：

$$\rho = \lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right|,\qquad R = \frac{1}{\rho}$$

（$\rho = 0$ 时 $R = \infty$；$\rho = \infty$ 时 $R = 0$。）

**收敛区间与收敛域**：对 $\sum a_n(x-x_0)^n$，中心点是 $x_0$（如 $\sum a_n x^n$ 中心是 $0$），收敛区间为 $(x_0 - R,\ x_0 + R)$。**端点 $x = x_0 \pm R$ 要单独判定**（代入后变成数项级数，用数项级数审敛法）——收敛区间加上端点情况才是**收敛域**。

**例 4（真题）**：求 $\sum\limits_{n=1}^{\infty}\dfrac{(-1)^{n-1}}{n(2n-1)}x^{2n}$ 的收敛域。

解：

1. 系数 $a_n = \dfrac{1}{n(2n-1)}$（注意 $x^{2n}$ 的系数取法）：$\rho = \lim\limits_{n\to\infty}\dfrac{n(2n-1)}{(n+1)(2n+1)} = 1$ ⟹ $R = 1$。
2. 收敛区间 $(-1, 1)$，判定端点 $x = \pm 1$：$x^{2n} = 1$，级数变为 $\sum\dfrac{(-1)^{n-1}}{n(2n-1)}$。加绝对值后 $\sim \dfrac{1}{2n^2}$（$P = 2 > 1$ 收敛）→ **绝对收敛**。
3. 收敛域：$[-1, 1]$（闭区间）。

## 8. 幂级数求和函数

**基本出发点——等比级数**（注意首项随下标变化）：

$$\sum_{n=0}^{\infty}x^n = \frac{1}{1-x}\quad(|x|<1),\qquad \sum_{n=1}^{\infty}x^n = \frac{x}{1-x}\quad(|x|<1)$$

> **易错点**："一减公比分之首项"——**首项取决于 $\Sigma$ 下标从几开始**（$n=0$ 首项是 $1$，$n=1$ 首项是 $x$）。

**两个加工方向**：
- **求导**：$n$ 和 $x^{n-1}$ 相乘的级数由等比级数求导得来（如 $\sum nx^{n-1} = \dfrac{1}{(1-x)^2}$）；
- **积分**：除法形式（如 $\dfrac{x^n}{n+1}$）由等比级数积分得来。

**操作原则**：遇到**乘积**用"**先积后导**"（积分把 $n$ 降到 $x^n$ 变成等比级数，再求导还原）；遇到**除法**用"**先导后积**"（求导消掉分母变成等比级数，再积分还原）。**求完和函数必须带收敛域**。

**例 5（先导后积）**：求 $S(x) = \sum\limits_{n=0}^{\infty}\dfrac{(-1)^n}{2n+1}x^{2n+1}$ 的和函数。

解：

$$S'(x) = \sum_{n=0}^{\infty}(-1)^n x^{2n} = \sum_{n=0}^{\infty}(-x^2)^n = \frac{1}{1+x^2}\quad(\text{等比级数})$$

$$S(x) = S(0) + \int_0^x\frac{dt}{1+t^2} = \arctan x$$

**例 6（先积后导）**：证明 $\sum\limits_{n=1}^{\infty} n x^{n-1} = \dfrac{1}{(1-x)^2}$。

解：先积分（交换积分与求和）：

$$\int_0^x\sum_{n=1}^{\infty}n t^{n-1}dt = \sum_{n=1}^{\infty}x^n = \frac{x}{1-x}\quad(n \text{ 从 1 起，首项是 } x)$$

再对和函数求导还原：$\left(\dfrac{x}{1-x}\right)' = \dfrac{1}{(1-x)^2}$ ✓

## 9. 真题：数项级数求和（转幂级数）

**真题 7**：求 $\pi\sum\limits_{n=1}^{\infty}\dfrac{n^2}{2^n}$ 的和。

解：

1. 数项级数直接求和很困难 → **变形为幂级数在一点取值**：$\sum n^2 x^n$ 在 $x = \frac{1}{2}$ 处。
2. 求 $\sum n^2 x^{n-1}$ 的和函数：提 $x$ 后先积分两次还原：

$$\sum_{n=1}^{\infty}n^2 x^{n-1}\;\overset{\int}{=}\;\sum_{n=1}^{\infty}n x^n = x\sum_{n=1}^{\infty}n x^{n-1} = \frac{x}{(1-x)^2}$$

3. 求导还原：$\sum n^2 x^{n-1} = \left(\dfrac{x}{(1-x)^2}\right)' = \dfrac{1+x}{(1-x)^3}$，故 $\sum n^2 x^n = \dfrac{x(1+x)}{(1-x)^3}$。
4. 代入 $x = \dfrac{1}{2}$：

$$\sum_{n=1}^{\infty}\frac{n^2}{2^n} = \frac{\frac{1}{2}\cdot\frac{3}{2}}{\left(\frac{1}{2}\right)^3} = 6 \;\Longrightarrow\; \text{原式} = \pi \times 6 = \boxed{6\pi}$$

> **套路**：数项级数求和 ⟹ 把 $\frac{1}{2^n}$ 换成 $x^n$ 构造幂级数，求出和函数后代入 $x = \frac{1}{2}$。

## 10. 幂级数展开（泰勒级数）

**幂级数展开就是求和的逆过程**（也叫泰勒级数/泰勒展开），本质是**背模板 + 转化**：

| 常用展开（收敛域内） |
|----------------------|
| $\dfrac{1}{1-x} = \sum\limits_{n=0}^{\infty}x^n$，$\lvert x\rvert<1$ |
| $\ln(1+x) = \sum\limits_{n=1}^{\infty}\dfrac{(-1)^{n-1}}{n}x^n$；$\ln(1-x) = -\sum\limits_{n=1}^{\infty}\dfrac{x^n}{n}$ |
| $\arctan x = \sum\limits_{n=0}^{\infty}\dfrac{(-1)^n}{2n+1}x^{2n+1}$ |
| $e^x = \sum\limits_{n=0}^{\infty}\dfrac{x^n}{n!}$ |

**两种转化手法**：
- **拆分**：利用 $\ln$ 性质把 $\ln(1+x)(1-2x) = \ln(1+x) + \ln(1-2x)$ 拆成两个已知展开；
- **同乘**：缺项时乘个因子配成熟悉形式（如乘 $(1-x)$ 凑成立方差公式），拆开逐项展开。

## 11. 真题：在 $x=2$ 处展开并求收敛域

**真题 8（去年真题）**：将 $f(x) = \dfrac{1}{(x-1)(x+3)}$ 在 $x = 2$ 处展开成泰勒级数，并求收敛域。

解：

1. **拆分**：$\dfrac{1}{(x-1)(x+3)} = \dfrac{1}{4}\left(\dfrac{1}{x-1} - \dfrac{1}{x+3}\right)$。
2. **凑 $x-2$**（目标明确，把分母凑成 $1 \pm$ 公比的形式）：

$$\frac{1}{x-1} = \frac{1}{1+(x-2)} = \sum_{n=0}^{\infty}(-1)^n(x-2)^n$$

$$\frac{1}{x+3} = \frac{1}{5+(x-2)} = \frac{1}{5}\cdot\frac{1}{1+\frac{x-2}{5}} = \frac{1}{5}\sum_{n=0}^{\infty}(-1)^n\left(\frac{x-2}{5}\right)^n$$

3. 合并：

$$f(x) = \frac{1}{4}\sum_{n=0}^{\infty}(-1)^n\left(1 - \frac{1}{5^{n+1}}\right)(x-2)^n$$

4. **收敛域**：两个等比级数都收敛需 $\|x-2\| < 1$（前一个更严），区间 $(1, 3)$；再判定端点：
   - $x = 1$：通项 $\frac{1}{4}\left(1 - \frac{1}{5^{n+1}}\right) \to \frac{1}{4} \ne 0$ → 发散（不满足必要条件）；
   - $x = 3$：交错级数但通项不趋于零 → 不满足莱布尼茨 → 发散。
5. 收敛域：$(1, 3)$（**开区间，端点取不到**）。

> **要点**：在非零处展开，就是得到 $(x-2)^n$ 的幂级数——同样的拆分/凑等比思路；端点必须单独判。

| 通项含 $\sin\frac{1}{n}$、$\arctan\frac{1}{n}$、$1-\cos\frac{1}{n}$ | 等价无穷小 | 换成 $\frac{1}{n}$、$\frac{1}{n}$、$\frac{1}{2n^2}$ 再判 |

### 12.2 带对数的比较尺度（补齐 §2 的表）

| 级数 | 结论 | 记忆 |
| --- | --- | --- |
| $\sum\dfrac{1}{n^p}$ | $p>1$ 收敛，$p\le1$ 发散 | 幂次说了算 |
| $\sum\dfrac{1}{n(\ln n)^\beta}$ | $\beta>1$ 收敛，$\beta\le1$ 发散 | 对数也"一次方"时，$\beta$ 说了算 |
| $\sum\dfrac{1}{n^p(\ln n)^\beta}$ | $p>1$ 时**对任意 $\beta$** 收敛 | 幂次比对数强，$p>1$ 一票通过 |

> **为什么**：$\ln n$ 增长比 $n^{\varepsilon}$ 慢，所以 $p>1$ 时可放缩成 $\dfrac{1}{n^{(p+1)/2}}$（仍是 $P$ 级数且指数 $>1$），对数因子被彻底吸收。第三行正是用 $\dfrac{1/(n^p\ln^\beta n)}{1/n^p}=\dfrac{1}{\ln^\beta n}\to0$ 配合极限形式比较法得到的（比值趋于 $0$，分母收敛则分子收敛）。

### 12.3 一个条件，两个相反的结论

**例题 12-1**：设 $f$ 在 $x=0$ 的某邻域内有连续导数，$f(0)=0$，且 $\lim\limits_{x\to0}\dfrac{f(x)}{x}=A>0$。讨论 $\sum\limits_{n=1}^{\infty}f\left(\dfrac{1}{n}\right)$ 与 $\sum\limits_{n=1}^{\infty}(-1)^{n-1}f\left(\dfrac{1}{n}\right)$ 的敛散性。

解：

1. **正项级数看比值**：取 $x=\dfrac{1}{n}\to0$，则

$$\frac{f(1/n)}{1/n}=\frac{f(x)}{x}\to A>0$$

由比较审敛法的极限形式（极限为非零常数 ⟹ 同敛散），$\sum f\left(\dfrac{1}{n}\right)$ 与调和级数 $\sum\dfrac{1}{n}$ 同敛散，故**发散**。
2. **交错级数查莱布尼茨两个条件**。① 趋于零：$f\left(\dfrac{1}{n}\right)=\dfrac{1}{n}\cdot\dfrac{f(1/n)}{1/n}\to0\cdot A=0$ ✓。
3. ② 单调递减：由条件 $\lim\limits_{x\to0}\dfrac{f(x)-f(0)}{x-0}=f'(0)=A>0$，再由 $f'$ 连续与**保号性**，存在 $\delta>0$ 使 $f'(x)>\dfrac{A}{2}>0$（$\lvert x\rvert<\delta$），即 $f$ 在 $(-\delta,\delta)$ 上严格递增。
4. 而 $\dfrac{1}{n}$ 严格递减，故 $f\left(\dfrac{1}{n}\right)$ 严格递减（函数增、自变量减，复合后减）。两个条件齐备，由莱布尼茨判别法**收敛**。
5. 又 $\sum\left\lvert(-1)^{n-1}f\left(\dfrac{1}{n}\right)\right\rvert=\sum f\left(\dfrac{1}{n}\right)$ 发散，故为**条件收敛**。

**答案 $\sum f\left(\dfrac{1}{n}\right)$ 发散；$\sum(-1)^{n-1}f\left(\dfrac{1}{n}\right)$ 条件收敛**。

> **要点**：这道题把"比较法"和"莱布尼茨"缝在一起——**同一个 $f(1/n)$，加不加 $(-1)^{n-1}$ 结论相反**。判断单调性时不必求导算 $f(1/n)$ 的差，只需"$f$ 增、$1/n$ 减 ⟹ 复合后减"。
> **易错点**：条件只说 $f$ 在 $0$ 附近有连续导数，所以要靠保号性把"$f'(0)>0$"升级成"邻域内 $f'>0$"；只写 $f'(0)>0$ 不能直接推出单调。

### 12.4 端点敛散反推半径，再平移到新中心

**例题 12-2**：已知幂级数 $\sum\limits_{n=0}^{\infty}a_n(x+2)^n$ 在 $x=0$ 处收敛、在 $x=-4$ 处发散，求 $\sum\limits_{n=0}^{\infty}a_n(x-3)^n$ 的收敛域。

解：

1. 令 $t=x+2$，第一个级数就是 $\sum a_nt^n$，中心 $t=0$、半径记为 $R$。
2. $x=0$ 对应 $t=2$，收敛 ⟹ 收敛点不会落在收敛区间外 ⟹ $R\ge2$。
3. $x=-4$ 对应 $t=-2$，发散 ⟹ 发散点不会落在收敛区间内 ⟹ $R\le2$。
4. 夹逼得 $R=2$。结合端点信息：$t=2$ 收敛（右端点取到）、$t=-2$ 发散（左端点取不到），故第一个级数关于 $x$ 的收敛域为 $[-4,\,0)$。
5. 第二个级数 $a_n$ 完全没变，半径仍是 $R=2$，只是中心挪到 $x=3$：

$$\lvert x-3\rvert<2\ \Longrightarrow\ 1<x<5$$

6. 端点搬到新级数：$x=5$ 时 $x-3=2$，与 $t=2$ 是同一个数项级数，**收敛**；$x=1$ 时 $x-3=-2$，对应 $t=-2$，**发散**。

**答案 收敛域为 $(1,\,5]$**。

> **要点**：三个概念分清——**收敛半径**是一个数 $R$（中心到端点的距离），**收敛区间**是开区间 $(x_0-R,x_0+R)$，**收敛域**才是加上端点判定的最终答案。
> **易错点**：这里的"端点敛散"能直接搬给新级数，是因为系数 $a_n$ 一个没动；若题目换成了 $\sum a_n^2(x-3)^n$ 之类，端点结论就不能照搬，必须重新代入判断。

### 12.5 分母有两层，就求两次导

**例题 12-3**：求 $S(x)=\sum\limits_{n=1}^{\infty}\dfrac{(-1)^n}{n(2n+1)}x^{2n+1}$ 的和函数及收敛域。

解：

1. 系数绝对值 $\sim\dfrac{1}{2n^2}$ ⟹ $R=1$；端点 $x=\pm1$ 时级数为 $\sum\dfrac{(-1)^n(\pm1)^{2n+1}}{n(2n+1)}$，加绝对值 $\sim\dfrac{1}{2n^2}$（$p=2$）收敛 ⟹ 收敛域 $[-1,1]$。
2. 分母有 $2n+1$，先求导把它削掉：

$$S'(x)=\sum_{n=1}^{\infty}\frac{(-1)^n}{n}x^{2n},\qquad S'(0)=0$$

3. 分母还剩 $n$，再求一次导：

$$S''(x)=\sum_{n=1}^{\infty}\frac{(-1)^n\cdot2n}{n}x^{2n-1}=2\sum_{n=1}^{\infty}(-1)^n x^{2n-1}=-\frac{2x}{1+x^2}$$

（最后一步：$\sum\limits_{n\ge1}(-1)^nx^{2n-1}=-x\sum\limits_{n\ge1}(-x^2)^{n-1}=-\dfrac{x}{1+x^2}$，等比级数。）
4. **积回去一次**（用 $S'(0)=0$ 定常数）：

$$S'(x)=\int_0^x\frac{-2t}{1+t^2}\,dt=-\ln(1+x^2)$$

5. **再积一次**（用 $S(0)=0$ 定常数，分部积分）：

$$S(x)=-\int_0^x\ln(1+t^2)\,dt=-x\ln(1+x^2)+2\int_0^x\frac{t^2}{1+t^2}\,dt=-x\ln(1+x^2)+2x-2\arctan x$$

（$\dfrac{t^2}{1+t^2}=1-\dfrac{1}{1+t^2}$，积出来是 $x-\arctan x$。）

**答案 $S(x)=2x-2\arctan x-x\ln(1+x^2)$，$x\in[-1,1]$**。

> **要点**：**求了几次导，就要积几次回去**，且每次积分都写成 $\int_0^x$ 的形式（自动带上 $S(0)$、$S'(0)$，不会漏常数）。看到分母是 $n$ 与 $2n+1$ 的乘积，就知道要导两次。
> **易错点**：最后必须写收敛域；若只在 $(-1,1)$ 上求，端点 $x=\pm1$ 处级数其实收敛，答案会不完整。

### 12.6 先求导成等比，再积回去

**例题 12-4**：将 $f(x)=\arctan x$ 展开成 $x$ 的幂级数，并求收敛域。

解：

1. $\arctan x$ 本身不好展，但**求导后是有理函数**：

$$f'(x)=\frac{1}{1+x^2}=\sum_{n=0}^{\infty}(-x^2)^n=\sum_{n=0}^{\infty}(-1)^nx^{2n}\qquad(\lvert x\rvert<1)$$

2. 逐项积分（$f(0)=0$）：

$$\arctan x=\int_0^x\sum_{n=0}^{\infty}(-1)^nt^{2n}dt=\sum_{n=0}^{\infty}\frac{(-1)^n}{2n+1}x^{2n+1}$$

3. **端点回到原级数单独判**：$x=1$ 时是 $\sum\dfrac{(-1)^n}{2n+1}$，通项单调趋于 $0$，莱布尼茨 ⟹ 收敛（其和为 $\frac{\pi}{4}$）；$x=-1$ 同理收敛。
4. 注意第 1 步那个级数在 $x=\pm1$ 处通项不趋于 $0$（发散），**积分改善了端点收敛性**，不能拿求导后的结论代替原级数。

**答案 $\arctan x=\sum\limits_{n=0}^{\infty}\dfrac{(-1)^n}{2n+1}x^{2n+1}$，$x\in[-1,1]$**。

> **要点**：这条流水线适用于一切"求导后变有理函数"的函数——$\arctan x$、$\arcsin x$、$\ln(1+x)$、$\ln(1+x^2)$ 都是。同法可得
> $\dfrac{1}{2}\ln(1+x^2)=\sum\limits_{n=1}^{\infty}\dfrac{(-1)^{n-1}}{2n}x^{2n}$，两式相加即可处理 $\arctan x+\dfrac{1}{2}\ln(1+x^2)$ 这类组合。
> **易错点**：展开题**漏写收敛域等于没做完**；端点处"求导后发散"绝不等于"原级数发散"。

### 12.7 傅立叶系数：只求 $a_n$

**例题 12-5**：设 $f(x)$ 是以 $2$ 为周期的函数，在 $[0,2)$ 上 $f(x)=\begin{cases}x,&0\le x<1\\0,&1\le x<2\end{cases}$，求其傅立叶级数中的 $a_n$。

解：

1. 周期 $T=2$ ⟹ 半周期 $L=\dfrac{T}{2}=1$，公式为

$$a_n=\frac{1}{L}\int_{-L}^{L}f(x)\cos\frac{n\pi x}{L}\,dx=\int_{-1}^{1}f(x)\cos(n\pi x)\,dx$$

2. **平移区间**：把 $[-1,0)$ 左移一个周期（$x\mapsto x+2\in[1,2)$）得 $f(x)=f(x+2)=0$；$[0,1)$ 上本就是 $f(x)=x$。于是在 $[-1,1]$ 上只剩一段非零：$f(x)=0\ (-1\le x<0)$，$f(x)=x\ (0\le x\le1)$。
3. 只有 $[0,1]$ 一段有贡献，分部积分（取 $u=x$、$dv=\cos(n\pi x)dx$）：

$$a_n=\int_0^1x\cos(n\pi x)\,dx=\left[\frac{x\sin n\pi x}{n\pi}\right]_0^1+\left[\frac{\cos n\pi x}{n^2\pi^2}\right]_0^1=\frac{(-1)^n-1}{n^2\pi^2}$$

（第一项在 $0$、$1$ 处都为 $0$，只剩第二项。）
4. 分奇偶看：$n$ 为偶数时 $a_n=0$；$n$ 为奇数时 $a_n=-\dfrac{2}{n^2\pi^2}$。

**答案 $a_n=\dfrac{(-1)^n-1}{n^2\pi^2}$（$n\ge1$），即 $a_{2k}=0$、$a_{2k-1}=-\dfrac{2}{(2k-1)^2\pi^2}$**。

> **要点**：傅立叶级数写成 $\dfrac{a_0}{2}+\sum\left(a_n\cos\dfrac{n\pi x}{L}+b_n\sin\dfrac{n\pi x}{L}\right)$——**常数项是 $\frac{a_0}{2}$，不是 $a_0$**。若题目问"$a_0$ 等于多少"，答 $\frac{1}{L}\int_{-L}^{L}f\,dx$（本题为 $\frac{1}{2}$），别自作主张乘 $\frac{1}{2}$。
> **易错点**：$L$ 是**半周期**（$T=2$ 时 $L=1$），公式里的系数 $\frac{1}{L}$ 与 $\cos\frac{n\pi x}{L}$ 一起用，别把 $L$ 当周期代成 $2$。

## 13. 本节重点

> **本节重点**：
> - 要点 1：级数 $=$ 部分和极限；**收敛 ⟹ 通项→0**（只可判发散，不可推收敛）；绝对收敛 ⟹ 收敛，条件收敛 = 收敛但加绝对值发散。
> - 要点 2：正项级数四法——**比较审敛法**（大收小收/小散大散，尺度：等比 $|q|<1$、$P$ 级数 $p>1$、交错 $P$、广义 $P$）；**极限形式**（同敛散；$L=1$ 即等价无穷小，$\sin\frac{1}{n} \sim \frac{1}{n}$ 判发散）；**比值法**（$\rho<1$ 收敛）；**根值法**（通项含 $n$ 次方时用）。
> - 要点 3：交错级数用**莱布尼茨**——$u_n$（去掉 $(-1)^n$）单调递减且趋于零；带根号的交错级数先**有理化拆项**。
> - 要点 4：幂级数收敛半径 $R = 1/\rho$（系数之比取倒）；收敛域 $=$ 区间 $+$ **端点单独判定**（端点变数项级数）。
> - 要点 5：求和函数——**乘积先积后导、除法先导后积**，一切回到等比级数 $\frac{1}{1-x}$（注意首项随下标）；求完带收敛域。
> - 要点 6：数项级数求和 = 构造幂级数取点；幂级数展开 = **背模板 + 拆分/同乘转化**，展开带收敛域、端点单独判。
> - 要点 7：**带对数的尺度**——$\sum\dfrac{1}{n(\ln n)^\beta}$ 在 $\beta>1$ 收敛、$\beta\le1$ 发散；$\sum\dfrac{1}{n^p(\ln n)^\beta}$ 只要 $p>1$ **对任意 $\beta$ 收敛**（幂次压倒对数，可用极限形式比较法证）。
> - 要点 8：**一个条件两个结论**——$f(0)=0$、$f'(0)=A>0$ 时，$\sum f\left(\frac{1}{n}\right)$ 与 $\sum\frac1n$ 同敛散（发散），而 $\sum(-1)^{n-1}f\left(\frac{1}{n}\right)$ 由莱布尼茨收敛（条件收敛）。单调性靠"$f$ 增 + $\frac1n$ 减"复合得到。
> - 要点 9：**端点敛散反推半径**——收敛点给出 $R\ge\lvert t_0\rvert$，发散点给出 $R\le\lvert t_0\rvert$，夹出 $R$；再按"中心平移、端点结论照搬（系数不变才可搬）"写出新收敛域。
> - 要点 10：**和函数求两次导**——分母是 $n$ 与 $2n+1$ 的乘积就导两次；积分一律写成 $\int_0^x$，用 $S(0)$、$S'(0)$ 定常数，求完标收敛域。
> - 要点 11：**展开流水线**——求导成有理函数 → 写成等比级数 → 逐项积分 → **端点回原级数单独判**（积分会改善端点收敛性，$\arctan x$ 在 $x=\pm1$ 收敛就是例子）。
> - 要点 12：**傅立叶系数** $a_n=\frac{1}{L}\int_{-L}^{L}f\cos\frac{n\pi x}{L}dx$，$L$ 是半周期；常数项是 $\frac{a_0}{2}$，$a_0$ 本身不带 $\frac12$。
> - **常见坑**：用"通项→0"判收敛（错误！）；等比与 $P$ 级数结论记反；莱布尼茨带着 $(-1)^n$ 看单调性；$\sum_{n=0}^\infty x^n$ 与 $\sum_{n=1}^\infty x^n$ 的首项混淆（$1$ vs $x$）；求收敛域漏判端点。
> - **补充坑**：$L$ 误当周期（它只是半周期）；$a_0$ 与 $\frac{a_0}{2}$ 混淆；端点处用"求导后发散"判原级数发散；反推半径时只用一个端点就断言 $R$；和函数求完不写收敛域。
