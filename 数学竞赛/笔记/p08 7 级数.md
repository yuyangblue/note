## 1. 基本概念

| 概念 | 含义 |
|------|------|
| 级数 | **数列的无穷项和**：$\sum\limits_{n=1}^{\infty} u_n = \lim\limits_{n\to\infty} S_n$（前 $n$ 项和取极限） |
| 收敛/发散 | 部分和极限存在为收敛，不存在为发散（级数问题归结为极限问题） |
| 必要条件 | 级数收敛 ⟹ $\lim\limits_{n\to\infty} u_n = 0$（**不可逆！**不能由通项趋于零推收敛） |
| 绝对收敛 | $\sum\lvert u_n\rvert$ 收敛（则去掉绝对值也收敛） |
| 条件收敛 | $\sum u_n$ 收敛但 $\sum\lvert u_n\rvert$ 发散 |

> **反例**：调和级数 $\sum\frac{1}{n}$ 通项趋于零但**必发散**——说明"通项→0"不能作为审敛法，只能判发散（通项不趋于零 ⟹ 发散）。

**条件收敛的典型例子**：交错调和级数 $\sum(-1)^{n-1}\frac{1}{n}$——莱布尼茨审敛法可判定它收敛；但加绝对值后变成调和级数，发散。这就是条件收敛。

## 2. 正项级数的比较审敛法

**（以下四种审敛法均针对正项级数）**

**两句话**：**大收则小收；小散则大散**。
- 找到比 $u_n$ 大的级数 $v_n$ 且 $v_n$ 收敛 ⟹ $u_n$ 收敛；
- 找到比 $u_n$ 小的级数且其发散 ⟹ $u_n$ 发散。
- 方向不能反着用（找到比它大的发散，什么也推不出）。

**四个"比较尺度"（必背）**：

| 尺度 | 形式 | 敛散结论 |
|------|------|----------|
| 等比级数 | $\sum aq^{n}$ | $\lvert q\rvert < 1$ 收敛于 $\dfrac{a}{1-q}$；$\lvert q\rvert \ge 1$ 发散 |
| $P$ 级数 | $\sum\dfrac{1}{n^p}$ | $p > 1$ 收敛；$p \le 1$ 发散（$p=1$ 即调和级数） |
| 交错 $P$ 级数 | $\sum\dfrac{(-1)^{n-1}}{n^p}$ | $p > 1$ **绝对**收敛；$0 < p \le 1$ 收敛但**条件**收敛 |
| 广义 $P$ 级数 | $\sum\dfrac{1}{n(\ln n)^p}$ | "底数"是 $\ln n$：与反常积分 $\int\dfrac{dx}{x(\ln x)^p}$ 同敛散（$\frac{dx}{x} = d\ln x$ 凑微分） |

> **易混淆点**：等比级数是**公比**大于 1 发散；$P$ 级数是**参数**大于 1 收敛——正好相反，别记反。

## 3. 比较审敛法的极限形式与等价无穷小

若 $\lim\limits_{n\to\infty}\dfrac{u_n}{v_n} = L$，则：

| $L$ 的情况 | 结论 |
|------------|------|
| $0 < L < \infty$（非零常数） | $u_n$ 与 $v_n$ **同敛散** |
| $L = 0$（$v_n$ 相对高阶） | $v_n$ 收敛 ⟹ $u_n$ 收敛 |
| $L = \infty$（$u_n$ 相对高阶） | $v_n$ 发散 ⟹ $u_n$ 发散 |

> **最重要的推论**：取 $L = 1$ 即**等价无穷小同敛散**——$\sin\frac{1}{n} \sim \frac{1}{n}$、$\arctan\frac{1}{n} \sim \frac{1}{n}$，对应级数都与调和级数同敛散（发散）。**判敛时先用等价无穷小化简**。

## 4. 比值审敛法与根值审敛法

**比值审敛法（达朗贝尔判别法）**：不需要外来级数，自己算极限

$$\lim_{n\to\infty}\frac{u_{n+1}}{u_n} = \rho:\quad \rho < 1 \text{ 收敛},\quad \rho > 1 \text{ 发散},\quad \rho = 1 \text{ 失效}$$

**根值审敛法（柯西判别法）**：通项开 $n$ 次根再取极限 $\lim\sqrt[n]{u_n} = \rho$，结论同上。

> **选法**：通项含 $n$ 次方（如 $a^n$、$n^n$）时用根值法（开根能抵消高次方）；含阶乘、多项式乘积时用比值法。

## 5. 交错级数：莱布尼茨审敛法

**交错级数**：通项带 $(-1)^{n-1}$（正负交替）。

**莱布尼茨审敛法**：满足两个条件则收敛——① $u_n$（**去掉 $(-1)^n$ 后的部分**）**单调递减**；② $\lim\limits_{n\to\infty} u_n = 0$。

> **易错点**：判断单调性和极限时，**看的是去掉 $(-1)^n$ 之后的 $u_n$**，不能带着正负号看。

## 6. 典型例题：三种审敛法的应用

**例 1（比较审敛法 + 放缩）**：判断 $\sum\dfrac{\sqrt{\ln n}}{n^3}$ 的敛散性。

解：对数比幂函数增长慢，放缩 $\ln n < n$ ⟹ $\sqrt{\ln n} < \sqrt{n}$：

$$\frac{\sqrt{\ln n}}{n^3} < \frac{\sqrt{n}}{n^3} = \frac{1}{n^{5/2}}$$

右边是 $P = \frac{5}{2} > 1$ 的 $P$ 级数，收敛 → **大收则小收**，原级数收敛。

（为什么不用比值/根值法：通项带根号和对数，比值的极限难求；根值法再开根只会更复杂。）

**例 2（比值审敛法）**：判断 $\sum\dfrac{3^n}{n^2}$ 的敛散性。

解：

$$\lim_{n\to\infty}\frac{u_{n+1}}{u_n} = \lim_{n\to\infty}\frac{3^{n+1}/(n+1)^2}{3^n/n^2} = 3\lim_{n\to\infty}\left(\frac{n}{n+1}\right)^2 = 3 > 1$$

**发散**。

**例 3（交错级数 + 有理化拆项）**：判断 $\sum\dfrac{(-1)^{n-1}}{\sqrt{n} + (-1)^{n-1}}$ 的敛散性。

解：

1. 直接对 $u_n = \dfrac{1}{\sqrt{n}+(-1)^{n-1}}$ 用莱布尼茨会失败（$u_n$ 不单调）。分母带根号 → **有理化**（$[(\sqrt{n}+(-1)^{n-1})(\sqrt{n}-(-1)^{n-1})] = n - 1$）：

$$\frac{1}{\sqrt{n}+(-1)^{n-1}} = \frac{\sqrt{n}-(-1)^{n-1}}{n-1} = \frac{(-1)^{n-1}\sqrt{n}}{n-1} - \frac{1}{n-1}$$

2. 前一项是交错级数：函数 $\dfrac{\sqrt{x}}{x-1}$ 求导得 $\dfrac{-(x+1)}{2\sqrt{x}(x-1)^2} < 0$ → 单调递减，且 $\dfrac{\sqrt{n}}{n-1} \to 0$ → **莱布尼茨条件满足，收敛**。
3. 后一项 $\sum\dfrac{1}{n-1}$ 是调和级数 → **发散**。
4. 收敛 $+$ 发散 $=$ **发散**。

## 7. 幂级数与收敛域

**幂级数**：$\sum\limits_{n=0}^{\infty} a_n x^n$（通项是一堆幂函数；$a_n$ 是系数）。

**收敛半径**（类似比值审敛法，对系数作比）：

$$\rho = \lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right|,\qquad R = \frac{1}{\rho}$$

（$\rho = 0$ 时 $R = \infty$；$\rho = \infty$ 时 $R = 0$。）

**收敛区间与收敛域**：对 $\sum a_n(x-x_0)^n$，中心点是 $x_0$（如 $\sum a_n x^n$ 中心是 $0$），收敛区间为 $(x_0 - R,\ x_0 + R)$。**端点 $x = x_0 \pm R$ 要单独判定**（代入后变成数项级数，用数项级数审敛法）——收敛区间加上端点情况才是**收敛域**。

**例 4（真题）**：求 $\sum\limits_{n=1}^{\infty}\dfrac{(-1)^{n-1}}{n(2n-1)}x^{2n}$ 的收敛域。

解：

1. 系数 $a_n = \dfrac{1}{n(2n-1)}$（注意 $x^{2n}$ 的系数取法）：$\rho = \lim\limits_{n\to\infty}\dfrac{n(2n-1)}{(n+1)(2n+1)} = 1$ ⟹ $R = 1$。
2. 收敛区间 $(-1, 1)$，判定端点 $x = \pm 1$：$x^{2n} = 1$，级数变为 $\sum\dfrac{(-1)^{n-1}}{n(2n-1)}$。加绝对值后 $\sim \dfrac{1}{2n^2}$（$P = 2 > 1$ 收敛）→ **绝对收敛**。
3. 收敛域：$[-1, 1]$（闭区间）。

## 8. 幂级数求和函数

**基本出发点——等比级数**（注意首项随下标变化）：

$$\sum_{n=0}^{\infty}x^n = \frac{1}{1-x}\quad(|x|<1),\qquad \sum_{n=1}^{\infty}x^n = \frac{x}{1-x}\quad(|x|<1)$$

> **易错点**："一减公比分之首项"——**首项取决于 $\Sigma$ 下标从几开始**（$n=0$ 首项是 $1$，$n=1$ 首项是 $x$）。

**两个加工方向**：
- **求导**：$n$ 和 $x^{n-1}$ 相乘的级数由等比级数求导得来（如 $\sum nx^{n-1} = \dfrac{1}{(1-x)^2}$）；
- **积分**：除法形式（如 $\dfrac{x^n}{n+1}$）由等比级数积分得来。

**操作原则**：遇到**乘积**用"**先积后导**"（积分把 $n$ 降到 $x^n$ 变成等比级数，再求导还原）；遇到**除法**用"**先导后积**"（求导消掉分母变成等比级数，再积分还原）。**求完和函数必须带收敛域**。

**例 5（先导后积）**：求 $S(x) = \sum\limits_{n=0}^{\infty}\dfrac{(-1)^n}{2n+1}x^{2n+1}$ 的和函数。

解：

$$S'(x) = \sum_{n=0}^{\infty}(-1)^n x^{2n} = \sum_{n=0}^{\infty}(-x^2)^n = \frac{1}{1+x^2}\quad(\text{等比级数})$$

$$S(x) = S(0) + \int_0^x\frac{dt}{1+t^2} = \arctan x$$

**例 6（先积后导）**：证明 $\sum\limits_{n=1}^{\infty} n x^{n-1} = \dfrac{1}{(1-x)^2}$。

解：先积分（交换积分与求和）：

$$\int_0^x\sum_{n=1}^{\infty}n t^{n-1}dt = \sum_{n=1}^{\infty}x^n = \frac{x}{1-x}\quad(n \text{ 从 1 起，首项是 } x)$$

再对和函数求导还原：$\left(\dfrac{x}{1-x}\right)' = \dfrac{1}{(1-x)^2}$ ✓

## 9. 真题：数项级数求和（转幂级数）

**真题 7**：求 $\pi\sum\limits_{n=1}^{\infty}\dfrac{n^2}{2^n}$ 的和。

解：

1. 数项级数直接求和很困难 → **变形为幂级数在一点取值**：$\sum n^2 x^n$ 在 $x = \frac{1}{2}$ 处。
2. 求 $\sum n^2 x^{n-1}$ 的和函数：提 $x$ 后先积分两次还原：

$$\sum_{n=1}^{\infty}n^2 x^{n-1}\;\overset{\int}{=}\;\sum_{n=1}^{\infty}n x^n = x\sum_{n=1}^{\infty}n x^{n-1} = \frac{x}{(1-x)^2}$$

3. 求导还原：$\sum n^2 x^{n-1} = \left(\dfrac{x}{(1-x)^2}\right)' = \dfrac{1+x}{(1-x)^3}$，故 $\sum n^2 x^n = \dfrac{x(1+x)}{(1-x)^3}$。
4. 代入 $x = \dfrac{1}{2}$：

$$\sum_{n=1}^{\infty}\frac{n^2}{2^n} = \frac{\frac{1}{2}\cdot\frac{3}{2}}{\left(\frac{1}{2}\right)^3} = 6 \;\Longrightarrow\; \text{原式} = \pi \times 6 = \boxed{6\pi}$$

> **套路**：数项级数求和 ⟹ 把 $\frac{1}{2^n}$ 换成 $x^n$ 构造幂级数，求出和函数后代入 $x = \frac{1}{2}$。

## 10. 幂级数展开（泰勒级数）

**幂级数展开就是求和的逆过程**（也叫泰勒级数/泰勒展开），本质是**背模板 + 转化**：

| 常用展开（收敛域内） |
|----------------------|
| $\dfrac{1}{1-x} = \sum\limits_{n=0}^{\infty}x^n$，$\lvert x\rvert<1$ |
| $\ln(1+x) = \sum\limits_{n=1}^{\infty}\dfrac{(-1)^{n-1}}{n}x^n$；$\ln(1-x) = -\sum\limits_{n=1}^{\infty}\dfrac{x^n}{n}$ |
| $\arctan x = \sum\limits_{n=0}^{\infty}\dfrac{(-1)^n}{2n+1}x^{2n+1}$ |
| $e^x = \sum\limits_{n=0}^{\infty}\dfrac{x^n}{n!}$ |

**两种转化手法**：
- **拆分**：利用 $\ln$ 性质把 $\ln(1+x)(1-2x) = \ln(1+x) + \ln(1-2x)$ 拆成两个已知展开；
- **同乘**：缺项时乘个因子配成熟悉形式（如乘 $(1-x)$ 凑成立方差公式），拆开逐项展开。

## 11. 真题：在 $x=2$ 处展开并求收敛域

**真题 8（去年真题）**：将 $f(x) = \dfrac{1}{(x-1)(x+3)}$ 在 $x = 2$ 处展开成泰勒级数，并求收敛域。

解：

1. **拆分**：$\dfrac{1}{(x-1)(x+3)} = \dfrac{1}{4}\left(\dfrac{1}{x-1} - \dfrac{1}{x+3}\right)$。
2. **凑 $x-2$**（目标明确，把分母凑成 $1 \pm$ 公比的形式）：

$$\frac{1}{x-1} = \frac{1}{1+(x-2)} = \sum_{n=0}^{\infty}(-1)^n(x-2)^n$$

$$\frac{1}{x+3} = \frac{1}{5+(x-2)} = \frac{1}{5}\cdot\frac{1}{1+\frac{x-2}{5}} = \frac{1}{5}\sum_{n=0}^{\infty}(-1)^n\left(\frac{x-2}{5}\right)^n$$

3. 合并：

$$f(x) = \frac{1}{4}\sum_{n=0}^{\infty}(-1)^n\left(1 - \frac{1}{5^{n+1}}\right)(x-2)^n$$

4. **收敛域**：两个等比级数都收敛需 $\|x-2\| < 1$（前一个更严），区间 $(1, 3)$；再判定端点：
   - $x = 1$：通项 $\frac{1}{4}\left(1 - \frac{1}{5^{n+1}}\right) \to \frac{1}{4} \ne 0$ → 发散（不满足必要条件）；
   - $x = 3$：交错级数但通项不趋于零 → 不满足莱布尼茨 → 发散。
5. 收敛域：$(1, 3)$（**开区间，端点取不到**）。

> **要点**：在非零处展开，就是得到 $(x-2)^n$ 的幂级数——同样的拆分/凑等比思路；端点必须单独判。

## 12. 本节重点

> **本节重点**：
> - 要点 1：级数 $=$ 部分和极限；**收敛 ⟹ 通项→0**（只可判发散，不可推收敛）；绝对收敛 ⟹ 收敛，条件收敛 = 收敛但加绝对值发散。
> - 要点 2：正项级数四法——**比较审敛法**（大收小收/小散大散，尺度：等比 $|q|<1$、$P$ 级数 $p>1$、交错 $P$、广义 $P$）；**极限形式**（同敛散；$L=1$ 即等价无穷小，$\sin\frac{1}{n} \sim \frac{1}{n}$ 判发散）；**比值法**（$\rho<1$ 收敛）；**根值法**（通项含 $n$ 次方时用）。
> - 要点 3：交错级数用**莱布尼茨**——$u_n$（去掉 $(-1)^n$）单调递减且趋于零；带根号的交错级数先**有理化拆项**。
> - 要点 4：幂级数收敛半径 $R = 1/\rho$（系数之比取倒）；收敛域 $=$ 区间 $+$ **端点单独判定**（端点变数项级数）。
> - 要点 5：求和函数——**乘积先积后导、除法先导后积**，一切回到等比级数 $\frac{1}{1-x}$（注意首项随下标）；求完带收敛域。
> - 要点 6：数项级数求和 = 构造幂级数取点；幂级数展开 = **背模板 + 拆分/同乘转化**，展开带收敛域、端点单独判。
> - **常见坑**：用"通项→0"判收敛（错误！）；等比与 $P$ 级数结论记反；莱布尼茨带着 $(-1)^n$ 看单调性；$\sum_{n=0}^\infty x^n$ 与 $\sum_{n=1}^\infty x^n$ 的首项混淆（$1$ vs $x$）；求收敛域漏判端点。
