## 1. 积分的基本概念

| 类型 | 目的 | 结果 |
|------|------|------|
| 不定积分 | 找被积函数的**原函数**（$\int f(x)\,dx = F(x) + C$，$F'(x) = f(x)$） | 无数多个原函数，**必须加任意常数 $C$** |
| 定积分 | 计算曲边梯形面积 | 一个**具体的数字**（牛顿–莱布尼兹：上限代入减下限代入） |

> **易错点**：不定积分结果**一定加 $C$**——因为 $F(x)$ 求导等于 $f(x)$，而任意常数求导为零，加上 $C$ 仍是原函数。

## 2. 换元积分法（凑微分）

**核心思想**：导数公式的逆用 + **善于发现被积函数中"函数与其导数同时出现"**——只要被积函数里有一个函数和它的导数（差个常数倍），就可以把导数部分"凑"进微分号。

> **直观理解**：凑微分的难点就在"发现"——看到 $\sin$ 和 $\cos$、看到根号和根号分之一、看到 $e^x$ 和 $e^x$，都是"函数与其导数同框"的信号。

**例 1（基本型，提取 + 凑微分）**：

$$\int\frac{dx}{\sqrt{a^2-x^2}} = \arcsin\frac{x}{a} + C, \qquad \int\frac{dx}{a^2+x^2} = \frac{1}{a}\arctan\frac{x}{a} + C$$

套路：把 $a^2$ 提出来化成 $1 - (\frac{x}{a})^2$ 的形式，再用 $\frac{1}{a}$ 凑微分 $d(\frac{x}{a})$。**凑完后微分里的变量必须与换元变量一致**，才能放心用公式。

**例 2（函数与导数同框）**：$\displaystyle\int \tan x\,dx = \int\frac{\sin x}{\cos x}dx = -\int\frac{1}{\cos x}d(\cos x) = -\ln|\cos x| + C$。

（$\sin$ 与 $\cos$ 互为导数关系 → 把 $\sin x\,dx$ 凑成 $-d(\cos x)$。）

**例 3（根号与其导数同框）**：$\displaystyle\int\frac{e^{3\sqrt{x}}}{\sqrt{x}}dx = \frac{2}{3}e^{3\sqrt{x}} + C$。

（$\sqrt{x}$ 的导数是 $\frac{1}{2\sqrt{x}}$，所以 $\frac{1}{\sqrt{x}}dx = 2d(\sqrt{x})$，再凑成 $d(3\sqrt{x})$ 配系数。）

**例 4（正割高次幂）**：$\displaystyle\int\sec^6 x\,dx = \frac{1}{5}\tan^5 x + \frac{2}{3}\tan^3 x + \tan x + C$。

用两个必记公式：$\tan' x = \sec^2 x$，$1 + \tan^2 x = \sec^2 x$。拆出两个 $\sec^2 x$ 凑成 $d(\tan x)$，剩下的 $\sec^4 x = (1+\tan^2 x)^2$ 也换成 $\tan$，展开积分即可。

**例 5（缺什么补什么）**：$\displaystyle\int\frac{dx}{1+e^x} = x - \ln(1+e^x) + C$。

被积函数"光秃秃"没法凑微分 → **加 $e^x$ 减 $e^x$** 拆分：$\dfrac{1+e^x-e^x}{1+e^x} = 1 - \dfrac{e^x}{1+e^x}$，后一项把 $e^x dx$ 凑成 $d(1+e^x)$ 得 $\ln(1+e^x)$。

> **要点**：换元/凑微分时，微分里的变量**必须与换元变量一致**；"缺什么补什么"（加项减项）在积分里同样是拼凑利器。

## 3. 三角换元法：去根号

**适用**：被积函数带根号，且根号下是"平方和差"形式。去根号最朴素的思路——**把根号里捏成一个平方**，用三角函数公式抵消：

| 根号形式 | 换元 | 依据 |
|----------|------|------|
| $\sqrt{a^2 - x^2}$ | $x = a\sin t$ | $1 - \sin^2 t = \cos^2 t$ |
| $\sqrt{a^2 + x^2}$ | $x = a\tan t$ | $1 + \tan^2 t = \sec^2 t$ |
| $\sqrt{x^2 - a^2}$ | $x = a\sec t$ | $\sec^2 t - 1 = \tan^2 t$ |

（若系数不是 $1$，先提 $a^2$ 出来，令 $\frac{x}{a} = \sin t$ 等。）

**例 6（三角换元 + 凑微分 + 回代）**：求 $\displaystyle\int\frac{dx}{x^2\sqrt{4+x^2}}$。

解：

1. 根号下是 $4 + x^2$（$a^2+x^2$ 型）→ 令 $x = 2\tan t$。则 $dx = 2\sec^2 t\,dt$，$\sqrt{4+x^2} = 2\sec t$。
2. 代换：$\displaystyle\int\frac{2\sec^2 t}{(4\tan^2 t)(2\sec t)}dt = \frac{1}{4}\int\frac{\sec t}{\tan^2 t}dt = \frac{1}{4}\int\frac{\cos t}{\sin^2 t}dt$。
3. 又见 $\cos$ 与 $\sin$ 同框 → 凑微分 $d(\sin t)$：$\dfrac{1}{4}\displaystyle\int\frac{d(\sin t)}{\sin^2 t} = -\frac{1}{4\sin t} + C$。
4. **回代**（画直角三角形）：$\tan t = \dfrac{x}{2}$ ⟹ 对边 $x$、邻边 $2$、斜边 $\sqrt{4+x^2}$，故 $\sin t = \dfrac{x}{\sqrt{4+x^2}}$。
5. 答案：$-\dfrac{\sqrt{4+x^2}}{4x} + C$。

> **易错点**：换元后**$dx$ 不能直接写成 $dt$**，必须算 $dx = x'(t)dt$；不定积分最后要把 $t$ 换回 $x$（用直角三角形法），不能停在 $t$。

## 4. 分部积分法

**公式**：

$$\int U\,dV = UV - \int V\,dU$$

**适用**：两个函数相乘的积分（或单个"孤零零"函数——把它看成 $U\,dV$，其中 $V = x$）。

**选 $U$ 的规则——"反对幂指三"**：反三角函数、对数函数、幂函数、指数函数、三角函数，**谁靠左谁当 $U$**，剩下的当 $dV$。

**例 7**：$\displaystyle\int x\arctan x\,dx$。

解：按"反对幂指三"，$U = \arctan x$（反三角在幂函数左边），$dV = x\,dx$ → $V = \dfrac{x^2}{2}$，$dU = \dfrac{dx}{1+x^2}$。

$$\int x\arctan x\,dx = \frac{x^2}{2}\arctan x - \frac{1}{2}\int\frac{x^2}{1+x^2}dx = \frac{x^2}{2}\arctan x - \frac{1}{2}\bigl(x - \arctan x\bigr) + C$$

（中间的 $\int\frac{x^2}{1+x^2}dx$ 用加 1 减 1 拆成 $1 - \frac{1}{1+x^2}$。）

**例 8（单函数看成 $U\,dV$）**：$\displaystyle\int_0^{1/2}\arcsin x\,dx = \frac{\pi}{12} + \frac{\sqrt{3}}{2} - 1$。

解：把 $\arcsin x$ 看成 $U$、$dx$ 看成 $dV$（$V = x$）：

$$\Bigl[x\arcsin x\Bigr]_0^{1/2} - \int_0^{1/2}\frac{x}{\sqrt{1-x^2}}dx = \frac{\pi}{12} - \Bigl[-\sqrt{1-x^2}\Bigr]_0^{1/2} = \frac{\pi}{12} + \frac{\sqrt{3}}{2} - 1$$

（$x$ 与 $\sqrt{1-x^2}$ 同框 → 凑微分 $d(1-x^2)$。）

**真题 9（第 16 届）**：$\displaystyle\int_0^1 \ln(1+x^2)\,dx = \ln 2 - 2 + \frac{\pi}{2}$。

解：$U = \ln(1+x^2)$（对数函数靠左），$dV = dx$，$V = x$：

$$\Bigl[x\ln(1+x^2)\Bigr]_0^1 - \int_0^1\frac{2x^2}{1+x^2}dx = \ln 2 - 2\int_0^1\Bigl(1 - \frac{1}{1+x^2}\Bigr)dx = \ln 2 - 2\bigl[x - \arctan x\bigr]_0^1 = \ln 2 - 2 + \frac{\pi}{2}$$

**例 10（先换元再分部）**：$\displaystyle\int e^{\sqrt{x}}dx = 2(\sqrt{x}-1)e^{\sqrt{x}} + C$。

解：根号在 $e$ 的头顶没法凑微分/三角换元 → **整体换元** $\sqrt{x} = t$，$x = t^2$，$dx = 2t\,dt$：

$$\int e^{\sqrt{x}}dx = 2\int t e^t\,dt = 2(te^t - e^t) + C = 2(\sqrt{x}-1)e^{\sqrt{x}} + C$$

（换元后变成幂×指数，用分部积分：$U = t$，$dV = e^t dt$。）

## 5. 有理函数积分法

**适用**：分母是**两个式子乘积**（尤其一次×二次）的复杂分式。思路：**拆成简单分式**，让每项都能用 $\ln$ 或 $\arctan$ 积分。

**拆分规则**：

| 分母形式 | 拆法 |
|----------|------|
| 一次多项式 $(x-a)$ | 分子配常数 $A$ |
| 高次幂 $(x-a)^k$ | 逐次拆出 $k$ 次、$k-1$ 次、…、$1$ 次共 $k$ 项，分子都是常数 |
| 二次式（不可约，如 $x^2+px+q$） | 分子配一次式 $Bx + C$ |

**求系数技巧**：
- 分子只有常数 $A$ 时：**令对应分母为零解出 $x$，代入原式其余部分**即得 $A$；
- 其余系数：取特殊值（如 $x=0$、$x=1$）联立求解。

**例 11**：$\displaystyle\int\frac{dx}{(2x+1)(1+x^2)}$。

解：

1. 拆：$\dfrac{1}{(2x+1)(1+x^2)} = \dfrac{A}{2x+1} + \dfrac{Bx+C}{1+x^2}$。
2. 求 $A$：令 $2x+1 = 0$ → $x = -\dfrac{1}{2}$，代入原式其余部分：$A = \dfrac{1}{1+x^2}\Big|_{x=-1/2} = \dfrac{1}{1+1/4} = \dfrac{4}{5}$。
3. 取 $x=0$：$1 = A + C$ → $C = \dfrac{1}{5}$；取 $x=1$：$\dfrac{1}{6} = \dfrac{A}{3} + \dfrac{B+C}{2}$ → $B = -\dfrac{2}{5}$。
4. 积分：

$$\int\left[\frac{4/5}{2x+1} - \frac{2x/5 - 1/5}{1+x^2}\right]dx = \frac{2}{5}\ln|2x+1| - \frac{1}{5}\ln(1+x^2) + \frac{1}{5}\arctan x + C$$

## 6. 定积分的应用：面积、弧长、旋转体

**求面积**（三种坐标系）：

| 坐标系 | 公式 |
|--------|------|
| 直角坐标（$y = f(x)$） | $S = \displaystyle\int_a^b f(x)\,dx$ |
| 参数方程（$x = \varphi(t)$，$y = \psi(t)$） | $S = \displaystyle\int_\alpha^\beta \psi(t)\,\varphi'(t)\,dt$ |
| 极坐标（$r = r(\theta)$） | $S = \dfrac{1}{2}\displaystyle\int_\alpha^\beta r^2(\theta)\,d\theta$（多为扇形） |

**求弧长**（三种坐标系）：

| 坐标系 | 公式 |
|--------|------|
| 直角坐标（$y = f(x)$） | $s = \displaystyle\int_a^b\sqrt{1 + (y')^2}\,dx$ |
| 参数方程 | $s = \displaystyle\int_\alpha^\beta\sqrt{(\varphi')^2 + (\psi')^2}\,dt$ |
| 极坐标 | $s = \displaystyle\int_\alpha^\beta\sqrt{r^2 + (r')^2}\,d\theta$ |

**旋转体体积**：

| 旋转轴 | 公式 |
|--------|------|
| 绕 $x$ 轴（$y = f(x)$，$x \in [a,b]$） | $V = \pi\displaystyle\int_a^b f^2(x)\,dx$ |
| 绕 $y$ 轴（$x = \varphi(y)$，$y \in [c,d]$） | $V = \pi\displaystyle\int_c^d \varphi^2(y)\,dy$ |

> 绕 $y$ 轴就是把 $x$、$y$ 互换：函数写成 $x = \varphi(y)$，对 $y$ 积分。公式**需要背下来**。

## 7. 综合真题：面积 + 旋转体体积最值

**真题 12（第 16 届）**：曲线 $y = 3ax^2 + 2bx + c$ 过原点，且在 $[0,1]$ 上 $y > 0$。曲线与 $x=1$、$x$ 轴围成的图形 $D$ 面积为 $1$。确定 $a,b,c$ 使 $D$ 绕 $x$ 轴旋转所得旋转体体积最小。

解：

1. **过原点** → $c = 0$（$y(0) = 0$）。
2. **面积条件**：$S = \displaystyle\int_0^1 (3ax^2 + 2bx)dx = \Bigl[ax^3 + bx^2\Bigr]_0^1 = a + b = 1$。
3. **体积**（绕 $x$ 轴）：$V = \pi\displaystyle\int_0^1 (3ax^2+2bx)^2dx = \pi\int_0^1(9a^2x^4 + 12abx^3 + 4b^2x^2)dx = \pi\left(\frac{9a^2}{5} + 3ab + \frac{4b^2}{3}\right)$。
4. 消元 $b = 1 - a$：$V = \pi\left(\dfrac{2a^2}{15} + \dfrac{a}{3} + \dfrac{4}{3}\right)$。
5. **一元函数求最值**：$V'(a) = \pi\left(\dfrac{4a}{15} + \dfrac{1}{3}\right) = 0$ ⟹ $a = -\dfrac{5}{4}$，$b = 1 - a = \dfrac{9}{4}$。
6. **答案**：$a = -\dfrac{5}{4}$，$b = \dfrac{9}{4}$，$c = 0$。

> **复盘**：这题看着吓人，其实**只套了两个公式**（面积、旋转体体积）+ 一元求极值。考试遇到要冷静分析——把几何条件翻译成积分等式，再消元求驻点。

## 8. 乘积求导型积分："狗咬狗"与"硬凑"

> 本节 §8—§10 的真题选自 B站「epsilon-delta_」CMC 初赛精选题串讲（原始材料：`数学竞赛/原始材料/BV1cYWb62Emn/`）。

**识别特征**：被积函数长得复杂，但**可以拆成两块，而两块分别是某个乘积求导的两半**：

$$(uv)' = u'v + uv'$$

它的原函数直接就是 $uv$。问题在于这两半各自都**没有初等原函数**，硬积一定积不出来。两条破解路线：

| 路线 | 做法 |
|------|------|
| **看出来的** | 直接认出被积函数 $= (uv)'$，答案 $uv + C$ |
| **看不出来（狗咬狗）** | 拆成 $\int u'v + \int uv'$ 两个积分，对其中一个分部积分，其产物与另一个**正好抵消**，剩下的边界项就是 $uv$ |

**"硬凑"技巧**：想凑微分却看不出"谁求导得它"时，**就单独对这个因子做一次不定积分**（草稿纸上算），算出的原函数就是你要凑的东西。确认能凑，正式写分部积分即可。硬凑不丢人。

**真题 9**：计算 $\displaystyle\int_0^{\pi/2}\frac{e^{x}(1+\sin x)}{1+\cos x}\,dx$。

解：

1. **拆成两条"狗"**：

$$I = \underbrace{\int_0^{\pi/2}\frac{e^{x}}{1+\cos x}dx}_{\text{狗一}} + \underbrace{\int_0^{\pi/2}\frac{e^{x}\sin x}{1+\cos x}dx}_{\text{狗二}}$$

2. **对狗二凑 $e^{x}$ 做分部积分**（指数型与三角型相乘时，把指数整体凑到微分号后）：

$$\int_0^{\pi/2}\frac{\sin x}{1+\cos x}\,e^{x}dx = \left[\frac{e^{x}\sin x}{1+\cos x}\right]_0^{\pi/2} - \int_0^{\pi/2}e^{x}\,d\left(\frac{\sin x}{1+\cos x}\right)$$

3. **算那个微分**：$\left(\dfrac{\sin x}{1+\cos x}\right)' = \dfrac{\cos x(1+\cos x) + \sin^{2}x}{(1+\cos x)^{2}} = \dfrac{1+\cos x}{(1+\cos x)^{2}} = \dfrac{1}{1+\cos x}$，于是

$$\int_0^{\pi/2}\frac{e^{x}\sin x}{1+\cos x}dx = \left[\frac{e^{x}\sin x}{1+\cos x}\right]_0^{\pi/2} - \int_0^{\pi/2}\frac{e^{x}}{1+\cos x}dx$$

4. **两条狗互咬**：上式右边那个积分正是**负的狗一**，搬回 $I$ 里与狗一抵消，只剩边界项：

$$I = \left[\frac{e^{x}\sin x}{1+\cos x}\right]_0^{\pi/2} = e^{\pi/2}\cdot\frac{1}{1+0} - e^{0}\cdot\frac{0}{2} = e^{\pi/2}$$

**答案 $e^{\pi/2}$**。

**真题 10**：求 $\displaystyle\int e^{-\sin x}\frac{\sin 2x}{(1-\sin x)^{2}}\,dx$。

解：

1. **二倍角化一倍角**：$\sin 2x = 2\sin x\cos x$，被积函数里全是 $\sin x$ 与 $\cos x$ → 凑 $d(\sin x)$：

$$\int e^{-\sin x}\frac{2\sin x\cos x}{(1-\sin x)^{2}}dx = 2\int e^{-u}\frac{u}{(1-u)^{2}}du \quad (u = \sin x)$$

2. **分子凑出分母的因子**：$u = (u-1)+1 = -(1-u)+1$，故 $\dfrac{u}{(1-u)^{2}} = \dfrac{1}{(1-u)^{2}} - \dfrac{1}{1-u}$：

$$2\int e^{-u}\frac{u}{(1-u)^{2}}du = 2\int\frac{e^{-u}}{(1-u)^{2}}du - 2\int\frac{e^{-u}}{1-u}du$$

3. **对第一条狗分部积分**（凑 $d\left(\dfrac{1}{1-u}\right)$）：

$$2\int e^{-u}d\left(\frac{1}{1-u}\right) = \frac{2e^{-u}}{1-u} + 2\int\frac{e^{-u}}{1-u}du$$

（分部后出现的 $+2\int\dfrac{e^{-u}}{1-u}du$ 与第 2 步的 $-$ 项**正好抵消**。）
4. **回代** $u = \sin x$：

$$\int e^{-\sin x}\frac{\sin 2x}{(1-\sin x)^{2}}dx = \frac{2e^{-\sin x}}{1-\sin x} + C$$

> **易错点**：算到 $u$ 的答案**必须换回 $x$**，否则等于白做（定积分无所谓，不定积分不回代就是零分）。

**真题 11（硬凑示范）**：求 $\displaystyle\int\frac{\ln\left(x+\sqrt{1+x^{2}}\right)}{(1+x^{2})^{3/2}}\,dx$。

解：

1. 看到 $1+x^{2}$ 想到 $x = \tan t$，可得 $\displaystyle\int\frac{dx}{(1+x^{2})^{3/2}} = \frac{x}{\sqrt{1+x^{2}}}$——但每次都三角换元太笨。**"硬凑"**：先单独求一次这个不定积分，记下"谁求导得 $\dfrac{1}{(1+x^{2})^{3/2}}$"。

   （验证：$x=\tan t$ 时 $\int\dfrac{\sec^{2}t}{\sec^{3}t}dt = \int\cos t\,dt = \sin t = \dfrac{x}{\sqrt{1+x^{2}}}$。）

2. 于是原式 $=\displaystyle\int\ln\left(x+\sqrt{1+x^{2}}\right)d\left(\frac{x}{\sqrt{1+x^{2}}}\right)$，分部积分：

$$= \frac{x\ln\left(x+\sqrt{1+x^{2}}\right)}{\sqrt{1+x^{2}}} - \int\frac{x}{\sqrt{1+x^{2}}}\cdot\frac{dx}{\sqrt{1+x^{2}}}$$

3. 后一项化简：$\displaystyle\int\frac{x}{1+x^{2}}dx = \frac{1}{2}\ln(1+x^{2})$。故

$$\int\frac{\ln\left(x+\sqrt{1+x^{2}}\right)}{(1+x^{2})^{3/2}}dx = \frac{x\ln\left(x+\sqrt{1+x^{2}}\right)}{\sqrt{1+x^{2}}} - \frac{1}{2}\ln(1+x^{2}) + C$$

> **要点**：对数函数的导数才是"没有对数"的式子，所以**对数必当 $U$、其余凑进微分**（"反对幂指三"的极端情形）。凑不出来时就用硬凑——先算掉那个因子的原函数。

## 9. 旋转曲面的面积：绕一般直线

§6 只记了旋转体的**体积**，面积（侧面积）同样要会。核心是**微元法**：曲线上长 $ds$ 的微段绕直线 $L$ 转一圈，得到一条"彩带"——**宽是弧微分 $ds$，长是周长 $2\pi d$**（$d$ 为该点到 $L$ 的距离），故

$$dS = 2\pi d\,ds$$

| 旋转轴 | 距离 $d$ | 面积公式 |
|--------|----------|----------|
| $x$ 轴 | $\lvert f(x)\rvert$ | $S = 2\pi\displaystyle\int_a^b\lvert f(x)\rvert\sqrt{1+(f')^{2}}\,dx$ |
| $y$ 轴 | $\lvert x\rvert$ | $S = 2\pi\displaystyle\int_a^b\lvert x\rvert\sqrt{1+(f')^{2}}\,dx$ |
| 一般直线 $Ax+By+C=0$ | $\dfrac{\lvert Ax+By+C\rvert}{\sqrt{A^{2}+B^{2}}}$ | $S = 2\pi\displaystyle\int_a^b d(x)\sqrt{1+(f')^{2}}\,dx$ |

> **去绝对值的依据**：先判断曲线在直线哪一侧。取曲线在端点的**切线斜率**与直线斜率比较，就能确定位置关系（若切线斜率大于直线斜率，则曲线在直线上方）。

**真题 12**：设曲线 $y = \dfrac{x^{3}}{3} + 2x$（$x\in[0,1]$）绕直线 $y = \dfrac{4}{3}x$ 旋转，求所得旋转曲面的面积。

解：

1. **判断位置**：令 $\varphi(x) = y - \dfrac{4}{3}x$，则 $\varphi(0) = 0$，且 $\varphi'(x) = x^{2}+2-\dfrac{4}{3} = x^{2}+\dfrac{2}{3} > 0$，故 $\varphi(x) > 0$——**曲线恒在直线上方**，即 $3y - 4x > 0$（经验判断也可：$y'(0) = 2 > \dfrac{4}{3}$，曲线在起点的切线就比直线陡）。
2. **求距离**：直线写成 $4x-3y = 0$，则

$$d = \frac{\lvert 4x-3y\rvert}{\sqrt{4^{2}+3^{2}}} = \frac{3y-4x}{5} = \frac{x^{3}+6x-4x}{5} = \frac{x^{3}+2x}{5}$$

3. **写面积微元并积分**：$ds = \sqrt{1+(y')^{2}}\,dx = \sqrt{1+(x^{2}+2)^{2}}\,dx$，

$$S = 2\pi\int_0^1\frac{x^{3}+2x}{5}\sqrt{1+(x^{2}+2)^{2}}\,dx$$

4. **提公因式再换元**（关键一步，别急着展开）：$x^{3}+2x = x(x^{2}+2)$，令 $u = x^{2}+2$，$x\,dx = \dfrac{du}{2}$，$x:0\to1$ 对应 $u:2\to3$：

$$S = \frac{2\pi}{5}\cdot\frac{1}{2}\int_2^3 u\sqrt{1+u^{2}}\,du = \frac{\pi}{5}\left[\frac{(1+u^{2})^{3/2}}{3}\right]_2^3 = \frac{\pi}{15}\left(10\sqrt{10} - 5\sqrt{5}\right)$$

**答案 $S = \dfrac{\pi}{15}\left(10\sqrt{10}-5\sqrt{5}\right)$**。

> **要点**：① 绕一般直线的面积题，全部落回 $dS = 2\pi d\,ds$，**先定 $d$ 再去绝对值**；② 定积分里出现 $x^{3}+2x$ 与 $x^{2}+2$ 同时出现时，**先提公因式造出"函数 × 它的导数"**，再换元——一展开就废了。

## 10. 积分恒等式与积分不等式

### 10.1 恒等式：用"交换次序 + 对称"或"变限配平方"

**真题 13**：设 $f$ 在 $[a,b]$ 上连续，证明

$$\left(\int_a^b f(x)\,dx\right)^{2} = 2\int_a^b f(x)\left(\int_x^b f(t)\,dt\right)dx$$

**证法一（二重积分 + 对称性）**：右边 $=2\displaystyle\iint_{D}f(x)f(t)\,d\sigma$，其中 $D = \{(x,t): a\le x\le t\le b\}$（上三角）。交换 $x$、$t$ 的字母，区域变成关于 $y=x$ 对称的 $D'$，而 $f(x)f(t)$ 交换后不变，故两个积分相等：

$$2\iint_D f(x)f(t) = \iint_D + \iint_{D'} = \iint_{[a,b]\times[a,b]}f(x)f(t)\,d\sigma = \left(\int_a^b f(x)dx\right)\left(\int_a^b f(t)dt\right) = \left(\int_a^b f\right)^{2}$$

**证法二（变限积分 + 凑平方）**：注意 $\left(\displaystyle\int_x^b f(t)dt\right)^{2}$ 求导得 $-2f(x)\displaystyle\int_x^b f(t)dt$，于是

$$2\int_a^b f(x)\left(\int_x^b f(t)dt\right)dx = -\int_a^b d\left[\left(\int_x^b f(t)dt\right)^{2}\right] = -\left[0 - \left(\int_a^b f\right)^{2}\right] = \left(\int_a^b f\right)^{2}$$

> **要点**：证法二的思路更值得记——**看到 $f(x)\cdot(\text{含 } x \text{ 的积分})$ 就想"这是某个平方的导数"**。考研里常见的 $\displaystyle\int_0^x f(t)dt\cdot f(x) = \frac{1}{2}\left[\left(\int_0^x f\right)^2\right]'$ 是同一个东西。

### 10.2 不等式：弧长 ≥ 弦长

**真题 14**：设 $f$ 在 $[a,b]$ 上有一阶连续导数，证明

$$\sqrt{(b-a)^{2} + \bigl(f(b)-f(a)\bigr)^{2}} \le \int_a^b\sqrt{1+(f'(x))^{2}}\,dx$$

并给出等号成立的条件。

**几何意义**（先把两分拿到手）：左边是连接两端点的**弦长**，右边是曲线的**弧长**——两点之间线段最短，所以弧长不小于弦长。等号成立当且仅当**曲线就是那条线段**，即 $f$ 在 $[a,b]$ 上是**线性函数**。

**证明（变限积分 + 柯西不等式）**：令

$$F(x) = \int_a^x\sqrt{1+(f')^{2}}\,dt - \sqrt{(x-a)^{2} + \bigl(f(x)-f(a)\bigr)^{2}}$$

则 $F(a) = 0$，只需证 $F$ 在 $[a,b]$ 上单调不减。求导：

$$F'(x) = \sqrt{1+(f')^{2}} - \frac{(x-a) + \bigl(f(x)-f(a)\bigr)f'(x)}{\sqrt{(x-a)^{2}+\bigl(f(x)-f(a)\bigr)^{2}}}$$

要证 $F'\ge 0$，即证

$$\sqrt{1+(f')^{2}}\cdot\sqrt{(x-a)^{2}+\bigl(f(x)-f(a)\bigr)^{2}} \ge (x-a) + \bigl(f(x)-f(a)\bigr)f'(x)$$

而这正是**柯西不等式**（把右边看成两组数 $1,\,f'$ 与 $x-a,\,f(x)-f(a)$ 的内积）：

$$\Bigl[(x-a) + \bigl(f(x)-f(a)\bigr)f'\Bigr]^{2} \le \Bigl[1+(f')^{2}\Bigr]\Bigl[(x-a)^{2}+\bigl(f(x)-f(a)\bigr)^{2}\Bigr]$$

左边非负，故开方后不等式成立，$F'\ge 0$。

于是 $F(b)\ge F(a) = 0$，即所证不等式成立。等号成立需柯西取等，即两组数成比例：$\bigl(x-a,\,f(x)-f(a)\bigr)$ 与 $(1,f')$ 成比例，推出 $f'(x)$ 为常数——$f$ 线性。

> **要点**：① 积分不等式证不出来时，把上限 $b$ 换成 $x$ 造**变限函数**，把不等式变成**单调性**（这是积分不等式最通用的套路）；② 中间那步"通分比较"往往就是**柯西不等式**，认出来就一行写完；③ 明白几何背景（弧长 vs 弦长）能先把"取等条件"这两分稳稳拿到。

## 11. 补充（周老师课）：不定积分与定积分的考点速览

> 本节内容来自 B站「周老师带你学数竞」《大学生数学竞赛四小时突击速成课》P5「不定积分」、P6「定积分」（原始材料：`数学竞赛/原始材料/BV15Qe76cE6W/`）。

### 11.1 三种"非三角"换元

| 看到什么 | 换元 | 为什么有效 |
| --- | --- | --- |
| $\sqrt{ax+b}$ 单独出现 | $t=\sqrt{ax+b}$ | 根号变多项式，$x$ 可反解 |
| 分母次数比分子高两次以上 | $x=\frac{1}{t}$ | 分母的高次幂被"翻"到分子上 |
| 隐函数 $F(x,y)=0$，$x,y$ 同次 | $t=\frac{y}{x}$ | 曲线变参数式，$x,y,dx$ 全是 $t$ |

**例 15（根式换元）**：$\displaystyle\int\frac{x}{\sqrt{1-x}}dx$。

解：

1. 令 $t=\sqrt{1-x}$，则 $x=1-t^2$，$dx=-2t\,dt$。
2. $\displaystyle\int\frac{1-t^2}{t}(-2t)dt=\int(2t^2-2)dt=\frac{2}{3}t^3-2t+C$，回代 $t=\sqrt{1-x}$。

**答案** $\dfrac{2}{3}(1-x)^{3/2}-2\sqrt{1-x}+C$。

> **要点**：根号下是**一次式**就整体换元（换完 $x$、$dx$ 都是多项式，必积得出）；根号下是 $a^2-x^2$ 这类**二次式**才轮到三角换元。

**例 16（倒代换）**：$\displaystyle\int\frac{dx}{x^2(1+x^2)}$。

解：

1. 分母四次、分子零次 → 令 $x=\dfrac{1}{t}$，$dx=-\dfrac{dt}{t^2}$。
2. $\dfrac{1}{x^2(1+x^2)}=\dfrac{t^4}{1+t^2}$，乘 $dx$ 得 $-\dfrac{t^2}{1+t^2}dt=-\left(1-\dfrac{1}{1+t^2}\right)dt$，积分后回代 $t=\dfrac{1}{x}$。

**答案** $-\dfrac{1}{x}+\arctan\dfrac{1}{x}+C$（$x>0$ 时也可写 $-\dfrac{1}{x}-\arctan x+C$）。

> **易错点**：$dx=-\frac{dt}{t^2}$ 的负号十有八九会丢；回代是 $\arctan\frac{1}{x}$，不是 $\frac{1}{\arctan x}$。

**隐函数积分**只需一句话：方程给出 $x,y$ 同次关系时令 $t=\frac{y}{x}$，把 $x$、$y$、$dx$ 全写成 $t$ 的式子（如由 $y-x=\frac{y}{x}$ 得 $x=\frac{t}{t-1}$、$dx=-\frac{dt}{(t-1)^2}$），$\int\frac{dx}{y^2}$ 立刻变成 $-\int t^{-4}dt=\frac{1}{3t^3}+C=\frac{1}{3}(\frac{x}{y})^3+C$。

> **要点**：隐函数积分的关键是**先参数化再积分**，别硬去求 $y(x)$ 的显式；换完之后 $dx$ 要从参数式里算，不能漏。

### 11.2 定积分的值是常数：把它设出来

**看到"$f(x)=$ 已知函数 $+\int_a^b f$"** → 那个积分是**数**，不是函数，设成 $A$ 就破题。

**例 17**：设 $f$ 连续，$f(x)=x^2-x+\displaystyle\int_0^2 f(t)dt$，求 $f(x)$。

解：

1. 设 $A=\displaystyle\int_0^2 f(t)dt$，则 $f(x)=x^2-x+A$。
2. 两边在 $[0,2]$ 上积分：$A=\displaystyle\int_0^2(x^2-x)dx+2A=\frac{8}{3}-2+2A$。
3. 解出 $A=-\dfrac{2}{3}$ 并代回。

**答案** $f(x)=x^2-x-\dfrac{2}{3}$。

> **要点**：有几个未知定积分就设几个常数（$A,B,\dots$），代回积分一次得方程组；**解完必须代回**，答案里留 $A$ 等于没做。

### 11.3 对称性与区间再现

**奇偶性**：$\int_{-a}^{a}f=0$（$f$ 奇）、$=2\int_0^a f$（$f$ 偶）。如 $\int_{-1}^{1}\bigl[x(e^x-e^{-x})+x^{26}(e^x-e^{-x})\bigr]dx$：前者奇×奇为偶、后者偶×奇为奇，于是 $=2\int_0^1x(e^x-e^{-x})dx=\frac{4}{e}$。

**区间再现公式**（难题最爱考）：

$$\int_a^b f(x)\,dx=\int_a^b f(a+b-x)\,dx=\frac{1}{2}\int_a^b\left[f(x)+f(a+b-x)\right]dx$$

作用是把 $x$ **消掉或变成常数**。最常用的一格是（因 $\sin(\pi-x)=\sin x$）：$\int_0^{\pi}x f(\sin x)\,dx=\frac{\pi}{2}\int_0^{\pi}f(\sin x)\,dx$。

**例 18**：$\displaystyle\int_0^{\pi}x\sin^2x\cos^2x\,dx$。

解：

1. 用 $\cos^2x=1-\sin^2x$ 把被积函数化成只含 $\sin x$，即 $f(\sin x)=\sin^2x\cos^2x$。
2. 区间再现：原式 $=\dfrac{\pi}{2}\displaystyle\int_0^{\pi}\sin^2x\cos^2x\,dx$；被积函数关于 $\frac{\pi}{2}$ 对称，$=2\cdot\dfrac{\pi}{2}\displaystyle\int_0^{\pi/2}\sin^2x\cos^2x\,dx$。
3. $\displaystyle\int_0^{\pi/2}\sin^2x\cos^2x\,dx=\frac{1}{4}\int_0^{\pi/2}\sin^22x\,dx=\frac{1}{4}\cdot\frac{\pi}{4}$。

**答案** $\dfrac{\pi^2}{16}$。

> **要点**：触发条件是"$x$ 乘一个关于 $\sin x$ 的函数 + 中点对称区间"；换元一律取 $x=a+b-t$，且要检查 $f(a+b-x)$ 是否回到 $f(x)$。

### 11.4 周期性、夹逼与 Wallis 公式

**周期函数**：$\int_a^{a+T}f=\int_0^T f$（起点可平移），故 $\int_0^{nT}f=n\int_0^T f$。含积分的极限按"整周期块 + 余项"拆：$|\sin t|$ 以 $\pi$ 为周期、每块积分 $2$，故 $\lim_{n\to\infty}\frac{1}{n}\int_0^n|\sin t|dt=\frac{2}{\pi}$。夹逼时由 $m\pi\le n<(m+1)\pi$ 得 $\frac{m}{n}\to\frac{1}{\pi}$——**分母是 $n$ 不是 $m$**。

**Wallis 公式**（双阶乘 $6!!=6\cdot4\cdot2$、$5!!=5\cdot3\cdot1$，**只有偶数才乘 $\frac{\pi}{2}$**）：

$$\int_0^{\pi/2}\sin^nx\,dx=\int_0^{\pi/2}\cos^nx\,dx=\begin{cases}\dfrac{(n-1)!!}{n!!}\cdot\dfrac{\pi}{2}, & n\text{ 为偶数}\\[4pt] \dfrac{(n-1)!!}{n!!}, & n\text{ 为奇数}\end{cases}$$

**例 19**：$\displaystyle\int_0^{2\pi}(\sin^4x-\sin^6x)dx$。

解：

1. 两项都以 $2\pi$ 为周期且关于 $\frac{\pi}{2}$ 对称 → 原式 $=4\displaystyle\int_0^{\pi/2}(\sin^4x-\sin^6x)dx$。
2. 分别用 Wallis 算出 $\displaystyle\int_0^{\pi/2}\sin^4x\,dx=\frac{3\pi}{16}$、$\displaystyle\int_0^{\pi/2}\sin^6x\,dx=\frac{5\pi}{32}$，两者相减再乘以 4。

**答案** $\dfrac{\pi}{8}$。

> **要点**：$\int_0^{2\pi}$、$\int_0^{\pi}$ 上的偶次三角幂，先化到 $\int_0^{\pi/2}$ 再用 Wallis；本题被积函数 $=\sin^4x\cos^2x\ge0$，答案为正可作粗检。

## 12. 反常积分（广义积分）：从零补齐

> 本节内容来自同课 P7「反常积分」。

反常积分只有两种"坏"：**区间无限长**，或**被积函数在有限点附近无界**。处理方式完全一致——**先当正常积分算，再对坏点取极限**（牛顿–莱布尼兹公式在 $F$ 端点无定义时本来就该写成 $\lim_{x\to b^-}F-\lim_{x\to a^+}F$）。全部判敛结论都由两把尺子推出：

$$\int_1^{+\infty}\frac{dx}{x^p}\ \text{收敛}\iff p>1,\qquad \int_0^{1}\frac{dx}{x^p}\ \text{收敛}\iff p<1$$

### 12.1 无穷区间上的反常积分

**定义**：$\displaystyle\int_a^{+\infty}f(x)dx=\lim_{b\to+\infty}\int_a^b f(x)dx$，极限存在则收敛。$\int_{-\infty}^{+\infty}$ 要求**左右两段各自收敛**。

**为什么是 $p>1$**：$\int_1^{b}x^{-p}dx=\dfrac{b^{1-p}-1}{1-p}$（$p\neq1$），只有 $1-p<0$ 时上限才给出有限值——**尾巴必须比 $\frac{1}{x}$ 衰减得快**。

**例 20**：$\displaystyle\int_1^{+\infty}\frac{dx}{x\sqrt{x^2+1}}$。

解：

1. $x\to+\infty$ 时被积函数 $\sim\dfrac{1}{x^2}$，$p=2>1$ → 收敛（先判敛，再动手）。
2. 令 $x=\dfrac{1}{t}$，$dx=-\dfrac{dt}{t^2}$，且 $\dfrac{1}{x\sqrt{x^2+1}}=\dfrac{t^2}{\sqrt{1+t^2}}$。
3. 原式 $=\displaystyle\int_0^1\frac{dt}{\sqrt{1+t^2}}=\Bigl[\ln\left(t+\sqrt{1+t^2}\right)\Bigr]_0^1$。

**答案** $\ln(1+\sqrt{2})$。

> **要点**：无穷限积分第一招是**倒代换把 $\infty$ 搬到 $0$**，$\int_1^\infty$ 变成 $\int_0^1$ 后按正常定积分算；$\int\frac{dt}{\sqrt{1+t^2}}=\ln(t+\sqrt{1+t^2})$ 必须背。

### 12.2 无界函数的反常积分（瑕积分）

**瑕点**：$f$ 在该点任意邻域内无界（$\frac{1}{\sqrt{x}}$ 在 $0$、$\frac{1}{x-1}$ 在 $1$）。若 $a$ 是瑕点：

$$\int_a^b f(x)\,dx=\lim_{\varepsilon\to0^+}\int_{a+\varepsilon}^b f(x)\,dx$$

区间**内部**有瑕点 $c$ 时必须拆成 $\int_a^c+\int_c^b$，两段都收敛才算收敛。

**例 21**：$\displaystyle\int_{1/2}^{3/2}\frac{dx}{\sqrt{|x-x^2|}}$。

解：

1. 分母在 $x=1$ 为零 → 瑕点 $x=1$，拆成 $\int_{1/2}^{1}+\int_{1}^{3/2}$。
2. 左段 $x<1$：$x-x^2=\dfrac{1}{4}-\left(x-\dfrac{1}{2}\right)^2$，令 $x-\dfrac{1}{2}=\dfrac{1}{2}\sin t$，被积式化为 $dt$，得 $\dfrac{\pi}{2}$。
3. 右段 $x>1$：$x^2-x=\left(x-\dfrac{1}{2}\right)^2-\dfrac{1}{4}$，令 $x-\dfrac{1}{2}=\dfrac{1}{2}\cosh u$，同样化为 $du$，得 $\operatorname{arcosh}2=\ln(2+\sqrt{3})$；两段相加。

**答案** $\dfrac{\pi}{2}+\ln(2+\sqrt{3})$。

> **易错点**：$\sqrt{x-x^2}$ 与 $\sqrt{x^2-x}$ 定义域不同，**必须按 $x<1$、$x>1$ 分别配方**，绝对值不能"约掉"；两段各自收敛才能相加，不能先合并再算。

### 12.3 收敛判别法：比较、p 积分、绝对收敛

**比较判别法（极限形式，只对非负被积函数有效，有正有负先看绝对收敛）**：设 $f(x)\ge0$，$\lim_{x\to+\infty}x^pf(x)=l$，则

- $0<l<+\infty$：与 $\int_1^\infty\frac{dx}{x^p}$ 同敛散，即 $p>1$ 收敛、$p\le1$ 发散；
- $l=0$ 且 $p>1$：收敛；
- $l=+\infty$ 且 $p\le1$：发散。

**瑕点版**：$\lim_{x\to a^+}(x-a)^pf(x)=l$，结论里把 $p>1$ 换成 $p<1$（尺子换成 $\int_0^1x^{-p}$）。

| 积分 | 收敛 | 发散 |
| --- | --- | --- |
| $\int_1^{+\infty}\frac{dx}{x^p}$ | $p>1$ | $p\le1$ |
| $\int_0^{1}\frac{dx}{x^p}$ | $p<1$ | $p\ge1$ |
| $\int_2^{+\infty}\frac{dx}{x\ln^{\beta}x}$ | $\beta>1$ | $\beta\le1$ |

**操作与注意**：分子、分母各取"最高阶项"做等价，定出 $p$ 再套表；**对数因子不改变幂次结论**——$\frac{1}{x\ln x}$ 比任何 $\frac{1}{x^{1+\varepsilon}}$ 慢、比 $\frac{1}{x}$ 快，可它恰好发散（原函数 $\ln\ln x$），所以 $\beta=1$ 是临界线。**绝对收敛**：$\int|f|$ 收敛 ⇒ $\int f$ 收敛；$\int_1^\infty\frac{\sin x}{x^2}dx$ 绝对收敛（$|\sin x|\le1$，比 $\frac{1}{x^2}$），$\int_1^\infty\frac{\sin x}{x}dx$ 只是**条件收敛**（Dirichlet：$\frac{1}{x}$ 单调趋于 $0$，$\sin x$ 部分和有界）。

**例 22（两端都是瑕点）**：判断 $\displaystyle\int_0^{+\infty}\frac{dx}{\sqrt{x}(1+x)}$ 的敛散性并求值。

解：

1. $x\to0^+$：被积函数 $\sim x^{-1/2}$，$p=\dfrac{1}{2}<1$ → 收敛。
2. $x\to+\infty$：被积函数 $\sim x^{-3/2}$，$p=\dfrac{3}{2}>1$ → 收敛。
3. 两端都收敛，故收敛，才允许算值：令 $x=t^2$、$dx=2t\,dt$，原式 $=\displaystyle\int_0^{+\infty}\frac{2\,dt}{1+t^2}=2\cdot\frac{\pi}{2}$。

**答案** 收敛，值为 $\pi$。

> **要点**：$0$ 端与 $+\infty$ 端要**分别判、分别算**；任一段发散整体就发散，绝不能"$\int_0^\infty$ 一步到位"。

### 12.4 典型例题

**例 23（倒代换合并区间）**：$\displaystyle\int_0^{+\infty}\frac{dx}{(1+x^2)(1+x^{10})}$。

解：

1. 拆成 $\int_0^1+\int_1^\infty$；第二段令 $x=\dfrac{1}{u}$，得 $\displaystyle\int_0^1\frac{u^{10}\,du}{(1+u^2)(1+u^{10})}$。
2. 两段变量统一写成 $t$ 后合并：$\displaystyle\int_0^1\frac{1+t^{10}}{(1+t^2)(1+t^{10})}dt=\int_0^1\frac{dt}{1+t^2}$。
3. $=\Bigl[\arctan t\Bigr]_0^1$。

**答案** $\dfrac{\pi}{4}$。

> **要点**：$\int_0^\infty$ 且被积函数在 $x\mapsto\frac{1}{x}$ 下"分母首尾对称"时，倒代换后两段能拼成同一分母，$1+t^{10}$ 直接约掉——不这样做几乎算不动。

**高斯积分（结论直接用）**：$\displaystyle\int_0^{+\infty}e^{-x^2}dx=\frac{\sqrt{\pi}}{2}$、$\displaystyle\int_{-\infty}^{+\infty}e^{-x^2}dx=\sqrt{\pi}$——把 $I^2$ 写成二重积分、极坐标算出 $\frac{\pi}{4}$，再用"正方形夹在两圆之间"夹逼。计算三条：无穷限优先**倒代换**搬到有限区间，或**先算不定积分再取极限**（$\int_0^\infty e^{-x}\sin x\,dx=\frac{1}{2}$：分部两次回到自身，解方程再取极限）；瑕积分**在瑕点切开**，配方后用 $\arcsin$ 或 $\ln$ 型原函数；**收敛性不明的先判后算**。

## 13. 本节重点

> **本节重点**：
> - 要点 1：**不定积分必须加 $C$**；定积分是具体数字（牛顿–莱布尼兹）。
> - 要点 2：换元积分法核心是**发现"函数与其导数同框"**（$\sin$/$\cos$、根号/根号分之一、$e^x$），凑微分时**微分内变量必须与换元变量一致**；缺东西就"加项减项"补。
> - 要点 3：三角换元去根号三表：$\sqrt{a^2-x^2} \to x=a\sin t$、$\sqrt{a^2+x^2} \to x=a\tan t$、$\sqrt{x^2-a^2} \to x=a\sec t$；换元要算 $dx$，算完**用直角三角形回代**。
> - 要点 4：分部积分"**反对幂指三**"选 $U$；单个函数也可当 $U\,dV$（$V=x$）；先换元去根号后再分部的组合拳要熟。
> - 要点 5：有理函数积分——分母乘积就拆分（一次配常数、二次配一次式、高次逐项拆）；求系数用"令分母为零代入" + 特殊值法。
> - 要点 6：定积分应用公式要背：面积（直角/参数/极坐标）、弧长（三种）、旋转体（绕 $x$ 轴 $\pi\int f^2$，绕 $y$ 轴互换）；**旋转曲面面积** $S=2\pi\int d\,ds$，绕一般直线时 $d=\lvert Ax+By+C\rvert/\sqrt{A^2+B^2}$，先去绝对值再积分。
> - 要点 7：**"狗咬狗"型积分**——被积函数是 $(uv)'$ 的一半一半，拆成两个积分、对其中一个分部积分，产物与另一个抵消，答案就是 $uv$；凑不出微分就用**硬凑**（单独对被凑因子做一次不定积分）。
> - 要点 8：**积分恒等式**两个证法——交换积分次序 + 区域对称性（$\iint_D + \iint_{D'}$ = 整个正方形）、或变限积分凑平方（$f(x)\int_x^b f = -\frac{1}{2}\left[(\int_x^b f)^2\right]'$）。
> - 要点 9：**积分不等式**通用套路——上限换成 $x$ 造变限函数、求导转单调性；比较那一步多半是**柯西不等式**；几何背景（弧长 ≥ 弦长）能先拿下取等条件。
> - 要点 10：换元不止三角——$\sqrt{ax+b}$ 整体换元、分母高次用 $x=\frac{1}{t}$、隐函数用 $t=\frac{y}{x}$ 参数化，三种都把问题降成多项式或有理式积分。
> - 要点 11：牛顿–莱布尼兹公式在 $F$ 端点无定义时**必须取极限**，这正是反常积分的定义。
> - 要点 12：$f(x)=$ 已知函数 $+\int_a^b f$ 型，把定积分**设成常数 $A$**，代回积分一次解方程，最后换成数值。
> - 要点 13：对称区间先拆奇偶（奇 $0$、偶 $2\int_0^a$）；$\int_0^\pi xf(\sin x)dx=\frac{\pi}{2}\int_0^\pi f(\sin x)dx$ 是区间再现最常用的一格。
> - 要点 14：周期函数按整周期分块，$\int_0^{nT}=n\int_0^T$，余项用夹逼；$|\sin t|$ 那题答案是 $\frac{2}{\pi}$。
> - 要点 15：Wallis——偶次乘 $\frac{\pi}{2}$、奇次不乘；先化到 $\int_0^{\pi/2}$ 再用。
> - 要点 16：两把尺子：$\int_1^\infty x^{-p}$ 收敛 $\iff p>1$；$\int_0^1 x^{-p}$ 收敛 $\iff p<1$。判敛 = 定阶 + 套尺子，对数因子只在 $\beta=1$ 这条线上起作用。
> - 要点 17：区间内有瑕点必须**拆段**，每段独立判敛；$\int_0^\infty$ 要两端都收敛。
> - 要点 18：$\int|f|$ 收敛 ⇒ $\int f$ 收敛；$\frac{\sin x}{x^2}$ 绝对收敛，$\frac{\sin x}{x}$ 仅条件收敛。
> - **常见坑**：不定积分忘加 $C$；换元后 $dx$ 直接写成 $dt$；分部积分选错 $U$（指数/三角当了 $U$ 越积越复杂）；有理函数分母高次只拆一项；极坐标面积忘 $\frac{1}{2}$；旋转曲面面积忘 $2\pi$ 或漏去绝对值；"狗咬狗"里忘回代换元变量。
> - **补充坑**：倒代换丢负号；$\sqrt{|x-x^2|}$ 不分区就配方；瑕积分直接代上下限（应为极限）；对会变号的 $\sin x$ 做等价替换；把 $\int_1^\infty\frac{dx}{x\ln x}$ 当成收敛。
