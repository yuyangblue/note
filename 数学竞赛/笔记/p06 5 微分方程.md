## 1. 基本概念

| 概念 | 定义 |
|------|------|
| 微分方程 | 含有**未知函数及其导数**的方程（必须含有导数） |
| 阶 | **最高阶导数**的阶数（二阶方程最多出现二阶导） |
| 通解 | 含任意常数 $C$ 的解 |
| 特解 | 由**初始条件**确定 $C$ 后得到的解 |

> **直观理解**：有任意常数 $C$ 说明求解离不开**不定积分**——所以解微分方程的过程里到处要加 $C$。

## 2. 可分离变量型

**形式**：$\dfrac{dy}{dx} = f(x)\cdot g(y)$——特征是两个"泾渭分明"：①导数在左边、函数和自变量在右边；②右边的 $x$ 是一堆、$y$ 是一堆，**互不纠缠**。

**解法**：分离变量，两边同时积分。

$$\frac{dy}{g(y)} = f(x)\,dx \;\Longrightarrow\; \int\frac{dy}{g(y)} = \int f(x)\,dx$$

## 3. 齐次型

**形式**：$\dfrac{dy}{dx} = f\left(\dfrac{y}{x}\right)$——右边 $x$、$y$ 以 $\dfrac{y}{x}$ 的形式**捏在一起**出现（$x$、$y$ 都是一次，所以叫"齐次"）。

**解法**：换元 $u = \dfrac{y}{x}$ ⟹ $y = ux$，则

$$\frac{dy}{dx} = u + x\frac{du}{dx} = f(u)$$

化为 $x\dfrac{du}{dx} = f(u) - u$——**变成可分离变量型**。解出 $u$ 后**回代 $y = ux$**。

**例 1**：解 $\dfrac{dy}{dx} = \dfrac{y}{x} + \tan\dfrac{y}{x}$。

解：令 $u = \dfrac{y}{x}$，则 $\dfrac{dy}{dx} = u + xu'$，方程化为 $xu' = \tan u$。

$$\frac{du}{\tan u} = \frac{dx}{x} \;\Longrightarrow\; \int\frac{\cos u}{\sin u}du = \int\frac{dx}{x} \;\Longrightarrow\; \ln|\sin u| = \ln|x| + C$$

把 $C$ 写成 $\ln C$ 合并：$\sin u = Cx$，回代 $u = \dfrac{y}{x}$：**$\sin\dfrac{y}{x} = Cx$**（隐函数形式的解）。

> **易错点**：解出来的是 $u$，原方程要的是 $y$——**最后别忘把 $u$ 换回 $\dfrac{y}{x}$**。

## 4. 一阶线性微分方程

**标准形式**：

$$\frac{dy}{dx} + P(x)\,y = Q(x)$$

- $Q(x) = 0$：**齐次**——移项后变成可分离变量型（$y' = -P(x)y$）。
- $Q(x) \ne 0$：**非齐次**——直接套通解公式：

$$y = e^{-\int P\,dx}\left[\int Q\,e^{\int P\,dx}\,dx + C\right]$$

> **直观理解**：非齐次一阶线性方程的本质就是**算两个积分**（$\int P\,dx$ 和 $\int Qe^{\int P}dx$），算完套公式。公式要背熟。

**关键变形思路**：把方程凑成标准形式时，**要让导数 $\frac{dy}{dx}$ 周围"干干净净"**（不乘别的函数），系数都并进 $P(x)$。

## 5. 真题：多次换元化一阶线性

**真题 2（第 14 届）**：解微分方程（含 $\sin y$、$\cos y$、$\ln x$ 的复杂方程）。

> 原方程：$\sin y\,\dfrac{dy}{dx} + \dfrac{\cos y - x\cos^2 y}{x\ln x} = 0$（即 $x\ln x\sin y\,dy + (\cos y - x\cos^2 y)dx = 0$）。

解（核心是**通过换元逐步凑成一阶线性非齐次**）：

1. 两边同除 $x\ln x$，让导数旁边变干净：

$$\sin y\frac{dy}{dx} + \frac{\cos y}{x\ln x} - \frac{\cos^2 y}{\ln x} = 0$$

2. **第一次换元** $u = \cos y$：$\dfrac{du}{dx} = -\sin y\dfrac{dy}{dx}$，代入得

$$\frac{du}{dx} - \frac{u}{x\ln x} = -\frac{u^2}{\ln x}$$

3. 右边还含 $u$（不满足标准形式）→ **两边同除 $u^2$**，并发现 $\dfrac{d}{dx}\left(\dfrac{1}{u}\right) = -\dfrac{u'}{u^2}$：

**第二次换元** $w = \dfrac{1}{u}$：

$$\frac{dw}{dx} + \frac{w}{x\ln x} = \frac{1}{\ln x}$$

4. 现在是一阶线性非齐次：$P = \dfrac{1}{x\ln x}$，$Q = \dfrac{1}{\ln x}$。$\displaystyle\int P\,dx = \ln|\ln x|$（凑微分 $d\ln x = \frac{dx}{x}$）。

$$w = e^{-\ln\ln x}\left[\int\frac{1}{\ln x}\,e^{\ln\ln x}dx + C\right] = \frac{1}{\ln x}\bigl[x + C\bigr]$$

5. **依次回代**：$w = \dfrac{1}{u}$、$u = \cos y$ ⟹ $\dfrac{1}{\cos y} = \dfrac{x+C}{\ln x}$，即

$$\boxed{(x + C)\cos y = \ln x}$$

> **要点**：本题最大难点是**通过两次换元把复杂方程凑成一阶线性形式**——回代时也要按 $w \to u \to y$ 逆序换回，别漏。

## 6. 真题：变限积分 ⟹ 微分方程

**真题 3**：设可导函数 $f(x)$ 满足 $f(x)\cos x + 2\displaystyle\int_0^x f(t)\sin t\,dt = x + 1$，求 $f(x)$。

解：

1. **变限积分生来就是要被求导的**——先两边求导（前导后不导 $+$ 变限积分求导）：

$$f'(x)\cos x - f(x)\sin x + 2f(x)\sin x = 1 \;\Longrightarrow\; f'(x)\cos x + f(x)\sin x = 1$$

2. 整理成标准一阶线性非齐次（同除 $\cos x$，让导数干净）：

$$f'(x) + \tan x\cdot f(x) = \sec x$$

3. 套公式：$P = \tan x$，$\int P\,dx = -\ln|\cos x|$（凑微分）。$e^{-\int P} = e^{\ln\cos x} = \cos x$。

$$f(x) = \cos x\left[\int \sec x\cdot\frac{1}{\cos x}dx + C\right] = \cos x\left[\int\sec^2 x\,dx + C\right] = \cos x(\tan x + C) = \sin x + C\cos x$$

4. **初始条件定 $C$**：原方程代入 $x = 0$（变限积分为 $0$）：$f(0)\cos 0 = 1$ ⟹ $f(0) = 1$ ⟹ $C = 1$。

$$\boxed{f(x) = \sin x + \cos x}$$

> **套路**：看到"可导函数 + 变限积分 + 等式"→ 先求导把积分消掉，变成微分方程；**通解求完后用 $x=0$ 代入原方程找初始条件**（变限积分取零下限时自动为 $0$），从而求特解。

## 7. 二阶常系数线性方程（齐次）

**标准形式**：$y'' + py' + qy = f(x)$，其中 $p$、$q$ 为**常数**（区别于一般一阶线性，系数不一定常数）。

**齐次（$f(x) = 0$）解法**：写**特征方程** $r^2 + pr + q = 0$（二阶导 → $r^2$，一阶导 → $r$，$y$ → $1$），按根的情况套通解：

| 特征根情况 | 判别式 | 通解 |
|------------|--------|------|
| 两个不同实根 $r_1 \ne r_2$ | $\Delta > 0$ | $y = C_1e^{r_1x} + C_2e^{r_2x}$ |
| 重根 $r_1 = r_2 = r$ | $\Delta = 0$ | $y = (C_1 + C_2x)e^{rx}$ |
| 共轭复根 $r = \alpha \pm \beta i$ | $\Delta < 0$ | $y = e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$ |

> 非齐次时先解特征方程，**顺便得到齐次通解**（两个根 $r_1, r_2$），下一步再求特解。

## 8. 二阶常系数线性方程（非齐次）

**核心原则（与线性代数一致）**：

$$\text{非齐次通解} = \text{对应齐次通解} + \text{非齐次特解}$$

**难点在求特解**。课本标准方法（$f(x) = e^{\lambda x}P_m(x)$ 型，$P_m$ 是 $m$ 次多项式）：

$$y^* = x^k\,e^{\lambda x}\,Q_m(x)$$

其中 $Q_m(x)$ 是与 $P_m(x)$ 同次的**待定多项式**（系数待求）；$k$ 按 $\lambda$ 与特征根的关系取：

| $\lambda$ 与特征根的关系 | $k$ |
|--------------------------|-----|
| $\lambda$ **不是**特征根 | $0$ |
| $\lambda$ 是**单**特征根 | $1$ |
| $\lambda$ 是**重**特征根 | $2$ |

把 $y^*$ 求一阶、二阶导**代回原方程**，比较系数逐个确定 $Q_m$ 的系数（运算量大但机械）。

## 9. 真题：观察法求二阶非齐次特解

**真题 4（第 13 届）**：二阶常系数非齐次方程 $y'' + 14y' + 13y = f(x)$（$f$ 未给出具体形式），分析其微分方程部分的解法。

解：

1. **齐次通解**：特征方程 $r^2 + 14r + 13 = 0$ ⟹ $(r+1)(r+13) = 0$ ⟹ $r = -1,\,-13$：

$$y_{\text{齐}} = C_1e^{-x} + C_2e^{-13x}$$

2. **观察拆分降阶**（$f$ 未知，不能用待定系数法）：注意到 $14 = 13 + 1$，把方程拆成两种方式：

$$y'' + y' + 13(y' + y) = f(x), \qquad y'' + 13y' + (y' + 13y) = f(x)$$

3. **两次换元降阶**：令 $Y_1 = y' + y$、$Y_2 = y' + 13y$，分别得到两个一阶方程：

$$Y_1' + 13Y_1 = f(x), \qquad Y_2' + Y_2 = f(x)$$

4. 分别套一阶线性公式解出（用变限积分表示，$f$ 未知）：

$$Y_1 = e^{-13x}\int_0^x f(t)e^{13t}dt, \qquad Y_2 = e^{-x}\int_0^x f(t)e^{t}dt$$

5. **两个方程、两个未知数**（$y$ 与 $y'$），令任意常数为 $0$ 联立解出 $y$——即非齐次**特解**。

> **要点**：当 $f(x)$ 不是标准型（未给出）时，通过把系数拆成和、凑出"导数关系"（$y'+y$ 与 $y''+y'$）**把二阶降成一阶**；两个方向各得到一个一阶方程，联立解出特解。这是竞赛中求非齐次特解的重要思路。

## 10. 解微分方程的通法：先判类型，再上"三板斧"

> 本节的通法总结与 §11、§12 的真题，来自 B站「epsilon-delta_」的 CMC 初赛精选题串讲（原始材料：`数学竞赛/原始材料/BV1cYWb62Emn/`）。

拿到一个微分方程，**第一件事是判类型**：是不是已经见过的标准型？

| 标准型 | 判别特征 | 解法 |
|--------|----------|------|
| 可分离变量 | $y' = f(x)g(y)$，$x$、$y$ 互不纠缠 | 分离后两边积分 |
| 齐次型 | $y' = f\left(\dfrac{y}{x}\right)$ | 令 $u = \dfrac{y}{x}$ |
| 一阶线性 | $y' + P(x)y = Q(x)$ | 套通解公式 |
| 伯努利方程 | $y' + P(x)y = Q(x)y^{n}$ | 令 $z = y^{1-n}$ 化为一阶线性 |
| 二阶常系数 | $y'' + py' + qy = f(x)$ | 特征方程 + 特解 |

是标准型就照着做。**但竞赛题（以及难一点的考研题）基本不会走这条路**——给出来就是一坨 $x$、$y$、$\sin y$、$\ln x$ 混在一起的式子。这时按顺序试下面三招。

### 10.1 第一板斧：变换视角

我们习惯把 $y$ 看成 $x$ 的函数。整理不下去时，**改把 $x$ 看成 $y$ 的函数**，方程改写 $\dfrac{dx}{dy}$ 的形式再看一遍。

> **本质**：命题人最省力的出题手法就是"把 $x$ 和 $y$ 的字母互换"——原本标准的方程换个字母就显得陌生了。视角一换，隐藏的标准型就露出来了。

### 10.2 第二板斧：找"某部分求导是另一部分"

**这是考得最多的一招**，几乎年年出现。在一堆项里观察导数关系：

| 观察到的结构 | 对应的导数关系 |
|--------------|----------------|
| $y^2$ 与 $yy'$ | $(y^2)' = 2yy'$ |
| $\cos y$ 与 $y'\sin y$ | $(\cos y)' = -y'\sin y$ |
| $\dfrac{1}{p}$ 与 $\dfrac{p'}{p^2}$ | $\left(\dfrac{1}{p}\right)' = -\dfrac{p'}{p^2}$ |
| $\ln y$ 与 $\dfrac{y'}{y}$ | $(\ln y)' = \dfrac{y'}{y}$，$(\ln y)'' = \dfrac{yy''-(y')^2}{y^2}$ |
| 两项乘积 $uv$ | $(uv)' = u'v + uv'$ |

认出关系就**把那一部分整体记成新变量**，方程立刻降成标准型（见 §11 两题）。

### 10.3 第三板斧：换元

| 换元 | 适用场合 |
|------|----------|
| $u = \dfrac{y}{x}$，或 $u = \dfrac{y-y_0}{x-x_0}$ | 齐次结构 |
| $u = \cos y$、$u = \sin y$ | 三角函数与 $y'$ 纠缠在一起 |
| $u = \dfrac{1}{y}$、$u = \dfrac{1}{y^{k}}$ | 出现 $y^2$、$y^{n}$ 与 $y'$ 同框 |
| $u = ax+by+c$ | 形如 $y' = f(ax+by+c)$ |
| $u = y^2$、$u = \ln y$ | $y^2$、$\ln y$ 与导数同框（§11 两题的正解） |

> **考场策略**：三板斧砍完还不行，就该放掉这题去拿别处的分。微分方程的分数是靠"第一条路走不通就立刻换路"挣来的，不是靠死磕。

## 11. 真题：识别"求导关系"完成换元

**真题 5（第 13 届初赛）**：解方程 $(x^3-y^2)dx + (x^2y+xy)dy = 0$。

解：

1. **先按常规思路试**：两边同除 $dx$，化成 $x^3-y^2+(x^2y+xy)y'=0$，想整理成一阶线性——但 $x^3$、$x^2y$、$xy$ 里的 $x$ 与 $y$ 怎么都分不干净，**这条路走不通**。
2. **再试全微分**：$P = x^3-y^2$，$Q = x^2y+xy$，则 $\dfrac{\partial Q}{\partial x} = 2xy+y$，$\dfrac{\partial P}{\partial y} = -2y$，两者不等，不是全微分方程。**这条路也走不通**。
3. **找导数关系**：看到 $y^2$ 与 $yy'$，立刻想到 $(y^2)' = 2yy'$。令 $p = y^2$，则 $p' = 2yy'$，代入得

$$x^3 - p + \frac{x^2+x}{2}p' = 0 \;\Longrightarrow\; p' - \frac{2}{x^2+x}p = -\frac{2x^3}{x^2+x}$$

4. 已成标准一阶线性，其中 $P = -\dfrac{2}{x(x+1)}$，$Q = -\dfrac{2x^2}{x+1}$。先算 $\displaystyle\int P\,dx = -2\ln x + 2\ln(x+1) = \ln\frac{(x+1)^2}{x^2}$，于是

$$e^{\int P} = \frac{(x+1)^2}{x^2}, \qquad e^{-\int P} = \frac{x^2}{(x+1)^2}, \qquad Qe^{\int P} = -2(x+1)$$

5. 套通解公式：

$$p = \frac{x^2}{(x+1)^2}\left[\int -2(x+1)\,dx + C\right] = \frac{x^2}{(x+1)^2}\left[C - (x+1)^2\right] = -x^2 + \frac{Cx^2}{(x+1)^2}$$

6. **回代** $p = y^2$，并整理成整式形式：

$$(x+1)^2(x^2+y^2) = Cx^2$$

> **要点**：一阶线性公式里 $e^{\int P}$ 与 $e^{-\int P}$ 互为倒数，**先把 $\int P$ 算干净再代**，符号就不容易错。另外，前面两次试错（分离变量、全微分）不是浪费——排除法本身也是解题的一部分。

**真题 6（第 15 届决赛第一题）**：解方程 $yy'' - (y')^2 = y^2\ln y$。

解：

1. 二阶、非线性、还带 $\ln y$，标准型里没有它。**找导数关系**：$\dfrac{yy''-(y')^2}{y^2}$ 正是 $(\ln y)''$。
2. 两边同除 $y^2$：

$$(\ln y)'' = \ln y$$

3. 令 $u = \ln y$，方程变成二阶常系数齐次 $u'' - u = 0$，特征根 $\lambda = \pm 1$，故 $u = C_1e^{x} + C_2e^{-x}$。
4. **回代**：

$$y = e^{C_1e^{x} + C_2e^{-x}}, \quad C_1,\,C_2 \text{ 为任意常数}$$

> **要点**：二阶方程不一定非要"降阶"。本题的关键是看出**左边除以 $y^2$ 恰好是 $\ln y$ 的二阶导**——把"非线性"整体换元后，它其实是课本上最规矩的二阶常系数齐次（详见 §7）。

## 12. 真题：证明微分方程的解有界

**真题 7（第 14 届）**：设 $f(x)$ 在 $[0,+\infty)$ 上连续且**有界**（存在 $M>0$ 使 $|f(x)|\le M$）。证明方程

$$y'' + 14y' + 13y = f(x)$$

的**每一个**解在 $[0,+\infty)$ 上都是有界函数。

解：

1. **先把"每一个解"拆成齐次通解 + 一个特解**。特征方程 $\lambda^2+14\lambda+13 = (\lambda+1)(\lambda+13) = 0$ ⟹ $\lambda = -1,\,-13$，齐次通解 $C_1e^{-x} + C_2e^{-13x}$ 在 $[0,+\infty)$ 上显然有界。**于是只需证特解有界。**
2. **拆系数降阶**：$f$ 是抽象函数，待定系数法用不上；注意 $14 = 1 + 13$，把方程拆成

$$(y'+y)' + 13(y'+y) = f(x)$$

3. 令 $p = y'+y$，得 $p' + 13p = f(x)$。用**带上下限**的一阶线性解公式（下限 $0$、上限 $x$）：

$$p(x) = e^{-13x}\left[p(0) + \int_0^{x}e^{13t}f(t)\,dt\right]$$

4. **取绝对值放缩**（这一步是主要得分点）：由 $|f(t)|\le M$ 且 $e^{13t}>0$，

$$|p(x)| \le e^{-13x}|p(0)| + e^{-13x}M\int_0^{x}e^{13t}dt = \frac{M}{13} + \left(|p(0)| - \frac{M}{13}\right)e^{-13x} \le \frac{M}{13} + |p(0)| =: K$$

即 $p$ 在 $[0,+\infty)$ 上有界。
5. **再解一层**：由 $y'+y = p$，两边乘 $e^{x}$ 得 $(e^{x}y)' = e^{x}p$，积分：

$$e^{x}y(x) = y(0) + \int_0^{x}e^{t}p(t)\,dt$$

6. 再放缩：$|e^{x}y(x)| \le |y(0)| + K(e^{x}-1)$，两边除 $e^{x}$：

$$|y(x)| \le |y(0)|e^{-x} + K(1 - e^{-x}) \le |y(0)| + K$$

7. 齐次通解有界、特解有界 ⟹ 方程每一个解有界。证毕。

> **要点**：这类题两个硬基本功——① 会写**带上下限的一阶线性解公式**（否则解不出抽象的特解）；② 会把二阶拆成两层一阶、**逐层放缩**。$p(0)$、$y(0)$ 是某一个具体解在 $0$ 处的值，都是有限的常数，可以放心当成常数放进界里。

## 13. 补充（周老师课）：常微分方程

> 本节内容来自 B站「周老师带你学数竞」《大学生数学竞赛四小时突击速成课》P14「常微分方程」（原始材料：`数学竞赛/原始材料/BV15Qe76cE6W/`）。
> 前面 §1–§12 已把"识别 + 三板斧"讲透，这一节补具体手法模板：常数变易法、准齐次平移、伯努利、主次调换、全微分求原函数、二阶重根特解。

### 13.1 拿到方程先归类：六种模板各配一句口诀

| 类型 | 认出它的标志 | 一句口诀 |
| --- | --- | --- |
| 一阶线性 | $y'+P(x)y=Q(x)$，$y$、$y'$ 都是一次 | 套公式；或**常数变易法**现场推 |
| 齐次 | $y'=f\left(\dfrac{y}{x}\right)$，$x,y$ 同次 | 令 $u=\dfrac{y}{x}$，除完捡回 $u=0$、$u=1$ |
| 准齐次 | $y'=\dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2}$，上下一次 | 先平移消常数，再当齐次做 |
| 伯努利 | $y'+P(x)y=Q(x)y^{n}$ | 除 $y^{n}$，令 $u=y^{1-n}$ |
| 主次调换 | $y^2$、$e^y$、$\sin y$ 与 $x$ 相加，对 $y$ 解不动 | 把 $x$ 当函数，写 $\dfrac{dx}{dy}$ |
| 全微分 | $P\,dx+Q\,dy=0$ 且 $P_y=Q_x$ | 求原函数 $u$，通解 $u=C$ |

> **试的顺序**：先看能否分离（最省事）→ 是否线性/伯努利 → 不行就翻主次 → 最后试全微分。准齐次与齐次只差一次平移，算同一类。

### 13.2 常数变易法：不背公式也能出答案

**例题 13-1**：解初值问题 $y'=xy+xe^{x^2}$，$y(0)=1$。

解：

1. 先解齐次方程 $y'=xy$：分离变量得 $\ln\lvert y\rvert=\dfrac{x^2}{2}+C$，故 $y=Ce^{x^2/2}$。
2. **常数变易**：把 $C$ 换成待定函数 $C(x)$，令 $y=C(x)e^{x^2/2}$，则

$$y'=C'(x)e^{x^2/2}+C(x)\,x\,e^{x^2/2}$$

3. 代回原方程，右端为 $C(x)\,x\,e^{x^2/2}+xe^{x^2}$。两边相减，**含 $C(x)$ 的齐次项整块抵消**（必然的，$Ce^{x^2/2}$ 本来就解齐次方程），只剩

$$C'(x)e^{x^2/2}=xe^{x^2}\ \Longrightarrow\ C'(x)=x\,e^{x^2/2}\ \Longrightarrow\ C(x)=e^{x^2/2}+C_1$$

4. 通解 $y=\left(e^{x^2/2}+C_1\right)e^{x^2/2}=e^{x^2}+C_1e^{x^2/2}$；代 $y(0)=1$ 得 $1+C_1=1$，即 $C_1=0$。

**答案 $y=e^{x^2}$**。

> **要点**：第 3 步**不用真展开**——代回后齐次部分必抵消，可直接写"$C'(x)\cdot(\text{齐次解})=\text{非齐次项}$"。这是所有一阶线性公式的来源，忘了公式可现场推。

### 13.3 齐次与准齐次：换元后都是可分离

**例题 13-2**：(1) 解 $y'=\left(\dfrac{y}{x}\right)^2$；(2) 解 $y'=\dfrac{2(y+2)}{x-1}$。

解：

**(1)** 令 $u=\dfrac{y}{x}$（即 $y=ux$，$y'=u+xu'$），代入得 $xu'=u^2-u=u(u-1)$。分离变量（$\dfrac{1}{u(u-1)}=\dfrac{1}{u-1}-\dfrac{1}{u}$）并积分：

$$\ln\left\lvert\frac{u-1}{u}\right\rvert=\ln\lvert x\rvert+C\ \Longrightarrow\ \frac{u-1}{u}=C_1x\ \Longrightarrow\ u=\frac{1}{1-C_1x}$$

回代 $u=\dfrac{y}{x}$，得 $y=\dfrac{x}{1-C_1x}$。

**补丢解**：分离时除了 $u(u-1)$，须单独检查 $u=0$（即 $y=0$）与 $u=1$（即 $y=x$）。两者代回都成立；$y=x$ 含在 $C_1=0$ 中，但**$y=0$ 是漏掉的解，必须补写**。

**(2)** 上下都是一次、常数项不为零 → **平移消常数**：令 $X=x-1$、$Y=y+2$（平移不改导数），方程变齐次 $\dfrac{dY}{dX}=\dfrac{2Y}{X}$。再令 $U=\dfrac{Y}{X}$，得 $U+XU'=2U$，即 $\dfrac{dU}{U}=\dfrac{dX}{X}$，故 $U=CX$，回代得 $y+2=C(x-1)^2$（丢掉的 $U=0$ 即 $y=-2$，含在 $C=0$ 中）。

**答案 (1) $y=\dfrac{x}{1-Cx}$ 及 $y=0$；(2) $y=C(x-1)^2-2$**。

> **易错点**：齐次方程分离时一定除一个含 $u$ 的因子，**除掉的零点就是丢掉的解**——竞赛解答漏写 $y=0$ 是常见扣分点。
> **补充**：若准齐次的两行系数成比例（$a_2:b_2=a_1:b_1$），平移消不掉常数，改令 $u=a_1x+b_1y$ 直接降成可分离。

### 13.4 伯努利方程：换元后正好是一阶线性

**例题 13-3**：解 $y'=y+y^3$。

解：

1. 写成标准形 $y'-y=y^3$，是 $n=3$ 的伯努利方程。**先看 $y\equiv0$**：代入两边皆为 $0$，成立，记下这个解。
2. $y\ne0$ 时两边同除 $y^3$ 得 $y^{-3}y'-y^{-2}=1$；令 $u=y^{-2}$，则 $u'=-2y^{-3}y'$，代入得

$$-\frac{u'}{2}-u=1\ \Longrightarrow\ u'+2u=-2$$

3. 一阶线性（$P=2$，$Q=-2$），套公式：

$$u=e^{-2x}\left[\int(-2)e^{2x}dx+C\right]=e^{-2x}\left[-e^{2x}+C\right]=Ce^{-2x}-1$$

4. 回代 $u=y^{-2}$，得 $y^{2}\left(Ce^{-2x}-1\right)=1$。

**答案 $y^2\left(Ce^{-2x}-1\right)=1$ 及 $y=0$**。

> **要点**：标准换元是 $u=y^{1-n}$（$n=3$ 时即 $y^{-2}$），换完必落到一阶线性。**除 $y^n$ 之前先声明 $y=0$ 是解**，否则漏解。代回求导可自查符号（本题已验证残差为 $0$）。

### 13.5 调换 $x$、$y$ 的主次

**例题 13-4**：解 $\dfrac{dy}{dx}=\dfrac{y}{x+y^2}$。

解：

1. 右端对 $y$ 是二次，按"$y$ 是 $x$ 的函数"整理不成任何标准型。**反过来看**：把 $x$ 当未知函数、$y$ 当自变量，取倒数

$$\frac{dx}{dy}=\frac{x+y^2}{y}=\frac{x}{y}+y$$

2. 这是关于 $x(y)$ 的一阶线性 $x'-\dfrac{1}{y}x=y$：$P=-\dfrac{1}{y}$，$Q=y$，且 $\displaystyle\int P\,dy=-\ln\lvert y\rvert$，故积分因子 $e^{-\int P}=y$。
3. 套公式：

$$x=y\left[\int y\cdot\frac{1}{y}\,dy+C\right]=y\left[y+C\right]=y^2+Cy$$

4. 取倒数时分掉了 $y$，须补检 $y\equiv0$：代入原方程两边皆为 $0$，成立。

**答案 $x=y^2+Cy$，以及 $y=0$**。

> **要点**：什么时候该翻主次？只要 $y^2$、$e^y$、$\sin y$、$\ln y$ 与 $x$ **相加**（不是相乘）、而 $x$ 只以一次形式出现，翻过来几乎一定是一阶线性。翻转后自变量是 $y$，积分因子对 $y$ 积。

### 13.6 全微分方程：求原函数 $u$

**例题 13-5**：解 $\left(2x+ye^{xy}\right)dx+\left(xe^{xy}+2y\right)dy=0$。

解：

1. **先验恰当性**：$P=2x+ye^{xy}$，$Q=xe^{xy}+2y$，则 $P_y=e^{xy}+xye^{xy}=Q_x$，故存在 $u$ 使 $du=P\,dx+Q\,dy$，方程即 $du=0$。
2. 对 $P$ 关于 $x$ 积分（$y$ 当常数，$\displaystyle\int ye^{xy}dx=e^{xy}$）：

$$u=x^2+e^{xy}+\varphi(y)$$

3. 再对 $y$ 求偏导与 $Q$ 对照：$u_y=xe^{xy}+\varphi'(y)=xe^{xy}+2y$，故 $\varphi'(y)=2y$，$\varphi(y)=y^2+C_0$。
4. 于是 $u=x^2+y^2+e^{xy}$，通解 $u=C$。

**答案 $x^2+y^2+e^{xy}=C$**。

> **要点**：三步走——**验 $P_y=Q_x$ → 积一个、偏导定另一个 → 写 $u=C$**。视频还给了快法：$P$ 对 $x$ 积、$Q$ 对 $y$ 积，两份结果的**公共项**必在 $u$ 中（此处是 $e^{xy}$，再把各自独占的 $x^2$、$y^2$ 收进来），最后求导检验兜底。

### 13.7 二阶非齐次：$\lambda$ 恰是重根

**例题 13-6**：求 $y''-2y'+y=e^{x}$ 的通解。

解：

1. 特征方程 $r^2-2r+1=(r-1)^2=0$，二重根 $r=1$，齐次通解 $y_{\text{齐}}=(C_1+C_2x)e^{x}$。
2. 右端 $\lambda=1$ **恰是二重特征根** ⟹ $k=2$，特解设 $y^{*}=Ax^2e^{x}$（不是特征根设 $Ae^x$，单根设 $Axe^x$——重复几次乘几个 $x$）。
3. 求导：$y^{*\prime}=A(2x+x^2)e^{x}$，$y^{*\prime\prime}=A(2+4x+x^2)e^{x}$。代回左端：

$$Ae^{x}\left[(2+4x+x^2)-2(2x+x^2)+x^2\right]=2Ae^{x}=e^{x}\ \Longrightarrow\ A=\frac{1}{2}$$

（$x$、$x^2$ 项全消只剩常数 $2$，这正是"重根"的代数表现。）
4. 通解 $=$ 齐次通解 $+$ 特解。

**答案 $y=(C_1+C_2x)e^{x}+\dfrac{1}{2}x^{2}e^{x}$**。

> **要点**：$k$ 只由"$\lambda$ 是几重特征根"决定。重根时代回后 $x$ 的低次项全部抵消，只剩 $(D-\lambda)^k$ 作用在 $x^k$ 上产生的常数因子 $k!$（二重根出 $2!=2$，三重根出 $3!=6$）——这也是为什么要乘 $x^2$：不乘的话代回左边直接是 $0$，凑不出右端。

## 14. 本节重点

> **本节重点**：
> - 要点 1：**可分离变量**（$y' = f(x)g(y)$，XY 泾渭分明）→ 分离后两边积分；**齐次型**（$y' = f(y/x)$）→ 令 $u = y/x$ 化可分离，解完回代。
> - 要点 2：**一阶线性** $y' + P(x)y = Q(x)$——齐次化可分离；非齐次**套公式** $y = e^{-\int P}\left[\int Qe^{\int P}dx + C\right]$（本质是两个积分）；变形时让导数周围"干净"。
> - 要点 3：**变限积分方程先求导**消积分，变成微分方程；求特解用 $x=0$ 代入原方程找初始条件。
> - 要点 4：**二阶常系数齐次**：特征方程 $r^2+pr+q=0$ 三情况（两异实根、重根、共轭复根）分别套通解。
> - 要点 5：**非齐次通解 = 齐次通解 + 非齐次特解**；标准型 $f = e^{\lambda x}P_m(x)$ 设 $y^* = x^k e^{\lambda x}Q_m$（$k$ 按 $\lambda$ 是否为特征根取 $0/1/2$）；$f$ 未知时用**拆系数降阶 + 两方程联立**求特解。
> - 要点 6：**通法顺序**——先判标准型（可分离/齐次/一阶线性/伯努利/二阶常系数），不是标准型就上**三板斧**：① 变换视角（把 $x$ 看成 $y$ 的函数）；② 找"某部分求导是另一部分"（$y^2 \leftrightarrow yy'$、$\cos y \leftrightarrow y'\sin y$、$\ln y \leftrightarrow y'/y$，考得最多）；③ 换元（$y/x$、$\cos y$、$1/y$、$y^2$、$\ln y$）。三板斧不成立刻换题。
> - 要点 7：证明解有界 = **齐次通解有界 + 特解有界**；抽象 $f$ 只能靠**带上下限的一阶线性公式** + 逐层取绝对值放缩。
> - 要点 8：**常数变易法**——齐次解里的 $C$ 换成 $C(x)$，代回后齐次项自动抵消，只剩 $C'(x)\cdot(\text{齐次解})=\text{非齐次项}$，积一次分即得；它是一阶线性公式的母体。
> - 要点 9：**齐次 / 准齐次**——齐次令 $u=\dfrac{y}{x}$；准齐次先平移 $\begin{cases}X=x-x_0\\Y=y-y_0\end{cases}$ 消常数项再当齐次（两行系数成比例时改令 $u=a_1x+b_1y$）。**分离时除掉的零点就是丢掉的解**。
> - 要点 10：**伯努利** $y'+Py=Qy^{n}$：先声明 $y=0$ 是解，再除 $y^{n}$、令 $u=y^{1-n}$，落到一阶线性。
> - 要点 11：**主次调换**——$y^2$、$e^y$、$\sin y$ 与 $x$ 相加时取倒数，把 $x$ 当函数，通常立刻是一阶线性；补检 $y=0$。
> - 要点 12：**全微分方程**——验 $P_y=Q_x$，由 $u=\int P\,dx+\varphi(y)$ 与 $u_y=Q$ 定 $\varphi$，通解 $u=C$；"两次积分取公共项"的速算法必须求导检验。
> - 要点 13：**二阶非齐次** $f=e^{\lambda x}P_m(x)$：$y^{*}=x^{k}e^{\lambda x}Q_m(x)$，$k$ 是 $\lambda$ 作为特征根的重数（$0/1/2$）；乘 $x^k$ 是为了让代回后不整体消失，重根时留下的常数因子是 $k!$。
> - **常见坑**：解出 $u$ 忘回代 $y$；一阶线性公式中 $e^{-\int P}$ 与 $e^{+\int P}$ 的符号搞反；二阶复根只写实部忘 $\sin/\cos$ 两项；非齐次忘加齐次通解；多次换元回代顺序错乱；把 $p(0)$、$y(0)$ 误当成未知量而不放进界里。
> - **补充坑**：把 $C(x)$ 当常数求导（漏 $C'$ 项）；齐次换元后忘回代 $u=\dfrac{y}{x}$；伯努利除 $y^n$ 前不声明 $y=0$；翻转主次后积分因子仍对 $x$ 积；全微分不验 $P_y=Q_x$ 就硬凑；重根特解忘乘 $x^2$。
