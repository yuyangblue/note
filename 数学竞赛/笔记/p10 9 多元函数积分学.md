## 1. 三重积分：直角坐标

三重积分化为**一重积分 + 二重积分**，直角坐标下分两类：

**先一后二法**（立体有明确的上下底面 $z_1(x,y) \le z \le z_2(x,y)$）：

$$\iiint_\Omega f\,dV = \iint_D dxdy\int_{z_1(x,y)}^{z_2(x,y)} f(x,y,z)\,dz$$

先积 $z$（函数上下限），再把立体投影到 $XOY$ 面做二重积分。

**先二后一法**（立体的 $z$ 用两个常数界定 $a \le z \le b$，$z$ 最后积）：

$$\iiint_\Omega f\,dV = \int_a^b dz\iint_{D(z)} f(x,y,z)\,dxdy$$

$D(z)$ 是**截面**（带 $z$ 的二维区域），先做二重积分（常算成截面面积），再积 $z$。

> **选法**：上下底面是曲面 → 先一后二；上下边界是常数平面 → 先二后一（截面法）。

## 2. 柱坐标与球坐标

**柱坐标** = 极坐标 + $z$ 轴（$XOY$ 面用极坐标，$z$ 不变）：

$$x = \rho\cos\theta,\quad y = \rho\sin\theta,\quad z = z,\qquad \boxed{dxdydz = \rho\,d\rho\,d\theta\,dz}$$

> **易错点**：与二重积分一样，$dxdydz$ 换柱坐标**必须乘 $\rho$**，别漏。

**球坐标**（三个参数）：$r$ = 到原点距离，$\theta$ = $XOY$ 面上从 $x$ 轴扫过的角度，$\varphi$ = 空间中从 $z$ 轴扫过的角度：

$$x = r\sin\varphi\cos\theta,\quad y = r\sin\varphi\sin\theta,\quad z = r\cos\varphi,\qquad \boxed{dxdydz = r^2\sin\varphi\,dr\,d\varphi\,d\theta}$$

> **关键**：球坐标的体积微元**必须乘 $r^2\sin\varphi$**（最容易漏）。取范围：$r$ 看离原点距离；$\theta$ 看 $XOY$ 面上绕 $x$ 轴转的角度；$\varphi$ 看 $z$ 轴扫过的角度。

## 3. 真题：圆锥与椭球围成区域的体积

**真题 1（第 15 届）**：圆锥面（顶点 $(0,4,0)$）与椭球面 $\dfrac{x^2}{3} + \dfrac{y^2}{4} + \dfrac{z^2}{3} = 1$ 相切，求两者围成区域的体积。

解：

1. **拍扁到 $XOY$ 面**：椭球投影为椭圆 $\dfrac{x^2}{3} + \dfrac{y^2}{4} = 1$；圆锥投影为从 $(0,4)$ 引出的**两条切线**（相切 ⟹ 投影也相切）。
2. 求切点：设切点 $(x_0, y_0)$。在椭圆上 $\dfrac{x_0^2}{3} + \dfrac{y_0^2}{4} = 1$；椭圆隐函数求导 $y' = -\dfrac{4x}{3y}$；与连线斜率相等：

$$\frac{y_0 - 4}{x_0} = -\frac{4x_0}{3y_0}$$

联立解得 $x_0 = \pm\dfrac{3}{2}$，$y_0 = 1$。
3. **圆锥体积**：底面半径 $\dfrac{3}{2}$，高 $= 4 - 1 = 3$：

$$V_1 = \frac{1}{3}\pi r^2 h = \frac{1}{3}\pi\left(\frac{3}{2}\right)^2\cdot 3 = \frac{9\pi}{4}$$

> 注：字幕中该处读作"4/9π"，按公式验算应为 $9\pi/4$（AI 字幕数字识别差异），已修正。

4. **椭球被切下的部分**（$1 \le y \le 2$，$y$ 用常数上下限）→ **先二后一法**。截面（$y$ 固定时 $XOZ$ 面）：

$$x^2 + z^2 = 3\left(1 - \frac{y^2}{4}\right) \quad(\text{圆})$$

截面面积 $= 3\pi\left(1 - \dfrac{y^2}{4}\right)$：

$$V_2 = \int_1^2 3\pi\left(1 - \frac{y^2}{4}\right)dy = 3\pi\left[y - \frac{y^3}{12}\right]_1^2 = \frac{5\pi}{4}$$

5. 围成体积：$V = V_1 - V_2 = \dfrac{9\pi}{4} - \dfrac{5\pi}{4} = \boxed{\pi}$。

> **思路**：空间图形难想象 → **投影到 $XOY$ 面**化为平面几何（切线/切点）；旋转体拆成"圆锥 $-$ 椭球帽"；椭球帽用先二后一法（$y$ 常数上下限 + 截面圆）。

## 4. 曲线积分：两类

**第一类（对弧长）** $\displaystyle\int_L f\,ds$：微元是**弧长** $ds$。无方向，下限 $\alpha$ 必须小于上限 $\beta$（弧长是正的）。参数方程 $x = \varphi(t)$、$y = \psi(t)$：

$$ds = \sqrt{(\varphi')^2 + (\psi')^2}\,dt$$

（就是定积分应用里的弧长公式。）

**第二类（对坐标）** $\displaystyle\int_L P\,dx + Q\,dy$：微元是 $dx$、$dy$，**有方向**（$\alpha$ 到 $\beta$ 按题目给定方向，大小顺序无所谓）。计算同样是**换元**：

$$x = \varphi(t),\ dx = \varphi'(t)dt;\qquad y = \psi(t),\ dy = \psi'(t)dt$$

## 5. 格林公式与"挖洞法"

**格林公式**：封闭曲线（**正向**：沿曲线走时区域始终在左手边）上的曲线积分 ⟹ 二重积分：

$$\oint_L P\,dx + Q\,dy = \iint_D\left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)dxdy$$

**挖洞法**（有奇点时）：当 $P$、$Q$ 在区域内部某点（如原点）**不定义/不可导**（常因分母为零），格林公式不满足应用条件 → 挖掉奇点，补一条**小闭曲线** $L_1$，在环域上用格林公式：

$$\oint_L = \oint_{L_1}\quad(\text{环域上被积函数为零时})$$

**选 $L_1$ 的技巧**：选得让分母在 $L_1$ 上变成**常数**，奇点影响被消除。

**真题 2（第 16 届）**：计算 $\displaystyle\oint_L \frac{x\,dy - y\,dx}{4x^2 + y^2}$，其中 $L$ 为包含原点在其内部的闭曲线。

解：

1. $P = \dfrac{-y}{4x^2+y^2}$，$Q = \dfrac{x}{4x^2+y^2}$。若直接格林公式：$\dfrac{\partial Q}{\partial x} - \dfrac{\partial P}{\partial y} = 0$——但不能直接说积分为零，因为**原点处分母为零，$P,Q$ 不定义**（奇点），不满足格林条件。
2. **挖洞**：取 $L_1$：$4x^2 + y^2 = 4$（小椭圆，使分母 $= 4$ 常数）。在 $L$ 与 $L_1$ 围成的环域上格林公式成立且被积函数为零：

$$\oint_L + \oint_{L_1^-} = 0 \;\Longrightarrow\; \oint_L = \oint_{L_1^+}\frac{-y\,dx + x\,dy}{4} = \frac{1}{4}\oint_{L_1}x\,dy - y\,dx$$

3. 再用格林公式：$\dfrac{1}{4}\displaystyle\iint(1+1)dxdy = \frac{1}{2}\cdot$（椭圆 $4x^2+y^2=4$ 的面积）$= \dfrac{1}{2}\cdot\pi\cdot 1\cdot 2 = \boxed{\pi}$。

> **要点**：带分母的曲线积分要警惕**分母为零的奇点**——先检查格林公式是否处处适用，不行就挖洞；补的曲线选"分母变常数"的最优。

## 6. 曲面积分：两类

**第一类（对面积）** $\displaystyle\iint_\Sigma f\,dS$：微元是**曲面面积** $dS$，无方向。投影到 $XOY$ 面（$z = z(x,y)$）：

$$dS = \sqrt{1 + z_x^2 + z_y^2}\,dxdy$$

（也可投影到 $YOZ$、$ZOX$ 面，做法类似。）

**第二类（对坐标）** $\displaystyle\iint_\Sigma P\,dydz + Q\,dzdx + R\,dxdy$：三个函数对应三个投影微元，**有方向**（曲面**上侧为正、下侧为负**等）。分别投影：$P$ 项投影到 $YOZ$ 面（$x$ 用 $y,z$ 表示）、$Q$ 项投影到 $ZOX$ 面、$R$ 项投影到 $XOY$ 面。

**两类转化**（方向余弦投影）：

$$dydz = \cos\alpha\,dS,\qquad dzdx = \cos\beta\,dS,\qquad dxdy = \cos\gamma\,dS$$

（$\alpha,\beta,\gamma$ 是曲面法向量的方向角，见 **p09 第 1 节**。）

## 7. 高斯公式与斯托克斯公式

**高斯公式**（封闭曲面（外侧为正）上的第二型曲面积分 ⟹ 三重积分，被积函数是**散度** $\mathrm{div}\,\vec A$）：

$$\oiint_\Sigma P\,dydz + Q\,dzdx + R\,dxdy = \iiint_\Omega\left(\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}\right)dV$$

**斯托克斯公式**（空间**封闭曲线**上的曲线积分 ⟹ 曲面积分，被积函数是**旋度**，行列式记法）：

$$\oint_L P\,dx + Q\,dy + R\,dz = \iint_\Sigma \begin{vmatrix}dydz & dzdx & dxdy \\ \frac{\partial}{\partial x} & \frac{\partial}{\partial y} & \frac{\partial}{\partial z} \\ P & Q & R\end{vmatrix}$$

> **对比记忆**：高斯 = 封闭曲面积分 ⟹ 散度的三重积分；斯托克斯 = 封闭曲线积分 ⟹ 旋度的曲面积分。

## 8. 真题：对面积的曲面积分

**真题 3（第 15 届）**：计算 $\displaystyle\iint_\Sigma (x + y + z)\,dS$，其中 $\Sigma$ 是平面 $y + z = 5$ 被柱面 $x^2 + y^2 \le 25$ 截得的部分。

解：

1. 平面截圆柱 → 倾斜的圆片，**投影到 $XOY$ 面最方便**：$D$ 为 $x^2 + y^2 \le 25$（投影后仍是完整圆域）。
2. 由 $z = 5 - y$：$z_x = 0$，$z_y = -1$ ⟹ $dS = \sqrt{1 + 0 + 1}\,dxdy = \sqrt{2}\,dxdy$。
3. 被积函数换 $z$：$x + y + z = x + y + (5-y) = x + 5$：

$$\iint_\Sigma (x+y+z)dS = \sqrt{2}\iint_D (x + 5)dxdy = \sqrt{2}\left[\iint_D x\,dxdy + 5\iint_D dxdy\right]$$

4. 区域 $D$ 关于 $y$ 轴对称、$x$ 是奇函数 → 第一项 $= 0$；第二项 $= 5\cdot 25\pi$：

$$\text{原式} = \sqrt{2}\cdot 125\pi = \boxed{125\sqrt{2}\pi}$$

## 9. 真题：对坐标的曲面积分与补面法

**真题 4（第 16 届）**：计算上半球面 $x^2 + y^2 + z^2 = R^2$（$z \ge 0$）**上侧**的曲面积分（其散度形式的被积函数为 $2(x+y+z) - 3$）。

> 注：字幕未完整给出 $P,Q,R$ 的具体形式，但明确指出"$P,Q,R$ 分别对 $x,y,z$ 求偏导相加后为 $2(x+y+z)-3$"，以下按此展开（方法为本题核心）。

解：

1. 上半球面**不封闭**，但 $P,Q,R$ 形式整齐、想用高斯公式 → **补面法**：补底面 $\Sigma_0$：$z = 0$，$x^2 + y^2 \le R^2$（使整体封闭）。
2. **补面上积分为零**：$z = 0$ 时 $dydz$、$dzdx$ 两项消失（$P,Q$ 含 $z$ 因子），第三项被积函数含 $z$ 因子也为零 ⟹ 补面贡献 $0$。所以原积分 $=$ 半球体上的三重积分：

$$\iint_\Sigma = \iiint_{\text{半球}}\bigl[2(x+y+z) - 3\bigr]dV$$

3. **对称性化简**：半球关于 $x$、$y$ 都对称（关于 $z$ 不对称）→ $2x$、$2y$ 是奇函数扔掉：$\iiint(2z - 3)dV$。
4. **球坐标**：$z = r\cos\varphi$，$dV = r^2\sin\varphi\,dr\,d\varphi\,d\theta$；范围 $r \in [0,R]$，$\varphi \in \left[0,\frac{\pi}{2}\right]$（$z$ 轴扫过 $90^\circ$ 覆盖半球），$\theta \in [0, 2\pi]$：

$$= 2\pi\int_0^R\int_0^{\pi/2}(2r\cos\varphi - 3)\,r^2\sin\varphi\,d\varphi\,dr = 2\pi\int_0^R\left(r^3 - 3r^2\right)dr = \boxed{2\pi\left(\frac{R^4}{4} - R^3\right)}$$

> **套路**：第二型曲面积分不封闭 + $P,Q,R$ 散度简单 → **补面法**（补的面上积分常为 $0$）+ 高斯公式 + 对称性化简 + 球/柱坐标算三重积分。

## 10. 本节重点

> **本节重点**：
> - 要点 1：三重积分直角坐标两法——**先一后二**（上下底面是曲面，先积 $z$ 再投影二重）与**先二后一**（$z$ 常数上下限，截面法）；柱坐标 $dV = \rho\,d\rho d\theta dz$，球坐标 $dV = r^2\sin\varphi\,dr d\varphi d\theta$（$r^2\sin\varphi$ 别漏）。
> - 要点 2：曲线积分两类——**对弧长**（$ds$，无方向，$\alpha<\beta$）与**对坐标**（$dx,dy$，有方向），都换元成定积分；**格林公式**：正向闭曲线 ⟹ $\iint(\partial_x Q - \partial_y P)dxdy$；**分母为零的奇点**必须挖洞，补线选"分母变常数"。
> - 要点 3：曲面积分两类——**对面积**（$dS = \sqrt{1+z_x^2+z_y^2}dxdy$，无方向）与**对坐标**（三个投影微元，有方向，上侧为正）；**高斯公式**（封闭曲面 ⟹ 散度三重积分，外侧为正）、**斯托克斯公式**（封闭曲线 ⟹ 旋度曲面积分）。
> - 要点 4：空间体积题：先投影到 $XOY$ 面变平面几何；旋转体拆成"圆锥 $-$ 椭球帽"；用先二后一法算帽体。
> - 要点 5：第二型曲面积分不封闭 → **补面法**（补面贡献常为 0）+ 高斯公式 + 对称性（关于哪轴对称就扔哪个变量的奇函数）+ 球坐标。
> - **常见坑**：球坐标忘 $r^2\sin\varphi$；柱坐标忘 $\rho$；格林公式被积函数符号写反（应为 $\partial_x Q - \partial_y P$）；有奇点直接套格林；补面方向/符号处理错；曲面积分把两类（面积/坐标）微元混用。
