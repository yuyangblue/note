## 1. 向量的基本运算

**数量积（点积）**——结果是**一个数**：

$$\vec{a}\cdot\vec{b} = a_xb_x + a_yb_y + a_zb_z$$

**向量积（叉积）**——结果是**一个向量**（三阶行列式）：

$$\vec{a}\times\vec{b} = \begin{vmatrix}\vec{i} & \vec{j} & \vec{k} \\ a_x & a_y & a_z \\ b_x & b_y & b_z\end{vmatrix}$$

- $\vec{a}\times\vec{b} = -\vec{b}\times\vec{a}$（行列式交换两行变号）；
- **方向**：右手法则（四指从 $\vec{a}$ 转向 $\vec{b}$，大拇指指向）；$\vec{a}\times\vec{b}$ **同时垂直于 $\vec{a}$、$\vec{b}$ 所在的平面**——这是后面求平面法向量的关键用途。

**方向角与方向余弦**：向量与 $x,y,z$ 轴的夹角为 $\alpha,\beta,\gamma$，则

$$\cos\alpha = \frac{a_x}{|\vec{a}|},\quad \cos\beta = \frac{a_y}{|\vec{a}|},\quad \cos\gamma = \frac{a_z}{|\vec{a}|},\qquad \boxed{\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1}$$

## 2. 空间平面

平面最重要属性是**法向量**（垂直于平面的向量 $\vec{n}$）。三种方程写法：

| 形式 | 方程 | 说明 |
|------|------|------|
| 一般式 | $ax + by + cz + d = 0$ | 系数 $(a,b,c)$ 就是法向量 |
| 点法式 | $a(x-x_0) + b(y-y_0) + c(z-z_0) = 0$ | 一点 $(x_0,y_0,z_0)$ $+$ 法向量 $(a,b,c)$ |
| 截距式 | $\dfrac{x}{a} + \dfrac{y}{b} + \dfrac{z}{c} = 1$ | 平面过三轴上的点 $(a,0,0)$、$(0,b,0)$、$(0,0,c)$ |

> **直观理解**：二元一次方程（三个变量都一次方）就是空间平面；点法式"给定一点 + 法向量"即可确定唯一平面，最重要。

## 3. 空间直线

直线最重要属性是**方向向量** $\vec{\tau} = (l,m,n)$。三种写法：

| 形式 | 方程 | 说明 |
|------|------|------|
| 一般式 | $\begin{cases}A_1x+B_1y+C_1z+D_1=0 \\ A_2x+B_2y+C_2z+D_2=0\end{cases}$ | **两个平面联立（交线）**，不要死记，看到两平面方程并列就想到直线 |
| 点向式 | $\dfrac{x-x_0}{l} = \dfrac{y-y_0}{m} = \dfrac{z-z_0}{n}$ | 一点 $+$ 方向向量（与点法式对应） |
| 参数式 | $\begin{cases}x = x_0+lt \\ y = y_0+mt \\ z = z_0+nt\end{cases}$ | 点向式令比值都等于 $t$ 即得 |

## 4. 点线面的位置关系

**点到平面距离**：

$$d = \frac{|ax_0 + by_0 + cz_0 + d|}{\sqrt{a^2+b^2+c^2}}$$

（分子：点代入平面方程取绝对值；分母：系数平方和开根。）

**关系归结为向量关系**：

| 关系 | 转化 |
|------|------|
| 线线关系 | ⟹ 方向向量 $\vec{\tau}_1, \vec{\tau}_2$：平行 = 对应分量成比例（$\frac{l_1}{l_2} = \frac{m_1}{m_2} = \frac{n_1}{n_2}$）；垂直 = 点积为零；夹角 = $\cos\theta = \frac{\vec{\tau}_1\cdot\vec{\tau}_2}{\|\vec{\tau}_1\|\|\vec{\tau}_2\|}$ |
| 面面关系 | ⟹ 法向量 $\vec{n}_1, \vec{n}_2$：同样的平行/垂直/夹角判定 |
| 线面关系 | ⟹ 方向向量 $\vec{\tau}$ 与法向量 $\vec{n}$：**线面角与 $\vec{\tau},\vec{n}$ 夹角互补**（线面角 $\sin\varphi = |\cos\langle\vec{\tau},\vec{n}\rangle|$） |

## 5. 空间曲线：切线与法平面

**法平面**：与切线垂直的平面。所以**切线的方向向量 = 法平面的法向量**——只要求出这一个关键向量即可。

**参数方程形式** $\vec{r}(t) = (\varphi(t), \psi(t), \omega(t))$：切向量就是

$$\vec{\tau} = \bigl(\varphi'(t),\ \psi'(t),\ \omega'(t)\bigr)$$

有了切向量 + 切点 → 切线写**点向式**、法平面写**点法式**。

**一般式形式**（两个曲面的交线）：切向量取

$$\vec{\tau} = \left(1,\ \frac{dy}{dx},\ \frac{dz}{dx}\right)$$

其中 $\frac{dy}{dx}$、$\frac{dz}{dx}$ 由**隐函数组 + 克莱姆法则**求出（见 **p07 第 4 节**）：对两个隐函数方程两边同时关于 $x$ 求偏导，得到以 $\frac{dy}{dx}$、$\frac{dz}{dx}$ 为未知数的二元方程组，分母是系数行列式 $\begin{vmatrix}F_y & F_z \\ G_y & G_z\end{vmatrix}$，分子"求谁换谁"。

## 6. 空间曲面：切平面与法线

**隐函数** $F(x,y,z) = 0$：法向量为梯度

$$\vec{n} = (F_x,\ F_y,\ F_z)$$

**显函数** $z = f(x,y)$：移项 $f(x,y) - z = 0$，法向量为

$$\vec{n} = (f_x,\ f_y,\ -1)$$

（对 $z$ 求偏导自然是 $-1$，**理解了就不用背**。）有了法向量 + 一点 → 切平面写点法式、法线写点向式。

## 7. 常见曲面

**旋转曲面**：$YOZ$ 面上曲线 $f(y,z) = 0$ 绕 $z$ 轴旋转，把 $y$ 换成 $\pm\sqrt{x^2+y^2}$：

$$f\bigl(\pm\sqrt{x^2+y^2},\ z\bigr) = 0$$

**原理**：绕谁转**谁不动**；旋转前后向量**模长相等**（$y_1^2 = x^2 + y^2$，$z$ 不变）。绕 $y$ 轴则把 $z$ 换成 $\sqrt{x^2+z^2}$。

**柱面（最具迷惑性）**：$x^2 + y^2 = a^2$ 在空间中不是圆，是**圆柱**！——方程里没有 $z$，意味着 $z$ 任意取，但 $XOY$ 面上始终保持圆。**只有 $z=0$ 时才是 $XOY$ 面上的圆**，别忽视没出现的那个变量。

**二次曲面**：

| 曲面 | 方程 | 形状 |
|------|------|------|
| 球面 | $x^2+y^2+z^2 = a^2$ | 球 |
| 椭球面 | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}+\dfrac{z^2}{c^2} = 1$ | 椭球 |
| 椭圆抛物面 | $z = x^2 + y^2$ | 碗状（$ZOX$ 面上是抛物线 $z=x^2$，旋转成碗） |
| 圆锥面 | $z = \sqrt{x^2+y^2}$ | 锥形（与抛物面只差开根号，母线是直的） |

## 8. 真题：求曲线的切线与法平面

**真题 1**：求曲线 $x = y^2$，$z = y^4$ 在点 $(1,1,1)$ 处的切线与法平面。

解：

1. **难点：识别并转化**——既不是参数方程也不是两平面交线，但 $z$ 与 $x$ 有关、$x$ 与 $y$ 有关，$y$ 是最底层变量：**令 $y = t$**，得参数方程

$$\vec{r}(t) = (t^2,\ t,\ t^4)$$

2. 切向量 $\vec{\tau} = (2t,\ 1,\ 4t^3)$，在 $t = 1$（对应点 $(1,1,1)$）处为 $(2,\ 1,\ 4)$。
3. **切线**（点向式）：

$$\frac{x-1}{2} = \frac{y-1}{1} = \frac{z-1}{4}$$

4. **法平面**（点法式，法向量即切向量）：

$$2(x-1) + (y-1) + 4(z-1) = 0$$

> **要点**：见到"奇形怪状"的曲线表达式，先想办法**化成熟悉的参数方程**（找到最底层变量作参数），后面就机械了。

## 9. 真题：直线绕轴旋转的曲面方程

**真题 2**：求直线 $x = 3 - t$，$y = t - 1$，$z = 2t + 1$ 绕 $y$ 轴旋转一周所得旋转曲面的方程。

解：

1. 绕 $y$ 轴旋转 → **$y$ 不动**；旋转前后模长相等：$x^2 + z^2 = x_1^2 + z_1^2$（$y$ 方向分量相同，消去 $y^2$ 项）。
2. 用 $y$ 表示参数：$t = y + 1$。于是

$$x^2 + z^2 = (3-t)^2 + (2t+1)^2 = \bigl(3-(y+1)\bigr)^2 + \bigl(2(y+1)+1\bigr)^2 = (2-y)^2 + (2y+3)^2$$

3. 展开化简：

$$x^2 + z^2 = 5y^2 + 8y + 13 \;\Longrightarrow\; \boxed{x^2 - 5y^2 + z^2 = 8y + 13}$$

> **套路**：直线给参数式时直接把 $x$、$z$ 都换成参数表达式，再用**不动的变量（绕谁转谁）替换参数**，$x^2 + z^2$（或 $x^2+y^2$）就出来了。
> 注：字幕中该直线参数写作 $z=12t$，按最终答案反推并验算应为 $z = 2t+1$（AI 字幕数字识别差异），已按数学结果修正。

## 10. 本节重点

> **本节重点**：
> - 要点 1：数量积是数（对应相乘相加），向量积是向量（三阶行列式，$\vec{a}\times\vec{b}$ 垂直 $\vec a,\vec b$，方向右手法则，交换变号）；方向余弦 $\cos^2\alpha+\cos^2\beta+\cos^2\gamma = 1$。
> - 要点 2：平面三式（一般式/点法式/截距式）以系数为法向量；直线三式（一般式=**两平面联立**/点向式/参数式）以方向向量为核心。
> - 要点 3：位置关系全部转成向量关系——线线看方向向量、面面看法向量、**线面角与向量夹角互补**；点到面距离公式背熟。
> - 要点 4：曲线切线/法平面与曲面切平面/法线，本质都是**找一个关键向量**（曲线的切向量 = 法平面法向量；曲面的梯度 = 法向量），写点向式/点法式即可；隐函数组用克莱姆法则。
> - 要点 5：旋转曲面"绕谁谁不动、模长相等"；**柱面方程缺变量 = 那个变量任意**（$x^2+y^2=a^2$ 是圆柱不是圆）；常见二次曲面（球、椭球、抛物面、锥面）的方程要熟。
> - **常见坑**：把 $x^2+y^2=a^2$ 当圆（漏 $z$ 任意）；显函数切平面法向量忘写 $-1$；曲线一般式求切向量不会用隐函数组；旋转曲面把不动的变量也换掉；方向角余弦平方和 $\ne 1$。
