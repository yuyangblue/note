## 一、Doolittle 分解：逐层拆分的实现

### 1.1 思路：把 A 一层一层拆成 L 和 U

- 目标：$A = LU$，$L$ 为单位下三角、$U$ 为上三角。
- 拆法：**第一行第一列 → 第二行第二列 → … → 第 n 行第 n 列**，逐层推进。
  - 第一层：由 A 的第一行直接得到 U 的第一行；由 A 的第一列（除以 $u_{11}$）得到 L 的第一列。
  - 第二层：用"A 的第二行 − l 与 u 的乘积修正"得到 U 的第二行；同理得 L 的第二列。
  - 依此类推，每层把 U 的一行和 L 的一列同时算出来。

### 1.2 递推公式（第 k 层）

对于 $k = 1, 2, \dots, n$：

$$u_{kj} = a_{kj} - \sum_{s=1}^{k-1} l_{ks}\,u_{sj}, \qquad j = k, k+1, \dots, n$$

$$l_{ik} = \frac{a_{ik} - \sum_{s=1}^{k-1} l_{is}\,u_{sk}}{u_{kk}}, \qquad i = k+1, \dots, n$$

（$k=1$ 时求和为空，即 $u_{1j}=a_{1j}$、$l_{i1}=a_{i1}/u_{11}$——先填 U 第一行，再除出 L 第一列。）

### 1.3 依赖分析：为什么可以逐层做下去

- 算 U 的第 $k$ 行：依赖 $l_{k1..k,k-1}$（L 前 $k-1$ 列）与 $u_{1..k-1,j}$（U 前 $k-1$ 行）——**都已算好**。
- 算 L 的第 $k$ 列：依赖 $l_{i1..i,k-1}$（L 前 $k-1$ 列）与 $u_{sk}$（U 前 $k-1$ 行第 $k$ 列）——**都已算好**。
- 结论：每层所需信息都在"自己那一层之前"，写成程序时**循环执行前所有依赖都就绪**，因此可以用一个简单的双层循环实现。

> 老师强调：写公式时先判断**哪些量已知、哪些量未知**；只要循环执行前所有元素都已算好，公式就是可执行的算法，而不是"看起来正确但没用"的恒等式。

> 课程脉络：上节课讲了"先解下三角、再解上三角"（前代+回代）；本节课是把一般矩阵的 LU 分解本身也拆成程序化的逐层递推——即 Doolittle 分解的完整实现。

## 二、平方根法（Cholesky 分解）

### 2.1 适用对象与分解形式

- 三角分解不止一种：Doolittle（$A=LU$，L 单位下三角）、LDU 分解、对称情形的 $LDL^T$、平方根法 $A=\tilde L\tilde L^T$ 等。
- **平方根法针对对称正定矩阵**：若 $A$ 对称正定，则存在唯一的单位下三角 $L$ 与对角元全为正的对角阵 $D$，使

$$A = LDL^T$$

进一步 $D = D^{1/2}D^{1/2}$（对角元开平方），得 Cholesky 分解

$$A = \tilde L\tilde L^T, \qquad \tilde L = L\,D^{1/2}$$

### 2.2 为什么成立（证明梗概，老师口头推导）

1. $A$ 正定 ⇒ 各阶顺序主子式 $\det(A_p) > 0$（课本定理 6 推论），故 LU 分解存在唯一。
2. 取各阶顺序主子块：$A_p = L_p U_p$，两边取行列式（$L_p$ 单位下三角，$\det(L_p)=1$）：

$$\det(A_p) = \det(U_p) = u_{11}u_{22}\cdots u_{pp} > 0$$

3. 由 $p=1,2,\dots,n$ 递推得**每个 $u_{pp} > 0$**（U 的对角元全正）。
4. 由对称性 $A = A^T$ 与 LU 分解唯一性，得 $L = U_0^T$（$U_0$ 为 U 去对角后的单位上三角），即

$$A = LDL^T$$

5. $D$ 对角元全正 ⇒ 可开平方，合并进 $L$ 得 $\tilde L\tilde L^T$。

### 2.3 解方程流程

解 $Ax = b$（$A = \tilde L\tilde L^T$）：

1. 前代：$\tilde L y = b$（下三角，从上往下）；
2. 回代：$\tilde L^T x = y$（上三角，从下往上）。

### 2.4 缺点（引出改进平方根法）

1. **开根号耗费运算量**：开平方比四则运算贵；
2. **更关键：开根号可能做不下去**——输入只有对称（甚至非正定）时，中间算出的数若为负，平方根法直接中断；而方程组只要矩阵可逆就能解，不应因方法限制而失败。

## 三、改进平方根法（LDLᵀ 分解）

### 3.1 动机

不做开根号，直接用 $A = LDL^T$（$L$ 单位下三角、$D$ 对角）解方程；对任意可逆对称矩阵都能算，遇负数不中断。

### 3.2 存储与运算量对比

| 方法 | 需要算的元素 | 每元素操作 |
|------|------------|-----------|
| 平方根法 $\tilde L\tilde L^T$ | $\tilde L$ 共 $n(n+1)/2$ 个元素 | 含**开根号** |
| 改进平方根法 $LDL^T$ | $L$ 的 $n(n-1)/2$ 个 + $D$ 的 $n$ 个 = $n(n+1)/2$ 个 | 纯**四则运算** |

- 元素个数相同（$n(n+1)/2$），但改进法把"开根号"这个贵操作去掉了。
- 运算量仍是 $O(n^3)$ 量级（约 $\frac{1}{3}n^3$ 上下，具体常数待课件核对）；对称性只省了部分元素计算，没有改变量级。

### 3.3 递推公式（逐列推进，依赖全在前面）

为避免重复计算引入 $t_{ij} = l_{ij}d_j$（记 $T = LD$，则 $A = TL^T$），逐元素比较得：

- 非对角（$j = 1,\dots,i-1$）：

$$t_{ij} = a_{ij} - \sum_{k=1}^{j-1} t_{ik}\,l_{jk}, \qquad l_{ij} = \frac{t_{ij}}{d_j}$$

- 对角元：

$$d_i = a_{ii} - \sum_{k=1}^{i-1} t_{ik}\,l_{ik}$$

初值 $d_1 = a_{11}$。按列推进：算第 $j$ 列只依赖前面 $j-1$ 列的信息，循环可一直做下去。

> 与 Doolittle 的依赖逻辑完全相同：**每步需要的信息都在前面已算好**。推导见同目录《线性方程组条件数相关讲解-转录稿整理》及教材 5.3.2 页（先假设顺序主子式非零保证 $u_{kk}\ne0$，正定保证 $d_i>0$）。

### 3.4 优点

1. **避免开根号**（省运算量、无中断风险）；
2. 即使 $d_i$ 出现负值也能继续算完——它说明输入只是对称、非正定，但方程组仍可解；
3. 附带给出**实用的正定性判定**：对称矩阵完成 $LDL^T$ 分解后，检查是否所有 $d_i > 0$——全正 ⇔ 对称正定（由 $\det(A_k) = d_1d_2\cdots d_k$）。

> 代价：判断正定性也要先做一次 $O(n^3)$ 的分解；$n=10^4$ 阶就是 $10^{12}$ 量级运算，很大但可行。

### 3.5 解方程的技巧（D 先乘还是先除）

解 $LDL^T x = b$ 有两种等价写法，但运算量不同：

- 把 $D$ 先并入 $L$（算 $\tilde L = LD^{1/2}$）：要对 $n(n+1)/2$ 个元素做乘法；
- 先把 $D$ 留到右边（解 $Ly=b$，$Dz=y$，$L^Tx=z$）：对角阵 $D$ 只做 $n$ 次除法。

后者更省，故实现时通常先把 $D$ 除过去。

## 四、追赶法（Thomas 算法，三对角矩阵）

### 4.1 三对角结构

三对角矩阵 $A$：只有主对角、上次对角、下次对角非零（其余全 0），非零元共 $3n-2$ 个。

其 LU 分解保持带状结构：$L$ 只有主对角与下次对角（两条线），$U$ 只有主对角与上次对角（对角全 1，两条线）。

### 4.2 稀疏记号（Kronecker δ）

用 $\delta_{ij}$（当 $i=j$ 为 1，否则为 0）把 $L$、$U$ 的元素紧凑写成两项之和（如 $l_{ij} = \alpha_i\delta_{ij} + \beta_i\delta_{i,j+1}$ 形式），好处：代入 $A = LU$ 展开后**每项是否非零一眼可判**（$\delta$ 的指标相等才贡献），避免对着 $n^2$ 个格子硬算。

### 4.3 递推计算

逐层交错推进：先由第一行定 $\alpha_1$（$=a_{11}$），然后 $\beta$ 与 $\alpha$ 交替算出（$\beta_i$ 由上次对角元素给出，$\alpha_{i+1}$ 由 $\alpha_i,\beta_i$ 与主对角 $a_{i+1,i+1}$ 修正得到），一直推到第 $n$ 个。

### 4.4 高效性与应用背景

- 三对角系统用追赶法求解**运算量 $O(n)$**（每层常数次操作），远小于稠密消元的 $O(n^3)$。
- 为什么值得研究：实际问题（三次样条插值、差分法离散化、有限元等）大量出现三对角方程组——带状结构 + 线性成本，是"利用矩阵特殊结构"的典型例子。
