# 02 最短路

> 最短路是图论最经典的问题。四种算法各有适用场景：Dijkstra（非负权单源）、Floyd（多源/稠密图）、Bellman-Ford/SPFA（负权边/判负环）。

## 1. 问题定义

给定带权图 G=(V,E) 和起点 s，求 s 到所有其他顶点的最短路径长度。

- **单源最短路**：一个起点到所有点
- **多源最短路**：所有点对之间的最短路
- **边权**：可以是正数、负数（但不能有负环，否则最短路无意义）

**常见图规模与算法选择：**

| 图规模 | 边权 | 推荐算法 |
|--------|------|---------|
| n ≤ 500 | 任意 | Floyd（O(n³)，好写） |
| n ≤ 1e5, m ≤ 2e5 | 非负 | Dijkstra 堆优化（O(m log n)） |
| n ≤ 1e3, m ≤ 1e4 | 非负 | Dijkstra 朴素版（O(n²)） |
| 有负权边 | 负权 | Bellman-Ford / SPFA |
| 判负环 | 负权 | SPFA |

## 2. Dijkstra 算法

### 大白话引入

从起点出发，每次选"当前距离最近的未访问顶点"，用它去更新邻居的距离。类似"扩散"——离起点近的点先被确定，然后一层层往外扩展。

**前提：所有边权非负。** 因为一旦某个顶点被标记为"已确定"，它的最短距离就不会再变了（负权边可能让已确定的点后来被更新得更小）。

### 思维启发

维护 dist[v] = 起点到 v 的当前最短距离。
1. 初始化：dist[s]=0，其他=∞
2. 重复 n 次：
   a. 选未访问中 dist 最小的顶点 u
   b. 标记 u 已访问
   c. 用 u 更新所有邻居 v：dist[v] = min(dist[v], dist[u] + w(u,v))

**为什么选最小的？** 因为所有边权非负，当前 dist 最小的未访问点，不可能通过其他未访问点绕路变得更小（其他点的 dist 都比它大，加上非负边权只会更大）。

### 2.1 朴素版 Dijkstra（O(n²)）

每次遍历找最小 dist 的顶点。适合稠密图（m 接近 n²）。

### 2.2 堆优化 Dijkstra（O(m log n)）

用优先队列（小根堆）维护 (dist, vertex)，每次取堆顶就是最小的。适合稀疏图。

### C++ 代码：Dijkstra 双版本

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1005;
const long long INF = 1e18;

struct Edge {
    int to;
    long long w;
};

vector<Edge> adj[MAXN];
long long dist[MAXN];
bool vis[MAXN];

// 朴素版 Dijkstra：O(n²)，适合稠密图
void dijkstra_naive(int s, int n) {
    // 初始化
    for (int i = 1; i <= n; i++) {
        dist[i] = INF;
        vis[i] = false;
    }
    dist[s] = 0;

    for (int iter = 0; iter < n; iter++) {
        // 1. 找未访问中 dist 最小的顶点 u
        int u = -1;
        long long min_dist = INF;
        for (int i = 1; i <= n; i++) {
            if (!vis[i] && dist[i] < min_dist) {
                min_dist = dist[i];
                u = i;
            }
        }
        if (u == -1) break;  // 剩余顶点不可达

        // 2. 标记 u 已访问（最短距离已确定）
        vis[u] = true;

        // 3. 用 u 更新所有邻居
        for (auto& e : adj[u]) {
            int v = e.to;
            if (!vis[v] && dist[u] + e.w < dist[v]) {
                dist[v] = dist[u] + e.w;
            }
        }
    }
}

// 堆优化 Dijkstra：O(m log n)，适合稀疏图
void dijkstra_heap(int s, int n) {
    for (int i = 1; i <= n; i++) {
        dist[i] = INF;
        vis[i] = false;
    }
    dist[s] = 0;

    // 优先队列：小根堆，存 (距离, 顶点)
    // greater 让距离小的在堆顶
    priority_queue<pair<long long, int>, vector<pair<long long, int>>, greater<pair<long long, int>>> pq;
    pq.push({0, s});

    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();

        // ⚠️ 关键：如果 d > dist[u]，说明这是过期的旧记录，跳过
        if (d > dist[u]) continue;
        if (vis[u]) continue;
        vis[u] = true;

        for (auto& e : adj[u]) {
            int v = e.to;
            if (dist[u] + e.w < dist[v]) {
                dist[v] = dist[u] + e.w;
                pq.push({dist[v], v});  // 新距离入队
            }
        }
    }
}

int main() {
    int n = 5, s = 1;
    // 建图：1->2(2), 1->3(5), 2->3(1), 2->4(3), 3->5(2), 4->5(1)
    adj[1].push_back({2, 2});
    adj[1].push_back({3, 5});
    adj[2].push_back({3, 1});
    adj[2].push_back({4, 3});
    adj[3].push_back({5, 2});
    adj[4].push_back({5, 1});

    cout << "=== 朴素版 Dijkstra ===" << endl;
    dijkstra_naive(s, n);
    for (int i = 1; i <= n; i++) {
        cout << "1 -> " << i << ": " << (dist[i] == INF ? "INF" : to_string(dist[i])) << endl;
    }
    // 预期: 1->1=0, 1->2=2, 1->3=3(1->2->3), 1->4=5(1->2->4), 1->5=6(1->2->4->5)

    cout << "\n=== 堆优化 Dijkstra ===" << endl;
    dijkstra_heap(s, n);
    for (int i = 1; i <= n; i++) {
        cout << "1 -> " << i << ": " << (dist[i] == INF ? "INF" : to_string(dist[i])) << endl;
    }

    return 0;
}
```

> **坑：** 堆优化中同一个顶点可能多次入队（每次更新距离都入队），必须用 `if (d > dist[u]) continue` 跳过过期记录。INF 要开足够大（1e18，因为 dist[u]+w 可能超过 1e9），但不能大到相加溢出 long long。优先队列用 `greater` 变成小根堆，默认是大根堆。朴素版不需要 vis 也能跑（因为选最小的自然不会重复），但加上更清晰。

## 3. Floyd 算法

### 大白话引入

求所有点对之间的最短路。思路很暴力：**枚举中间点 k，看 i→k→j 是否比 i→j 更短。**

三重循环：k 在外层（中间点），i 和 j 在内层（起点和终点）。

### 核心讲解

**状态转移：**
$$dist[i][j] = \min(dist[i][j], dist[i][k] + dist[k][j])$$

**为什么 k 在外层？** 因为当处理中间点 k 时，dist[i][k] 和 dist[k][j] 必须已经是用 1..k-1 作为中间点的最短路。k 在外层保证了这个顺序。

**时间复杂度：O(n³)**，空间 O(n²)。

**优点：** 代码极短（5行核心），可以处理负权边（但不能有负环），一次求出所有点对。
**缺点：** O(n³)，n > 500 就很慢了。

### C++ 代码：Floyd

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 105;
const long long INF = 1e18;

long long dist[MAXN][MAXN];

void floyd(int n) {
    // 初始化：对角线为0，其他为INF
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (i == j) dist[i][j] = 0;
            else dist[i][j] = INF;
        }
    }

    // 三重循环：k是中间点，必须在外层！
    for (int k = 1; k <= n; k++) {
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n; j++) {
                if (dist[i][k] < INF && dist[k][j] < INF) {
                    dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
                }
            }
        }
    }
}

int main() {
    int n = 4;
    // 建图（邻接矩阵）
    // 1->2(1), 1->3(4), 2->3(2), 2->4(5), 3->4(1)
    floyd(n);  // 先初始化
    dist[1][2] = 1; dist[2][1] = 1;
    dist[1][3] = 4; dist[3][1] = 4;
    dist[2][3] = 2; dist[3][2] = 2;
    dist[2][4] = 5; dist[4][2] = 5;
    dist[3][4] = 1; dist[4][3] = 1;

    // 重新跑Floyd（因为上面加了边）
    for (int k = 1; k <= n; k++)
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                if (dist[i][k] < INF && dist[k][j] < INF)
                    dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);

    cout << "所有点对最短路:" << endl;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (dist[i][j] >= INF) cout << "INF ";
            else cout << dist[i][j] << " ";
        }
        cout << endl;
    }
    // 预期:
    // 0 1 3 4
    // 1 0 2 3
    // 3 2 0 1
    // 4 3 1 0

    return 0;
}
```

> **坑：** k 必须在外层！写反了结果不对。INF 要判断 `dist[i][k] < INF && dist[k][j] < INF` 才能相加，否则 INF+INF 会溢出。Floyd 可以处理负权边，但有负环时 dist[i][i] 会变成负数（可以用来判负环）。

## 4. Bellman-Ford 与 SPFA

### 4.1 Bellman-Ford

**用途：** 处理有负权边的单源最短路，判断是否有负环。

**思路：** 对所有边进行 n-1 轮松弛。每轮松弛：dist[v] = min(dist[v], dist[u] + w(u,v))。

- 为什么 n-1 轮？最短路最多经过 n-1 条边（不重复走顶点）。
- 判负环：n-1 轮后，如果还能继续松弛，说明存在负环。

**时间复杂度：O(n·m)**，较慢。

### 4.2 SPFA（Shortest Path Faster Algorithm）

**Bellman-Ford 的队列优化：** 只有 dist 被更新过的顶点，它的邻居才可能被更新。用队列维护待处理的顶点。

**平均时间复杂度：O(m)**，但最坏情况 O(n·m)（可以被卡）。

**判负环：** 记录每个顶点入队次数，超过 n 次说明有负环。

### C++ 代码：Bellman-Ford 与 SPFA

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1005;
const long long INF = 1e18;

struct Edge {
    int u, v;
    long long w;
};

vector<Edge> edges;  // Bellman-Ford用所有边的列表
vector<pair<int, long long>> adj[MAXN];  // SPFA用邻接表
long long dist[MAXN];

// Bellman-Ford：返回true表示有负环
bool bellman_ford(int s, int n, int m) {
    for (int i = 1; i <= n; i++) dist[i] = INF;
    dist[s] = 0;

    // n-1 轮松弛
    for (int i = 0; i < n - 1; i++) {
        bool updated = false;
        for (auto& e : edges) {
            if (dist[e.u] < INF && dist[e.u] + e.w < dist[e.v]) {
                dist[e.v] = dist[e.u] + e.w;
                updated = true;
            }
        }
        if (!updated) break;  // 没有更新，提前结束
    }

    // 第 n 轮还能松弛 → 有负环
    for (auto& e : edges) {
        if (dist[e.u] < INF && dist[e.u] + e.w < dist[e.v]) {
            return true;  // 有负环
        }
    }
    return false;
}

// SPFA：返回true表示有负环
bool spfa(int s, int n) {
    for (int i = 1; i <= n; i++) dist[i] = INF;
    dist[s] = 0;

    vector<int> cnt(n + 1, 0);   // 入队次数
    vector<bool> inq(n + 1, false);  // 是否在队列中
    queue<int> q;

    q.push(s);
    inq[s] = true;
    cnt[s] = 1;

    while (!q.empty()) {
        int u = q.front();
        q.pop();
        inq[u] = false;

        for (auto& [v, w] : adj[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                if (!inq[v]) {
                    q.push(v);
                    inq[v] = true;
                    cnt[v]++;
                    if (cnt[v] > n) {
                        return true;  // 入队超过n次，有负环
                    }
                }
            }
        }
    }
    return false;
}

int main() {
    int n = 4;
    // 图：1->2(2), 2->3(-1), 3->4(3), 1->3(5)（有负权边但无负环）
    edges.push_back({1, 2, 2});
    edges.push_back({2, 3, -1});
    edges.push_back({3, 4, 3});
    edges.push_back({1, 3, 5});
    for (auto& e : edges) {
        adj[e.u].push_back({e.v, e.w});
    }

    cout << "=== Bellman-Ford ===" << endl;
    bool has_cycle = bellman_ford(1, n, edges.size());
    cout << "有负环? " << (has_cycle ? "是" : "否") << endl;
    for (int i = 1; i <= n; i++) {
        cout << "1 -> " << i << ": " << (dist[i] >= INF ? "INF" : to_string(dist[i])) << endl;
    }
    // 预期: 1->1=0, 1->2=2, 1->3=1(1->2->3: 2+(-1)=1), 1->4=4(1->2->3->4: 2-1+3=4)

    cout << "\n=== SPFA ===" << endl;
    has_cycle = spfa(1, n);
    cout << "有负环? " << (has_cycle ? "是" : "否") << endl;
    for (int i = 1; i <= n; i++) {
        cout << "1 -> " << i << ": " << (dist[i] >= INF ? "INF" : to_string(dist[i])) << endl;
    }

    // 测试负环：加一条 4->2(-5)，形成 2->3->4->2，权值 -1+3-5=-3 < 0
    cout << "\n=== 加入负环后 ===" << endl;
    edges.push_back({4, 2, -5});
    adj[4].push_back({2, -5});
    has_cycle = spfa(1, n);
    cout << "有负环? " << (has_cycle ? "是" : "否") << endl;

    return 0;
}
```

> **坑：** SPFA 在最坏情况会被卡成 O(nm)（比如网格图），竞赛中非负权图优先用 Dijkstra。判负环用 `cnt[v] > n`（入队次数超过顶点数）。Bellman-Ford 的边列表要包含所有边（有向图只加一条，无向图加两条）。有负环时最短路无意义（可以无限绕环变小）。

## 5. 四种算法对比

| 算法 | 时间复杂度 | 适用场景 | 负权边 | 判负环 | 代码量 |
|------|-----------|---------|--------|--------|--------|
| Dijkstra 朴素 | O(n²) | 稠密图、非负权 | ❌ | ❌ | 小 |
| Dijkstra 堆优化 | O(m log n) | 稀疏图、非负权 | ❌ | ❌ | 中 |
| Floyd | O(n³) | 多源最短路、n≤500 | ✅ | ✅ | 极小 |
| Bellman-Ford | O(nm) | 负权边、判负环 | ✅ | ✅ | 小 |
| SPFA | O(m)~O(nm) | 负权边、判负环 | ✅ | ✅ | 中 |

**选择决策树：**
1. 多源最短路？→ Floyd（n≤500）或 每个点跑一次 Dijkstra
2. 有负权边？→ SPFA / Bellman-Ford
3. 非负权 + 稠密图？→ Dijkstra 朴素
4. 非负权 + 稀疏图？→ Dijkstra 堆优化（最常用）

> **本节重点**：
> - Dijkstra：非负权单源，每次选最近未访问点更新邻居，堆优化O(m log n)
> - Floyd：三重循环k在外层，O(n³)，多源最短路，可处理负权
> - Bellman-Ford：n-1轮松弛所有边，O(nm)，可判负环
> - SPFA：Bellman-Ford队列优化，平均O(m)，入队>n判负环，可被卡
> - 堆优化Dijkstra必须跳过过期记录（d > dist[u]）
> - INF开1e18，相加前判断是否INF防溢出
> - **常见坑**：Dijkstra处理负权边结果错误；Floyd k循环写内层；SPFA忘判负环；INF不够大导致溢出；优先队列用大根堆而非小根堆
