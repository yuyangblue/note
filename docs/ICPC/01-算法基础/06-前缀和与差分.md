# 06. 前缀和 & 差分

> 🎯 目标：吃透前缀和（一维/二维）和差分（一维/二维）——**它们不是两个独立技巧，而是互为逆运算**：差分数组做前缀和还原原数组，前缀和做差分又变回差分数组。学会"什么时候用、为什么 O(1)"。

---

## 一、一维前缀和 — "累计值"解决区间查询

### 1.1 大白话引入

老师给你一份成绩单，问你 100 次"第 3 名到第 7 名的总分是多少"。每次现场加 5 个数，100 次就是 500 次加法——太笨了。

聪明做法：提前算好 **pre[i] = 第 1 名到第 i 名的累计总分**，存一张表。之后问 [l, r]，直接 `pre[r] - pre[l-1]`，一次减法搞定。

> 类比：仓库管理员每天记"累计入库量"。想知道"第 3 天到第 7 天入库多少"？用"前 7 天累计 − 前 2 天累计"——中间的货就出来了。**前缀和 = 从第 1 个位置累计到当前位置的总和**。

### 1.2 核心思想

```
原数组 a:   3  1  4  1  5
前缀和 pre: 3  4  8  9 14
            ↑pre[3]=8 = 3+1+4
```

**区间和公式**：`sum(l, r) = pre[r] - pre[l-1]`

验证 [2,4]：pre[4] − pre[1] = 9 − 3 = 6 = 1+4+1 ✓

为什么是 pre[l-1] 而不是 pre[l]？因为 pre[l] 把 a[l] 也算进去了，减掉它就把区间开头的元素误删了。**区间 [l,r] 的和 = 前 r 个 − 前 l-1 个**。

**复杂度**：预处理 O(n)，每次查询 O(1)。暴力是每次 O(n)，q 次查询 O(nq) → 前缀和把 q 次查询压到 O(n+q)。

### 1.3 代码（P8218 求区间和就是模板）

```cpp
#include <bits/stdc++.h>
using namespace std;

// 一维前缀和：O(n) 预处理，O(1) 回答任意区间 [l,r] 的和
int main() {
    int n, q;
    cin >> n >> q;
    vector<int> a(n + 1), pre(n + 1, 0);
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = 1; i <= n; i++)
        pre[i] = pre[i - 1] + a[i];        // pre[i] = a[1]+...+a[i]，顺带把 pre[0] 留成 0
    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << pre[r] - pre[l - 1] << endl;   // 区间和 = 两个前缀一减
    }
    return 0;
}
```

**坑**：
- **下标从 1 开始**（a[0] 空着，pre[0] = 0）：查询 [1,r] 时 pre[l-1] = pre[0] = 0，不用特判。从 0 开始的话 pre[-1] 直接越界。
- **前缀和可能溢出**：a[i] 上亿、n 上万时 pre 累加超 int，竞赛里直接 `long long` 更省心。
- 别把 `pre[r] - pre[l-1]` 写成 `pre[r] - pre[l]`（会漏掉 a[l]）。

## 二、二维前缀和 — 从"区间"升级到"矩形"

### 2.1 大白话引入

一维查区间，二维查矩形。比如一张地图上每个格子的价值，问你 100 次"(2,2) 到 (5,7) 这个矩形里价值总和"。

暴力每次把矩形里的格子全加一遍，太慢。跟一维一个思路：**提前算好 P[x][y] = 从左上角 (1,1) 到 (x,y) 这个矩形的累计和**，之后任何矩形和都是四个 P 值的加减组合。

### 2.2 构造：P[x][y] 怎么 O(1) 递推（容斥）

```
P[x][y] = P[x-1][y] + P[x][y-1] - P[x-1][y-1] + a[x][y]
           ↑上边矩形   ↑左边矩形   ↑重叠部分减掉    ↑自己
```

P[x-1][y]（上面）和 P[x][y-1]（左边）**重叠**——重叠区就是 (1,1) 到 (x-1,y-1) 那个矩形，被加了两次，要减一次。这就是**容斥**：加起来，减掉多算的。

例子（3×3 表，值 1..9）：

```
原表 a:           前缀和 P:
1 2 3            1   3   6
4 5 6            5  12  21
7 8 9           12  27  45
```

P[2][2] = 12 = P[1][2](3) + P[2][1](5) − P[1][1](1) + a[2][2](5) ✓

### 2.3 查询：任意矩形和（还是容斥）

查 (x1,y1) 到 (x2,y2) 的矩形和：

```
sum = P[x2][y2] - P[x1-1][y2] - P[x2][y1-1] + P[x1-1][y1-1]
      ↑大矩形     ↑上面多出的   ↑左边多出的    ↑重复减的角落加回
```

验证右下 2×2（原表 5+6+8+9 = 28）：P[3][3](45) − P[1][3](6) − P[3][1](12) + P[1][1](1) = 28 ✓

> 记忆口诀：**大矩形 − 上条 − 左条 + 角落**。和一维的"pre[r] − pre[l-1]"一样，只是二维要多处理一个角。

### 2.4 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 二维前缀和：O(n*m) 预处理，O(1) 回答任意矩形和
int main() {
    int n, m, q;
    cin >> n >> m >> q;
    vector<vector<int>> P(n + 1, vector<int>(m + 1, 0));
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            int x;
            cin >> x;
            // 容斥构造：上 + 左 - 左上角 + 自己
            P[i][j] = P[i - 1][j] + P[i][j - 1] - P[i - 1][j - 1] + x;
        }
    while (q--) {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        // 矩形和：大矩形 - 上条 - 左条 + 角落
        cout << P[x2][y2] - P[x1 - 1][y2] - P[x2][y1 - 1] + P[x1 - 1][y1 - 1] << endl;
    }
    return 0;
}
```

**坑**：
- 第 0 行/第 0 列全 0（vector 初始化自动是），查询时 x1-1 或 y1-1 为 0 时对应项自动变 0，不用特判。
- **构造和查询的容斥别混**：构造是 `+自己`，查询是 `+角落`——都有四个项，但符号位置不同，手滑就错。
- 想原地构造（不额外存 a）：读一个数就累进 P[i][j]（上面代码就是），省内存。

## 三、差分 — 前缀和的"逆运算"，批量区间修改

### 3.1 大白话引入

这次不是查询，是**修改**：给数组做 10 万次"区间 [l,r] 全部 +v"的操作，最后问每个位置的值是多少。

暴力每次把区间里每个数加一遍，O(n) 一次，10 万次 × n 就炸了。

差分的思想：**把"区间修改"变成"两个点的修改"**——给 [l,r] 整体 +v，等价于在差分数组 d 上做 `d[l] += v` 和 `d[r+1] -= v` 两个 O(1) 操作，最后对 d 做一遍前缀和就还原出原数组。

### 3.2 核心思想

定义**差分数组** `d[i] = a[i] - a[i-1]`（相邻差）。显然：

```
a[i] = d[1] + d[2] + ... + d[i]     ← 原数组是差分数组的前缀和！
```

所以"对 a 做区间加"可以转为"对 d 做点修改"：

```
给 a[l..r] 全部 +v  ⟺  d[l] += v; d[r+1] -= v
```

为什么？想象对 d 做前缀和的"水流"：d[l] += v 之后，从 l 开始前缀和里都多了 v；这个 v 一路"流"到 r+1 处，被 d[r+1] -= v 抵消——**只有 [l, r] 这一段的前缀和 +v，正好就是 a[l..r] + v**。

例：a = [0,0,0,0,0]（全 0），给 [2,4] +3：

```
d 初始: 0 0 0 0 0 0（多开一位）
d[2]+=3, d[5]-=3 → d: 0 3 0 0 -3 0
前缀和还原 a: 0 3 3 3 0    ✓ 只有 2~4 是 3
```

**复杂度**：每次区间加 O(1)，最后还原 O(n)。暴力 O(n)/次 → 差分 O(1)/次。

### 3.3 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 一维差分：O(1) 区间加，最后 O(n) 还原数组
int main() {
    int n, m;
    cin >> n >> m;
    vector<int> d(n + 2, 0);   // 差分数组开 n+2：d[r+1] 可能到 n+1，别越界
    for (int i = 0; i < m; i++) {
        int l, r, v;
        cin >> l >> r >> v;
        d[l] += v;             // 从 l 开始"生效"
        d[r + 1] -= v;         // 到 r+1 "失效"
    }
    long long cur = 0;         // 累加值可能大，用 long long
    for (int i = 1; i <= n; i++) {
        cur += d[i];           // 对差分数组做前缀和 = 原数组
        cout << cur << (i == n ? '\n' : ' ');
    }
    return 0;
}
```

**坑**：
- **d 数组开 n+2**，不是 n+1：`d[r+1]` 在 r=n 时是 d[n+1]，必须能放下。
- 还原时用 `cur += d[i]` 累加（前缀和），不是 `a[i] = d[i]`——d 是"差值"，不是最终值。
- 如果原数组初始不是 0：先正常读 a，然后 `d[i] = a[i] - a[i-1]` 建差分，区间加照旧，还原时累加即可。

### 3.4 二维差分 — 矩形整体加

和一维完全对称：**矩形 (x1,y1)-(x2,y2) 全部 +v = 四个角打标记**：

```
d[x1][y1] += v
d[x2+1][y1] -= v
d[x1][y2+1] -= v
d[x2+1][y2+1] += v
```

然后对 d 做一遍二维前缀和还原。为什么是四个角？因为二维前缀和的"水流"从 (x1,y1) 向右下扩散，需要两条"停止线"（x2+1 行、y2+1 列），而停止线交叉的角落被减了两次要加回——和 2.3 的矩形查询容斥是同一个道理，只是角色互换。

P3397 地毯就是模板题：n×n 网格铺 m 张地毯，问每格被盖了几层。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 二维差分（P3397 地毯）：每张地毯矩形 +1，最后前缀和还原
int main() {
    int n, m;
    cin >> n >> m;              // n×n 网格，m 张地毯
    vector<vector<int>> d(n + 2, vector<int>(n + 2, 0));
    for (int i = 0; i < m; i++) {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        // 四角打标记（类比一维的 d[l]+=v, d[r+1]-=v）
        d[x1][y1] += 1;
        d[x2 + 1][y1] -= 1;
        d[x1][y2 + 1] -= 1;
        d[x2 + 1][y2 + 1] += 1;
    }
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            // 原地做二维前缀和还原（d[i-1][j]、d[i][j-1] 此时已是还原后的值）
            d[i][j] += d[i - 1][j] + d[i][j - 1] - d[i - 1][j - 1];
            cout << d[i][j] << (j == n ? '\n' : ' ');
        }
    }
    return 0;
}
```

**坑**：`d[x2+1]`、`d[y2+1]` 在边界时会到 n+1，所以 d 开 n+2；还原时按行从左到右、从上到下，`d[i-1][j]` 和 `d[i][j-1]` 必须是已经还原好的值（上面的写法满足）。

## 四、实战：P10561 里的二维前缀和（数区间）

前缀和不只能数"数字之和"，还能**数"某种对象的个数"**——06-状压DP 的 P10561 就是这么用的：

把"区间 [l,r] 出现几次"放进表格 g（行 = 左端点 l，列 = 右端点 r），对 g 做二维前缀和 P。于是：

```
P[x][y] = 左端点 ≤ x 且右端点 ≤ y 的区间总数
```

"数被 x 夹住的区间"（l ∈ [L+1, i]、r ∈ [i, R-1]）= 查一个矩形：

```
cnt = P[i][R-1] - P[L][R-1] - P[i][i-1] + P[L][i-1]
```

O(1) 数完 → 整个状压 DP 才能压到 O(N·2^N)。**看到"数满足某些端点条件的区间/点对"，想想能不能用二维前缀和。**
