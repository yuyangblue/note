## 1. 大白话引入

想象一个学校有很多班级，已知：
- a 和 b 同班
- b 和 d 同班
- d 和 e 同班

问你：a 和 e 是不是同班？

**暴力做法**：从 a 开始，沿着"同班"关系一个个找，看能不能走到 e。太慢了。

**并查集做法**：把同班的人合并成一个集合，用集合的"代表元素"（根节点）来标识。查询时只需要看 a 和 e 的代表元素是否相同。

**核心操作**：
- `find(x)`：找到 x 所在集合的代表元素
- `union(x, y)`：把 x 和 y 所在集合合并

**应用场景**：
- 判断两点是否在同一联通块
- 维护等价类（同班、同色、同类...）
- Kruskal 最小生成树

## 2. 基础并查集

### 核心思想

用数组 `f[i]` 记录 i 的父节点。如果 `f[i] == i`，说明 i 是根节点（代表元素）。

**初始化**：每个人自己是一个集合，`f[i] = i`

**查找**：沿着父节点往上找，直到根节点

**合并**：把 x 的根节点挂到 y 的根节点上

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 10005;
int f[N];  // f[i] 是 i 的父节点
int sz[N]; // sz[i] 是以 i 为根的集合大小

// 初始化：每个人自己是一个集合
void init(int n) {
    for (int i = 1; i <= n; i++) {
        f[i] = i;  // 自己是自己的父节点 = 根节点
        sz[i] = 1; // 初始集合大小为 1
    }
}

// 查找 x 的根节点（无优化，逐层向上）
int find(int x) {
    if (x == f[x]) {
        return x;  // 找到根节点
    }
    return find(f[x]);  // 递归向上找
}

// 合并 x 和 y 所在集合
void unite(int x, int y) {
    int fx = find(x), fy = find(y);
    if (fx == fy) return;  // 已在同一集合，跳过
    
    // 把 fx 挂到 fy 上
    f[fx] = fy;
    sz[fy] += sz[fx];  // 更新集合大小
}

// 查询 x 和 y 是否在同一集合
bool query(int x, int y) {
    return find(x) == find(y);
}

int main() {
    int n, m;
    cin >> n >> m;
    init(n);
    
    while (m--) {
        int op, x, y;
        cin >> op >> x >> y;
        if (op == 1) {
            unite(x, y);
        } else {
            cout << (query(x, y) ? "Y" : "N") << "\n";
        }
    }
    
    return 0;
}
```

**问题**：如果合并操作总是把长链挂到短链上，树会退化成链，`find` 变成 O(N)。

**复杂度**：单次操作最坏 O(N)，需要优化。

## 3. 路径压缩

### 核心思想

**问题**：树退化成链时，`find` 要逐层向上，太慢。

**解决**：在 `find` 时，把路径上所有节点直接挂到根节点。下次查询时，一步到位。

```cpp
// 路径压缩示意（核心修改只有一行）
#include <bits/stdc++.h>
using namespace std;

const int N = 10005;
int f[N];

// 路径压缩：查找时把路径上所有节点直接挂到根
int find(int x) {
    if (x == f[x]) {
        return x;
    }
    return f[x] = find(f[x]);  // 关键：把 f[x] 直接指向根节点
}

int main() { return 0; }
```

**图解**：
```
查找 4 之前：        查找 4 之后：
    1                   1
    |                 / | \
    2                2  3  4
    |
    3
    |
    4
```

**效果**：虽然单次 `find` 还是 O(树高)，但经过路径压缩后，树高会快速降低。均摊复杂度接近 O(1)。

**完整代码**（P3367 模板题）：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 10005;
int f[N];

void init(int n) {
    for (int i = 1; i <= n; i++) {
        f[i] = i;
    }
}

int find(int x) {
    if (x == f[x]) return x;
    return f[x] = find(f[x]);  // 路径压缩
}

void unite(int x, int y) {
    int fx = find(x), fy = find(y);
    if (fx != fy) {
        f[fx] = fy;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n, m;
    cin >> n >> m;
    init(n);
    
    while (m--) {
        int op, x, y;
        cin >> op >> x >> y;
        if (op == 1) {
            unite(x, y);
        } else {
            cout << (find(x) == find(y) ? "Y" : "N") << "\n";
        }
    }
    
    return 0;
}
```

**复杂度**：均摊 O(α(N))，其中 α 是反阿克曼函数，增长极慢，可以认为是 O(1)。

## 4. 按秩合并

### 核心思想

**问题**：路径压缩改变了树的结构，某些场景下不适用（如需要维护树的深度信息）。

**解决**：不压缩路径，而是保证树的高度最小。合并时，把矮树挂到高树上。

用 `rank[i]` 记录以 i 为根的树的高度（上界）。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 10005;
int f[N];   // 父节点
int sz[N];  // 集合大小
int rnk[N]; // 树高（上界），不能用 rank 因为和 std::rank 冲突

void init(int n) {
    for (int i = 1; i <= n; i++) {
        f[i] = i;
        sz[i] = 1;
        rnk[i] = 0;  // 初始树高为 0
    }
}

int find(int x) {
    if (x == f[x]) return x;
    return find(f[x]);  // 注意：按秩合并不做路径压缩
}

void unite(int x, int y) {
    int fx = find(x), fy = find(y);
    if (fx == fy) return;
    
    // 把矮树挂到高树上
    if (rnk[fx] < rnk[fy]) {
        f[fx] = fy;
        sz[fy] += sz[fx];
    } else if (rnk[fx] > rnk[fy]) {
        f[fy] = fx;
        sz[fx] += sz[fy];
    } else {
        // 高度相等，随便挂，被挂的树高 +1
        f[fx] = fy;
        sz[fy] += sz[fx];
        rnk[fy]++;
    }
}

int main() {
    int n, m;
    cin >> n >> m;
    init(n);
    
    while (m--) {
        int op, x, y;
        cin >> op >> x >> y;
        if (op == 1) {
            unite(x, y);
        } else {
            cout << (find(x) == find(y) ? "Y" : "N") << "\n";
        }
    }
    
    return 0;
}
```

**关键点**：
- 按秩合并保证树高 O(log N)，`find` 最坏 O(log N)
- 路径压缩 + 按秩合并：通常只用路径压缩就够了
- 需要维护树结构时（如可撤销并查集），只用按秩合并

**对比**：
| 优化方式 | 单次 find | 适用场景 |
|---------|----------|---------|
| 路径压缩 | 均摊 O(α) | 通用，最常用 |
| 按秩合并 | O(log N) | 需要维护树结构 |
| 两者结合 | 均摊 O(α) | 理论最优，但按秩合并意义不大 |

## 5. 带权并查集

### 核心思想

普通并查集只维护"是否在同一集合"，带权并查集还维护节点之间的**关系信息**（如距离、倍数、相对位置）。

**关键**：在 `init`、`find`、`unite` 三个操作中正确维护权值。

### 5.1 食物链（P2024）

**题意**：三种动物 A、B、C，A 吃 B，B 吃 C，C 吃 A。给出若干语句，判断假话数量。

**建模**：
- 用 0、1、2 表示关系：0=同类，1=x 是 y 的食物，2=x 吃 y
- 关系传递：`dis[x]` 表示 x 到父节点的关系，路径压缩时累加 mod 3

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 50005;
int f[N];   // 父节点
int dis[N]; // x 到父节点的关系（0=同类，1=被吃，2=吃）

void init(int n) {
    for (int i = 1; i <= n; i++) {
        f[i] = i;
        dis[i] = 0;  // 自己和自己同类
    }
}

int find(int x) {
    if (x == f[x]) return x;
    int fx = find(f[x]);
    // 路径压缩：x 到根的关系 = x 到父的关系 + 父到根的关系
    dis[x] = (dis[x] + dis[f[x]]) % 3;
    return f[x] = fx;
}

// x 对 y 的关系是 val（0=同类，2=x 吃 y）
void unite(int x, int y, int val) {
    int fx = find(x), fy = find(y);
    if (fx == fy) return;
    
    // x -> fx: dis[x]
    // y -> fy: dis[y]
    // x -> y: val
    // 需要求 fx -> fy 的关系
    
    // x -> y -> fy = val + dis[y]
    // x -> fx -> fy = dis[x] + dis[fx]
    // 所以 dis[fx] = val + dis[y] - dis[x]
    
    f[fx] = fy;
    dis[fx] = ((val + dis[y] - dis[x]) % 3 + 3) % 3;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n, k;
    cin >> n >> k;
    init(n);
    
    int ans = 0;
    while (k--) {
        int op, x, y;
        cin >> op >> x >> y;
        
        if (x > n || y > n) {
            ans++;
            continue;
        }
        
        if (op == 1) {
            // x 和 y 同类
            int fx = find(x), fy = find(y);
            if (fx == fy) {
                if (dis[x] != dis[y]) {
                    ans++;  // 矛盾
                }
            } else {
                unite(x, y, 0);
            }
        } else {
            // x 吃 y
            int fx = find(x), fy = find(y);
            if (fx == fy) {
                // x -> y 的关系 = dis[x] - dis[y] (mod 3)
                int rel = ((dis[x] - dis[y]) % 3 + 3) % 3;
                if (rel != 2) {
                    ans++;  // 不是 x 吃 y
                }
            } else {
                unite(x, y, 2);  // x 吃 y，关系为 2
            }
        }
    }
    
    cout << ans << "\n";
    return 0;
}
```

**关键点**：
- `dis[x]` 是 x 到**父节点**的关系，路径压缩后变成到**根节点**的关系
- 合并时，通过 x、y 的关系推导出 fx、fy 的关系
- 关系传递用 mod 3 处理环形关系

### 5.2 线性关系（xi + xj = 2c）

**题意**：给定若干条件 `xi + xj = val`，判断是否矛盾，或求出某个变量的值。

**建模**：
- 用 `x[i] = val - k * x[fa]` 表示 i 和父节点的关系
- 路径压缩时，合并系数 k 和常数 val

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 10005;
const int INF = 1e9;
const int MOD = 1e9 + 7;

struct Node {
    int fa;   // 父节点
    int val;  // 常数项
    int k;    // 系数：x[i] = val - k * x[fa]
} a[N];

int hav[N];  // 根节点是否有确定值
int ans[N];  // 根节点的值

void init(int n) {
    for (int i = 1; i <= n; i++) {
        a[i].fa = i;
        a[i].val = 0;
        a[i].k = -1;  // x[i] = 0 - (-1) * x[i]，即 x[i] = x[i]
        hav[i] = 0;
        ans[i] = INF;
    }
}

int find(int x) {
    if (a[x].fa == x) return x;
    int rt = find(a[x].fa);
    // 路径压缩：合并 x -> fa -> root
    // x = val_x - k_x * fa
    // fa = val_fa - k_fa * root
    // x = val_x - k_x * (val_fa - k_fa * root)
    //   = (val_x - k_x * val_fa) - (k_x * k_fa) * root  // 注意符号
    // 但我们的定义是 x = val - k * root，所以：
    // val_new = val_x - k_x * val_fa  // 这里要注意 k 的定义
    // k_new = k_x * k_fa
    a[x].val = (a[x].val - a[x].k * a[a[x].fa].val) % MOD;
    a[x].k = (a[x].k * a[a[x].fa].k) % MOD;
    a[x].fa = rt;
    return rt;
}

// x + y = val，合并 x 和 y 所在集合
void unite(int x, int y, int val) {
    int fx = find(x), fy = find(y);
    if (fx == fy) return;
    
    // x = val_x - k_x * fx
    // y = val_y - k_y * fy
    // x + y = val
    // 把 fy 挂到 fx 上，需要求 fy = ? - ? * fx
    
    // 从 x + y = val 得：y = val - x
    // val_y - k_y * fy = val - (val_x - k_x * fx)
    // val_y - k_y * fy = val - val_x + k_x * fx
    // k_y * fy = val_y - val + val_x - k_x * fx
    // fy = (val_y - val + val_x) / k_y - (k_x / k_y) * fx
    
    a[fy].fa = fx;
    a[fy].val = (a[y].val + a[x].val - val) % MOD;
    // 需要除以 k_y，这里简化处理
    // 实际题目可能需要逆元
    a[fy].k = a[x].k;  // 简化
    hav[fy] = 0;
}

// 给 x 赋值为 val
void update(int x, int val) {
    int fx = find(x);
    hav[fx] = 1;
    // x = val_x - k_x * fx = val
    // fx = (val_x - val) / k_x
    ans[fx] = (a[x].val - val + MOD) % MOD;  // 简化
}

// 查询 x 的值
int getval(int x) {
    int fx = find(x);
    if (!hav[fx]) return INF;
    // x = val_x - k_x * fx
    return (a[x].val - a[x].k * ans[fx] % MOD + MOD) % MOD;
}

int main() {
    // 具体实现根据题目调整
    return 0;
}
```

**关键点**：
- 权值信息在路径压缩时要正确传递
- 合并时要根据已知关系推导根节点之间的关系
- 这类题目需要仔细推导数学关系

## 6. 应用：最小生成树（Kruskal）

### 核心思想

Kruskal 算法：按边权从小到大排序，依次加入边，如果两端点不在同一集合就加入，否则跳过。

并查集用来快速判断两点是否已联通。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 5005;
const int M = 200005;

struct Edge {
    int u, v, w;
    bool operator<(const Edge& o) const {
        return w < o.w;
    }
} e[M];

int f[N];

int find(int x) {
    if (x == f[x]) return x;
    return f[x] = find(f[x]);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n, m;
    cin >> n >> m;
    
    for (int i = 1; i <= n; i++) {
        f[i] = i;
    }
    
    for (int i = 1; i <= m; i++) {
        cin >> e[i].u >> e[i].v >> e[i].w;
    }
    
    sort(e + 1, e + 1 + m);
    
    long long total = 0;
    int cnt = 0;
    
    for (int i = 1; i <= m; i++) {
        int fu = find(e[i].u), fv = find(e[i].v);
        if (fu != fv) {
            f[fu] = fv;
            total += e[i].w;
            cnt++;
            if (cnt == n - 1) break;  // 已加入 n-1 条边
        }
    }
    
    if (cnt == n - 1) {
        cout << total << "\n";
    } else {
        cout << "orz\n";  // 无法生成树
    }
    
    return 0;
}
```

**复杂度**：排序 O(M log M)，并查集操作 O(M α(N))，总复杂度 O(M log M)。

## 7. 应用：网格联通块

### 问题

给定 n×m 网格，有些格子是障碍物。支持：
1. 查询某个联通块的大小
2. 把某个格子变成障碍物/空地

### 核心思想

- 二维坐标映射到一维：`id = (x-1) * m + y`
- 相邻空地合并到同一集合
- 删除格子时，不能直接修改并查集结构（会破坏子节点指向），需要新建节点

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1005;
const int MAXN = N * N + N * N;  // 预留新建节点的空间

int f[MAXN], sz[MAXN];
int mp[N * N];  // mp[id] 记录该位置对应的并查集节点编号
int tot;        // 当前最大节点编号

int find(int x) {
    if (x == f[x]) return x;
    return f[x] = find(f[x]);
}

void unite(int x, int y) {
    int fx = find(x), fy = find(y);
    if (fx != fy) {
        f[fx] = fy;
        sz[fy] += sz[fx];
    }
}

int n, m;
int dx[] = {0, 0, 1, -1};
int dy[] = {1, -1, 0, 0};

int getid(int x, int y) {
    return (x - 1) * m + y;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    cin >> n >> m;
    
    // 初始化
    tot = n * m;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            int id = getid(i, j);
            char c;
            cin >> c;
            if (c == '.') {
                mp[id] = id;  // 空地，用自己的编号
                f[id] = id;
                sz[id] = 1;
            } else {
                mp[id] = 0;  // 障碍物
            }
        }
    }
    
    // 合并相邻空地
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            int id = getid(i, j);
            if (mp[id]) {
                for (int k = 0; k < 4; k++) {
                    int ni = i + dx[k], nj = j + dy[k];
                    if (ni >= 1 && ni <= n && nj >= 1 && nj <= m) {
                        int nid = getid(ni, nj);
                        if (mp[nid]) {
                            unite(id, nid);
                        }
                    }
                }
            }
        }
    }
    
    int q;
    cin >> q;
    while (q--) {
        int op, cs;
        cin >> op >> cs;
        
        if (op == 1) {
            // 查询最大联通块
            int max_sz = 0, ans_idx = 1;
            for (int i = 1; i <= cs; i++) {
                int x, y;
                cin >> x >> y;
                int id = getid(x, y);
                if (mp[id]) {
                    int root = find(mp[id]);
                    if (sz[root] > max_sz) {
                        max_sz = sz[root];
                        ans_idx = i;
                    }
                }
            }
            cout << ans_idx << "\n";
        } else {
            // 修改格子状态
            for (int i = 1; i <= cs; i++) {
                int x, y;
                cin >> x >> y;
                int id = getid(x, y);
                
                if (mp[id]) {
                    // 变成障碍物：从集合中移除
                    // 不能直接修改，会破坏子节点
                    int root = find(mp[id]);
                    sz[root]--;
                    mp[id] = 0;
                } else {
                    // 变成空地：新建节点
                    tot++;
                    mp[id] = tot;
                    f[tot] = tot;
                    sz[tot] = 1;
                    
                    // 合并相邻空地
                    for (int k = 0; k < 4; k++) {
                        int ni = x + dx[k], nj = y + dy[k];
                        if (ni >= 1 && ni <= n && nj >= 1 && nj <= m) {
                            int nid = getid(ni, nj);
                            if (mp[nid]) {
                                unite(tot, mp[nid]);
                            }
                        }
                    }
                }
            }
        }
    }
    
    return 0;
}
```

**关键点**：
- 删除节点时，只减少集合大小，不修改并查集结构
- 新增节点时，用新的编号，避免破坏已有结构

> **本节重点**：
> - 并查集核心：`find` 找根，`unite` 合并，用根节点标识集合
> - 路径压缩：`f[x] = find(f[x])`，均摊 O(α)，最常用
> - 按秩合并：矮树挂高树，O(log N)，需要维护树结构时用
> - 带权并查集：在 `init`/`find`/`unite` 三处正确维护权值
> - **常见坑**：
>   - 删除节点不能直接改父指针，会破坏子节点指向
>   - 带权并查集路径压缩时，权值传递顺序不能错
>   - Kruskal 要判断是否已形成生成树（cnt == n-1）
