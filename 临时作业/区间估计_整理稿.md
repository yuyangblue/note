## 一、为什么要从点估计转向区间估计（00:00）

假设从同一个总体里抽一批样本求均值，第一批抽 64 个，算出来是 50；再换一批抽 64 个，很可能就不是 50 了。不同批次之间的随机性让单个点估计显得不太可靠。于是我们想：能不能不要只给一个点，而是给一个区间，并且附带一个保证——比如以 1−α 的概率，这个区间能把我们关心的真值包在里面。

这样一来，给出的信息比一个点更宽泛，但可靠性有了明确的保障。这就是从点估计转到区间估计的动机。

我们想达到的目标有两条：第一，区间在分布下覆盖的概率是我们能控制的，比如 95%、98%，由自己选；第二，最终写出来的区间，要把未知参数（而不是数据）夹在上下界之间。

## 二、正态情形下精确置信区间的构造（09:18）

先看最理想的情形：数据来自正态分布，估计量是样本均值。利用正态分布的性质可以直接知道 X̄ 的确切分布：若 X₁,…,Xₙ 独立同分布于 N(μ, σ²)，则

X̄ ~ N(μ, σ²/n)

因为估计量的精确分布已知，就可以在这个分布下找区间。构造分三步：

1. **标准化**：减去均值、除以标准差，把估计量变成标准正态：
   (X̄ − μ)/(σ/√n) ~ N(0, 1)
2. **在标准正态上找对称区间**：取 [−1.96, 1.96]，恰好使 P(−1.96 ≤ Z ≤ 1.96) = 0.95（此时 α = 0.05）。
3. **等价变形**：把不等式里夹着的 Z 换成 μ，解出
   μ ∈ [X̄ − 1.96·σ/√n, X̄ + 1.96·σ/√n]

这里与只报告 X̄ 的区别在于：我们利用了分布本身的形状，直接找到了两侧各留出 α/2 的两个点。

**区间的随机性落在哪里**，这一点要讲清楚。随机性来自不同批次的抽样：第一批抽 64 个、第二批抽 64 个，每批构造出的区间都不一样。95% 说的是在这个"批次随机性"之下，长期来看有 95% 的区间会把参数包住。一旦真的观察到一批数据，上下界就是两个固定的数，真值虽然未知但也是固定的数，此时"真值是否属于这个区间"已经没有随机性可言。

## 三、分位数与置信水平（05:06）

上面的 1.96 来自标准正态的分位数。标准正态密度在 0 点对称、中间高、两边往下降；我们想找上下两个点，使中间覆盖的面积恰好是 1−α。做法是让上侧排除 α/2、下侧也排除 α/2：

记 q_{α/2} = Φ⁻¹(1 − α/2)，即 P(Z > q_{α/2}) = α/2。由对称性，下侧的分位点是 −q_{α/2}。于是

P(−q_{α/2} ≤ Z ≤ q_{α/2}) = 1 − α

α 之所以写成参数，是因为置信水平 1−α 由使用者指定：可以取 0.05，也可以取 0.01。不同置信水平对应不同的分位点；后续计算时要用的是 (1−α/2)-分位数，做题时要能自己对应上。

把 α = 0.05 换成一般的 1−α，正态情形下区间的通用形式就是

θ̂ₙ ± q_{α/2}·se(θ̂ₙ)

即：估计量，减／加"由 α 确定的分位数 × 对它放缩后的标准差"。要强调：只有在用标准正态分布做精确或近似刻画时，才会有这种对称形式。

## 四、置信区间的一般定义

一般地，用样本构造下界 a(X₁,…,Xₙ) 与上界 b(X₁,…,Xₙ)，记 Cₙ = [a, b]。若对任何一个可能的参数值 θ 都有

P_θ(θ ∈ Cₙ) ≥ 1 − α

就称 Cₙ 是置信水平 1−α 的置信区间（置信集）。在正态例子中，因为 X̄ 的分布精确已知，我们可以取到等号；把观测到的样本代进去，就得到具体的区间数值。

## 五、渐近置信区间（13:41、16:55）

以上是"恰好知道精确分布"的理想情况。有限样本下如果拿不到精确分布，但估计量具有渐近正态性，也能构造区间：设统计量标准化后依分布收敛到标准正态，

√n(θ̂ₙ − θ)/σ̂ₙ ⇝ N(0, 1)

则区间 θ̂ₙ ± q_{α/2}·σ̂ₙ/√n 满足 P_θ(θ ∈ Cₙ) → 1−α。这里证明所需要的全部工具就是渐近正态性（再用 Slutsky 把未知的标准差换成它的估计）。

两类区间的区别来自两种收敛性，是本节最容易混的地方：

- **精确区间**：对每个有限的 n 都成立，覆盖率直接等于 1−α；
- **渐近区间**：不对每个 n 成立，只在 n → ∞ 时覆盖率趋于 1−α，样本越大越接近。

所以只要依据的是"分布渐近收敛到正态"，得到的区间就是近似的 95% 区间，不能像正态情形那样宣称精确的 0.95。

## 六、例题：Poisson 参数的 95% 区间（16:55）

设数据有 100 个，来自 Poisson(λ)，λ 是要估计的参数；这批样本算出的样本均值为 14。构造 95% 置信区间。

按流程走：先写出标准化形式，明确均值与方差。Poisson 有 E(X) = Var(X) = λ，由中心极限定理

√n(X̄ − λ)/√λ ⇝ N(0, 1)

于是 λ̂ = X̄ = 14，se = √(λ/n)。但 λ 未知，区间里不能留着未知参数，所以把方差换成它的估计 λ̂：ŝe = √(λ̂/n) = √(14/100) ≈ 0.374。代入通用形式得

14 ± 1.96 × 0.374 ≈ (13.27, 14.73)

（数值为按上述公式复算；录音只给了 n = 100 与样本均值 14。）这个区间是**渐近**的：它依赖 CLT，还把真方差替换成了估计值，只有样本足够大时才接近 95% 的覆盖。

## 七、例题：Logistic 回归里 β₁ 的区间怎么读（25:31）

再看一个把区间"翻译成结论"的例子。设 X 是图片，Y 是类别标签：Y = 1 表示狗，Y = 0 表示猫。模型给出 P(Y = 1 | X)，比较狗、猫两个概率哪个大，就得到一个分类器——这就是逻辑回归用于图像分类的思路。更复杂的多类别情形，核心想法相同，只是函数构造和工具不同。

模型写成

P(Y = 1 | X) = e^(β₀ + β₁X) / (1 + e^(β₀ + β₁X))

我们关心的是 β₁：它刻画 X 与 Y 之间的联系。β₁ = 0 时，取不同的 X 对概率没有影响；β₁ > 0 是正向影响，β₁ < 0 是负向影响。β̂₁ 具有渐近正态性，标准误也能从样本算出来，于是照上一节的形式得到 95% 区间。录音给出的区间约为 (1.87, 2.25)（口述值，无法与课件交叉核对）。

**读区间的方式**：整个区间都是正数，0 不在其中，于是有理由认为这个特征 X 对"是狗"的概率存在正向影响。也就是说，区间不只是给一个范围，它的符号本身就能支撑结论；本题正是要练习把区间数值翻译回实际问题。

## 八、非正态分布：均匀分布的精确区间（31:52、47:25）

前面遇到的要么是标准正态，要么是数据来自正态、样本均值仍是精确正态。若分布不是正态，比如 X₁,…,Xₙ ~ Uniform(0, θ)，MLE 是最大次序统计量 θ̂ = X₍ₙ₎，它的精确分布可以直接算出来；而且它的渐近分布也不是正态（n(θ − θ̂)/θ 收敛到指数分布）。所以前面"θ̂ ± q·se"的形式不适用，要另找枢轴量。

课堂按 A–D 四步构造，关键是前两步：

1. **构造与参数无关的量**：取 U = θ̂/θ = X₍ₙ₎/θ。由 P(X₍ₙ₎ ≤ t) = (t/θ)ⁿ 得
   P(U ≤ u) = uⁿ, 0 ≤ u ≤ 1
   这个分布里不含 θ，这正是做这个变换的原因。
2. **确定临界值**：令 P(U ≥ c) = 1 − cⁿ = 1 − α，反解出 c = α^(1/n)。
3. **利用支撑给出另一端**：θ̂ ≤ θ 恒成立（最大值不可能超过上界），所以下界直接取 θ̂，不必再靠分位数。
4. **写成 θ 的区间**：由 U ≥ c 得 θ ≤ θ̂/c，于是
   θ ∈ [X₍ₙ₎, X₍ₙ₎/α^(1/n)]

这是一个**非对称**区间：上界来自精确分布的分位点，下界来自支撑约束。录音给出的数值约为 (8, 10.79)——按 θ̂ = 8、n = 10、α = 0.05 复算，8/0.05^(1/10) ≈ 10.79，与录音一致。

这里不套标准正态形式，有两个理由：极大值估计的精确分布已知，可以直接用；而且它的渐近分布也不是正态。

## 九、方差的精确区间：卡方分布（47:25）

再看均值与方差都不知道的正态样本。已算出 MLE：μ̂ = X̄，σ̂² = (1/n)Σ(Xᵢ − X̄)²。我们要对 σ² 构造 90%、95% 这样的区间。两条思路：一是用渐近分布，二是用精确分布；这里走第二条，因为

n·σ̂²/σ² ~ χ²ₙ₋₁

卡方分布的含义：自由度为 k 时，它是 k 个独立标准正态变量的平方和。因为全是平方、取值非负，它一定右偏、不对称，所以上下分位点不能像正态那样直接取相反数。记 χ²ₖ,₁₋α/₂ 与 χ²ₖ,α/₂ 为卡出上、下各 α/2 面积的两个分位点，则

P(χ²ₙ₋₁,α/₂ ≤ n σ̂²/σ² ≤ χ²ₙ₋₁,₁₋α/₂) = 1 − α

把不等式对 σ² 做等价变形（注意取倒数时不等号翻方向），就得到 σ² 的 1−α 精确置信区间。这里用的仍是同一套流程：先找一个分布与参数无关的量，卡出 1−α 概率，再解出参数的范围；只是分布从标准正态换成了卡方。

## 十、极端数据：300 件全部合格（56:37、01:03:12）

生产线抽样，结果只有合格／不合格。独立随机抽取 300 次，发现全部合格。设每次不合格的概率为 p，K 是 300 次中的不合格件数，则 K ~ Bin(300, p)，观测值 K = 0，于是 p̂ = 0。

若照搬渐近正态区间 p̂ ± q_{α/2}√(p̂(1−p̂)/n)，代进去得到 [0, 0]：形式上套用了极限理论，实际上给出一个毫无意义的区间。问题在于渐近正态只在样本足够大、且 p 不贴着边界时才近似成立；这里 p̂ = 0 使估计的标准误也是 0，正态近似离真实分布很远。

正确的做法是回到精确分布：

P(K = 0) = (1 − p)³⁰⁰

它随 p 单调递减：p 越大，越不可能观测到"全合格"这件事。反过来，既然已经观测到这件事，就要求这个概率不至于太小，即 (1 − p)³⁰⁰ ≥ α。取 α = 0.05 解得

p ≤ 1 − 0.05^(1/300) ≈ 0.00994 ≈ 1%

所以不合格率的**单侧** 95% 置信区间是 [0, 1%]：下界取 0（p 越小越能解释全合格），上界由上面的临界值给出，"单侧"是因为只用到了下侧的概率信息。这个例子说明：当渐近方法给出的区间明显不合理时，要换策略；恰好数据满足二项分布，就能直接算出合理且精确的上限。

## 十一、小结：从概率回到统计（01:08:34、01:12:33）

学这门课之前，看到一批数据会觉得它是确定发生的事件；学统计之后，理解变成：数据是从某个分布里随机抽样出来的，出现在你面前是偶然的。图像生成模型也是这个思路——把图像当作从某个分布抽出来的样本，再去学这个分布。

于是统计分析的出发点是：手上有一组观测 X₁,…,Xₙ，背后暗含一个生成它们的模型，我们只是恰好看到了某一次随机产生的结果；要做的反推，就是从数据去讨论这个模型。模型可以有很多种，只要能生成这类数据。模型越复杂，能刻画的特征越多，但有限的数据越难把它还原出来——这就是模型复杂度与数据量之间的权衡。本课程主要处理其中较简单的一类：参数模型，即先假设分布属于某一族、只有若干参数未知，再用数据把这些参数恢复出来，从而刻画数据背后的统计规律。

这一小节的概念链是：统计模型 → 参数与参数空间 → 样本、估计量与估计值 → 两类构造估计量的方法（矩估计、极大似然）→ 评价指标（偏差、标准误、均方误差）→ 大样本性质（相合性、渐近正态性）→ 区间估计（精确或渐近的覆盖率保证）。前一半讨论估计量的平均行为与样本量很大时的行为，后一半讨论不只看一个点、而是给出更有统计保证的区间。

## 十二、补充：样本均值与样本方差为什么独立（01:15:18）

正态样本里，X̄ 与 σ̂² 不仅各自能算出分布，而且相互独立；由此还能推出 t 分布。证明要用到三条性质：

1. 多元正态中，不相关等价于独立；协方差矩阵是单位阵时，各分量两两独立；
2. 多元正态经线性变换后仍是正态，只要把均值与协方差这两个参数重新算出来即可；
3. 卡方分布是独立标准正态变量的平方和。

设标准化后的样本向量 Z = (X − μ)/σ ~ Nₙ(0, Iₙ)。样本均值是 Z 的一个线性组合，因此思路是：找一个正交矩阵 A，使 Y = AZ 的第一个分量恰好是 √n 倍（标准化后的）样本均值。把 A 的第一行定为 (1/√n, …, 1/√n)——它的长度为 1——再把这个单位向量补成一组标准正交基，就得到所需的正交矩阵。

正交变换不改变独立性，于是 Y₁ 与 Y₂,…,Yₙ 相互独立，且各分量仍是标准正态；正交变换还保持平方和不变：ΣYᵢ² = ΣZᵢ²。把 Y₁ 那一项减掉并展开，就有

Σᵢ₌₂ⁿ Yᵢ² = Σ(Zᵢ − Z̄)² = n·σ̂²/σ²

右边正是 n−1 个独立标准正态的平方和，即服从 χ²ₙ₋₁；而它只依赖 Y₂,…,Yₙ，与只依赖 Y₁ 的样本均值独立。这就是"把整体信息拆成均值那一份和方差那一份、两份彼此独立"的核心。

这个结果有两个用途。第一，前面卡方方差区间里直接拿来用的 n σ̂²/σ² ~ χ²ₙ₋₁，在这里得到了证明，因此那一节构造的是精确区间。第二，把标准化后的均值除以"样本标准差的估计"：

T = (X̄ − μ)/(S/√n) = Y₁ / √( (Σᵢ₌₂ⁿ Yᵢ²)/(n−1) )

分子是标准正态，分母是独立的 χ²ₙ₋₁ 除自由度再开方，按定义 T ~ tₙ₋₁。实际中方差通常未知，用样本标准差 S（分母 n−1）替换 σ 之后，构造均值置信区间就该用 t 分布的分位数，而不是 1.96；这同样是精确区间。
