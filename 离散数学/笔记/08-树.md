## 1. 树的模型与应用场景

### 1.1 什么是树状结构

树是一种特殊的图，核心特征是**连通而没有回路**。生活中大量层级结构天然是树：

| 模型 | 说明 |
|------|------|
| 家族族谱 | 伯努利家族数学家谱系（约翰一世→欧拉→拉格朗日→傅立叶/泊松） |
| 分子化合物 | 凯利用树表示饱和碳氢化合物 $C_nH_{2n+2}$，独立发现树结构 |
| 组织机构 | 总经理→部门经理→主任，每个节点一个职位 |
| 文件系统 | 根目录→子目录→文件，Linux 的 `/usr/bin` 等层级 |
| 并行计算网络 | 满二元树连接 $2^k-1$ 个处理器，三步完成八个数求和 |

### 1.2 树的三大经典应用

**（1）二元搜索树（BST）**

每个节点存一个元素，左子树所有元素的键值小于该节点，右子树所有元素的键值大于该节点。插入/查找时只需从根向下比较，最多比较次数 = 根到叶的最长通路长度。

**（2）决策树**

排序问题可用决策树建模：每个内部节点是一次比较，叶节点是一种排序结果。对 $n$ 个元素排序，至少需要 $\lceil \log_2(n!) \rceil$ 次比较（决策树的叶节点数至少为 $n!$）。

**（3）前缀码**

不定长编码需要避免歧义：任何一个字母的编码不能是另一个字母编码的前缀。用二元树构造前缀码——叶节点代表字母，从根到叶的路径（左0右1）就是该字母的编码。

例：E=0, A=10, T=110, N=1110, S=1111，互为前缀，解码无歧义。

## 2. 无向树的定义与等价刻画

### 2.1 基本定义

- **无向树（树）**：连通且不含回路的无向图，记作 $T$。
- **叶（树叶）**：度数为 1 的节点。
- **分支点（内部节点）**：度数大于 1 的节点。
- **森林**：每个连通分支都是树的无向图。
- **平凡树**：仅一个节点的图（平凡图），连通且无回路。

> 树一定是简单图：不含自环（自环是回路），不含平行边（平行边构成2阶回路）。
> 非平凡树中没有度数为 0 的节点（否则不连通）。

> 一棵单独的树也可以称为森林（满足"每个连通分支都是树"），这与生活常识略有不同。

### 2.2 树的六个等价定义

树可以用以下任意一种方式定义，它们完全等价：

| 编号 | 定义 |
|------|------|
| ① | 连通且不含回路 |
| ② | 无回路且 $m = n - 1$ |
| ③ | 连通且 $m = n - 1$ |
| ④ | 无回路，但在任意两节点间增加一条新边，得到唯一一条基本回路 |
| ⑤ | 连通，但删除任意一条边后便不再连通 |
| ⑥ | 每对节点之间有唯一一条基本通路 |

**等价性证明思路**：采用循环论证 ①→②→③→④→⑤→⑥→①，避免 $C_6^2 \times 2 = 30$ 次两两证明。

**①→② 证明（$m=n-1$）**：对节点数 $n$ 做归纳。
- $n=1$：平凡树，$m=0=n-1$。
- 假设 $n=k$ 成立。$n=k+1$ 时，树中至少有一个度为 1 的节点 $v_0$（若所有节点度≥2则必含回路）。删去 $v_0$ 及其关联边，得到 $k$ 个节点的树，由归纳假设有 $k-1$ 条边。加回 $v_0$ 和一条边，总边数 $= k = (k+1)-1$。

**②→③ 证明（连通性）**：假设有 $k$ 个连通分支，每个分支是树，故 $m_i = n_i - 1$。总边数 $m = \sum m_i = \sum(n_i-1) = n - k$。由 $m=n-1$ 得 $k=1$，即连通。

**③→④ 证明**：先用归纳证无回路（类似①→②，找度为1的节点删去），再证加边得唯一回路——连通则两节点间已有通路 $L$，加边构成回路；若回路不唯一，删去该边后仍有回路，与无回路矛盾。

### 2.3 树的核心性质

由等价定义可得：

- **树是边数最多的无回路图**：再加一条边就产生回路。
- **树是边数最少的连通图**：再删一条边就不连通。
- 树的边数恰好 $m = n - 1$，"增之一分则太长，减之一分则太短"。

### 2.4 握手定理 + $m=n-1$ 的联合应用

树的几乎所有证明和计算题都靠这两个公式联合求解。

**定理：非平凡树至少有两片叶。**

证明：设树有 $k$ 片叶（度为1），其余 $n-k$ 个分支点度≥2。由握手定理：

$$2m = \sum \deg(v) \ge k + 2(n-k) = 2n - k$$

代入 $m = n-1$：

$$2(n-1) \ge 2n - k \implies k \ge 2$$

**计算例题**：一棵无向树中有 4度、3度、2度的分支点各一个，其余为树叶，求树叶数。

设树叶数为 $x$，则 $n = 3 + x$。握手定理：

$$4 + 3 + 2 + x = 2m = 2(n-1) = 2(3+x-1)$$

$$9 + x = 4 + 2x \implies x = 5$$

即有 5 片树叶。

## 3. 生成树

### 3.1 定义

设 $G = \langle V, E \rangle$ 是无向图，若 $G$ 的某个**生成子图**是树，则称之为 $G$ 的**生成树**，记作 $T_G$。

- **树枝**：生成树 $T_G$ 中的边。
- **弦**：在 $G$ 中但不在 $T_G$ 中的边。
- **生成树的补**：所有弦的集合。

生成树必须同时满足：① 是生成子图（节点数与原图相同）；② 是树（连通且无回路）。二者缺一不可。

### 3.2 存在条件

**定理**：图 $G$ 存在生成树 $\iff$ $G$ 是连通图。

- 必要性：生成树连通，作为子图的原图必连通。
- 充分性（构造性证明）：若 $G$ 无回路，自身就是生成树；若有回路，在回路中删去一条边，仍连通且节点不变。重复此过程，最终得到无回路的连通生成子图，即生成树。

### 3.3 求生成树的算法

**（1）破圈法**

循环找到图中的回路，删除回路中的一条边。共删除 $m - (n-1) = m - n + 1$ 条边。

**（2）避圈法**

循环选取一条与已选边不构成回路的边，直到选满 $n-1$ 条边。

> 破圈法和避圈法得到的生成树可能不同——一个连通图的生成树通常不唯一。两种方法都涉及回路判定，计算机实现复杂度较高。

**（3）基于广度优先搜索（BFS）的生成树算法**

不需要回路判定，复杂度更低：

1. 任选节点 $s$，标记为 0，集合 $L = \{s\}$，未访问集 $V' = V - \{s\}$，边集 $E_T = \emptyset$。
2. 若 $V' = \emptyset$ 则结束；否则标记号 $k = k+1$。
3. 依次对 $L$ 中所有标记为 $k-1$ 的节点 $v$，若它与 $V'$ 中节点 $w$ 相连，则将 $w$ 标记为 $k$，指定 $v$ 为 $w$ 的前驱，$L \cup= \{w\}$，$V' -= \{w\}$，$E_T \cup= \{(v,w)\}$。
4. 回到步骤 2。

所有节点的"前驱边"构成一棵生成树。

### 3.4 应用：IP 组播

组播报文从源计算机发往多个目的计算机，数据走过的通路不应存在回路（避免重复转发和网络资源浪费）。求出源、目的和路由器构成的连通图的生成树，即可得到组播分发树。

## 4. 最小生成树

### 4.1 定义

设 $G = \langle V, E \rangle$ 是连通赋权图，$T$ 是 $G$ 的一棵生成树。$T$ 的所有树枝的权值之和称为 $T$ 的**权**，记作 $W(T)$。$G$ 中权最小的生成树称为**最小生成树**。

> 赋权图中可能存在权值相同的边，因此最小生成树也不一定唯一。

### 4.2 Kruskal（克鲁斯卡尔）算法

由避圈法推广而来：**按权从小到大选边，跳过会构成回路的边**。

算法步骤：
1. 选取权最小的边 $e_1$，$E_T = \{e_1\}$，$i=1$。
2. 若 $i = n-1$ 则结束。
3. 在未选边中选取 $e_{i+1}$，使得 $E_T \cup \{e_{i+1}\}$ 无回路，且 $e_{i+1}$ 是满足条件的最小权边。
4. $E_T \cup= \{e_{i+1}\}$，$i=i+1$，回到步骤 2。

> Kruskal 需要回路判定，常用并查集（Union-Find）高效实现。算法复杂度 $O(m \log m)$（主要在排序）。

### 4.3 Prim（普里姆）算法

从任意节点开始，**每次在"已选节点集"与"未选节点集"之间选最小权边**，天然避免回路。

算法步骤：
1. 任选节点 $v_1$，$V_T = \{v_1\}$，$E_T = \emptyset$，$k=1$。
2. 在 $V - V_T$ 中选取节点 $v_j$，使得存在 $v_i \in V_T$ 且边 $(v_i, v_j)$ 的权最小。
3. $V_T \cup= \{v_j\}$，$E_T \cup= \{(v_i, v_j)\}$，$k=k+1$。
4. 重复直到 $k = n$。

> Prim 不需要回路判定，用邻接矩阵 + 最小权数组实现，复杂度 $O(n^2)$，适合稠密图。

### 4.4 两算法对比

| 维度 | Kruskal | Prim |
|------|---------|------|
| 核心思想 | 全局选最小边，避圈 | 从已选集向外扩展最小边 |
| 回路判定 | 需要（并查集） | 不需要 |
| 适合图 | 稀疏图 | 稠密图 |
| 复杂度 | $O(m \log m)$ | $O(n^2)$ |

## 5. 根树

### 5.1 有向树与根树

- **有向树**：略去所有有向边的方向后，所得无向图是一棵树。
- **根树（外向树）**：一棵非平凡有向树，恰有一个节点入度为 0，其余所有节点入度均为 1。

根树中的节点分类：

| 类型 | 定义 |
|------|------|
| 树根 | 入度为 0 的节点 |
| 树叶 | 出度为 0 的节点 |
| 内点 | 入度为 1 且出度 > 0 的节点 |
| 分支点 | 内点 + 树根（都可以"分支"） |

### 5.2 层数与高

- **层数**：从根到该节点的通路长度（边数）。根的层数为 0（或 1，视教材约定）。
- **高**：所有节点层数的最大值。

> 画根树时通常根在上、叶在下，有向边方向向下，可省略箭头。这与哈斯图（箭头向上）方向相反。

### 5.3 家族关系命名

根树的节点间关系借用家族称谓：

| 关系 | 定义 |
|------|------|
| 祖先 / 后代 | 若从 $v_i$ 到 $v_j$ 可达，则 $v_i$ 是 $v_j$ 的祖先，$v_j$ 是 $v_i$ 的后代 |
| 父亲 / 儿子 | 若 $v_i \to v_j$ 是根树中的有向边，则 $v_i$ 是父亲，$v_j$ 是儿子 |
| 兄弟 | 同一个父亲的儿子们 |

### 5.4 有序树与 K 元树

- **有序树**：规定了每一层上节点的次序的根树。
- **K 元树**：每个分支点至多有 $K$ 个儿子。
- **满 K 元树**：每个分支点恰好有 $K$ 个儿子。
- **K 元有序树 / 满 K 元有序树**：同时满足有序性。

> 主要研究二元树，因为所有根树都可以转化为二元树。

二元有序树中，每个节点的两个儿子分别称为**左儿子**和**右儿子**，对应的子树称为**左子树**和**右子树**。

> 注意区分：以节点 $v$ 为根的**子树** = $v$ 及其所有后代；$v$ 的**左子树** = 以 $v$ 的左儿子为根的子树。前者包含 $v$ 本身，后者不包含。

### 5.5 满 K 元树的重要定理

**定理**：在满 K 元树中，若树叶数为 $t$，分支点数为 $i$，则

$$(K-1) \cdot i = t - 1$$

**证明**：总节点数 $= i + t$，边数 $= (i+t) - 1$（树的性质）。由握手定理（出度之和 = 边数），每个分支点出度为 $K$，故总出度 $= K \cdot i$。因此：

$$K \cdot i = i + t - 1 \implies (K-1)i = t - 1$$

**应用例题**：一台计算机的加法指令可直接计算三个数的和，求 9 个数之和至少执行几次加法指令？

转化为：求含 9 片树叶的满三元树的分支点数。$K=3, t=9$：

$$(3-1)i = 9-1 \implies i = 4$$

即至少 4 次加法指令。若用多处理器并行，平衡的满三元树只需 2 个时间单位（3个处理器同时算第一层，再1个算第二层），而串行链需要 4 个时间单位。

## 6. 根树的遍历

### 6.1 遍历的定义

**根树的遍历**：系统地访问树的每个节点，使得每个节点恰好被访问一次。

### 6.2 二元树的三种遍历

二元树分为根、左子树、右子树三部分，按根的访问位置分为三种：

| 遍历方式 | 顺序 | 口诀 |
|----------|------|------|
| 先根遍历（前序） | 根 → 左子树 → 右子树 | 根左右 |
| 中根遍历（中序） | 左子树 → 根 → 右子树 | 左根右 |
| 后根遍历（后序） | 左子树 → 右子树 → 根 | 左右根 |

均为递归定义：对子树也按同样规则遍历。

**示例**：对一棵根为 A、左子树 B(D,G,H)、右子树 C(E(I,J(K,L,M)),F) 的二元树：
- 先根：A B D G H C E I J K L M F
- 中根：G D H B A I E K L J M C F（按左根右递归）
- 后根：G H D B I K L M J E F C A

### 6.3 表达式树与三种表达式形式

算术表达式可用二元树表示：叶节点是数字/变量，分支节点是运算符。

对表达式树做不同遍历得到不同形式：

| 遍历方式 | 表达式形式 | 别名 | 求值方向 | 是否需要括号 |
|----------|-----------|------|----------|-------------|
| 中根遍历 | 中缀表达式 | — | 需括号定序 | 需要 |
| 先根遍历 | 前缀表达式 | 波兰符号法 | 从右向左 | 不需要 |
| 后根遍历 | 后缀表达式 | 逆波兰符号法 | 从左向右 | 不需要 |

**前缀/后缀无二义性**：三个不同的表达式树可能有相同的中缀形式（如 $X+Y/X+3$ 不加括号有歧义），但前缀和后缀形式各不相同。因此编译器大量使用后缀表达式（栈求值：遇操作数入栈，遇运算符弹出两个操作数计算后结果入栈）。

### 6.4 一般 K 元树的遍历

K 元树分为根 + K 棵子树，只有两种遍历：
- **先根次序**：先访问根，再从左到右按先根次序遍历各子树。
- **后根次序**：先从左到右按后根次序遍历各子树，再访问根。

## 7. 最优树与哈夫曼算法

### 7.1 前缀码

**前缀**：符号串 $a_1a_2\cdots a_n$ 的子串 $a_1$、$a_1a_2$、...、$a_1a_2\cdots a_{n-1}$ 分别是其长度为 1、2、...、$n-1$ 的前缀。

**前缀码**：在一组符号串 $\{b_1, b_2, \dots, b_m\}$ 中，任何两个不同的符号串互不为前缀。只含 0 和 1 的前缀码称为**二元前缀码**。

例：$\{1, 00, 010, 011\}$ 是前缀码；$\{1, 11, 001, 0011\}$ 不是（1是11的前缀，001是0011的前缀）。

### 7.2 用二元树构造二元前缀码

构造一棵有 $t$ 片树叶的二元树，每个分支点引出的左标 0、右标 1（只有一个儿子时可标 0 或 1）。从根到每片树叶的路径上的标号串，就是该叶对应符号的编码。

**为什么这样得到的一定是前缀码**：一片树叶不可能在另一片树叶的根到叶路径上（否则它就不是树叶了），所以任何两个叶的编码互不为前缀。

### 7.3 最优树的定义

- **赋权二元树**：对二元树的所有 $t$ 片叶赋予权值 $w_1, w_2, \dots, w_t$。
- **赋权二元树的权**：$W(T) = \sum_{i=1}^{t} w_i \cdot l(w_i)$，其中 $l(w_i)$ 是权为 $w_i$ 的叶的层数（路径长度）。
- **最优树**：在所有具有相同叶权 $w_1, \dots, w_t$ 的二元树中，权 $W(T)$ 最小的二元树。

直观理解：出现频率高（权大）的符号应放在离根近的位置（层数小），使总编码长度最短。

### 7.4 哈夫曼（Huffman）算法

1952 年由 Huffman 提出。算法步骤：

1. 初始集合 $S = \{w_1, w_2, \dots, w_t\}$。
2. 从 $S$ 中取出两个最小的权 $w_i, w_j$，画节点 $v_i, v_j$（带权 $w_i, w_j$），画它们的父亲 $v$，令 $v$ 的权为 $w_i + w_j$。
3. 从 $S$ 中去掉 $w_i, w_j$，加入 $w_i + w_j$。
4. 若 $S$ 只剩一个元素则停止；否则回到步骤 2。

**示例**：叶权 7, 8, 9, 12, 16。
- 选 7+8=15，$S=\{9,12,15,16\}$
- 选 9+12=21，$S=\{15,16,21\}$
- 选 15+16=31，$S=\{21,31\}$
- 选 21+31=52，结束。

最终树的权 $W(T) = 7\times3 + 8\times3 + 9\times2 + 12\times2 + 16\times1 = 21+24+18+24+16 = 103$（层数根据实际树结构计算）。

### 7.5 应用：最优前缀编码

已知字母 A-F 出现频率 30%, 25%, 20%, 10%, 10%, 5%，构造使传输二进制位最少的前缀码：

1. 以频率为权，用 Huffman 算法构造最优二元树。
2. 左标 0、右标 1，从根到叶得到各字母编码。

可能结果（具体树结构取决于合并顺序）：
- A=11, B=10, C=01, D=001, E=0001, F=0000

平均码长 $= 2\times0.30 + 2\times0.25 + 2\times0.20 + 3\times0.10 + 4\times0.10 + 4\times0.05 = 2.25$ 位/字母，优于等长编码的 3 位/字母。

### 7.6 应用：决策树优化

用机器分辨 1分、2分、5分硬币，出现概率 0.5, 0.4, 0.1。设计分辨算法使平均时间最少：

以概率为权构造最优二元树：0.1 和 0.4 合并为 0.5，再与 0.5 合并为 1。

决策流程：先判断是否1分（概率0.5，1次判断）；若不是，判断是否2分（概率0.4，2次判断）；否则是5分（概率0.1，2次判断）。

平均时间 $= 1\times0.5 + 2\times0.4 + 2\times0.1 = 1.5$ 个时间单位。

## 8. 本章重点

> **本节重点**：
> - 无向树的定义：连通且无回路，核心公式 $m = n - 1$，与握手定理联合解题是必考题型。
> - 树的六个等价定义要熟悉，循环论证是证明等价性的标准技巧。
> - 生成树：连通图必有生成树；破圈法删 $m-n+1$ 条边，避圈法选 $n-1$ 条边；BFS 生成树不需要回路判定。
> - 最小生成树：Kruskal（全局选最小边+并查集避圈）和 Prim（从已选集向外扩展），两者对比要清楚。
> - 根树：入度0为根、出度0为叶、入度1出度>0为内点；层数和高的定义。
> - 满 K 元树定理 $(K-1)i = t-1$，常用于计算分支点/树叶数和并行加法问题。
> - 二元树三种遍历（先根/中根/后根）对应前缀（波兰）/中缀/后缀（逆波兰）表达式，前缀后缀无二义性。
> - 前缀码定义 + 二元树构造方法 + Huffman 算法求最优树，是本章最实用的算法。
> - **常见坑**：① 树一定是简单图（无自环无平行边）；② 非平凡树至少两片叶（不是一片）；③ 中缀表达式需要括号，前缀后缀不需要；④ Huffman 算法每次选两个最小权，合并后放回继续选。
