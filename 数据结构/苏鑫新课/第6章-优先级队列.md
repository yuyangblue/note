## 一、优先级队列的定义

### 1. 从普通队列到优先级队列

**概念** 普通队列是先进先出（FIFO）：先入队的元素先出队。优先级队列（Priority Queue）改变了出队规则——每次出队的是**优先级最高**的元素，而与入队先后无关。课件以"值最小"为优先级最高，故出队操作取名 `ExtractMin`。

**动机** 许多问题只关心"当前最急、最小、最优的那一个"，而不要求整体有序。例如操作系统调度中最先执行最高优先级进程，事件模拟中总要处理时间最早的事件，哈夫曼算法中每轮取权重最小的两棵树（见 [[第5章-树和二叉树.md]] 与本章第五节）。若用排序数组实现，每次插入要挪动元素；若用有序链表，取最小是 $O(1)$ 而插入是 $O(n)$。堆结构把两种操作都压到 $O(\log n)$。

### 2. 优先级队列 ADT

```
ADT PriorityQueue {
    数据对象：元素取自全集 U 的可重集合 E，表示优先级队列中包含的元素。
    数据关系：全集 U 中的元素须满足严格弱序。
    基本操作：（初始化、销毁、清空、判空、求个数等从略）
        Insert(pq, x)      在 pq 中插入元素 x。
        ExtractMin(pq)     删除并返回优先级最高（值最小）的元素。
        PeekMin(pq)        返回值最小的元素，但元素仍留在 pq 中。
}
```

`ExtractMin` 与 `PeekMin` 的差别是前者改变队列、后者只读。优先级用"值最小"表示是约定，最大优先队列只需把比较方向反过来。

### 3. 实现途径与本章路线

**思路** 实现优先级队列的难点是同时做好"插入"与"取最小"。可行路线：

- 无序数组或链表：插入 $O(1)$，取最小 $O(n)$；
- 有序数组或链表：取最小 $O(1)$，插入 $O(n)$；
- 二叉堆：两者 $O(\log n)$，建堆 $O(n)$，综合最优，本章第二节详述；
- D 叉堆：调节插入与取最小的比重，第三节；
- 可并堆：把"合并两个队列"做成基本操作，第四节。

## 二、二叉堆

### 1. 二叉堆的定义与下标约定

**概念** 二叉堆是一棵**完全二叉树**，且父子结点满足堆序。若所有父结点元素不大于子结点元素，称**最小堆**；反之称**最大堆**。本章以最小堆为例，最大堆把不等号反向即可。

注意两件事：其一，"完全二叉树"保证树高为 $\lfloor\log_2 n\rfloor$，且可用数组连续存放不留空洞；其二，"堆序"只约束父子，不约束兄弟以及祖先与后代的远近关系，所以堆不是排序好的。

**下标约定（1 起算）** 课件二叉堆部分把数据存在数组 `data[1..size]`，下标 0 闲置：

| 关系 | 下标公式 |
|---|---|
| 父结点 | $\lfloor i/2\rfloor$（$i>1$） |
| 左孩子 | $2i$ |
| 右孩子 | $2i+1$ |
| 最后元素 | $size$ |

存成 C++ 结构如下，后续算法都把它作为整体传入。

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;

struct BinHeap {
    vector<int> data;   /* data[0] 闲置；元素存放在 data[1..size] */
    int size = 0;       /* 元素个数，同时是最后一个元素的下标 */
    BinHeap() { data.push_back(0); }              /* 占位下标 0 */
};
```

### 2. 上调 SiftUp（算法 6-1）

**思路** 插入把新元素放到末尾，可能破坏堆序——只可能违反"该元素比父结点小"这一条，因为原来的树本已满足堆序。修法：拿新元素 `elem` 与父结点比较，若 `elem` 更小就把父结点**下移**一层，继续向上比，直到 `elem` 不小于父结点或到达根；最后把 `elem` 放进空出来的位置。每轮只挪动一个元素（洞式下移），比反复交换省一半赋值。

```cpp
/* 算法 6-1：从位置 i 上调 */
void SiftUp(BinHeap& h, int i) {
    int elem = h.data[i];
    while (i > 1 && elem < h.data[i / 2]) {
        h.data[i] = h.data[i / 2];   /* 父结点下移，空出父位 */
        i /= 2;
    }
    h.data[i] = elem;                /* 填入 elem 的最终位置 */
}
```

思路：循环每轮把较小者往上送一层，且只动了一条从 i 到根的路径。退出时 `elem` 的父结点不大于 `elem`；它的子结点（原路径上被下移过的那些）都曾比 `elem` 大，下移后仍不小于 `elem` 的新位置——堆序在整条路径上恢复，其余路径未受影响。

### 3. 下调 SiftDown（算法 6-2）

**思路** 下调用于"根被换成较大元素"的场合。比较两个孩子（取较小者）与 `elem`：若较小孩子比 `elem` 还小，就把该孩子**上移**，空出其位置，`elem` 继续往下；直到 `elem` 不大于两个孩子或落到叶子。每轮只比较两个孩子，故单轮 $O(1)$，总轮数为树高。

```cpp
/* 算法 6-2：从位置 i 下调 */
void SiftDown(BinHeap& h, int i) {
    int n = h.size, elem = h.data[i];
    while (true) {
        int child = 2 * i;                       /* 先指向左孩子 */
        if (child > n) break;                    /* 无孩子，是叶子 */
        if (child < n && h.data[child + 1] < h.data[child])
            ++child;                             /* 右孩子存在且更小，改指右孩子 */
        if (h.data[child] >= elem) break;        /* 较小孩子都不小于 elem */
        h.data[i] = h.data[child];               /* 较小孩子上移 */
        i = child;
    }
    h.data[i] = elem;
}
```

注意 `child < n` 这一步判右孩子是否存在；若写成 `child + 1 <= n` 会越界。课件原文用 `child > last` 判叶、用 `child < last` 判右孩子，语义与此处一致。

### 4. 插入与删顶（算法 6-3、6-4）

插入直接复用上调：把 x 放到第 `size+1` 位（保持完全二叉树），再上调。

```cpp
/* 算法 6-3：插入 */
void Insert(BinHeap& h, int x) {
    ++h.size;
    h.data.push_back(x);
    SiftUp(h, h.size);
}
```

删顶取出根（最小元），把原最后一个元素搬到根以维持完全二叉树，再把根下调。注意顺序：先保存 `min_key`、先覆盖根、**后**减 `size`，这样 `SiftDown` 看到的 `n` 是删除后的元素个数。

```cpp
/* 算法 6-4：删顶 */
int ExtractMin(BinHeap& h) {
    int min_key = h.data[1];
    h.data[1] = h.data[h.size];
    --h.size;
    h.data.pop_back();
    SiftDown(h, 1);
    return min_key;
}

int PeekMin(BinHeap const& h) { return h.data[1]; }   /* O(1)，只读 */
```

### 5. 建堆：朴素与快速（算法 6-5、6-6）

**思路** 给定 n 个无序数据，有两种一次建成堆的办法：

- 朴素建堆（算法 6-5）：从第二个元素起逐个上调。每插入一个就把它并入已有的堆，等价于连续 n-1 次 Insert。
- 快速建堆（算法 6-6）：叶子天然满足堆序，只需从最后一个非叶结点 $\lfloor n/2\rfloor$ 倒着下调到根。下调时它的子树已经是堆，调完即整棵树是堆，这是自底向上的归纳。

```cpp
/* 算法 6-5：朴素建堆，data[1..size] 已装好 n 个元素 */
void MakeHeapUp(BinHeap& h) {
    for (int i = 2; i <= h.size; ++i) SiftUp(h, i);
}

/* 算法 6-6：快速建堆 */
void MakeHeapDown(BinHeap& h) {
    for (int i = h.size / 2; i >= 1; --i) SiftDown(h, i);
}
```

思路：快速建堆之所以是 $O(n)$，是因为高度为 $k$ 的结点至多 $\lceil n/2^{k+1}\rceil$ 个，下调最多走 $k$ 层，故总代价

$$\sum_{k\ge 0} \left\lceil \frac{n}{2^{k+1}} \right\rceil \cdot k \;\le\; n\sum_{k\ge 0}\frac{k}{2^{k+1}} \;=\; 2n \;=\; O(n).$$

而朴素建堆的上调总成本是 $\sum_{i=2}^{n} O(\log i) = O(n\log n)$。这就是"先装数据再自底向上调"优于"逐个插入"的原因。

### 6. 二叉堆的复杂度小结

| 操作 | 实现 | 时间复杂度 |
|---|---|---|
| PeekMin | 读根 | $O(1)$ |
| Insert | 末尾加 SiftUp | $O(\log n)$ |
| ExtractMin | 根换末加 SiftDown | $O(\log n)$ |
| MakeHeapUp | 逐个 SiftUp | $O(n\log n)$ |
| MakeHeapDown | 自底向上 SiftDown | $O(n)$ |

空间 $O(n)$，仅用一个数组，不需要指针。

## 三、多叉堆

### 1. D 堆的定义与下标约定

**概念** 把二叉堆的"每个结点 2 个孩子"推广为"每个结点最多 d 个孩子"，得 **d 叉堆（D 堆）**，仍是一棵完全 d 叉树且满足堆序（父小于等于子）。

**下标约定（0 起算）** 课件多叉堆改用数组下标从 0 开始，这与上一节的二叉堆（1 起算）不同，务必分清：

| 关系 | 下标公式 |
|---|---|
| 父结点 | $\lfloor (i-1)/d\rfloor$（$i>0$） |
| 第 k 个孩子 | $d\cdot i + k$（$k=1,2,\dots,d$） |
| 最后元素 | $n-1$ |

**动机** 二叉堆树高 $\log_2 n$；D 堆树高 $\log_d n$，插入时向上走的层数更少。代价是下调时每层要比较 d 个孩子。当插入远多于删顶时，取较大的 d 有利。

### 2. 上调 SiftUpD（算法 6-7）

与二叉堆同构，只把"除以 2"换成"除以 d"、"下标 1 起"换成"下标 0 起"：

```cpp
/* 算法 6-7：d 叉堆上调，a 为 0 起算数组 */
void SiftUpD(vector<int>& a, int d, int i) {
    int elem = a[i];
    while (i > 0 && elem < a[(i - 1) / d]) {
        a[i] = a[(i - 1) / d];
        i = (i - 1) / d;
    }
    a[i] = elem;
}
```

### 3. 下调 SiftDownD（算法 6-8）

**思路** 从位置 i 出发，在至多 d 个孩子中找最小者；若它比 `elem` 小就上移，`elem` 继续下沉；否则位置合适，定位成功。

注意：课件算法 6-8 原文有一处 bug，本笔记按正确写法给出。原文用 `child ← i` 初始化，并用 `if child = i` 判断"i 是叶子"。这是错的：查找最小孩子时应把 `child` 初始化为**第一个孩子** `d·i+1`，并用第一个孩子是否存在（`child < n`）判叶。原文的比较是把各孩子与 `a[i]`（刚被上移上来的值）比，而不是与 `elem`（真正要下沉的值）比——当所有孩子都不小于 `a[i]`、却存在小于 `elem` 的孩子时，算法会误判为叶子提前结束，堆序被破坏。实测 d=2 至 5 有大量反例。正确写法：孩子下标上限取 $\min(d\cdot i+d,\ n-1)$ 防止越界。

```cpp
/* 算法 6-8（修正版）：d 叉堆下调，a 为 0 起算数组 */
void SiftDownD(vector<int>& a, int d, int i) {
    int n = (int)a.size();
    int elem = a[i];
    while (true) {
        int first = d * i + 1;                       /* 第一个孩子 */
        if (first >= n) break;                       /* 没有孩子即叶子 */
        int last = min(d * i + d, n - 1);            /* 孩子下标上限，防越界 */
        int child = first;                           /* 从第一个孩子开始找最小 */
        for (int k = first + 1; k <= last; ++k)
            if (a[k] < a[child]) child = k;
        if (a[child] >= elem) break;                 /* 最小孩子不小于 elem */
        a[i] = a[child];
        i = child;
    }
    a[i] = elem;
}
```

### 4. 插入、删顶与分叉数的取舍

```cpp
struct DHeap {
    vector<int> a;   /* 0 起算 */
    int d;
    DHeap(int branches): d(branches) {}
    void Insert(int x) { a.push_back(x); SiftUpD(a, d, (int)a.size() - 1); }
    int ExtractMin() {
        int mn = a[0];
        a[0] = a.back();
        a.pop_back();
        SiftDownD(a, d, 0);
        return mn;
    }
    void Build() {                                   /* 自底向上快速建堆 */
        for (int i = ((int)a.size() - 2) / d; i >= 0; --i)
            SiftDownD(a, d, i);
    }
};
```

D 堆把树高从 $\log_2 n$ 降到 $\log_d n$：上调 $O(\log_d n)$，下调每层扫描 d 个孩子、共 $O(d\log_d n)$。d 越大插入越快、删顶越慢；d=2 即二叉堆。注意两套下标不要混：二叉堆 1 起算（父 $i/2$、孩子 $2i$ 与 $2i+1$），D 堆 0 起算（父 $(i-1)/d$、孩子 $di+k$）。

## 四、可并堆

### 1. 为什么要研究可并堆

**动机** 数组二叉堆擅长 Insert 与 ExtractMin，但要**合并两个堆**时很笨：直接拼接两个数组得到的通常不是堆。课件示例：A=[2,5,7,9] 与 B=[3,4,8] 拼接后，下标 1 的 5 大于下标 4 的 3，不满足堆序。重新 Heapify 需 $O(n+m)$，逐个插入更慢，为 $O(m\log(n+m))$。

**思路** 可并堆让合并路径成为结构本身的一部分：用链表式二叉树表示堆，把 Merge 作为基本操作，Insert、ExtractMin、Build 都归约到 Merge。这样"合并频繁"的场合效率大幅提升。

### 2. 左堆与 NPL

**概念** 左堆（Leftist Heap）在二叉堆的堆序基础上增加结构约束：给每个结点定义 NPL（Null Path Length，到最近空子树的路径长度）。课件采用严蔚敏/Weiss 约定：

$$\mathrm{NPL}(\text{null})=0,\qquad \mathrm{NPL}(\text{leaf})=1,\qquad \mathrm{NPL}(x)=\min\big(\mathrm{NPL}(x.\mathrm{left}),\ \mathrm{NPL}(x.\mathrm{right})\big)+1.$$

规则：始终维护 $\mathrm{NPL}(\mathrm{left}) \ge \mathrm{NPL}(\mathrm{right})$，即"左重右轻"，于是右路径最短，$\mathrm{NPL}(x)=\mathrm{NPL}(x.\mathrm{right})+1$。

注意：若某结点 NPL=k，从它到叶的右路径每步至少使 NPL 减 1，且以它为根的子树至少是一棵高 k 的完美二叉树，含至少 $2^k-1$ 个结点。故 $2^k-1\le n$，即 $k\le \log_2(n+1)$——右脊长度 $O(\log n)$，这正是合并高效的原因。

Merge 递归：比较两根，取关键字小者作新根，把另一个堆并入它的右子堆；回到上层后若左子的 NPL 小于右子就交换两子，再更新自身 NPL。

```cpp
struct HeapNode {
    int key, npl;
    HeapNode *left, *right;
    HeapNode(int k): key(k), npl(1), left(nullptr), right(nullptr) {}
};
using LeftistHeap = HeapNode*;

int NPL(HeapNode* h) { return h ? h->npl : 0; }       /* 空结点 NPL 为 0 */

/* 合并两棵左堆，返回合并后的根 */
HeapNode* Merge(HeapNode* a, HeapNode* b) {
    if (!a) return b;
    if (!b) return a;
    if (a->key > b->key) swap(a, b);                  /* a 的根更小 */
    a->right = Merge(a->right, b);                    /* 并入 a 的右子堆 */
    if (NPL(a->left) < NPL(a->right)) swap(a->left, a->right);
    a->npl = NPL(a->right) + 1;                       /* 右脊更短，取右 */
    return a;
}

/* 一切操作归约到 Merge */
void Insert(LeftistHeap& h, int x) { h = Merge(h, new HeapNode(x)); }
int PeekMin(LeftistHeap h) { return h->key; }         /* O(1) */
int ExtractMin(LeftistHeap& h) {
    int mn = h->key;
    HeapNode *l = h->left, *r = h->right;
    delete h;
    h = Merge(l, r);                                  /* 合并左右子堆 */
    return mn;
}
```

Build 有两种：逐个 Insert 是 $O(n\log n)$；把 n 个单结点两两配对合并（队列法）是 $O(n)$。注意"逐插 $O(n\log n)$、批量 $O(n)$"的差别在课件里被特别标出。

```cpp
LeftistHeap Build(vector<int> const& keys) {
    queue<LeftistHeap> q;
    for (int k : keys) q.push(new HeapNode(k));
    while (q.size() > 1) {
        LeftistHeap a = q.front(); q.pop();
        LeftistHeap b = q.front(); q.pop();
        q.push(Merge(a, b));
    }
    return q.empty() ? nullptr : q.front();
}
```

### 3. 斜堆

**概念** 斜堆（Skew Heap）不存 NPL，合并时**无条件交换**左右孩子（左堆只在 NPL(left) 小于 NPL(right) 时交换）。单次交换可能使右脊变长，但摊还分析可得各操作 $O(\log n)$。

```cpp
/* 斜堆结点无需 npl 字段；合并时无条件交换 */
HeapNode* SkewMerge(HeapNode* a, HeapNode* b) {
    if (!a) return b;
    if (!b) return a;
    if (a->key > b->key) swap(a, b);
    swap(a->left, a->right);                          /* 与左堆唯一的结构差别 */
    a->left = SkewMerge(a->left, b);
    return a;
}
```

注意这里复用 `HeapNode` 仅为了讲解，实用中可去掉 npl 字段。斜堆"以自调整换空间"：省去 NPL 的存储与判断，单次合并可能退化，但连续操作的摊还界与左堆同阶。

### 4. 二项堆

**概念** 二项堆（Binomial Heap）不是一棵树，而是**一组满足堆序的二项树的森林**，且每个阶（rank）至多一棵树——这正是二进制进位的类比：$B_k$ 由两棵 $B_{k-1}$ 拼接而成（一棵作另一棵的最左孩子）。合并两个二项堆就像两个二进制数相加：同阶树相加产生进位到高一阶。

- 结构：阶为 k 的二项树含 $2^k$ 个结点，根有 k 个孩子；森林中各阶至多一棵，故树的棵数不超过 $\lfloor\log_2 n\rfloor+1$。
- Merge：$O(\log n)$，逐阶处理进位即可。
- ExtractMin：找出含最小根的那棵树，删根后把它拆成的子树森林与原森林合并，$O(\log n)$。
- Insert：相当于与单结点堆合并，$O(\log n)$；利用二进制进位的摊还性质，连续 Insert 均摊 $O(1)$。
- PeekMin：读各树根中的最小者，$O(\log n)$（若维护全局最小指针可 $O(1)$）。

二项堆适合"先大量插入、后批量取最小"的批处理场景。

### 5. 三种可并堆对照

| 结构 | 核心结构 | Merge | 其他操作 |
|---|---|---|---|
| 左堆 | 维护 NPL，右脊短 | $O(\log n+\log m)$ | Insert 与 ExtractMin $O(\log n)$，PeekMin $O(1)$ |
| 斜堆 | 不存 NPL，合并时自调整交换 | 摊还 $O(\log n)$ | 各操作摊还 $O(\log n)$ |
| 二项堆 | 二项树森林，类似二进制进位 | $O(\log n)$ | ExtractMin $O(\log n)$，连续 Insert 摊还 $O(1)$ |

## 五、优先级队列的应用

### 1. 用二叉堆加速哈夫曼树构建

回顾 [[第5章-树和二叉树.md]]：哈夫曼算法 `CreateHuffmanTree` 反复从二叉树集合中取出 WPL 最小、次小的两棵，合并后把新树放回集合。这正是优先级队列的典型应用——把 WPL 作为优先级（越小越优先），用 `ExtractMin` 取最小与次小、用 `Insert` 放回合并结果。

用二叉堆作实现：建堆 $O(n)$；随后共 $2n-2$ 次删除（每合并一次删两棵，共 n-1 次合并）与 $n-1$ 次插入，各 $O(\log n)$，总复杂度

$$O(n) + (2n-2)O(\log n) + (n-1)O(\log n) = O(n\log n).$$

思路：关键在"每次只要最小的两个，不需要全体有序"。若每轮都对整个集合排序，成本是 $O(n^2\log n)$ 量级；堆把工作集中到根附近的 $O(\log n)$ 路径上，这是优先级队列价值的最好例证。

### 2. 其他典型应用

- **Top-K 问题**：维护大小为 K 的最小堆，遍历 n 个元素，比堆顶大就替换并下调，最终堆中即最大的 K 个，时间 $O(n\log K)$。
- **堆排序**：建堆后连续 ExtractMin，得到升序序列，$O(n\log n)$ 原地排序。
- **后续课程的基石**：第 8 章的单源最短路（Dijkstra）与最小生成树（Prim）都要靠优先级队列取当前最小的顶点或边。

## 本章小结

本章把"取最小"这一需求从抽象 ADT 落到具体结构。二叉堆以数组加堆序实现，上调与下调是全部算法的两种基本动作，插入、删顶、建堆都是它们的组合；快速建堆自底向上，把复杂度从 $O(n\log n)$ 降到 $O(n)$。多叉堆改变了树高与每层代价的权衡，下标从 0 起算，SiftDownD 的 child 初值与叶子判定必须按修正版写。可并堆把 Merge 提升为基本操作，左堆靠 NPL 约束右脊、斜堆靠无条件交换做自调整、二项堆靠森林与二进制进位，三者都让"频繁合并"变得可行。最后，哈夫曼树构建说明：只要问题反复询问"当前最小"，优先级队列就是自然的工具。
