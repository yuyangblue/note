## 一、树的定义与结构

### 1. 树的定义与递归特性

**概念** 树是由结点组成的有限集合 $T$，用 $\lvert T\rvert$ 表示结点数。它满足：$\lvert T\rvert = 0$ 时是空树；$\lvert T\rvert > 0$ 时，有且仅有一个特殊结点 $r \in T$ 称为树根，其余结点 $T-\{r\}$ 划分为 $m\ (\ge 0)$ 个互不相交的子集 $T_1,\dots,T_m$，每个 $T_i$ 本身也是树（根的子树）；若 $\lvert T_i\rvert > 0$，子树根 $r_i$ 是 $r$ 的子结点，$r$ 是 $r_i$ 的父结点。

**思路** 这是**递归**定义：树由根和子树构成，子树又是树。由此得三条判据——各子树互不相交；除根外每个结点有且仅有一个父结点；$n$ 个结点的树恰有 $n-1$ 条边。树是保证 $n$ 个结点连通所需边数最少的结构：少一条边会失联（成森林），多一条必成环。推广到森林（$m$ 棵树）：设第 $i$ 棵有 $n_i$ 结点、$e_i$ 边，$n_i = e_i+1$，求和得结点总数 $N = k + m$（$k$ 为总边数），即森林结点数只由边数与树的棵数决定，与形态无关；反之 $n$ 结点、$m$ 个连通分量的森林有 $k = n-m$ 条边。

### 2. 树的基本术语

- **结点的度**：子结点（非空子树）个数；**树的度**：所有结点度的最大值。度为 0 的是**叶结点**，其余是**中间结点**。
- **父/子/兄弟结点**：同一父结点的结点互称兄弟。注意与图的"度"（关联边数）区分。
- **路径与路径长度**：从上到下由边相连的结点序列，长度为所含**边数**，$k$ 个结点的路径长度为 $k-1$。
- **层次（深度）**：根在第 1 层，子结点层次父结点加 1。**结点的高度**：叶为 1，中间结点为其子结点高度最大值加 1；**树的高度**是根的高度，亦称树的深度。
- **有序树**：子树从左向右依次排列、不能交换；否则为无序树（本书默认有序树）。**森林**：零个或多个互不相交的树的集合。树与森林只差一个根——删去树根得森林，给森林接虚拟根得树。

注意"深度"与"高度"方向相反：层次自根向下数（根第 1 层），高度自叶向上数（叶为 1）。有的教材按边数定义高度（根第 0 层），以题目约定为准。

### 3. 树的基本操作

```
InitTree(tree)                      初始化空树
CreatTree(tree, definition)         按定义构造树
IsEmpty(tree) / Root(tree)          判空 / 返回根结点
Get(tree, node) / Parent(tree, node) 返回值 / 返回父结点
GetChild(tree, node, k)             返回第 k 棵子树
InsertChild(tree, node, k, subtree) 插入为第 k 棵子树
Search(tree, x)                     查找值为 x 的结点，无则 NIL
Traverse(tree)                      访问每个结点恰好一次
```

`Traverse`（遍历）是后续所有树算法的基础：第四节讲二叉树遍历，第七节回到一般树遍历。课件把本章分为"树的定义、二叉树、二叉树遍历、哈夫曼树、树与森林、应用"六块，本笔记按此组织。

## 二、二叉树的定义与结构

### 1. 二叉树的定义与五种形态

**概念** 二叉树是 $n$ 个结点的有限集合：空集为空树；非空时由一个根和两棵互不相交、分别称为左子树与右子树的二叉树组成。**左右子树有严格次序、不能互换**——这是它与"度为 2 的树"的本质区别（后者只有一个孩子时不分左右）。五种基本形态：空、单结点、仅左、仅右、左右皆非空。斜二叉树是一路向左或向右退化的极端形态，等价于链表。注意二叉树允许为空，与"树有根"的表述并不矛盾——定义单独允许空集。

### 2. 满二叉树、完全二叉树与完美二叉树

**概念** 三种形态要严格区分：

- **完美二叉树**（Perfect，中文常称满二叉树）：除叶外每个结点都有两个孩子，且叶全在同一层（每层填满）。
- **完全二叉树**（Complete）：按层编号后与同高度完美二叉树一一对应，允许最后一层右侧缺若干结点，中间不能有空洞。
- **满二叉树**（英文 Full Binary Tree）：每个结点度为 0 或 2，不要求各层填满。

注意英文 Full 与中文"满二叉树"（Perfect）不是同一概念。哈夫曼树属于"每个结点度为 0 或 2"的正则二叉树（Full 意义），却通常不是各层填满的 Perfect；课件定理 5-4 称哈夫曼树为"满二叉树"，用的是中文习惯叫法，要按定义而非名字判断。

完全二叉树的判定落在**编号位置**上。课件反例：根 A，第二层 B、C，第三层 D、E、F、G，第四层 H 挂 D 下、J、K 挂 E 下。D 缺右孩子（第 4 层第 2 位空），J、K 却占第 3、4 位——照层序编号 J 拿到 9 号，而同高度完美二叉树中 9 号应是 D 的右孩子，位置对不上，故非完全二叉树。

### 3. 二叉树的重要性质

**性质 1** 第 $i$ 层至多 $2^{i-1}$ 个结点（$i$ 从 1 起）。**思路** 归纳：根层至多 $2^0=1$，每个结点至多生 2 个孩子，故第 $i$ 层至多 $2\times 2^{i-2}=2^{i-1}$（若按 0 起算须写成 $2^i$，用错差一层）。

**性质 2** 深度为 $k$ 的二叉树至多 $2^k-1$ 个结点。**思路** 各层取最大求和 $2^0+\dots+2^{k-1}=2^k-1$，完美二叉树取等号。

**性质 3** 叶结点数 $n_0$ 与度为 2 的结点数 $n_2$ 满足 $n_0 = n_2 + 1$。

**思路** 双向数边：设度为 1 的有 $n_1$ 个，总数 $n = n_0+n_1+n_2$。从上往下看边数 $= n-1$（除根外每结点一个父），从下往上看 $= 0\cdot n_0+1\cdot n_1+2\cdot n_2$。两式相等得 $n_0+n_1+n_2-1 = n_1+2n_2$，即 $n_0 = n_2+1$。

**推广到 $m$ 叉树**：$n_0 = 1+\sum_{i\ge2}(i-1)n_i$（每多一个度为 $i$ 的非叶结点，多出 $i-1$ 个"孩子位缺口"，由叶补）。$m=2$ 即上式，$m=3$ 为 $n_0 = 1+n_2+2n_3$；式中不含 $n_1$（度 1 结点产生 1 个孩子位又占父结点 1 个位置，净贡献 0）。第 $i$ 层至多 $m^{i-1}$ 个，深度 $k$ 至多 $\frac{m^k-1}{m-1}$ 个。

完全二叉树另有常用结论（$n$ 为结点数）：高度 $\lfloor\log_2 n\rfloor+1$，叶结点 $\lceil n/2\rceil$ 个，最后一个非叶编号 $\lfloor n/2\rfloor$，度为 1 的结点至多一个（$n$ 偶时恰有一个且只有左孩子）。这些结论集中用在存储上——只有完全二叉树能连续存放不留空洞。

### 4. 二叉树的构造（算法 5-1）

```cpp
struct TreeNode {                          /* 二叉链表结点 */
    char data;  TreeNode *left, *right;
    TreeNode(char v, TreeNode *l=nullptr, TreeNode *r=nullptr):data(v),left(l),right(r){}
};
using BinTree = TreeNode*;                 /* 指向结点的指针，兼作"树"类型 */

/* 算法 5-1：以 value 为根、left_tree/right_tree 为左右子树构造二叉树 */
BinTree CreateBinaryTree(char value, BinTree l, BinTree r) {
    BinTree tree = new TreeNode(value);
    tree->left = l;  tree->right = r;  return tree;
}
```

返回的指针既可表示"一棵树"（指向其根），也可表示"某个结点"，后续遍历函数参数都按此语义使用。

## 三、二叉树的存储实现

### 1. 顺序存储

对完全二叉树按层编号，根存下标 1（下标 0 空置），则下标 $i$ 的左右孩子在 $2i$、$2i+1$，父结点在 $\lfloor i/2\rfloor$。

注意：公式只在 1-based 下成立；根改存下标 0 时孩子变为 $2i+1$、$2i+2$、父变为 $\lfloor(i-1)/2\rfloor$，照搬全错。判断孩子是否存在看**下标是否越界**（左孩子存在当且仅当 $2i \le n$），而非读该位置内容——这与链式存储"看指针是否为 `nullptr`"是两套判据。一般二叉树也能这样存（补成完全二叉树、空位留空），代价是空洞：5 个结点可能排到编号 13，最坏斜树深度 $k$ 要占 $2^k-1$ 个槽，指数级浪费。故顺序存储只适合完全二叉树（堆靠它实现 $O(1)$ 父子定位，见 [[第6章-优先级队列.md]]）。

### 2. 链式存储

每个结点数据域加左右两个指针，缺孩子处置 `nullptr`。$n$ 个结点共 $2n$ 个指针域，非空的恰有 $n-1$ 个（除根外每结点被一指针指到），空指针 $n+1$ 个——这也等于"每结点按最大度 $m$ 预留指针"的空指针公式 $mn-(n-1)$ 在 $m=2$ 时的结果。再加一个 `parent` 指针成**三叉链表**，换来"从孩子回到父结点"的能力，代价是每结点多一域。注意三叉链表是存储方式，与"三叉树"（每结点最多 3 个孩子）无关。

## 四、二叉树的遍历

**概念** 遍历是把二维的树线性化为一维序列。核心难题：访问一个结点后，另一支必须先保存起来。深度优先用栈（含系统递归栈），广度优先用队列。

### 1. 深度优先：先序、中序、后序（算法 5-2 至 5-4）

以根、左、右三部分的访问次序区分（课件称"前序"，与"先序"同义）：**先序**根→左→右，**中序**左→根→右，**后序**左→右→根。三种遍历路径相同，只差每结点被第几次经过时输出：

```cpp
void PreOrder(BinTree t)  { if(t){ Visit(t); PreOrder(t->left); PreOrder(t->right); } }    /* 5-2 先序 */
void InOrder(BinTree t)   { if(t){ InOrder(t->left); Visit(t); InOrder(t->right); } }     /* 5-3 中序 */
void PostOrder(BinTree t) { if(t){ PostOrder(t->left); PostOrder(t->right); Visit(t); } } /* 5-4 后序 */
```

`if (t)` 是递归出口：空树直接返回，调用者不必先判孩子，把空指针交给下一层即可。后序两个推论：序列**末元素必是根**、**首元素必是最左最深处的叶**；但左右子树边界不固定，这是"先序 + 后序不能唯一还原"的原因（两端能定根，中间无从切分）。

### 2. 遍历的应用：求高度与表达式树（算法 5-5、5-6）

**求高度（5-5）**用后序框架，空树高 0、叶高 1：

```cpp
int Height(BinTree t) {
    return t ? max(Height(t->left), Height(t->right)) + 1 : 0;  /* 空树 0，H=max(左,右)+1 */
}
```

释放整棵树也用后序：先释放左右子树再释放自己，顺序反了会丢失孩子地址。**表达式树（5-6）**：叶放运算数、非叶放运算符；中序加括号可输出中缀式，算法在左右子树非空时各输出一对括号：

```cpp
void PrintInfix(BinTree t) {
    if (t->left)  { cout << '('; PrintInfix(t->left);  cout << ')'; }
    cout << t->data;
    if (t->right) { cout << '('; PrintInfix(t->right); cout << ')'; }
}
```

先序得前缀式、后序得后缀式（无需括号），中序得中缀式但必须加括号恢复优先级。

### 3. 递归的问题与非递归的动机

**动机** 课件指出递归三点问题：(1) 有些语言不支持递归；(2) 需系统在内存栈保存参数、返回地址、局部变量，效率较低；(3) 进程栈容量有限，树太深时递归层次过高易栈溢出。**思路** 非递归的关键是**用显式栈模拟系统栈**——沿左子树下行时把结点压栈，记下"将来回来还要往右走"。

### 4. 非递归先序与中序（算法 5-7、5-8）

两算法结构相同，只差访问时机。外层条件必须是 `t || !st.empty()`，若写成 `&&`，左子树走到底（`t` 为 `nullptr`）时会直接退出，只输出最左一条链。

```cpp
void PreOrderIter(BinTree t) {               /* 5-7 先序：压栈时访问 */
    vector<BinTree> st;
    while (t || !st.empty()) {
        while (t) { Visit(t); st.push_back(t); t = t->left; }
        t = st.back(); st.pop_back(); t = t->right;
    }
}
void InOrderIter(BinTree t) {                /* 5-8 中序：出栈时访问 */
    vector<BinTree> st;
    while (t || !st.empty()) {
        while (t) { st.push_back(t); t = t->left; }
        t = st.back(); st.pop_back(); Visit(t); t = t->right;
    }
}
```

这印证了"三种遍历路径相同、只差访问时机"。

### 5. 非递归后序（算法 5-9）

后序最难：弹出结点时其右子树可能尚未走完。课件用 `pre_top` 记录上次访问的结点，判断栈顶右子树是否已处理：

```cpp
void PostOrderIter(BinTree t) {              /* 5-9 后序 */
    vector<BinTree> st;
    BinTree top = nullptr, pre = nullptr;
    while (t || !st.empty()) {
        while (t) { st.push_back(t); t = t->left; }
        top = st.back(); pre = nullptr;
        /* 右子树为空，或右子树刚访问过（== pre），说明该访问 top 了 */
        while (!st.empty() && top->right == pre) {
            Visit(top); pre = top; st.pop_back();
            if (!st.empty()) top = st.back(); else top = nullptr;
        }
        if (top) t = top->right;
    }
}
```

**思路** 课件把后序序列分成若干"段"：段内访问连续，相邻两点次序小者是次序大者的右孩子，段末（若非根）是其父的左孩子。`pre` 用来识别"右子树已访问完、可回到父结点"的时机。三个非递归算法都只用一个栈，每结点恰好一进一出，时间、空间均为 $O(n)$。

### 6. 广度优先：层序遍历

**概念** 按层从上到下、每层从左到右访问。根入队；循环出队一个结点、访问它、把左右孩子（非空）依次入队。

```cpp
void LevelOrder(BinTree t) {
    if (!t) return;                          /* 空树必须提前返回 */
    vector<BinTree> que; size_t head = 0;
    que.push_back(t);
    while (head < que.size()) {
        BinTree node = que[head++];  Visit(node);
        if (node->left)  que.push_back(node->left);
        if (node->right) que.push_back(node->right);
    }
}
```

注意三处结构差别：循环由**队列不空**驱动而非"树不空"；空树必须显式返回（没有 `if (t)` 的天然屏障，空指针入队再出队会解引用崩溃）；入队前先判孩子非空。两个 `push_back` 的先后决定同层输出方向。

## 五、二叉树的序列化与反序列化

### 1. 概念与动机

**概念** 序列化：按某种遍历方案访问所有结点并依次输出数据，形成线性序列；反序列化：据此线性序列重构原树。作用是把非线性结构转成线性结构，便于用线性表或字符串存储、传输。

**动机** 完全二叉树的顺序存储本身就是序列化（位置隐含父子关系），但对一般二叉树浪费空间，最坏（斜树）空间复杂度达 $O(2^n)$。普通前序/层序只输出结点数据、丢了空子树信息，无法重构。关键是**在序列中标出空子树**。

### 2. 带 # 的先序序列化（算法 5-11）

**规则** 用 `#` 表示空子树：先序遍历遇到空结点时输出 `#`（而非直接返回），否则输出结点值，再递归序列化左、右子树（课件算法 5-11 的伪代码即此过程的文字化）。这样每个实结点后紧跟它的两棵子树标记，序列唯一确定一棵树。

```cpp
void PreOrderSerialize(BinTree t, vector<char> &out) {
    if (!t) { out.push_back('#'); return; }
    out.push_back(t->data);
    PreOrderSerialize(t->left,  out);
    PreOrderSerialize(t->right, out);
}
```

对 $A\big(B(D,\,E(J)),\ C(\_,F(K))\big)$ 序列化得 `A B D # # E J # # # C # F K # # #`。序列长度 $= 2n+1$（$n$ 个实结点 + $n+1$ 个空指针）。

### 3. 先序反序列化（算法 5-12）

**规则** 按序列顺序读，用游标 `k`（课件用全局变量、初值 -1，先加 1 再读）指示当前位置：读到 `#` 返回空树；否则建新结点填值，递归重构左、右子树（次序与序列化一致）。`#` 代替递归出口，在没有显式子树规模信息时确定边界。课件算法 5-12 的伪代码即"读一个元素、非 `#` 则建根并递归左右"的文字化。

```cpp
BinTree PreOrderDeSerialize(const vector<char> &seq, size_t &k) {
    if (k >= seq.size()) return nullptr;
    char data = seq[k++];
    if (data == '#') return nullptr;
    BinTree t = new TreeNode(data);
    t->left  = PreOrderDeSerialize(seq, k);        /* 共享 k，先左后右 */
    t->right = PreOrderDeSerialize(seq, k);
    return t;
}
```

**思路** 递归调用共享 `k`，每读一元素前进一格，整趟恰好消费完序列。序列化与反序列化互为逆过程，只要递归顺序一致即可无损还原。注意用引用参数（或每次重置全局 `k`），否则连续反序列化多棵树时第二棵会从第一棵末尾接着读。

### 4. 层序序列化与反序列化

**规则** 用队列按层展开，空子树也入队（输出 `#` 但不再挂孩子）；反序列化时同样用队列，按"成对"方式为出队结点挂左右孩子。

```cpp
void LevelSerialize(BinTree t, vector<char> &out) {
    if (!t) { out.push_back('#'); return; }
    vector<BinTree> que; size_t head = 0;  que.push_back(t);
    while (head < que.size()) {
        BinTree node = que[head++];
        if (!node) { out.push_back('#'); continue; }  /* 空结点输出 #，不展开 */
        out.push_back(node->data);
        que.push_back(node->left);  que.push_back(node->right);
    }
}
BinTree LevelDeSerialize(const vector<char> &seq) {
    if (seq.empty() || seq[0] == '#') return nullptr;
    BinTree root = new TreeNode(seq[0]);
    vector<BinTree> que; size_t head = 0, k = 1;  que.push_back(root);
    while (head < que.size() && k < seq.size()) {
        BinTree node = que[head++];
        if (k < seq.size() && seq[k] != '#')           /* 左孩子 */
            { node->left = new TreeNode(seq[k]);  que.push_back(node->left); }
        ++k;
        if (k < seq.size() && seq[k] != '#')           /* 右孩子 */
            { node->right = new TreeNode(seq[k]);  que.push_back(node->right); }
        ++k;
    }
    return root;
}
```

对树 A(B(D,\_), C(\_,E))（A 左 B 右 C，B 左 D，C 右 E），层序得 `A B C D # # # E # #`。

注意：课件给出的层序序列例子 `<A, B, C, D, E, F, #, H, I, #, J, #, K, #, #>` 是按**完全二叉树位置**补齐的写法（下标 $i$ 的孩子在 $2i+1$、$2i+2$，空位记 `#`，在最后有效位置截断），与上面的"队列紧凑写法"字符串不同，但都能唯一还原同一棵树；实现时序列化与反序列化必须用**同一种约定**。课件注明层序方案"过程及算法参考教材"，本节给出可直接使用的队列版本。

### 5. 不带空标记时的疑问：先序 + 中序重构

**思路** 先序不带 `#` 时，结合**中序序列**即可重构。课件数据：前序 `<A, B, D, H, I, E, J, C, F, K>`、中序 `<H, D, I, B, E, J, A, F, K, C>`。先序首元素 A 是根；在中序中定位 A，左边 $\{H,D,I,B,E,J\}$ 是左子树、右边 $\{F,K,C\}$ 是右子树；据此把先序切成"A 之后 6 个属左、末 3 个属右"，对两段递归。先序（或层序）只指出**根是谁**，中序指出**左右子树各占几个**。缺中序时（先序 + 后序）无法切分：两结点的树先序 $A,B$、后序 $B,A$，$B$ 在左在右两种树都合法。时间若每次线性查找根为 $O(n^2)$，用哈希表预存"值到下标"可降为 $O(n)$。带 `#` 的先序序列化只需一个序列、一趟 $O(n)$ 还原，这正是它的价值。

## 六、哈夫曼树与哈夫曼编码

### 1. 带权路径长度 WPL 与最优二叉树

**概念** 给定 $n$ 个带权叶结点，二叉树的**带权路径长度**

$$WPL = \sum_{k=1}^{n} w_k\, l_k$$

（$w_k$ 为第 $k$ 个叶的权，$l_k$ 为其到根的路径长度）。使 WPL 最小的二叉树即**最优二叉树**——**哈夫曼树**。

**动机** 同一组权、不同形态 WPL 差别很大：权大的叶离根近则加权路径和小。以 $\{1,2,3,4,5\}$ 为五个叶的权，哈夫曼树的叶深度为 3,3,2,2,2，$WPL = 1\times3+2\times3+3\times2+4\times2+5\times2 = 33$，为最小（另一种等深形态 2,2,2,3,3 的 WPL 为 42）。

### 2. 最优二叉树的性质（定理 5-4 与命题 5-5、5-6）

**定理 5-4：最优二叉树（哈夫曼树）是满二叉树。**

**思路** 反证：若有度为 1 的中间结点，删除它、把其唯一子结点直接连到父结点，则根到该结点所有子孙的路径长度减 1，WPL 减小，与最优矛盾。故最优二叉树无度为 1 的结点（英文 Full 意义）。由 $n_0 = n_2+1$ 得：$n$ 个叶则有 $n-1$ 个度为 2 的内部结点，**总结点数 $2n-1$**（必为奇数）；给定总数 $N$ 则叶数为 $(N+1)/2$。

**命题 5-5** 最优二叉树中权值不同的两叶，权小者的层数 $\ge$ 权大者。**思路** 否则交换两者位置会让大权值走短路，WPL 更小，与最优矛盾——这是"权大者近根"的严格表述。

**命题 5-6** 存在最优二叉树使权值最小与次小的两叶在最下层且互为兄弟。**思路** 由命题 5-5 最小两权应在最深处，把它们并排为兄弟叶不增大 WPL。这正是哈夫曼算法"每次取两个最小合并"的理论依据。

注意哈夫曼树不唯一（合并时左右可换、同层分支可换），形态不同但 WPL 都相同且最小。故判据是"WPL 是否等于最优值"，而非"树形是否与答案一致"。

### 3. 哈夫曼算法与构建（算法 5-15）

**概念** 哈夫曼算法**自下而上**构建最优二叉树：每个叶看作单结点带权树，反复合并根权值最小的两棵树，直到只剩一棵。中间结点权值 = 左右子结点权值之和。

**规则** 维护二叉树集合：① 为每个权值建叶结点放入集合；② 循环 $n-1$ 次，取出根权值最小的两棵（左、右），新建根（权为两者之和）合并后放回；③ 集合中唯一剩下的即哈夫曼树。用最小堆实现 `ExtractMin`：

```cpp
struct HuffNode { int weight; HuffNode *left=nullptr, *right=nullptr;
                  HuffNode(int w):weight(w){} };

HuffNode* CreateHuffmanTree(const vector<int> &w) {
    vector<HuffNode*> forest;                       /* 用 vector 模拟集合 */
    for (int x : w) forest.push_back(new HuffNode(x));
    while (forest.size() > 1) {                     /* 共 n-1 次合并 */
        auto it1 = min_element(forest.begin(), forest.end(),
            [](HuffNode*a,HuffNode*b){return a->weight<b->weight;});
        HuffNode *m1 = *it1; forest.erase(it1);      /* 最小 */
        auto it2 = min_element(forest.begin(), forest.end(),
            [](HuffNode*a,HuffNode*b){return a->weight<b->weight;});
        HuffNode *m2 = *it2; forest.erase(it2);      /* 次小 */
        HuffNode *p = new HuffNode(m1->weight + m2->weight);
        p->left = m1; p->right = m2;  forest.push_back(p);
    }
    return forest.empty() ? nullptr : forest[0];
}

int WPL(HuffNode *t, int depth) {                   /* 根深度取 0 */
    if (!t) return 0;
    if (!t->left && !t->right) return t->weight * depth;
    return WPL(t->left, depth+1) + WPL(t->right, depth+1);
}
```

注意循环必须恰好 $n-1$ 次：写 $n$ 次会在只剩一棵时再取最小而出错，写 $n-2$ 次漏掉最后合并。用最小堆时若循环条件写成 `i < heap.Size` 且 `Size` 每轮净减 1（删两插一），会提前结束——应先存初值或直接用 `while (size > 1)`。堆的构建见 [[第6章-优先级队列.md]]。

### 4. 前缀编码与哈夫曼编码

**概念** 等长编码（如 ASCII）每位相同、简单但未利用频率差异；变长码让高频字符短、低频长，但必须满足**前缀编码**：任一编码都不是另一编码的前缀，否则解码歧义（若 `a`=`01`、`b`=`010`，读到 `010` 无法判断是 `a`+`0` 还是 `b`）。

**思路** 用二叉树天然构造前缀编码：字符放叶结点，根到叶的路径（左 0 右 1）是编码；任一叶不在另一叶到根的路径上，故无编码互为前缀，解码时从根沿位串走到叶即可。**规则** 以字符频率为权构造哈夫曼树，左分支标 0、右标 1，根到叶路径即编码；其总长（= WPL）在所有前缀编码中最小，故是**最优前缀编码**。等长码需 $\lceil\log_2 C\rceil$ 位（$C$ 为字符集大小），哈夫曼省下的正是"等长位数 $\times$ 字符总数"与 WPL 之差。

### 5. 完整算例

字符集 $\{a,x,u,z\}$，出现次数 $a:4,\ x:2,\ u:1,\ z:1$。**等长码** 4 字符需 2 位，总长 $2\times(4+2+1+1)=16$。**哈夫曼构造**：① 合并 $u:1,z:1$ 得权 2；② 集合 $\{x:2,(uz):2,a:4\}$，合并 $x$ 与 $(uz)$ 得权 4；③ 合并 $\{(uzx):4,a:4\}$ 得根权 8。

| 字符 | 频度 | 编码 | 码长 | 贡献 |
|---|---|---|---|---|
| a | 4 | 0 | 1 | 4 |
| x | 2 | 10 | 2 | 4 |
| u | 1 | 110 | 3 | 3 |
| z | 1 | 111 | 3 | 3 |

总长 $=1\times4+2\times2+3\times1+3\times1=14$，比等长码省 2 位，WPL $=14$ 即最优。编码不唯一（左右互换得另一组码），但总长与 WPL 必为 14——这正是"判断编码最优看 WPL"的含义。

## 七、树与森林

### 1. 树的存储表示（三种表示法）

- **双亲表示法**：每结点只存指向父的指针（或父下标），找父 $O(1)$，找孩子要遍历全表。
- **孩子表示法**：每结点带若干孩子指针；按最大度 $m$ 统一设指针时空指针多达 $mn-(n-1)$，浪费严重。改进为把孩子排成链表、结点只存"孩子链表头"——**孩子链表表示法**。
- **孩子兄弟表示法（重点）**：每结点两个指针——`FirstChild`（第一个孩子）与 `NextSibling`（下一个兄弟），$n$ 个结点只用 $2n$ 个指针域、非空恰 $n-1$ 个，浪费很小，结构与二叉树结点完全相同：

```cpp
struct GNode { char data; GNode *firstChild=nullptr, *nextSibling=nullptr; };
```

**思路** 把"左=第一个孩子、右=下一个兄弟"的链旋转 45°就得二叉树，故研究一般树可归结为研究二叉树。

### 2. 树、森林与二叉树的转换

**规则 树 → 二叉树**：每结点 `FirstChild` 指第一个孩子、`NextSibling` 指下一个兄弟；根无兄弟，其 `NextSibling` 为空；旋转 45°后左指针成左孩子、右指针成右孩子。

**规则 森林 → 二叉树**：各树根在"无父结点"上平级，把根也当兄弟——用 `NextSibling` 依次串起来（第一棵根指第二棵根……），再按上规则旋转。以森林 $\{A(B(D),C),\ E(F)\}$ 为例：转后 $A$ 左孩子 $B$、右孩子 $E$；$B$ 左 $D$、右 $C$；$E$ 左 $F$。

**规则 二叉树 → 树/森林（逆）**：只看根——**根无右孩子则原为树，有右孩子则原为森林**；沿根右链断开，每段还原一棵树（右指针表示"兄弟"，树根无兄弟，森林各根才互为兄弟）。

由"左指针=`FirstChild`、右指针=`NextSibling`"可读出计数关系：**森林的叶（无孩子）恰是对应二叉树中左孩子指针为空的结点**，这是一一对应；而二叉树的叶（左右皆空）只是森林中叶的一部分（森林的叶若有右邻兄弟，转后右指针非空就不再是叶）。注意只有这条是恒等式，其余计数在小例子上常碰巧成立，不能当判据。

### 3. 树与森林的遍历

**概念** 树只有两种遍历：**先根遍历**（先访问根，再依次先根遍历各子树）与**后根遍历**（先依次后根遍历各子树，最后访问根）。一般树的孩子只论排列、不分左右，故树**没有"中根遍历"**。

**规则** 树、森林遍历与对应二叉树遍历的对应：

| 原结构 | 对应的二叉树 |
|---|---|
| 树的先根遍历 | 先序遍历 |
| 树的后根遍历 | 中序遍历 |
| 森林的先序遍历 | 先序遍历 |
| 森林的后根遍历 | 中序遍历 |

**思路** 先根与先序都是"先访问自身、再往下走"。后根为何对应中序：中序访问根时，左子树（第一个孩子及后代）刚好走完，右链代表下一个兄弟或下一棵树，正该排在根之后——即"子树全走完再回到自身"的后根语义。树无中根遍历，因为只有转成二叉树、分出左右后才有"中序"这个位置。

## 本章小结

> 树由根与互不相交的子树递归构成，有 $n-1$ 条边；二叉树左右有序，第 $i$ 层至多 $2^{i-1}$ 个结点、深度 $k$ 至多 $2^k-1$ 个、$n_0 = n_2+1$。存储上完全二叉树适合顺序存储（父子下标 $2i$、$2i+1$），一般二叉树用二叉链表。遍历分深度优先（先序/中序/后序，递归与基于栈的非递归）与广度优先（层序，基于队列），非递归用显式栈模拟系统栈、每结点一进一出故 $O(n)$。序列化用带 `#` 的先序（算法 5-11/5-12）可 $O(n)$ 唯一还原，层序方案用队列按对挂接，不带空标记时须借中序切分左右子树。哈夫曼树（最优二叉树）满足 WPL 最小、无度为 1 的结点、权小者层数大、最小两权为最深层兄弟，按"反复合并两棵最小权树"构建 $n-1$ 次，配合左 0 右 1 得最优前缀编码。树与森林用孩子兄弟表示法转二叉树，树的先根/后根分别对应二叉树的先序/中序遍历。下一章 [[第6章-优先级队列.md]] 用完全二叉树的顺序存储实现二叉堆。
