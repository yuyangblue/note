## 四、两套体系的关系

陈越笔记按"讲次"编号、苏鑫课件按"章"编号，且不是简单平移（陈越"树(中)"里的 BST/AVL 在苏鑫属于第 11 章查找；陈越的堆在"树(下)"，苏鑫独立成第 6 章）。两套各自完整、独立使用：

- **复习苏鑫期末** → 用本库 7 篇完整笔记，按章走。
- **按知识点深挖、找例题习题** → 用陈越主线（`../` 下 11 篇，含小白专场、PTA/洛谷题单）。各篇头部引用块给了对应篇名。
- **对照两套的差异** → 见 `../笔记库vs新课件_覆盖对照.html`。

本库已写完的 7 章都是自包含的；陈越篇只是延伸阅读，不是依赖。
