## 一、课程结构（教学日历 15 章）

## 二、第 1–7 章：课件已提供

每章按"本库的落点 + 陈越对应篇 + 差异点"列出。**两套都讲、内容一致**的部分不另写，直接看陈越对应篇即可；**本库单独写**的是苏鑫课件有、陈越讲次没有或讲法不同的部分。

**第 1 章 绪论** — 落在 [[01-绪论.md]]。陈越讲次覆盖数据结构定义、ADT、复杂度与最大子列和。苏鑫课件另有"AI 时代为什么学数据结构"的引言与课程考核说明（签到/作业/实践/期末的权重），属课程事务，不属考点。

**第 2 章 线性表** — 落在 [[02-线性表与栈队列.md]] §二。差异点是**块状链表**（苏鑫列为重难点），本库在 [[补充-新课件独有知识点.md#4. 块状链表]] 单列，正文对照见 [[04-字符串.md#4. 块链与两种结构的比较]]。双链表、循环链表陈越篇已讲。

**第 3 章 栈和队列** — 落在 [[02-线性表与栈队列.md]] §三§四。苏鑫课件大篇幅讲表达式求值（中缀转后缀、前缀/后缀表达式、括号匹配）与数制转换，陈越篇的表达式求值一节已覆盖；顺序栈/链栈/循环队列/链队列两套一致。

**第 4 章 字符串** — 落在 [[04-字符串.md]]（该篇即按苏鑫课件整理，含 BF、KMP、next/nextval、块链）。苏鑫课件"字符串特征向量"就是 next 数组的另一种叫法，陈越篇已按 next 讲透。BM 算法的详细规则陈越篇给了 OI-Wiki 入口。

**第 5 章 树和二叉树** — 主体落在 [[05a-树和二叉树(上).md]] 与 [[05c-树和二叉树(下)-堆与并查集.md]]（定义、性质、存储、遍历、哈夫曼、森林转换）。本库单独写**二叉树的序列化与反序列化**（课件算法 5-11/5-12）：[[补充-新课件独有知识点.md#1. 二叉树的序列化与反序列化]]。

**第 6 章 优先级队列** — 二叉堆部分落在 [[05c-树和二叉树(下)-堆与并查集.md]] §一（定义、上调、下调、建堆）。本库单独写**多叉堆/D 叉堆**（算法 6-7/6-8）与**可并堆**（左堆／斜堆／二项堆）：[[补充-新课件独有知识点.md#2. 多叉堆（D 叉堆）]]、[[补充-新课件独有知识点.md#3. 可并堆：左堆、斜堆、二项堆]]。注意苏鑫把"优先级队列"独立成章，陈越则把堆放在"树(下)"。

**第 7 章 图** — 落在 [[07-图(上).md]]（定义、邻接矩阵/邻接表、DFS/BFS、连通性、拯救 007、六度空间）。苏鑫课件用哥尼斯堡七桥引入欧拉路径，属常规补充，陈越篇未单列。图应用（最短路径、MST、拓扑、关键路径）是第 8 章，见下。

## 四、两套体系的对应关系

陈越笔记按"讲次"编号、苏鑫课件按"章"编号，且不是简单平移。复习时按需求选入口：

- **按知识点查** → 用陈越主线（`../` 下 11 篇，体系完整、例题与习题齐全）。
- **按苏鑫课件/期末考点查** → 用本库，从第 1–7 章的落点表进入，缺的部分在本库单列的篇章里。
- **两套都有的考点** → 直接看陈越对应篇，本库不复制内容。

对照表把每个考点的落点列在一起：见 `../笔记库vs新课件_覆盖对照.html`。
