## 一、问题引入：哥尼斯堡七桥

### 1. 一笔画问题

**动机** 哥尼斯堡城中有两条河汇合，河心与两岸共四块陆地，七座桥把它们连在一起。问题是：能否从某块陆地出发，每座桥**恰好经过一次**，最后回到起点？这就是著名的七桥问题，也是图论的起源。欧拉 1736 年的关键一步是**抽象**：把四块陆地缩成四个顶点，把七座桥画成连接顶点的边，于是"走桥"变成"在图上沿边行走"。

注意抽象的威力——桥的长度、陆地的大小都无关紧要，只有"哪两块陆地之间有桥相连"这一拓扑关系决定答案。这种"顶点加边"的结构就是图。

### 2. 欧拉路径、欧拉回路与相关概念

**概念** 下列定义都以"经过每条边一次且仅一次"为核心：

- **欧拉路径**：图中一条经过每条边一次且仅一次的路径。
- **欧拉回路**：起点与终点相同的欧拉路径，它是一个回路。
- **欧拉图**：具有欧拉回路的图，简称 E 图。
- **半欧拉图**：具有欧拉路径但不具有欧拉回路的图。
- **一笔画**：从图中一个顶点出发做深度优先搜索，一直往前走、不做回溯，观察是否存在一条走遍所有边且每条边只走一次的路径。

一笔画能否成功，不靠试走，而由顶点的度数决定，见下小节。

### 3. 欧拉定理：奇度顶点决定能否一笔画

**概念** 欧拉定理（对**无向连通图**）：

1. 若度为奇数的顶点**超过 2 个**，则欧拉路径不存在，不能一笔画；
2. 若**恰有 2 个**顶点的度为奇数、其余全为偶数，则从一个奇度顶点出发，必能找到经过每条边一次且仅一次、到达另一个奇度顶点的路径（半欧拉图，一笔画但终点不同于起点）；
3. 若**所有顶点度都是偶数**，则从任意顶点出发，都能找到经过每条边一次且仅一次并回到起点的回路（欧拉图）。

思路：一笔画时，除起点与终点外，每次"进入"一个顶点必然还要"离开"它，故这些顶点的度必须为偶数；只有起点与终点可以多出一次"只进不出"或"只出不进"，所以奇度顶点至多 2 个。必要条件在连通图上也充分，这就是欧拉定理。

回到七桥：四块陆地的度分别是 3、3、3、5，四个顶点全为奇度，超过 2 个，故七桥问题无解——不可能一笔画成。

## 二、图的定义与相关概念

### 1. 图的定义与 ADT

**概念** 图记作 $G=(V,E)$，其中 $V$ 是顶点的有穷非空集合，$E$ 是顶点之间关系的集合（边的集合）。$E$ 可以为空，但 $V$ 不能为空。

```
ADT Graph {
    数据对象：顶点集合 V，元素 vi 属于 ElemSet，i=1..n，n>0；或空集。
    数据关系：边集合 E，元素为序对 <vi, vj> 或 (vi, vj)，
             其中 vi、vj 属于 ElemSet，且 P(vi, vj) 定义该边的意义或信息。
    基本操作：（初始化、销毁、增删顶点与边、遍历、判连通等，见第三至第五节）
}
```

注意 $V$ 非空而 $E$ 可空：只有顶点没有边的图称为零图，它仍然是图。

### 2. 有向与无向、邻接与关联

**概念** 边带方向的是有向边，记作带尖括号的顶点对 $\langle D,A\rangle$，表示由 D 射向 A；D 称弧尾，A 称弧头。由顶点集和有向边集组成的图是**有向图**。边不带方向的是无向边，记作圆括号顶点对 $(C,A)$，表示 C 与 A 之间有一条边；对应的图是**无向图**。

- **邻接**：若 $(v_i,v_j)$ 是无向边，称 $v_i$ 与 $v_j$ 互相邻接，边 $(v_i,v_j)$ 关联于 $v_i$ 与 $v_j$；若 $\langle v_i,v_j\rangle$ 是有向边，称 $v_i$ 邻接到 $v_j$，或 $v_j$ 邻接自 $v_i$，边关联于这两个顶点。
- **关联**：边与它的两个端点之间的关系；一条边关联两个顶点。
- **直接前驱与直接后继**：在有向边 $\langle v_i,v_j\rangle$ 中，$v_i$ 是 $v_j$ 的直接前驱，$v_j$ 是 $v_i$ 的直接后继。无向图中边的两端互为前驱与后继。

### 3. 度、入度与出度

**概念** 顶点的"度"是关联于它的边的条数，按图的有向性细分：

- 无向图中，顶点 $v$ 的**度**是关联于 $v$ 的边的总数。
- 有向图中，**出度**是由 $v$ 射出的有向边条数，**入度**是射入 $v$ 的有向边条数，总度为两者之和。

思路：每条边有两个端点，数所有顶点的度之和时每条边被数两次，故无向图满足**握手定理**

$$\sum_{v\in V} \deg(v) = 2m,$$

其中 $m$ 为边数；有向图则 $\sum \text{入度}(v) = \sum \text{出度}(v) = m$。这条关系常用来校验度数统计是否遗漏。注意自环（若允许）对度贡献 2，本笔记默认不考虑自环。

### 4. 路径、回路与可达

**概念** 若可从 $v_i$ 出发经过若干条边到达 $v_j$，则称 $v_i$ 到 $v_j$ 之间存在一条**路径**。

- **路径长度**：路径上边的条数；若边带权，也可用各边权重之和表示。
- **可达**：$v_i$ 到 $v_j$ 有路径存在，则称两者可达。
- **简单路径**：除第一个与最后一个顶点可能相同外，其余顶点都不相同的路径。
- **简单回路（简单环）**：第一个顶点与最后一个顶点相同的简单路径。

注意"路径"与"简单路径"的差别：路径允许重复经过顶点，简单路径不允许。七桥的欧拉路径要求的是边不重复，顶点可以重复，所以它不是简单路径。

### 5. 简单图、多重图、完全图与网络

**概念** 按边的特殊性分类：

- **简单图**：不带重边（两顶点间至多一条边）、不带自回路的图。课件默认讨论简单图。
- **多重图**：允许重边的图。
- **无向完全图**：边数达到最大值 $n(n-1)/2$ 的无向图。思路：任意两顶点之间恰有一条边，共 $\binom{n}{2}=n(n-1)/2$ 对。
- **有向完全图**：边数达到最大值 $n(n-1)$ 的有向图。思路：每个有序顶点对 $\langle v_i,v_j\rangle$（$i\ne j$）都有一条边，共 $n(n-1)$ 条。
- **加权图**：边上带权重的图，分加权有向图与加权无向图；两者统称**网络**。

### 6. 子图、连通与连通分量

**概念** 设有两图 $G=(V,E)$ 与 $G'=(V',E')$，若 $V'$ 是 $V$ 的子集、$E'$ 是 $E$ 的子集，则称 $G'$ 是 $G$ 的**子图**。

- **连通**：若 $v_i$ 到 $v_j$ 之间有路径存在，称 $v_i$ 与 $v_j$ 连通。
- **连通图**：无向图中任意两个顶点对之间都连通，称该图为连通图。
- **极大连通子图**：把该子图外的任一顶点加进来都会造成不连通，且它包含了其中顶点间所有的边——"极大"指顶点加不进、边一条不漏。
- **连通分量**：无向图的极大连通子图。

思路：连通是顶点间的等价关系（自反、对称、传递），故顶点集被划分成若干互不相交的等价类，每个类加其内部的边就是一个连通分量。非连通图恰有至少两个连通分量；连通图只有一个连通分量，即自身。

### 7. 有向图的强连通

**概念** 有向图的连通性比无向图复杂，分三个层次：

- **强连通**：$v_i$ 到 $v_j$ 有路径且 $v_j$ 到 $v_i$ 也有路径（互相可达）。强连通图指任意两顶点都强连通的有向图。
- **单向连通**：任意两顶点之间至少有一个方向可达。
- **弱连通**：忽略所有边的方向后，底图是无向连通图。

**强连通分量**是有向图的极大强连通子图。注意强连通要求"双向"，是无向图连通概念在有向图中的直接推广；单向与弱连通则依次减弱。判定强连通分量的经典算法（Kosaraju、Tarjan）留作拓展，本笔记只要求概念与后文的判定思路。

## 三、图的存储实现

**动机** 图的操作时间通常同时依赖顶点数 n 与边数 m，故复杂度写作 $O(n+m)$ 这类含两个变量的形式。存储方案必须同时回答两个问题：顶点的数据放哪里，边的关系怎么记。两种基本结构是邻接矩阵与邻接表。

### 1. 邻接矩阵

**概念** 用一个一维数组 `ver_list` 保存顶点数据，用一个二维数组 `edge_matrix` 保存边：$edge\_matrix[u][v]$ 为从 $u$ 到 $v$ 的边的权重，无边时填入 `no_edge_value`（一般图为 0，网为表示无穷大的 kMaxNum）。再用 `directed` 标记有向与否。

课件给出的已知条件包括：实际顶点数 `n_verts`、实际边数 `m_edges`、顶点可能的最大数量 `kMaxVertex`、`ver_list`、`edge_matrix`、`no_edge_value` 与 `directed`。对应结构：

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;

const int kMaxVertex = 100;
const int kMaxNum = 0x3f3f3f3f;                   /* 网中"无边"的无穷大 */

struct MGraph {
    int n_verts = 0, m_edges = 0;
    vector<int> ver_list;                         /* 顶点数据（示例用编号） */
    vector<vector<int>> edge_matrix;              /* 邻接矩阵 */
    int no_edge_value;                            /* 一般图 0，网 kMaxNum */
    bool directed;                                /* 有向为真 */
    MGraph(int noedge, bool dir)
        : no_edge_value(noedge), directed(dir),
          ver_list(kMaxVertex, 0),
          edge_matrix(kMaxVertex, vector<int>(kMaxVertex, noedge)) {}
};
```

无向图的矩阵关于主对角线对称，一条边被存了两次；有向图则不一定对称。矩阵对角线恒为 `no_edge_value`（不考虑自环）。空间代价固定为 $O(\text{kMaxVertex}^2)$，与边数无关。

### 2. 邻接矩阵上的基本操作

**算法 7-1** 取顶点数，直接返回字段，$O(1)$。

**算法 7-2** 判断边是否存在：先检查下标合法且 $u\ne v$，再看 $edge\_matrix[u][v]$ 是否不等于 `no_edge_value`，$O(1)$。

```cpp
int NumberOfVex(MGraph const& g) { return g.n_verts; }

bool ExistEdge(MGraph const& g, int u, int v) {
    if (u < g.n_verts && v < g.n_verts && u != v)
        return g.edge_matrix[u][v] != g.no_edge_value;
    return false;
}

/* 算法 7-4：插入边 */
void InsertEdge(MGraph& g, int u, int v, int weight) {
    if (u != v && !ExistEdge(g, u, v)) {
        g.edge_matrix[u][v] = weight;
        ++g.m_edges;
        if (!g.directed)
            g.edge_matrix[v][u] = weight;          /* 无向图对称位置同赋 */
    }
}
```

**算法 7-6** 删除顶点 v 及其所有关联边。思路：直接用最后一个顶点的数据覆盖 v，再把矩阵的最后一行、最后一列搬到第 v 行、第 v 列，这样数组前部保持紧凑，不留空洞；搬移前要先数出被删的边数以便更新 `m_edges`。

```cpp
void RemoveVex(MGraph& g, int v) {
    if (v < 0 || v >= g.n_verts) return;
    int last = g.n_verts - 1;
    g.ver_list[v] = g.ver_list[last];              /* 末顶点覆盖 v */
    int count = 0;
    for (int u = 0; u < g.n_verts; ++u) {           /* 数射出、射入的边 */
        if (ExistEdge(g, v, u)) ++count;
        if (g.directed && ExistEdge(g, u, v)) ++count;
    }
    for (int u = 0; u < g.n_verts; ++u) {           /* 末行、末列移入 v */
        g.edge_matrix[v][u] = g.edge_matrix[last][u];
        g.edge_matrix[u][v] = g.edge_matrix[u][last];
    }
    for (int u = 0; u < g.n_verts; ++u) {           /* 清掉原末行与末列 */
        g.edge_matrix[last][u] = g.no_edge_value;
        g.edge_matrix[u][last] = g.no_edge_value;
    }
    g.m_edges -= count;
    --g.n_verts;
}
```

注意两个细节：有向图要分别数射出与射入的边（各一趟循环），无向图只需数一行；无向图的一条边在矩阵里出现两次，但数度时按一行统计即可，不会重复。按加法原理，四个 $O(n)$ 的循环相加仍是 $O(n)$，故删顶总复杂度 $O(n)$。

### 3. 邻接表

**概念** 对每个顶点维护一个单链表，链表中每个结点记录一条从该顶点射出的边：终点 `dest`、权重 `weight` 与指向下一边的 `next`。顶点表 `ver_list` 存每个顶点的边链表头指针 `adj`。无向图的每条边在两个端点的链表中各存一份。

```cpp
struct EdgeNode {
    int dest, weight;
    EdgeNode* next;
    EdgeNode(int d, int w, EdgeNode* n): dest(d), weight(w), next(n) {}
};
struct VexNode { EdgeNode* adj = nullptr; };

struct LGraph {
    int n_verts = 0, m_edges = 0;
    vector<VexNode> ver_list;
    bool directed;
    LGraph(int maxv, bool dir): ver_list(maxv), directed(dir) {}
    /* 深拷贝：无向图只复制一次，避免重复分配 */
    LGraph(LGraph const& o): n_verts(o.n_verts), m_edges(o.m_edges),
            ver_list(o.ver_list.size()), directed(o.directed) {
        for (int u = 0; u < n_verts; ++u)
            for (EdgeNode* p = o.ver_list[u].adj; p; p = p->next)
                if (u < p->dest || directed)
                    ver_list[u].adj = new EdgeNode(p->dest, p->weight, ver_list[u].adj);
    }
    ~LGraph() {
        for (auto& v : ver_list) {
            EdgeNode* p = v.adj;
            while (p) { EdgeNode* nx = p->next; delete p; p = nx; }
        }
    }
};
```

空间代价 $O(n+m)$，与边数成正比：稀疏图（$m\ll n^2$）远比邻接矩阵省空间。

### 4. 邻接表上的基本操作

**算法 7-7** 取第一个邻接点：返回 `ver_list[v].adj`，$O(1)$。

**算法 7-8** 判断边是否存在：沿 u 的边链表扫描，查是否有 `dest == v`。最坏 $O(m)$（实际为 $O(\text{degree}(u))$）。

**算法 7-9** 插入边：先确认边不存在，再**头插**新结点到 u 的边表；无向图还要在 v 的边表头插一条反向边。头插省去遍历到表尾，$O(1)$。

```cpp
EdgeNode* FirstAdjVex(LGraph const& g, int v) {
    return v < g.n_verts ? g.ver_list[v].adj : nullptr;   /* NIL 用 nullptr */
}

bool ExistEdge(LGraph const& g, int u, int v) {
    for (EdgeNode* p = FirstAdjVex(g, u); p; p = p->next)
        if (p->dest == v) return true;
    return false;
}

void InsertEdge(LGraph& g, int u, int v, int weight) {
    if (u != v && !ExistEdge(g, u, v)) {
        g.ver_list[u].adj = new EdgeNode(v, weight, g.ver_list[u].adj);
        ++g.m_edges;
        if (!g.directed)
            g.ver_list[v].adj = new EdgeNode(u, weight, g.ver_list[v].adj);
    }
}
```

**算法 7-10** 删除顶点 v 及所有关联边，分四步：删去 v 射出的边（直接释放 v 的边表）；扫描其余每个顶点的边表，删去射入 v 的边；把原来指向最后一个顶点的边改指 v（因为随后末顶点要搬到 v 的位置）；把末顶点的边表整体移入 v 的位置。无向图的每条边在"射出"与"射入"两步各被数一次，最后边数要减半。

```cpp
void RemoveVex(LGraph& g, int v) {
    if (v < 0 || v >= g.n_verts) return;
    int count = 0;
    EdgeNode* p = g.ver_list[v].adj;                 /* 第一步：删射出的边 */
    while (p) { EdgeNode* nx = p->next; delete p; p = nx; ++count; }
    g.ver_list[v].adj = nullptr;
    for (int u = 0; u < g.n_verts; ++u) {             /* 第二步：删射入的边 */
        if (u == v) continue;
        EdgeNode* q = g.ver_list[u].adj, *prev = nullptr;
        while (q) {
            if (q->dest == v) {
                EdgeNode* dead = q;
                q = q->next;
                if (prev) prev->next = q;
                else g.ver_list[u].adj = q;
                delete dead; ++count;
            } else { prev = q; q = q->next; }
        }
        /* 第三步：原来射向末顶点的边改为射向 v */
        for (EdgeNode* r = g.ver_list[u].adj; r; r = r->next)
            if (r->dest == g.n_verts - 1) r->dest = v;
    }
    int last = g.n_verts - 1;                        /* 第四步：末顶点移入 v */
    if (v != last) {
        g.ver_list[v].adj = g.ver_list[last].adj;
        g.ver_list[last].adj = nullptr;
    }
    if (!g.directed) count /= 2;
    g.m_edges -= count;
    --g.n_verts;
}
```

思路：换一个角度数代价——算法对每个顶点都检查了它的每一条邻接边，故总时间 $O(n+m)$。这比邻接矩阵删顶的 $O(n)$ 看似更贵，但矩阵那是固定扫 n 行 n 列，邻接表则与真实边数相关，稀疏图上仍可能更快。

### 5. 两种存储的对照

| 维度 | 邻接矩阵 | 邻接表 |
|---|---|---|
| 空间 | $O(n^2)$，与边数无关 | $O(n+m)$，与边数成正比 |
| 判边是否存在 | $O(1)$ | $O(m)$ 最坏 |
| 插入一条边 | $O(1)$ | $O(1)$ 头插 |
| 删除一个顶点 | $O(n)$ | $O(n+m)$ |
| 适合 | 稠密图、频繁判边 | 稀疏图、按邻接点遍历 |

## 四、图的遍历

### 1. 遍历的特点与已访问标志

**概念** 图的遍历是按某种方式逐个访问所有顶点，且每个顶点只访问一次。最简单的是沿顶点表顺序扫一遍，但这用不到边的信息；借助边信息才能派生出深度优先遍历（DFS）与广度优先遍历（BFS），进而解决连通性等问题。

遍历图与遍历二叉树有三点不同：

1. 顶点地位相同，没有特殊的根结点；二叉树有根。
2. 一个顶点可与多个顶点邻接，可看作有多个直接前驱与后继，且可能存在回路；二叉树每结点只有一个直接前驱、至多两个后继，无回路。
3. 无向图中一条边的两个端点甚至互为后继。

**动机** 正因为存在回路，同一顶点可能经不同前驱被反复到达。为避免重复访问，遍历时给每个顶点附加**已访问标志** `visited`，访问后置真，只有未访问的顶点才进入下一步。

### 2. 深度优先遍历 DFS（算法 7-11、7-12）

**思路** 从某顶点出发，访问它，然后对其每个未访问的邻接点递归做 DFS——一条路走到黑，走不通才回退。算法 7-11 是外层驱动：先把所有标志置假，再对每个未访问顶点发起一次 DFS；算法 7-12 是递归核心。

```cpp
vector<bool> visited;                                /* 全局已访问标志 */

void visit(LGraph const&, int v) { cout << v << ' '; } /* 示例：输出顶点编号 */

/* 算法 7-12：从指定顶点 v 出发的 DFS */
void DFS(LGraph const& g, int v) {
    visited[v] = true;
    visit(g, v);
    for (EdgeNode* p = g.ver_list[v].adj; p; p = p->next)
        if (!visited[p->dest]) DFS(g, p->dest);
}

/* 算法 7-11：遍历整张图 */
void DFSTraverse(LGraph const& g) {
    visited.assign(g.n_verts, false);
    for (int v = 0; v < g.n_verts; ++v)
        if (!visited[v]) DFS(g, v);
}
```

注意外层循环的意义：若图不连通，从 0 号顶点出发的 DFS 只能覆盖一个连通分量，必须对每个仍未访问的顶点再发起一次，才能遍历全图。

### 3. 广度优先遍历 BFS（算法 7-13、7-14）

**思路** 从某顶点出发，先访问它，再按"先访问者其邻接点先访问"的层次顺序扩散。借助队列 [[第3章-栈与队列.md]]：顶点入队后等待处理，出队时访问，并把其未访问的邻接点入队。算法 7-13 是外层驱动，算法 7-14 是队列核心。

```cpp
/* 算法 7-14：从指定顶点 v 出发的 BFS */
void BFS(LGraph const& g, int v) {
    queue<int> q;
    q.push(v);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        if (visited[u]) continue;                    /* 可能重复入队，这里去重 */
        visited[u] = true;
        visit(g, u);
        for (EdgeNode* p = g.ver_list[u].adj; p; p = p->next)
            if (!visited[p->dest]) q.push(p->dest);
    }
}

/* 算法 7-13：遍历整张图 */
void BFSTraverse(LGraph const& g) {
    visited.assign(g.n_verts, false);
    for (int v = 0; v < g.n_verts; ++v)
        if (!visited[v]) BFS(g, v);
}
```

注意课件写法在**入队时不检查** visited、仅在出队时检查：同一顶点可能被多个前驱重复入队，但只会出队访问一次，故结果正确。若改用"入队即置 visited"，队列更短，效果等价。

### 4. 复杂度与两种遍历的用途

采用邻接表时，DFS 与 BFS 对每个顶点访问一次、对每条边检查一次（无向图的边在两端各检查一次，仍是常数倍），故时间复杂度 $O(n+m)$；采用邻接矩阵时，找某顶点的邻接点要扫一整行 n 个元素，总复杂度 $O(n^2)$。空间上，递归栈或队列最坏 $O(n)$。

用途上，DFS 沿一条路径深入、天然带回溯结构，适合探测路径与连通分量；BFS 按离起点的边数逐层推进，适合"最少边数"类问题。两者都能判定连通性，下一节即是最直接的例子；第 8 章的单源最短路则是 BFS 在带权情形下的推广。

## 五、图的连通性

### 1. 无向图的连通性判断（算法 7-15）

**思路** 若图连通，从任一顶点出发的一次遍历就能走遍全部顶点；反之，每遇到一个未访问顶点就开启一次新的遍历，恰好对应一个新的连通分量。于是统计遍历次数即可：次数为 1 则连通，否则输出连通分量数。

```cpp
/* 算法 7-15：判断无向图连通性，返回是否连通，components 传出分量数 */
bool IsConnect(LGraph const& g, int& components) {
    visited.assign(g.n_verts, false);
    components = 0;
    for (int v = 0; v < g.n_verts; ++v)
        if (!visited[v]) {
            ++components;
            BFS(g, v);                               /* 也可用 DFS */
        }
    return components == 1;
}
```

复杂度：一次遍历 $O(n+m)$，外层每个顶点只触发一次未访问分支，故总复杂度仍是 $O(n+m)$。注意算法对有向图不能照搬——从某点出发可达所有点，不代表别人也能到达它。

### 2. 有向图连通性的判定思路

**概念** 有向图强连通的判定要比无向图多一个方向：从 v 出发做 DFS/BFS 若能到达所有顶点，只说明 v 能到达其余各点；还要在**反向图**（所有边反向）中从 v 出发也能到达所有顶点，才说明其余各点也能到达 v，即 v 与所有点互相可达。

推广到强连通分量：经典做法（Kosaraju 算法）是先在原图上按完成顺序做一次 DFS，再在反向图上按逆序做 DFS，每次得到一棵 DFS 树即一个强连通分量。本日历只要求理解强连通的概念与上述双向判定思路，完整算法留作拓展。

## 六、图的应用：一笔画的求解

本节回到开篇的七桥问题，给出欧拉回路的构造算法，对应课件"图的应用：哥尼斯堡七桥问题求解"。它只到一笔画为止，不涉及第 8 章的最短路径、最小生成树等内容。

### 1. 求一条回路 GetCircuit（算法 7-17）

**思路** 在无向图中从 start 出发**贪心走边、边走边删**：每走到一个顶点 tail，就删掉无向边 (head, tail) 的两个方向，再把 tail 追加到回路链表末尾，继续从 tail 出发；直到回到 start（或无路可走）为止。删边保证同一条边不会被走第二次。

```cpp
/* 从 u 的邻接表中摘去一条到 v 的边，不修改 m_edges */
void UnlinkArc(LGraph& g, int u, int v) {
    EdgeNode *p = g.ver_list[u].adj, *prev = nullptr;
    while (p && p->dest != v) { prev = p; p = p->next; }
    if (!p) return;
    if (prev) prev->next = p->next;
    else g.ver_list[u].adj = p->next;
    delete p;
}

/* 算法 7-17：从 start 出发获得一条回路（顶点序列） */
vector<int> GetCircuit(LGraph& g, int start) {
    vector<int> circuit{start};
    int head = start;
    while (true) {
        EdgeNode* p = g.ver_list[head].adj;
        if (!p) break;                               /* 无路可走 */
        int tail = p->dest;
        UnlinkArc(g, head, tail);                    /* 删无向边的两个方向 */
        UnlinkArc(g, tail, head);
        --g.m_edges;
        circuit.push_back(tail);
        head = tail;
        if (head == start) break;                    /* 回到起点，闭合成回路 */
    }
    return circuit;
}
```

注意该算法针对**无向图**：删边时正反两个方向都要摘除。若图中还有从 start 可达的其他边未走完，说明这条只是"子回路"，需要进一步并入，这正是算法 7-18 的工作。

### 2. 求欧拉回路 EulerCircle（算法 7-18）

**思路** 先用度数检查存在性：只要有一个顶点度为奇数，就返回空序列（无欧拉回路）。存在性满足后，在图的一份副本上边走边删，依次得到若干子回路；再把子回路**拼接**进主回路：扫描主回路的每个顶点，若它在剩余图中还有边，就从它出发再走一条子回路，把这条子回路（去掉重复的首顶点）插入主回路该顶点之后。拼接直至所有边都被用完。

```cpp
/* 算法 7-18：求无向连通图的欧拉回路，不存在则返回空序列 */
vector<int> EulerCircle(LGraph const& src) {
    for (int v = 0; v < src.n_verts; ++v) {          /* 度数检查 */
        int degree = 0;
        for (EdgeNode* p = src.ver_list[v].adj; p; p = p->next) ++degree;
        if (degree % 2 == 1) return {};              /* 有奇度顶点，无欧拉回路 */
    }
    LGraph g(src);                                   /* 深拷贝，边走边删 */
    vector<int> circuit = GetCircuit(g, 0);
    for (size_t i = 1; i < circuit.size(); ) {
        if (g.ver_list[circuit[i]].adj) {
            vector<int> next = GetCircuit(g, circuit[i]);
            circuit.insert(circuit.begin() + i + 1, next.begin() + 1, next.end());
        } else {
            ++i;
        }
    }
    return circuit;
}
```

注意拼接时插入的是 `next.begin()+1` 到末尾：子回路的首顶点与主回路当前顶点是同一个，只保留一次。数组中间插入使最坏时间到 $O(n^2)$，若改用链表做回路即可保持更高级的效率；作为教学设计，此处重点在"子回路并入主回路"的思想。

### 3. 从欧拉回路到欧拉路径

**思路** 若图恰有两个奇度顶点 $u$、$v$（半欧拉图），它没有欧拉回路，但有欧拉路径。做法是**加一条虚拟边** $(u,v)$：加入后所有顶点度都变偶，可求欧拉回路；在所得回路中删除这条虚拟边，回路就在该处断开，成为一条从 $u$ 到 $v$ 的欧拉路径。这样算法 7-18 也能服务于半欧拉图，呼应欧拉定理的第二种情形。

## 本章小结

本章从七桥的一笔画引入，建立了图的完整概念体系：顶点与边、有向与无向、度与入度出度、路径与回路、完全图与网络、子图与连通分量、有向图的强连通。存储上，邻接矩阵以 $O(n^2)$ 空间换 $O(1)$ 判边，邻接表以 $O(n+m)$ 空间更适合稀疏图；删除顶点时两者都采用"末元素覆盖被删位置"的技巧以保持紧凑。遍历上，DFS 与 BFS 在邻接表上都是 $O(n+m)$，靠 `visited` 标志避免回路导致的重复访问，二者都能求连通分量——算法 7-15 数出遍历次数即连通分量数。最后，欧拉定理把"能否一笔画"归结为奇度顶点的个数，算法 7-17 与 7-18 则给出了无向连通图欧拉回路的构造：贪心走子回路，再逐条并入主回路。
