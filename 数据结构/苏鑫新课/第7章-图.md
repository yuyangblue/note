## 一、问题引入：哥尼斯堡七桥

### 1. 一笔画问题

**动机** 哥尼斯堡城中两条河汇合，河心与两岸共四块陆地，七座桥相连。问题是：能否从某块陆地出发，每座桥**恰好经过一次**，最后回到起点？欧拉 1736 年把四块陆地缩成顶点、七座桥画成边，于是"走桥"变成"沿边行走"，这就是图论的起源。注意：桥的长度、陆地大小都无关紧要，只有"哪两块陆地有桥相连"这一拓扑关系决定答案。

### 2. 欧拉路径、欧拉回路与相关概念

**概念** 下列定义都以"经过每条边一次且仅一次"为核心：

- **欧拉路径**：经过每条边一次且仅一次的路径。
- **欧拉回路**：起点与终点相同的欧拉路径。
- **欧拉图**：具有欧拉回路的图，简称 E 图。
- **半欧拉图**：有欧拉路径但无欧拉回路的图。
- **一笔画**：从一顶点出发做深度优先搜索，一直往前走、不回溯，看是否存在走遍所有边且每条边只走一次的路径。

### 3. 欧拉定理：奇度顶点决定能否一笔画

**概念** 对**无向连通图**：

1. 奇度顶点**超过 2 个**：欧拉路径不存在，不能一笔画；
2. **恰 2 个**奇度顶点、其余偶度：从一个奇度顶点出发，必能走到另一个奇度顶点，经过每条边一次且仅一次（半欧拉图，一笔画但终点不同）；
3. **全部偶度**：从任意顶点出发都能找到回到起点的欧拉回路（欧拉图）。

思路：一笔画时除起点与终点外，每次"进入"一个顶点必然还要"离开"，故这些顶点度为偶数；只有起点与终点可以多一次"只进不出"或"只出不进"，故奇度顶点至多 2 个。在连通图上这个必要条件也充分。七桥四块陆地的度分别是 3、3、3、5，四个奇度顶点超过 2 个，故无解。

## 二、图的定义与相关概念

### 1. 图的定义与 ADT

**概念** 图记作 $G=(V,E)$：$V$ 是顶点的有穷非空集合，$E$ 是边的集合。$E$ 可以为空，$V$ 不能为空（只有顶点没有边的是零图）。

```
ADT Graph {
    数据对象：顶点集合 V，vi 属于 ElemSet，i=1..n，n>0；或空集。
    数据关系：边集合 E，元素为 <vi, vj> 或 (vi, vj)，vi、vj 属于 ElemSet，
             P(vi, vj) 定义该边的意义或信息。
    基本操作：初始化、销毁、增删顶点与边、遍历、判连通等，见第三至第五节。
}
```

### 2. 有向与无向、邻接与关联

**概念** 带方向的边是有向边，记作 $\langle D,A\rangle$，由弧尾 D 射向弧头 A；由顶点集与有向边集组成的是**有向图**。不带方向的边是无向边 $(C,A)$，对应**无向图**。

- **邻接**：$(v_i,v_j)$ 中两者互相邻接；$\langle v_i,v_j\rangle$ 称 $v_i$ 邻接到 $v_j$、$v_j$ 邻接自 $v_i$。
- **关联**：边与它的两个端点之间的关系。
- **直接前驱与直接后继**：$\langle v_i,v_j\rangle$ 中 $v_i$ 是 $v_j$ 的直接前驱，$v_j$ 是 $v_i$ 的直接后继；无向图中两端互为前驱与后继。

### 3. 度、入度与出度

**概念** 无向图中顶点 $v$ 的**度**是关联于它的边数；有向图中**出度**是射出的边数、**入度**是射入的边数，总度为两者之和。

思路：每条边有两个端点，数所有顶点度之和时每条边被数两次，故无向图有握手定理 $\sum_{v\in V}\deg(v)=2m$（$m$ 为边数）；有向图则 $\sum \text{入度}=\sum \text{出度}=m$。这条关系可校验度数统计。默认不考虑自环（若允许，自环对度贡献 2）。

### 4. 路径、回路与可达

**概念** 从 $v_i$ 经若干条边能到达 $v_j$，则称两者间有一条**路径**、$v_i$ 到 $v_j$ **可达**。路径长度是边数，带权图也可取权重之和。**简单路径**除首尾可能相同外顶点互不相同；**简单回路（环）**是首尾相同的简单路径。注意欧拉路径要求边不重复、顶点可重复，故一般不是简单路径。

### 5. 简单图、多重图、完全图与网络

**概念** **简单图**无重边、无自回路（课件默认）；**多重图**允许重边。**无向完全图**边数最大为 $n(n-1)/2$（任意两点一条边，共 $\binom n2$ 对）；**有向完全图**边数最大为 $n(n-1)$（每个有序对一条边）。边上带权重的图称加权图，分加权有向图与加权无向图，统称**网络**。

### 6. 子图、连通与连通分量

**概念** $G'=(V',E')$ 满足 $V'\subseteq V$、$E'\subseteq E$，称 $G'$ 是 $G$ 的**子图**。若 $v_i$ 到 $v_j$ 有路径，称两者**连通**；任意两点都连通的无向图是**连通图**。**极大连通子图**指再加任一外部顶点就不连通、且包含其中所有边的子图；无向图的极大连通子图称**连通分量**。

思路：连通是顶点间的等价关系，故顶点集被划分为若干等价类，每类连同内部的边就是一个连通分量。连通图只有一个分量。

### 7. 有向图的强连通

**概念** 有向图连通分三层：**强连通**指 $v_i$ 与 $v_j$ 互相可达，任意两点强连通的为强连通图；**单向连通**指任意两点至少一个方向可达；**弱连通**指忽略方向后的底图连通。有向图的极大强连通子图称**强连通分量**。注意强连通要求双向，是无向图连通概念的直接推广。Kosaraju、Tarjan 等完整算法留作拓展。

## 三、图的存储实现

**动机** 图的操作时间同时依赖顶点数 n 与边数 m，故复杂度写作 $O(n+m)$。存储要回答两件事：顶点数据放哪里、边的关系怎么记。两种基本结构是邻接矩阵与邻接表。

### 1. 邻接矩阵

**概念** 一维数组 `ver_list` 存顶点数据，二维数组 `edge_matrix` 存边：$edge\_matrix[u][v]$ 是 $u$ 到 $v$ 的边的权重，无边填 `no_edge_value`（一般图 0，网为无穷大 kMaxNum）；`directed` 标记有向与否。课件已知条件还有实际顶点数 `n_verts`、实际边数 `m_edges`、顶点上限 `kMaxVertex`。

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;
const int kMaxVertex = 100;
const int kMaxNum = 0x3f3f3f3f;                   /* 网中"无边"的无穷大 */
struct MGraph {
    int n_verts = 0, m_edges = 0;
    vector<int> ver_list;                         /* 顶点数据（示例用编号） */
    vector<vector<int>> edge_matrix;              /* 邻接矩阵 */
    int no_edge_value;                            /* 一般图 0，网 kMaxNum */
    bool directed;
    MGraph(int noedge, bool dir)
        : no_edge_value(noedge), directed(dir),
          ver_list(kMaxVertex, 0),
          edge_matrix(kMaxVertex, vector<int>(kMaxVertex, noedge)) {}
};
```

无向图矩阵关于主对角线对称，一条边存两次；有向图不一定对称；对角线恒为 `no_edge_value`。空间固定 $O(\text{kMaxVertex}^2)$，与边数无关。

### 2. 邻接矩阵上的基本操作

**算法 7-1** 返回顶点数，$O(1)$。**算法 7-2** 判边：下标合法且 $u\ne v$ 时看 $edge\_matrix[u][v]$ 是否不等于 `no_edge_value`，$O(1)$。**算法 7-4** 插边：写入权重并计数，无向图对称位置同赋，$O(1)$。

```cpp
int NumberOfVex(MGraph const& g) { return g.n_verts; }

bool ExistEdge(MGraph const& g, int u, int v) {
    if (u < g.n_verts && v < g.n_verts && u != v)
        return g.edge_matrix[u][v] != g.no_edge_value;
    return false;
}

void InsertEdge(MGraph& g, int u, int v, int weight) {   /* 算法 7-4 */
    if (u != v && !ExistEdge(g, u, v)) {
        g.edge_matrix[u][v] = weight;
        ++g.m_edges;
        if (!g.directed) g.edge_matrix[v][u] = weight;
    }
}
```

**算法 7-6** 删顶点 v 及关联边：用最后顶点的数据覆盖 v，再把矩阵末行、末列搬到第 v 行、第 v 列，保持数组前部紧凑不留洞；搬移前先数出被删边数以更新 `m_edges`。

```cpp
void RemoveVex(MGraph& g, int v) {
    if (v < 0 || v >= g.n_verts) return;
    int last = g.n_verts - 1;
    g.ver_list[v] = g.ver_list[last];
    int count = 0;
    for (int u = 0; u < g.n_verts; ++u) {           /* 数射出、射入的边 */
        if (ExistEdge(g, v, u)) ++count;
        if (g.directed && ExistEdge(g, u, v)) ++count;
    }
    for (int u = 0; u < g.n_verts; ++u) {           /* 末行、末列移入 v */
        g.edge_matrix[v][u] = g.edge_matrix[last][u];
        g.edge_matrix[u][v] = g.edge_matrix[u][last];
    }
    g.m_edges -= count;
    --g.n_verts;
}
```

注意：有向图分别数射出与射入边，无向图只数一行（一条边在矩阵中出现两次，按行统计不重复）。按加法原理，几个 $O(n)$ 循环相加仍是 $O(n)$，故删顶 $O(n)$。

### 3. 邻接表

**概念** 每个顶点维护一条单链表，链上结点记录一条射出的边：终点 `dest`、权重 `weight`、下一边 `next`；顶点表的 `adj` 是边表头指针。无向图每条边在两端各存一份。

```cpp
struct EdgeNode {
    int dest, weight;
    EdgeNode* next;
    EdgeNode(int d, int w, EdgeNode* n): dest(d), weight(w), next(n) {}
};
struct VexNode { EdgeNode* adj = nullptr; };
struct LGraph {
    int n_verts = 0, m_edges = 0;
    vector<VexNode> ver_list;
    bool directed;
    LGraph(int maxv, bool dir): ver_list(maxv), directed(dir) {}
    /* 深拷贝供欧拉算法使用；无向图只复制一次 */
    LGraph(LGraph const& o): n_verts(o.n_verts), m_edges(o.m_edges),
            ver_list(o.ver_list.size()), directed(o.directed) {
        for (int u = 0; u < n_verts; ++u)
            for (EdgeNode* p = o.ver_list[u].adj; p; p = p->next)
                if (u < p->dest || directed)
                    ver_list[u].adj = new EdgeNode(p->dest, p->weight, ver_list[u].adj);
    }
    ~LGraph() { for (auto& v : ver_list) { EdgeNode* p = v.adj; while (p) { auto nx = p->next; delete p; p = nx; } } }
};
```

空间 $O(n+m)$，与边数成正比，稀疏图（$m\ll n^2$）远比邻接矩阵省空间。

### 4. 邻接表上的基本操作

**算法 7-7** 取第一个邻接点：返回 `ver_list[v].adj`，$O(1)$。**算法 7-8** 判边：沿 u 的边表扫描有无 `dest == v`，最坏 $O(m)$。**算法 7-9** 插边：确认不存在后**头插**到 u 的边表，无向图再在 v 的表头插反向边，$O(1)$。

```cpp
EdgeNode* FirstAdjVex(LGraph const& g, int v) {
    return v < g.n_verts ? g.ver_list[v].adj : nullptr;   /* NIL 用 nullptr */
}
bool ExistEdge(LGraph const& g, int u, int v) {
    for (EdgeNode* p = FirstAdjVex(g, u); p; p = p->next)
        if (p->dest == v) return true;
    return false;
}
void InsertEdge(LGraph& g, int u, int v, int weight) {
    if (u != v && !ExistEdge(g, u, v)) {
        g.ver_list[u].adj = new EdgeNode(v, weight, g.ver_list[u].adj);
        ++g.m_edges;
        if (!g.directed) g.ver_list[v].adj = new EdgeNode(u, weight, g.ver_list[v].adj);
    }
}
```

**算法 7-10** 删顶点 v 及关联边，四步：释放 v 的边表；扫描其余各顶点边表删去射入 v 的边；把原来指向末顶点的边改指 v；把末顶点边表整体移入 v 的位置。无向图每条边在"射出""射入"两步各数一次，边数最后减半。

```cpp
void RemoveVex(LGraph& g, int v) {
    if (v < 0 || v >= g.n_verts) return;
    int count = 0;
    for (EdgeNode* p = g.ver_list[v].adj; p; ) {       /* 删射出的边 */
        EdgeNode* nx = p->next; delete p; p = nx; ++count;
    }
    g.ver_list[v].adj = nullptr;
    for (int u = 0; u < g.n_verts; ++u) {              /* 删射入的边、改指末顶点 */
        if (u == v) continue;
        EdgeNode *q = g.ver_list[u].adj, *prev = nullptr;
        while (q) {
            if (q->dest == v) {
                EdgeNode* dead = q; q = q->next;
                if (prev) prev->next = q; else g.ver_list[u].adj = q;
                delete dead; ++count;
            } else { prev = q; q = q->next; }
        }
        for (EdgeNode* r = g.ver_list[u].adj; r; r = r->next)
            if (r->dest == g.n_verts - 1) r->dest = v;
    }
    int last = g.n_verts - 1;                          /* 末顶点移入 v */
    if (v != last) { g.ver_list[v].adj = g.ver_list[last].adj; g.ver_list[last].adj = nullptr; }
    if (!g.directed) count /= 2;
    g.m_edges -= count; --g.n_verts;
}
```

思路：对每个顶点检查其每条邻接边，故总时间 $O(n+m)$。看似比矩阵删顶的 $O(n)$ 贵，但矩阵固定扫 n 行 n 列，邻接表与真实边数相关，稀疏图上可能更快。

### 5. 两种存储的对照

| 维度 | 邻接矩阵 | 邻接表 |
|---|---|---|
| 空间 | $O(n^2)$，与边数无关 | $O(n+m)$，与边数成正比 |
| 判边是否存在 | $O(1)$ | $O(m)$ 最坏 |
| 插入一条边 | $O(1)$ | $O(1)$ 头插 |
| 删除一个顶点 | $O(n)$ | $O(n+m)$ |
| 适合 | 稠密图、频繁判边 | 稀疏图、按邻接点遍历 |

## 四、图的遍历

### 1. 遍历的特点与已访问标志

**概念** 遍历是按某种方式访问所有顶点、每个只访问一次。沿顶点表顺序扫一遍最简单但用不到边；借助边信息才派生出 DFS 与 BFS，进而解决连通性等问题。遍历图与遍历二叉树有三点不同：顶点地位相同没有根；一个顶点可有多个前驱与后继且可能存在回路；无向图中一条边的两端互为后继。

**动机** 因存在回路，同一顶点可能经不同前驱被反复到达，故给每个顶点附加**已访问标志** `visited`，访问后置真，未访问者才进入下一步。

### 2. 深度优先遍历 DFS（算法 7-11、7-12）

**思路** 从 v 出发访问它，再对每个未访问邻接点递归 DFS，一条路走到黑、走不通才回退。算法 7-11 是外层驱动：标志全置假后对每个未访问顶点发起一次 DFS；算法 7-12 是递归核心。

```cpp
vector<bool> visited;                                /* 全局已访问标志 */
void visit(LGraph const&, int v) { cout << v << ' '; } /* 示例：输出编号 */

void DFS(LGraph const& g, int v) {                    /* 算法 7-12 */
    visited[v] = true;
    visit(g, v);
    for (EdgeNode* p = g.ver_list[v].adj; p; p = p->next)
        if (!visited[p->dest]) DFS(g, p->dest);
}
void DFSTraverse(LGraph const& g) {                   /* 算法 7-11 */
    visited.assign(g.n_verts, false);
    for (int v = 0; v < g.n_verts; ++v)
        if (!visited[v]) DFS(g, v);
}
```

注意外层循环：图不连通时从 0 号出发只能覆盖一个分量，必须对每个仍未访问的顶点再发起一次。

### 3. 广度优先遍历 BFS（算法 7-13、7-14）

**思路** 从 v 出发访问它，按"先访问者其邻接点先访问"的层次顺序扩散。借助队列 [[第3章-栈与队列.md]]：入队等待，出队访问并把未访问邻接点入队。算法 7-13 外层驱动，7-14 队列核心。

```cpp
void BFS(LGraph const& g, int v) {                    /* 算法 7-14 */
    queue<int> q;
    q.push(v);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        if (visited[u]) continue;                    /* 可能重复入队，这里去重 */
        visited[u] = true;
        visit(g, u);
        for (EdgeNode* p = g.ver_list[u].adj; p; p = p->next)
            if (!visited[p->dest]) q.push(p->dest);
    }
}
void BFSTraverse(LGraph const& g) {                   /* 算法 7-13 */
    visited.assign(g.n_verts, false);
    for (int v = 0; v < g.n_verts; ++v)
        if (!visited[v]) BFS(g, v);
}
```

注意课件写法在**入队时不检查** visited、仅出队时检查：同一顶点可能被重复入队，但只访问一次，结果正确。

### 4. 复杂度与两种遍历的用途

邻接表上 DFS 与 BFS 对每个顶点访问一次、每条边检查一次，复杂度 $O(n+m)$；邻接矩阵上找邻接点要扫一整行 n 个元素，复杂度 $O(n^2)$。空间上递归栈或队列最坏 $O(n)$。用途：DFS 沿一条路径深入、带回溯结构，适合探测路径与连通分量；BFS 按离起点的边数逐层推进，适合"最少边数"类问题；第 8 章的单源最短路是 BFS 在带权情形下的推广。

## 五、图的连通性

### 1. 无向图的连通性判断（算法 7-15）

**思路** 连通图从任一顶点出发的一次遍历就能走遍全部顶点；反之每遇到未访问顶点就开启一次新遍历，恰好对应一个新连通分量。故统计遍历次数：1 次则连通，否则输出分量数。

```cpp
bool IsConnect(LGraph const& g, int& components) {    /* 算法 7-15 */
    visited.assign(g.n_verts, false);
    components = 0;
    for (int v = 0; v < g.n_verts; ++v)
        if (!visited[v]) { ++components; BFS(g, v); }  /* 也可用 DFS */
    return components == 1;
}
```

复杂度 $O(n+m)$：每次遍历 $O(n+m)$，外层每个顶点只触发一次未访问分支。注意不能照搬到有向图——从某点可达所有点，不代表别人也能到达它。

### 2. 有向图连通性的判定思路

**概念** 有向图强连通判定多一个方向：从 v 出发 DFS/BFS 能到达所有顶点，只说明 v 能到达其余点；还要在**反向图**（所有边反向）中从 v 出发也能到达所有顶点，才说明互相可达。推广到强连通分量，Kosaraju 算法先在原图按完成顺序做一次 DFS，再在反向图按逆序做 DFS，每次得到一棵 DFS 树即一个分量。本日历只要求强连通概念与上述双向判定思路，完整算法留作拓展。

## 六、图的应用：一笔画的求解

本节回到开篇七桥，给出欧拉回路构造算法，对应课件"图的应用：哥尼斯堡七桥问题求解"，不涉及第 8 章内容。

### 1. 求一条回路 GetCircuit（算法 7-17）

**思路** 在无向图中从 start 出发贪心走边、边走边删：走到 tail 就删掉无向边 (head, tail) 的两个方向，把 tail 追加到回路末尾继续；直到回到 start（或无路可走）。删边保证每条边只走一次。

```cpp
void UnlinkArc(LGraph& g, int u, int v) {            /* 摘去 u 到 v 的弧，不动 m_edges */
    EdgeNode *p = g.ver_list[u].adj, *prev = nullptr;
    while (p && p->dest != v) { prev = p; p = p->next; }
    if (!p) return;
    if (prev) prev->next = p->next; else g.ver_list[u].adj = p->next;
    delete p;
}
vector<int> GetCircuit(LGraph& g, int start) {        /* 算法 7-17 */
    vector<int> circuit{start};
    int head = start;
    while (true) {
        EdgeNode* p = g.ver_list[head].adj;
        if (!p) break;                               /* 无路可走 */
        int tail = p->dest;
        UnlinkArc(g, head, tail);
        UnlinkArc(g, tail, head);                    /* 无向边两个方向都删 */
        --g.m_edges;
        circuit.push_back(tail);
        head = tail;
        if (head == start) break;                    /* 回到起点，闭合成回路 */
    }
    return circuit;
}
```

注意该算法针对**无向图**，删边时正反两个方向都要摘除。若还有从 start 可达的边未走完，说明这只是子回路，需进一步并入。

### 2. 求欧拉回路 EulerCircle（算法 7-18）

**思路** 先用度数检查存在性：只要有一个奇度顶点就返回空序列。然后在图的副本上边走边删，得到若干子回路；再把子回路**拼接**进主回路：扫描主回路每个顶点，若它在剩余图中还有边，就从它出发再走一条子回路，把这条子回路（去掉重复首顶点）插入该顶点之后，直至边用完。

```cpp
vector<int> EulerCircle(LGraph const& src) {         /* 算法 7-18 */
    for (int v = 0; v < src.n_verts; ++v) {          /* 度数检查 */
        int degree = 0;
        for (EdgeNode* p = src.ver_list[v].adj; p; p = p->next) ++degree;
        if (degree % 2 == 1) return {};              /* 有奇度顶点，无欧拉回路 */
    }
    LGraph g(src);                                   /* 深拷贝，边走边删 */
    vector<int> circuit = GetCircuit(g, 0);
    for (size_t i = 1; i < circuit.size(); ) {
        if (g.ver_list[circuit[i]].adj) {
            vector<int> next = GetCircuit(g, circuit[i]);
            circuit.insert(circuit.begin() + i + 1, next.begin() + 1, next.end());
        } else ++i;
    }
    return circuit;
}
```

注意拼接时插入 `next.begin()+1` 到末尾：子回路首顶点与主回路当前顶点是同一个，只保留一次。数组中间插入最坏 $O(n^2)$，改用链表可更高级；教学重点在"子回路并入主回路"的思想。

### 3. 从欧拉回路到欧拉路径

**思路** 恰有两个奇度顶点 $u$、$v$ 时（半欧拉图）无欧拉回路但有欧拉路径：加一条虚拟边 $(u,v)$ 使所有顶点度变偶，求出欧拉回路后删去这条虚拟边，回路即在该处断开成从 $u$ 到 $v$ 的欧拉路径，呼应欧拉定理第二种情形。

## 本章小结

本章从七桥的一笔画引入，建立图的完整概念体系：顶点与边、有向与无向、度与入度出度、路径与回路、完全图与网络、子图与连通分量、有向图的强连通。存储上，邻接矩阵以 $O(n^2)$ 空间换 $O(1)$ 判边，邻接表以 $O(n+m)$ 空间更适合稀疏图；删除顶点时两者都用"末元素覆盖被删位置"保持紧凑。遍历上，DFS 与 BFS 在邻接表上都是 $O(n+m)$，靠 `visited` 避免回路导致的重复访问，二者都能求连通分量——算法 7-15 数遍历次数即分量数。最后，欧拉定理把"能否一笔画"归结为奇度顶点个数，算法 7-17 与 7-18 给出无向连通图欧拉回路的构造：贪心走子回路，再逐条并入主回路。
