## 一、字符串的定义与 ADT

字符串（String）是 n 个字符组成的有限序列，记作 $s = c_1c_2\dots c_n$（$n \ge 0$）。$n=0$ 时为空串；字符串中的字符取自某字符集（如 ASCII）。

**子串与子序列**：s 中**连续**的一段字符组成的串称为 s 的子串，由起点与长度唯一确定，记作 $s[i..j]$（下标从 0 起，$i \le j$）；$i > j$ 时为空串。空串与 s 自身都是 s 的子串，不含 s 自身的称为真子串。从 s 中删去若干字符（也可不删）而不改变剩余字符相对顺序所得的串称为 s 的子序列，它不要求连续，因而不一定是子串。长度为 n 且字符互不相同的串有 $n(n+1)/2$ 个非空子串。

前缀是贴着串首的子串，后缀是贴着串尾的子串，真前缀与真后缀则不含串自身（详见 `OI-Wiki/字符串/基础.md`）。

**字符串的 ADT**：

- 数据对象：$D = \{s_i \mid s_i \in CharacterSet,\ i=1,2,\dots,n,\ n>0\}$ 或 $\varnothing$（空串）
- 数据关系：$R = \{\langle s_{i-1}, s_i \rangle \mid s_{i-1}, s_i \in D,\ i=2,\dots,n,\ n>0\}$

基本操作：

| 操作 | 说明 |
|---|---|
| InitStr(s) | 初始化空串 s，最大长度 kMaxSize |
| StrCopy(s) | 返回复制字符串 s 得到的新串 |
| StrIsEmpty(s) | 判断 s 是否空串，返回布尔值 |
| StrInsert(s, pos, t) | 在 s 的 pos 位置插入串 t，返回新 s |
| StrRemove(s, pos, len) | 删除 s 从 pos 起长度为 len 的子串 |
| SubString(s, pos, len) | 返回 s 从 pos 起长度为 len 的子串 |
| StrLength(s) | 返回 s 的长度 |
| StrConcat(s, t) | 返回 s 与 t 联接而成的新串 |
| StrCompare(s, t) | 比较大小：$s>t$ 返回 +1，相等 0，$s<t$ 返回 -1 |
| PatternMatch(s, t) | 返回 s 中首次出现 t 的位置，无则返回 NIL |
| Replace(s, sub_s, t) | 把 s 中所有子串 sub_s 替换为 t |

注意：位置 pos 从 1 开始计数（对应数组下标 pos-1）。

**终止符与存储约定**：C 风格字符串在末尾自动附加转义字符 `'\0'`（反斜杠 + 零，是一个字符）作终止符，扫到它即认为串结束，其本身不显示。

- 串长不计入 `'\0'`，所需存储空间则为串长 + 1：如 `"shallow"` 长度为 7，至少占 8 字节。答题时注意问的是长度还是空间大小。
- `'\0'` 的 ASCII 码为 0，是最小字符，故前缀相同时更长的串更大（把 `'\0'` 拉入比较即可判定），与 StrCompare 的规则一致。
- 连接要覆盖前一个串的 `'\0'` 并保留后一个串的 `'\0'`；清空只需令首位为 `'\0'`。

线性表用**长度指示位**界定范围，字符串用**终止符**当哨兵；也有的实现两者都存，用长度指示位把 StrLength 变成 $O(1)$。

## 二、字符串的存储实现

### 1. 顺序串（顺序存储结构）

所有字符存放在一段连续的存储空间中，字符的存储位置反映逻辑关系（本质是顺序表）。

**算法 4-1 字符串插入 StrInsert(s, pos, t)**

```text
输入：字符串 s，插入位置 pos≥1，待插字符串 t
输出：完成插入后的 s；若插入后长度 > kMaxSize 则直接退出
n ← s.length;  m ← t.length
if n+m ≤ kMaxSize then
    for i ← n-1 downto pos-1 do
        s.data[i+m] ← s.data[i]      // 从 pos-1 起的子串整体后移，给 t 留空位
    end
    for i ← 0 to m-1 do
        s.data[pos-1+i] ← t.data[i]  // 把 t 写入
    end
    s.length ← n+m
else
    长度超限，退出
end
```

思路：**从后往前**移动元素腾出空位（与顺序表插入一致，防止覆盖）。

**算法 4-2 字符串删除 StrRemove(s, pos, len)**

```text
输入：字符串 s，删除位置 pos≥1，删除字符个数 len
输出：删除子串后的 s
n ← s.length
if pos+len-1 < n then
    for i ← pos+len-1 to n-1 do
        s.data[i-len] ← s.data[i]    // 后面的字符前移覆盖
    end
    s.length ← n - len
else                              // 从 pos-1 起的所有字符全部删掉
    s.length ← pos - 1
end
```

**算法 4-3 字符串截取 SubString(s, pos, len)**

```text
输入：字符串 s，开始位置 pos≥1，截取长度 len
输出：截取的子串 sub_s
InitStr(sub_s)
n ← s.length;  i ← 0
while pos-1+i < n 且 i < len do     // 若 s 从 pos-1 起不足 len 个字符，截到末尾
    sub_s.data[i] ← s.data[pos-1+i]
    sub_s.length ← sub_s.length + 1
    i ← i + 1
end
return sub_s
```

**算法 4-4 字符串连接 StrConcat(s, t)**

```text
输入：字符串 s, t
输出：s 尾部联接 t 的新串；若长度 > kMaxSize 则退出
n ← s.length;  m ← t.length
if n+m ≤ kMaxSize then
    for i ← 0 to m-1 do
        s.data[n+i] ← t.data[i]
    end
    s.length ← n+m
else
    长度超限，退出
end
```

**算法 4-5 字符串比较 StrCompare(s, t)**

```text
输入：字符串 s, t
输出：s>t → +1；s=t → 0；s<t → -1
len ← Min(s.length, t.length);  i ← 0
while i < len 且 s.data[i] = t.data[i] do
    i ← i + 1
end
if i = len then
    if s.length > len then ret ← 1
    else if t.length > len then ret ← -1
    else ret ← 0
else if s.data[i] > t.data[i] then ret ← 1
else ret ← -1
return ret
```

规则：逐位比较字符；前缀相同则更长的串更大；全部相同为相等。字符比的是它在 ASCII 码表中的数值（`'A'=65`、`'a'=97`，同大小写内按字母表顺序递增）。

注意：字符串比较不是比较长度，也不是比较各字符 ASCII 值之和。

### 2. 链式串（链接存储结构）

每个字符是一个链表结点，逻辑上相邻的元素物理位置任意（本质是链表）。所有操作都需处理头结点与 pos=1 的边界。

**算法 4-6 链式串插入 StrInsert(s, pos, t)**

```text
输入：字符串 s，插入位置 pos≥1，待插字符串 t
输出：完成插入后的 s；若不存在位置 pos 则 s 不变
flag ← NormalCode
if t.length > 0 then
    tail ← t.head
    while tail.next ≠ NIL do tail ← tail.next   // 找 t 的末结点
    if s.length > 0 then
        p ← s.head;  count ← 1
        while p ≠ NIL 且 count < pos-1 do        // 找第 pos 个元素的前驱
            count ← count+1;  p ← p.next
        end
        if count = pos-1 then                     // 把 t 插在 p 后面
            tail.next ← p.next;  p.next ← t.head
        else if pos = 1 then                      // 插到 s 头部
            tail.next ← s.head;  s.head ← t.head
        else
            flag ← ErrorCode                      // 不存在位置 pos
        end
    else                                          // s 是空串
        s ← t
    end
end
if flag ≠ ErrorCode then s.length ← s.length + t.length
```

**算法 4-7 链式串删除 StrRemove(s, pos, len)**

```text
输入：字符串 s，删除位置 pos≥1，删除字符个数 len
输出：删除子串后的 s；删除位置不存在则 s 不变
if s.length > 0 then
    p ← s.head;  count ← 1
    while p ≠ NIL 且 count < pos-1 do
        count ← count+1;  p ← p.next
    end
    if pos = 1 或 (p ≠ NIL 且 count = pos-1) then
        if pos = 1 then deleted ← s.head
        else deleted ← p.next
        count ← 0
        while deleted ≠ NIL 且 count < len do    // 不足 len 个则删到末尾
            t ← deleted.next;  delete deleted
            count ← count+1;  s.length ← s.length-1
            deleted ← t
        end
        if pos = 1 then s.head ← deleted
        else p.next ← deleted
    end
end
```

**算法 4-8 链式串截取 SubString(s, pos, len)**：定位到第 pos 个结点，从它开始复制 len 个结点到新串 sub_s（不足则复制到末尾）；用临时头结点统一挂接，最后删除临时头结点返回。

**算法 4-9 链式串连接 StrConcat(s, t)**：若 s 非空，找到 s 末结点，把 `p.next ← t.head`；若 s 为空，直接 `s.head ← t.head`；最后 `s.length ← s.length + t.length`。

**算法 4-10 链式串比较 StrCompare(s, t)**：双指针 sp、tp 同步前进，遇到首对不同字符按 data 大小判定；一方先到 NIL 则长度更短的串更小；同时到 NIL 则相等。

**小结**：顺序串与链式串的对比同顺序表与链表——顺序串随机访问快、存储密度高，但插入删除需移动元素；链式串插入删除方便，但需逐个定位、每字符一个指针开销大。工程上常用"块链"（每个结点存多个字符）降低指针开销。

## 三、字符串的模式匹配

**概念**：在字符串 s 中找出与字符串 t 相等的子串的操作称为模式匹配（子串定位）。s 称为主串或目标串，t 称为模式串。

形式化：主串 s 用长度为 n 的数组 $s[0..n-1]$ 表示，模式串 t 用长度为 m（$m \le n$）的数组 $t[0..m-1]$ 表示。若存在 $p$（$0 \le p \le n-m$）使得 $s[p..p+m-1] = t[0..m-1]$，则 p 是一个**有效位移**。匹配就是从 s 中找出有效位移 p。

常见算法：BF（朴素）、KMP、BM、KR、Sunday 等。

### 1. BF 朴素算法

枚举主串的每个起点，从模式串第 0 位开始逐字符比较；失配则模式串整体后移一位重来。

**算法 4-11 朴素匹配 PatternMatchBF(s, t)**

```text
输入：目标串 s，模式串 t
输出：首个有效位移 p；失败返回 NIL
n ← s.length;  m ← t.length
for p ← 0 to n-m do
    for i ← 0 to m-1 do
        if s.data[p+i] ≠ t.data[i] then break
    end
    if i = m then break
end
if p > n-m then p ← NIL
return p
```

最坏情况 $O(nm)$（如主串全是 `a`、模式串 `aa...ab`，每次都在最后一位失配）。

思路：设 i 遍历主串、j 遍历模式串、k 记录本轮在主串中的起始位置，三者初值均为 0。字符相等则 i、j 都 +1；失配则 `j ← 0`、`i ← k+1`、`k ← k+1`；j 到达 m 而 i 未到 n 为匹配成功，i 到达 n 而 j 未到 m 为匹配失败，成功时返回定位 k。失配时主串指针要退回本轮起点的下一个位置，这一回退正是 KMP 所要消除的。

### 2. KMP 算法

**动机**：BF 失配时模式串整体右移一位、从头比较，大量已匹配信息被丢弃。KMP（Knuth–Morris–Pratt，克努特—莫里斯—普拉特）利用"失配时前 j-1 位已匹配成功"这一信息，把模式串一次右移多格。

**相关概念**（以字符串 `"aabaa"` 为例）：

| 概念 | 定义 | 例（"aabaa"） |
|---|---|---|
| 前缀 | $s[0..i]$，$0 \le i < n-1$ | {"a","aa","aab","aaba"} |
| 后缀 | $s[i..n-1]$，$0 < i \le n-1$ | {"a","aa","baa","abaa"} |
| 公共前后缀 | 前缀集合与后缀集合的交集 | {"a","aa"} |
| 最长公共前后缀 | 交集中最长的子串 | "aa" |

**next 数组定义**：串 t 的特征向量（next 数组），`next[i]` 表示 $t[0..i]$ 的最长公共前后缀中**前缀最末字符的下标**；若不存在最长公共前后缀则置 -1。因此 $t[0..i]$ 的最长公共前后缀长度为 `next[i] + 1`。

课件例：`"abcac"` 的特征向量为 `[-1, -1, -1, 0, -1]`。

| i | 子串 t[0..i] | 前缀集合 | 后缀集合 | 最长公共前后缀 | next[i] |
|---|---|---|---|---|---|
| 0 | a | 空 | 空 | 空 | -1 |
| 1 | ab | {a} | {b} | 空 | -1 |
| 2 | abc | {a,ab} | {c,bc} | 空 | -1 |
| 3 | abca | {a,ab,abc} | {a,ca,bca} | a | 0 |
| 4 | abcac | {a,ab,abc,abca} | {c,ac,cac,bcac} | 空 | -1 |

另一种常见约定（408 / 王道教材）：下标从 0 起时 `next[0] = -1`、`next[1] = 0`，`next[i]` 定义为 $t[0..i-1]$ 的最长公共真前后缀的**长度**，也就是最长公共前缀的下一位下标。两种约定相差一位：

| 约定 | next[i] 的含义 | `"ababc"` 的 next | 失配回退 |
|---|---|---|---|
| 课件（武大） | $t[0..i]$ 最长公共前后缀的前缀末字符下标（无则 -1） | -1、-1、0、1、-1 | $i \leftarrow \text{next}[i-1]+1$ |
| 408 / 王道 | $t[0..i-1]$ 最长公共真前后缀的长度 | -1、0、0、1、2 | $j \leftarrow \text{next}[j]$ |

换算：408 的 $next[i]$ = 课件的 $next[i-1]+1$（$i \ge 1$），反之课件 $next[i]$ = 408 的 $next[i+1]-1$。差异来自两处选择：下标从 0 还是 1 起，定义的是长度还是长度的下一位置，排列组合共四种，都能自洽，做题时按题目给定的前提走。部分匹配表 PMT 存的是最长公共真前后缀长度本身，与 408 的 next 恰好差 1，有的教材将两者混用；next 也称作前缀函数数组、失配跳转数组。

**next 数组的快速计算（O(m)）**：朴素求法需 $O(m^3)$。设 $j = \text{next}[i-1]$，则 $t[0..i-1]$ 的最长公共前后缀前缀末字符下标为 j、长度为 j+1。考察 $t[i]$ 与 $t[j+1]$：

- 若相等：$t[0..i]$ 的最长公共前后缀长度 = j+2，即 `next[i] = j+1`；
- 若不相等：问题递归为求 $t[0..j]$ 的最长公共前后缀（即 next[j]），令 $j \leftarrow \text{next}[j]$ 继续比较，直到相等或 j 不合法（j < 0）为止。

**算法 4-13 求解 next 数组 GetNext(t, next)**

```text
输入：模式串 t
输出：t 的 next 数组
m ← t.length
next[0] ← -1
for i ← 1 to m-1 do
    j ← next[i-1]
    while j ≥ 0 且 t.data[i] ≠ t.data[j+1] do
        j ← next[j]
    end
    if t.data[i] = t.data[j+1] then
        next[i] ← j+1
    else
        next[i] ← -1
    end
end
```

**next 数组的逐位求法**（408 约定，便于手算）：先取 `next[0] = -1`、`next[1] = 0`（若下标从 1 起则整体加 1，即 `next[1]=0`、`next[2]=1`）。对位置 i，取出前串 $t[0..i-1]$，从左侧起列出它的所有真前缀、从右侧起列出所有等长真后缀，取两者最长的公共项，其长度 L 即 `next[i] = L`；无公共项则 `next[i] = 0`。所列真前缀与真后缀都不含与前串等长的那一项，否则它恒等于自身而失去意义。

**KMP 匹配过程**：目标串指针 j 与模式串指针 i 同步前进；字符相等则 i、j 都 +1；失配时若 i > 0，模式串右移，令 $i \leftarrow \text{next}[i-1]+1$ 继续匹配；i = 0 时目标串指针 j +1。匹配全程目标串只向右移动，比较复杂度 $O(n)$，加上 next 数组 $O(m)$，总复杂度 $O(n+m)$。

**算法 4-14 KMP 匹配 PatternMatchKMP(s, t)**

```text
输入：目标串 s，模式串 t
输出：首个有效匹配位置 p；失败返回 NIL
n ← s.length;  m ← t.length;  p ← NIL
if n ≥ m then
    GetNext(t, next)
    i ← 0;  j ← 0
    while j < n 且 i < m do
        if s.data[j] = t.data[i] then
            i ← i+1;  j ← j+1
        else if i > 0 then
            i ← next[i-1] + 1
        else
            j ← j+1
        end
    end
    if i = m then p ← j-m
end
return p
```

另一种写法（408 约定）用 $j \leftarrow \text{next}[j]$ 表达回退，与算法 4-14 等价，其中 i 遍历主串、j 遍历模式串：

```text
i ← 0;  j ← 0
while i < n 且 j < m do
    if j = -1 或 s[i] = t[j] then
        i ← i+1;  j ← j+1      // j = -1 为首位即失配，主串指针前进一位
    else
        j ← next[j]            // 模式串右移，主串指针原地不动
    end
end
if j = m then 匹配位置 ← i - m
```

注意：两种写法都保持主串指针不回退，这也是 KMP 适用于流式文本与大文件分块检索的原因（读一段、匹配一段、丢弃一段，指针只朝一个方向移动）。改用 nextval 时只需把 `next[j]` 换成 `nextval[j]`。

### 3. nextval 数组（改进的 next）

**动机**：若 $t[i] = t[\text{next}[i]]$，则按 next 跳到下标 next[i] 后，该位字符与失配位字符相同，必然再次失配，多出一次无用的比较。nextval 把这种注定失败的跳转提前合并。

**nextval 的定义**：`nextval[0] = -1`；对 $i \ge 1$，令 $k = \text{next}[i]$：

- 若 $t[i] \ne t[k]$：`nextval[i] = k`，即沿用 next 值；
- 若 $t[i] = t[k]$：`nextval[i] = nextval[k]`，即继承而一步到位。

课件例 `"ababc"`（408 约定，`next = [-1, 0, 0, 1, 2]`）：

| i | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| t[i] | a | b | a | b | c |
| next[i] | -1 | 0 | 0 | 1 | 2 |
| nextval[i] | -1 | 0 | -1 | 0 | 2 |

i=2 处 $t[2]='a' = t[0]='a'$，故继承 `nextval[0] = -1`；i=3 处 $t[3]='b' = t[1]='b'$，故继承 `nextval[1] = 0`。nextval 也称作优化或修正的 next 数组，题干出现"优化""修正"字样即指它。

KMP 的优点：复杂度 $O(n+m)$ 为线性，主串指针不回退因而适合大文件分块检索，next 数组由模式串单独决定、可与模式串绑定复用（同一模式串多次查找只需计算一次）。缺点：需额外 $O(m)$ 空间，短串上优化不明显，逻辑较 BF 难理解。

### 4. BM 与 KR（了解）

| 算法 | 核心思想 |
|---|---|
| BM | 模式串**从右向左**比较；失配时用**坏字符**规则与**好后缀**规则选择右移量，跳过尽量多的位置，平均性能优于 KMP |
| KR | 用哈希函数把模式串与主串子串映射为数值，先比较哈希值（哈希筛选），相等再逐字符核验（碰撞核验）；配合**滚动哈希**在 O(1) 内更新下一个窗口的哈希值 |

## 本节重点

- 字符串的本质是受限线性表，顺序串操作的核心是"插入从后往前移、删除从前往后移"；链式串操作注意头结点与 pos=1 边界。
- 子串是原串中连续的一段，子序列不要求连续；前后缀是贴着串首或串尾的子串，真前后缀不含串自身。
- 终止符 `'\0'` 不计入串长但占 1 字节空间（长 n 的串至少需 n+1）；比较是逐位比 ASCII，与长度及各字符 ASCII 值之和无关。
- next 数组：`next[i]` = $t[0..i]$ 最长公共前后缀中前缀末字符下标（无则 -1），最长公共前后缀长度 = `next[i]+1`；408 约定定义为 $t[0..i-1]$ 最长公共真前后缀的长度，与课件相差一位。
- nextval：$t[i] \ne t[\text{next}[i]]$ 时 $nextval[i] = \text{next}[i]$，相等时 $nextval[i] = \text{nextval}[\text{next}[i]]$。
- KMP 复杂度 $O(n+m)$：next 快速计算 $O(m)$ + 匹配 $O(n)$，目标串指针永不回退。
- 失配回退：课件写法回退到 `next[i-1]+1` 位，408 写法为 $j \leftarrow \text{next}[j]$，`j = -1` 时主串指针前进一位。
- 注意：next 与 nextval 不要混用；不同教材的 next 可能相差 1，照抄答案前先确认下标起点与定义。
