# 第 06 讲 图（上）：定义、存储与遍历

> 本讲依据视频 065–079（6.1 什么是图、6.2 图的遍历、6.3 拯救 007、6.4 六度空间、小白专场：建立图）整理。
> 学习目标：掌握图的定义与基本术语；会用邻接矩阵、邻接表两种方法表示图并分析其空间与时间代价；掌握 DFS 与 BFS 两种遍历及其复杂度；能处理非连通图；并能把"图"这一抽象工具应用到拯救 007、六度空间等实际问题。

## 一、什么是图

### 1. 图是描述"多对多"关系的工具

线性表描述一对一，树描述一对多，而**图（Graph）**描述的是多对多关系——线性表和树其实都是图的特例。现实中的社交网络、交通路网、电路网络都是图：顶点是人或站点，边代表"朋友关系"或"通路"。由此引出三个经典问题：六度空间理论（任意两人之间最多隔 6 个人）、最短路径（两村之间怎么走最快）、最小生成树（修公路连通所有村子且花费最少）。

一个图由两部分组成：

- 顶点集合 $V$（Vertex 的缩写）：非空有限。一个图可以没有边，但不能没有顶点；
- 边集合 $E$：顶点之间的某种关系。用顶点对表示一条边——无向边用圆括号 $(v, w)$，表示双向；有向边用尖括号 $\langle v, w\rangle$，表示单向。

本课程默认不考虑重边（两顶点间至多一条边）和自回路（边不指回自身）。若每条边还带一个数字（权重，如路程长度），这样的图又称**网络**。

### 2. 基本术语速查

| 术语 | 含义 |
|---|---|
| 无向图 / 有向图 | 所有边无方向 / 边的方向有意义 |
| 度 | 与某顶点关联的边数；有向图分出度（发出）与入度（指向） |
| 路径 | 从 $v$ 到 $w$ 依次经过的顶点序列，相邻顶点间有边 |
| 路径长度 | 无权图为边数；带权图为各边权重之和 |
| 简单路径 | 路径上顶点互不相同；含回路（起点等于终点）的路径不简单 |
| 连通 | $v$ 到 $w$ 存在路径；连通图即任意两顶点都连通 |
| 连通分量 | 无向图的极大连通子图（顶点数与边数均极大：再加顶点就不连通，所含边一条不漏） |
| 强连通 / 弱连通 | 有向图中两顶点互相可达为强连通；抹掉方向后连通为弱连通 |
| 强连通分量 | 有向图的极大强连通子图 |

【进阶】图论术语体系与连通性判定详见 OI-Wiki：[图论/连通性](../OI-Wiki/图论/连通性.md)。

## 二、图的存储表示

### 1. 邻接矩阵

用二维数组 $G$ 表示 $n$ 个顶点（编号 $0$ 到 $n-1$）：$G[i][j]=1$ 表示有边，$0$ 表示无边。

特点与代价：

- 对角线元素恒为 0（无自回路）；无向图的矩阵关于主对角线对称，一条边被存了两次。
- 想省一半空间，不能"只存一半、另一半填 0"——0 也是格子、也占内存。真正的做法是**压缩存下三角**，用一维数组按行存放：$G[i][j]$（$i \ge j$）藏在 $a[i(i+1)/2+j]$ 的位置。省了空间，判边要先算下标。
- 带权图只需把 1 换成权重；"无边"究竟填 0 还是无穷大，取决于具体问题，到最短路径一节再细谈。

优缺点：

- 优点：直观；判两顶点间有没有边是 $O(1)$；无向图扫一行、有向图扫一行即得邻接点，扫一行（无向图也可扫一列）求和即得度。
- 缺点：存**稀疏图**（点多边少）时矩阵里堆满 0，既浪费空间又浪费时间——统计边数要把 $n^2$ 个元素全扫一遍；稠密图乃至完全图则正合适，没有浪费的格子。

复杂度：空间 $O(n^2)$。

### 2. 邻接表

邻接表是一个**指针数组**：每个顶点配一个头指针，把该顶点的所有邻接点串成一条链表，矩阵里的 0 一个都不存。

- 邻接点在链表里的先后没有约定，因此邻接表表示不唯一。
- 空间 = $n$ 个头指针 + $2e$ 个边结点（无向图一条边存两遍）；每个结点除邻接点编号外还有指针域（带权图再加权重域），所以**必须足够稀疏才合算**。
- 找某顶点的所有邻接点：顺着链表走即可，不碰任何 0；无向图链表长度即度。
- 有向图只能算出度；要算入度需另建**逆邻接表**（把矩阵每一列也串成链表）。
- 缺点：判任意两顶点间有没有边要沿链表查找，不如邻接矩阵直接。

【进阶】两种存储的系统对比与更多表示法详见 OI-Wiki：[图论/图的存储](../OI-Wiki/图论/图的存储.md)。

> 提醒：邻接矩阵与邻接表只是最常见的两种，不是唯一选择。表示方法取决于具体问题——后面"拯救 007"就会看到，不必真的把图建出来。

## 三、图的遍历

遍历即把每个顶点访问且仅访问一次，是后面所有图算法的基础。

### 1. 深度优先搜索（DFS）

类比走迷宫：站在路口，挑一条没走过的路一路走到底，所有方向都走过了就**原路返回**（对应栈的弹出、递归返回），直到所有灯都点亮。

伪码要点：先置 `visited[v]=true`，再对 $v$ 的每个未访问邻接点 $w$ 递归调用 DFS(w)；邻接点全部访问过后函数返回，即"原路返回"。这正是树的先序遍历向图的推广。

时间复杂度取决于存储方式：邻接表下每顶点访问一次、每条边（双向计两次）扫一次，为 $O(n+e)$；邻接矩阵下找邻接点要扫一整行 $n$ 个元素，为 $O(n^2)$。

### 2. 广度优先搜索（BFS）

对应树的层序遍历，借助**队列**：起点入队并标记访问；每次出队一个顶点 $v$，把它所有未访问的邻接点标记并入队，如此一圈圈向外扩张。

复杂度与 DFS 相同：邻接表 $O(n+e)$，邻接矩阵 $O(n^2)$。

【进阶】两种遍历的细节与非递归实现详见 OI-Wiki：[图论/深度优先搜索](../OI-Wiki/图论/深度优先搜索.md)、[图论/广度优先搜索](../OI-Wiki/图论/广度优先搜索.md)。

### 3. 为什么需要两种遍历

以方格迷宫寻路为例：DFS 一条道走到黑，若邻接点选取顺序不巧，会先在死胡同里绕出很远才找到出口；BFS 一圈圈扩散，先访问到出口时路径一定最短。但若把出口放在离起点很近的角落，DFS 可能一步到位，BFS 反而要逐层铺开。两种策略各有所长——要最短路径选 BFS，要穷举与回溯选 DFS，解决具体问题时按"想要什么"来选。

### 4. 图不连通怎么办

从一个顶点出发的一次 DFS/BFS 只能覆盖它所在的连通分量。要遍历整个非连通图，只需套一层循环：对每个顶点 $v$，若 `visited[v]` 为假，就从 $v$ 出发做一次 DFS/BFS——每调用一次就啃掉一个连通分量。这就是"列出连通集"（ListComponents）类问题的核心。

## 四、应用实例

### 1. 拯救 007

007 被押到湖心小岛，靠踩鳄鱼头跳上岸。建模：鳄鱼头是顶点，**岸边也要当成一个顶点**（图的顶点可以是任何抽象对象，不必圆头圆脑）；两条鳄鱼间距不超过 007 的跳跃距离则连边；某鳄鱼与岸边能一步跳到，则它与岸连边。问题变成：从"孤岛"出发能否遍历到"岸"顶点？

- 第一跳与后续不同：第一跳半径 = 跳跃半径 + 小岛半径，其余跳半径就是跳跃半径。孤岛单独处理，不放进递归。
- 总体框架是 ListComponents 的改造：枚举所有"第一跳够得着且未踩过"的鳄鱼，从它做 DFS；`visited` 表示"已踩过"。
- 改良 DFS：踩到鳄鱼后**先问 IsSafe(v)**（能否直接跳上岸），能则返回"是"；否则对每个未访问且 Jump(v,w) 为真的 $w$ 递归，任一子调用返回"是"即提前返回。
- 图不一定非要显式存：本问题里"邻接点"靠实时算两点距离判断更省事，邻接矩阵、邻接表反而都麻烦。

### 2. 六度空间

给定社交网络图，对每个顶点统计"6 步以内能到达的人数"占总人数的百分比。思路是从每个顶点做一次 BFS，但只数到第 6 层。

- BFS 要返回访问计数 count：入队即 count++。
- 层数控制的两种做法：① 给每个顶点加 layer 域，占 $O(n)$ 额外空间；② 教材推荐的省空间做法——用 level、last、tail 三个变量：tail 跟踪当前层已入队的最后一个顶点，当出队的顶点恰为 last（本层最后一个）时 level++，再令 last=tail。level 到 6 即停止。

## 五、小白专场：建立图

### 1. 邻接矩阵版（MGraph）

- 结构：把邻接矩阵 `G[MaxVertexNum][MaxVertexNum]`、顶点数 Nv、边数 Ne 打包进 GNode；再用一个数组 Data[] 存顶点附带信息。为传参方便，图类型定义为指向结点的指针（MGraph = PtrToGNode）。
- CreateGraph(N)：申请结点，置 Nv=N；无权图把矩阵全置 0，有权图全置成无穷大 INFINITY。顶点编号约定从 0 开始。
- 边 Edge = (V1, V2, Weight)；InsertEdge 只需给 `G[V1][V2]` 赋值，无向图再对称写 `G[V2][V1]`。
- BuildGraph：先读顶点数建空图，再读 Ne（直接读进 Graph->Ne，无需临时变量），循环读边调用 InsertEdge；顶点有数据时再补一个循环读 Data。
- 取巧写法：考试时把矩阵、Nv、Ne 写成全局变量，BuildGraph 返回 void，二重循环初始化后逐条读边赋值即可。是否值得工程化打包，取决于代码要长期复用还是交一次就走。

### 2. 邻接表版（LGraph）

- 头结点 VNode 含 FirstEdge 指针与可选的 Data；边结点 AdjVNode 只存**邻接点下标 AdjV**（起点由它挂在谁家链表决定，不必再存）、权重（带权图）和 Next 指针。
- 初始化"没有边"：把每个顶点的 FirstEdge 置空，一重循环即可（不用像邻接矩阵那样二重循环）。
- 插入边：把新边结点**插在链表头部**最简单——`NewNode->Next = G[V1].FirstEdge; G[V1].FirstEdge = NewNode;`；无向图把 V1、V2 互换再插一次。
- BuildGraph 流程与 MGraph 对称，先初始化空表再逐条插边。
