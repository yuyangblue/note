### 1. 二、实验介绍浏览器的前进和后退功能让用户能够在已访问的页面之间导航。点击链接访问新页面时，当前页面被压入后退栈；点击后退按钮时，从后退栈弹出页面作为当前页，同时将原当前页压入前进栈；点击前进按钮时，从前进栈弹出页面。

本实验用 C 语言实现基于双栈的浏览器导航模拟，通过控制台菜单交互，支持访问新页面、后退、前进、显示状态、清空历史和设置栈容量等功能。

|功能模块|子功能|详细说明|
|---|---|---|
|访问新页面|输入 URL 并访问|将当前页压入后退栈，清空前进栈，设置新当前页|
|后退|回退到上一页|从后退栈弹出，当前页压入前进栈|
|前进|前进到下一页|从前进栈弹出，当前页压入后退栈|
|显示状态|查看三部分状态|显示当前页面、后退栈内容、前进栈内容、栈容量|
|清空历史|清空双栈|释放后退栈和前进栈的所有 URL|
|设置栈容量|重新设置容量|销毁当前浏览器，创建新的指定容量浏览器|

|操作|后退栈|前进栈|当前页|
|:--|:--|:--|:--|
|访问新页面|push(当前页)|清空|新 URL|
|后退|pop → 新当前页|push(原当前页)|后退栈弹出页|
|前进|push(原当前页)|pop → 新当前页|前进栈弹出页|

```c
    if (b->current) {

}
```

```c
void destroyBrowser(Browser *b) {
    if (!b) return;
    // 释放当前页
    if (b->current) free(b->current);
    
    // 释放后退栈的所有 URL 字符串
    for (int i = 0; i <= b->backStack->top; i++)
        if (b->backStack->urls[i]) free(b->backStack->urls[i]);
    free(b->backStack->urls);   // 释放后退栈指针数组
    free(b->backStack);          // 释放后退栈结构体
    
    // 释放前进栈的所有 URL 字符串
    for (int i = 0; i <= b->forwardStack->top; i++)
        if (b->forwardStack->urls[i]) free(b->forwardStack->urls[i]);
    free(b->forwardStack->urls);  // 释放前进栈指针数组
    free(b->forwardStack);        // 释放前进栈结构体
    
    free(b);  // 释放浏览器结构体
}

| 步骤 | 释放内容 | 说明 |
|:-----|:---------|:-----|
| ① | 当前页 URL | free(b->current) |
| ② | 后退栈 URL 数组 | 遍历 top 逐个 free，再 free 数组 |
| ③ | 后退栈结构体 | free(b->backStack) |
| ④ | 前进栈 URL 数组 | 同样遍历释放 |
| ⑤ | 前进栈结构体 | free(b->forwardStack) |
| ⑥ | 浏览器结构体 | free(b) |
```

### 1. 六、栈操作模块```c

// 创建栈：分配 capacity 个指针的空间，top 初始化为 -1  
Stack _createStack(int capacity) {  
Stack_ s = (Stack_)malloc(sizeof(Stack));  
if (!s) return NULL;  
s->urls = (char_*)calloc(capacity, sizeof(char*));  
if (!s->urls) { free(s); return NULL; }  
s->top = -1;  
s->capacity = capacity;  
return s;  
}

// 销毁栈：释放所有 URL 字符串和数组内存  
void destroyStack(Stack *s) {  
if (!s) return;  
for (int i = 0; i <= s->top; i++)  
if (s->urls[i]) free(s->urls[i]);  
free(s->urls);  
free(s);  
}

// 压栈：先检查是否已满，复制 URL 后存入栈顶  
void pushStack(Stack _s, const char_ url) {  
if (isStackFull(s)) {  
printf("栈已满，无法压入: %s\n", url);  
return;  
}  
s->top++; // 栈顶指针上移  
if (s->urls[s->top]) free(s->urls[s->top]); // 释放旧值（如有）  
s->urls[s->top] = (char*)malloc(strlen(url) + 1);  
strcpy(s->urls[s->top], url); // 复制 URL 到栈中  
}

// 弹栈：返回 URL 所有权给调用者（调用者负责释放）  
char _popStack(Stack_ s) {  
if (isStackEmpty(s)) return NULL;  
char *url = s->urls[s->top]; // 取出栈顶 URL  
s->urls[s->top] = NULL; // 置 NULL 避免重复释放  
s->top--; // 栈顶指针下移  
return url; // 调用者负责 free  
}

int isStackEmpty(Stack _s) { return s->top == -1; }  
int isStackFull(Stack_ s) { return s->top >= s->capacity - 1; }


### 1. 十二、设计思路总结浏览器的前进后退功能天然适合用双栈实现：

- 后退栈记录访问历史（每次访问新页面时压入）
    
- 前进栈记录后退操作（每次后退时压入）
    
- 两个栈的配合完美模拟了前进后退的语义
    

1. **访问新页面**：当前页→后退栈，清空前进栈，设置新当前页
    
2. **后退**：后退栈 pop→新当前页，原当前页→前进栈
    
3. **前进**：前进栈 pop→新当前页，原当前页→后退栈
    
4. **清空历史**：释放双栈所有 URL，当前页不变
    

|操作|时间复杂度|空间复杂度|
|:--|:--|:--|
|访问新页面|O(k)|O(1)|
|后退|O(1)|O(1)|
|前进|O(1)|O(1)|
|显示状态|O(n)|O(1)|
|清空历史|O(n)|O(1)|

k 为前进栈大小（需要清空），n 为栈中元素个数。

1. **字符串所有权管理**：pop 后调用者负责释放，push 时创建副本
    
2. **访问新页面一定要清空前进栈**：这是浏览器前进后退的核心语义
    
3. **栈容量检查**：push 前先检查 isFull，防止数组越界
    
4. **内存释放要彻底**：destroyBrowser 要逐层释放所有动态内存
    
5. **显示状态时只遍历 top 以内的元素**：capacity 之外的元素未初始化
    

```c
void visit(Browser *b, const char *url) {
    if (b->current) {                              // ① 如果有当前页
        pushStack(b->backStack, b->current);        // ② 当前页压入后退栈
        free(b->current);                           // ③ 释放原当前页
    }
    while (!isStackEmpty(b->forwardStack)) {        // ④ 清空前进栈
        char *furl = popStack(b->forwardStack);
        free(furl);                                 // ⑤ 释放 URL 内存
    }
    b->current = (char*)malloc(strlen(url) + 1);    // ⑥ 分配新 URL 内存
    strcpy(b->current, url);                        // ⑦ 复制 URL
    printf("访问: %s\n", url);
}
```

|行|说明|
|:--|:--|
|①|首次访问时 b->current 为 NULL，跳过|
|②|将当前页备份到后退栈，供后退使用|
|③|释放旧 URL（已复制到栈中）|
|④|新页面产生新浏览分支，前进历史失效|
|⑤|popStack 返回 URL 所有权，需 free|
|⑥-⑦|为新 URL 分配空间并复制|

```c

        printf("无法后退: 后退栈为空\n");

    pushStack(b->forwardStack, b->current);         // ② 当前页→前进栈

    free(b->current);                                // ④ 释放原当前页
    b->current = url;                                // ⑤ 设置新当前页

}
```

|:--|:--|
|①|后退栈空则无法后退|
|②|当前页先保存到前进栈，供前进恢复|
|③|从后退栈取出上一页|
|④|释放当前页（已压入前进栈）|
|⑤|指向新的当前页|

```c
char* goForward(Browser *b) {
    if (isStackEmpty(b->forwardStack)) {            // ① 检查前进栈
        printf("无法前进: 前进栈为空\n");
        return b->current;
    }
    pushStack(b->backStack, b->current);            // ② 当前页→后退栈
    char *url = popStack(b->forwardStack);           // ③ 前进栈弹出
    free(b->current);                                // ④ 释放原当前页
    b->current = url;                                // ⑤ 设置新当前页
    printf("前进到: %s\n", b->current);
    return b->current;
}
```

|行|说明|
|:--|:--|
|①|前进栈空则无法前进|
|②|当前页保存到后退栈|
|③|从前进栈取出之前后退的页面|
|④|释放原当前页|

|方案|实现方式|优点|缺点|
|:--|:--|:--|:--|
|双栈|后退栈+前进栈|前进后退 O(1)，语义清晰|多一个栈的空间开销|
|单栈+指针|一个栈+当前指针|省空间|前进时需重新压栈，逻辑复杂|
|链表|双向链表|无容量限制|实现复杂，内存碎片|

双栈方案是浏览器前进后退功能的最经典实现，也是栈的典型应用案例。

| 对比项  | 数组实现    | 链表实现  |
| :--- | :------ | :---- |
| 随机访问 | O(1)    | O(n)  |
| 内存管理 | 固定容量    | 动态扩展  |
| 实现难度 | 简单      | 较复杂   |
| 缓存友好 | 是（连续内存） | 否     |
| 适用场景 | 容量可预估   | 容量不确定 |
