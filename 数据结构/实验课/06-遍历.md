-  **二、实验介绍**

---

二叉树的遍历是按特定顺序访问树中所有节点的过程，是树结构算法的基础。前序遍历先访问根节点再遍历左右子树，中序遍历先遍历左子树再访问根节点然后遍历右子树，后序遍历先遍历左右子树再访问根节点，层序遍历按从上到下从左到右的顺序逐层访问。

本实验实现一个基于 C 语言的二叉树遍历系统，支持交互式菜单操作，提供前序、中序、后序、层序四种遍历方式，每种遍历提供递归和非递归两种实现，同时支持根据遍历序列重建二叉树、镜像翻转和树形结构可视化。

| 功能模块  | 子功能   | 详细说明                     |
| ----- | ----- | ------------------------ |
| 交互式菜单 | 主菜单循环 | 启动后显示菜单，数字键选择功能          |
| 递归遍历  | 前序    | preR(root)：根→左→右         |

**功能描述**：选择 1 前序遍历，按 根→左→右 的顺序递归访问每个节点。

![前序](http://115.156.107.145/cguserImages?_img=3d89b4d00a1efffc85f513152fd29c7e.png)

```c
void preR(Node *r) {
    if (!r) return;          // 空节点返回（递归终止条件）
    // if (!r) 等价于 if (r == NULL)，检查是否为空指针
    // 空指针表示已到达叶节点的子节点，直接返回
    // 这是递归终止条件，防止无限递归

    printf("%d ", r->data);  // 1. 访问根节点
    // printf 的位置决定了遍历类型
    // 放在两个递归之前 = 前序（根左右）
    // 放在两个递归中间 = 中序（左根右）
    // 放在两个递归之后 = 后序（左右根）

    preR(r->left);           // 2. 递归遍历左子树
    // 先一直向左递归，直到遇到 NULL
    // 左子树完全遍历完后才会执行下一行

    preR(r->right);          // 3. 递归遍历右子树
    // 左子树遍历完成后，再遍历右子树
    // 右子树也遍历完后，函数返回到上一层
}
// 输出: 1 2 4 8 5 3 6 7
// 从根1开始，先输出1，再递归左2
// 输出2后递归左4，输出4后递归左8，输出8后左右NULL返回
// 回到4右NULL返回，回到2右5，输出5后左右NULL返回
// 回到1右3，输出3，递归左6输出6，递归右7输出7
```

**逐行详解**:

|行号|代码|功能|说明|
|:-:|:--|:--|:--|
|1|if(!r) return|终止条件|r==NULL时返回，防止空指针访问|
|2|printf("%d",r->data)|访问根节点|前序：先输出当前节点，再递归子树|
|3|preR(r->left)|遍历左子树|递归处理左子树所有节点|
|4|preR(r->right)|遍历右子树|左子树完成后，递归处理右子树|

![层序](http://115.156.107.145/cguserImages?_img=902dacc4ce8831cc0ec069963afcd70d.png)

```c
void levelOrder(Node *r) {
    if (!r) return;              // 空树直接返回
    // 层序遍历需要队列，这里用数组模拟队列

    Node *q[100];                // 队列数组，最多存100个节点指针
    int front = 0, rear = 0;     // front=队首出队下标, rear=队尾入队下标

    q[rear++] = r;               // 根节点入队：q[0]=root, rear=1

    while (front < rear) {       // 队列不为空时循环
        // front<rear 表示队列中还有元素等待处理

        Node *n = q[front++];    // 出队：取出队首元素，front后移
        // 先入队的节点先出队（FIFO特性）

        printf("%d ", n->data);  // 访问当前节点

        if (n->left)             // 如果左子节点存在
            q[rear++] = n->left; // 左子节点入队
        if (n->right)            // 如果右子节点存在
            q[rear++] = n->right;// 右子节点入队
        // 子节点入队顺序：先左后右
        // 保证同一层从左到右的顺序
    }
}
// 输出: 1 2 3 4 5 6 7 8
// 队列变化过程:
// 初始: [1]
// 出1: 入2,3 -> [2,3]
// 出2: 入4,5 -> [3,4,5]
// 出3: 入6,7 -> [4,5,6,7]
// 出4: 入8   -> [5,6,7,8]
// 出5,6,7,8: 无子节点入队
// 输出: 1 2 3 4 5 6 7 8
```

|步骤|队列内容(front→rear)|出队|子节点入队|
|:-:|:--|:-:|:--|
|1|[1]|1|2,3|
|2|[2,3]|2|4,5|
|3|[3,4,5]|3|6,7|
|4|[4,5,6,7]|4|8|
|5|[5,6,7,8]|5|-|
|6|[6,7,8]|6|-|
|7|[7,8]|7|-|
|8|[8]|8|-|

![非递归前序](http://115.156.107.145/cguserImages?_img=2f89f940489375781784492758e5dd75.png)

````c
void preI(Node *r) {
    Node *stack[100]; int top = -1;
    // stack数组模拟栈，top指向栈顶，-1表示空栈
    // 栈用于存储待访问的节点指针

    if (r) stack[++top] = r;
    // 根节点入栈，++top先自增再赋值
    // 栈内容: [root]

    while (top >= 0) {
        // 只要栈不为空就循环处理
        Node *n = stack[top--];  // 出栈: 取出栈顶元素
        printf("%d ", n->data);  // 访问节点(根)

        // 关键: 先右后左入栈
        if (n->right) stack[++top] = n->right;  // 右子入栈
        if (n->left)  stack[++top] = n->left;    // 左子入栈
        // 栈后进先出: 左子后入栈但先出栈
        // 所以左子先被访问，实现 "根->左->右"
    }
}
// 输出: 1 2 4 8 5 3 6 7

**逐行详解**:
| 行号 | 代码 | 功能 | 说明 |
|:----:|:-----|:-----|:------|
| 1 | if(r) stack[++top]=r | 根入栈 | 根节点先入栈，循环起点 |
| 2 | while(top>=0) | 栈非空循环 | 直到所有节点被处理 |
| 3 | n=stack[top--] | 出栈 | 取出栈顶节点 |
| 4 | printf("%d",n->data) | 访问 | 出栈后立即访问(前序) |
| 5 | right入栈 | 右子入栈 | 先压右子 |
| 6 | left入栈 | 左子入栈 | 后压左子->先出访问 |

```c
void inI(Node *r) {
    Node *stack[100]; int top = -1;
    Node *cur = r;
    while (cur || top >= 0) {
        while (cur) { stack[++top] = cur; cur = cur->left; }
        cur = stack[top--];
        printf("%d ", cur->data);
        cur = cur->right;
    }
}
// 输出: 8 4 2 5 1 6 3 7

**逐行详解**:
| 行号 | 代码 | 功能 | 说明 |
|:----:|:-----|:-----|:------|
| 1 | while(cur) | 左链入栈 | 将所有左子节点入栈 |
| 2 | stack[++top]=cur | 入栈 | 保存路径节点 |
| 3 | cur=cur->left | 向左 | 一直走到最左边 |
| 4 | cur=stack[top--] | 出栈 | 取出最近入栈节点 |
| 5 | printf | 访问 | 出栈后访问(中序) |
| 6 | cur=cur->right | 转右 | 处理右子树 |

```c
void postI(Node *r) {
    if (!r) return;
    Node *stack[100]; int top = -1;
    Node *output[100]; int top2 = -1;
    stack[++top] = r;
    while (top >= 0) {
        Node *n = stack[top--];
        output[++top2] = n;
        if (n->left) stack[++top] = n->left;
        if (n->right) stack[++top] = n->right;
    }
    while (top2 >= 0) printf("%d ", output[top2--]->data);
}
// 输出: 8 4 5 2 6 7 3 1

stack2逆序输出: 8 4 5 2 6 7 3 1

Node* mirror(Node *r) {
    if (!r) return NULL;

    // 交换左右子树
    Node *t = r->left;
    r->left = r->right;
    r->right = t;

    // 递归处理子树
    mirror(r->left);
    mirror(r->right);

    return r;
}
````
