## 一、核心数据结构

表达式树的内部结点存运算符，叶子结点存操作数；用一个 `type` 字段把「数字 / 运算符 / 变量」三类结点统一到同一个结构体里，避免为三种结点各写一套遍历函数。

```c
typedef struct ExprNode {
    char type;           // 'n':数字 'o':运算符 'v':变量
    double val;          // type=='n' 时的数值
    char op;             // type=='o' 时的运算符 (+ - * /)
    char varName[16];    // type=='v' 时的变量名
    struct ExprNode *left, *right;
} ExprNode;

typedef ExprNode* ExprTree;

static ExprNode* createNode(char type) {
    ExprNode *n = (ExprNode*)malloc(sizeof(ExprNode));
    n->type = type;
    n->op = 0;
    n->val = 0.0;
    n->varName[0] = '\0';
    n->left = n->right = NULL;
    return n;
}
```

三类结点共用一个结构体的代价是多存几个字段，换来的是**所有遍历 / 求值 / 替换算法只写一份**，这是整份代码能压到几百行的关键。

## 二、关键步骤 1：用栈由后缀式建树

后缀式的性质是「运算符总在其两个操作数之后出现」，所以顺序扫描 token：操作数造结点入栈，运算符弹出**两个**结点作右、左孩子再入栈。

```c
ExprTree buildFromPostfix(const char *postfix) {
    ExprNode *stack[256];
    int top = 0;
    const char *p = postfix;
    char buf[64];

    while (*p) {
        if (isspace(*p)) { p++; continue; }

        if (isalpha(*p)) {                       // 变量：字母开头
            int k = 0;
            while (isalnum(*p)) buf[k++] = *p++; // 连续字母数字视为同一变量名
            buf[k] = '\0';
            ExprNode *n = createNode('v');
            strcpy(n->varName, buf);
            stack[top++] = n;
        } else if (isdigit(*p) || *p == '.') {   // 数字（含小数）
            int k = 0;
            while (isdigit(*p) || *p == '.') buf[k++] = *p++;
            buf[k] = '\0';
            ExprNode *n = createNode('n');
            n->val = atof(buf);
            stack[top++] = n;
        } else if (*p == '+' || *p == '-' || *p == '*' || *p == '/') {
            ExprNode *n = createNode('o');
            n->op = *p;
            n->right = stack[--top];   // 先弹出的是右操作数
            n->left  = stack[--top];   // 后弹出的是左操作数
            stack[top++] = n;
            p++;
        } else { p++; }
    }
    return stack[0];                   // 栈中唯一剩下的结点即根
}
```

**建树过程**（输入 `3 4 + 5 *`）：

| Token | 动作                     | 栈内容      |
| :---- | :--------------------- | :------- |
| `3`   | 造数字结点入栈                | `[3]`    |
| `4`   | 造数字结点入栈                | `[3, 4]` |
| `+`   | 弹 4(右)、3(左)，造 `+` 入栈   | `[+]`    |
| `5`   | 造数字结点入栈                | `[+, 5]` |
| `*`   | 弹 5(右)、`+`(左)，造 `*` 入栈 | `[*]`    |

## 三、关键步骤 2：三种遍历输出三种表达式

同一个递归骨架换「访问根」的时机，就分别得到中缀、前缀、后缀三种形式。

```c
// 中缀：左 → 根 → 右
void printInfix(ExprTree t) {
    if (!t) return;
    if (t->type == 'n')      printf("%d", (int)t->val);
    else if (t->type == 'v') printf("%s", t->varName);
    else {
        int needParen = (t->op == '+' || t->op == '-');   // 优先级低的运算符才需要括号
        if (needParen && t->left && t->left->type == 'o'
            && (t->left->op == '+' || t->left->op == '-'))
            { printf("("); printInfix(t->left); printf(")"); }
        else printInfix(t->left);

        printf(" %c ", t->op);

        if (needParen && t->right && t->right->type == 'o'
            && (t->right->op == '+' || t->right->op == '-'))
            { printf("("); printInfix(t->right); printf(")"); }
        else printInfix(t->right);
    }
}

// 前缀：根 → 左 → 右
void printPrefix(ExprTree t) {
    if (!t) return;
    if (t->type == 'n')      printf("%d", (int)t->val);
    else if (t->type == 'v') printf("%s", t->varName);
    else { printf("%c ", t->op); printPrefix(t->left); printf(" "); printPrefix(t->right); }
}

// 后缀：左 → 右 → 根
void printPostfix(ExprTree t) {
    if (!t) return;
    printPostfix(t->left);  printf(" ");
    printPostfix(t->right); printf(" ");
    if (t->type == 'n')      printf("%d", (int)t->val);
    else if (t->type == 'v') printf("%s", t->varName);
    else printf("%c", t->op);
}
```

## 四、关键步骤 3：后序遍历求值

求值必须「先算子后算父」，正是后序遍历：左右子树各递归出一个 `double`，再按当前结点的运算符合并。

```c
double evaluate(ExprTree t, const char *vars[], double vals[], int vn) {
    if (!t) return 0.0;
    if (t->type == 'n') return t->val;
    if (t->type == 'v') {                       // 变量在变量表中查值
        for (int i = 0; i < vn; i++)
            if (strcmp(t->varName, vars[i]) == 0) return vals[i];
        return 0.0;
    }
    double l = evaluate(t->left,  vars, vals, vn);
    double r = evaluate(t->right, vars, vals, vn);
    switch (t->op) {
        case '+': return l + r;
        case '-': return l - r;
        case '*': return l * r;
        case '/': return (r != 0.0) ? l / r : 0.0;   // 除零保护
        default:  return 0.0;
    }
}
```

## 五、关键步骤 4：树形结构可视化

树的层级关系在控制台里靠缩进表达，深度每降一层多两个空格。先打根，再递归两个孩子——即前序遍历。

```c
void printTree(ExprTree t, int depth) {
    if (!t) return;
    for (int i = 0; i < depth; i++) printf("  ");
    if (t->type == 'n')      printf("%d\n", (int)t->val);
    else if (t->type == 'v') printf("%s\n", t->varName);
    else {
        printf("%c\n", t->op);
        printTree(t->left,  depth + 1);
        printTree(t->right, depth + 1);
    }
}
```

## 六、关键步骤 5：变量替换

替换不原地改，而是**递归复制出一棵新树**，遇到目标变量结点时换成数字结点。这样原树仍可用于其他变量的替换，也避免复制过程中丢失指针。

```c
ExprTree substitute(ExprTree t, const char *var, double val) {
    if (!t) return NULL;
    if (t->type == 'v' && strcmp(t->varName, var) == 0) {
        ExprNode *n = createNode('n');   // 命中：变量 → 数字常量
        n->val = val;
        return n;
    }
    ExprNode *n = createNode(t->type);   // 未命中：原样复制本结点
    if (t->type == 'n')      n->val = t->val;
    else if (t->type == 'v') strcpy(n->varName, t->varName);
    else {
        n->op    = t->op;
        n->left  = substitute(t->left,  var, val);
        n->right = substitute(t->right, var, val);
    }
    return n;
}
```

## 七、关键步骤 6：程序退出与内存释放

链式二叉树必须逐个 `free`，用后序遍历：左右子树都释放完，才能释放当前结点（先释放父结点就会丢失子树指针）。

```c
void destroyTree(ExprTree t) {
    if (!t) return;
    destroyTree(t->left);
    destroyTree(t->right);
    free(t);
}
```

## 八、问题与分析

| 现象                                 | 原因                                                                        | 改进方向                                                            |
| :--------------------------------- | :------------------------------------------------------------------------ | :-------------------------------------------------------------- |
| 中缀输出 `3 + 4 * 5`（应为 `(3 + 4) * 5`） | `printInfix` 只在**父结点是 `+`/`-`** 时才给子结点加括号，漏掉了「父为 `*`/`/`、子为 `+`/`-`」这一半情况 | 括号条件改为：父运算符优先级 **高于** 子结点即加括号；右子树因不满足结合律还需在「父为 `-`/`/`、子为同级」时也加 |
| 后缀输出 `3 4+ 5*` 空格不齐                | 数字后统一带空格、运算符后不带，拼接处出现 `4+`                                                | 每个 token 后统一补空格，或统一在 `printf` 里输出 `"%d "` 与 `"%c "`             |
| 变量未赋值时静默按 0 计算                     | `evaluate` 查不到变量名直接 `return 0.0`                                          | 返回标志位或打印提示，避免错误结果被当成正确值                                         |
| 除数为 0 返回 0                         | `case '/': return (r != 0.0) ? l / r : 0.0;`                              | 打印「除数为零」，或返回 `NAN`                                              |
| 建树前若干功能按钮可用                        | 主控只用 `root != NULL` 做了空判断                                                 | 空表达式时提示「请先输入后缀表达式」                                              |

其中**括号问题**是本次实验最值得记的一条：语法树的信息是完整的，但把它线性化成中缀串时，运算符优先级这一约束必须由输出函数自己补回去，树本身不会替你保存括号。

## 九、总结

1. **后缀式与表达式树是一一对应的**。后缀式相当于表达式树的「后序展开」，所以建树算法就是对后缀式做一次自底向上的归约，栈是天然的归约工作区：操作数压栈、运算符归约，复杂度 $O(n)$，无需任何优先级判断，也不需要括号——这正是逆波兰式适合机器处理的原因。
2. **三种遍历和一式三形是同一个东西**。中序→中缀、前序→前缀、后序→后缀，一套递归换访问时机即可；求值用的也是后序，只是把「打印」换成了「返回 `double`」。这让我对「遍历顺序不是记法，而是算法结构」有了实感。
3. **弹栈顺序、释放顺序、复制顺序三处都必须「先左后右」**。建树时先弹出的是右操作数、销毁时要先子树后父结点、替换时要在复制中保留左右指针——这三处一旦写反，程序不一定崩，但结果是错的，比崩溃更难查。用「树结构」可视化打印来验证建树结果，是一个非常划算的调试手段。
4. **踩到的坑主要在线性化环节**。中缀输出缺括号这件事提醒我：数据结构正确 $\neq$ 输出正确。凡是「结构 → 线性表示」的转换（中缀输出、序列化、生成代码），都要单独设计并测试，尤其是括号、结合性和精度这类隐性约束。
5. **可继续扩展的方向**：支持 `^`、`%`（`pow`/`fmod`，编译需 `-lm`）；代数化简（`x*0→0`、`x*1→x`、`x+0→x`）；以及用调度场算法（Shunting-yard）补上「中缀 → 后缀」这一环，让程序可以直接读入人类书写的表达式，形成完整的中缀 ⇄ 树 ⇄ 后缀 ⇄ 求值闭环。
