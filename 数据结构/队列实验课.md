- **二、实验介绍**

---

在办公室或打印店中，多台打印机需要处理大量的打印任务。用户提交打印任务后，系统需要将任务分配到合适的打印机，按提交顺序处理，并统计每台打印机的工作负载。当某些打印机队列过长时，需要进行负载均衡。

本实验用 C 语言实现基于链式队列的打印任务调度系统，通过控制台菜单交互，支持添加打印机、提交打印任务、处理任务、查看状态统计、负载均衡和查看任务队列等功能。

|功能模块|子功能|详细说明|
|---|---|---|
|添加打印机|创建打印机|添加新打印机，每个打印机有独立的任务队列|
|提交任务|创建并分配任务|输入名称/页数/优先级，分配到队列最短的打印机|
|处理任务|处理所有等待任务|按 FIFO 处理每台打印机的所有任务|
|状态统计|查看各打印机统计|显示任务数、已处理页数、忙时间等|
|负载均衡|重新分配任务|将超出平均数的任务移到其他打印机|
|查看队列|显示各队列长度|显示每台打印机当前等待的任务数|

链式队列使用链表实现，有 front（队首）和 rear（队尾）两个指针。入队在 rear 后插入新节点，出队从 front 取出节点。

提交任务时，系统遍历所有打印机，选择当前队列长度最短的打印机分配任务，实现简单的负载均衡。

每个任务的处理时间 = 页数 * 0.1 秒。等待时间 = 当前时间 - 提交时间。

```c
void submitJob(Printer printers[], int pn, Job j) {
    // 选择队列最短的打印机
    int best = 0;
    for (int i = 1; i < pn; i++)
        if (printers[i].queue->count < printers[best].queue->count)
            best = i;
    enqueue(printers[best].queue, j);
}

void enqueue(Queue *q, Job j) {
    QNode *node = (QNode*)malloc(sizeof(QNode));
    node->job = j;
    node->next = NULL;
    if (q->rear == NULL) {          // 空队列
        q->front = q->rear = node;
    } else {
        q->rear->next = node;       // 接到队尾
        q->rear = node;              // 更新队尾指针
    }
    q->count++;
}
```

```c
void processJobs(Printer printers[], int pn) {
    for (int i = 0; i < pn; i++) {
        Printer *p = &printers[i];
        if (isQueueEmpty(p->queue)) {
            printf("打印机 #%d 空闲\n", p->id);
            continue;
        }
        while (!isQueueEmpty(p->queue)) {
            Job j = dequeue(p->queue);            // FIFO出队
            double process = j.pages * 0.1;       // 模拟处理时间
            p->totalPages += j.pages;
            p->jobCount++;
            p->busyTime += process;
        }
    }
}

Job dequeue(Queue *q) {
    QNode *tmp = q->front;
    Job j = tmp->job;              // 取队首任务
    q->front = q->front->next;     // 队首后移
    if (q->front == NULL)          // 队列变空
        q->rear = NULL;
    free(tmp);                     // 释放节点
    q->count--;
    return j;
}
```

```c
Queue* createQueue() {
    Queue *q = (Queue*)malloc(sizeof(Queue));  // 分配队列结构体内存
    if (!q) return NULL;
    q->front = NULL;   // 队首初始化为空
    q->rear = NULL;    // 队尾初始化为空
    q->count = 0;      // 队列长度初始为 0
    return q;
}
```

|行|说明|
|:--|:--|
|①|malloc 分配 Queue 结构体|
|②|front=NULL 表示空队列|
|③|rear=NULL，空队列时 front 和 rear 均为 NULL|
|④|count 记录队列长度，便于查询|

```c
void enqueue(Queue *q, Job j) {
    // 1. 分配新节点内存
    QNode *node = (QNode*)malloc(sizeof(QNode));
    if (!node) return;
    
    // 2. 将任务数据复制到节点中（结构体赋值，深拷贝）
    node->job = j;
    node->next = NULL;  // 新节点将成为队尾，next 指向 NULL
    
    // 3. 处理空队列和普通队列两种情况
    if (q->rear == NULL) {          // 队列为空
        q->front = node;             // front 指向新节点
        q->rear = node;              // rear 也指向新节点
    } else {                         // 队列非空
        q->rear->next = node;        // 当前队尾的 next 指向新节点
        q->rear = node;              // rear 更新为新节点
    }
    q->count++;  // 队列长度加 1
}
```

|步骤|说明|
|:--|:--|
|①|malloc 分配 QNode，失败则返回|
|②|结构体赋值复制 Job 数据|
|③|空队列时 front 和 rear 都指向新节点|
|④|非空队列时接到队尾并更新 rear|
|⑤|count 自增记录长度|

```c
Job dequeue(Queue *q) {
    // 1. 空队列检查
    if (q->front == NULL) {
        Job empty = {0, "", 0, 0, 0.0};
        return empty;
    }
    
    // 2. 保存队首节点和任务数据
    QNode *tmp = q->front;    // 暂存队首节点
    Job j = tmp->job;          // 取出任务数据
    
    // 3. front 后移（删除队首）
    q->front = q->front->next;
    
    // 4. 如果队列变空，rear 也必须置 NULL
    if (q->front == NULL)
        q->rear = NULL;
    
    // 5. 释放原队首节点内存
    free(tmp);
    q->count--;  // 队列长度减 1
    
    return j;  // 返回任务数据
}
```

|步骤|说明|
|:--|:--|
|①|front==NULL 则队列为空，返回空 Job|
|②|暂存队首节点指针和任务数据|
|③|front 后移到下一节点|
|④|队列变空时 rear 也要置 NULL（保持一致性）|
|⑤|free 释放原队首节点|
|⑥|count 自减，返回任务数据|

```c
int isQueueEmpty(Queue *q) {
    return q->front == NULL;
}
```

|操作|前状态|后状态|
|:--|:--|:--|
|空队列入队 A|front=NULL, rear=NULL|front=A, rear=A, A.next=NULL|
|入队 B（非空）|front=A, rear=A|front=A, rear=B, A.next=B|
|出队 A|front=A, rear=B|front=B, rear=B|
|出队 B（变空）|front=B, rear=B|front=NULL, rear=NULL|

```c
void submitJob(Printer printers[], int pn, Job j) {
    // 遍历所有打印机，选择队列最短的
    int best = 0;
    for (int i = 1; i < pn; i++) {
        if (printers[i].queue->count < printers[best].queue->count)
            best = i;
    }
    // 将任务入队到选中的打印机
    enqueue(printers[best].queue, j);

}
```

|步骤|说明|
|:--|:--|
|①|假设第 0 台最短|
|②-③|遍历比较每台的 queue->count|
|④|count 最小的即为最佳选择|
|⑤|将任务入队到目标打印机|

```c
void processJobs(Printer printers[], int pn) {
    for (int i = 0; i < pn; i++) {
        Printer *p = &printers[i];
        if (isQueueEmpty(p->queue)) {
            printf("打印机 #%d 空闲\n", p->id);
            continue;
        }
        while (!isQueueEmpty(p->queue)) {
            Job j = dequeue(p->queue);          // FIFO 出队
            double process = j.pages * 0.1;      // 页数*0.1秒
            p->totalPages += j.pages;             // 累加页数
            p->jobCount++;                        // 累加任务数
            p->busyTime += process;               // 累加忙时间
            printf("  任务 #%d [%s] 页数=%d 处理=%.2fs\n",
                   j.id, j.name, j.pages, process);
        }
    }
}
```

|步骤|说明|
|:--|:--|
|①|遍历每台打印机|
|②|空队列则显示空闲|
|③|while 循环处理所有等待任务|
|④|dequeue FIFO 出队|
|⑤-⑥|process=页数*0.1 模拟处理时间|
|⑦-⑨|累加统计信息|

```c
void loadBalance(Printer printers[], int pn) {
    // 计算总任务数和平均值
    int total = 0;
    for (int i = 0; i < pn; i++)
        total += printers[i].queue->count;
    int avg = total / pn;
    
    // 将超出平均数的任务移到下一台打印机
    for (int i = 0; i < pn; i++) {
        while (printers[i].queue->count > avg) {
            Job j = dequeue(printers[i].queue);  // 从长队列取出
            int target = (i + 1) % pn;            // 下一台
            enqueue(printers[target].queue, j);   // 移到目标队列
            printf("  移动任务 #%d 从 #%d 到 #%d\n",
                   j.id, i + 1, target + 1);
        }
    }
}
```

| 步骤  | 说明                       |
| :-- | :----------------------- |
| ①   | 遍历计算所有队列的总任务数            |
| ②   | avg = total / pn 计算平均值   |
| ③-④ | 队列长度 > avg 时移出任务         |
| ⑤   | dequeue 从长队列取出           |
| ⑥   | target = (i+1)%pn 轮转到下一台 |
| ⑦   | enqueue 移到目标队列           |
