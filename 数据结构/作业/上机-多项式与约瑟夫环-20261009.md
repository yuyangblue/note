## 1. 多项式相加（50 分）

**问题描述**：用单链表表示一元多项式（每个结点存一项的系数 coef 和指数 expon，按指数升序），实现两个多项式的加法运算，结果合并同类项。

结点结构（课程给定）：

```c
typedef struct PolyNode *Polynomial;
struct PolyNode {
    int coef;       // 系数
    int expon;      // 指数
    Polynomial link; // 指向下一项
};
```

**要求**：读入两个多项式的非零项，输出相加后的多项式（按指数升序）。

**评判记录**：5 个测试用例，全部正确；平均 CPU 时间 0.0024s。

> 考点：链表的合并类操作（类似归并两个有序链表），按指数大小比较结点、同指数系数相加、系数为 0 则删项。

## 2. 约瑟夫环问题 v2（50 分）

**问题描述**：n 个人围成一圈，编号 1..n，从第 1 个人开始报数，数到 k 的人出列，下一个人重新从 1 开始报数，依次输出出列顺序，最后输出幸存者编号。

**要求**：输入 n、k（及起始位置，视具体约定），按顺序输出出列编号。

**评判记录**：8 个测试用例，全部正确；平均 CPU 时间 0.0023s。

> 考点：线性表的应用——顺序表模拟报数出列（O(nk)）或环形链表模拟；进阶可用数学递推 O(n) 求解幸存者编号。
