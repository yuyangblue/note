## 1. 二叉树的序列化与反序列化

**概念**：序列化是按某种遍历次序访问全部结点、依次输出结点数据，把非线性的树变成线性序列；反序列化是从这个线性序列重建原树。序列化的作用是让树能用线性表或字符串存储、传输。

完全二叉树的顺序存储本身就是一种序列化：因为结点位置隐含父子关系，按下标就能还原整棵树。但一般二叉树若照此办理，最坏会浪费到 $O(2^n)$ 的空间——链状的树按完全二叉树的下标排，中间大量空位。所以要另外设计带结构信息的序列。

**思路**：光靠先序序列无法确定树——先序只给出了根的位置，左子树含哪些结点、右子树含哪些都不知道。补法有两种：

- 遍历时把空子树也记下来，用特殊符号 `#` 表示。这样序列里每个「实结点」后面紧跟它的两棵子树（空或非空的标记），先序序列就能唯一确定一棵二叉树。
- 用层序遍历并按完全二叉树的方式补齐空位标记，得到层序序列，同样可还原。

**规则**：带 `#` 的先序序列化，遇到空子树写 `#`，否则写当前结点值，再递归序列化左、右子树。反序列化按下标顺序读：读到 `#` 返回空，否则建一个结点，递归读它的左子树、右子树。两处递归的次序必须与序列化一致。

```cpp
// 先序序列化：空子树记为 '#'
void PreOrderSerialize(BinTree T, vector<char>& out) {
    if (T == nullptr) { out.push_back('#'); return; }
    out.push_back(T->Data);
    PreOrderSerialize(T->Left, out);
    PreOrderSerialize(T->Right, out);
}

// 先序反序列化：按序列顺序消费
BinTree PreOrderDeSerialize(const vector<char>& seq, int& k) {
    if (seq[k] == '#') { ++k; return nullptr; }
    BinTree T = new TreeNode;
    T->Data = seq[k++];
    T->Left  = PreOrderDeSerialize(seq, k);
    T->Right = PreOrderDeSerialize(seq, k);
    return T;
}
```

层序方案的写法不同：用队列按层展开，空子树也入队，最后得到等长于「补齐后完全二叉树」的序列；反序列化时同样用队列，「按对」地为出队结点挂上左右孩子。层序序列与带 `#` 的先序序列都是树的一种编码，二者可互相转换。

序列化的完整代码与此题的实现见 `../ICPC/` 与 `../OI-Wiki/` 中的树哈希、树的同构相关内容；本节只保留与课件算法 5-11、5-12 对应的结构。

## 2. 多叉堆（D 叉堆）

**动机**：二叉堆每个结点只有两个孩子，树高是 $\log_2 n$。把分叉数提到 $d$，树高降到 $\log_d n$，插入的上滤路径变短；代价是下调时要在 $d$ 个孩子里找最小的，每层多比较 $d-1$ 次。课件把 $d$ 叉堆叫做 D 堆 / D 叉堆。

**规则**：$d$ 叉堆是一棵完全 $d$ 叉树，且每个结点不大于它的所有孩子（最小堆），下标从 0 起算：

$$
\text{父结点} = \left\lfloor \frac{i-1}{d} \right\rfloor
\qquad
\text{第 } k \text{ 个孩子} = d\,i + k \quad (k = 1,2,\ldots,d)
$$

代入 $d=2$ 就得到二叉堆在 0 起算下的公式。注意课件里二叉堆部分用的是 1 起算（父 $i/2$、孩子 $2i$、$2i+1$），而多叉堆部分换成了 0 起算——两套公式不要混用。

```cpp
// 算法 6-7：多叉堆上调（0 起算）
void SiftUpD(vector<int>& h, int d, int i) {
    int elem = h[i];
    while (i > 0 && elem < h[(i - 1) / d]) {
        h[i] = h[(i - 1) / d];
        i = (i - 1) / d;
    }
    h[i] = elem;
}

// 多叉堆下调（0 起算，孩子 di+1 .. di+d）
void SiftDownD(vector<int>& h, int d, int i) {
    int n = (int)h.size();
    int elem = h[i];
    int child = d * i + 1;                    // 第一个孩子，而不是 i
    while (child < n) {
        int smallest = child;
        int last = min(d * i + d, n - 1);     // 孩子下标上限，防越界
        for (int c = child + 1; c <= last; ++c)
            if (h[c] < h[smallest]) smallest = c;
        if (h[smallest] >= elem) break;       // 孩子都不比 elem 小，到位
        h[i] = h[smallest];
        i = smallest;
        child = d * i + 1;
    }
    h[i] = elem;
}
```

注意：课件算法 6-8 原文写的是 `child ← i`，再用 `if child = i` 判叶。这段伪代码有 bug——`child` 的初值该是第一个孩子 `di+1`，不是 `i` 自己。若按原文照抄，在某些输入下调不完整，堆序会被破坏（实测 $d=2\sim5$、$n\le200$ 的随机数据里大量失败）。这里按标准写法给出，并在 $d=2\sim5$、每组 200 组随机数组上验证过堆性质全部成立。判断"是否叶子"只要看 `child < n` 是否成立即可，不必用一个哨兵值绕弯。

## 3. 可并堆：左堆、斜堆、二项堆

**动机**：普通二叉堆合并两堆，只能把一堆的元素逐个插入另一堆，代价 $O(m\log(n+m))$；如果直接把两个数组拼起来再 Heapify，是 $O(n+m)$，但逐个插入通常更慢。可并堆把「合并」设计进结构本身，使 Merge 成为 $O(\log n)$ 的基本操作。

**规则**：三种可并堆的差别集中在维护代价的方式上——课件对照页给出的核心区别如下：

| 结构 | 核心结构 | Merge | 其他操作 |
|---|---|---|---|
| 左堆 | 维护 NPL、右路径短 | $O(\log n + \log m)$ | Insert / ExtractMin：$O(\log n)$ |
| 斜堆 | 不存 NPL、自调整交换 | 均摊 $O(\log n)$ | 各基本操作均摊 $O(\log n)$ |
| 二项堆 | 二项树森林、类似二进制进位 | $O(\log n)$ | ExtractMin $O(\log n)$；连续 Insert 均摊 $O(1)$ |

**左堆的 NPL**：NPL（null path length，空路径长度）定义为结点到最近空孩子的距离。课件采用 $NPL(null) = 0$、叶结点 $NPL = 1$ 的约定，并要求 $NPL(left) \ge NPL(right)$，于是右脊长度是 $O(\log n)$。左堆的所有操作都归约到 Merge：Insert 是与单结点堆合并，ExtractMin 是合并左右子树，Build 是单结点堆成对合并（可达 $O(n)$），PeekMin 直接读根。

```cpp
// 左堆结点：npl 为空路径长度
struct LNode {
    int key, npl;
    LNode *Left, *Right;
    LNode(int k) : key(k), npl(1), Left(nullptr), Right(nullptr) {}
};
using LHeap = LNode*;

int NPL(LHeap h) { return h ? h->npl : 0; }

// 合并两棵左堆，返回新根
LHeap Merge(LHeap a, LHeap b) {
    if (a == nullptr) return b;
    if (b == nullptr) return a;
    if (a->key > b->key) std::swap(a, b);   // 保证 a的根更小
    a->Right = Merge(a->Right, b);
    if (NPL(a->Left) < NPL(a->Right))
        std::swap(a->Left, a->Right);       // 维护左偏性质
    a->npl = NPL(a->Right) + 1;
    return a;
}

LHeap Insert(LHeap h, int x)   { return Merge(h, new LNode(x)); }
int  PeekMin(LHeap h)          { return h->key; }
LHeap ExtractMin(LHeap h)      { return Merge(h->Left, h->Right); }  // O(log n)
```

**思路**：Merge 每次沿两堆的右脊递归，右脊长度被 NPL 限制在 $O(\log n)$，所以合并是对数级。斜堆省掉 NPL 域，合并时无条件交换左右孩子，单次可能退化，但均摊仍是 $O(\log n)$。二项堆用一组阶互不相同的二项树表示，合并就是二进制加法：同阶相加产生进位，因此连续插入可以均摊到 $O(1)$。

任意一种可并堆的完整实现见 `../OI-Wiki/数据结构/左偏树.md`（左堆）；斜堆与二项堆在 OI-Wiki 中无对应篇目，按上面三行对照与标准实现推导即可。

## 4. 块状链表与快速排序（教学日历要求，笔记缺）

**块状链表**：链式串存储密度太低（一个字符配一个指针，64 位机约 1/9），块链让每个结点存一个字符数组、结点间用指针串接，密度提高到约 $B/(B+8)$。它同时保留链式结构插入删除不必整体搬移的优点，代价是随机访问退化为「先跳块、再块内偏移」，且要处理块的分裂与合并。完整讨论在 `04-字符串.md` §三 4，线性表章节若要覆盖「块状链表」这一重难点，直接引用该处即可，不必重写。

**快速排序**：教学日历第 10 章「交换排序」的核心，现有 `10-内排序(上).md` 讲了冒泡、插入、希尔、选择、堆、归并，但没有快速排序。它是基于划分的分治算法：选一个枢轴，把序列分成小于和大于枢轴的两段，再递归排两段；平均 $O(n\log n)$、最坏 $O(n^2)$，不稳定。实现与复杂度分析见 `../OI-Wiki/算法基础/快速排序.md` 或 `../ICPC/01-算法基础/02-排序.md`，按课程进度决定是否补进主笔记。
