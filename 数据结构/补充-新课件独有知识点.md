## 1. 二叉树的序列化与反序列化

**要点**：按遍历次序把树变成线性序列；先序序列必须把空子树记为 `#` 才能唯一还原，否则只有先序无法确定左右子树边界。层序方案按完全二叉树方式补齐空位标记。

**完整内容**（定义、动机、带 `#` 的先序序列化/反序列化 C++ 代码、层序方案、算法 5-11/5-12）：见 [[第5章-树和二叉树.md]] 的序列化一节。

## 2. 多叉堆（D 叉堆）

**要点**：完全 $d$ 叉树 + 堆序，0 起算下标——父 $=(i-1)/d$，孩子 $=di+k\ (k=1,\ldots,d)$。上调每层 1 次比较（比二叉堆浅），下调每层要在 $d$ 个孩子里找最小（多 $d-1$ 次比较）；$d=3$ 落在比较次数最优点附近。

**注意**：课件算法 6-8 的 `SiftDownD` 原文有 bug（`child ← i` 初始化 + `if child = i` 判叶会破坏堆序），正确写法是把 `child` 初值取第一个孩子 `di+1`。

**完整内容**（SiftUpD/SiftDownD 的正确 C++ 实现、D 堆取舍分析、算法 6-7/6-8）：见 [[第6章-优先级队列.md]] 的多叉堆一节。

## 3. 可并堆：左堆、斜堆、二项堆

**要点**：三者都把 Merge 做成基本操作（$O(\log n)$ 级），区别在维持代价的方式——

| 结构 | 核心 | Merge |
|---|---|---|
| 左堆 | 维护 NPL、右路径短 | $O(\log n+\log m)$ |
| 斜堆 | 不存 NPL、自调整交换 | 均摊 $O(\log n)$ |
| 二项堆 | 二项树森林、二进制进位 | $O(\log n)$，连续 Insert 均摊 $O(1)$ |

左堆采用课件/严蔚敏的 NPL 约定：$NPL(null)=0$、叶 $=1$，且 $NPL(left)\ge NPL(right)$；所有操作归约到 Merge。

**完整内容**（三种结构的对照、左堆 Merge/Insert/ExtractMin 的 C++ 实现、NPL 推导）：见 [[第6章-优先级队列.md]] 的可并堆一节。

## 4. 块状链表

**要点**：每个结点存一个字符数组、结点间指针串接，存储密度从链式串的约 $1/9$ 提到 $B/(B+8)$；保留插入删除不必整体搬移的优点，代价是随机访问退化为"先跳块、再块内偏移"，且要处理块的分裂与合并。

**完整内容**（动机、密度计算、与顺序串/链式串的三方对照表）：见 [[第2章-线性表.md]] 与 [[第4章-字符串.md]] 的块链小节。
