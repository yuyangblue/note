## 1. 引子：一元多项式的表示

**问题**：用程序设计语言表示一元多项式 $P(x)=a_0+a_1x+\dots+a_nx^n$，并支持加减乘运算。关键信息 = 每项的**系数 + 指数**。

三种表示方法：

| 方法 | 做法 | 优点 | 缺点 |
|------|------|------|------|
| ① 顺序存储·直接表示 | 数组分量存系数，**下标即指数** | 实现简单；相加 = 对应分量直接加 | $x+3x^{2000}$ 要开 2001 个分量，只有 2 项非零，空间巨浪费；加 0 浪费时间 |
| ② 顺序存储·只存非零项 | 结构数组 `{coef, expo}`，按指数有序 | 省空间；按序合并做加法 | 需事先确定数组大小 |
| ③ 链式存储·只存非零项 | 链表结点 `{coef, expo, link}` | 动态性强，不浪费 | 编程复杂、调试难 |

**多项式加法（②③通用思路）**：两表都按指数递降排列，从头比较当前项指数——指数大的直接拷贝输出，指数相等则系数相加（和为 0 丢弃）。

> **启示**：同一问题可有多种存储表示（数组/链表）；"管理一个有序线性序列"就是**线性表**问题的原型。

## 2. 线性表（List）

### 2.1 定义与 ADT

**定义**：由**同类元素**构成的**有序序列**的线性结构。

| 术语 | 含义 |
|------|------|
| 长度 | 表中元素个数 $n$ |
| 空表 | 没有元素的表 |
| 表头 / 表尾 | 起始位置元素 / 最后一个元素位置 |

**ADT 描述**：对象集 = $n$ 个元素 $\{a_1,a_2,\dots,a_n\}$ 的有序序列（元素类型 `ElementType`，位置用整数表示）；操作集 = MakeEmpty（建空表）、FindKth（按位序取元素）、Find（按值查首次出现位置）、Insert（第 $i$ 位前插入）、Delete（删第 $i$ 位元素）、Length（返回长度）。

### 2.2 顺序存储（数组）

结构：`struct LNode { ElementType Data[MAXSIZE]; int Last; }`，`Last` 指示最后一个元素下标。

| 操作 | 实现要点 | 复杂度 |
|------|---------|--------|
| MakeEmpty | `malloc` 结构，`Last=-1`（空表） | $O(1)$ |
| Find(X) | 从 0 循环到 Last 比较 | 平均 $(n+1)/2$ 次比较 |
| Insert(i, X) | **从 Last 往前挪**（不能从前），腾出下标 $i-1$，`Last++`；先判满（`Last==MAXSIZE-1`）与位置合法（$1\le i\le n+1$） | 平均移动 $n/2$ |
| Delete(i) | **从 i 往后往前挪**（覆盖），`Last--`；判位置合法（$1\le i\le n$） | 平均移动 $(n-1)/2$ |

> **常见坑**：插入必须**从后往前**挪（否则覆盖丢失）；删除必须**从前往后**挪（道理相同，方向相反）。

### 2.3 链式存储（链表）

**定义**：逻辑相邻的元素通过链相连，**不要求物理相邻**。结点 = 数据域 + 指针域。

| 操作 | 实现要点 | 复杂度 |
|------|---------|--------|
| Length | 从头遍历计数 | $O(n)$ |
| FindKth(K) | 从表头数到第 K 个；`p==NULL` 表示不存在 | $O(n)$ |
| Find(X) | 遍历比较 Data | $O(n)$ |
| Insert(i, X) | 先 `malloc` 新结点 s；**找到第 $i-1$ 个结点 p**；`s->Next = p->Next; p->Next = s;` | $O(n)$ |
| Delete(i) | 找第 $i-1$ 个结点 p；`s = p->Next; p->Next = s->Next; free(s);` | $O(n)$ |

**两个必考细节**：

1. **插入语句顺序不能换**：必须先 `s->Next = p->Next` 再 `p->Next = s`。颠倒的话 p->Next 先被改掉，新结点就丢了。
2. **`i==1`（头结点）特殊处理**：第 0 个结点不存在，须直接改表头：
   - 插入头：`s->Next = PtrL; PtrL = s;`（函数**返回新表头**，调用方 `PtrL = Insert(...)`）
   - 删除头：`PtrL = PtrL->Next; free(旧头);`（空表时返回 NULL）

### 2.4 广义表与多重链表（扩展）

**广义表** = 线性表的推广：元素既可以是单元素，也可以是另一个广义表。C 语言用 `union` + `Tag` 标记区分（`Tag=0` 单元素，`Tag=1` 指向子表指针）。例：二元多项式可看成"系数是 y 的一元多项式"的 x 链表。

**多重链表**：结点同时属于多个链表（有多个指针）。注意：双向链表的两个指针串的是**同一个**链表，不算多重链表。典型应用——**稀疏矩阵的十字链表**：

- 每个非零项结点：`{Row, Col, Value, Right, Down}`，`Right` 串同行，`Down` 串同列
- 行/列头结点（Head）与非零项结点（Term）结构不同但有共性（都有 Right/Down），用 `union` 统一
- 左上角入口结点存整个矩阵的**总行数、总列数、非零项个数**

> 为什么不用二维数组存稀疏矩阵：学生×课程矩阵（万人×千门课）几乎全是 0，必须只存非零项。

## 3. 堆栈（Stack）

### 3.1 什么是堆栈

**定义**：只在一端（**栈顶 Top**）做插入和删除的**受限线性表**。特点：**后入先出 LIFO**（Last In First Out）。

- 插入 = **Push（入栈）**；删除 = **Pop（出栈）**
- 日常生活中一叠碗就是堆栈

**ADT 操作**：CreateStack（建空栈）、IsFull（判满）、Push（入栈）、IsEmpty（判空）、Pop（出栈并返回栈顶元素）。入栈前判满，出栈前判空。

**例：ABC 依次入栈，出栈序列不能是 CAB**——要让 C 第一个出，A、B 必已在栈中且 A 在下 B 在上，A 不可能先于 B 出来。

### 3.2 顺序存储（数组）

结构：`{ ElementType Data[MaxSize]; int Top; }`，**`Top=-1` 表示空栈**，`Top==MaxSize-1` 表示满栈。

| 操作 | 一句话实现 |
|------|-----------|
| Push | 判满后 `Data[++S->Top] = item;`（先加再用） |
| Pop | 判空后 `return S->Data[S->Top--];`（先用再减） |

**一个数组实现两个堆栈**：分别从两端**往中间长**（top1 从 -1 向右 `++`，top2 从 MaxSize 向左 `--`）。判满条件是**两指针相遇**（`top2 - top1 == 1`），而不是 `top1+top2==n`（下标相加无意义）。用 `Tag` 区分操作哪个栈。

### 3.3 链式存储

- **Top 必须在链表头部**（链尾做删除找不到前驱）
- 加一个**头结点**（不存数据）：判空 = `S->Next == NULL`；Push/Pop 都在头结点之后操作，链表无满的问题
- Pop：`FirstCell = S->Next; S->Next = FirstCell->Next; e = FirstCell->Element; free(FirstCell); return e;`（**先保存再释放**，防内存泄漏）

### 3.4 堆栈应用：表达式求值

**后缀表达式求值（易）**：从左到右扫描，遇**运算数入栈**，遇**运算符**则弹出**最近两个**运算数运算、结果压回。结束时栈顶即答案。例：`6 2 / 3 - 4 2 * +` → 结果为 8。

**中缀转后缀（重点流程）**：

```
从头到尾读中缀表达式的每个对象：
  运算数  → 直接输出
  左括号  → 压栈
  右括号  → 弹出栈顶运算符并输出，直到碰到左括号（左括号丢弃不输出）
  运算符  → 与栈顶比较：
             优先级 > 栈顶   → 压栈
             优先级 ≤ 栈顶   → 弹出栈顶输出，继续比较，直到可压栈
结束时：弹出栈内剩余所有运算符
```

**关键点**：

- **左括号特殊性**：在栈外优先级最高（强制先算括号内），一旦入栈优先级降到最低（括号内运算符要压在它上面）
- 同级运算符**从左到右**结合：`a*b/c` 中遇到 `/` 时栈顶 `*` 要先弹出
- 运算数在转换中**相对顺序不变**（中缀 `2+9/3-5` → 后缀 `2 9 3 / + 5 -`）

**堆栈其他用途**：函数调用/递归的实现机制（保存变量状态+返回地址，倒序恢复）、回溯算法（老鼠走迷宫）、图的深度优先搜索（DFS）。

## 4. 队列（Queue）

### 4.1 定义

**定义**：插入在一端（**队尾 rear**）、删除在另一端（**队头 front**）的受限线性表。特点：**先进先出 FIFO**（先来先服务）。

**ADT 操作**：CreateQueue、IsFull、AddQ（入队）、IsEmpty、DeleteQ（出队并返回队头元素）。

### 4.2 顺序存储（数组 + 循环队列）

结构：`{ ElementType Data[MaxSize]; int front, rear; }`，`front` 指向队头元素**前一个位置**，`rear` 指向队尾元素。

**普通数组的缺陷**：元素不断出队后，front 前移，rear 到数组尾就"假满"，前面还有空位却用不上 → 用**循环队列**（数组首尾相接，靠**取模**实现，`(rear+1) % MaxSize`）。

**核心矛盾**：$n$ 个位置的数组，队列元素个数有 $n+1$ 种状态（0~n 个），而 front/rear 的相对差距只有 $n$ 种 → 无法仅靠 front==rear 区分空和满。三种解法：

| 方案 | 做法 |
|------|------|
| ① 加 Size 变量 | 记录元素个数，入队 `Size++`，出队 `Size--`；`Size==0` 空，`Size==n` 满 |
| ② 加 Tag 标记 | 每次操作记 `Tag`（插入=1，删除=0）；front==rear 时看 Tag 判断 |
| ③ **少放一个元素**（常用） | 最多放 $n-1$ 个；满 = `(rear+1)%n == front` |

**入队/出队**：判满（`(rear+1)%n==front`）后 `rear=(rear+1)%n; Data[rear]=item;`；判空（`front==rear`）后 `front=(front+1)%n; return Data[front];`

### 4.3 链式存储

- **front 必须在链表头**（出队要改头），**rear 在链表尾**（入队直接挂尾）
- 队列结构 = 两个指针 `{front, rear}`；空队 = `front == NULL`
- 出队要点：先取头结点 `FrontCell`，改 `front = front->Next`；**若删后 front 变 NULL（原来只有一个元素），须同时把 rear 置 NULL**；再取元素、`free(FrontCell)`

## 5. 多项式的加法运算实现（链式）

不带头结点单向链表，每结点 `{coef, expo, link}`，指数递降排列。

**Add(P1, P2) 算法框架**：

```
用 front、rear 指向结果链表头尾；构造临时空表头（front=rear=临时结点）
while (P1 && P2):
    k = Compare(P1->expo, P2->expo)   # 返回 1 / -1 / 0
    k==1  → Attach(P1->coef, P1->expo, &rear); P1 = P1->link
    k==-1 → Attach(P2->coef, P2->expo, &rear); P2 = P2->link
    k==0  → sum = P1->coef + P2->coef
            if (sum != 0) Attach(sum, P1->expo, &rear)
            P1 = P1->link; P2 = P2->link
# 循环退出：P1 或 P2 为空，把剩下的全部接到结果后面
while (P1): Attach(...); P1 = P1->link
while (P2): Attach(...); P2 = P2->link
rear->link = NULL
# 释放临时表头结点，返回 front 之后的真表头
```

**Attach(c, e, &pRear)**：`pRear` 是**指针的指针**——C 语言按值传递，要修改调用方的 rear 指针必须传它的地址；申请新结点、赋值、挂到 `(*pRear)->link`，再更新 `*pRear = p`。

> **常见坑**：系数相加为 0 的项**不输出**但两指针都要后移；临时表头结点最后必须 free（防泄漏）。

## 6. 小白专场：一元多项式的乘法与加法

**题目理解**：输入两行多项式（每行：项数 + 系数指数对），输出两行——**乘积**多项式、**和**多项式（均按指数递降，系数指数成对输出）。

- 加法：逐项合并，**同类项合并**（如 $3x^4$ 与 $-7x^4$ → $-4x^4$）
- 乘法：每一项 × 另一多项式的每一项（系数相乘、**指数相加**），再合并同类项（$3x^4\cdot 3x=9x^5$ 与 $-7x^4\cdot 6x=-42x^5$ 合并）

**表示方法选择**：题目会先告诉项数 → 可以用**动态数组**（`malloc` 按项数申请，实现简单、调试容易）；但为训练链表，经典解法用**链表**（动态性强、不浪费空间，但指针操作复杂）。两种方法都要会。

## 7. 本节重点

- 线性表 = 同类元素的有序序列；ADT = 对象集（$n$ 个元素）+ 操作集（建/查/插/删/长）
- 顺序存储：`Last` 指针；插入从后往前挪、删除从前往后挪；平均移动 $n/2$ 与 $(n-1)/2$
- 链式存储：插入两语句**顺序不能反**；`i==1` 头结点要改表头（返回新表头）；删除要 `free`
- 堆栈 LIFO：`Top=-1` 空栈；链式 Top 在链头；后缀求值遇数入栈遇符弹二
- 中缀转后缀：运算数直出、左括号入栈降级、右括号弹到左括号、优先级≤栈顶则弹
- 循环队列：front 指前驱、rear 指队尾；判满 `(rear+1)%n==front`（留一格法）；front==rear 判空
- 多项式链表加法：Compare 分三种情况；系数和 0 不输出；Attach 用指针的指针；临时头结点释放
- **常见坑**：双向链表不是多重链表；循环队列满/空判别是本章第一大坑；`union`+`Tag` 区分广义表域类型
