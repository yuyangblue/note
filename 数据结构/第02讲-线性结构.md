# 第 02 讲 线性结构：线性表、堆栈与队列

> 本讲依据视频 011–024（2.1 线性表、2.2 堆栈、2.3 队列、2.4 多项式加法实现）与小白专场整理。
> 学习目标：掌握线性表、堆栈、队列三种线性结构的定义、存储实现（顺序/链式）与基本操作，理解循环队列空满判定的本质，能实现链表版多项式加法。

## 一、引子：一元多项式的表示

一元多项式的关键信息是**项数**以及每项的**系数与指数**。三种表示方法：

| 方法 | 思路 | 优点 | 缺点 |
|---|---|---|---|
| 顺序存储·直接表示 | 数组下标对应指数，值为系数 | 实现简单，加法对应分量直接相加 | 稀疏多项式浪费空间（如 $x+3x^{2000}$ 需 2001 个分量） |
| 顺序存储·只存非零项 | 结构数组存放（系数, 指数），按指数有序 | 节省空间，加法像归并过程 | 需事先确定数组大小 |
| 链表存储非零项 | 结点含系数、指数、指针 | 动态增长，无需预知项数 | 指针操作复杂、调试较难 |

多项式加法：从头比较两个多项式的当前项指数——指数大的先输出；指数相等则系数相加，和为 0 时该项丢弃。

## 二、线性表

### 1. 定义与基本操作

线性表是由同类型元素构成的有序序列；元素个数为表长，空表表长为 0；首元素为表头，末元素为表尾。ADT 常用操作：MakeEmpty（建空表）、FindKth（按位序取元素）、Find（按值查找位置）、Insert（在第 i 个位置前插入 X）、Delete（删除第 i 个元素）、Length（求表长）。

### 2. 顺序存储（数组实现）

结构：`Data[MAXSIZE]` + `Last`（最后一个元素的下标，空表时 Last = -1）。

- **MakeEmpty**：申请结构空间，Last = -1。
- **Find（按值查找）**：从下标 0 扫到 Last，成功平均比较 $(n+1)/2$ 次。
- **Insert（第 i 个位置前插入）**：先判满（Last == MAXSIZE-1）与位置合法（1 ≤ i ≤ n+1）；元素**从后往前**移动（j 从 Last 到 i-1），腾出位置后放入 X，Last++。平均移动 $n/2$ 次。
- **Delete（删除第 i 个元素）**：判位置合法（1 ≤ i ≤ n）；元素**从前往后**移动（下标 i 起逐个前移覆盖），Last--。平均移动 $(n-1)/2$ 次。

注意：插入必须从后往前移动，否则前面的移动会覆盖尚未移动的元素。

### 3. 链式存储（单向链表实现）

结点 = 数据域 + 指针域；逻辑上相邻的元素在物理上不必相邻。已知头指针时，求表长、按位序查找、按值查找都需要从头遍历，均为 $O(n)$。

- **插入**：先找第 i-1 个结点 p；新结点 s 的 Next 指向 p->Next，再令 p->Next = s（两条赋值**顺序不能颠倒**，否则会丢失原后继）。插入表头（i==1）需特殊处理，并返回新的头指针。
- **删除**：找第 i-1 个结点 p；用 s 指向被删结点，令 p->Next = s->Next，再 free(s) 释放空间，避免内存泄漏。删除表头同样特殊处理。
- 插入与删除的平均查找次数均为 $n/2$。

【进阶】链表的各种操作与技巧见 OI-Wiki：[数据结构/链表](../OI-Wiki/数据结构/链表.md)。

### 4. 广义表与多重链表

- **广义表**：线性表的推广，元素既可以是单元素，也可以是另一个广义表（如二元多项式按 x 整理后，系数位置存放关于 y 的多项式）。实现上用 `union` 把单元素与子表指针放在同一空间，再用 Tag 标记区分。
- **多重链表**：结点可同时属于多个链表（含多个指针域）。注意：双向链表不算多重链表——两个指针串的是同一条链。
- **十字链表存稀疏矩阵**：每个非零项结点含行坐标、列坐标、值，用 Right 串同行元素、Down 串同列元素，形成十字结构；Head 结点作行/列链表头；入口结点记录行数、列数、非零项数。对"学生选课"这类行列都很大、非零项很少的稀疏矩阵，比二维数组大幅节省空间。

## 三、堆栈（后入先出）

### 1. 定义

堆栈是**受约束的线性表**：只在一端（栈顶）做插入和删除。基本操作：CreateStack、IsFull、Push（入栈）、IsEmpty、Pop（出栈）。核心特性是**后入先出（LIFO）**。

应用：后缀表达式求值时，扫描一遍表达式，遇运算数压栈，遇运算符弹出最近的两个运算数计算后压回结果，结束时栈顶即答案，时间为线性。

### 2. 顺序存储实现

结构：`Data[MAXSIZE]` + `Top`（栈顶下标，空栈 Top = -1）。

- **Push**：判满（Top == MAXSIZE-1），执行 `Data[++Top] = item`（先加后存）。
- **Pop**：判空（Top == -1），执行 `return Data[Top--]`（先取后减）。

一个数组实现两个堆栈：两个栈**从两头向中间生长**——Top1 从 -1 向右，Top2 从 MAXSIZE 向左。判满条件是两栈顶相邻（Top2 - Top1 == 1），而不是 Top1 + Top2 == MAXSIZE（这是常见错误）。用 Tag 参数区分操作哪个栈；入栈分别用 ++ 与 --。

### 3. 链式存储实现

用单向链表实现堆栈时，**栈顶必须是链表头**：链表头做插入、删除都方便；若把链尾当栈顶，删除时找不到前驱。可增设头结点统一操作；判空条件为 `S->Next == NULL`；Push 在头部插入，Pop 删除头部结点并 free 释放。

【进阶】栈的完整内容（含单调栈）见 OI-Wiki：[数据结构/栈](../OI-Wiki/数据结构/栈.md)。

### 4. 表达式求值

- **后缀表达式求值**：见前文，线性时间。
- **中缀转后缀**：运算数直接输出；左括号压栈（进栈后优先级降到最低）；右括号弹出栈顶运算符直到左括号（左括号丢弃）；普通运算符与栈顶比较——优先级高于栈顶则压栈，否则弹出栈顶、继续比较，直到可压栈为止。整个过程线性时间。
- **其他典型应用**：函数调用与递归的现场保存、恢复（返回地址与局部状态按调用顺序压栈、按相反顺序恢复）；回溯算法（如走迷宫，试探失败后回到最近一次可试探状态）；图的深度优先搜索。

## 四、队列（先进先出）

### 1. 定义

队列是**受约束的线性表**：在队尾插入（入队 AddQ）、在队头删除（出队 DeleteQ），特性为**先进先出（FIFO）**。基本操作：CreateQueue、IsFull、AddQ、IsEmpty、DeleteQ。

### 2. 顺序存储：循环队列

结构：`Data[MAXSIZE]` + `front` + `rear`。约定 front 指向队头元素的前一个位置，rear 指向队尾元素；**front == rear 表示队空**。

用求余实现环形环绕：入队 `rear = (rear+1) % MAXSIZE`；出队 `front = (front+1) % MAXSIZE`。

**空满判定问题（本质）**：大小为 n 的数组，front 与 rear 的相对差距只有 n 种取值，而队列的装载状态有 n+1 种（0~n 个元素），因此只用 front/rear 无法区分"空"与"满"。两种解决方案：
1. 附加标记：用 Size 计数，或 Tag 记录最后一次操作是插入还是删除；
2. 牺牲一个位置：队列最多存放 n-1 个元素，判满条件为 `(rear+1) % MAXSIZE == front`。

### 3. 链式存储实现

front 指向链表头（做删除），rear 指向链表尾（做插入）——方向不能反过来，否则单向链表在链尾删除时找不到前驱。出队时若队列只剩一个元素（front == rear），删除后 front 与 rear 都要置空。

【进阶】队列的完整内容（含单调队列）见 OI-Wiki：[数据结构/队列](../OI-Wiki/数据结构/队列.md)。

## 五、多项式加法实现（链表版）

用不带头结点的单向链表表示多项式，结点含系数、指数、指针，按指数递降有序。

- 用 front、rear 分别记录结果链表的头与尾；先建一个临时头结点便于统一挂接，结束时释放。
- 循环比较 P1、P2 当前项指数（Compare 返回 1 / -1 / 0）：P1 指数大则复制 P1 项、P1 后移；P2 指数大则反之；指数相等则系数相加，结果非零才挂接（Attach），两者都后移。
- 循环退出后，把仍有剩余的多项式全部 Attach 到结果尾部。
- **Attach(c, e, pRear)**：申请结点并赋值，挂到 rear 之后并更新 rear。由于 C 语言按值传递，要修改调用方的 rear 指针，参数必须是指针的指针。

## 六、小白专场：一元多项式的乘法与加法运算

- **题意**：读入两个多项式（项数 + 系数指数对），按指数递降分别输出乘积与和。
- **和**：逐项相加并合并同类项（指数相同的项系数相加，和为 0 则省略）。
- **积**：每一项与另一多项式的每一项相乘（系数相乘、指数相加），再合并同类项。
- **表示选择**：数组实现简单、调试容易，但需事先确定大小；链表动态增长、不浪费空间，但指针操作复杂。本题输入明确告知项数，使用动态数组是更简单的选择；教学演示采用链表以训练链表编程能力。
