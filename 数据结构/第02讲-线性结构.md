## 0. 这一讲在讲啥（先看这段）

这一讲是全书地基，讲三种**最基础的数据结构**，全是"排成一排"的东西：

| 结构 | 生活类比 | 核心规则 |
|------|----------|----------|
| 线性表 | 一串珠子 | 排队排成一列，头尾明确 |
| 堆栈 | 一叠碗 | **后放上的先拿走**（后进先出） |
| 队列 | 食堂排队打饭 | **先来的先吃**（先进先出） |

还要学会一个引子问题（多项式表示），它串起整讲。

---

## 1. 引子：一个多项式怎么存

多项式 $4x^5-3x^2+1$ 怎么存进电脑？三种存法：

| 存法 | 做法 | 缺点 |
|------|------|------|
| 数组·直接存 | 下标当指数，`a[i]` 存 $x^i$ 的系数 | $x+3x^{2000}$ 要开 2001 个格子，几乎全空 |
| 数组·只存非零项 | 存 `(系数, 指数)` 对 | 要先知道有多少项 |
| **链表·只存非零项** | 每个结点存 `(系数, 指数, 指向下一个的指针)` | 代码麻烦，但省空间 |

> **启示**：同一个东西有好几种存法——这就是后面"数组 vs 链表"之争的由来。

## 2. 线性表：排成一排的元素

### 2.1 是啥

**同类元素排成有序的一列**：$a_1, a_2, \dots, a_n$。第一个叫表头，最后一个叫表尾，有几个元素叫长度。

能干的事（ADT 操作）：建空表、按位置取第 k 个、按值找位置、**在第 i 个位置前插入**、删第 i 个、求长度。

### 2.2 两种存法对比（重点）

| 操作 | 数组（一排连续格子） | 链表（手拉手的结点） |
|------|----------------------|----------------------|
| 找第 k 个 | 直接 `a[k-1]`，$O(1)$ | 从头数过去，$O(n)$ |
| 插入/删除 | 要把后面元素**整体挪动**，$O(n)$ | 只改两个指针，$O(1)$（但要先找到位置 $O(n)$） |
| 求长度 | 有个 `Last` 指针，$O(1)$ | 从头数到尾，$O(n)$ |
| 空间 | 开多大写死，可能浪费 | 来一个申请一个，不浪费 |

**一句话**：数组"查快改慢"，链表"改快查慢"，看场景选。

### 2.3 链表的两个必踩的坑（面试/考试常问）

1. **插入顺序不能反**：新结点 `s` 插到 `p` 后面，必须
   ```
   s->Next = p->Next   # 先让 s 指向 p 后面的老结点
   p->Next = s        # 再让 p 指向 s
   ```
   反过来写，`p` 后面的链表就丢了。
2. **改头结点要特判**：插到最前面/删最前面，直接动头指针，函数要**返回新头**。删结点必须 `free` 释放（不然内存泄漏）。

> 【进阶·可跳过】广义表（元素可以是"子表"）、稀疏矩阵的十字链表（一个结点同时属于行和列两个链表）→ 看 `OI-Wiki\数据结构\链表.md`，第一遍不用深究。

## 3. 堆栈：后进先出（一叠碗）

### 3.1 是啥

只在一端（**栈顶**）放碗、拿碗。**后放进去的先拿出来**（后进先出 LIFO）。

两个基本操作：**Push**（放碗）、**Pop**（拿碗）。入栈前看满没满，出栈前看空没空。

**验证是不是栈**：ABC 依次入栈，出栈顺序**不可能**是 CAB——C 要第一个出来，说明 A、B 早就在里面压着了，A 在底下，不可能先于 B 出来。

### 3.2 两种实现要点

| 实现 | 要点 |
|------|------|
| 数组 | `Top=-1` 表示空；入栈 `Data[++Top]=x`，出栈 `return Data[Top--]` |
| 链表 | **栈顶必须放链表头**（链尾删不掉）；加个不存数据的头结点，判空看 `head->Next==NULL` |

### 3.3 堆栈最大用途：表达式求值

**后缀表达式**（运算符在数后面）超好算：从左往右，**遇到数就压栈，遇到运算符就弹两个数算完压回**。

例：`6 2 / 3 - 4 2 * +` → 算出来是 `8`。

但我们平时写的是**中缀**（`5+6/2`）。怎么转后缀？**口诀版流程**：

| 读到的东西 | 怎么办 |
|------------|--------|
| 数字 | 直接输出 |
| 左括号 `(` | 压栈 |
| 右括号 `)` | 疯狂弹出栈顶并输出，直到弹出 `(`（`(` 扔掉） |
| 运算符 | 和栈顶比：优先级**高**就压栈；**≤** 栈顶就弹出栈顶，继续比 |
| 读完了 | 把栈里剩下的全部弹出 |

两个坑：

- **左括号在栈外最牛、进栈就最怂**：进栈后优先级降到最低（好让括号里的运算符压在上面）
- **同级从左到右**：`a*b/c` 读到 `/` 时，栈顶 `*` 要先出来

> 堆栈还用在：函数调用/递归的实现（保存现场再恢复）、走迷宫回溯、DFS。

## 4. 队列：先进先出（排队打饭）

### 4.1 是啥

一头进（队尾）、一头出（队头）。**先来的先走**（先进先出 FIFO）。入队 `AddQ`，出队 `DeleteQ`。

### 4.2 数组实现：循环队列（本章第一大坑）

普通数组排到尾巴就"假满"了（前面明明空着）→ 把数组**首尾接成环**，靠**取模** `(i+1) % n` 转圈。

问题：`front == rear` 时，到底是**空**还是**满**？分不清！

> 为什么分不清（人话版）：$n$ 个格子能装 $n+1$ 种状态（0 个、1 个……$n$ 个元素），但 front/rear 的位置组合只有 $n$ 种——信息不够，必然撞车。

三种解法，**最常用第三种**：

1. 加一个 `Size` 变量记录个数（最简单直观）
2. 加一个 `tag` 标记最后一次是插入还是删除
3. **留一个格子不用**：最多放 $n-1$ 个，判满用 `(rear+1) % n == front`

### 4.3 链表实现：就记住一句

**队头 `front` 必须放在链表头**（出队要动头），队尾 `rear` 放链表尾。删除头结点后如果队列空了，记得把 `rear` 也置空。

## 5. 多项式加法（链表版）：一个完整例子

两个指数递降排列的多项式链表相加，思路就是**"归并"**：

```
while 两个都还没走完:
    比当前两项的指数：
        P1 大 → 复制 P1 这项，P1 后移
        P2 大 → 复制 P2 这项，P2 后移
        一样大 → 系数相加；和≠0 才复制，然后两个都后移
把剩下的那串整个接上去
```

两个小坑：**系数相加得 0 的项不输出**（但指针照常后移）；结果链表的**临时头结点用完要 free**。

> 小白专场（PTA 02-线性结构2）就是这道题的完整版：还要做**乘法**（每项×每项，系数乘、指数加，再合并同类项）。

## 6. 本讲重点（背下来）

1. **线性表**：数组查快改慢，链表改快查慢；链表插入顺序不能反、头结点特判、删了要 free
2. **堆栈 LIFO**：`Top=-1` 空；后缀求值"遇数压栈遇符弹二"；中缀转后缀四句口诀
3. **队列 FIFO**：循环队列判满 `(rear+1)%n == front`（留一格）；front 在链头
4. **多项式相加**=归并：指数大的复制，相等合并（和为 0 丢弃）

> **常见坑**：双向链表不是多重链表；循环队列空满判别；`free` 忘写内存泄漏。
