## 1. 线性表（List）

### 1.1 ADT 定义

线性表是 $n$ 个同类型数据元素组成的**有限序列**（$n\ge0$，$n=0$ 为空表）。逻辑上元素排成一条线，除首尾外每个元素有唯一前驱和唯一后继。

| ADT 要素 | 内容 |
|---------|------|
| 数据对象集 | $a_1, a_2, \dots, a_n$，同类型、有次序 |
| 操作集 | 初始化、求长度、按序号取元素、按值查找、插入、删除 |
| 规则 | $1 \le i \le n$ 表示合法位置；插入在位置 i，删除第 i 个元素 |

> 白话：线性表就是"排好队的一列同类型元素"，支持在任意位置插人/删人/找人。

### 1.2 顺序存储（数组实现）——顺序表

用一段连续地址依次存放元素。

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| 按序号访问（随机访问） | $O(1)$ | 直接下标定位 `L[i-1]` |
| 按值查找 | $O(n)$ | 平均要扫一半 |
| 插入（位置 i） | $O(n)$ | 从后往前把元素往后搬 |
| 删除（位置 i） | $O(n)$ | 从前往后把元素往前挪 |

**插入代码**（把新元素放到第 i 个位置，1-based）：

```cpp
bool insert(ElementType a[], int &last, int i, ElementType x) {
  if (i < 1 || i > last + 2) return false;   // 位置非法
  if (last + 1 >= MAXSIZE) return false;     // 表满
  for (int j = last; j >= i - 1; --j)
    a[j + 1] = a[j];                         // 从尾部开始后移
  a[i - 1] = x;
  ++last;
  return true;
}
```

> 顺序表的本质特点：**存取快（O(1)）、插入删除慢（O(n)）**，适合"建好后主要读"的场景。

### 1.3 链式存储（单链表）

每个结点 = **数据域 + 指针域**，通过指针把结点"链"起来。

```cpp
struct Node {
  ElementType data;
  Node *next;
};
```

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| 按序号/按值查找 | $O(n)$ | 必须从头一个个走 |
| 在已知结点 p 后插入 | $O(1)$ | 只改两个指针 |
| 删除已知结点 p 的后继 | $O(1)$ | 只改一个指针 |
| 删除/插入"第 i 个" | $O(n)$ | 先找到位置 |

**插入三连**（关键：先连后断，顺序不能反）：

```cpp
// 在结点 p 之后插入新结点 node
node->next = p->next;   // ① 新结点先指向 p 的后继
p->next = node;         // ② 再让 p 指向新结点
```

**删除 p 的后继 q**：

```cpp
p->next = q->next;   // 跳过 q
delete q;
```

**头结点（哨兵）的作用**：在表头加一个不存数据的头结点，使"在表头插入/删除"和"在中间"逻辑统一，不用特判表空。竞赛手写链表常用**静态链表**（数组存 next 下标）代替指针。

### 1.4 循环链表与双向链表

| 类型 | 结构 | 特点 |
|------|------|------|
| 循环链表 | 尾结点的 next 指向头结点 | 从任意结点出发能遍历全表 |
| 双向链表 | 每个结点有 prev 和 next | 可前驱/后继双向移动，删除已知结点 $O(1)$ |

```cpp
struct DNode {
  ElementType data;
  DNode *prev, *next;
};
```

### 1.5 顺序表 vs 链表（必考对比）

| 维度 | 顺序表 | 链表 |
|------|--------|------|
| 随机访问 | $O(1)$ | $O(n)$ |
| 插入/删除 | $O(n)$（搬元素） | $O(1)$（已知位置） |
| 空间 | 连续、可能浪费/扩容难 | 不连续、按需分配、有指针开销 |
| 适用场景 | 读多写少、规模稳定 | 写多读少、长度不定 |

## 2. 堆栈（Stack）

### 2.1 定义与性质

栈是**后进先出（LIFO）**的线性表，只允许在**栈顶**插入（push）和删除（pop）。

> 类比：一摞盘子——后放的先拿走。
> **坑**：LIFO 指"当前容器内"后进先出；`push(1) pop(1) push(2) pop(2)` 从全局看 1 先进先出，这不影响栈是 LIFO 的判定。

### 2.2 实现

**顺序栈**（数组 + 栈顶指针）：

```cpp
int st[MAXSIZE];  // st[0] 存元素个数，同时是栈顶下标
// push
st[++st[0]] = x;
// top
int u = st[st[0]];
// pop
if (st[0]) --st[0];
```

**链栈**：用单链表实现，表头做栈顶，push/pop 都是 $O(1)$。

所有操作复杂度：**push / pop / top 均 $O(1)$**。

### 2.3 经典应用

| 应用 | 场景 |
|------|------|
| 函数调用 | 系统栈保存返回地址与局部变量（递归依赖它） |
| 表达式求值 | 中缀转后缀、后缀求值（数字压栈，遇运算符弹两个算完再压） |
| 括号匹配 | 左括号压栈，右括号弹出比对 |
| DFS | 深度优先搜索天然用栈 |
| 浏览器后退 | 页面历史就是个栈 |

### 2.4 STL 用法（竞赛必备）

```cpp
#include <stack>
std::stack<int> s;
s.push(x);  s.pop();  s.top();  s.empty();  s.size();
```

## 3. 队列（Queue）

### 3.1 定义与性质

队列是**先进先出（FIFO）**的线性表：队尾插入（入队），队首删除（出队）。

> 类比：排队买饭——先来先服务。

### 3.2 数组实现与循环队列

用数组 + 头尾标记：

```cpp
int q[MAXSIZE], front = 0, rear = 0;   // 约定：rear 指向队尾下一个空位
// 入队
q[rear] = x; rear = (rear + 1) % MAXSIZE;
// 出队
x = q[front]; front = (front + 1) % MAXSIZE;
```

**循环队列的核心坑——队空 vs 队满**：

| 方案 | 判空 | 判满 |
|------|------|------|
| 少用一个元素 | `front == rear` | `(rear+1) % MAX == front` |
| 加 size 计数器 | `size == 0` | `size == MAX` |

> 不处理"假溢出"（rear 到数组末尾但前面有空间）就不能复用空间，这是数组队列必须用循环的根本原因。

### 3.3 链队列与 STL

链队列 = 带头尾指针的单链表，入队/出队 $O(1)$，无容量限制。

```cpp
#include <queue>
std::queue<int> q;
q.push(x);  q.pop();  q.front();  q.back();  q.empty();  q.size();
```

**应用**：BFS（广度优先搜索）、操作系统进程调度、打印缓冲。

## 4. 应用实例：多项式加法运算

两个多项式相加：合并同类项（指数相同则系数相加）。

- **用数组（顺序表）**：下标 = 指数，值 = 系数。操作简单，但指数很大时（如 $x^{1000}$）空间浪费
- **用链表**：每项一个结点（系数 + 指数），两个链表归并式扫描——指数大的先输出，相等则系数相加。空间按项数分配，不浪费

```cpp
// 链表表示多项式的相加（伪代码骨架）
Node *add(Node *p, Node *q) {
  while (p && q) {
    if (p->exp > q->exp) { 输出 p; p = p->next; }
    else if (p->exp < q->exp) { 输出 q; q = q->next; }
    else { 系数相加，非零则输出; p = p->next; q = q->next; }
  }
  输出剩余部分;
}
```

> 这正是"同一种数据结构，选对存储方式"的典型案例：**多项式项数少、指数跨度大 → 用链表**。

## 5. 本节重点

- 线性表两种存储：顺序表"读快写慢"、链表"写快读慢"；插入链表**先连后断**
- 头结点消除表头特判；循环链表解决"到尾部回不来"
- **栈 LIFO、队列 FIFO**，操作均 $O(1)$；栈记"表达式求值/括号匹配/DFS"，队列记"BFS/循环队列"
- **循环队列必考题**：队空 `front==rear`，队满 `(rear+1)%MAX==front`
- 多项式用链表存"稀疏"场景最合适
- **常见坑**：链表插入顺序颠倒导致丢链、循环队列满/空判断混淆、静态链表忘记初始化 next
