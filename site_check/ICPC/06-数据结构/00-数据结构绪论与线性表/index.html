    1. 数据结构是什么¶

    大白话引入¶

    你用计算机解决一个问题，步骤是：从问题中抽象出数学模型 → 设计算法 → 写程序 → 调试运行。

    早期计算机主要做数值计算（解方程组、求偏微分方程），操作对象之间的关系就是数学方程，用数组就能表示。

    但现在计算机越来越多用于非数值计算：教务系统管学生信息、图书管理系统管书籍、导航找最短路径、人机对弈选下一步棋。这些问题里，操作对象不是纯数字，对象之间的关系也不是方程——而是"一个接一个"（学生表）、"一个分多个"（文件夹目录）、"多对多"（地图路网）。

    数据结构就是研究这些非数值计算问题中，操作对象是什么、对象之间有什么关系、以及怎么对它们做操作的一门学科。

    核心讲解¶

    数据结构包含三方面内容：

    方面 含义 例子
    逻辑结构 数据元素之间的逻辑关系（和存储无关） 学生表是一对一、文件夹是一对多、地图是多对多
    存储结构（物理结构） 数据元素及关系在计算机内存中的表示 用连续内存存（顺序表）还是用指针连（链表）
    数据的运算和实现 对数据元素可以施加的操作，以及在存储结构上的实现 增删查改、排序、查找

    逻辑结构是抽象，存储结构是实现。 两者综合起来建立了数据元素之间的结构关系。

    2. 基本概念：数据、数据元素、数据项、数据对象¶

    这四个概念是包含关系，从大到小：

    1
2
3
4
    数据（最大，所有符号的集合）
  └── 数据对象（性质相同的数据元素的集合，是数据的子集）
        └── 数据元素（组成数据的基本单位，作为整体操作）
              └── 数据项（构成数据元素的最小单位，不可分割）
    概念 定义 学生表例子
    数据 能输入计算机且被处理的各种符号的集合 所有学生信息 + 课程信息 + ...
    数据元素 组成数据的基本单位，通常作为整体操作（也称记录、节点、顶点） 一条学生记录（学号+姓名+性别+...）
    数据项 构成数据元素的不可分割的最小单位 学号、姓名、性别（单独一个字段）
    数据对象 性质相同的数据元素的集合，是数据的子集 所有学生记录的集合（不含课程信息）

    数据元素在不同场景有不同名字：在表里叫"记录"，在树里叫"节点"，在图里叫"顶点"——说的都是同一个东西。

    3. 逻辑结构：数据元素之间的关系¶

    两种划分方法¶

    方法一：分成两大类

    • 线性结构：数据元素之间是一对一的关系。有且仅有一个开始节点和一个终端节点，所有节点最多一个直接前驱和一个直接后继。
    • 非线性结构：一对多（树）或多对多（图）。

    方法二：分成四种基本逻辑结构

    结构 关系 典型例子
    集合 元素除了"同属一个集合"外没有其他关系 一个班级的学生（不排序时）
    线性结构 一对一 线性表、栈、队列、字符串、数组
    树形结构 一对多（层次关系） 文件目录、人机对弈的棋局树、组织架构
    图形结构 多对多（任意关系） 地图路网、社交网络、通信网络

    王卓老师的例子：教务系统的学生表是线性（一个接一个），磁盘文件夹是树（一个父目录多个子目录），导航地图是图（地点之间多对多的路）。

    4. 存储结构：数据在内存中怎么放¶

    逻辑结构只关心"元素之间什么关系"，存储结构关心"在内存里怎么存才能表达这个关系"。

    四种存储结构¶

    4.1 顺序存储结构¶

    用一片连续的存储单元，按数据元素的逻辑顺序依次存放。元素之间的逻辑关系由存储位置的先后来表示。

    1
2
3
4
    内存地址:  100   104   108   112   116
内容:      a1    a2    a3    a4    a5
           ↑                 ↑
        a1在a2前面        位置靠后=逻辑靠后
    • C语言中用数组实现
    • 优点：随机访问 O(1)，存储密度高（不存额外指针）
    • 缺点：插入删除需要移动大量元素 O(n)，预先分配大小可能浪费或不够

    4.2 链式存储结构¶

    用任意的存储单元（可以连续也可以不连续）存放数据元素。每个元素除了存自身数据，还存下一个元素的地址（指针），用指针把元素像链条一样连起来，表示逻辑关系。

    1
2
3
4
5
6
    节点结构: [数据 | 下一个节点的地址]

地址:  165         130         135         170
内容: [a1|→130] → [a2|→135] → [a3|→170] → [a4|→null]
       ↑                                    ↑
    头指针指向165                          最后一个指针为null
    • C语言中用指针 + 结构体实现
    • 优点：插入删除只需改指针 O(1)（找到位置后），不需要预先分配，动态增长
    • 缺点：不能随机访问（要从头遍历 O(n)），每个节点多存指针的空间开销

    4.3 索引存储结构¶

    存储数据本身的同时，额外建一张索引表（目录）。索引表中记录关键字和对应数据的存储地址，通过索引快速定位。

    • 例子：手机通讯录按拼音首字母分组，点"P"直接跳到姓潘的联系人
    • 优点：查找快
    • 缺点：索引表占用额外空间，插入删除时要维护索引

    4.4 散列存储结构（哈希存储）¶

    根据数据元素的关键字，通过一个散列函数（哈希函数）直接计算出存储位置。

    • 例子：根据学生学号直接算出在数组中的下标
    • 优点：查找极快 O(1)（理想情况）
    • 缺点：需要处理哈希冲突，只适合关键字查找，不支持范围查询
    • 详细内容在"查找"章节

    重点掌握顺序存储和链式存储，索引和散列了解即可。

    5. 抽象数据类型 ADT¶

    什么是抽象数据类型¶

    抽象数据类型（Abstract Data Type，ADT） = 从具体问题中抽象出来的数学模型 + 定义在这个模型上的一组操作。

    "抽象"的意思：只关心"是什么、能做什么"，不关心"在计算机内部怎么存储、怎么实现"。

    王卓老师的比喻：你看到各种圆（大小、颜色、实心空心不同），抽象出"圆"的本质——到定点距离相等的所有点的集合。然后定义圆的操作：构造圆、求面积、求周长。这就是一个ADT。

    • D：数据对象（Data）
    • S：数据对象上的关系集合（Structure）
    • P：对数据对象的基本操作集合（Operation）

    6. 线性表的定义和特点¶

    定义¶

    线性表是具有相同特性的数据元素的一个有限序列。

    三个关键词： 1. 序列：元素之间有先后顺序 2. 相同特性：所有元素性质相同（都是字母、都是学生记录、都是整数） 3. 有限：元素个数是有限的（n ≥ 0）

    术语¶

    用 (a₁, a₂, ..., aₙ) 表示一个线性表：

    术语 含义
    aᵢ 第 i 个数据元素，i 是它的序号（位序）
    首元 / 起始节点 a₁，第一个元素，没有直接前驱
    终端节点 aₙ，最后一个元素，没有直接后继
    直接前驱 aᵢ₋₁，aᵢ 前面紧挨着的那个元素
    直接后继 aᵢ₊₁，aᵢ 后面紧挨着的那个元素
    表长 n，线性表中元素的个数
    空表 n = 0 时，线性表中没有元素

    线性表的逻辑特征（非空表）¶

    1. 有且仅有一个开始节点 a₁，它没有直接前驱，仅有一个直接后继 a₂
    2. 有且仅有一个终端节点 aₙ，它没有直接后继，仅有一个直接前驱 aₙ₋₁
    3. 除首尾外的每个内部节点 aᵢ（2 ≤ i ≤ n-1），有且仅有一个直接前驱 aᵢ₋₁ 和一个直接后继 aᵢ₊₁

    一句话：一对一的线性关系，一个接一个排好队。

    例子¶

    • 26个英文字母 (A, B, C, ..., Z) 是一个线性表
    • 学生信息表 (学号1+姓名1, 学号2+姓名2, ...) 是一个线性表（每个元素是一条记录）
    • 某单位历年计算机数量 (6, 17, 28, 50, 92, 188) 是一个线性表
    • 12星座 (白羊座, 金牛座, ..., 双鱼座) 是一个线性表

    7. 线性表的顺序存储实现¶

    思维启发¶

    线性表是"一个接一个"的关系。怎么在内存里表达"接一个"？

    最直观的想法：让它们在内存里也一个接一个地放——a₁ 放在地址 100，a₂ 放在 104，a₃ 放在 108... 这样"aᵢ 的下一个是 aᵢ₊₁"就由"aᵢ₊₁ 存在 aᵢ 后面那个位置"自然表达了。

    这就是顺序表：用一段连续内存，按逻辑顺序依次存放元素。

    核心讲解¶

    顺序表用数组实现。设每个元素占 sizeof(ElemType) 字节，起始地址为 LOC(a₁)，则：

    \[LOC(a_i) = LOC(a_1) + (i-1) \times sizeof(ElemType)\]

    这就是随机访问的基础：知道下标 i，直接算地址，O(1) 时间访问。

    顺序表的基本操作：

    操作 时间复杂度 说明
    按位置访问 O(1) 直接算地址
    按值查找 O(n) 遍历比较
    插入 O(n) 插入位置后所有元素后移
    删除 O(n) 删除位置后所有元素前移
    求表长 O(1) 直接返回 length

    #include <bits/stdc++.h>
using namespace std;

// 顺序表的最大容量
const int MAXSIZE = 100;

// 顺序表结构体
template <typename ElemType>
struct SqList {
    ElemType data[MAXSIZE];  // 用数组存储元素，连续内存
    int length;               // 当前表长（元素个数）
};

// 初始化顺序表
template <typename ElemType>
void InitList(SqList<ElemType>& L) {
    L.length = 0;  // 空表，长度为0
}

// 判断是否为空
template <typename ElemType>
bool ListEmpty(const SqList<ElemType>& L) {
    return L.length == 0;
}

// 求表长
template <typename ElemType>
int ListLength(const SqList<ElemType>& L) {
    return L.length;
}

// 按位置取值：取第 i 个元素（i 从 1 开始）
template <typename ElemType>
bool GetElem(const SqList<ElemType>& L, int i, ElemType& e) {
    // 检查 i 是否合法：必须在 [1, length] 范围内
    if (i < 1 || i > L.length) return false;
    // 数组下标从0开始，第i个元素存在 data[i-1]
    e = L.data[i - 1];
    return true;
}

// 按值查找：找第一个值等于 e 的元素，返回位序（从1开始），找不到返回0
template <typename ElemType>
int LocateElem(const SqList<ElemType>& L, const ElemType& e) {
    for (int i = 0; i < L.length; i++) {
        if (L.data[i] == e) {
            return i + 1;  // 数组下标+1 = 位序
        }
    }
    return 0;  // 没找到
}

// 插入：在第 i 个位置插入元素 e（i 从 1 开始，i=length+1 表示末尾插入）
template <typename ElemType>
bool ListInsert(SqList<ElemType>& L, int i, const ElemType& e) {
    // 检查 i 是否合法：可以在 [1, length+1] 插入
    if (i < 1 || i > L.length + 1) return false;
    // 检查表是否已满
    if (L.length >= MAXSIZE) return false;
    // 从最后一个元素开始，把第 i 个及之后的元素全部后移一位
    // 注意：必须从后往前移，否则会覆盖还没移的元素
    for (int j = L.length; j >= i; j--) {
        L.data[j] = L.data[j - 1];
    }
    // 在空出来的第 i 个位置放入新元素
    L.data[i - 1] = e;
    // 表长加1
    L.length++;
    return true;
}

// 删除：删除第 i 个元素，并用 e 返回被删元素的值
template <typename ElemType>
bool ListDelete(SqList<ElemType>& L, int i, ElemType& e) {
    // 检查 i 是否合法
    if (i < 1 || i > L.length) return false;
    // 保存被删元素
    e = L.data[i - 1];
    // 从第 i+1 个元素开始，全部前移一位（覆盖被删的位置）
    // 注意：必须从前往前移
    for (int j = i; j < L.length; j++) {
        L.data[j - 1] = L.data[j];
    }
    // 表长减1
    L.length--;
    return true;
}

// 遍历输出
template <typename ElemType>
void PrintList(const SqList<ElemType>& L) {
    for (int i = 0; i < L.length; i++) {
        cout << L.data[i];
        if (i < L.length - 1) cout << " ";
    }
    cout << endl;
}

int main() {
    SqList<int> L;
    InitList(L);

    // 插入测试：在末尾插入 1,2,3,4,5
    for (int i = 1; i <= 5; i++) {
        ListInsert(L, i, i);
    }
    cout << "插入后: ";
    PrintList(L);  // 预期: 1 2 3 4 5

    // 在第3个位置插入 100
    ListInsert(L, 3, 100);
    cout << "在位置3插入100后: ";
    PrintList(L);  // 预期: 1 2 100 3 4 5

    // 删除第4个元素
    int deleted;
    ListDelete(L, 4, deleted);
    cout << "删除位置4(值=" << deleted << ")后: ";
    PrintList(L);  // 预期: 1 2 100 4 5

    // 按值查找
    int pos = LocateElem(L, 100);
    cout << "值100的位置: " << pos << endl;  // 预期: 3

    // 按位置取值
    int val;
    GetElem(L, 2, val);
    cout << "位置2的值: " << val << endl;  // 预期: 2

    cout << "表长: " << ListLength(L) << endl;  // 预期: 5

    return 0;
}

    复杂度分析： - 插入/删除：平均需要移动 n/2 个元素，O(n) - 按位置访问：O(1) - 空间：O(MAXSIZE)，预先分配固定大小

    插入时必须从后往前移：如果从前往后移，data[i] = data[i-1] 会把还没移动的 data[i] 覆盖掉，导致所有后面的元素都变成同一个值。删除时相反，必须从前往前移。

    8. 线性表的链式存储实现¶

    思维启发¶

    顺序表插入删除要移动大量元素，很麻烦。能不能不移动？

    换个思路：每个元素除了存自己的数据，再存一个"下一个元素在哪"的地址（指针）。这样元素在内存里可以随便放，不要求连续——插入时只需让前一个元素的指针指向新节点，新节点的指针指向原来的下一个节点，O(1) 就搞定了。

    这就是链表：用指针把节点像链条一样连起来。

    核心讲解¶

    链表的每个节点包含两部分： - 数据域：存元素本身的值 - 指针域：存下一个节点的地址

    1
2
    头指针 head → [data|next] → [data|next] → [data|next] → NULL
                节点1           节点2           节点3
    • 头指针：指向第一个节点的指针，是链表的入口
    • 头节点（可选）：在第一个元素节点之前额外加的一个节点，数据域不存有效数据，指针域指向第一个元素节点。加头节点的好处：插入/删除第一个元素时不需要特殊处理（统一操作）
    • 尾节点：最后一个节点，指针域为 NULL（表示后面没有了）

    链表的基本操作：

    操作 时间复杂度 说明
    按位置访问 O(n) 必须从头遍历
    按值查找 O(n) 遍历比较
    插入（已知位置） O(1) 只需改指针，但找位置要 O(n)
    删除（已知位置） O(1) 只需改指针，但找前驱要 O(n)
    求表长 O(n) 遍历计数

    #include <bits/stdc++.h>
using namespace std;

// 链表节点结构体
template <typename ElemType>
struct LNode {
    ElemType data;       // 数据域：存元素的值
    LNode* next;         // 指针域：指向下一个节点
};

// 用 LinkList 作为指向节点的指针类型（即头指针类型）
template <typename ElemType>
using LinkList = LNode<ElemType>*;

// 初始化：创建带头节点的空链表
template <typename ElemType>
void InitList(LinkList<ElemType>& L) {
    // 分配头节点空间
    L = new LNode<ElemType>();
    // 头节点的 next 为 NULL，表示空表
    L->next = nullptr;
}

// 判断是否为空
template <typename ElemType>
bool ListEmpty(const LinkList<ElemType>& L) {
    // 头节点的 next 为 NULL 就是空表
    return L->next == nullptr;
}

// 求表长：遍历计数
template <typename ElemType>
int ListLength(const LinkList<ElemType>& L) {
    int count = 0;
    LNode<ElemType>* p = L->next;  // 从第一个元素节点开始
    while (p != nullptr) {
        count++;
        p = p->next;
    }
    return count;
}

// 按位置取值：取第 i 个元素（i 从 1 开始）
template <typename ElemType>
bool GetElem(const LinkList<ElemType>& L, int i, ElemType& e) {
    LNode<ElemType>* p = L->next;  // p 指向第一个元素节点
    int j = 1;                       // j 是 p 所指节点的位序
    while (p != nullptr && j < i) {
        p = p->next;
        j++;
    }
    // 循环结束后，如果 p 为 NULL 说明 i 超出范围；如果 j == i 说明找到了
    if (p == nullptr || j > i) return false;
    e = p->data;
    return true;
}

// 按值查找：找第一个值等于 e 的节点，返回位序，找不到返回0
template <typename ElemType>
int LocateElem(const LinkList<ElemType>& L, const ElemType& e) {
    LNode<ElemType>* p = L->next;
    int j = 1;
    while (p != nullptr) {
        if (p->data == e) return j;
        p = p->next;
        j++;
    }
    return 0;
}

// 插入：在第 i 个位置插入元素 e
// 关键：必须找到第 i-1 个节点（前驱），然后在它后面插入
template <typename ElemType>
bool ListInsert(LinkList<ElemType>& L, int i, const ElemType& e) {
    LNode<ElemType>* p = L;  // 从头节点开始，p 最终指向第 i-1 个节点
    int j = 0;                // 头节点是第0个位置
    // 找到第 i-1 个节点
    while (p != nullptr && j < i - 1) {
        p = p->next;
        j++;
    }
    if (p == nullptr || j > i - 1) return false;  // i 不合法

    // 分配新节点
    LNode<ElemType>* s = new LNode<ElemType>();
    s->data = e;

    // 核心：先连后断！
    // 步骤1：新节点的 next 指向原来的第 i 个节点（p->next）
    s->next = p->next;
    // 步骤2：前驱节点 p 的 next 指向新节点
    p->next = s;
    // ⚠️ 顺序不能反！如果先 p->next = s，原来的第i个节点地址就丢了

    return true;
}

// 删除：删除第 i 个元素，用 e 返回被删元素的值
// 关键：找到第 i-1 个节点（前驱），让它的 next 跳过第 i 个节点
template <typename ElemType>
bool ListDelete(LinkList<ElemType>& L, int i, ElemType& e) {
    LNode<ElemType>* p = L;  // 从头节点开始
    int j = 0;
    // 找到第 i-1 个节点
    while (p->next != nullptr && j < i - 1) {
        p = p->next;
        j++;
    }
    if (p->next == nullptr || j > i - 1) return false;  // i 不合法

    // q 指向要删除的第 i 个节点
    LNode<ElemType>* q = p->next;
    e = q->data;  // 保存被删元素的值

    // 核心：让前驱的 next 跳过被删节点，直接指向被删节点的下一个
    p->next = q->next;

    // 释放被删节点的内存（防止内存泄漏）
    delete q;

    return true;
}

// 头插法：将元素插入到链表头部（第一个元素节点之前）
// 特点：插入顺序和最终链表顺序相反
template <typename ElemType>
void HeadInsert(LinkList<ElemType>& L, const ElemType& e) {
    LNode<ElemType>* s = new LNode<ElemType>();
    s->data = e;
    s->next = L->next;  // 新节点指向原来的第一个元素
    L->next = s;        // 头节点指向新节点
}

// 尾插法：将元素追加到链表末尾
// 需要维护一个尾指针，否则每次都要遍历到末尾
template <typename ElemType>
void TailInsert(LinkList<ElemType>& L, const ElemType& e) {
    // 找到尾节点
    LNode<ElemType>* p = L;
    while (p->next != nullptr) p = p->next;
    // 在尾节点后插入
    LNode<ElemType>* s = new LNode<ElemType>();
    s->data = e;
    s->next = nullptr;
    p->next = s;
}

// 遍历输出
template <typename ElemType>
void PrintList(const LinkList<ElemType>& L) {
    LNode<ElemType>* p = L->next;
    bool first = true;
    while (p != nullptr) {
        if (!first) cout << " ";
        cout << p->data;
        first = false;
        p = p->next;
    }
    cout << endl;
}

// 销毁链表：释放所有节点内存
template <typename ElemType>
void DestroyList(LinkList<ElemType>& L) {
    LNode<ElemType>* p = L;
    while (p != nullptr) {
        LNode<ElemType>* temp = p;
        p = p->next;
        delete temp;
    }
    L = nullptr;
}

int main() {
    LinkList<int> L;
    InitList(L);

    // 尾插法插入 1,2,3,4,5
    for (int i = 1; i <= 5; i++) {
        TailInsert(L, i);
    }
    cout << "尾插1-5后: ";
    PrintList(L);  // 预期: 1 2 3 4 5

    // 在第3个位置插入 100
    ListInsert(L, 3, 100);
    cout << "在位置3插入100后: ";
    PrintList(L);  // 预期: 1 2 100 3 4 5

    // 删除第4个元素
    int deleted;
    ListDelete(L, 4, deleted);
    cout << "删除位置4(值=" << deleted << ")后: ";
    PrintList(L);  // 预期: 1 2 100 4 5

    // 头插法插入 999
    HeadInsert(L, 999);
    cout << "头插999后: ";
    PrintList(L);  // 预期: 999 1 2 100 4 5

    // 按值查找
    cout << "值100的位置: " << LocateElem(L, 100) << endl;  // 预期: 4

    // 按位置取值
    int val;
    GetElem(L, 1, val);
    cout << "位置1的值: " << val << endl;  // 预期: 999

    cout << "表长: " << ListLength(L) << endl;  // 预期: 6

    DestroyList(L);
    return 0;
}

    复杂度分析： - 插入/删除：找到前驱需要 O(n)，改指针本身 O(1)，总体 O(n) - 按位置访问：O(n)（必须从头遍历） - 头插法：O(1)（不需要遍历） - 空间：O(n)，每个节点多一个指针的开销

    插入时"先连后断"是最经典的坑：必须先 s->next = p->next（新节点连上后面），再 p->next = s（前驱连上新节点）。如果顺序反了，p->next 被覆盖后原来的第i个节点地址就永远丢了。

    9. 顺序表 vs 链表：怎么选¶

    对比维度 顺序表 链表
    存储方式 连续内存 离散内存，用指针连接
    随机访问 O(1)，直接算地址 O(n)，必须从头遍历
    插入/删除 O(n)，要移动元素 O(1)改指针（但找位置O(n)）
    空间开销 无额外开销，但需预分配 每个节点多一个指针
    表长变化 固定大小，可能浪费或溢出 动态分配，随时增长
    存储密度 高（=1） 低（<1，有指针开销）
    缓存友好 好（连续内存，缓存命中高） 差（节点离散，缓存命中率低）

    选择建议： - 频繁查询、很少增删 → 顺序表（随机访问快） - 频繁增删、很少查询 → 链表（改指针快） - 表长不确定、变化大 → 链表（动态分配） - 对空间要求高、表长固定 → 顺序表（无指针开销）

    竞赛中：数组模拟链表（用数组下标当指针）比 new 动态分配更快、更可控，是常用技巧。

    本节重点： - 数据结构三要素：逻辑结构、存储结构、运算 - 四种逻辑结构：集合、线性、树、图 - 两种核心存储结构：顺序（连续内存）、链式（指针连接） - 线性表逻辑特征：一对一，首无前驱、尾无后继、中间各一个 - 顺序表插入从后往前移、删除从前往前移 - 链表插入"先连后断"，必须先找前驱 - 常见坑：链表插入时先改前驱指针导致后续节点地址丢失；顺序表插入时从前往后移导致覆盖；忘记 delete 被删节点导致内存泄漏
