    1. 大白话引入¶

    想象你管理一个仓库，货架上摆着 \(n\) 个箱子，每个箱子装了些零件。你经常要做两件事：

    1. 改：往某个箱子里加/减零件
    2. 查：问"从 1 号箱到 x 号箱一共多少零件？"

    零件数量随时在变，老板随时在问。这就是单点修改 + 前缀求和问题。

    朴素做法要么查询慢、要么修改慢，树状数组（Binary Indexed Tree，BIT）让两个操作都只要 \(O(\log n)\)——代价是你要接受一个有点魔性的东西：lowbit。

    2. 思维启发：从前缀和到树状数组¶

    如果我是做题人，我会怎么想？

    先试两个最朴素的想法：

    做法 修改 查询 问题
    直接数组 \(O(1)\) \(O(n)\) 逐箱数 查询太慢
    前缀和数组 \(O(n)\) 后面全要改 \(O(1)\) 修改太慢

    前缀和"查得快改得慢"，数组"改得快查得慢"。能不能两边都折中？

    关键观察：如果我把数组分块，块内维护"块和"，那么： - 查询 [1,x]：整块直接取块和，只散块逐个数 → 快多了 - 修改一个点：只要改它所在的块和 → 也快

    树状数组做的正是这件事，只不过它的分块方式不是均匀的，而是按二进制分，分得特别巧妙，让"查询拆块数"和"修改影响块数"都恰好是 \(O(\log n)\)。

    手算最小例子找规律。设 \(n=8\)，每个位置 \(i\) 管辖一个区间，树状数组的规则是：

    i 二进制 管辖长度 管辖区间
    1 0001 1 [1,1]
    2 0010 2 [1,2]
    3 0011 1 [3,3]
    4 0100 4 [1,4]
    5 0101 1 [5,5]
    6 0110 2 [5,6]
    7 0111 1 [7,7]
    8 1000 8 [1,8]

    发现规律：位置 \(i\) 管辖的区间长度 = 二进制里最低位 1 对应的值。比如 6 = 110，最低位 1 在"2"的位置 → 管辖长度 2。这就是 lowbit。

    查询 [1,7]：7 → c[7]([7,7]) → 6 → c[6]([5,6]) → 4 → c[4]([1,4])，三块拼成 [1,7]，块数 = 7 的二进制里 1 的个数 ≤ \(\log n\)。

    修改 a[3]：影响 3 → 4 → 8，即包含 3 的管辖区间 [3,3]、[1,4]、[1,8]，链长 ≤ \(\log n\)。

    先记住"是什么"：c[i] 存的是区间 \([i-\text{lowbit}(i)+1,\ i]\) 的和。"为什么"马上讲。

    3. lowbit：整个算法的魔数¶

    定义：lowbit(x) = \(x\) 二进制最低位的 1 及其后面的 0 组成的数。

    x 二进制 lowbit(x)
    6 110 2
    12 1100 4
    8 1000 8

    代码（就一行）：int lowbit(int x) { return x & (-x); }（补码性质：-x = ~x + 1，与运算正好留下最低位的 1）。完整程序见下一节。

    为什么管辖区间是 \([i-\text{lowbit}(i)+1,\ i]\)：把 \(i\) 写成 \(i = 2^k \cdot q\)（\(q\) 奇数），则 \(\text{lowbit}(i) = 2^k\)。二进制视角下，\(i\) 的"低 \(k\) 位全是 0"，从 \(i\) 往前数 \(2^k\) 个数，它们恰好都共享同一个"高位前缀"——把它们打包成一个块，查询时才能"一步跳过一整段"。

    类比：lowbit 就像切蛋糕的刀，永远切出一块"2 的幂大小"的蛋糕。8 号位置（1000）一刀切走整块 [1,8]；7 号位置（111）只能切出 [7,7]，剩下 [1,6] 交给 6 再切……最终保证任何前缀都能切成 \(O(\log n)\) 块。

    为什么 i + lowbit(i) 是 i 的父亲（管辖区间包含关系）：i + lowbit(i) 把 i 的最低位 1 向左进一位，管辖区间至少扩大 2 倍。设 lowbit(i) = 2^k（i 的最低位 1 在第 k 位），i + lowbit(i) 把第 k 位的 1 进位到第 k+1 位，结果的低 k+1 位全是 0，所以 lowbit(i + lowbit(i)) ≥ 2^{k+1} = 2 \cdot lowbit(i)，管辖区间长度至少翻倍，且右端点更大 → 必然包含 i 的管辖区间。

    i lowbit(i) i + lowbit(i) i 的管辖区间 i+lowbit 的管辖区间 包含？
    2 (010) 2 4 (100) [1, 2] [1, 4] ✓
    3 (011) 1 4 (100) [3, 3] [1, 4] ✓
    6 (110) 2 8 (1000) [5, 6] [1, 8] ✓

    父亲链示例（n=8）： 

    1
2
3
4
    1 → 2 → 4 → 8
3 → 4 → 8
5 → 6 → 8
7 → 8

    每次 +lowbit 都跳到包含当前区间的更大区间，最终汇聚到根（最大的 2 的幂）。

    4. 前缀查询与单点修改（P3374 模板）¶

    有了管辖区间规则，两个操作水到渠成：

    前缀查询 sum(x)：求 \(a_1 + \dots + a_x\)。从 \(x\) 开始，每次加上 c[x]，然后 x -= lowbit(x) 跳到左边相邻块的末尾。

    单点修改 add(pos, v)：\(a_{pos} += v\)。从 pos 开始，每次 c[x] += v，然后 x += lowbit(x) 跳到父亲节点（包含它的下一个更大区间）。

    手算验证：\(a = [1,5,4,2,3]\)（\(n=5\)）

    1
2
3
4
5
    c[1] = a[1] = 1
c[2] = a[1]+a[2] = 6
c[3] = a[3] = 4
c[4] = a[1]+a[2]+a[3]+a[4] = 12
c[5] = a[5] = 3

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 500005;
int n, m;
long long c[MAXN];  // 树状数组本体：c[i] 管辖 [i-lowbit(i)+1, i] 的区间和

int lowbit(int x) {
    return x & (-x);  // 最低位 1 及其后面的 0
}

// 单点修改：a[pos] += v
// 为什么 x += lowbit(x)：包含 a[pos] 的所有管辖区间是一条"父亲链"，
// pos 的父亲是 pos + lowbit(pos)，一路跳到 n 为止
void add(int pos, long long v) {
    while (pos <= n) {
        c[pos] += v;
        pos += lowbit(pos);
    }
}

// 前缀查询：求 a[1] + ... + a[x]
// 为什么 x -= lowbit(x)：c[x] 只覆盖 [x-lowbit(x)+1, x]，
// 查 [1,x] 就得往前跳，每次跳掉一整块，块数 = 二进制中 1 的个数
long long sum(int x) {
    long long res = 0;
    while (x > 0) {
        res += c[x];
        x -= lowbit(x);
    }
    return res;
}

// 区间查询 [l, r]：前缀和相减（和满足可减性，这是树状数组能做区间和的根基）
long long rangeSum(int l, int r) {
    return sum(r) - sum(l - 1);
}

int main() {
    scanf("%d%d", &n, &m);
    for (int i = 1; i <= n; i++) {
        int x;
        scanf("%d", &x);
        add(i, x);  // 用单点修改初始化，O(n log n)；大数据用第 5 节 O(n) 建树
    }
    while (m--) {
        int op, a, b;
        scanf("%d%d%d", &op, &a, &b);
        if (op == 1) add(a, b);                    // 操作1：a[a] += b
        else printf("%lld\n", rangeSum(a, b));     // 操作2：查询区间 [a,b] 的和
    }
    return 0;
}

    复杂度：单次 add / sum 循环次数 = 二进制中 1 的个数或父亲链长度 ≤ \(\log_2 n\)，\(n=10^5\) 时约 17 次，非常快。空间 \(O(n)\)。

    5. O(n) 建树¶

    第 4 节用 \(n\) 次 add 初始化是 \(O(n \log n)\)。其实可以 \(O(n)\) 建树，两种写法：

    方法一（利用前缀和）：c[i] = s[i] - s[i - lowbit(i)]，就是管辖区间的区间和。

    方法二（儿子上交给父亲）：从小到大扫，c[i] 收齐所有儿子的贡献后，把自己的区间和传给父亲 i + lowbit(i)。

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int n;
long long a[MAXN];

int lowbit(int x) { return x & (-x); }

int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) scanf("%lld", &a[i]);

    // 方法一：利用前缀和，c1[i] = 区间 [i-lowbit(i)+1, i] 的和
    static long long s[MAXN], c1[MAXN];
    for (int i = 1; i <= n; i++) {
        s[i] = s[i - 1] + a[i];
        c1[i] = s[i] - s[i - lowbit(i)];  // 管辖区间 [i-lowbit(i)+1, i] 的和
    }

    // 方法二：儿子贡献给父亲
    static long long c2[MAXN];  // 初始全 0
    for (int i = 1; i <= n; i++) {
        c2[i] += a[i];            // 把自己放进去（此时 c2[i] 已含所有儿子的贡献）
        int fa = i + lowbit(i);   // 父亲下标
        if (fa <= n) c2[fa] += c2[i];  // 把整棵子树的区间和上交给父亲
        // 为什么正确：i 从小到大处理，儿子下标 < i 都处理完了，
        // 所以走到 i 时 c2[i] 恰好等于管辖区间的和
    }

    for (int i = 1; i <= n; i++)
        printf("%lld%c", c1[i], i == n ? '\n' : ' ');
    printf("%s\n", memcmp(c1, c2, sizeof(c1)) == 0 ? "OK" : "DIFF");
    return 0;
}

    6. 模型二：区间加 + 单点查询（差分，P3368）¶

    第 4 节是"单点改 + 区间查"，现在反过来的需求：区间 \([l,r]\) 整体加 \(v\)，单点查询 \(a_i\)。

    思维启发：区间加一次影响一整段，朴素做法 \(O(n)\)。能不能把"区间加"变成"两次单点改"？

    差分！定义 \(d_i = a_i - a_{i-1}\)（\(d_1 = a_1\)），那么： - \(a_i = d_1 + d_2 + \dots + d_i\)（差分的前缀和还原原数组） - 区间 \([l,r]\) 整体加 \(v\)：\(d_l += v\)，\(d_{r+1} -= v\)（只动两个点！）

    于是：用树状数组维护差分数组 \(d\)，区间加 = 两次单点改，单点查询 = 前缀和。

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 500005;
int n, m;
long long c[MAXN];  // 树状数组维护的是差分数组 d：d[i] = a[i] - a[i-1]

int lowbit(int x) { return x & (-x); }

void add(int pos, long long v) {
    while (pos <= n) {
        c[pos] += v;
        pos += lowbit(pos);
    }
}

long long sum(int x) {
    long long res = 0;
    while (x > 0) {
        res += c[x];
        x -= lowbit(x);
    }
    return res;
}

// 区间加 [l, r] += v：差分数组上只改两个点
// 为什么：a[i] = Σ d[1..i]，区间 [l,r] 整体加 v 等价于
//   d[l] += v   （l 及以后的前缀和都 +v）
//   d[r+1] -= v （r+1 及以后抵消回去，不影响 [r+1, n]）
void rangeAdd(int l, int r, long long v) {
    add(l, v);
    add(r + 1, -v);  // r+1 可能等于 n+1：add 里 while(pos<=n) 自然停住，不会越界
}

int main() {
    scanf("%d%d", &n, &m);
    long long last = 0;
    for (int i = 1; i <= n; i++) {
        long long x;
        scanf("%lld", &x);
        add(i, x - last);  // 直接插入差分值 d[i] = a[i] - a[i-1]
        last = x;
    }
    while (m--) {
        int op;
        scanf("%d", &op);
        if (op == 1) {
            int l, r;
            long long k;
            scanf("%d%d%lld", &l, &r, &k);
            rangeAdd(l, r, k);
        } else {
            int x;
            scanf("%d", &x);
            printf("%lld\n", sum(x));  // a[x] = 差分数组前缀和
        }
    }
    return 0;
}

    为什么能"单点查询 = 前缀和"：差分数组的第 \(i\) 个前缀和 = \(a_i\)（这是差分的定义性质）。注意这里是"区间加 + 单点查"，跟第 4 节"单点改 + 区间查"是两个不同模型，别混。

    7. 应用一：逆序对（值域树状数组，P1908）¶

    题意：求逆序对数量：\(i < j\) 且 \(a_i > a_j\)。

    思维启发：逆序对 = "前面比我大的数"或"后面比我小的数"。逐对枚举是 \(O(n^2)\)。能不能边扫边记"每个值出现几次"，然后 \(O(\log n)\) 问"比我小的有多少个"？

    值域树状数组：把值当下标建树状数组，c[x] 表示"值 x 出现了几次"。

    从右往左扫： - 到 \(a_i\) 时，树里已经存了所有 \(j > i\) 的值 - sum(a_i - 1) = 右边比 \(a_i\) 小的个数 = 以 \(i\) 为左端的逆序对数 - 然后把 \(a_i\) 插入树里

    坑：\(a_i\) 最大 \(10^9\)，开不下 \(10^9\) 的数组 → 离散化，把值域压到 \(1..n\)。

using namespace std;

const int MAXN = 500005;
int n;
long long c[MAXN];

int lowbit(int x) { return x & (-x); }

void add(int pos, long long v) {
    while (pos <= n) { c[pos] += v; pos += lowbit(pos); }
}

long long sum(int x) {
    long long res = 0;
    while (x > 0) { res += c[x]; x -= lowbit(x); }
    return res;
}

int main() {
    scanf("%d", &n);
    vector<int> a(n), b(n);
    for (int i = 0; i < n; i++) {
        scanf("%d", &a[i]);
        b[i] = a[i];
    }
    // 离散化：把值域压到 1..n（原值域 1e9 开不下数组）
    sort(b.begin(), b.end());
    b.erase(unique(b.begin(), b.end()), b.end());
    for (int i = 0; i < n; i++)
        a[i] = lower_bound(b.begin(), b.end(), a[i]) - b.begin() + 1;

    // 从右往左扫：右边已插入所有 a[j] (j>i)，其中比 a[i] 小的就是逆序对
    long long ans = 0;
    for (int i = n - 1; i >= 0; i--) {
        ans += sum(a[i] - 1);  // 右边比 a[i] 小的个数
        add(a[i], 1);          // a[i] 进入"已扫过集合"
    }
    printf("%lld\n", ans);
    return 0;
}

    8. 应用二：最长上升子序列（前缀 max）¶

    题意：求 LIS 长度，\(n \le 10^5\)（\(O(n^2)\) 的朴素 DP 过不了）。

    从朴素 DP 出发：我们到底在问什么¶

    朴素递推式：

    \[dp_i = 1 + \max_{j < i,\ a_j < a_i} dp_j\]

    瓶颈在"找前面所有值小于 \(a_i\) 的 dp 最大值"——每处理一个元素都要扫一遍前面，\(O(n^2)\)。

    注意这个式子的本质：我们不需要知道具体是哪个下标 \(j\)，只需要"在所有已处理元素中，值小于 \(x\) 的 dp 最大值"。这意味着处理到第 \(i\) 个时，必须记住前面每个元素的 (值, dp)，否则每次都得重扫。核心矛盾是：要不断往历史里塞新信息，又要随时能问"值 \(< x\) 的最大 dp"。

    最朴素的存储：给每个值开一个格子¶

    一个非常自然的想法：把"值"当作横轴，开数组：

    \[f[v] = \text{当前已处理元素中，值恰好等于 } v \text{ 的最大 dp}\]

    那么两个操作变成： - 插入（来了新元素，值 \(v\)，算出 \(dp\)）：f[v] = max(f[v], dp) - 查询（值 \(< x\) 的最大 dp）：max(f[1], f[2], ..., f[x-1]) —— 前缀最大值

    以 \(a = [3, 1, 4, 2]\)（值域 \(\{1,2,3,4\}\)）为例，完整过程：

    步骤 处理 查询（前缀 max） 得到 dp 更新
    i=0 a=3 max(f[1],f[2])=0 dp=1 f[3]=1
    i=1 a=1 max(空)=0 dp=1 f[1]=1
    i=2 a=4 max(f[1],f[2],f[3])=1 dp=2 f[4]=2
    i=3 a=2 max(f[1])=1 dp=2 f[2]=2

    答案 2，正确。这里树状数组还没出现——一个普通数组 \(f\) 就够了，逻辑完全自洽。

    为什么需要树状数组：值域太大¶

    上面方案的问题：每次查询前缀要扫 \(O(M)\) 个格子（\(M\) = 值域大小）。\(n\) 到 \(10^5\) 时，离散化后 \(M\) 也有 \(10^5\)，总复杂度 \(O(nM) \approx 10^{10}\)，直接超时。

    所以需要把"前缀最大值查询"和"单点更新"都加速到 \(O(\log M)\)。树状数组就是这个加速工具——它做的是同一件事，只是不存每个单点的 \(f[v]\)，而是存"若干段区间的 \(f\) 最大值"，按 lowbit 分块：

    关键限制：max 不可逆¶

    求和版本的树状数组可以做区间查询（sum(r) - sum(l-1)），因为减法是加法的逆运算。但 max 没有逆运算——一旦 c[pos] 被 max 改大，就再也算不回旧值。这带来两个限制：

    1. 只能查前缀 max，不能像求和那样做区间 max（没有减法把中间减掉）；
    2. 只能"增大"不能撤销，updateMax 只能把值往大了改。

    但在 LIS 这个问题里这完全不是问题：历史只会累积（处理完的元素不会消失，没有删除操作），所以永远不需要撤销，只管往上增就对了。

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int n, M;          // M 是离散化后的值域
int c[MAXN];       // 树状数组维护"前缀最大值"

int lowbit(int x) { return x & (-x); }

// 前缀 max 更新：把位置 pos 的值尽量往大了更新
// 注意：只能"增大"，因为 max 没有逆操作，不能把某次更新撤销
void updateMax(int pos, int v) {
    while (pos <= M) {
        c[pos] = max(c[pos], v);
        pos += lowbit(pos);
    }
}

// 查询 [1, x] 的最大值（前缀 max）
int queryMax(int x) {
    int res = 0;
    while (x > 0) {
        res = max(res, c[x]);
        x -= lowbit(x);
    }
    return res;
}

int main() {
    scanf("%d", &n);
    vector<int> a(n), b(n);
    for (int i = 0; i < n; i++) {
        scanf("%d", &a[i]);
        b[i] = a[i];
    }
    // 离散化（LIS 只关心大小关系，不关心具体值）
    sort(b.begin(), b.end());
    b.erase(unique(b.begin(), b.end()), b.end());
    M = b.size();
    for (int i = 0; i < n; i++)
        a[i] = lower_bound(b.begin(), b.end(), a[i]) - b.begin() + 1;

    int ans = 0;
    for (int i = 0; i < n; i++) {
        // dp = 以 a[i] 结尾的 LIS 长度 = 前面值 < a[i] 的最大 dp + 1
        int dp = queryMax(a[i] - 1) + 1;
        ans = max(ans, dp);
        updateMax(a[i], dp);  // 把 dp 挂到值域 a[i] 上
    }
    printf("%d\n", ans);
    return 0;
}

    9. 应用三：树状数组上二分（第 K 小）¶

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int M = 100000;      // 值域 1..1e5
long long c[MAXN];   // 值域出现次数的树状数组

int lowbit(int x) { return x & (-x); }

void add(int pos, long long v) {
    while (pos <= M) { c[pos] += v; pos += lowbit(pos); }
}

// 查询第 k 小：倍增从高位往低位凑
// 贪心正确性：如果 pos+2^j 的前缀和还 < k，说明第 k 小必然在更右边，
// 放心跳过去；反过来如果 >= k，这一位不取（答案在这段内部）
int findKth(int k) {
    int pos = 0;
    for (int j = 20; j >= 0; j--) {   // 2^20 > 1e5，从大到小凑
        int nxt = pos + (1 << j);
        if (nxt <= M && c[nxt] < k) { // 跳过去也不超过第 k 小
            pos = nxt;
            k -= c[nxt];              // 砍掉左边已有的数量
        }
    }
    return pos + 1;   // 第一个前缀和 >= k 的位置
}

int main() {
    int q;
    scanf("%d", &q);
    while (q--) {
        int op, x;
        scanf("%d%d", &op, &x);
        if (op == 1) add(x, 1);           // 插入一个 x
        else printf("%d\n", findKth(x));  // 查询第 x 小
    }
    return 0;
}

    坑：倍增上限要和值域匹配（\(2^{20} > 10^5\) 就够，值域 \(10^9\) 要开到 \(2^{30}\)）。c[nxt] < k 必须用 < 而不是 <=，否则答案会偏右一位。

    10. 本节重点¶

    本节重点： - lowbit(x) = x & (-x)：节点 \(x\) 管辖区间 \([x-\text{lowbit}(x)+1, x]\)，长度 = lowbit - 单点修改：x += lowbit(x) 跳父亲链 - 前缀查询：x -= lowbit(x) 跳左边相邻块 - 两个经典模型： - 单点改 + 区间查：区间和 = 前缀和相减 - 区间加 + 单点查：维护差分数组，区间加 = 两个点，单点查 = 前缀和 - 值域树状数组：值当下标，可以数逆序对、做 LIS（前缀 max）、二分第 K 小 - 前缀 max 树状数组：只能增不能减，不能做区间 max（不可逆） - 常见坑： - 值域太大必须离散化 - 差分模型里 r+1 可能等于 n+1，add 循环条件自然处理 - 逆序对/求和注意 long long 防爆
