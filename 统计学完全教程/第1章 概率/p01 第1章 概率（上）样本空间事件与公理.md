## 2. 样本空间与事件

### 2.1 样本空间

**定义**：样本空间 $\Omega$ 是某试验所有可能结果的集合。$\Omega$ 中的点 $\omega$ 称为**样本点**、**实现**或**元素**。$\Omega$ 的**子集**称为**事件**。

**例 1.1**：连续抛两次硬币，$\Omega = \{HH, HT, TH, TT\}$。第一次出现正面的事件是 $A = \{HH, HT\}$。

**例 1.2**：测量某物理量（如温度），$\Omega = \mathbb{R} = (-\infty, +\infty)$。测量值大于 10 但小于等于 23 的事件记为 $A = (10, 23]$。

**例 1.3**：永不停止地抛硬币，样本空间是无限集：

$$\Omega = \{\omega = (\omega_1, \omega_2, \omega_3, \cdots) : \omega_i \in \{H, T\}\}$$

第一次正面出现在第 3 次抛的事件：$E = \{(\omega_1,\omega_2,\omega_3,\cdots) : \omega_1 = T, \omega_2 = T, \omega_3 = H, \omega_i \in \{H,T\}, i > 3\}$。

> **直观理解**：样本空间可以很小（两次抛硬币，4 个点）、可以连续（整个实数轴）、也可以无穷维（无限次抛硬币的序列空间）。写清楚 $\Omega$ 是概率建模的第一步。

### 2.2 事件的集合运算

给定事件 $A$：

- **余集**：$A^c = \{\omega \in \Omega : \omega \notin A\}$，读作"非 A"。$\Omega$ 的余集是空集 $\varnothing$。
- **并集**：$A \cup B = \{\omega \in \Omega : \omega \in A \text{ 或 } \omega \in B\}$（"A 或者 B"）。无限并：$\bigcup_{i=1}^{\infty} A_i = \{\omega : \text{至少存在一个 } i \text{ 使得 } \omega \in A_i\}$。
- **交集**：$A \cap B = \{\omega \in \Omega : \omega \in A \text{ 并且 } \omega \in B\}$（"A 和 B"），有时记为 $AB$ 或 $(A,B)$。无限交：$\bigcap_{i=1}^{\infty} A_i = \{\omega : \text{对一切 } i \text{ 都有 } \omega \in A_i\}$。
- **差集**：$A - B = \{\omega : \omega \in A, \omega \notin B\}$。
- **包含**：$A \subset B$（$A$ 的元素都在 $B$ 中）。$|A|$ 表示有限集 $A$ 的元素个数。

### 2.3 集合术语速查表

| 记号 | 含义 |
|------|------|
| $\Omega$ | 样本空间 |
| $\omega$ | 试验结果（点或元素） |
| $A$ | 事件（$\Omega$ 的子集） |
| $A^c$ | 集合 $A$ 的余集（非 A） |
| $A \cup B$ | 并（A 或 B） |
| $A \cap B$ 或 $AB$ | 交（A 和 B） |
| $A - B$ | 集合差（$\omega$ 属于 A 但不属于 B） |
| $A \subset B$ | 集合包含 |
| $\varnothing$ | 零事件（永不为真） |
| $\Omega$ | 必然事件（永远为真） |

### 2.4 集合序列的极限

- **两两不相交（互斥）**：$A_i \cap A_j = \varnothing$（$i \ne j$）。
- **划分**：两两不相交且 $\bigcup_{i=1}^{\infty} A_i = \Omega$ 的集合序列称为 $\Omega$ 的一个**划分**。
- **示性函数**：$I_A(\omega) = I(\omega \in A) = \begin{cases} 1, & \omega \in A, \\ 0, & \omega \notin A \end{cases}$。它把"事件是否发生"变成 0/1 开关，后面写统计量会反复用到。
- **单调递增序列**：$A_1 \subset A_2 \subset \cdots$，极限 $\lim_{n\to\infty} A_n = \bigcup_{i=1}^{\infty} A_i$。
- **单调递减序列**：$A_1 \supset A_2 \supset \cdots$，极限 $\lim_{n\to\infty} A_n = \bigcap_{i=1}^{\infty} A_i$。
- 二者都记为 $A_n \to A$。

**例 1.4**：$\Omega = \mathbb{R}$，$A_i = [0, 1/i)$，则 $\bigcup_{i=1}^{\infty} A_i = [0, 1)$，$\bigcap_{i=1}^{\infty} A_i = \{0\}$。若 $A_i = (0, 1/i)$，则 $\bigcup_{i=1}^{\infty} A_i = (0, 1)$，$\bigcap_{i=1}^{\infty} A_i = \varnothing$。

> **常见坑**：区分开区间和闭区间对端点的影响——$[0, 1/i)$ 的无穷交包含 0（每个区间都有 0），而 $(0, 1/i)$ 的无穷交是空集（0 不在任何区间里）。

## 3. 概率公理

### 3.1 定义

**定义 1.5**：函数 $P$ 对每一事件赋值 $P(A)$，若 $P$ 满足下面 3 条公理则称 $P$ 为**概率分布**或**概率测度**：

- **公理 1（非负性）**：对任意事件 $A$，$P(A) \ge 0$；
- **公理 2（规范性）**：$P(\Omega) = 1$；
- **公理 3（可列可加性）**：如果 $A_1, A_2, \cdots$ 两两互斥，则

$$P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)$$

### 3.2 概率的两种解释（重要！）

- **频率解释**：$P(A)$ 是重复实验中事件 $A$ 出现次数的**最终比例**。抛硬币正面概率 1/2 = 抛掷次数增加时正面比例趋于 1/2。
- **可信度解释**：$P(A)$ 度量观察者对"$A$ 为真"的**信度**。

**两种解释对应统计推断的两大学派**：频率学派和贝叶斯学派，课本第 11 章详细讨论。不管哪种解释，公理 1-3 都必须满足。

> **直观理解**：频率解释是"客观的、长期的比例"；可信度解释是"主观的、个人的信度"。这是理解全书"频率学派方法 vs 贝叶斯方法"之争的起点。

### 3.3 脚注：为什么要 $\sigma$ 代数

如果样本空间很大（如整个实直线），对**每一个**子集都给定概率非常困难。因此只对特定的集类定义概率，该集类称为 **$\sigma$ 代数**（附录 1.9 会讲）。初学时知道这件事即可，不必深究。

## 4. 由公理推出的性质

从 3 条公理可推导出常用性质：

$$P(\varnothing) = 0$$

$$A \subset B \Rightarrow P(A) \le P(B) \quad (\text{单调性})$$

$$0 \le P(A) \le 1$$

$$P(A^c) = 1 - P(A)$$

$$A \cap B = \varnothing \Rightarrow P(A \cup B) = P(A) + P(B) \quad (1.1)$$

### 4.1 引理 1.6（加法公式）

对任意事件 $A$ 和 $B$：

$$P(A \cup B) = P(A) + P(B) - P(AB)$$

**证明思路**：把 $A \cup B$ 拆成三个互斥部分 $(AB^c) \cup (AB) \cup (A^cB)$，用可列可加性逐块相加，再把 $P(AB)$ 加回一次、减去一次凑出 $P(A)$ 和 $P(B)$。

> **白话解读**：把 $P(A)$ 和 $P(B)$ 相加时，交集 $AB$ 被算了两次，所以要扣掉一次。三个事件时公式为 $P(A \cup B \cup C) = P(A)+P(B)+P(C) - P(AB)-P(AC)-P(BC) + P(ABC)$（容斥原理）。

**例 1.7**：连续抛两次硬币，$H_1$ = 第 1 次正面，$H_2$ = 第 2 次正面：

$$P(H_1 \cup H_2) = \frac{1}{2} + \frac{1}{2} - \frac{1}{4} = \frac{3}{4}$$

### 4.2 定理 1.8（概率的连续性）

如果 $A_n \to A$（单调集合序列极限），则当 $n \to \infty$ 时：

$$P(A_n) \to P(A)$$

**证明思路**（单调递增情形）：设 $B_1 = A_1$，$B_2 = A_2 - A_1$，$B_3 = A_3 - A_2$，$\cdots$，则 $B_1, B_2, \cdots$ 两两不相交，且 $A_n = \bigcup_{i=1}^n B_i$、$A = \bigcup_{i=1}^{\infty} B_i$。由公理 3 得 $P(A_n) = \sum_{i=1}^n P(B_i) \to \sum_{i=1}^{\infty} P(B_i) = P(A)$。

> **白话解读**：概率对集合极限"连续"——单调递增事件的概率极限等于极限事件的概率。后面第 5 章证明收敛定理时这个工具很重要。

## 5. 有限样本空间与组合计数

### 5.1 均匀概率分布

如果 $\Omega = \{\omega_1, \cdots, \omega_n\}$ 有限且每个结果等可能，则：

$$P(A) = \frac{|A|}{|\Omega|}$$

**例**：抛两次骰子，$\Omega$ 有 36 个元素。点数之和为 11 的结果只有 $(5,6),(6,5)$ 两个，故概率 $= 2/36$。

### 5.2 组合计数

$n$ 个元素排序有 $n! = n(n-1)\cdots 3 \cdot 2 \cdot 1$ 种（约定 $0! = 1$）。从 $n$ 个元素中选 $k$ 个：

$$\binom{n}{k} = \frac{n!}{k!(n-k)!} \quad (1.2)$$

读作"n 选 k"。**性质**：$\binom{n}{0} = \binom{n}{n} = 1$，$\binom{n}{k} = \binom{n}{n-k}$。

**例**：20 个学生选 3 个，共 $\binom{20}{3} = \frac{20!}{3!17!} = 1140$ 种方法。

> **常见坑**：区分"排列"（有序，$n!/(n-k)!$）和"组合"（无序，$\binom{n}{k}$）。本题选学生是组合——3 个人不分先后。

## 6. 例题

**例 1（加法公式应用）**：某班 60% 学生通过数学课（$P(A) = 0.6$），50% 通过统计课（$P(B) = 0.5$），30% 两门都通过（$P(AB) = 0.3$）。至少通过一门的比例：

$$P(A \cup B) = 0.6 + 0.5 - 0.3 = 0.8$$

**例 2（示性函数与计数）**：抛 3 次硬币，事件 $A$ = "至少两次正面"。用示性函数 $I_A$ 表示并计算：$A$ 有 $\binom{3}{2} + \binom{3}{3} = 3 + 1 = 4$ 个样本点，$\Omega$ 有 $2^3 = 8$ 个样本点，$P(A) = 4/8 = 1/2$。

**例 3（概率连续性直觉）**：$A_n$ = "前 $n$ 次抛硬币全是正面"，$A_n \downarrow \varnothing$（无穷次全正面概率为 0），所以 $P(A_n) = (1/2)^n \to 0 = P(\varnothing)$，与定理 1.8 一致。

## 7. 本节重点

> **本节重点**：
> - 概率三公理（非负、规范、可列可加）是全部概率论的根基；频率/可信度两种解释对应频率学派/贝叶斯学派。
> - 加法公式 $P(A \cup B) = P(A) + P(B) - P(AB)$ 必须加"减交集"；互斥时才能直接相加。
> - 概率连续性：$A_n \to A \Rightarrow P(A_n) \to P(A)$，用"切块 $B_i$"证明。
> - 等可能模型 $P(A) = |A|/|\Omega|$ + 组合数 $\binom{n}{k}$。
> - **常见坑**：把 $A - B$ 与 $A^c$ 混淆；忘记加法公式的 $-P(AB)$；排列组合不分。
