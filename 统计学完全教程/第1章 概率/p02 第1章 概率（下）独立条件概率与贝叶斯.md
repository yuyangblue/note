## 1. 核心概念

本章（上）篇建立了概率公理体系，本篇进入两个"因果反转"的核心工具：

- **条件概率**：已知部分信息后，概率如何更新（$P(A|B)$）；
- **贝叶斯理论**：由"结果"反推"原因"（$P(A_i|B)$ 用 $P(B|A_i)$ 表达）。

这两个工具贯穿全书：第 11 章贝叶斯推断直接建立在这套语言上，第 17 章贝叶斯网络也是。

## 2. 独立事件

### 2.1 定义

**定义 1.9**：如果下式成立，则事件 $A$ 和 $B$ 是**独立**的：

$$P(AB) = P(A)P(B) \quad (1.3)$$

记为 $A \amalg B$。如果对 $I$ 的所有子集 $J$ 都有 $P\left(\bigcap_{i \in J} A_i\right) = \prod_{i \in J} P(A_i)$，则事件集 $\{A_i : i \in I\}$ 独立。若不独立，记为 $A \not\amalg B$。

> **直观理解**：独立性 = "知道 $A$ 发生不会改变 $B$ 的概率"。数学定义只有一条：联合概率等于边缘概率的乘积。

### 2.2 独立性的两种来源（课本特别区分）

1. **假设独立**：如连续两次抛硬币，"每次抛硬币独立"反映了硬币对第一次结果没有记忆。
2. **推导独立**：通过验证 $P(AB) = P(A)P(B)$ 来证明独立。如抛均匀骰子，$A = \{2,4,6\}$，$B = \{1,2,3,4\}$，则 $P(AB) = 2/6 = P(A)P(B) = (1/2)(2/3)$，所以独立。

### 2.3 互斥 ≠ 独立（重点坑）

**正概率的互斥事件不可能独立**：$P(A)P(B) > 0$ 但 $P(AB) = P(\varnothing) = 0$。

> **白话解读**：互斥是"不能同时发生"（交集为空），独立是"互不影响"。两者方向相反——互斥事件因为"一个发生另一个必不发生"，信息量最大；独立事件是"一个发生对另一个毫无提示"。

### 2.4 独立事件的性质（引理 1.14）

如果 $A$ 与 $B$ 独立，则 $P(A|B) = P(A)$。对任意两事件 $A, B$：

$$P(AB) = P(A|B)P(B) = P(B|A)P(A)$$

> **白话解读**：独立 ⇔ 条件概率等于无条件概率。$P(AB) = P(A)P(B|A)$ 这条乘法公式在计算"逐步抽取"问题时非常有用。

## 3. 条件概率

### 3.1 定义

**定义 1.12**：如果 $P(B) > 0$，则 $A$ 在 $B$ 下的条件概率为：

$$P(A|B) = \frac{P(AB)}{P(B)} \quad (1.4)$$

**白话解读**：$P(A|B)$ 可理解为"A、B 同时发生的次数占 B 发生次数的比例"——把样本空间收缩到 B 上，重新看 A 占多大份额。

### 3.2 条件概率的性质（课本 3 条警告）

1. 对固定 $B$（$P(B) > 0$），$P(\cdot|B)$ 满足概率的 3 条公理（是一个概率测度）：$P(A|B) \ge 0$，$P(\Omega|B) = 1$，互斥事件可加。**但一般 $P(A|B \cup C) = P(A|B) + P(A|C)$ 不成立**——概率法则只适用于竖杠左边的事件。
2. 一般 $P(A|B) \ne P(B|A)$——**检察官谬论**（见例）。
3. $A$ 和 $B$ 独立当且仅当 $P(A|B) = P(A)$。

> **常见坑**：条件概率的"加法"只对竖杠左边的事件成立。$P(A|B \cup C)$ 需要把竖杠左边当作一个整体事件处理，不能拆开。

## 4. 贝叶斯理论

### 4.1 全概率法则（定理 1.16）

令 $A_1, \cdots, A_k$ 是 $\Omega$ 的一个**划分**（两两互斥且并为 $\Omega$），则对任意事件 $B$：

$$P(B) = \sum_{i=1}^{k} P(B|A_i)P(A_i)$$

**证明思路**：设 $C_j = BA_j$，则 $C_1, \cdots, C_k$ 互斥且 $B = \bigcup_{j=1}^k C_j$。于是 $P(B) = \sum_j P(BA_j) = \sum_j P(B|A_j)P(A_j)$。

> **白话解读**：想算 $B$ 的总概率？把 $\Omega$ 切成几块，在每一块里算 $B$ 的条件概率，再按块的大小（$P(A_i)$）加权求和。

### 4.2 贝叶斯定理（定理 1.17）

令 $A_1, \cdots, A_k$ 是 $\Omega$ 的划分，$P(A_i) > 0$，$P(B) > 0$，则对 $i = 1, \cdots, k$：

$$P(A_i|B) = \frac{P(B|A_i)P(A_i)}{\sum_j P(B|A_j)P(A_j)} \quad (1.5)$$

**证明**：$P(A_i|B) = \frac{P(A_i B)}{P(B)}$，分子用乘法公式 $P(A_i B) = P(B|A_i)P(A_i)$，分母用全概率法则。

### 4.3 先验与后验（注 1.18）

- $P(A_i)$ 称为 $A_i$ 的**先验概率**（观察数据前的信念）；
- $P(A_i|B)$ 称为 $A_i$ 的**后验概率**（观察到 $B$ 后的信念）。

> **白话解读**：贝叶斯定理就是"由果溯因"——我知道"原因 $A_i$ 产生证据 $B$ 的可能性"（$P(B|A_i)$），想反推"看到证据 $B$ 后，原因 $A_i$ 有多可能"（$P(A_i|B)$）。$P(B|A_i)$ 叫**似然**，$P(A_i)$ 叫先验，$P(A_i|B)$ 叫后验。

## 5. 例题

**例 1（疾病检验，例 1.13）**：疾病 $D$ 的检验结果可能为 + 和 -，概率如下：

| | $D$ | $D^c$ |
|---|---|---|
| + | 0.009 | 0.099 |
| - | 0.001 | 0.891 |

- 检验灵敏度：$P(+|D) = \frac{0.009}{0.009+0.001} = 0.9$；
- 特异度：$P(-|D^c) = \frac{0.891}{0.891+0.099} = 0.9$。

检验相当精确（患者 90% 阳性、健康者 90% 阴性）。但拿到阳性结果后患病概率：

$$P(D|+) = \frac{P(+ \cap D)}{P(+)} = \frac{0.009}{0.009 + 0.099} \approx 0.08$$

**结论**：很多人直觉认为 $P(D|+) = 0.90$，实际只有 0.08！原因：患病先验 $P(D) = 0.01$ 太小，大量假阳性稀释了后验。**这一教训说明要通过计算获得答案，不要相信直觉。**

**例 2（垃圾邮件分类，例 1.19）**：邮件分三类 $A_1$=垃圾（$P=0.7$）、$A_2$=低优先级（0.2）、$A_3$=高优先级（0.1）。含单词 "free" 的概率：$P(B|A_1) = 0.9$，$P(B|A_2) = 0.01$，$P(B|A_3) = 0.01$。收到含 "free" 的邮件：

$$P(A_1|B) = \frac{(0.9)(0.7)}{(0.9)(0.7) + (0.01)(0.2) + (0.01)(0.1)} = 0.995$$

> **白话解读**：虽然"free"在正常邮件里也偶尔出现（1%），但垃圾邮件基数太大（70%）且命中率极高（90%），所以后验几乎锁定垃圾邮件——这就是贝叶斯垃圾邮件过滤的原理。

**例 3（轮流投篮，例 1.11）**：两人轮流投篮，第 1 人投进概率 1/3，第 2 人 1/4。第 1 人先投进的概率：令 $A_j$ = "第 $j$ 轮由第 1 人首次投进"，$A_1, A_2, \cdots$ 互斥且 $E = \bigcup_j A_j$。$P(A_1) = 1/3$，$P(A_2) = (2/3)(3/4)(1/3) = (1/2)(1/3)$，一般 $P(A_j) = (1/3)(1/2)^{j-1}$。用等比数列求和（$0 < r < 1$ 时 $\sum_{j=k}^\infty r^j = r^k/(1-r)$）：

$$P(E) = \frac{1}{3}\sum_{j=1}^\infty \left(\frac{1}{2}\right)^{j-1} = \frac{2}{3}$$

## 6. 本节重点

> **本节重点**：
> - 独立性：$P(AB) = P(A)P(B)$；独立有时是假设、有时需验证；**正概率互斥事件不可能独立**。
> - 条件概率 $P(A|B) = P(AB)/P(B)$；$P(\cdot|B)$ 是概率测度，但 $P(A|\cdot)$ 不是；$P(A|B) \ne P(B|A)$（检察官谬论）。
> - 乘法公式 $P(AB) = P(A|B)P(B)$；全概率法则 $P(B) = \sum_i P(B|A_i)P(A_i)$；贝叶斯定理 = 似然×先验 / 归一化。
> - **常见坑**：拿直觉代替贝叶斯计算（疾病检验例）；混淆先验/似然/后验；把互斥当独立。
