## 复习课 B 知识回顾：期望、方差与协方差

**两种方差写法**（要求 $\mathbb{E}[X^2]<\infty$）：

$$\operatorname{Var}(X)=\mathbb{E}(X-\mathbb{E}[X])^2=\mathbb{E}[X^2]-\mathbb{E}[X]^2$$

**协方差**：$\operatorname{Cov}(X,Y)=\mathbb{E}[XY]-\mathbb{E}[X]\mathbb{E}[Y]$。

**线性组合的方差**（$a,b,c$ 为常数）：

$$\operatorname{Var}(aX+bY+c)=a^2\operatorname{Var}(X)+b^2\operatorname{Var}(Y)+2ab\operatorname{Cov}(X,Y)$$

两条容易忽略的规则：常数平移 $c$ **不改变**方差；协方差项**不能省**，只有 $X,Y$ 不相关（例如独立）时才为 $0$。

**样本均值与样本方差**（教材定理 3.17）：设 $X_1,\ldots,X_n$ iid，$\mathbb{E}[X_i]=\mu$、$\operatorname{Var}(X_i)=\sigma^2<\infty$，$n\ge2$，令 $\bar X=\frac1n\sum X_i$、$S_n^2=\frac{1}{n-1}\sum(X_i-\bar X)^2$，则

$$\mathbb{E}[\bar X]=\mu,\qquad \operatorname{Var}(\bar X)=\frac{\sigma^2}{n},\qquad \mathbb{E}[S_n^2]=\sigma^2$$

注意 $S_n^2$ 的分母是 $n-1$ 才无偏；分母写 $n$ 会得到 $\frac{n-1}{n}\sigma^2$。

**三个把条件期望用起来的动作**（第 21 题、混合分布都靠它们）：

- 全期望公式 $\mathbb{E}[Y]=\mathbb{E}\big[\mathbb{E}(Y\mid X)\big]$；
- 全方差公式 $\operatorname{Var}(Y)=\mathbb{E}\big[\operatorname{Var}(Y\mid X)\big]+\operatorname{Var}\big(\mathbb{E}[Y\mid X]\big)$；
- 提出已知量：条件在 $X$ 上时，$X$ 的函数就是"已知量"，可以像常数一样提到条件期望外面。

## 第2题

**题目：** 证明 $V(X) = 0$ 当且仅当存在常数 $c$ 使得 $P(X = c) = 1$。

**解答：**
（正向）若 $P(X = c) = 1$，则 $E[X] = c$，$E[X^2] = c^2$，所以 $V(X) = E[X^2] - (E[X])^2 = c^2 - c^2 = 0$。

（反向）若 $V(X) = 0$，则 $E[(X - E[X])^2] = 0$。令 $Y = (X - E[X])^2 \geq 0$，只需证明 $E[Y] = 0 \implies P(Y = 0) = 1$。

取 $A_n = \{Y \geq 1/n\}$，则：
$$0 = E[Y] \geq E[Y I_{A_n}] \geq \frac{1}{n} P(A_n)$$

所以 $P(A_n) = 0$ 对所有 $n$ 成立。由概率的连续性：
$$P(Y > 0) = P(\bigcup_n A_n) = \lim_{n \to \infty} P(A_n) = 0$$

因此 $P(Y = 0) = 1$，即 $P(X = E[X]) = 1$。

## 第4题

**题目：** 设 $X_1, \ldots, X_n \sim \text{Uniform}(0, 1)$ 独立同分布，令 $Y_n = \max\{X_1, \ldots, X_n\}$。求 $E[Y_n]$。

**解答：**
$Y_n$ 的 CDF：
$$F_{Y_n}(y) = P(\max\{X_1, \ldots, X_n\} \leq y) = P(X_1 \leq y)^n = y^n, \quad 0 \leq y \leq 1$$

密度函数：$f_{Y_n}(y) = n y^{n-1}$

期望：
$$E[Y_n] = \int_0^1 y \cdot n y^{n-1} dy = n \int_0^1 y^n dy = \frac{n}{n+1}$$

## 第7题

**题目：** 证明非负随机变量 $X$ 的期望可以表示为：
$$E[X] = \int_0^\infty P(X > x) dx$$

**思路：**
① 目标是"期望 = 尾部面积"，所以要把 $x$ 本身写成一条尾部积分。
② 逐点恒等式 $x=\int_0^\infty \mathbf{1}\{x>t\}\,dt$，代入后再取期望。
③ 交换期望与积分不需要可积性前提，因为被积函数非负（Tonelli）。

**解答：**
（连续型情况）由分部积分：
$$
\begin{aligned}
E[X] &= \int_0^\infty x f_X(x) dx = \lim_{y \to \infty} y F_X(y) - \int_0^y F_X(x) dx \\
&= \lim_{y \to \infty} \int_0^y (F_X(y) - F_X(x)) dx \\
&= \lim_{y \to \infty} \int_0^\infty (1 - F_X(x)) I_{(0,y)}(x) dx
\end{aligned}
$$

令 $G_y(x) = (1 - F_X(x)) I_{(0,y)}(x)$，当 $y \to \infty$ 时 $G_y(x) \to 1 - F_X(x)$，且 $G_y$ 单调递增。由勒贝格单调收敛定理：

$$E[X] = \int_0^\infty (1 - F_X(x)) dx = \int_0^\infty P(X > x) dx$$

**另解（示性函数 + Tonelli）：** 不走分部积分，直接从"把正数写成积分"开始。对每个 $\omega$，

$$X(\omega)=\int_0^{X(\omega)}1\,dx=\int_0^\infty \mathbf{1}\{X(\omega)>x\}\,dx$$

两边取期望，被积函数 $\mathbf 1\{X>x\}\ge0$，Tonelli 定理允许直接交换：

$$\mathbb{E}[X]=\mathbb{E}\int_0^\infty \mathbf{1}\{X>x\}\,dx=\int_0^\infty \mathbb{E}\big[\mathbf{1}\{X>x\}\big]\,dx=\int_0^\infty P(X>x)\,dx$$

（最后一步用了 $\mathbb{E}[\mathbf 1_A]=P(A)$。）这个证法的好处是**不需要先知道 $\mathbb{E}[X]<\infty$**，也顺手把"两边同时为 $+\infty$"的情形包含进去了；分部积分法则要求边界项 $t[1-F(t)]\to0$。

**拓展一：高阶矩也是尾积分。** 把 $x$ 换成 $x^r$（$x\ge0$）：$x^r=\int_0^{x}rt^{r-1}dt$，同样交换得

$$\mathbb{E}[X^r]=r\int_0^\infty t^{r-1}P(X>t)\,dt\qquad(r>0)$$

$r=1$ 回到本题，$r=2$ 给出 $\mathbb{E}[X^2]=2\int_0^\infty tP(X>t)\,dt$。权重 $rt^{r-1}$ 随 $t$ 增大，所以 $r$ 越大，尾部对大数值越敏感。

**拓展二：尾部速度决定哪些矩存在。** 取 Pareto 型尾 $P(X>t)=t^{-\alpha}$（$t\ge1$，$t<1$ 时为 $1$），代入上式

$$\mathbb{E}[X^r]=r\Big[\int_0^1 t^{r-1}dt+\int_1^\infty t^{r-1-\alpha}dt\Big]=\begin{cases}\dfrac{\alpha}{\alpha-r}, & 0<r<\alpha,\\[4pt] +\infty, & r\ge\alpha.\end{cases}$$

于是 $\alpha>1$ 才有有限均值，$\alpha>2$ 才有有限方差。**判断矩是否有限不必先求密度，只看尾部衰减多快。**

**拓展三：变量可取负值怎么办。** 令 $X^+=\max\{X,0\}$、$X^-=\max\{-X,0\}$，则两端都非负且 $X=X^+-X^-$，分别套用非负版本

$$\mathbb{E}[X^+]=\int_0^\infty P(X>t)\,dt,\qquad \mathbb{E}[X^-]=\int_0^\infty P(X<-t)\,dt$$

当 $\mathbb{E}|X|<\infty$ 时相减得 $\mathbb{E}[X]=\int_0^\infty P(X>t)dt-\int_0^\infty P(X<-t)dt$。

## 第8题

**题目：** 设 $X_1, \ldots, X_n$ 独立同分布，$E[X_i] = \mu$，$V(X_i) = \sigma^2$。
(a) 求 $E[\bar{X}]$ 和 $V(\bar{X})$
(b) 证明样本方差 $S_n^2 = \frac{1}{n-1} \sum_{i=1}^n (X_i - \bar{X})^2$ 是 $\sigma^2$ 的无偏估计（即 $E[S_n^2] = \sigma^2$）

**解答：**
(a)
$$E[\bar{X}] = \frac{1}{n} \sum_{i=1}^n E[X_i] = \mu$$

$$V(\bar{X}) = \frac{1}{n^2} \sum_{i=1}^n V(X_i) = \frac{\sigma^2}{n}$$

(b) 展开平方项：
$$(n-1) S_n^2 = \sum_{i=1}^n (X_i - \bar{X})^2 = \sum_{i=1}^n X_i^2 - n \bar{X}^2$$

取期望：
$$(n-1) E[S_n^2] = E[X_1^2] - n E[\bar{X}^2]$$

已知 $E[X_1^2] = \sigma^2 + \mu^2$，$E[\bar{X}^2] = V(\bar{X}) + (E[\bar{X}])^2 = \sigma^2/n + \mu^2$

代入：
$$(n-1) E[S_n^2] = (\sigma^2 + \mu^2) - n(\sigma^2/n + \mu^2) = (n-1)\sigma^2$$

所以 $E[S_n^2] = \sigma^2$，即样本方差是无偏的。

## 第15题

**题目：** 证明协方差的双线性性：
$$\text{Cov}\left(\sum_i a_i X_i, \sum_j b_j Y_j\right) = \sum_{i,j} a_i b_j \text{Cov}(X_i, Y_j)$$

**解答：**
$$
\begin{aligned}
\text{Cov}\left(\sum_i a_i X_i, \sum_j b_j Y_j\right)
&= E\left[\left(\sum_i a_i X_i\right)\left(\sum_j b_j Y_j\right)\right] - E\left[\sum_i a_i X_i\right] E\left[\sum_j b_j Y_j\right] \\
&= \sum_{i,j} a_i b_j E[X_i Y_j] - \sum_{i,j} a_i b_j E[X_i] E[Y_j] \\
&= \sum_{i,j} a_i b_j \left(E[X_i Y_j] - E[X_i] E[Y_j]\right) \\
&= \sum_{i,j} a_i b_j \text{Cov}(X_i, Y_j)
\end{aligned}
$$

## 第16题

**题目：** 设 $(X, Y)$ 的联合密度为 $f(x, y) = \frac{1}{3}(x + y)$，$0 \leq x \leq 2$，$0 \leq y \leq 1$。求 $V(2X - 3Y + 8)$。

**思路：**
① 常数不影响方差，$V(2X-3Y+8)=V(2X-3Y)$，先把 $+8$ 丢掉。
② 有两条路：直接算 $E[(2X-3Y)^2]-(E[2X-3Y])^2$；或先求两个边缘密度，拿 $V$、$\text{Cov}$ 逐项拼。
③ 不管走哪条，二阶矩和交叉项都要用**联合**密度（$E[XY]$ 不能由边缘唯一确定）。

**解答：**
常数不影响方差，所以 $V(2X - 3Y + 8) = V(2X - 3Y)$。

先算期望：
$$E[2X - 3Y] = \int_0^2 \int_0^1 (2x - 3y) \cdot \frac{1}{3}(x + y) \,dy\,dx = \frac{7}{9}$$

再算二阶矩：
$$E[(2X - 3Y)^2] = \int_0^2 \int_0^1 (2x - 3y)^2 \cdot \frac{1}{3}(x + y) \,dy\,dx = \frac{47}{18}$$

所以：
$$V(2X - 3Y) = E[(2X - 3Y)^2] - (E[2X - 3Y])^2 = \frac{47}{18} - \frac{49}{81} = \frac{423 - 98}{162} = \frac{325}{162}$$

**另解（逐项算 $V$ 与 $\text{Cov}$）：** 边缘密度

$$f_X(x)=\frac13\int_0^1(x+y)dy=\frac{2x+1}{6},\qquad f_Y(y)=\frac13\int_0^2(x+y)dx=\frac{2+2y}{3}$$

于是 $E[X]=\frac{11}{9}$、$E[Y]=\frac59$、$E[X^2]=\frac{16}{9}$、$E[Y^2]=\frac{7}{18}$、$E[XY]=\frac23$，得

$$V(X)=\frac{23}{81},\qquad V(Y)=\frac{13}{162},\qquad \operatorname{Cov}(X,Y)=\frac23-\frac{11}{9}\cdot\frac59=-\frac{1}{81}$$

$$V(2X-3Y)=4\cdot\frac{23}{81}+9\cdot\frac{13}{162}+2\cdot2\cdot(-3)\cdot\Big(-\frac{1}{81}\Big)=\frac{184+117+24}{162}=\frac{325}{162}$$

**注：** 原记录写的是 $E[2X-3Y]=-23/9$、$E[(2X-3Y)^2]=86/9$、方差 $245/81$——那三个数是把区间记反的结果。本题 $x\in[0,2]$、$y\in[0,1]$，若改成 $x\in[0,1]$、$y\in[0,2]$，同一密度仍合法但 $E[X]$ 与 $E[Y]$ 互换，$V(2X-3Y)$ 就真等于 $245/81$。**系数 $2$ 和 $-3$ 不对称，区间方向不能随手调换。**

## 第21题

**题目：** 证明全方差法则（EVVE 法则）：
$$V(Y) = E[V(Y|X)] + V(E[Y|X])$$

**解答：**
（第一部分）由条件方差的定义：
$$V(Y|X) = E[Y^2|X] - (E[Y|X])^2$$

取期望：
$$E[V(Y|X)] = E[Y^2] - E[(E[Y|X])^2]$$

（第二部分）：
$$V(E[Y|X]) = E[(E[Y|X])^2] - (E[E[Y|X]])^2 = E[(E[Y|X])^2] - (E[Y])^2$$

两式相加：
$$E[V(Y|X)] + V(E[Y|X]) = E[Y^2] - (E[Y])^2 = V(Y)$$

## 第24题

**题目：** 设 $X_1, \ldots, X_n \sim \text{Exp}(\beta)$ 独立同分布。证明 $\sum_{i=1}^n X_i \sim \text{Gamma}(n, \beta)$。

**解答：**
指数分布 $\text{Exp}(\beta)$ 的矩母函数（MGF）为：
$$E[e^{tX}] = \int_0^\infty \beta e^{-\beta x} e^{tx} dx = \frac{\beta}{\beta - t}, \quad t < \beta$$

$n$ 个独立随机变量和的 MGF 是各自 MGF 的乘积：
$$E[e^{t \sum_{i=1}^n X_i}] = \left(\frac{\beta}{\beta - t}\right)^n = \left(1 - \frac{t}{\beta}\right)^{-n}$$

这正是 $\text{Gamma}(n, \beta)$ 分布的 MGF。由 MGF 唯一确定分布，所以 $\sum_{i=1}^n X_i \sim \text{Gamma}(n, \beta)$。

**注（两套参数化，别混）：** 本题用的是**速率**参数化 $f(x)=\beta e^{-\beta x}$、$M(t)=\dfrac{\beta}{\beta-t}=\Big(1-\dfrac t\beta\Big)^{-1}$；复习课上用的是**尺度**参数化 $f(x)=\dfrac1\beta e^{-x/\beta}$、$M(t)=(1-\beta t)^{-1}$。两者只差 $\beta\leftrightarrow1/\beta$，但 MGF 长得不一样，抄公式时先看题目给的是哪一个。结论（$n$ 个独立指数之和是 $\text{Gamma}(n,\beta)$，均值 $n\beta$、方差 $n\beta^2$）在两套写法下都成立。

## 复习课 B 补充：两人到达（顺序统计量 + 条件密度）

**来源：** 复习课 B 课堂练习（补充）

**题目：** 甲、乙独立且均匀地在时段 $[0,1]$ 内到达。记 $X$ 为**后到者**的到达时刻、$Y$ 为**先到者**的到达时刻，联合密度

$$f_{X,Y}(x,y)=\begin{cases}2, & 0<y<x<1,\\ 0, & \text{其他}.\end{cases}$$

(a) 求 $f_X$、$f_Y$，以及 $\mathbb{E}[X]$、$\mathbb{E}[Y]$；
(b) 求 $f_{Y\mid X}(y\mid x)$ 与 $\mathbb{E}[Y\mid X=x]$，用全期望公式核对 $\mathbb{E}[Y]$，并判断 $X,Y$ 是否独立；
(c) 求 $\mathbb{P}(X+Y\le1)$。

**思路：**
① 支持集是三角形 $0<y<x<1$：$x$ 的范围是 $(0,1)$，给定 $x$ 后 $y$ 的范围是 $(0,x)$——**谁是内层变量由支持集决定**。
② 边缘密度就是"对另一个变量在支持集上积分"，积分限一定随另一个变量变。
③ 条件密度 $f_{Y|X}=f_{X,Y}/f_X$ 的支持仍然随 $x$ 变；正因为它是 $x$ 的函数（不是 $f_Y(y)$），所以 $X,Y$ 不独立。
④ $\{X+Y\le1\}$ 与三角形支持求交，交点 $x=1/2$ 决定分段。

**解答：**
(a) 边缘密度

$$f_X(x)=\int_0^x 2\,dy=2x\ (0<x<1),\qquad f_Y(y)=\int_y^1 2\,dx=2(1-y)\ (0<y<1)$$

$$\mathbb{E}[X]=\int_0^1 x\cdot 2x\,dx=\frac23,\qquad \mathbb{E}[Y]=\int_0^1 y\cdot 2(1-y)\,dy=\frac13$$

(b) 条件密度

$$f_{Y\mid X}(y\mid x)=\frac{2}{2x}=\frac1x,\qquad 0<y<x$$

即给定 $X=x$ 后 $Y\sim U(0,x)$，故 $\mathbb{E}[Y\mid X=x]=\dfrac{x}{2}$，作为随机变量 $\mathbb{E}[Y\mid X]=X/2$。全期望核对：

$$\mathbb{E}[Y]=\mathbb{E}\Big[\frac{X}{2}\Big]=\frac12\cdot\frac23=\frac13\ \checkmark$$

独立性：$f_{Y\mid X}(y\mid x)=\frac1x\mathbf 1_{(0,x)}(y)$ 随 $x$ 改变，不等于 $f_Y(y)=2(1-y)$，故 $X,Y$ **不独立**。

(c) 支持集与事件求交：$0<y<x$ 且 $y\le 1-x$。当 $x\le\frac12$ 时约束是 $y<x$；当 $x>\frac12$ 时约束变成 $y\le 1-x$，

$$\mathbb{P}(X+Y\le1)=\int_0^{1/2}\!\!\int_0^x 2\,dy\,dx+\int_{1/2}^1\!\!\int_0^{1-x}2\,dy\,dx=\int_0^{1/2}2x\,dx+\int_{1/2}^1 2(1-x)\,dx=\frac14+\frac14=\frac12$$

换积分次序（先 $x$ 后 $y$）同样得 $2\int_0^{1/2}(1-2y)dy=\frac12$，可作校验。

**易错点：** (a) 的积分限写成 $0$ 到 $1$ 就错了（三角形支持）；(c) 一定要先画支持集再与事件求交，否则分段点 $x=1/2$ 找不到。

**对应讲义：** [[统计学完全教程/第2章 随机变量/p06 第2章 随机变量（四）二元分布边际独立与条件分布#5.2 连续情形|p06 §5.2]]、[[统计学完全教程/第3章 数学期望/p11 第3章 数学期望（三）条件期望与矩母函数#3. 迭代期望法则|p11 §3]]

## 复习课 B 习题：条件期望可提出已知量

**来源：** 复习课 B 课后习题（教材 P60 第 16 题）

**题目：** 设 $r(x)$ 只依赖 $x$、$s(y)$ 只依赖 $y$。证明

$$\mathbb{E}[r(X)s(Y)\mid X]=r(X)\,\mathbb{E}[s(Y)\mid X],\qquad \mathbb{E}[r(X)\mid X]=r(X)$$

**思路：**
① 条件期望的定义是"固定 $X=x$ 后对 $y$ 积分"，此时 $r(x)$ 是常数。
② 常数可以提到积分号外，再把 $x$ 换回 $X$（对每个 $x$ 成立，就作为随机变量成立）。
③ 取 $s\equiv1$ 得第二式，因为条件密度积分为 $1$。

**解答：**
固定 $X=x$，

$$\mathbb{E}[r(X)s(Y)\mid X=x]=\int r(x)s(y)f_{Y\mid X}(y\mid x)\,dy=r(x)\int s(y)f_{Y\mid X}(y\mid x)\,dy=r(x)\,\mathbb{E}[s(Y)\mid X=x]$$

把 $x$ 换回 $X$ 即得第一式。取 $s\equiv1$：

$$\mathbb{E}[r(X)\mid X]=r(X)\int f_{Y\mid X}(y\mid x)\,dy=r(X)$$

**何时使用：** 这三条（全期望、提出已知量、$r(X)$ 可提）是同一套工具的三张面孔。凡是要算 $\mathbb{E}[XY]$、$\operatorname{Cov}(X,Y)$ 而手上只有条件分布时，标准动作都是"先套一层 $\mathbb{E}[\cdot\mid X]$ 把已知的 $X$ 提出来"。

**对应讲义：** [[统计学完全教程/第3章 数学期望/p11 第3章 数学期望（三）条件期望与矩母函数#2.2 条件期望的五条基本性质|p11 §2.2]]

## 复习课 B 习题：$\mathbb{E}(Y\mid X)=X$ 推出 $\operatorname{Cov}=\operatorname{Var}$

**来源：** 复习课 B 课后习题（教材 P61 第 21 题；注意与上文 All of Statistics 3.21 的全方差题不是同一题）

**题目：** 设 $\mathbb{E}[X^2]<\infty$、$\mathbb{E}[Y^2]<\infty$，且 $\mathbb{E}(Y\mid X)=X$。证明 $\operatorname{Cov}(X,Y)=\operatorname{Var}(X)$。

**思路：**
① $\mathbb{E}[Y]$ 用全期望公式，直接得到 $\mathbb{E}[X]$。
② $\mathbb{E}[XY]$ 套一层 $\mathbb{E}[\cdot\mid X]$，把 $X$ 提出去，再用题目给的 $\mathbb{E}(Y\mid X)=X$。
③ 代入协方差定义，正好凑成 $\mathbb{E}[X^2]-\mathbb{E}[X]^2$。

**解答：**

$$\mathbb{E}[Y]=\mathbb{E}\big[\mathbb{E}(Y\mid X)\big]=\mathbb{E}[X]$$

$$\mathbb{E}[XY]=\mathbb{E}\big[\mathbb{E}(XY\mid X)\big]=\mathbb{E}\big[X\,\mathbb{E}(Y\mid X)\big]=\mathbb{E}[X^2]$$

于是

$$\operatorname{Cov}(X,Y)=\mathbb{E}[XY]-\mathbb{E}[X]\mathbb{E}[Y]=\mathbb{E}[X^2]-\mathbb{E}[X]^2=\operatorname{Var}(X)$$

**注：** 条件 $\mathbb{E}(Y\mid X)=X$ 是"$Y$ 的条件均值恰好等于 $X$"，典型例子是 $Y=X+\varepsilon$、$\mathbb{E}(\varepsilon\mid X)=0$。此时 $\operatorname{Cov}(X,Y)=\operatorname{Var}(X)>0$，即 $X,Y$ 必然正相关——但**不相关**是 $\operatorname{Cov}=0$，别把两个结论搞混。

**对应讲义：** [[统计学完全教程/第3章 数学期望/p11 第3章 数学期望（三）条件期望与矩母函数#3. 迭代期望法则|p11 §3]]

## 复习课 B 补充：混合分布的全期望与全方差

**来源：** 复习课 B 补充练习③

**题目：** 先抛一枚均匀硬币（结果记为 $C$）：正面时 $X\sim U(0,1)$，反面时 $X\sim U(3,4)$。求 $\mathbb{E}[X]$ 与 $\mathrm{SD}(X)$。

**思路：**
① 条件在 $C$ 上，$X$ 是均匀分布，矩可以直接查表：$\mathbb{E}U(a,b)=\frac{a+b}{2}$、$\mathbb{E}U(a,b)^2=\frac{a^2+ab+b^2}{3}$。
② 全期望公式求 $\mathbb{E}[X]$ 与 $\mathbb{E}[X^2]$（二阶矩也要过一遍全期望）。
③ 用 $\operatorname{Var}=\mathbb{E}[X^2]-(\mathbb{E}[X])^2$ 收尾，再用全方差公式验算。

**解答：**
均匀分布的矩：$\mathbb{E}U(a,b)=\frac{a+b}{2}$、$\mathbb{E}U(a,b)^2=\frac{a^2+ab+b^2}{3}$。于是

$$\mathbb{E}[X\mid C=H]=\frac12,\quad \mathbb{E}[X^2\mid C=H]=\frac13;\qquad \mathbb{E}[X\mid C=T]=\frac72,\quad \mathbb{E}[X^2\mid C=T]=\frac{9+12+16}{3}=\frac{37}{3}$$

$$\mathbb{E}[X]=\frac12\cdot\frac12+\frac12\cdot\frac72=2,\qquad \mathbb{E}[X^2]=\frac12\cdot\frac13+\frac12\cdot\frac{37}{3}=\frac{19}{3}$$

$$\operatorname{Var}(X)=\frac{19}{3}-4=\frac73,\qquad \mathrm{SD}(X)=\sqrt{\frac73}\approx1.53$$

全方差验算：$\operatorname{Var}(X\mid C)=\frac1{12}$ 两种情形相同，故 $\mathbb{E}[\operatorname{Var}(X\mid C)]=\frac1{12}$；而 $\mathbb{E}[X\mid C]$ 以各 $\frac12$ 取 $\frac12,\frac72$，其方差为 $\frac{9}{4}$，故

$$\frac1{12}+\frac94=\frac1{12}+\frac{27}{12}=\frac{28}{12}=\frac73\ \checkmark$$

**易错点：** 不能把混合分布当成"$U(0,1)$ 和 $U(3,4)$ 各取一半区间"的 $U(0,4)$——后者均值为 $2$（碰巧一样），但方差 $\frac{16}{12}=\frac43\ne\frac73$。混合分布的方差明显更大，因为两个成分的**均值本身**在跳（$\frac12$ 与 $\frac72$），这部分不确定性进的是 $\operatorname{Var}(\mathbb{E}[X\mid C])$。

**对应讲义：** [[统计学完全教程/第3章 数学期望/p11 第3章 数学期望（三）条件期望与矩母函数#4. 条件方差与全方差法则|p11 §4]]
