## 1. 核心概念

第 3 章把随机变量的分布"压缩"成少数几个数字，最重要的就是**期望（均值）**——分布的"中心"。统计里估计量的好坏（无偏性、MSE）全部以期望/方差为语言（见 p15 第6章）。

本篇覆盖课本 3.1-3.2 节：期望定义、存在性、懒惰统计学家法则、期望的线性与乘积性质。

## 2. 期望的定义

**定义 3.1**：$X$ 的**期望值**（或均值、一阶矩）定义为：

$$\mathbb{E}(X) = \int x\,dF(x) = \begin{cases} \sum_x x f(x), & X \text{ 为离散}, \\ \int x f(x)dx, & X \text{ 为连续} \end{cases} \quad (3.1)$$

等价记号：$\mathbb{E}(X) = \mathbb{E}X = \int x\,dF(x) = \mu = \mu_X \quad (3.2)$。

> **白话解读**：期望 = 取值 × 概率的加权平均。离散是求和、连续是积分，符号 $\int x\,dF(x)$ 统一两者（实分析课程有严格定义，这里只当记号用）。

**$F_X(x)$ 是什么 / $dF_X(x)$ 怎么读**：$F_X(x)=P(X\le x)$ 是 $X$ 的累积分布函数（CDF）。$dF_X(x)$ 是 Riemann–Stieltjes 积分记号，读作"$X$ 落在 $x$ 附近那一小片的概率质量"，作用是把离散和连续写成同一个公式：

- 离散：$F_X$ 是阶梯函数，在每个可能取值处跳一下，跳跃高度就是该点概率 $p_X(x)$，故 $dF_X(x)$ 在跳跃处取 $p_X(x)$，积分退化为求和 $\sum_x x\,p_X(x)$；
- 连续：$F_X$ 光滑且 $F'_X=f_X$（密度），故 $dF_X(x)=f_X(x)\,dx$，积分退化为 $\int x\,f_X(x)\,dx$。

一句话：$\int r(x)\,dF_X(x)$ = 对所有可能的 $x$，把"值 × 它那一小片的概率质量"加起来——离散堆在几个点上（求和），连续铺成密度（积分）。

> **与大数定律的联系（课本原话）**：期望是分布的单值概括。$\mathbb{E}(X)$ 可以看成 IID 样本 $X_1, \cdots, X_n$ 的平均 $\sum_i X_i/n$——事实上 $\mathbb{E}(X) \approx \sum_i X_i/n$ 是**正确的**，它不是直观推断，它被称为**大数定律**（第 5 章讨论）。

**例 3.2**：$X \sim \text{Bernoulli}(p)$，$\mathbb{E}(X) = 0 \times (1-p) + 1 \times p = p$。

**例 3.3**：抛均匀硬币两次，$X$ = 正面次数：$\mathbb{E}(X) = 0(1/4) + 1(1/2) + 2(1/4) = 1$。

**例 3.4**：$X \sim \text{Uniform}(-1,3)$：$\mathbb{E}(X) = \frac{1}{4}\int_{-1}^3 x\,dx = 1$。

## 3. 期望存在性与柯西分布反例

如果 $\int |x|\,dF_X(x) < \infty$，则称 $\mathbb{E}(X)$ **存在**；否则称期望不存在。

**柯西分布是什么**：标准柯西分布的密度为

$$f_X(x) = \frac{1}{\pi(1+x^2)},\qquad -\infty < x < \infty$$

形状像"胖一号的正态钟形"（对称、单峰、在 0 处最高），但尾部厚得多：$|x|$ 大时 $f_X(x)\sim 1/(\pi x^2)$（多项式衰减），而正态是 $e^{-x^2/2}$（指数衰减），极端值出现概率远高于正态。CDF 有闭式 $F_X(x)=\frac12+\frac1\pi\arctan x$。

**最常见的来源**：两个独立标准正态变量之比 $Z_1/Z_2$ 服从标准柯西——分母接近 0 时比值极易取到很大/很小的值，这就是厚尾的直观来源。

**例 3.5（柯西分布均值不存在）**：用分部积分（$u = x$，$v = \arctan x$）：

$$\int |x|\,dF(x) = \frac{2}{\pi}\int_0^\infty \frac{x\,dx}{1+x^2} = \frac{2}{\pi}[x\arctan x]_0^\infty - \frac{2}{\pi}\int_0^\infty \arctan x\,dx = \infty$$

所以柯西分布均值不存在。

**为什么样本均值也不收敛**：柯西是**稳定分布**——$n$ 个 i.i.d. 柯西样本的平均 $\bar X_n$ 仍然服从柯西分布，与 $n$ 无关。抽样 10 个和 10000 个，均值的"脾气"一模一样，永远可能被一个极端值带跑。这正是大数定律（见 p18 / L18 WLLN）要求"期望存在"的原因：柯西连期望都不存在，样本均值也就无从收敛。

**模拟验证**：对柯西分布多次抽样取均值，均值不会稳定——因为尾部太厚，很容易出现很大的观察值。

> **白话解读**：期望不是"永远都有"。重尾分布（柯西）的积分发散，样本均值不稳定。**统计里遇到重尾分布要特别小心"均值"这类统计量**。

## 4. 懒惰统计学家法则

**定理 3.6（懒惰统计学家法则，LOTUS）**：令 $Y = r(X)$，则：

$$\mathbb{E}(Y) = \mathbb{E}(r(X)) = \int r(x)\,dF_X(x) \quad (3.3)$$

> **白话解读**：想算 $E(Y)$ 不用先求出 $Y$ 的分布！直接用"$r(x)$ 对 $X$ 的分布积分"即可。名字的由来：统计学家"懒得"求 $f_Y$。这是全书最高频使用的技巧之一。
>
> **直觉理解**：假想一个游戏，$X$ 是随机变量，付给你 $Y = r(X)$。你的平均收入 = $r(x)$ 乘以 $X = x$ 的概率，再对 $x$ 求和（或积分）。

**特殊情况：概率是期望**：**示性函数**（indicator function，也写作 $\mathbf{1}\{x\in A\}$ 或 $1_A(x)$）是一个"开关"：

$$I_A(x) = \begin{cases} 1, & x \in A \\ 0, & x \notin A \end{cases}$$

它"指示"$x$ 是否属于集合 $A$：属于就亮（1），不属于就灭（0）。令 $r(x)=I_A(x)$，则：

$$\mathbb{E}(I_A(X)) = \int I_A(x)f_X(x)dx = \int_A f_X(x)dx = P(X \in A)$$

被积函数 $I_A(x)$ 只在 $x\in A$ 时为 1、其余地方为 0，积分自动缩到 $A$ 上。**这是概率论核心桥梁：概率 = 示性函数的期望**（反过来按期望定义看：$I_A(X)$ 是 0/1 随机变量，$E[I_A(X)]=1\cdot P(I_A=1)+0\cdot P(I_A=0)=P(X\in A)$，一眼即得）。马尔可夫不等式、切比雪夫、指示变量分解求期望（二项均值、固定点问题）都建立在这个等式上。

**多变量版本**：$Z = r(X,Y)$ 时：

$$\mathbb{E}(Z) = \mathbb{E}(r(X,Y)) = \iint r(x,y)\,dF(x,y) \quad (3.4)$$

**例 3.7**：$X \sim \text{Uniform}(0,1)$，$Y = e^X$：

$$\mathbb{E}(Y) = \int_0^1 e^x dx = e - 1$$

（对比：先求 $f_Y(y) = 1/y$（$1 < y < e$），再 $\mathbb{E}(Y) = \int_1^e y \cdot \frac{1}{y}dy = e - 1$——两条路结果一致，LOTUS 更省事。）

**例 3.8（折断棍子）**：单位长度棍子在 $X \sim \text{Uniform}(0,1)$ 处折断，$Y$ = 较长段长度 $= \max\{X, 1-X\}$。当 $0 < x < 1/2$ 时 $r(x) = 1-x$，当 $1/2 \le x < 1$ 时 $r(x) = x$：

$$\mathbb{E}(Y) = \int_0^{1/2}(1-x)dx + \int_{1/2}^1 x\,dx = \frac{3}{8} + \frac{3}{8} = \frac{3}{4}$$

## 5. 期望的性质

### 5.1 矩的定义

假设 $\mathbb{E}(|X|^k) < \infty$，则 $X$ 的 **$k$ 阶矩**定义为 $\mathbb{E}(X^k)$。$k$ 阶**中心矩**定义为 $\mathbb{E}((X-\mu)^k)$。

**定理 3.10**：如果 $k$ 阶矩存在且 $j < k$，则 $j$ 阶矩存在。

**证明思路**：把积分拆成 $|x| \le 1$ 和 $|x| > 1$ 两部分。$|x| \le 1$ 部分 $\le P(|X| \le 1) \le 1$；$|x| > 1$ 部分 $|x|^j \le |x|^k$，故 $\mathbb{E}|X|^j \le 1 + \mathbb{E}|X|^k < \infty$。

> **白话解读**：高阶矩存在 ⇒ 低阶矩存在。因为 $|x|>1$ 时幂越大增长越快，"更大的矩收敛"自然蕴含"更小的矩收敛"。

**具体走一遍（设 $k=2$、$j=1$：已知 $E[X^2]<\infty$，证 $E|X|<\infty$）**：把 $E|X|=\int|x|f(x)\,dx$ 按 $|x|\le1$ 和 $|x|>1$ 拆成两片。

小片（$|x|\le1$）：$|x|\le1$ 本身 ⇒ $|x|f(x)\le f(x)$，

$$\int_{|x|\le1}|x|f(x)\,dx\le\int_{|x|\le1}f(x)\,dx=P(|X|\le1)\le1$$

尾巴片（$|x|>1$）：$x>1$ 时幂次越高值越大（如 $x=2$：$2<4<8$），故 $|x|\le|x|^2$，

$$\int_{|x|>1}|x|f(x)\,dx\le\int_{|x|>1}x^2f(x)\,dx\le E[X^2]<\infty$$

合起来 $E|X|\le 1+E[X^2]<\infty$。数值上若 $E[X^2]=3$，则 $E|X|\le4$——不用算精确值，光靠不等式就知道有限。

**为什么在 $|x|=1$ 处分界**：$|x|^j\le|x|^k$ 只在 $|x|>1$ 成立；$|x|\le1$ 时反过来（$0.5^2=0.25<0.5$），但小片被 $|x|\le1$ 本身按住（贡献 $\le1$），不靠幂次比较。两片各用各的方法拼起来即可。

### 5.2 线性性质（定理 3.11）

如果 $X_1, \cdots, X_n$ 为随机变量，$a_1, \cdots, a_n$ 为常数，则：

$$\mathbb{E}\left(\sum_i a_i X_i\right) = \sum_i a_i \mathbb{E}(X_i) \quad (3.5)$$

**注意：线性不需要独立性**——加法定理不要求 $X_i$ 独立。

**例 3.12（二项均值）**：$X \sim \text{Binomial}(n,p)$。直接求和 $\sum_x x\binom{n}{x}p^x(1-p)^{n-x}$ 很难算。换个思路：$X = \sum_{i=1}^n X_i$，其中 $X_i = 1$（第 $i$ 次正面）、$0$（反面）。$\mathbb{E}(X_i) = p$，故：

$$\mathbb{E}(X) = \sum_i \mathbb{E}(X_i) = np$$

> **白话解读**：把"难算的组合和"拆成"简单指示变量的和"——这是统计里的万能技巧（线性期望法）。

### 5.3 乘积性质（定理 3.13）

令 $X_1, \cdots, X_n$ 为**独立**随机变量，则：

$$\mathbb{E}\left(\prod_{i=1}^n X_i\right) = \prod_i \mathbb{E}(X_i) \quad (3.6)$$

**注意：乘法定理需要独立**——与加法定理（不需要独立）形成对比。

> **常见坑**：$E(XY) = E(X)E(Y)$ 只在 $X, Y$ 独立（或至少不相关）时成立。不独立时 $E(XY) \ne E(X)E(Y)$ 一般成立，差值正是协方差（见 p10）。

## 6. 例题

**例 1（LOTUS 应用）**：$X \sim N(0,1)$，求 $E(X^2)$。LOTUS：$E(X^2) = \int x^2 \varphi(x)dx$。已知 $V(X) = E(X^2) - 0^2 = 1$，所以 $E(X^2) = 1$。

**例 2（指示函数法）**：$n$ 个人随机坐 $n$ 个座位（随机排列），$X$ = 坐在自己座位上的人数。令 $X_i = I(\text{第 } i \text{ 人坐对自己位置})$，$P(X_i = 1) = 1/n$，则 $E(X) = \sum_i E(X_i) = n \cdot \frac{1}{n} = 1$——期望不动点人数恒为 1，与 $n$ 无关！（这就是"固定点期望"经典题。）

**例 3（期望的线性不依赖独立）**：$X \sim \text{Uniform}(0,1)$，$Y = X$（完全依赖），$E(X+Y) = E(2X) = 2 \times 1/2 = 1 = E(X) + E(Y)$ 仍然成立——线性性质不需要独立，但 $E(XY) = E(X^2) = 1/3 \ne E(X)E(Y) = 1/4$（乘积性质需要独立）。

## 7. 本节重点

> **本节重点**：
> - 期望定义：离散求和、连续积分，统一记号 $\int x\,dF(x)$；存在条件 $\int|x|dF < \infty$（柯西反例）。
> - **懒惰统计学家法则（LOTUS）**：$E(r(X)) = \int r(x)dF_X(x)$——算期望不用先求 $Y$ 的分布；概率 = 期望的示性函数特例。
> - 线性 $E(\sum a_i X_i) = \sum a_i E(X_i)$ **不需要独立**；乘积 $E(\prod X_i) = \prod E(X_i)$ **需要独立**。
> - 指示变量分解 $X = \sum_i X_i$ 求期望（二项均值、固定点问题）。
> - **常见坑**：对不独立变量用乘积公式；期望不存在还硬算（柯西）；忘了 LOTUS 能省事。
