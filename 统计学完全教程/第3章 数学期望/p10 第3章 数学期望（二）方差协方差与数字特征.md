## 1. 核心概念

期望描述分布的"中心"，**方差**描述分布的"散布程度"，**协方差/相关系数**描述两个变量之间的**线性关系**。这三个量是统计推断的语言——估计量的偏差看 $E(\hat\theta)$，方差/标准误看 $V(\hat\theta)$，MSE 分解就是"偏差²+方差"（p15 第6章）。

本篇覆盖课本 3.3-3.4 节。

## 2. 方差

### 2.1 定义

**定义 3.14**：令 $X$ 是均值为 $\mu$ 的随机变量，$X$ 的**方差**（记 $\sigma^2$ 或 $V(X)$）定义为：

$$\sigma^2 = \mathbb{E}(X - \mu)^2 = \int (x - \mu)^2 dF(x) \quad (3.7)$$

（方差的定义、$\text{var}(X)=E[X^2]-(E[X])^2$ 与 $\text{var}(aX+b)=a^2\text{var}(X)$ 的推导见 [[概率论MIT/笔记/02-离散随机变量/L06 方差条件作用与多个随机变量#2.1 方差|L06 §2.1]]。）

**标准差**：$\text{sd}(X) = \sqrt{V(X)}$，记 $\sigma$ 或 $\sigma_X$。

> **脚注（为什么用平方）**：不能用 $\mathbb{E}(X - \mu)$ 度量散布程度，因为它恒等于 0（$\mathbb{E}(X) - \mu = \mu - \mu = 0$）。有时用 $\mathbb{E}|X - \mu|$（平均绝对偏差），但通常用方差。

### 2.2 方差的性质（定理 3.15）

假设方差存在：

1. $V(X) = \mathbb{E}(X^2) - \mu^2$；
2. 如果 $a, b$ 为常数，则 $V(aX + b) = a^2 V(X)$；
3. 如果 $X_1, \cdots, X_n$ **独立**，$a_1, \cdots, a_n$ 为常数，则：

$$V\left(\sum_{i=1}^n a_i X_i\right) = \sum_{i=1}^n a_i^2 V(X_i) \quad (3.8)$$

（独立和的方差为何直接相加、交叉项为何消失见 [[概率论MIT/笔记/04-随机变量进一步专题/L12 独立随机变量之和与协方差#2.4 和的方差|L12 §2.4]]。）

**例 3.16（二项方差）**：$X \sim \text{Binomial}(n,p)$，$X = \sum_i X_i$（$X_i$ 独立 Bernoulli）：

$$\mathbb{E}(X_i) = p, \quad \mathbb{E}(X_i^2) = p, \quad V(X_i) = p - p^2 = p(1-p)$$

$$V(X) = \sum_i V(X_i) = np(1-p)$$

> **白话解读**：性质 2 说明平移（$+b$）不改变方差、缩放（$a$）使方差乘 $a^2$（标准差乘 $|a|$）。性质 3 只有在独立时才是简单的求和——不独立时会出现协方差项（见第 4 节）。

## 3. 样本均值与样本方差

**先区分两个"方差"**：§2 的总体方差 $\sigma^2=E[(X-\mu)^2]$ 是分布的常数参数（真相，但通常未知）；样本方差 $S_n^2$ 是用 $n$ 个样本算出来的随机变量，用来估计未知的 $\sigma^2$。

| 维度 | 总体方差 $\sigma^2$ | 样本方差 $S_n^2$ |
| --- | --- | --- |
| 是什么 | 分布的常数参数 | 用 $n$ 个样本算的随机变量（估计量） |
| 中心 | 真实均值 $\mu=E(X)$ | 样本均值 $\bar X$（$\mu$ 未知时只能用它） |
| 公式 | $\sigma^2=E[(X-\mu)^2]$ | $S_n^2=\frac{1}{n-1}\sum(X_i-\bar X)^2$ |
| 分母 | 期望自动加权 | 除以 $n-1$（Bessel 修正，为了无偏） |
| 会不会变 | 固定不变 | 每次抽样结果不同（本身也有方差） |
| 用途 | 描述离散程度 | 估计未知的 $\sigma^2$ |

类比：总体方差 = 全校学生身高的真实离散程度（校长有全部数据）；样本方差 = 你随机抽 100 人算出的数，用来猜全校的。抽不同的 100 人，算出的 $S_n^2$ 就不一样——所以它是随机变量；长期平均下来正好等于 $\sigma^2$，这就是"无偏"。

如果 $X_1, \cdots, X_n$ 为随机变量，定义**样本均值**：

$$\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i \quad (3.9)$$

**样本方差**：

$$S_n^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X}_n)^2 \quad (3.10)$$

**为什么分母是 $n-1$（Bessel 修正，完整推导）**：$\bar X_n$ 是从同一批数据估出来的中心，它最小化 $\sum(X_i-c)^2$（在 $c=\bar X_n$ 处取最小），所以 $\sum(X_i-\bar X_n)^2$ 系统性偏小——偏小因子正好 $(n-1)/n$。

把 $X_i-\bar X_n$ 拆成 $(X_i-\mu)-(\bar X_n-\mu)$（$\mu$ 为真实均值），平方求和。利用 $\sum(X_i-\mu)=n(\bar X_n-\mu)$，交叉项化简得：

$$\sum_{i=1}^n(X_i-\bar X_n)^2=\sum(X_i-\mu)^2-n(\bar X_n-\mu)^2$$

取期望：第一项 $E[\sum(X_i-\mu)^2]=n\sigma^2$；第二项 $E[(\bar X_n-\mu)^2]=\text{var}(\bar X_n)=\sigma^2/n$，故

$$E\!\left[\sum(X_i-\bar X_n)^2\right]=n\sigma^2-n\cdot\frac{\sigma^2}{n}=(n-1)\sigma^2$$

于是分母换成 $n-1$ 正好把期望扳回 $\sigma^2$：

$$E\!\left[\frac{1}{n-1}\sum(X_i-\bar X_n)^2\right]=\sigma^2$$

若分母用 $n$，则 $E[\frac1n\sum(X_i-\bar X_n)^2]=\frac{n-1}{n}\sigma^2<\sigma^2$，系统性低估（$n=2$ 时低估一半）。

**自由度直觉**：$n$ 个偏差 $X_i-\bar X_n$ 满足约束 $\sum(X_i-\bar X_n)=0$（自动成立），前 $n-1$ 个自由、第 $n$ 个被约束住，独立偏差只有 $n-1$ 个，除以 $n-1$ 才是"平均每个独立偏差"的平方。极端情形 $n=1$：$\bar X_1=X_1$，平方和恒为 0（除以 $n=1$ 永远估出 0 方差，荒谬）；除以 $n-1=0$ 无定义（一个样本本来就没法估方差）。

**定理 3.17（IID 样本的数字特征，重要）**：令 $X_1, \cdots, X_n$ 为 IID 随机变量且 $\mu = \mathbb{E}(X_i)$，$\sigma^2 = \mathbb{V}(X_i)$，则：

$$\mathbb{E}(\bar{X}_n) = \mu, \quad \mathbb{V}(\bar{X}_n) = \frac{\sigma^2}{n}, \quad \mathbb{E}(S_n^2) = \sigma^2$$

（IID 求和的卷积性质与方差随 $n$ 的演化见 [[概率论MIT/笔记/04-随机变量进一步专题/L12 独立随机变量之和与协方差#2.1 独立同分布求和（卷积的性质）|L12 §2.1]]。）

> **白话解读（三个结论都要记住）**：
> - $\bar{X}_n$ 的均值 = 总体均值 $\mu$（**无偏**）；
> - $\bar{X}_n$ 的方差 = $\sigma^2/n$（样本量越大，均值越集中，这是大数定律/CLT 的"方差版本"）；
> - $S_n^2$ 用 $n-1$ 做分母是为了**无偏**（$\mathbb{E}(S_n^2) = \sigma^2$）。

## 4. 协方差与相关系数

### 4.1 定义

**定义 3.18**：令 $X, Y$ 均值分别为 $\mu_X, \mu_Y$，标准差 $\sigma_X, \sigma_Y$。**协方差**：

$$\text{Cov}(X,Y) = \mathbb{E}\left((X - \mu_X)(Y - \mu_Y)\right) \quad (3.11)$$

**相关系数**：

$$\rho = \rho_{X,Y} = \rho(X,Y) = \frac{\text{Cov}(X,Y)}{\sigma_X \sigma_Y} \quad (3.12)$$

（协方差与相关系数的定义、正负号与"原点理解"见 [[概率论MIT/笔记/04-随机变量进一步专题/L12 独立随机变量之和与协方差#1.2 协方差：衡量"一起变化"|L12 §1.2]]–§1.3。）

### 4.2 性质（定理 3.19）

1. $\text{Cov}(X,Y) = \mathbb{E}(XY) - \mathbb{E}(X)\mathbb{E}(Y)$；
2. $-1 \le \rho(X,Y) \le 1$；
3. 如果 $Y = aX + b$（$a, b$ 常数），则 $a > 0$ 时 $\rho = 1$，$a < 0$ 时 $\rho = -1$（完全线性相关）；
4. 如果 $X, Y$ 独立，则 $\text{Cov}(X,Y) = \rho = 0$——**反过来通常不成立**（不相关 ≠ 独立）（协方差性质里"独立 ⇒ 协方差为 0、反之不然"的逐条推导见 [[概率论MIT/笔记/04-随机变量进一步专题/L12 独立随机变量之和与协方差#2.2 协方差性质|L12 §2.2]]）。

> **常见坑**：独立 ⇒ 不相关成立，但不相关 ⇏ 独立。例：$X \sim \text{Uniform}(-1,1)$，$Y = X^2$，则 $\text{Cov}(X,Y) = E(X^3) - E(X)E(X^2) = 0 - 0 = 0$（不相关），但 $Y$ 完全由 $X$ 决定（不独立）。

**$\rho\le 1$ 的完整证明（Cauchy–Schwarz）**：令 $\tilde X = X-\mu_X$、$\tilde Y = Y-\mu_Y$。对任意实数 $t$，

$$0 \le E[(\tilde X - t\tilde Y)^2] = E[\tilde X^2] - 2t\,E[\tilde X\tilde Y] + t^2 E[\tilde Y^2] = \sigma_X^2 - 2t\,\text{Cov}(X,Y) + t^2\sigma_Y^2$$

这是关于 $t$ 的二次函数，恒非负 ⇒ 判别式非正：$(2\,\text{Cov})^2 - 4\sigma_X^2\sigma_Y^2 \le 0$，即 $\text{Cov}(X,Y)^2 \le \sigma_X^2\sigma_Y^2$，两边开方得 $|\rho|\le 1$。等号成立当且仅当二次函数有重根 $t=\sigma_X^2/\text{Cov}$，即 $\tilde X - t\tilde Y = 0$ 几乎处处成立，也就是 $Y$ 是 $X$ 的严格线性函数。（$|\rho|\le1$ 的逐点 AM-GM 证明、等号条件的 a.s. 表述、反方向推导与回归残差视角见 [[概率论MIT/笔记/04-随机变量进一步专题/L12 独立随机变量之和与协方差#2.3 相关系数的界与含义|L12 §2.3]]。）

### 4.3 线性组合的方差（定理 3.20）

$$V(X+Y) = V(X) + V(Y) + 2\text{Cov}(X,Y)$$

$$V(X-Y) = V(X) + V(Y) - 2\text{Cov}(X,Y)$$

更一般地：

$$V\left(\sum_i a_i X_i\right) = \sum_i a_i^2 V(X_i) + 2\sum_{i<j}\sum a_i a_j \text{Cov}(X_i, X_j)$$

> **白话解读**：独立时协方差为 0，退回简单求和公式；不独立时必须补协方差项。**符号规律**：$X+Y$ 加协方差、$X-Y$ 减协方差。

### 4.4 随机向量的协方差矩阵

把协方差推广到随机向量 $X = (X_1, \cdots, X_k)^T$：均值向量 $\mu = (\mathbb{E}(X_1), \cdots, \mathbb{E}(X_k))^T$，**方差-协方差矩阵**（对角是各分量方差，非对角是两两协方差）：

$$\Sigma = E\!\left[(X-\mu)(X-\mu)^T\right]$$

这是把一元 $Var(X)=E[(X-\mu)^2]$ 推广到向量的自然方式——外积 $(X-\mu)(X-\mu)^T$ 是一个 $k\times k$ 矩阵，第 $(i,j)$ 元就是 $E[(X_i-\mu_i)(X_j-\mu_j)]=\text{Cov}(X_i,X_j)$。

$$\mathbb{V}(X) = \begin{pmatrix} V(X_1) & \text{Cov}(X_1,X_2) & \cdots & \text{Cov}(X_1,X_k) \\ \text{Cov}(X_2,X_1) & V(X_2) & \cdots & \text{Cov}(X_2,X_k) \\ \vdots & \vdots & & \vdots \\ \text{Cov}(X_k,X_1) & \text{Cov}(X_k,X_2) & \cdots & V(X_k) \end{pmatrix}$$

它是对称半正定矩阵；线性变换 $Y=AX$ 时 $\mathbb{V}(Y)=A\mathbb{V}(X)A^T$（推广 $V(aX)=a^2V(X)$）。多项分布、多元正态 $\text{Multivariate Normal}(\mu,\Sigma)$ 的"方差"都是这个矩阵。

**为什么一定半正定**：对任意常向量 $a$，$a^T\Sigma a = \text{Var}(a^T X) \ge 0$（方差非负）。这是协方差矩阵唯一的约束——任何对称半正定矩阵都能作为某个随机向量的协方差矩阵。

**仿射变换公式**：$Y = AX + b$（$b$ 为常向量，平移不影响方差），则

$$\text{Cov}(Y) = A\,\Sigma\,A^T$$

这是 $V(aX+b)=a^2V(X)$ 的矩阵版本：$A$ 把方向"旋转+拉伸"，$A^T$ 把拉伸倍数平方后回卷到协方差上。

**奇异协方差矩阵**：当 $X$ 的分量之间存在精确线性关系时 $\Sigma$ 退化。典型例子是多项分布 $N=(N_1,\cdots,N_k)$，必有 $\sum_{j=1}^k N_j = n$，故 $1^T N = n$ 几乎处处成立，$1^T\Sigma 1 = \text{Var}(\sum_j N_j) = 0$——$1$ 是 $\Sigma$ 的零特征向量，$\det\Sigma = 0$。所以 $k$ 个分量里只有 $k-1$ 个自由度，Pearson $\chi^2$ 检验里自由度正是 $k-1$（第 10 章）。

**多项分布协方差矩阵的完整形式**：

$$\text{Cov}(N) = n\left(\text{diag}(p_1,\cdots,p_k) - pp^T\right)$$

即对角元 $n p_j(1-p_j)$（二项方差），非对角元 $-n p_i p_j$（与例 3 一致）。例如 $n=10$、$p=(0.5,0.3,0.2)$ 时：

$$\text{Cov}(N) = 10\left(\begin{pmatrix}0.5&0&0\\0&0.3&0\\0&0&0.2\end{pmatrix} - \begin{pmatrix}0.25&0.15&0.10\\0.15&0.09&0.06\\0.10&0.06&0.04\end{pmatrix}\right) = \begin{pmatrix}2.5&-1.5&-1.0\\-1.5&2.1&-0.6\\-1.0&-0.6&1.6\end{pmatrix}$$

各行和 $=0$，印证奇异性。

## 5. 重要分布的期望和方差表

**（课本表 3.1，必须熟记）**

| 分布 | 均值 | 方差 |
|------|------|------|
| 在 $a$ 处的点分布 | $a$ | 0 |
| Bernoulli$(p)$ | $p$ | $p(1-p)$ |
| Binomial$(n,p)$ | $np$ | $np(1-p)$ |
| Geometric$(p)$ | $1/p$ | $(1-p)/p^2$ |
| Poisson$(\lambda)$ | $\lambda$ | $\lambda$ |
| Uniform$(a,b)$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ |
| Normal$(\mu,\sigma^2)$ | $\mu$ | $\sigma^2$ |
| Exponential$(\beta)$ | $\beta$ | $\beta^2$ |
| Gamma$(\alpha,\beta)$ | $\alpha\beta$ | $\alpha\beta^2$ |
| Beta$(\alpha,\beta)$ | $\frac{\alpha}{\alpha+\beta}$ | $\frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$ |
| $t_\nu$ | 0（若 $\nu > 1$） | $\frac{\nu}{\nu-1}$（若 $\nu > 2$） |
| $\chi_p^2$ | $p$ | $2p$ |
| Multinomial$(n,p)$ | $np$ | 见协方差矩阵 |
| Multivariate Normal$(\mu,\Sigma)$ | $\mu$ | $\Sigma$ |

> **记忆技巧**：Poisson 的均值和方差都是 $\lambda$；指数 = Gamma$(1,\beta)$（均值 $\beta$、方差 $\beta^2$）；$\chi_p^2$ = Gamma$(p/2, 2)$（均值 $p$、方差 $2p$）；t 分布均值方差对自由度有条件（$\nu>1$、$\nu>2$）——因为重尾。

### 5.1 偏度与峰度

均值、方差只描述中心与散布，形状由更高阶标准矩刻画。

**偏度（Skewness）**：三阶标准矩

$$\text{Skew}(X) = E\!\left[\left(\frac{X-\mu}{\sigma}\right)^3\right]$$

偏度为正表示分布右尾更长（如指数分布、对数正态），为负表示左尾更长，对称分布（正态、均匀、t 分布）偏度为 0。

**峰度（Kurtosis）**：四阶标准矩减去 3

$$\text{Kurt}(X) = E\!\left[\left(\frac{X-\mu}{\sigma}\right)^4\right] - 3$$

减 3 是为了让正态分布的超额峰度为 0 作为基准。峰度 $>0$ 称尖峰厚尾（leptokurtic，如 t 分布、对数正态），$<0$ 称扁平（platykurtic，如均匀分布）。峰度大表示分布在中心和尾部都比正态更"重"——极端事件出现概率高于正态，这是金融风控关注峰度的原因。

## 6. 例题

**例 1（样本均值方差，定理 3.17 应用）**：$X_1, \cdots, X_n \sim \text{Exp}(\beta)$ iid，$\bar{X}_n$ 的均值和方差：$E(\bar{X}_n) = \beta$，$V(\bar{X}_n) = \beta^2/n$。用 CLT 得到 $\bar{X}_n \approx N(\beta, \beta^2/n)$（见 p14）（正态近似的两种写法与近似质量见 [[概率论MIT/笔记/05-极限定理/L19 中心极限定理#2.1 正态近似的两种写法|L19 §2.1]]、§2.4）。

**例 2（协方差计算）**：$X \sim \text{Uniform}(0,1)$，$Y = X^2$：$\text{Cov}(X,Y) = E(X^3) - E(X)E(X^2) = \frac{1}{4} - \frac{1}{2}\cdot\frac{1}{3} = \frac{1}{4} - \frac{1}{6} = \frac{1}{12}$。

**例 3（多项分布的协方差，课本 3.21 前）**：$X \sim \text{Multinomial}(n,p)$，$X_i \sim \text{Binomial}(n,p_i)$ 且 $X_i + X_j \sim \text{Binomial}(n, p_i + p_j)$。用 $V(X_i + X_j) = V(X_i) + V(X_j) + 2\text{Cov}(X_i,X_j)$ 解出：

$$\text{Cov}(X_i, X_j) = -np_i p_j$$

> **白话解读**：多项分布分量之间是**负相关**——一种颜色出现多了，另一种必然少。这个结果在第 10 章 $\chi^2$ 检验里会用到。

**例 4（$V(X) = 0 \iff X$ 恒为常数）**：习题 3.2。$V(X) = 0$ 当且仅当存在常数 $c$ 使 $P(X = c) = 1$——方差为零意味着随机变量"不随机"。

**例 5（两传感器取平均，正相关削弱降噪）**：两独立设计的传感器测量同一物理量，$\text{SD}(X)=\text{SD}(Y)=3$。若两者误差独立，$\text{Cov}(X,Y)=0$，取平均 $\bar Z=(X+Y)/2$ 的方差为 $(3^2+3^2)/4=4.5$，标准差 $\sqrt{4.5}\approx 2.12$——比单传感器 3 下降约 29%。但若共享环境干扰导致 $\rho=0.5$，$\text{Cov}=0.5\cdot 3\cdot 3=4.5$，则

$$\text{Var}\!\left(\frac{X+Y}{2}\right)=\frac{9+9+2\cdot 4.5}{4}=6.75$$

标准差 $\sqrt{6.75}\approx 2.60$，比独立时的 2.12 大很多。结论：**取平均降噪的效果取决于两传感器误差的相关性**，相关性越高，共享误差无法通过平均抵消，降噪越有限。

## 7. 本节重点

> **本节重点**：
> - 方差定义 $V(X) = E(X-\mu)^2 = E(X^2) - \mu^2$；$V(aX+b) = a^2V(X)$；独立时 $V(\sum a_iX_i) = \sum a_i^2V(X_i)$。
> - **定理 3.17**：$E(\bar{X}_n) = \mu$，$V(\bar{X}_n) = \sigma^2/n$，$E(S_n^2) = \sigma^2$（$n-1$ 分母为无偏）。
> - 协方差 $\text{Cov}(X,Y) = E(XY) - E(X)E(Y)$；相关系数 $\rho \in [-1,1]$；独立 ⇒ 不相关，反之不然。
> - $V(X+Y) = V(X) + V(Y) + 2\text{Cov}(X,Y)$；多项分布 $\text{Cov}(X_i,X_j) = -np_ip_j$。
> - **常见分布期望方差表必背**（Poisson 均值=方差；t 分布对自由度有条件）。
> - **常见坑**：不相关当独立；$V(X+Y)$ 忘协方差项；$S_n^2$ 分母写成 $n$（有偏）。
