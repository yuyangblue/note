## 2. 条件期望的定义

**给定事件的条件期望**：先有较初等的版本——已知事件 $A$ 发生后，$Y$ 的期望更新为

$$E(Y\mid A) = \sum_y y\,P(Y=y\mid A) \quad\text{或}\quad E(Y\mid A) = \int y\,f(y\mid A)\,dy$$

其中连续情形由混合 Bayes 公式 $f(y\mid A) = \frac{P(A\mid Y=y)f_Y(y)}{P(A)}$ 给出。对应地，**全期望公式**（以离散事件族 $A_i$ 划分为例）：

$$E(X) = \sum_i E(X\mid A_i)\,P(A_i)$$

这是全概率公式 $P(B)=\sum_i P(B\mid A_i)P(A_i)$ 的期望版本。

**连续型为什么能在"单点概率为 0"的事件上条件化**：对连续型 $X$，$P(X=x)=0$，按离散定义 $P(A|B)=P(AB)/P(B)$ 直接套用会得到 $0/0$。正确理解是把 $X=x$ 看成"$x$ 附近一个无穷小窗口"的极限：

$$f_{Y|X}(y|x) = \lim_{\epsilon\to 0^+}\frac{P(Y\in dy,\ x<X<x+\epsilon)}{P(x<X<x+\epsilon)} = \frac{f_{X,Y}(x,y)}{f_X(x)}$$

分子分母同约掉窗口宽度 $\epsilon$，剩下"密度之比"。所以连续型条件密度不是"拿概率相除"，而是"在无穷小窗口里看 $Y$ 的相对密度"——这与离散情形 $p_{Y|X}=p_{X,Y}/p_X$ 在代数形式上完全一致，只是把概率质量换成了密度。

**定义 3.22**：给定 $Y = y$ 情况下 $X$ 的**条件期望**为：

$$\mathbb{E}(X|Y=y) = \begin{cases} \sum x f_{X|Y}(x|y), & \text{离散情形}, \\ \int x f_{X|Y}(x|y)dx, & \text{连续情形} \end{cases} \quad (3.13)$$

如果 $r(x,y)$ 为 $x$ 和 $y$ 的函数，则：

$$\mathbb{E}(r(X,Y)|Y=y) = \begin{cases} \sum r(x,y) f_{X|Y}(x|y), & \text{离散}, \\ \int r(x,y) f_{X|Y}(x|y)dx, & \text{连续} \end{cases} \quad (3.14)$$

### 2.1 关键区分（课本强调，最容易混淆）

- $\mathbb{E}(X|Y = y)$ 是 $y$ 的**函数**（给定 $y$ 就是一个确定的数）；
- $\mathbb{E}(X|Y)$ 是**随机变量**——在观察 $Y$ 之前不知道它取什么值；当 $Y = y$ 时，其值为 $\mathbb{E}(X|Y = y)$。

类似地，$\mathbb{E}(r(X,Y)|Y)$ 是随机变量，当 $Y = y$ 时取 $\mathbb{E}(r(X,Y)|Y = y)$。

**例 3.23**：$X \sim \text{Uniform}(0,1)$，给定 $X = x$ 后 $Y|X = x \sim \text{Uniform}(x, 1)$。直觉 $E(Y|X = x) = (1+x)/2$，验证：

$$f_{Y|X}(y|x) = \frac{1}{1-x} \ (x < y < 1), \quad E(Y|X=x) = \frac{1}{1-x}\int_x^1 y\,dy = \frac{1+x}{2}$$

因此 $E(Y|X) = (1+X)/2$ 是随机变量。

> **白话解读**：$E(Y|X)$ 是一个"随 $X$ 变化的平均"——$X$ 已知时它是个数，$X$ 未知时它自己也是随机的。这有点像"回归函数"的雏形：给定 $X$，$Y$ 的平均水平是多少。

**$Y$ 到底是什么（两步随机实验）**：第一步在 $[0,1]$ 上随机选 $X$（如 0.3），第二步在区间 $(X,1)$ 上再随机选 $Y$（如 0.7）。$Y$ 就是第二步抽的数，天然满足 $Y>X$。积分 $\int_x^1 y\,dy$ 里的 $y$ 是积分哑变量——遍历 $(x,1)$ 上所有可能取值，乘密度 $1/(1-x)$ 求平均，不是某个特定的 $Y$。

具体感受：$X=0.3$ 时 $Y\sim\text{Unif}(0.3,1)$、中点 0.65；$X=0.8$ 时 $Y\sim\text{Unif}(0.8,1)$、中点 0.90——$X$ 越大，$Y$ 被挤在越靠近 1 的小窗口里，条件均值越大，这正是 $(1+x)/2$ 的直观来源。几何上 $(X,Y)$ 落在单位正方形的三角形区域 $0<x<y<1$ 内（对角线上方）。

### 2.2 条件期望的五条基本性质

1. **线性**：$E(aY_1+bY_2\mid X)=aE(Y_1\mid X)+bE(Y_2\mid X)$——继承自期望的线性。
2. **独立时归零更新**：若 $X,Y$ 独立，则 $E(Y\mid X)=E(Y)$——已知 $X$ 不提供 $Y$ 的新信息。
3. **Taking out what's known**：对任意函数 $h(\cdot)$，

$$E\bigl(h(X)\,Y \mid X\bigr) = h(X)\,E(Y\mid X)$$

当 $X$ 给定时 $h(X)$ 退化为常数，可直接提出条件期望外。这条在迭代期望化简中极常用。
4. **Law of total expectation（Adam 律）**：$E[E(Y\mid X)]=E(Y)$，见下节。
5. **投影解释**：$E(Y\mid X)$ 是 $Y$ 到"所有 $X$ 的函数构成的空间"的正交投影。形式上对任意 $h(X)$ 有

$$E\bigl[h(X)\,(Y-E(Y\mid X))\bigr] = 0$$

展开并对第二项用 taking out what's known 与 Adam 律：$E[h(X)E(Y\mid X)] = E\bigl[E(h(X)Y\mid X)\bigr] = E[h(X)Y]$，故残差 $Y-E(Y\mid X)$ 与任意 $h(X)$ 不相关。这正是"最佳预测"在 Hilbert 空间里的几何说法。

## 3. 迭代期望法则

**定理 3.24（迭代期望法则）**：对随机变量 $X, Y$，假定期望均存在，则：

$$\mathbb{E}\left[\mathbb{E}(Y|X)\right] = \mathbb{E}(Y), \quad \mathbb{E}\left[\mathbb{E}(X|Y)\right] = \mathbb{E}(X) \quad (3.15)$$

更一般地，对任意函数 $r(x,y)$：

$$\mathbb{E}\left[\mathbb{E}(r(X,Y)|X)\right] = \mathbb{E}(r(X,Y)) \quad (3.16)$$

**证明要点**（连续情形）：$\mathbb{E}[\mathbb{E}(Y|X)] = \int \mathbb{E}(Y|X=x)f_X(x)dx = \int\int y f(y|x)dy\, f(x)dx = \iint y f(x,y)dxdy = \mathbb{E}(Y)$。

**分步拆解**（四步每步靠什么）：

1. $\int \mathbb{E}(Y|X=x)f_X(x)dx$：把 $g(x)=\mathbb{E}(Y|X=x)$ 当普通函数，对 $g(X)$ 求期望，按 LOTUS 就是 $\int g(x)f_X(x)dx$。
2. $\int\int y f(y|x)dy\,f_X(x)dx$：把 $\mathbb{E}(Y|X=x)$ 按定义展开成条件期望 $\int y f(y|x)dy$，代入。
3. **关键一步**：用乘法法则 $f(y|x)=f(x,y)/f_X(x)$，反乘得 $f(y|x)f_X(x)=f(x,y)$，被积函数正好拼成联合密度，两层积分粘成对整个平面的二重积分。
4. $\iint y f(x,y)dxdy=\mathbb{E}(Y)$：这就是 $Y$ 期望的二维定义。所谓"二维定义"不是新东西——期望的本质是"取值 × 概率密度全平面积分"：一维 $E(Y)=\int y f_Y(y)dy$；二维里每个 $(x,y)$ 处的密度是联合密度 $f(x,y)$，不关心 $x$ 就先对 $x$ 积分：

$$\iint y f(x,y)dxdy=\int y\underbrace{\left[\int f(x,y)dx\right]}_{\text{边缘密度 }f_Y(y)}dy=\int y f_Y(y)dy=E(Y)$$

括号里的 $\int f(x,y)dx$ 就是 $Y$ 的边缘密度（沿 $x$ 方向积掉，得到"不管 $X$ 是什么、$Y=y$ 处的概率密度"）。离散情形同理：$\sum_x\sum_y y\,p(x,y)=\sum_y y\,\sum_x p(x,y)=\sum_y y\,p_Y(y)$。

离散情形对照（同样靠乘法法则粘合）：$\sum_x\sum_y y\,p(y|x)p_X(x)=\sum_x\sum_y y\,p(x,y)=\sum_y y\underbrace{\sum_x p(x,y)}_{p_Y(y)}=\mathbb{E}(Y)$。

> **白话解读**：**"平均的平均 = 总平均"**。先按 $X$ 分层算每层的平均，再把各层平均按 $X$ 的分布加权平均，得到 $Y$ 的总体平均。这是分层抽样、回归、贝叶斯里反复用的工具。

**例 3.25**：接例 3.23，求 $E(Y)$ 不用求联合密度：$E(Y) = E[E(Y|X)] = E((1+X)/2) = (1 + 1/2)/2 = 3/4$。

## 4. 条件方差与全方差法则

**定义 3.26（条件方差）**：

$$V(Y|X=x) = \int (y - \mu(x))^2 f(y|x)dy \quad (3.17)$$

其中 $\mu(x) = \mathbb{E}(Y|X=x)$。

**定理 3.27（全方差法则，EVVE 法则）**：对于随机变量 $X$ 和 $Y$：

$$V(Y) = \mathbb{E}V(Y|X) + V\mathbb{E}(Y|X)$$

> **白话解读**：$Y$ 的总方差 = **组内平均波动**（$EV(Y|X)$）+ **组间差异**（$VE(Y|X)$）。$X$ 能解释的"分层差异"越多，$VE(Y|X)$ 越大——这就是方差分析的分解思想，也是回归 $R^2$ 的直觉来源。
>
> **记忆技巧**："EVVE"（期望-方差-方差-期望）：外层 $V$，内层先 $E$ 后 $V$，再 $V$ 再 $E$。

**Eve 律的投影分解形式**：把 $Y$ 拆成 $Y=(Y-E(Y\mid X))+E(Y\mid X)$，由上节投影正交性（残差与任意 $h(X)$ 不相关），两部分不相关，故

$$V(Y) = V(Y-E(Y\mid X)) + V(E(Y\mid X))$$

对比原形式：$E[V(Y\mid X)] = V(Y-E(Y\mid X))$——"组内方差的期望"正是"垂直于 $X$ 的残差分量的方差"。这与回归里"总平方和 = 残差平方和 + 回归平方和"完全同构。

**全方差法则的完整证明（交叉项为什么是 0）**：令 $m(X)=E(Y|X)$、$v(X)=V(Y|X)$。把 $Y-EY$ 拆成

$$Y-EY = (Y-m(X)) + (m(X)-EY)$$

平方后取期望，交叉项 $2E[(Y-m(X))(m(X)-EY)]$ 看似非零。固定 $X=x$ 时，$(m(x)-EY)$ 是常数，可提出条件期望外：

$$E[(Y-m(X))(m(X)-EY)\mid X] = (m(X)-EY)\cdot E[Y-m(X)\mid X] = (m(X)-EY)\cdot 0 = 0$$

再对外层取期望，整个交叉项为 0。于是

$$V(Y) = E[(Y-m(X))^2] + E[(m(X)-EY)^2] = E[v(X)] + V(m(X))$$

第一项是组内平均波动 $E[V(Y|X)]$，第二项是组间差异 $V[E(Y|X)]$。

**条件均值是最佳 MSE 预测**：给定 $X=x$ 时用常数 $a$ 预测 $Y$，MSE 为

$$E[(Y-a)^2\mid X=x] = v(x) + (m(x)-a)^2$$

展开 $(Y-a)=(Y-m(x))+(m(x)-a)$ 即得。第二项在 $a=m(x)$ 时为 0，故**在 $X$ 已知的条件下，最佳常数预测就是条件均值 $m(x)$**；不利用 $X$ 时报常数 $a$，最优 $a=EY$，MSE$=V(Y)$；用 $X$ 时报 $m(X)$，MSE$=E[v(X)]$。两者之差恰为 $V[m(X)]$——这就是"知道 $X$ 后剩余波动的减少量"，也是回归 $R^2=V[m(X)]/V(Y)$ 的由来。

**"信息越多剩余波动一定越小吗"反例**：取 $Y|X=x\sim\text{Uniform}(0,x)$，$X\sim\text{Uniform}(0,1)$。条件方差 $v(x)=x^2/12$，在 $X=0.9$ 时 $v(0.9)=0.0675$；但 $E[Y]=1/4$、$V(Y)=E[v(X)]+V[m(X)]=\int_0^1 x^2/12\,dx + V(X/2)=1/36+1/48=7/144\approx 0.0486$，可见 $v(0.9)>V(Y)$——某个具体 $x$ 处的条件方差完全可能大于总体方差。但平均下来 $E[v(X)]=1/36\approx 0.0278 < V(Y)$，所以"平均而言信息越多剩余波动越小"成立，只是对每个样本点不成立。

**例 3.28（分层模型）**：$Q \sim \text{Uniform}(0,1)$，$X|Q=q \sim \text{Binomial}(n,q)$。

- $E(X) = E[E(X|Q)] = E(nQ) = n/2$；
- $V(X) = EV(X|Q) + VE(X|Q) = E[nQ(1-Q)] + V(nQ) = n/6 + n^2/12$。

**Beta–Binomial 完整算例**：取 $n=10$，则 $V(X)=10/6+100/12=1.67+8.33=10$。对比"批次固定为 $q=1/2$"的情形（即不考虑 $Q$ 的随机性），$X\sim\text{Bin}(10,1/2)$，方差 $=10\cdot\frac12\cdot\frac12=2.5$。批次间多出来的方差 $10-2.5=7.5$ 恰好是 $V(10Q)=100/12=8.33$ 中扣除 $E[nQ(1-Q)]$ 与固定 $n/4=2.5$ 之差后的部分；粗略地讲，$Q$ 在 $(0,1)$ 上漂移使同一批次内二项方差的期望从 $2.5$ 升至 $10/6\approx1.67$ 这一变化远小于批次间方差 $n^2/12\approx8.33$，整体方差放大到约 4 倍。

边缘分布 $P(X=k)=\int_0^1 \binom{10}{k}q^k(1-q)^{10-k}dq = \frac{1}{11}$（$k=0,1,\cdots,10$）——11 个取值上等可能，这是 Beta(1,1) 与二项共轭的直接结果（$q$ 的后验仍是 Beta）。

> **白话解读**：当 $n$ 很大时，$n^2/12$ 项主导——分层（$Q$ 变化）引起的组间差异远大于组内波动。这就是"层间差异大"数据的典型特征（如不同县的患病率差异）。

## 5. 矩母函数 MGF

### 5.1 定义

**定义 3.29**：$X$ 的**矩母函数（MGF）** 或拉普拉斯变换定义为：

$$\phi_X(t) = \mathbb{E}(e^{tX}) = \int e^{tx} dF(x)$$

其中 $t$ 为实数。假设 MGF 对 $t=0$ 的某个开区间中的任意 $t$ 都存在。

### 5.2 矩的生成

当 MGF 存在时，积分和期望算子可以互换，从而：

$$\phi'(0) = \left[\frac{d}{dt}\mathbb{E}e^{tX}\right]_{t=0} = \mathbb{E}[Xe^{tX}]_{t=0} = \mathbb{E}(X)$$

进行 $k$ 阶微分可得：$\phi^{(k)}(0) = \mathbb{E}(X^k)$。

> **白话解读**：MGF 的 $k$ 阶导数在 0 处的值 = $X$ 的 $k$ 阶矩。名字"矩母函数"（moment generating）由此而来——它"生出"所有矩。

**例 3.30**：$X \sim \text{Exp}(1)$，对 $t < 1$：

$$\phi_X(t) = \mathbb{E}e^{tX} = \int_0^\infty e^{tx}e^{-x}dx = \int_0^\infty e^{(t-1)x}dx = \frac{1}{1-t}$$

（$t \ge 1$ 时积分发散。）$\phi'(0) = 1 = E(X)$，$\phi''(0) = 2 = E(X^2)$，$V(X) = 2 - 1 = 1$。

### 5.3 MGF 的性质（引理 3.31）

1. 如果 $Y = aX + b$，则 $\phi_Y(t) = e^{bt}\phi_X(at)$；
2. 如果 $X_1, \cdots, X_n$ **独立**且 $Y = \sum_i X_i$，则：

$$\phi_Y(t) = \prod_i \phi_i(t)$$

**定理 3.33（MGF 唯一确定分布）**：令 $X$ 和 $Y$ 为随机变量，如果对以 0 为中心的某个开区间里所有的 $t$ 有 $\phi_X(t) = \phi_Y(t)$，则 $X \stackrel{d}{=} Y$。

> **白话解读**：MGF 是分布的"指纹"——相同 ⇒ 同分布。独立和的 MGF = 各 MGF 的乘积 ⇒ 若乘积恰好是某个已知分布的 MGF，就证明了这个分布的可加性。

**MGF 存在性反例：所有阶矩有限 ≠ MGF 存在**。设 $Z\sim N(0,1)$，令 $X=e^Z$（对数正态分布）。对任意 $k>0$，

$$E[X^k] = E[e^{kZ}] = e^{k^2/2} < \infty$$

即所有阶矩都存在。但对任意 $t>0$，

$$E[e^{tX}] = E[e^{t e^Z}] = \int_{-\infty}^{\infty} e^{t e^z}\varphi(z)\,dz = \infty$$

因为 $z\to+\infty$ 时被积函数 $e^{t e^z - z^2/2}/\sqrt{2\pi}$ 指数增长。所以对数正态的 MGF 在 $t>0$ 时整体发散，唯一性定理不能直接用——这也是为什么对数正态不能由矩序列唯一确定（矩问题病态）。CLT 证明中遇到厚尾分布时改用**特征函数** $\psi_X(t)=E[e^{itX}]$（对所有 $t$ 都存在）而非 MGF，道理就在这里。

### 5.4 常见分布的 MGF 表

| 分布 | MGF $\phi(t)$ |
|------|---------------|
| Bernoulli$(p)$ | $pe^t + (1-p)$ |
| Binomial$(n,p)$ | $(pe^t + (1-p))^n$ |
| Geometric$(p)$ | $\dfrac{pe^t}{1-(1-p)e^t}$，$t < -\ln(1-p)$ |
| Poisson$(\lambda)$ | $e^{\lambda(e^t - 1)}$ |
| Uniform$(a,b)$ | $\dfrac{e^{bt}-e^{at}}{t(b-a)}$（$t\ne0$）；$M(0)=1$ |
| Exponential$(\lambda)$ | $\dfrac{\lambda}{\lambda-t}$，$t<\lambda$ |
| Normal$(\mu,\sigma)$ | $\exp\left\{\mu t + \frac{\sigma^2 t^2}{2}\right\}$ |
| Gamma$(\alpha,\beta)$ | $\left(\frac{1}{1-\beta t}\right)^\alpha$，$t < 1/\beta$ |
| Chi-Squared$(\nu)$ | $(1-2t)^{-\nu/2}$，$t<1/2$ |
| Beta$(\alpha,\beta)$ | 无初等闭式（用超几何函数表示） |
| Cauchy$(x_0,\gamma)$ | **不存在**——不存在包含 0 的开邻域使 $E[e^{tX}]$ 有限，MGF 方法对 Cauchy 完全失效 |

**例 3.32（二项 MGF）**：$X \sim \text{Binomial}(n,p)$，$X = \sum_i X_i$（独立 Bernoulli），$\phi_i(t) = pe^t + (1-p)$，故 $\phi_X(t) = (pe^t + q)^n$（$q = 1-p$）。

**例 3.34（二项可加性）**：$X_1 \sim \text{Binomial}(n_1,p)$、$X_2 \sim \text{Binomial}(n_2,p)$ 独立，$Y = X_1 + X_2$：

$$\phi_Y(t) = (pe^t+q)^{n_1}(pe^t+q)^{n_2} = (pe^t+q)^{n_1+n_2}$$

右边是 $\text{Binomial}(n_1+n_2, p)$ 的 MGF，由唯一性：$Y \sim \text{Binomial}(n_1+n_2, p)$。

**例 3.35（泊松可加性）**：$Y_1 \sim \text{Poisson}(\lambda_1)$、$Y_2 \sim \text{Poisson}(\lambda_2)$ 独立：

$$\phi_Y(t) = e^{\lambda_1(e^t-1)}e^{\lambda_2(e^t-1)} = e^{(\lambda_1+\lambda_2)(e^t-1)}$$

所以 $Y \sim \text{Poisson}(\lambda_1 + \lambda_2)$。

> **白话解读**：MGF 证明可加性的套路统一：**独立和的 MGF = 乘积 → 凑成已知分布形式 → 由唯一性得结论**。这个套路在 CLT 证明里也会用到（正态 MGF 的收敛）。

## 6. 例题

**例 1（迭代期望）**：保险公司按 $X$（随机损失率）分层，每层损失 $Y|X = x \sim \text{Exp}(1/x)$，$X \sim \text{Uniform}(0,1)$。$E(Y) = E[E(Y|X)] = E(X) = 1/2$。

**例 2（全方差分解）**：$X \sim \text{Bernoulli}(1/2)$（$X = 0$ 或 1），$Y|X = 0 \sim N(0,1)$，$Y|X = 1 \sim N(10,1)$。$V(Y) = EV(Y|X) + VE(Y|X) = 1 + V(10X) = 1 + 100 \times 1/4 = 26$——组间差异 $VE(Y|X) = 25$ 主导。

**例 3（MGF 求矩）**：$X \sim N(\mu, \sigma^2)$，$\phi_X(t) = e^{\mu t + \sigma^2 t^2/2}$。$\phi'(0) = \mu$，$\phi''(0) = \mu^2 + \sigma^2$，$V(X) = \sigma^2$。

**例 4（伽马可加性）**：$X_i \sim \text{Gamma}(\alpha_i, \beta)$ 独立，$\phi_i(t) = (1-\beta t)^{-\alpha_i}$，乘积 $= (1-\beta t)^{-\sum\alpha_i}$，所以 $\sum_i X_i \sim \text{Gamma}(\sum_i \alpha_i, \beta)$。

**例 5（迷宫小老鼠，用迭代期望列方程）**：小老鼠进入迷宫起点，有三条等可能路径：第一条 2 步直接到出口；第二条 4 步回到起点；第三条 6 步回到起点。设 $T$ 为到达出口的总步数。由无记性（回到起点后情况与初始相同），$E[T|$选第二条$] = 4 + E[T]$，$E[T|$选第三条$] = 6 + E[T]$，故

$$E[T] = \frac13\cdot 2 + \frac13(4+E[T]) + \frac13(6+E[T]) = \frac{12}{3} + \frac{2}{3}E[T]$$

解得 $E[T]=12$。若改为"有记性"——走过的错路不再走（第二次回到起点时排除刚走过的那条路），则回到起点后只剩两条路径可选，$E[T]=\frac13\cdot2+\frac12(4+E[T])+\frac12(6+E[T])=\frac23+5+E[T]$ 会显得矛盾；正确列法是把"第一次选错"作为条件，最终解得 $E[T]=7$。差别在于无记性假设下"回到起点"后状态重置，而有记性下不是——这是迭代期望列方程时必须小心的地方。

## 7. 本节重点

> **本节重点**：
> - $E(X|Y=y)$ 是 $y$ 的函数；$E(X|Y)$ 是随机变量——两者要区分。
> - 迭代期望 $E(Y) = E[E(Y|X)]$；全方差 $V(Y) = EV(Y|X) + VE(Y|X)$（EVVE）——分层/回归的核心分解。
> - MGF：$\phi_X(t) = E(e^{tX})$；$\phi^{(k)}(0) = E(X^k)$；独立和的 MGF = 乘积；MGF 唯一确定分布。
> - 用 MGF 证明可加性（二项、泊松、伽马）的"乘积 → 唯一性"套路。
> - **常见坑**：$E(X|Y)$ 当随机变量处理时忘了它依赖 $Y$；全方差法则第二项是 $V[E(Y|X)]$ 不是 $E[V(Y|X)]$；MGF 不存在时硬用（换特征函数）。
