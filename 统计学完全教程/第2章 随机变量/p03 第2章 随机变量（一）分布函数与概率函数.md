## 1. 核心概念

统计学和数据挖掘都跟数据有关。怎么把样本空间和事件跟数据联系起来？**纽带就是随机变量**——把试验结果映射成实数，之后就能用微积分处理概率。

本篇（第 2 章第 1-2 节）建立描述随机变量的两套核心工具：
- **CDF（累积分布函数）**：对离散/连续都适用的统一描述；
- **PMF / PDF（概率函数/密度函数）**：离散和连续各自的"局部密度"。

第 2 章余下内容（常见分布、多元分布、变换）在 p04-p08 展开。

## 2. 随机变量的定义

**定义 2.1**：随机变量是映射 $X: \Omega \to \mathbb{R}$，该映射对每一个结果 $\omega$ 赋予实值 $X(\omega)$。

**例 2.2**：抛一枚硬币 10 次，$X(\omega)$ = 序列中正面出现的次数。若 $\omega = HHTHTHHTTT$，则 $X(\omega) = 6$。

**例 2.3**：$\Omega = \{(x,y) : x^2 + y^2 \le 1\}$（单位圆盘），随机取一点 $\omega = (x,y)$。随机变量的例子：$X(\omega) = x$，$Y(\omega) = y$，$Z(\omega) = x+y$，$W(\omega) = \sqrt{x^2+y^2}$。

给定随机变量 $X$ 和实直线子集 $A$，定义 $X^{-1}(A) = \{\omega : X(\omega) \in A\}$，并记：

$$P(X \in A) = P(X^{-1}(A)) = P(\{\omega : X(\omega) \in A\})$$

$$P(X = x) = P(X^{-1}(x)) = P(\{\omega : X(\omega) = x\})$$

> **注意**：$X$ 是随机变量（大写），$x$ 是 $X$ 的某一特定取值（小写）。这个大小写约定全书通用。

> **白话解读**：在绝大多数概率课程里样本空间很少被提及，直接从随机变量着手。但要清楚样本空间确实存在，位于事件的背后。严格来说随机变量必须是**可测映射**（附录），初学可忽略。

**例 2.4**：抛硬币两次，$X$ = 正面次数。

| $\omega$ | $P(\{\omega\})$ | $X(\omega)$ | | $x$ | $P(X = x)$ |
|---|---|---|---|---|---|
| TT | 1/4 | 0 | | 0 | 1/4 |
| TH | 1/4 | 1 | | 1 | 1/2 |
| HT | 1/4 | 1 | | 2 | 1/4 |
| HH | 1/4 | 2 | | | |

## 3. 累积分布函数 CDF

### 3.1 定义

**定义 2.5**：随机变量 $X$ 的**累积分布函数**（CDF）是函数 $F_X: \mathbb{R} \to [0,1]$：

$$F_X(x) = P(X \le x) \quad (2.1)$$

有时用 $F$ 代替 $F_X$。

**例 2.6**：抛均匀硬币两次，$X$ = 正面次数。$P(X=0) = P(X=2) = 1/4$，$P(X=1) = 1/2$。CDF：

$$F_X(x) = \begin{cases} 0, & x < 0, \\ 1/4, & 0 \le x < 1, \\ 3/4, & 1 \le x < 2, \\ 1, & x \ge 2 \end{cases}$$

> **白话解读**：CDF 是"阶梯函数"，在 $X$ 的每个取值点跳一次。$F_X(1.4) = 0.75$——因为 $X$ 只取 0、1、2，$P(X \le 1.4) = P(X \le 1) = 3/4$。注意右连续、非降。

### 3.2 CDF 的性质（定理 2.8）

从实直线映射到 $[0,1]$ 的函数 $F$ 是某个概率 $P$ 的 CDF，当且仅当 $F$ 满足 3 个条件：

1. **非降**：$x_1 < x_2 \Rightarrow F(x_1) \le F(x_2)$；
2. **规范化**：$\lim_{x \to -\infty} F(x) = 0$，$\lim_{x \to +\infty} F(x) = 1$；
3. **右连续**：$F(x) = F(x^+)$ 对所有 $x$ 成立，其中 $F(x^+) = \lim_{y \downarrow x} F(y)$。

**证明要点**（右连续部分）：取 $y_1 > y_2 > \cdots$ 且 $y_i \downarrow x$，令 $A_i = (-\infty, y_i]$，$A = (-\infty, x]$，则 $A_1 \supset A_2 \supset \cdots$ 且 $A = \bigcap_i A_i$，由概率连续性定理 1.8：$P(A_i) \to P(A)$，即 $F(y_i) \to F(x)$。

**反向结论**（$F$ 满足三条件 ⇒ 是某随机变量的 CDF）需借助实分析工具，不要求掌握证明。

### 3.3 CDF 完全决定分布（定理 2.7）

令 $X$ 的 CDF 为 $F$，$Y$ 的 CDF 为 $G$。如果对所有 $x$ 有 $F(x) = G(x)$，则对所有（可测）集合 $A$ 有：

$$P(X \in A) = P(Y \in A)$$

> **白话解读**：CDF 包含了随机变量的**所有**信息。两个随机变量 CDF 相同 ⇔ 同分布。

### 3.4 用 CDF 计算概率（引理 2.15）

令 $F$ 为 $X$ 的 CDF：

1. $P(X = x) = F(x) - F(x^-)$，其中 $F(x^-) = \lim_{y \uparrow x} F(y)$；
2. $P(x < X \le y) = F(y) - F(x)$；
3. $P(X > x) = 1 - F(x)$。

## 4. 离散型随机变量与概率函数

**定义 2.9**：如果 $X$ 取值为可数的值 $\{x_1, x_2, \cdots\}$，则 $X$ 是**离散的**。定义 $X$ 的**概率函数**（或概率密度函数，PMF）为：

$$f_X(x) = P(X = x)$$

对 $x \in \mathbb{R}$，$f_X(x) \ge 0$ 且 $\sum_i f_X(x_i) = 1$。CDF 与 PMF 的关系：

$$F_X(x) = P(X \le x) = \sum_{x_i \le x} f_X(x_i)$$

> **脚注**：集合有限或者能与整数建立一一对应关系，则集合是**可数的**。偶数、奇数、有理数都是可数的；$(0,1)$ 之间的实数不可数。

**例 2.10**：例 2.6 的概率函数：

$$f_X(x) = \begin{cases} 1/4, & x = 0, \\ 1/2, & x = 1, \\ 1/4, & x = 2, \\ 0, & \text{其他} \end{cases}$$

## 5. 连续型随机变量与概率密度函数

**定义 2.11**：如果存在函数 $f_X$ 使得对所有 $x$ 有 $f_X(x) \ge 0$、$\int_{-\infty}^{\infty} f_X(x)dx = 1$，并且对任意 $a \le b$：

$$P(a < X < b) = \int_a^b f_X(x)dx \quad (2.2)$$

则 $X$ 是**连续型随机变量**，$f_X$ 称为**概率密度函数（PDF）**。且有：

$$F_X(x) = \int_{-\infty}^{x} f_X(t)dt, \quad f_X(x) = F_X'(x)$$

（后者在 $F_X$ 可微的点成立。）

**例 2.12**：$X \sim \text{Uniform}(0,1)$（$(0,1)$ 均匀分布）：

$$f_X(x) = \begin{cases} 1, & 0 \le x \le 1, \\ 0, & \text{其他} \end{cases}, \quad F_X(x) = \begin{cases} 0, & x < 0, \\ x, & 0 \le x \le 1, \\ 1, & x > 1 \end{cases}$$

### 5.1 连续型的常见坑（课本"注意！"）

1. **对任意 $x$ 有 $P(X = x) = 0$**——不要将 $f(x)$ 看成 $P(X = x)$，那只对离散型成立。连续情形下通过**求 PDF 的积分**得到概率。
2. **PDF 可以大于 1**（离散 PMF 不行）。例：$f(x) = 5$（$x \in [0, 1/5]$），积分为 1，是合法 PDF。
3. **PDF 可以是无界的**。例：$f(x) = \frac{2}{3}x^{-1/3}$（$0 < x < 1$）无界但 $\int f = 1$。

**例 2.13**：$f(x) = \frac{1}{(1+x)^2}$（$x \ge 0$），验证 $\int f(x)dx = 1$，是 PDF。

**例 2.14**：$f(x) = \frac{1}{1+x}$（$x \ge 0$），$\int_0^\infty \frac{dx}{1+x} = \ln(\infty) = \infty$，**不是** PDF。

**例 2.15（连续 CDF 性质）**：若 $X$ 连续，则 $F(b) - F(a) = P(a < X < b) = P(a \le X < b) = P(a < X \le b) = P(a \le X \le b)$——端点是 0 概率，加不加都行。

## 6. 分位数函数

**定义 2.16**：令 $X$ 的 CDF 为 $F$，**逆 CDF** 或**分位数函数**定义为：

$$F^{-1}(q) = \inf\{x : F(x) > q\}, \quad q \in [0,1]$$

若 $F$ 严格递增且连续，则 $F^{-1}(q)$ 是满足 $F(x) = q$ 的唯一实数 $x$。

- $F^{-1}(1/4)$ = **第一分位数**；
- $F^{-1}(1/2)$ = **中位数**；
- $F^{-1}(3/4)$ = **第三分位数**。

> **白话解读**：$F^{-1}(q)$ 回答"累积概率达到 $q$ 时，$X$ 至少多大"。后面置信区间里的 $z_{\alpha/2} = \Phi^{-1}(1 - \alpha/2)$ 就是标准正态的分位数函数（见 p15 第6章）。

> **同分布记号**：若 $F_X(x) = F_Y(x)$ 对所有 $x$ 成立，则 $X$ 和 $Y$ **同分布**，记 $X \stackrel{d}{=} Y$。注意这不表示 $X$ 和 $Y$ 相等：若 $P(X=1)=P(X=-1)=1/2$，$Y = -X$，则 $X \stackrel{d}{=} Y$ 但 $P(X = Y) = 0$。

## 7. 例题

**例 1（CDF 三性质检验）**：$F(x) = \begin{cases} 0, & x < 0, \\ x, & 0 \le x \le 1, \\ 1, & x > 1 \end{cases}$ 是非降、规范化、右连续的，是某个随机变量（Uniform(0,1)）的 CDF。

**例 2（用 CDF 算概率）**：$X \sim \text{Uniform}(0,1)$，$P(0.2 < X \le 0.7) = F(0.7) - F(0.2) = 0.7 - 0.2 = 0.5$；$P(X = 0.5) = F(0.5) - F(0.5^-) = 0.5 - 0.5 = 0$。

**例 3（分位数）**：$X \sim \text{Uniform}(0,1)$，$F(x) = x$，故 $F^{-1}(q) = q$。中位数 $= 1/2$，第一分位数 $= 1/4$。

**例 4（离散 CDF 阶梯）**：$P(X=2) = P(X=3) = 1/10$，$P(X=5) = 8/10$（习题 2.2）。$F$ 在 $x \in [2,3)$ 时为 0.1，在 $[3,5)$ 为 0.2，$x \ge 5$ 为 1。$P(2 < X \le 4.8) = F(4.8) - F(2) = 0.2 - 0.1 = 0.1$；$P(2 \le X \le 4.8) = F(4.8) - F(2^-) = 0.2 - 0 = 0.2$（注意 $2$ 是跳跃点，含不含端点有区别）。

## 8. 本节重点

> **本节重点**：
> - 随机变量是 $\Omega \to \mathbb{R}$ 的映射；$X$（随机变量）vs $x$（取值）的记号约定。
> - CDF 三性质（非降、规范化、右连续）是"是不是 CDF"的判定标准；CDF 决定分布。
> - 离散用 PMF $f_X(x) = P(X=x)$；连续用 PDF（积分得概率）。**连续型 $P(X=x) = 0$，PDF 可大于 1、可无界**。
> - 分位数 $F^{-1}(q) = \inf\{x : F(x) > q\}$；中位数 $= F^{-1}(1/2)$。
> - **常见坑**：把 $f(x)$ 当 $P(X=x)$；CDF 在跳跃点 $F(x)$ 与 $F(x^-)$ 的区别（含不含端点）。
