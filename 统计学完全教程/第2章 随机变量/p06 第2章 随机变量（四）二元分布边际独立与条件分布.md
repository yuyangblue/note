## 1. 核心概念

从本节开始，研究对象从单个随机变量扩展到**多个随机变量的联合**。核心问题：

- 联合分布如何描述？（二元分布）
- 只看其中一个变量时怎么办？（边际分布）
- 两个变量是否相互影响？（独立）
- 已知一个变量后，另一个的分布如何变化？（条件分布）

这些都是第 3 章条件期望、第 13-14 章回归与多变量模型的基础。

## 2. 二元分布

### 2.1 离散情形

给定两个离散随机变量 $X$ 和 $Y$，定义**联合密度函数**（联合概率函数）：

$$f(x,y) = P(X = x, Y = y)$$

记为 $f_{X,Y}$（想表述更清楚时）。满足 $f(x,y) \ge 0$ 且 $\sum_x \sum_y f(x,y) = 1$。

**例 2.18**：取值为 0、1 的两个随机变量 $X, Y$ 的二元分布：

| | $Y=0$ | $Y=1$ | |
|---|---|---|---|
| $X=0$ | 1/3 | 2/9 | 5/9 |
| $X=1$ | 2/9 | 4/9 | 6/9 |
| | 5/9 | 6/9 | 1 |

其中 $f(1,1) = P(X=1, Y=1) = 4/9$。

### 2.2 连续情形

**定义 2.19**：连续情形下，称 $f(x,y)$ 为 $(X,Y)$ 的 PDF，如果：

1. 对所有 $(x,y)$，$f(x,y) \ge 0$；
2. $\int_{-\infty}^{\infty}\int_{-\infty}^{\infty} f(x,y)dxdy = 1$；
3. 对任意集合 $A \subset \mathbb{R} \times \mathbb{R}$：$P((X,Y) \in A) = \iint_A f(x,y)dxdy$。

**联合 CDF**（离散/连续通用）：

$$F_{X,Y}(x,y) = P(X \le x, Y \le y)$$

**例 2.20（单位正方形均匀）**：$(X,Y)$ 为单位正方形上的均匀分布：

$$f(x,y) = \begin{cases} 1, & 0 \le x \le 1, 0 \le y \le 1, \\ 0, & \text{其他} \end{cases}$$

$P(X < 1/2, Y < 1/2)$ = 区域面积 $= 1/4$（概率 = 密度在子集上的积分 = 面积）。

**例 2.21**：$f(x,y) = x + y$（$0 \le x, y \le 1$）：

$$\int_0^1\int_0^1 (x+y)dxdy = \frac{1}{2} + \frac{1}{2} = 1$$

**例 2.22（非矩形区域）**：$f(x,y) = cx^2y$，$x^2 \le y \le 1$。先定积分范围：$-1 \le x \le 1$，对固定 $x$，$x^2 \le y \le 1$：

$$1 = c\int_{-1}^1 x^2\left(\int_{x^2}^1 ydy\right)dx = c\int_{-1}^1 x^2\frac{1-x^4}{2}dx = \frac{4c}{21} \Rightarrow c = \frac{21}{4}$$

$$P(X \ge Y) = \frac{21}{4}\int_0^1\int_{x^2}^x x^2 y dydx = \frac{21}{4}\int_0^1 x^2\frac{x^2 - x^4}{2}dx = \frac{3}{20}$$

> **白话解读**：非矩形区域的二重积分关键是**画图定积分限**——固定一个变量，看另一个变量的取值范围（课本图 2.5）。这是最容易出错的地方。

## 3. 边际分布

**定义 2.23/2.25**：如果 $(X,Y)$ 有联合密度 $f_{X,Y}$，则 $X$ 的**边际概率密度函数**为：

- 离散：$f_X(x) = P(X = x) = \sum_y P(X = x, Y = y) = \sum_y f(x,y) \quad (2.4)$
- 连续：$f_X(x) = \int f(x,y)dy \quad (2.6)$

$Y$ 的边际类似（离散对 $x$ 求和、连续对 $x$ 积分）。边际分布函数记为 $F_X$ 和 $F_Y$。

**例 2.24**（离散）：$X$ 的边际 = 对应行的总和，$Y$ 的边际 = 对应列的总和。如 $f_X(0) = 3/10$，$f_X(1) = 7/10$。

**例 2.26**：$f_{X,Y} = e^{-(x+y)}$（$x,y \ge 0$），则 $f_X(x) = e^{-x}\int_0^\infty e^{-y}dy = e^{-x}$（指数分布）。

**例 2.27**：$f(x,y) = x + y$（$0 \le x,y \le 1$），则 $f_Y(y) = \int_0^1(x+y)dx = \frac{1}{2} + y$。

> **白话解读**：边际分布 = 把另一个变量"积分/求和掉"。像投影：联合分布在 $xy$ 平面上的分布，投到 $x$ 轴就是 $f_X$。

## 4. 独立随机变量

**定义 2.29**：如果对任意 $A$ 和 $B$ 有

$$P(X \in A, Y \in B) = P(X \in A)P(Y \in B) \quad (2.7)$$

则称 $X$ 和 $Y$ **独立**，记为 $X \amalg Y$；否则称相依，记 $X \not\amalg Y$。

原则上要对所有子集验证（2.7），但连续情形有简化：

**定理 2.30**：令 $X$ 和 $Y$ 有联合 PDF $f_{X,Y}$，则 $X \amalg Y$ 当且仅当

$$f_{X,Y}(x,y) = f_X(x)f_Y(y) \quad \text{对所有 } x, y$$

（脚注：密度可以在零测度集上无定义，严格陈述略。）

**定理 2.33（乘积判定）**：假设 $X$ 和 $Y$ 的范围是矩形（可能无穷），如果对函数 $g$ 和 $h$（不一定是密度）有 $f(x,y) = g(x)h(y)$ 成立，则 $X$ 和 $Y$ 独立。

**例 2.34**：$f(x,y) = 2e^{-(x+2y)}$（$x,y > 0$），范围是矩形 $(0,\infty) \times (0,\infty)$，写成 $f(x,y) = g(x)h(y)$，$g(x) = 2e^{-x}$，$h(y) = e^{-2y}$，所以 $X \amalg Y$。

**例 2.31（离散验证）**：联合分布 $f(0,0) = f(0,1) = f(1,0) = f(1,1) = 1/4$，边际都是 1/2，$f_X(x)f_Y(y) = f(x,y)$ 对所有 $(x,y)$ 成立 → 独立。若改为 $f(0,1) = 0$ 而其余 $1/2$（即 $f_X(0)f_Y(1) = 1/4 \ne f(0,1) = 0$）→ 不独立。

> **白话解读**：判断独立两条路——① 联合密度 = 边际密度乘积；② 联合密度可分解为"$x$ 的函数 × $y$ 的函数"且范围是矩形。注意 $g, h$ 不必是密度（常数因子可任意吸收）。

## 5. 条件分布

### 5.1 离散情形

**定义 2.35**：如果 $f_Y(y) > 0$，则**条件概率密度函数**为：

$$f_{X|Y}(x|y) = P(X = x | Y = y) = \frac{P(X = x, Y = y)}{P(Y = y)} = \frac{f_{X,Y}(x,y)}{f_Y(y)}$$

### 5.2 连续情形

**定义 2.36**：对连续情形（假设 $f_Y(y) > 0$）：

$$f_{X|Y}(x|y) = \frac{f_{X,Y}(x,y)}{f_Y(y)}, \quad P(X \in A | Y = y) = \int_A f_{X|Y}(x|y)dx$$

> **脚注**：严格说，条件事件 $\{Y = y\}$ 概率为 0，用 PDF 可以避免这一困境；高等课程有严格定义，这里当作定义接受即可。

**例 2.37**：$(X,Y)$ 为单位正方形均匀分布，$f_{X,Y} = 1$，$f_Y(y) = 1$（$0 \le y \le 1$），故 $f_{X|Y}(x|y) = 1$——给定 $Y = y$，$X \sim \text{Uniform}(0,1)$。

**例 2.38**：$f(x,y) = x + y$（$0 \le x,y \le 1$），$f_Y(y) = y + 1/2$：

$$f_{X|Y}(x|y) = \frac{x+y}{y + 1/2}, \quad P\left(X < \frac{1}{4}\Big|Y = \frac{1}{3}\right) = \int_0^{1/4}\frac{x + 1/3}{1/3 + 1/2}dx = \frac{11}{80}$$

**例 2.39（先 X 后 Y 的层次构造）**：$X \sim \text{Uniform}(0,1)$，给定 $X = x$，$Y|X=x \sim \text{Uniform}(x, 1)$。联合密度：

$$f_{X,Y}(x,y) = f_{Y|X}(y|x)f_X(x) = \begin{cases} \dfrac{1}{1-x}, & 0 < x < y < 1, \\ 0, & \text{其他} \end{cases}$$

$Y$ 的边际：

$$f_Y(y) = \int_0^y \frac{dx}{1-x} = -\ln(1-y), \quad 0 < y < 1$$

> **白话解读**：$f_{X,Y} = f_{Y|X}f_X$（"先 X 后 Y"的链条），这是**链式法则**，后面第 3 章条件期望、第 11 章贝叶斯、第 17 章贝叶斯网络都会用到。层次模型（先抽 $X$ 再按 $X$ 抽 $Y$）是它的典型应用。

## 6. 例题

**例 1（矩形分解判独立）**：$f(x,y) = \frac{21}{4}x^2 y$（$x^2 \le y \le 1$）。范围**不是**矩形（$y$ 的范围依赖 $x$），不能分解判独立；事实上也不独立（$\int f(x,y)dy = \frac{21}{8}x^2(1-x^4)$ 不等于 $f(x)$ 乘常数因子）。

**例 2（条件密度计算，例 2.40）**：$f(x,y) = \frac{21}{4}x^2y$（$x^2 \le y \le 1$），$f_X(x) = \frac{21}{8}x^2(1-x^4)$：

$$f_{Y|X}(y|x) = \frac{(21/4)x^2y}{(21/8)x^2(1-x^4)} = \frac{2y}{1-x^4}, \quad x^2 \le y \le 1$$

$$P\left(Y > \frac{3}{4}\Big|X = \frac{1}{2}\right) = \int_{3/4}^1 \frac{32y}{15}dy = \frac{7}{15}$$

**例 3（独立和的不等式，例 2.32）**：$X, Y$ 独立同密度 $f(x) = 2x$（$0 \le x \le 1$）：

$$P(X + Y \le 1) = 4\int_0^1 x\left(\int_0^{1-x} ydy\right)dx = 4\int_0^1 x\frac{(1-x)^2}{2}dx = \frac{1}{6}$$

（用 $f(x,y) = f_X(x)f_Y(y) = 4xy$ 在三角区域 $x + y \le 1$ 上积分。）

## 7. 本节重点

> **本节重点**：
> - 联合分布：离散 $f(x,y) = P(X=x,Y=y)$；连续 $P((X,Y)\in A) = \iint_A f$；非矩形区域积分要**画图定限**。
> - 边际分布：$f_X(x) = \sum_y f(x,y)$ 或 $\int f(x,y)dy$（"消掉另一个变量"）。
> - 独立：$f_{X,Y} = f_X f_Y$ ⇔ $X \amalg Y$；矩形范围 + 密度可分解 $g(x)h(y)$ ⇒ 独立。
> - 条件分布：$f_{X|Y}(x|y) = f_{X,Y}(x,y)/f_Y(y)$；链式法则 $f_{X,Y} = f_{Y|X}f_X$。
> - **常见坑**：非矩形区域积分限写错；密度可分解但范围非矩形（不独立）；把 $f_Y(y)$ 和 $f_{Y|X}(y|x)$ 混淆。
