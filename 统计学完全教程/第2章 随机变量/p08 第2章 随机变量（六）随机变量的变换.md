## 1. 核心概念

已知 $X$ 的分布，想知道 $Y = r(X)$ 的分布——这就是**随机变量的变换**问题。例如 $Y = X^2$、$Y = e^X$、$Y = X_1 + X_2$、$Y = \max\{X_1, X_2\}$。

**为什么重要**：统计中大量用到变换——估计量的函数（Delta 方法）、标准化 $Z = (X-\mu)/\sigma$、概率积分变换（生成随机数）都是变换问题。

---

## 2. 离散情形的变换

离散情形很简单：$Y = r(X)$ 的概率函数为：

$$f_Y(y) = P(Y = y) = P(r(X) = y) = P(\{x : r(x) = y\}) = P(X \in r^{-1}(y))$$

**例 2.45**：$P(X = -1) = P(X = 1) = 1/4$，$P(X = 0) = 1/2$，令 $Y = X^2$：

- $P(Y = 0) = P(X = 0) = 1/2$；
- $P(Y = 1) = P(X = 1) + P(X = -1) = 1/2$（两个原像合并到一个 $y$）（同型例题见 [[概率论MIT/笔记/02-离散随机变量/L11-2.3-离散函数分布|L11-2.3 例 1]]）。

| $x$ | $f_X(x)$ | | $y$ | $f_Y(y)$ |
|---|---|---|---|---|
| -1 | 1/4 | | 0 | 1/2 |
| 0 | 1/2 | | 1 | 1/2 |
| 1 | 1/4 | | | |

> **白话解读**：离散变换 = "合并原像"：$Y = y$ 的概率是把所有满足 $r(x) = y$ 的 $x$ 的概率**加起来**。注意 $Y$ 的取值通常比 $X$ 少（变换不是一一对应）。

## 3. 连续情形的变换：三步法

连续情形稍难，课本给出**求变换分布的 3 个步骤**：

1. **对每个 $y$，求集合** $A_y = \{x : r(x) \le y\}$；
2. **求 CDF**：

$$F_Y(y) = P(Y \le y) = P(r(X) \le y) = P(\{x : r(x) \le y\}) = \int_{A_y} f_X(x)dx \quad (2.11)$$

3. **PDF**：$f_Y(y) = F_Y'(y)$（同样的两步法用于连续导出分布见 [[概率论MIT/笔记/04-随机变量进一步专题/L11 导出分布#2.3 单调情形的通用公式|L11 §2.3]]）。

**例 2.46（指数取对数）**：$f_X(x) = e^{-x}$（$x > 0$），$F_X(x) = 1 - e^{-x}$，令 $Y = \ln X$。$A_y = \{x : x \le e^y\}$：

$$F_Y(y) = P(\ln X \le y) = P(X \le e^y) = F_X(e^y) = 1 - e^{-e^y}$$

$$f_Y(y) = e^y e^{-e^y}, \quad y \in \mathbb{R}$$

（这是 Gumbel 型分布——指数变量的对数。）

**例 2.47（均匀取平方，注意分段）**：$X \sim \text{Uniform}(-1, 3)$，$Y = X^2$。$Y$ 取值范围 $(0,9)$，分两段：

- (i) $0 < y < 1$：$A_y = [-\sqrt{y}, \sqrt{y}]$，$F_Y(y) = \frac{1}{4} \cdot 2\sqrt{y} = \frac{1}{2}\sqrt{y}$；
- (ii) $1 \le y < 9$：$A_y = [-1, \sqrt{y}]$，$F_Y(y) = \frac{1}{4}(\sqrt{y} + 1)$。

微分得：

$$f_Y(y) = \begin{cases} \dfrac{1}{4\sqrt{y}}, & 0 < y < 1, \\ \dfrac{1}{8\sqrt{y}}, & 1 < y < 9, \\ 0, & \text{其他} \end{cases}$$

> **白话解读**：三步法的核心是**正确写出 $A_y$**——解不等式 $r(x) \le y$。$r$ 不是单调时（如 $x^2$）要分段考虑 $A_y$ 的形状。**求 CDF 再求导**是通用手段，比硬记公式稳。

## 4. 严格单调函数的变换公式

当 $r$ 是严格增函数或严格减函数时，$r$ 有反函数 $s = r^{-1}$，此时可以证明：

$$f_Y(y) = f_X(s(y))\left|\frac{ds(y)}{dy}\right| \quad (2.12)$$

> **白话解读**：单调情形有现成公式：把 $x = s(y)$ 代入 $f_X$，再乘以"雅可比"（导数绝对值）。直观理解：密度在做变量替换时要乘上坐标变换的伸缩因子。

**例（$Y = e^X$，习题 2.13）**：$X \sim N(0,1)$，$s(y) = \ln y$，$ds/dy = 1/y$：

$$f_Y(y) = \varphi(\ln y) \cdot \frac{1}{y} = \frac{1}{y\sqrt{2\pi}}\exp\left\{-\frac{(\ln y)^2}{2}\right\}, \quad y > 0$$

（$Y$ 服从**对数正态分布**。）

### 4.1 非单调变换：多原像求和公式

当 $r$ 不单调时，对每个 $y$，方程 $r(x)=y$ 可能有多个原像 $x_1(y), x_2(y), \cdots$。把每个原像贡献的密度按雅可比加权后相加：

$$f_Y(y) = \sum_{i:\, r(x_i)=y} f_X(x_i(y))\left|\frac{dx_i(y)}{dy}\right|$$

例 2.47 中 $0<y<1$ 有两个原像 $x=\pm\sqrt y$，各贡献 $\frac14\cdot\frac{1}{2\sqrt y}$，合计 $\frac{1}{4\sqrt y}$；$1\le y<9$ 只剩 $x=\sqrt y$ 一个原像，贡献减半为 $\frac{1}{8\sqrt y}$——与三步法求导结果一致。

## 5. 多个随机变量的变换

有时更关心多个随机变量的变换：$X/Y$、$X+Y$、$\max\{X,Y\}$、$\min\{X,Y\}$。令 $Z = r(X,Y)$，求 $f_Z$ 的步骤与单变量相同：

1. **对每个 $z$，求集合** $A_z = \{(x,y) : r(x,y) \le z\}$；
2. **求 CDF**：

$$F_Z(z) = P(Z \le z) = P(r(X,Y) \le z) = \iint_{A_z} f_{X,Y}(x,y)dxdy$$

3. **PDF**：$f_Z(z) = F_Z'(z)$。

**例 2.48（两个均匀之和 = 三角分布）**：$X_1, X_2 \sim \text{Uniform}(0,1)$ 独立，$Y = X_1 + X_2$。联合密度 $f(x_1,x_2) = 1$（单位正方形）。$A_y = \{x_1 + x_2 \le y\}$：

- $0 < y \le 1$：$A_y$ 是三角形（顶点 $(0,0),(y,0),(0,y)$），面积 $y^2/2$；
- $1 < y < 2$：单位正方形减去小三角形（顶点 $(1,y-1),(1,1),(y-1,1)$），面积 $1 - (2-y)^2/2$。

$$F_Y(y) = \begin{cases} 0, & y < 0, \\ \dfrac{y^2}{2}, & 0 \le y \le 1, \\ 1 - \dfrac{(2-y)^2}{2}, & 1 \le y < 2, \\ 1, & y \ge 2 \end{cases}$$

微分得 PDF（**三角分布**）：

$$f_Y(y) = \begin{cases} y, & 0 \le y \le 1, \\ 2 - y, & 1 \le y \le 2, \\ 0, & \text{其他} \end{cases}$$

> **白话解读**：两个独立均匀之和是"三角形"密度。这是中心极限定理的最早体验——**两个**均匀之和还远不是正态，但**很多个**独立随机变量之和就逼近正态了（见 p14 第5章 CLT）。

### 5.1 独立和的卷积公式

若 $X,Y$ 独立，$Z=X+Y$ 的密度可由"卷积"直接写出：

$$f_Z(z) = \int_{-\infty}^{\infty} f_X(x)\,f_Y(z-x)\,dx$$

积分中 $x$ 的有效区间由 $f_X(x)>0$ 与 $f_Y(z-x)>0$ 同时成立决定（即两支持集沿 $x$ 轴的交集）。对两均匀 $(0,1)$ 情形：

- $0<z\le 1$：$x\in(0,z)$，$f_Z(z)=\int_0^z 1\cdot 1\,dx = z$；
- $1<z<2$：$x\in(z-1,1)$，$f_Z(z)=\int_{z-1}^1 1\cdot 1\,dx = 2-z$。

![[p08_convolution_regions.png]]

卷积的几何含义：把 $f_Y$ 沿横轴翻转再平移到 $z$，与 $f_X$ 重叠部分的面积就是 $f_Z(z)$。这也是"独立和的密度是各自密度的卷积"这一术语的来源（卷积公式与独立和的系统讲解见 [[概率论MIT/笔记/04-随机变量进一步专题/L12 独立随机变量之和与协方差#2.1 独立同分布求和（卷积的性质）|L12 §2.1]]）。

### 5.2 max/min 的一般公式

设 $X_1,\cdots,X_n$ iid，CDF 为 $F$，密度为 $f$。令 $M=\max_i X_i$、$L=\min_i X_i$：

$$F_M(z) = P(M\le z) = P(X_1\le z,\cdots,X_n\le z) = F(z)^n,\qquad f_M(z) = nF(z)^{n-1}f(z)$$

$$F_L(z) = 1 - P(L>z) = 1 - P(X_1>z,\cdots,X_n>z) = 1 - (1-F(z))^n$$

$$f_L(z) = n(1-F(z))^{n-1}f(z)$$

**灯串例题**：10 个灯泡寿命 iid $\sim\text{Exp}(1000)$（均值 1000 小时）。

- **串联**（任一坏则灯灭）：寿命 $=L=\min_i T_i$。$F_L(t)=1-(1-e^{-t/1000})^{10}$，$f_L(t)=10\cdot e^{-t/1000}\cdot(1-e^{-t/1000})^9$。用无记性：第一个灯坏前平均要等 $1000/10=100$ 小时（并联 10 个速率为 $1/1000$ 的指数过程，合并速率 $10/1000$），即 $E[L]=100$。
- **并联**（全坏才灭）：寿命 $=M=\max_i T_i$。$P(M>1000)=1-(1-e^{-1})^{10}\approx1-(0.632)^{10}\approx0.998$——十个并联几乎必然能撑过 1000 小时。

### 5.3 二维 Jacobian 变换

对二维变换 $(U,V)=g(X,Y)=(g_1(X,Y),g_2(X,Y))$，若 $g$ 是一一映射，反函数 $(x,y)=g^{-1}(u,v)$ 的雅可比行列式为

$$J = \det\frac{\partial(x,y)}{\partial(u,v)} = \begin{vmatrix} \partial x/\partial u & \partial x/\partial v \\ \partial y/\partial u & \partial y/\partial v \end{vmatrix}$$

则 $(U,V)$ 的联合密度为

$$f_{U,V}(u,v) = f_{X,Y}\!\left(x(u,v), y(u,v)\right)\,|J|$$

**例**：$(X,Y)\sim\text{Uniform}(0,1)^2$，令 $U=X+Y$、$V=X-Y$。反解 $x=(u+v)/2$、$y=(u-v)/2$，雅可比矩阵 $=\begin{pmatrix}1/2 & 1/2\\1/2 & -1/2\end{pmatrix}$，$|J|=1/2$。原单位正方形被映射为顶点在 $(0,0),(1,1),(2,0),(1,-1)$ 的菱形，面积 $=1/|J|=2$，恰好是正方形面积 1 在该变换下的拉伸倍数。

![[p08_jacobian_diamond.png]]

**多原像情形：$(M,L)=(\max,\min)$ 的联合密度**。上面公式要求 $g$ 是一一映射；而 $(t_1,t_2)\mapsto(\max,\min)$ 是**二对一**的——$(x,y)$ 与 $(y,x)$ 映到同一点，原像必须逐个求和（一元非单调公式见 4.1，其中的 $\sum_i$ 就是为这种情况准备的）。以 $T_1,T_2$ iid $U(0,1)$ 为例，$0<y<x<1$ 时两个原像的雅可比绝对值都是 1、$f_T\equiv1$，故

$$f_{M,L}(x,y)=1\cdot1+1\cdot1=2,\qquad 0<y<x<1$$

系数 $2$ 就是 $2!$：$n$ 个 iid 变量的次序统计量 $(T_{(1)},\cdots,T_{(n)})$ 在 $t_1<\cdots<t_n$ 上的密度为 $n!\prod_i f(t_i)$，此处 $n=2$。所以不必记"这里有个 2"，$n$ 元时系数自然升为 $n!$。

**用分布函数验算更稳**（不必先数原像有几个）：$0<y<x<1$ 时 $F(x,y)=P(T_1,T_2\le x)-P(y<T_1,T_2\le x)=x^2-(x-y)^2$，两次偏导得 $\frac{\partial^2 F}{\partial x\partial y}=2$；且 $\int_0^1\!\int_0^x 2\,dy\,dx=\int_0^1 2x\,dx=1$，密度积分为 1，自检通过。

**注意：密度是常数不代表独立**。完整写法是 $f=2\cdot\mathbf{1}\{0<y<x<1\}$，示性函数里两个变量缠在一起，拆不成 $g(x)h(y)$；若取 $g\equiv\sqrt2$、$h\equiv\sqrt2$，乘出来是覆盖整个正方形的常数 2，把三角形外那一半也算了进去。判据看支撑集：**独立变量的联合支撑集必为直积（矩形）**，而这里是三角形——$y$ 的取值范围 $(0,x)$ 随 $x$ 变化，本身就是依赖。边缘一算即可确认：$f_M(x)=2x$、$f_L(y)=2(1-y)$，乘积 $4x(1-y)\neq2$。二者还正相关：$\mathrm{Cov}(M,L)=E[ML]-E[M]E[L]=\frac14-\frac{2}{3}\cdot\frac{1}{3}=\frac{1}{36}>0$，正好是"独立 $\Rightarrow$ 不相关、不相关 $\nRightarrow$ 独立"的实例。

### 5.4 非负截断（ReLU）产生点质量

连续输入经 $Y=X^+=\max(0,X)$ 这样的非负截断后，$P(Y=0)=P(X\le 0)=F_X(0)>0$——即便 $X$ 是连续型，$Y$ 在 0 处也出现一个"点质量"，不再是纯连续型。例如 $X\sim N(0,1)$ 时 $P(Y=0)=1/2$，其余正半轴上密度为 $\varphi(y)$。这是"连续分布经非光滑变换后出现离散成分"的最简实例，深度学习里 ReLU 激活层输出的分布就是这种混合形式（混合随机变量的分解见 [[概率论MIT/笔记/03-一般随机变量/L09 事件条件作用与联合连续随机变量#1.2 混合随机变量|L09 §1.2]]）。

## 6. 例题

**例 1（min 的分布，习题 2.7）**：$X, Y \sim \text{Uniform}(0,1)$ 独立，$Z = \min\{X,Y\}$。用 $P(Z > z) = P(X > z)P(Y > z) = (1-z)^2$：

$$F_Z(z) = 1 - (1-z)^2, \quad f_Z(z) = 2(1-z), \quad 0 < z < 1$$

（对比 max：$F_{\max}(z) = z^2$。**min 看右尾、max 看左尾**是这类题的套路。）

**例 2（max 的分布，习题 2.21）**：$X_1, \cdots, X_n \sim \text{Exp}(\beta)$ iid，$Y = \max_i X_i$。$Y \le y \iff$ 所有 $X_i \le y$：

$$F_Y(y) = (1 - e^{-y/\beta})^n, \quad f_Y(y) = \frac{n}{\beta}e^{-y/\beta}(1-e^{-y/\beta})^{n-1}$$

**例 3（概率积分变换，习题 2.15，重要！）**：$X$ 有连续严格递增 CDF $F$，令 $Y = F(X)$，则 $Y \sim \text{Uniform}(0,1)$。反过来，$U \sim \text{Uniform}(0,1)$ 且 $X = F^{-1}(U)$，则 $X \sim F$（逆变换采样的验证见 [[概率论MIT/笔记/04-随机变量进一步专题/L11 导出分布#5. 补充：模拟（S11.1，p120）|L11 §5]]）。

> **白话解读**：这是**万能随机数生成器**——任何分布都能用"先抽均匀、再代入逆 CDF"生成。也说明任何连续随机变量都能"均匀化"（这在 Bootstrap、copula、正态性检验里都有用）。

**例 4（和差积商的分布思路）**：$X, Y \sim \text{Uniform}(0,1)$ 独立，求 $X-Y$ 与 $X/Y$ 的 PDF（习题 2.20）——同样按三步法：写 $A_z$、积分、求导。

## 7. 本节重点

> **本节重点**：
> - 离散变换 = 合并原像概率；连续变换 = 三步法（写 $A_y$ → 求 CDF → 求导）。
> - 单调变换公式 $f_Y(y) = f_X(s(y))|s'(y)|$（雅可比因子）。
> - 多元变换同一套路：$F_Z(z) = \iint_{A_z} f_{X,Y}$；两个均匀之和 → 三角分布。
> - **概率积分变换**：$F(X) \sim \text{Uniform}(0,1)$，$F^{-1}(U) \sim F$——万能随机数生成器。
> - **常见坑**：非单调变换忘分段；$A_y$ 边界写错；min 用右尾、max 用左尾记反；忘乘雅可比 $|ds/dy|$。
