## 1. 核心概念

**统计量**（statistic）是数据 $x^n = (x_1,\cdots,x_n)$ 的函数 $T(x^n)$。**充分统计量**（sufficient statistic）是"包含了数据中全部信息"的统计量。CMU 讲义 L10 给了两种动机，正好对应本篇的两条主线：

- **数据约简视角**：$n$ 个数压缩成一个（或几个）数而不损失任何推断所需的信息——例如 Bernoulli 样本里，推断 $p$ 只需要知道 $\sum X_i$，不需要知道具体哪次是 1；
- **估计改进视角**：不依赖充分统计量的估计量都可以被改进（Rao–Blackwell 定理，§5）。

注意：充分统计量是**参数模型里的概念**——"信息够不够"是相对模型 $\{f(x^n;\theta)\}$ 而言的；非参数模型没有这个结构。

## 2. 充分统计量：从似然形状定义

**定义 9.32**：记 $x^n \leftrightarrow y^n$，如果 $f(x^n;\theta) = c\,f(y^n;\theta)$，其中常数 $c$ 可以依赖 $x^n, y^n$ 但**不依赖 $\theta$**。统计量 $T(x^n)$ 是**充分的**，如果 $T(x^n) \leftrightarrow T(y^n)$ 蕴涵 $x^n \leftrightarrow y^n$。

注意：$x^n \leftrightarrow y^n$ 意味着基于 $x^n$ 的似然函数与基于 $y^n$ 的似然函数**形状完全相同**（只差一个与 $\theta$ 无关的倍数）。粗略地说：**只告诉你 $T(x^n)$ 就能算出似然函数**，则 $T$ 是充分的——似然是似然方法的全部原料（点估计、置信区间、检验都从它出发），能复现似然 = 不丢任何推断信息。

- **例 9.33**：$X_1,\cdots,X_n \sim \text{Bernoulli}(p)$，$\mathcal{L}(p) = p^S(1-p)^{n-S}$，$S = \sum X_i$，所以 $S$ 是充分的。
- **例 9.34**：$X_1,\cdots,X_n \sim N(\mu,\sigma)$，$T = (\overline{X}, S)$（$S^2$ 为样本方差）：

> [!note]- 解答
> $$f(x^n;\mu,\sigma) = \left(\frac{1}{\sigma\sqrt{2\pi}}\right)^n \exp\left\{-\frac{nS^2}{2\sigma^2}\right\}\exp\left\{-\frac{n(\overline{X}-\mu)^2}{2\sigma^2}\right\}$$
> 最后的表达式只通过 $T$ 依赖数据，故 $T = (\overline{X},S)$ 充分。注意 $U = (17\,\overline{X}, S)$ 也是充分统计量——知道 $U$ 就能算出 $T$ 再算似然。

**充分统计量远不是唯一的**。对 $N(\mu,\sigma^2)$ 模型比较四个统计量：

| 统计量 | 是否充分 | 说明 |
|---|---|---|
| $T_1 = (X_1,\cdots,X_n)$（全数据） | 是 | 信息最全但没有任何压缩 |
| $T_2 = (\overline{X},S)$ | 是 | 证明了 |
| $T_3 = \overline{X}$ | 否 | 只知道 $\overline{X}$ 算不出 $\mathcal{L}(\mu,\sigma)$（$S$ 丢了） |
| $T_4 = (\overline{X},S,X_3)$ | 是 | 比 $T_2$ 多带的 $X_3$ 是冗余信息 |

直观上 $T_2$ 比 $T_1$、$T_4$ 都"更简洁"：$T_2$ 是 $T_1$ 的函数、也是 $T_4$ 的函数（如 $T_2 = g(T_4)$，$g(a_1,a_2,a_3) = (a_1,a_2)$）。"最简洁"的正式化就是最小充分统计量（§4）。

## 3. 常用定义与因子分解定理

课本随后给出了**通常教科书里的定义**：

> $T$ 是充分的，当且仅当给定 $T(x^n) = t$ 时 $x^n$ 的分布**不依赖 $\theta$**：$f(x_1,\cdots,x_n \mid t;\theta) = h(x_1,\cdots,x_n, t)$，$h$ 与 $\theta$ 无关。

**概念**：两个定义说的是同一件事——"数据里关于 $\theta$ 的信息全部装在 $T$ 里"，一个从似然形状说，一个从条件分布说。**实际验证几乎总用下面的因子分解**：

**定理 9.40（因子分解定理）**：$T$ 充分当且仅当存在函数 $g(t,\theta)$ 与 $h(x)$ 使

$$f(x^n;\theta) = g(t(x^n),\theta)\,h(x^n)$$

**思路**：密度 = 只通过 $T$ 和 $\theta$ 的部分 × 与 $\theta$ 无关的部分。判断时把联合密度"拆"成这两块即可；拆不出来就不充分。

- **例 9.39（两枚硬币，用条件分布定义验证）**：$X = (X_1,X_2) \sim \text{Bernoulli}(p)$，$T = X_1 + X_2$：

> [!note]- 解答
> $T$ 取三个值，逐一检查给定 $T = t$ 时 $(X_1,X_2)$ 的条件分布：
> - $T = 0$：$\mathbb{P}(X_1=0,X_2=0 \mid t=0) = 1$，其余为 0；
> - $T = 1$：$\mathbb{P}(X_1=0,X_2=1\mid t=1) = \mathbb{P}(X_1=1,X_2=0\mid t=1) = 1/2$，其余为 0；
> - $T = 2$：$\mathbb{P}(X_1=1,X_2=1\mid t=2) = 1$，其余为 0。
>
> 三种情形都不含 $p$，故 $T$ 充分。

- **例 9.41（同一题用因子分解）**：$f(x_1,x_2;\theta) = \theta^{x_1}(1-\theta)^{1-x_1}\theta^{x_2}(1-\theta)^{1-x_2} = \underbrace{\theta^t(1-\theta)^{2-t}}_{g(t,\theta)}\cdot\underbrace{1}_{h(x_1,x_2)}$，故 $T = X_1+X_2$ 充分。

## 4. 最小充分统计量

**定义 9.35**：统计量 $T$ 是**最小充分的**（minimal sufficient），如果 (i) 它充分；(ii) 它是**每一个**其他充分统计量的函数。

**思路**：充分统计量按"谁能算出谁"有个偏序（$T_2$ 是 $T_4$ 的函数），最小充分的就是这个偏序下最"粗"的——压缩到极限、再压就丢信息的那个。

**定理 9.36（划分判据）**：如果下面的条件成立，则 $T$ 最小充分：

$$T(x^n) = T(y^n) \ \text{当且仅当} \ x^n \leftrightarrow y^n$$

统计量把结果集分成若干类（划分）；这个判据说：**最小充分统计量的划分恰好就是"$\leftrightarrow$"这个等价关系的划分**——两个数据集的似然形状相同当且仅当它们落进同一类。

- **例 9.37（划分视角）**：$X_1,X_2 \sim \text{Bernoulli}(\theta)$。取 $V = X_1$、$T = X_1+X_2$、$U = (T, X_1)$，三者诱导的划分为：
  - $V \to \{(0,0),(0,1)\}, \{(1,0),(1,1)\}$：太粗，**不充分**（同一类里的似然形状不同）；
  - $T \to \{(0,0)\}, \{(0,1),(1,0)\}, \{(1,1)\}$：充分，且是**最小充分**（与 $\leftrightarrow$ 的划分一致：$(0,1)$ 与 $(1,0)$ 的似然 $\theta(1-\theta)$ 相同）；
  - $U \to$ 四个单点集：充分但不最小——$x^n = (1,0)$ 与 $y^n = (0,1)$ 满足 $x^n \leftrightarrow y^n$，但 $U(x^n) \ne U(y^n)$，划分比必要的更细。
  另外 $W = 17\,T$ 诱导与 $T$ 相同的划分，也最小充分——最小充分统计量在可逆变换下不唯一，但**划分唯一**。

- **例 9.38（常用结论）**：$N(\mu,\sigma^2)$ 模型中 $T = (\overline{X},S)$ 最小充分；Bernoulli 模型中 $T = \sum X_i$ 最小充分；Poisson 模型中 $T = \sum X_i$ 最小充分。而 $T = (\sum X_i, X_1)$ 充分但非最小充分；$T = X_1$ 不充分。

CMU 讲义 L11 给了一个**更好用的比值判据**（定理 9.36 的操作版）：$T$ 最小充分当且仅当 $f(x^n;\theta)/f(y^n;\theta)$ 与 $\theta$ 无关 $\iff T(x^n) = T(y^n)$。判断时直接算似然比、看比值何时与 $\theta$ 无关。

## 5. Rao–Blackwell 定理

充分性在点估计上的直接后果：**估计量不应该依赖充分统计量以外的数据，否则可以被改进**。记估计量的 MSE 为 $R(\theta,\widehat{\theta}) = \mathbb{E}_\theta(\widehat{\theta}-\theta)^2$。

**定理 9.42（Rao–Blackwell）**：设 $\widehat{\theta}$ 是估计量，$T$ 是充分统计量。定义新估计量

$$\widetilde{\theta} = \mathbb{E}(\widehat{\theta} \mid T)$$

则对每个 $\theta$，$R(\theta,\widetilde{\theta}) \le R(\theta,\widehat{\theta})$。

**思路**：这是条件方差公式（全方差法则）的直接应用——把估计量对充分统计量取条件期望，条件方差那一块被整块消掉，只留下"围绕 $T$ 的随机性"（全方差法则见 [[统计学完全教程/第3章 数学期望/p11 第3章 数学期望（三）条件期望与矩母函数.md#4. 条件方差与全方差法则|p11 §4]]；条件期望的机制见 [[统计学完全教程/第3章 数学期望/p11 第3章 数学期望（三）条件期望与矩母函数.md#2. 条件期望的定义|p11 §2]]）。

- **例 9.43**：掷两次硬币。$\widehat{\theta} = X_1$ 是无偏估计，但不依赖充分统计量 $T = X_1+X_2$。Rao–Blackwell 化：$\widetilde{\theta} = \mathbb{E}(X_1 \mid T) = (X_1+X_2)/2$，MSE 至少和 $X_1$ 一样小。$n$ 次投掷同理：$\widehat{\theta} = X_1 \Rightarrow \widetilde{\theta} = \mathbb{E}(X_1 \mid \sum X_i) = \frac{1}{n}\sum X_i = \overline{X}$，MSE 更小。

注意：Rao–Blackwell 只保证 MSE 不增；$\widetilde{\theta}$ 是否无偏取决于条件期望是否把偏差也消掉（本例中恰好保持无偏）。它与 §4 的分工：最小充分统计量告诉你**用哪个**统计量，Rao–Blackwell 告诉你**怎么用**它改进手头的估计量。

## 6. 指数族

### 6.1 定义与例子

**概念**：迄今学过的大多数参数模型是同一大类模型的特例。称 $\{f(x;\theta) : \theta \in \Theta\}$ 为（单参数）**指数族**（exponential family），如果存在函数 $\eta(\theta), B(\theta), T(x), h(x)$ 使

$$f(x;\theta) = h(x)\,e^{\eta(\theta)T(x) - B(\theta)}$$

由因子分解定理立刻看出 $T(X)$ 充分，称**自然充分统计量**（natural sufficient statistic）。

- **例 9.44（Poisson）**：$f(x;\theta) = \theta^x e^{-\theta}/x! = \frac{1}{x!}e^{x\log\theta - \theta}$，是指数族，$\eta(\theta) = \log\theta$、$B(\theta) = \theta$、$T(x) = x$、$h(x) = 1/x!$。
- **例 9.45（Binomial）**：$f(x;\theta) = \binom{n}{x}\theta^x(1-\theta)^{n-x} = \binom{n}{x}\exp\left\{x\log\frac{\theta}{1-\theta} + n\log(1-\theta)\right\}$，$\eta(\theta) = \log\frac{\theta}{1-\theta}$、$B(\theta) = -n\log(1-\theta)$、$T(x) = x$、$h(x) = \binom{n}{x}$。

**规则**：IID 样本的联合密度仍是指数族，且自然充分统计量取和：

$$f(x^n;\theta) = h_n(x^n)\,e^{\eta(\theta)T_n(x^n) - B_n(\theta)}, \qquad T_n(x^n) = \sum_{i=1}^n T(X_i), \quad B_n(\theta) = nB(\theta)$$

这意味着 $\sum_i T(X_i)$ 充分——指数族模型的充分统计量永远是**和**的形式。

**例 9.46（反例：Uniform 不是指数族）**：$X_1,\cdots,X_n \sim \text{Unif}(0,\theta)$，$f(x^n;\theta) = \theta^{-n}\,\mathbb{1}(x_{(n)} \le \theta)$，$T(x^n) = x_{(n)} = \max\{X_1,\cdots,X_n\}$ 是充分的；但 $T(x^n) \ne \sum_i T(X_i)$ 的形式，所以**不可能是指数族**——呼应 p16 例 9.12：支撑依赖参数的模型连指数族都进不了，MLE 的正则理论（p18）自然也不适用。

### 6.2 自然参数与 log-partition 函数

把指数族改写成

$$f(x;\eta) = h(x)\,e^{\eta T(x) - A(\eta)}, \qquad A(\eta) = \log\int h(x)\,e^{\eta T(x)}\,dx$$

其中 $\eta = \eta(\theta)$ 称**自然参数**（natural parameter），$A(\eta)$ 称 log-partition 函数（对数配分函数；CMU 讲义 L12 的叫法）。例如 Poisson 可写成 $f(x;\eta) = e^{\eta x - e^\eta}/x!$，自然参数 $\eta = \log\theta$。

**定理 9.47（log-partition 生成矩）**：若 $X$ 的密度属于指数族，则

$$\mathbb{E}(T(X)) = A'(\eta), \qquad \mathbb{V}(T(X)) = A''(\eta)$$

> [!note]- 为什么对 $A$ 求导就出矩
> $A(\eta)$ 是归一化因子的对数：$e^{A(\eta)} = \int h\,e^{\eta T}dx$。两边对 $\eta$ 求导（积分号下求导）：
> $$e^{A}A' = \int T\,h\,e^{\eta T}dx \ \Longrightarrow\ A' = \mathbb{E}(T)$$
> 再求导一次得 $A'' = \mathbb{E}(T^2) - (\mathbb{E}(T))^2 = \mathbb{V}(T)$。这与 MGF 生成矩是同一机制——指数族不过是把 MGF 的思想内建到密度里（MGF 求矩的技巧见 [[统计学完全教程/第3章 数学期望/p11 第3章 数学期望（三）条件期望与矩母函数.md#5.2 矩的生成|p11 §5.2]]）。

**例（用定理 9.47 秒算 Poisson）**：$f(x;\eta) = e^{\eta x - e^\eta}/x!$，$A(\eta) = e^\eta$，故 $\mathbb{E}(X) = A'(\eta) = e^\eta = \theta$，$\mathbb{V}(X) = A''(\eta) = \theta$——不用积分，均值方差一步出来。

### 6.3 多参数形式

$\theta = (\theta_1,\cdots,\theta_k)$ 为向量时，$f(x;\theta)$ 具有指数族形式指

$$f(x;\theta) \approx h(x)\exp\left\{\sum_{j=1}^k \eta_j(\theta)T_j(x) - B(\theta)\right\}$$

同样 $T = (T_1,\cdots,T_k)$ 充分；IID 样本的充分统计量是 $(\sum_i T_1(X_i),\cdots,\sum_i T_k(X_i))$。矩公式相应变成：$\mathbb{E}(T(X)) = \nabla A$（偏导向量）、$\mathbb{V}(T(X)) = \nabla^2 A$（二阶导矩阵）。

**例 9.48（正态）**：$f(x;\mu,\sigma)$ 可写成 $\exp\left\{\frac{\mu}{\sigma^2}x - \frac{1}{2\sigma^2}x^2 - \frac{\mu^2}{2\sigma^2} - \log(\sigma\sqrt{2\pi})\right\}$，是两参数指数族，$(T_1,T_2) = (x, x^2)$；$n$ 个 IID 样本下 $(\sum_i X_i, \sum_i X_i^2)$ 充分。

注意：把 $\eta$ 取作自由坐标后，正态的自然参数是 $\left(\eta_1,\eta_2\right) = \left(\frac{\mu}{\sigma^2}, -\frac{1}{2\sigma^2}\right)$——$\sigma^2$ 前面的**负号**决定了自然参数空间的形状（$\eta_2 < 0$），这也是多参数理论里要区分"自然参数空间"的原因。

## 7. 例题

**例 1（Cauchy 位置参数的最小充分统计量，CMU L11 例 3）**
$p(x;\theta) = \dfrac{1}{\pi\left(1+(x-\theta)^2\right)}$，$x \in \mathbb{R}$。找出最小充分统计量。

> [!note]- 解答
> 用比值判据。对两组数据 $x^n, y^n$：
> $$\frac{p(y^n;\theta)}{p(x^n;\theta)} = \frac{\prod_{j=1}^n \{1+(x_j-\theta)^2\}}{\prod_{i=1}^n \{1+(y_i-\theta)^2\}}$$
> 这是 $\theta$ 的 $2n$ 次多项式之比；它与 $\theta$ 无关当且仅当分子分母是同一个多项式（差一个常数倍），即 $\{x_j\}$ 与 $\{y_j\}$ 作为**多重集合**相同——也就是次序统计量 $(x_{(1)},\cdots,x_{(n)}) = (y_{(1)},\cdots,y_{(n)})$。故最小充分统计量是次序统计量（排序后的全部样本）。
> 对比：正态的 $\mu$ 用 $\overline{X}$ 就够了，Cauchy 却要保留整个排好的样本——重尾分布对均值不敏感，位置信息散在每个观测里。

**考点**：[[#4. 最小充分统计量|最小充分统计量]]

**例 2（用因子分解验证正态的最小充分性，课本例 9.34 / 9.38）**
验证 $T = (\overline{X},S)$ 是 $N(\mu,\sigma^2)$ 模型的充分统计量，再用划分直觉说明它是最小充分的。

> [!note]- 解答
> 充分性即 §2 例 9.34 的分解：$f(x^n;\mu,\sigma) = g((\overline{X},S);\mu,\sigma)\cdot 1$，$h \equiv 1$，因子分解成立。
> 最小充分性：两个数据集的似然相同当且仅当 $\sum x_i$ 与 $\sum x_i^2$ 分别相等（似然通过这两个和依赖数据），而 $(\overline{X},S)$ 恰好是 $(\sum X_i, \sum X_i^2)$ 的一一变换——划分一致，故最小充分。任何真充分统计量都能从 $(\overline{X},S)$ 算出似然，反之 $(\overline{X},S)$ 可由它们构造，符合定义 9.35 的 (ii)。

**考点**：[[#2. 充分统计量：从似然形状定义|充分统计量]]、[[#4. 最小充分统计量|最小充分统计量]]

**例 3（几何分布的充分统计量，CMU HW06 同型题）**
$X_1,\cdots,X_n \sim \text{Geometric}(\theta)$，$f(x;\theta) = (1-\theta)^{x-1}\theta$，$x = 1,2,\cdots$。找最小充分统计量。

> [!note]- 解答
> 联合密度 $f(x^n;\theta) = \theta^n (1-\theta)^{\sum_i x_i - n} = \underbrace{\theta^n(1-\theta)^{T-n}}_{g(T,\theta)}\cdot 1$，$T = \sum_i X_i$。因子分解成立，故 $T$ 充分；似然通过 $T$ 依赖数据且 $T$ 是数据的函数，比值判据给出最小充分。这也是指数族逻辑的实例：$\text{Geometric}(\theta) = \exp\{(x-1)\log(1-\theta) + \log\theta\}$，自然充分统计量 $T(x) = x-1$，取和即 $\sum X_i - n$。

**考点**：[[#3. 常用定义与因子分解定理|因子分解定理]]、[[#6.1 定义与例子|指数族]]

**例 4（Rao–Blackwell 的一步改进）**
$X_1,X_2 \sim \text{Bernoulli}(\theta)$，估计量 $\widehat{\theta} = X_1$。对充分统计量 $T = X_1 + X_2$ 做 Rao–Blackwell 化，并比较两者的方差。

> [!note]- 解答
> $\widetilde{\theta} = \mathbb{E}(X_1 \mid T)$。$T = 0$ 或 $2$ 时 $X_1$ 由 $T$ 完全确定（0 或 1）；$T = 1$ 时两个状态对称，$\mathbb{E}(X_1\mid T=1) = 1/2$。统一写成 $\widetilde{\theta} = (X_1+X_2)/2 = \overline{X}$。
> 方差：$\mathbb{V}(X_1) = \theta(1-\theta)$，而 $\mathbb{V}(\overline{X}) = \theta(1-\theta)/2$——方差精确减半，MSE 相应下降。$n$ 次投掷时改进到 $\overline{X}$，方差 $\theta(1-\theta)/n$。

## 8. 本节重点

> **本节重点**：
> - 充分统计量 = 只凭 $T(x^n)$ 就能算出似然函数的统计量；验证几乎总用因子分解定理 $f(x^n;\theta) = g(t,\theta)h(x^n)$。
> - 充分统计量不唯一（$U = (17\overline{X},S)$ 也充分）；最"粗"的是最小充分统计量，用划分判据 $T(x)=T(y) \iff x \leftrightarrow y$ 或似然比判据识别。
> - Rao–Blackwell：估计量对充分统计量取条件期望，MSE 不增——不依赖充分统计量的估计量都可以免费改进。
> - 指数族 $f = h\,e^{\eta T - B}$：自然充分统计量取和；log-partition 函数求导给矩（$\mathbb{E}(T) = A'$，$\mathbb{V}(T) = A''$）；Uniform 这类支撑依赖参数的模型不是指数族。
> - **常见坑**：把"充分"当成"够用就行"（它是相对给定模型的信息概念）；对最小充分统计量只验证充分性而不验证最小性；忘记充分统计量的可逆变换仍是充分的（划分才是不变量）。
