    01 DP 基础 & 记忆化搜索¶

    动态规划（Dynamic Programming，DP）的核心思想：把大问题拆成互相重叠的小问题，每个小问题只算一次，存起来复用。 学会判断「什么时候能用 DP」+「怎么设计状态」+「记忆化搜索怎么过渡到递推」，是后面所有 DP（背包/线性/区间/树形/状压/数位）的地基。

    大白话引入¶

    想象你从教学楼顶楼走楼梯下楼，每一级台阶都能跳到第 1 或第 2 级。问：到第 n 级台阶有多少种走法？

    暴力枚举每一条路，台阶一多直接爆炸（2 的 n 次方）。但你会发现一个关键事实：到第 10 级的走法数 = 到第 9 级的走法数 + 到第 8 级的走法数。因为最后一步要么从 9 跳下来，要么从 8 跳下来。

    这就是 DP：一个大问题的答案，由几个更小问题的答案拼出来，而这些更小的答案会被反复用到。把它们存起来，就不用重复算了。

    思维启发 & 思考流程¶

    做题人拿到一道题，怎么判断它能不能用 DP？

    1. 看到"求方案数 / 最大值 / 最小值 / 可行性" —— 先警觉：可能是 DP
    2. 问自己：大问题能不能由小问题推出？ —— 例如「到第 10 级」由「到第 9 级 + 到第 8 级」推出
    3. 问自己：小问题之间有没有重叠？ —— 算「到第 9 级」时要用「到第 8 级」，算「到第 10 级」时又要用「到第 8 级」→ 重叠了，值得存
    4. 确定"状态" —— 描述一个问题的最小单位是什么？（这里是：到了第几级台阶）
    5. 确定"转移" —— 状态之间怎么互相推？（f[i] = f[i-1] + f[i-2]）
    6. 确定"边界" —— 最小的状态答案是什么？（f[1] = 1, f[2] = 2）

    直觉对不对要验证：先写个朴素的递归（能跑但慢），再想想哪里重复计算了，然后加个数组缓存——这就是记忆化搜索；再把递归改成循环——就是递推 DP。两条路殊途同归，但递推更快（没有递归调用开销）也更不容易爆栈。

    关键判断准则¶

    特征 能用 DP 不能用 DP
    子问题重叠 ✅ 大量重叠（如斐波那契） ❌ 子问题完全独立（如快排分治）
    无后效性 ✅ 当前决策只影响未来，不看过去怎么来的 ❌ 状态里必须携带历史信息（如"路径不能重复经过"就要用状压）
    最优子结构 ✅ 大问题最优解由小问题最优解组成 ❌ 局部最优推不出全局最优（贪心失效的例子）

    核心讲解¶

    1. 什么是状态、转移、边界¶

    • 状态：dp[i] 表示"规模为 i 的子问题的答案"。设计状态是 DP 最难的一步——状态要无后效（不关心过去怎么到达）、信息够用（能推出未来）。
    • 转移方程：dp[i] 怎么由更小的 dp[j] 算出来。
    • 边界条件：最小的状态，直接给值，不靠转移。漏了边界 = 全盘皆错。

    2. 自顶向下：记忆化搜索¶

    先写递归，再用一个数组记录算过的结果，遇到算过的直接返回（剪掉重复计算）。

    优点：只算真正用到的状态，代码和递归思维一致，好写。 缺点：递归有函数调用开销；深度太大（如 1e6）会爆栈。

    3. 自底向上：递推¶

    从小到大把状态全算一遍，最后取答案。没有递归开销，竞赛首选。

    4. 斐波那契三连（同一个问题三种写法）¶

    • 朴素递归：O(2^n)，算 f(50) 就要等一年 —— 问题在于同一个 f(k) 被重复算了无数遍
    • 记忆化递归：O(n)，每个 f(k) 只算一次
    • 递推循环：O(n)，常数更小，还能滚动数组优化到 O(1) 空间

    5. 复杂度¶

    • 时间：状态数 × 每个状态的转移代价
    • 空间：状态数（可优化：滚动数组只保留需要的几层）

    #include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const int MAXN = 100;
ll memo[MAXN];          // 记忆化数组，-1 表示没算过

// 写法一：朴素递归（错误示范，指数级爆炸）
ll fib_naive(int n) {
    if (n <= 1) return n;
    // 同一个 f(n-2) 会在 f(n) 和 f(n-1) 里各算一遍，层层叠叠重复计算
    return fib_naive(n - 1) + fib_naive(n - 2);
}

// 写法二：记忆化搜索（自顶向下）
ll fib_memo(int n) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n];       // 算过就直接返回，不再递归
    return memo[n] = fib_memo(n - 1) + fib_memo(n - 2);
}

// 写法三：递推（自底向上，竞赛实战首选）
ll fib_dp(int n) {
    if (n <= 1) return n;
    ll a = 0, b = 1;                         // 滚动：只保留前两个
    for (int i = 2; i <= n; i++) {
        ll c = a + b;                        // f[i] = f[i-1] + f[i-2]
        a = b; b = c;
    }
    return b;
}

int main() {
    memset(memo, -1, sizeof(memo));          // 初始化记忆化数组为"未计算"
    int n = 50;
    // cout << fib_naive(n) << endl;         // 会卡死，别试
    cout << fib_memo(n) << endl;             // 12586269025
    cout << fib_dp(n) << endl;               // 12586269025
    return 0;
}

    复杂度分析：朴素递归 O(2^n)（n=50 就卡死）；记忆化和递推都是 O(n) 时间、O(1) 空间（递推版滚动后只存两个变量）。

    #include <bits/stdc++.h>
using namespace std;

// 到第 n 级台阶，每次可以走 1 级或 2 级，有多少种走法？
// 状态：dp[i] = 到第 i 级的走法数
// 转移：最后一步从 i-1 来，或从 i-2 来 → dp[i] = dp[i-1] + dp[i-2]
// 边界：dp[1] = 1（走一步），dp[2] = 2（1+1 或 2）
int main() {
    int n;
    cin >> n;
    vector<long long> dp(n + 1, 0);
    dp[1] = 1;
    if (n >= 2) dp[2] = 2;                    // 注意 n=1 时不能访问 dp[2]，要判边界
    for (int i = 3; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];        // 不加 long long 的话 n=46 就开始溢出 int
    }
    cout << dp[n] << endl;
    return 0;
}

    坑： - n=1 时直接输出 dp[1]=1，不要访问 dp[2] - 答案增长快，用 long long - 这里和斐波那契唯一区别是边界：dp[1]=1, dp[2]=2（斐波那契是 f[1]=1, f[2]=1）

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 505;
int a[MAXN][MAXN];          // 三角形数字
int memo[MAXN][MAXN];       // memo[i][j] = 从 (i,j) 出发到底部的最大和，-1 表示没算
int n;

// 记忆化搜索：自顶向下，但先算下面的
int dfs(int i, int j) {
    if (i == n) return a[i][j];              // 到底部了，只能取自己
    if (memo[i][j] != -1) return memo[i][j]; // 算过直接返回（关键：剪掉重复计算）
    int down = dfs(i + 1, j);                // 向下走
    int downRight = dfs(i + 1, j + 1);       // 向右下走
    return memo[i][j] = max(down, downRight) + a[i][j];  // 选大的那个
}

int main() {
    cin >> n;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= i; j++)
            cin >> a[i][j];
    memset(memo, -1, sizeof(memo));
    cout << dfs(1, 1) << endl;

    // 等价递推写法（自底向上）：
    // for (int i = n - 1; i >= 1; i--)
    //     for (int j = 1; j <= i; j++)
    //         a[i][j] += max(a[i+1][j], a[i+1][j+1]);  // 原地滚动，把下面的最大值累加上来
    // cout << a[1][1] << endl;
    return 0;
}

    复杂度分析：状态数 O(n²)，每个状态 O(1) 转移 → 总 O(n²)。n=500 时 25 万个状态，秒过；若用朴素 DFS 不记忆化，是 2^n 指数爆炸。
