    04 区间 DP¶

    区间 DP：状态是一段区间 [i, j]，转移靠两种模式——端点展开或划分点展开，把大区间拆成小区间合并。 经典问题：石子合并、括号匹配、回文串分割。 套路固定：先枚举区间长度，再枚举左端点，再转移——三层循环。 进阶部分整理自 B 站《2026武汉联合集训-区间DP》（up：番茄君爱吃西红柿）。

    大白话引入¶

    有一排石子，每个石子有个重量。每次只能合并相邻的两堆，代价是两堆重量之和。问全部合并成一堆的最小总代价。

    关键在"相邻"两个字：如果不是相邻，直接贪心挑最轻的两堆就行；但相邻限制了合并只能在"挨着的两块"之间发生，于是问题自然变成区间的——合并 [i, j] 区间，最后一步一定是把某个断点 k 左边和右边分别合并好，再合成一整块。

    进阶玩法（对应进阶篇）： - 只关心区间两端字符怎么处理（插入、配对）→ 端点展开模式 - 区间可以在任意位置切成两半分别求解 → 划分点展开模式 - 状态里还要记住"人站在哪" → 加一维的端点展开（关路灯）

    思维启发 & 思考流程¶

    先手算一个最小例子¶

    石子合并，a = [1, 3, 5, 2]，合并成一堆的最小代价是多少？

    手算几种合并顺序：

    1
2
3
    先合并 5+2=7   → [1,3,7]   再合并 1+3=4 → [4,7]   最后 4+7=11  → 总 7+4+11 = 22
先合并 1+3=4   → [4,5,2]   再合并 4+5=9 → [9,2]   最后 9+2=11  → 总 4+9+11 = 24
先合并 3+5=8   → [1,8,2]   再合并 8+2=10 → [1,10]  最后 1+10=11 → 总 8+10+11 = 29

    最优是 22。注意：不同的合并顺序代价差很多，所以必须"枚举所有切法"——这就是区间 DP 的动机。

    关键观察：最后一步一定有个"分界点"¶

    不管前面怎么合并，最后一次一定是把某两堆合成一堆。这两堆分别对应"左边的连续一段"和"右边的连续一段"，所以中间一定存在一个分界点 k：

    • 左边 [i, k] 已经合并成一堆（最小代价 dp[i][k]）
    • 右边 [k+1, j] 已经合并成一堆（最小代价 dp[k+1][j]）
    • 最后合并这两堆，代价是区间总和 sum(i, j)

    于是：dp[i][j] = min(dp[i][k] + dp[k+1][j]) + sum(i, j)，枚举所有 k。

    为什么必须按"区间长度从小到大"遍历？¶

    dp[i][j] 依赖的 dp[i][k] 和 dp[k+1][j] 都是更短的区间。如果按 i、j 从小到大普通遍历，算 dp[1][3] 时 dp[2][3] 可能还没算（因为 2 > 1，外层 i 还没走到 2）。所以外层必须是区间长度 len，保证算长区间前所有短区间都算完了。

    for (i = 1; i + len - 1 <= n; i++)  // 再枚举左端点
        j = i + len - 1;              // 右端点由长度定
        for (k = i; k < j; k++)       // 最后枚举断点（划分点展开）
            dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + cost);

    两种转移模式（总纲）¶

    区间 DP 的状态和遍历顺序几乎都是固定的，唯一要动脑的是转移。所有区间 DP 的转移只有两种模式（2026武汉联合集训课上的总结）：

    模式 做法 复杂度 适用
    A. 端点展开 只讨论区间两端元素怎么处理 O(n²) 决策只涉及两端（配对、插入、关灯）
    B. 划分点展开 枚举内部分界点 k，区间一分为二 O(n³) 最后一步可能发生在任意缝隙（合并类）

    怎么选模式？ 问自己：最后一步操作发生在"两端"还是"中间的任意缝隙"？只发生在两端 → 端点展开；可能发生在任意缝隙 → 划分点展开。选错会漏掉最优解（见下文石子合并的讨论）。

    基础篇：划分点展开¶

    1. 石子合并（线性版）¶

    状态：dp[i][j] = 合并区间 [i, j] 的最小代价 转移：dp[i][j] = min(dp[i][k] + dp[k+1][j]) + sum(i, j)，k ∈ [i, j-1] - sum(i, j) 是最后一次合并的代价（区间重量总和），用前缀和 O(1) 求 边界：dp[i][i] = 0（单堆不用合并）

    为什么不能用贪心？（集训课重点）

    直觉：每次合并相邻最小的两堆，局部最优。但局部最优不保证全局最优——两个小数合并后会变成一个大数，它立刻"污染"周围的邻居，迫使你下次不得不去合并其他大数。

    反例 4 3 2 4： - 贪心：先合并 3+2=5 → 4 5 4，再合并 4+5=9 → 9 4，最后 9+4=13，总代价 5+9+13 = 27 - 最优：先合并 4+3=7 → 7 2 4，再合并 2+4=6 → 7 6，最后 7+6=13，总代价 7+6+13 = 26 - 26 < 27，贪心失败 ✅

    为什么不能用端点展开？

    端点展开默认"最后一步只操作左端点或右端点"，也就是最后一次合并时，最左边（或最右边）的一堆是单独一堆。但石子合并的最后一步可以发生在任意缝隙——比如 4 3 2 4 的最优解，最后一次合并是 7（=4+3）和 6（=2+4），左右两端都不是单独的一堆。所以必须用划分点展开。

    #include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n + 1), pre(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        pre[i] = pre[i - 1] + a[i];       // 前缀和：sum(i,j) = pre[j] - pre[i-1]
    }

    // dp[i][j] = 合并 [i,j] 的最小代价；初始化为无穷大
    vector<vector<int>> dp(n + 1, vector<int>(n + 1, INT_MAX));
    for (int i = 1; i <= n; i++) dp[i][i] = 0;   // 单堆不用合并

    for (int len = 2; len <= n; len++) {         // 1. 区间长度从小到大（关键！）
        for (int i = 1; i + len - 1 <= n; i++) { // 2. 左端点
            int j = i + len - 1;                 //    右端点由长度决定
            for (int k = i; k < j; k++) {        // 3. 断点（划分点展开）
                dp[i][j] = min(dp[i][j],
                    dp[i][k] + dp[k + 1][j] + (pre[j] - pre[i - 1]));
                // 左边合并好 + 右边合并好 + 最后合并这两块的代价（区间和）
            }
        }
    }
    cout << dp[1][n] << endl;                    // 整个区间合并完的最小代价
    return 0;
}

    坑： - 初始化必须 INT_MAX（求最小值），否则全 0 - 断点 k 的范围是 [i, j-1]，不能取到 j（右边为空没意义） - 如果外层枚举 i、内层枚举 j，dp[2][3] 会在 dp[1][3] 之后才算 → 用错值。必须长度优先！

    复杂度分析：三层循环 O(n³)。n=500 → 1.25 亿次，C++ 勉强能过；n=1000 → 10 亿次会超时。

    2. 石子合并（环形版，P1880）¶

    石子摆成一圈。套路：破环成链——把数组复制一遍接在后面，长度 2n，然后做线性石子合并，答案取 min(dp[i][i+n-1])。

    #include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(2 * n + 1), pre(2 * n + 1, 0);
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        a[i + n] = a[i];                  // 破环成链：复制一份接后面
    }
    for (int i = 1; i <= 2 * n; i++) pre[i] = pre[i - 1] + a[i];

    // 同时算最大和最小
    vector<vector<int>> dpMin(2 * n + 1, vector<int>(2 * n + 1, INT_MAX));
    vector<vector<int>> dpMax(2 * n + 1, vector<int>(2 * n + 1, 0));
    for (int i = 1; i <= 2 * n; i++) dpMin[i][i] = 0;

    for (int len = 2; len <= n; len++) {         // 最长只算 n（环上区间长度不超过 n）
        for (int i = 1; i + len - 1 <= 2 * n; i++) {
            int j = i + len - 1;
            for (int k = i; k < j; k++) {
                int cost = pre[j] - pre[i - 1];
                dpMin[i][j] = min(dpMin[i][j], dpMin[i][k] + dpMin[k + 1][j] + cost);
                dpMax[i][j] = max(dpMax[i][j], dpMax[i][k] + dpMax[k + 1][j] + cost);
            }
        }
    }

    int ansMin = INT_MAX, ansMax = 0;
    for (int i = 1; i <= n; i++) {               // 枚举环的断开点（起点）
        ansMin = min(ansMin, dpMin[i][i + n - 1]);
        ansMax = max(ansMax, dpMax[i][i + n - 1]);
    }
    cout << ansMin << endl << ansMax << endl;
    return 0;
}

    坑：外层 len 最多到 n（不是 2n）——环上我们只需要长度为 n 的区间；枚举到 2n 会算多余区间浪费一倍时间。

    3. 括号匹配（最长合法括号子序列）¶

    #include <bits/stdc++.h>
using namespace std;

bool match(char a, char b) { return (a == '(' && b == ')') || (a == '[' && b == ']'); }

int main() {
    string s;
    cin >> s;
    int n = s.size();
    // dp[i][j] = 区间 [i,j] 内最多能匹配的括号对（下标 0 基）
    vector<vector<int>> dp(n, vector<int>(n, 0));

    for (int len = 2; len <= n; len++) {                 // 长度为 1 的区间答案是 0
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            if (match(s[i], s[j]))
                dp[i][j] = max(dp[i][j], dp[i + 1][j - 1] + 1);   // 首尾配对
            for (int k = i; k < j; k++)
                dp[i][j] = max(dp[i][j], dp[i][k] + dp[k + 1][j]); // 中间断开拼起来
        }
    }
    cout << dp[0][n - 1] * 2 << endl;    // 括号对数 × 2 = 匹配字符数
    return 0;
}

    坑：首尾配对时别忘了还要和"断开拼起来"取 max——( [ ] ) 这种，首尾配对是 2 对，但 [ ] 内部先匹配再包外层，靠的就是两种转移取最大值。

    复杂度：O(n³)（断点循环），n ≤ 1000 可过。

    4. 插入最少字符变回文（P1435，端点展开）¶

    大白话：给一个字符串，只能往里面插字符，问最少插几个能变成回文串。比如 ab3bd，中间 b3b 已经是回文，两头 a...d 不配，左边补 d、右边补 a，插 2 次。

    核心思路：回文串只关心两端是否相等，典型的端点展开。

    • 状态：dp[i][j] = 子串 [i,j] 变成回文串所需的最少插入次数
    • 初始化：dp[i][i] = 0（单个字符已是回文）；其他为极大值
    • 转移：
    • s[i] == s[j]：两端相等，往里缩 → dp[i+1][j-1]（长度为 2 时是 0）
    • s[i] != s[j]：两种选择，取 min：
      • 在左端补一个 s[j]，处理剩下的 [i, j-1] → dp[i][j-1] + 1
      • 在右端补一个 s[i]，处理剩下的 [i+1, j] → dp[i+1][j] + 1
    • 答案：dp[1][n]

    #include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;
    int n = s.size();
    // dp[i][j] = 子串 [i,j] 变成回文串所需的最少插入次数
    vector<vector<int>> dp(n, vector<int>(n, INT_MAX));
    for (int i = 0; i < n; i++) dp[i][i] = 0;   // 单个字符已经是回文

    for (int len = 2; len <= n; len++) {
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            if (s[i] == s[j]) {
                // 两端相同：往里缩，看中间要插几个
                dp[i][j] = (len == 2) ? 0 : dp[i + 1][j - 1];
            } else {
                // 两端不同：左边补 s[j] 或 右边补 s[i]，处理剩下的部分 + 插的 1 个
                dp[i][j] = min(dp[i + 1][j], dp[i][j - 1]) + 1;
            }
        }
    }
    cout << dp[0][n - 1] << endl;
    return 0;
}

    坑：s[i] == s[j] 时注意长度为 2 的区间没有"中间"，直接是 0，不能访问 dp[i+1][j-1]（会越界）。两端不同时是 min(两个子问题) + 1，不是 min + 2——补一个字符只解决一端。

    复杂度：O(n²)，n ≤ 1000 直接过（P1435 的 n ≤ 1000）。

    5. 关路灯（P1220，端点展开 + 加维）¶

    大白话：一条街上有 n 盏路灯，每盏有功率。老张从位置 c 出发关灯，速度 1 m/s。关灯期间没关的灯持续耗电。问关完所有灯的最小总耗电。

    核心思路：状态是"关掉 [i,j] 区间的灯"，但人在左端还是右端决定了后续功耗，所以多开一维：

    • 状态：dp[i][j][0/1] = 关掉 [i,j] 的灯，人站在左端点(0) / 右端点(1) 的最小功耗
    • 初始化：dp[c][c][0] = dp[c][c][1] = 0（一开始在 c，直接关掉这盏，功耗 0）
    • 转移：从 [i+1,j] 或 [i,j-1] 扩展一格。扩展时人走的时间 × 还没关的灯的功率就是新增功耗
    • 答案：min(dp[1][n][0], dp[1][n][1])

    #include <bits/stdc++.h>
using namespace std;

int main() {
    int n, c;
    cin >> n >> c;
    vector<int> pos(n + 1), p(n + 1), pre(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        cin >> pos[i] >> p[i];
        pre[i] = pre[i - 1] + p[i];          // 功率前缀和
    }

    const long long INF = 1e18;
    // dp[i][j][0/1] = 关掉 [i,j] 的灯，人在左端点(0)/右端点(1) 的最小功耗
    vector<vector<array<long long, 2>>> dp(n + 2,
        vector<array<long long, 2>>(n + 2, {INF, INF}));
    dp[c][c][0] = dp[c][c][1] = 0;           // 一开始在 c，直接关掉这盏，功耗 0

    for (int len = 2; len <= n; len++) {
        for (int i = 1; i + len - 1 <= n; i++) {
            int j = i + len - 1;
            // 从 [i+1,j] 扩展到 [i,j]（这次要关左端 i）：
            // 走路的这段时间里灯 i 还亮着！未关功率 = [1..i] + [j+1..n]
            long long costL = pre[i] + (pre[n] - pre[j]);
            // 人在 i：上一站在 i+1（走 pos[i+1]-pos[i]）或上一站在 j（走 pos[j]-pos[i]）
            dp[i][j][0] = min(dp[i][j][0], dp[i + 1][j][0] + (pos[i + 1] - pos[i]) * costL);
            dp[i][j][0] = min(dp[i][j][0], dp[i + 1][j][1] + (pos[j] - pos[i]) * costL);
            // 从 [i,j-1] 扩展到 [i,j]（这次要关右端 j）：走路时灯 j 还亮着
            // 未关功率 = [1..i-1] + [j..n]
            long long costR = pre[i - 1] + (pre[n] - pre[j - 1]);
            // 人在 j：上一站在 i（走 pos[j]-pos[i]）或上一站在 j-1（走 pos[j]-pos[j-1]）
            dp[i][j][1] = min(dp[i][j][1], dp[i][j - 1][0] + (pos[j] - pos[i]) * costR);
            dp[i][j][1] = min(dp[i][j][1], dp[i][j - 1][1] + (pos[j] - pos[j - 1]) * costR);
        }
    }
    cout << min(dp[1][n][0], dp[1][n][1]) << endl;
    return 0;
}

    坑： - 功耗 = 走路时间 × 此刻还没关的灯的总功率。从 [i+1,j] 扩展到 [i,j] 时，走路的这段时间里灯 i 还亮着，功率必须算上它（costL）；关右端同理（costR）。如果统一用"区间外的功率"，每步漏掉一盏灯，答案偏小 - 距离用 pos 差，功率用前缀和差，两者相乘要开 long long（坐标 × 功率会超 int）

    复杂度：O(n²)，n ≤ 50 非常轻松；集训课提到可以斜率优化到 O(n)。

    6. 回文平衡括号子序列（2026 ICPC 陕西邀请赛）¶

    大白话：给一个只含 ( ) 的字符串，找一个最长的子序列，它是回文括号子序列：整体是平衡括号序列，且中间部分（去掉首尾）是回文括号序列。

    定义（竞赛新定义，注意区分）： - 回文括号序列（PBS）：空串；单个 ( 或 )；若 S 是 PBS，则 ( + S + ) 和 ) + S + ( 都是 PBS。直观理解：( 和 ) 互为镜像的"回文"。 - 平衡括号序列：标准栈匹配（空、(S)、ST 拼接）。 - 回文括号子序列 = 整体平衡 + 中间 PBS。

    关键观察：整体平衡 → 首字符是 (、尾字符是 )。中间部分是"平衡且回文"的 PBS，记作 BPBS（balanced PBS）。BPBS 的生成规则：空串；S 是 BPBS → ( S ) 是 BPBS；S 是 BPBS → ) S ( 也是 BPBS（这个反包裹也是合法的，因为 )S( 对括号类型做镜像后依然自对称）。

    • 状态：dp[i][j] = 区间 [i,j] 内最长的 BPBS 长度
    • 转移（子序列可以不取端点，所以两种跳过 + 两种包裹）：
    • 跳过：dp[i+1][j]、dp[i][j-1]
    • 包裹：若两端能配对成 PBS 包裹（( 配 ) 或 ) 配 (），dp[i+1][j-1] + 2
    • 答案：枚举最外层 (i, j) 满足 s[i]=='(' && s[j]==')'，取 max(dp[i+1][j-1] + 2)——因为题目要求整体平衡，最外层必须是 ( 和 )

    #include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;
    int n = s.size();
    // dp[i][j] = 区间 [i,j] 内最长的"平衡且回文"括号子序列长度（BPBS）
    // BPBS 生成规则：空串；S 是 BPBS → "(" S ")" 或 ")" S "(" 也是 BPBS
    vector<vector<int>> dp(n, vector<int>(n, 0));

    for (int len = 2; len <= n; len++) {
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            // 子序列可以不取端点：跳过左端点 / 跳过右端点
            dp[i][j] = max(dp[i + 1][j], dp[i][j - 1]);
            // 两端包裹成 BPBS：标准包裹 "(" S ")" 或 反包裹 ")" S "(" 都合法
            if ((s[i] == '(' && s[j] == ')') || (s[i] == ')' && s[j] == '('))
                dp[i][j] = max(dp[i][j], dp[i + 1][j - 1] + 2);
        }
    }

    // 题目的"回文括号子序列"要求整体平衡：最外层必须是 ( ... )
    // 所以枚举最外层端点，中间部分取任意 BPBS
    int ans = 0;
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++)
            if (s[i] == '(' && s[j] == ')')
                ans = max(ans, dp[i + 1][j - 1] + 2);
    cout << ans << endl;
    return 0;
}

    坑： - 反包裹 ")" S "(" 也是合法的 BPBS（)( 的镜像就是它自己），所以两端是 ) 和 ( 时同样可以包裹，别漏 - 最终答案不能直接取 dp[0][n-1]——BPBS 允许以 ) 开头（如 )(），但题目的"回文括号子序列"要求整体平衡，最外层必须是 ( 和 ) - 相邻两字符（len=2）时 dp[i+1][j-1] 访问的是未初始化的对角线下方区域，默认 0，正好等于"中间为空"，不用特判

    复杂度：O(n²)，n ≤ 5000 可过（5000² = 2500 万，C++ 轻松）。

    7. 拓展：四边形不等式优化¶

    划分点展开的转移如果满足四边形不等式（代价函数有单调性，如石子合并），可以把枚举断点 k 的循环剪枝到 O(n²)：记录每个区间的最优断点 opt[i][j]，下一层只在 [opt[i][j-1], opt[i+1][j]] 里找。竞赛中不常用，了解即可。
