    07 数位 DP¶

    数位 DP：按数字的每一位来 DP，解决"统计 [L, R] 范围内满足某条件的数的个数"。 经典问题：不含 4 / 不含 62 / windy 数 / 数位和整除。 核心套路：记忆化搜索 + limit 标记——从高位到低位逐位填数字，用 limit 判断当前位是否被上界卡住。 例 3 起整理自 B站《2026武汉联合培训 数位dp》（up：CruiseY_），笔记按 C++17 规范重写并验证。

    大白话引入¶

    数一数 1 到 1000 里有多少个数字不含 4？

    暴力从 1 数到 1000 当然可以，但换成 1 到 10^18 就彻底没戏了。换个思路：一位一位地构造数字。第一位可以是 0~9（不含 4），第二位也是 0~9（不含 4）……最后把符合条件的组合数出来。这不就是"按位做选择"嘛——天然适合 DP。

    难点只有一个：不能超过上界 N。比如 N=345，你第一位填了 3，第二位就只能填 0~4；但如果你第一位填了 2（已经比 3 小了），后面就随便填 0~9。这个"前面是否已经比上界小了"就是 limit 标记。

    类比：填数字像在"抽屉里选数字"，N 是天花板。你选的数字前缀只要比 N 小过一次，后面的抽屉就全打开了（0~9 随便挑）；如果一直贴着 N 走，每一步都被天花板压着（limit=1）。

    思维启发 & 思考流程¶

    1. 看到"统计 [L, R] 内满足条件的数" → 想到数位 DP，用前缀和技巧：f(R) - f(L-1)
    2. 把数字拆成每一位：存进数组，从最高位开始逐位填
    3. 设计 DFS 参数（这是数位 DP 的灵魂）：
    4. pos：当前填到第几位
    5. limit：前几位是否紧贴上界（1 = 被卡住，这一位有限制；0 = 随便填）
    6. 其他按题目加的：lead（前导零）、上一位是什么（windy 数 / 不含 62）、数位和等
    7. 记忆化：memo[pos][...] 只在 limit == 0 时才能存/取！
    8. 原因：limit=1 的情况每个数字只有一个，缓存了反而错；limit=0 时"后面随便填"的结果对任何前缀都通用
    9. 答案：f(R) - f(L-1)

    为什么必须 [L, R] 拆成 f(R) - f(L-1)？¶

    数位 DP 天然统计的是"0 到 N 的个数"。所以 [L, R] 的答案 = f(R) - f(L-1)，注意 L=0 时 L-1 = -1，solve(-1) 要返回 0。

    #include <bits/stdc++.h>
using namespace std;
typedef long long ll;              // 数位 DP 结果可能很大，统一用 long long

// 示意代码：只演示 dfs 骨架。
// digit/memo/len 的最小声明和空 main 只是为了能编译验证；
// 完整实现（拆位、多维度 memo、读入输出）见下面「例 1」。
const int len = 3;                 // 示意：N 有 3 位
int digit[len] = {3, 4, 5};        // 示意：N = 543（低位在前）
ll memo[len];                      // 示意：省略了 pre 等维度

// dfs(pos, limit)：
//   pos   = 当前填第几位（从最高位 0 开始）
//   limit = 前几位是否贴上界
ll dfs(int pos, bool limit) {
    if (pos == len) return 1;            // 所有位都填完了，这是一个合法数
    if (!limit && memo[pos] != -1) return memo[pos];  // 只有 limit=0 才能用缓存！
    int up = limit ? digit[pos] : 9;     // 被卡住则只能填到 digit[pos]，否则 0~9
    ll res = 0;
    for (int d = 0; d <= up; d++) {
        if (d == 4) continue;            // 不含 4 的限制
        res += dfs(pos + 1, limit && d == up);
        // 新 limit：之前被卡住 && 这一位又顶到上界 → 继续卡住
    }
    if (!limit) memo[pos] = res;         // 只缓存 limit=0 的结果
    return res;
}

int main() { return 0; }                 // 示意块不运行，完整版见例 1

    记忆化只缓存 limit=0 的原因：limit=1 的分支是"贴着上界走"的唯一路径，整棵搜索树里只会出现一次，缓存它纯属浪费且容易和其他前缀的状态混用；limit=0 的分支代表"前面已经比 N 小了，后面随便填"，结果只依赖 pos（和题目加的额外状态），可以被任意前缀复用——这才是记忆化的意义。

    经典变体（往模板里加参数）¶

    题目 额外状态 说明
    windy 数（P2657） pre（上一位数字） 相邻两位差 ≥ 2，例 1
    不含 4 / 62（HDU 2089 不要62） pre（上一位数字） 当前位是 6 且下一位 2 不合法，把例 1 的差 ≥ 2 条件换成 pre==6 && d==2 即可
    数字和整除（P4127 同类分布） sum（数位和） 枚举数位和 mod，dp 里带 sum，最后检查 sum % mod == 0
    数字 0 计数（P2602） lead（前面是否全 0） 前导零不计入统计，0 本身要特判，例 2
    手机号码（P4124） pre + 连续相同个数 三连号 + 不含 4 和 8，综合进阶

    复杂度¶

    状态数 O(len × 状态数)，转移 O(10)。len 最多 19 位（long long），所以数位 DP 几乎都是"常数级"——无论 N 多大（10^18）都只要几百个状态 × 10 转移。这就是它吊打暴力的原因。

    例 1：windy 数（P2657，完整可运行）¶

    #include <bits/stdc++.h>
using namespace std;
typedef long long ll;

int digit[20];                // N 的每一位（低位在前，dfs 从高位走）
ll memo[20][11];              // memo[pos][pre]：pre 取 0..9，10 表示"还没有上一位"
                              // 只缓存 limit=0 的结果（limit=1 的路径唯一、无需缓存），所以不设 limit 维

// 统计 [0, N] 中 windy 数的个数
// pos: 当前位（-1 = 填完了）；pre: 上一位数字（10 表示还没有）
// limit: 是否被上界卡住；lead: 是否还在前导零阶段
ll dfs(int pos, int pre, bool limit, bool lead) {
    if (pos == -1) return 1;                      // 填完了，这个数合法（含 0，前缀和会抵消）
    if (!limit && !lead && memo[pos][pre] != -1)
        return memo[pos][pre];                    // 只有 limit=0 且非前导零才能缓存

    int up = limit ? digit[pos] : 9;
    ll res = 0;
    for (int d = 0; d <= up; d++) {
        if (lead) {
            // 前导零阶段：继续填 0 保持前导零；填非 0 才开始真正的数字
            res += dfs(pos - 1, d, limit && d == up, lead && d == 0);
        } else {
            if (abs(d - pre) < 2) continue;       // windy 条件：相邻两位差必须 >= 2
            res += dfs(pos - 1, d, limit && d == up, false);
        }
    }
    if (!limit && !lead) memo[pos][pre] = res;    // 缓存通用结果
    return res;
}

ll solve(ll x) {
    if (x < 0) return 0;                          // 前缀和里 f(L-1)，L=0 时 L-1=-1
    int len = 0;
    while (x) { digit[len++] = x % 10; x /= 10; } // 拆位（低位在前）
    memset(memo, -1, sizeof(memo));
    return dfs(len - 1, 10, true, true);          // 最高位：limit=1（被 x 卡住），lead=1（前导零）
}

int main() {
    ll l, r;
    cin >> l >> r;
    cout << solve(r) - solve(l - 1) << endl;      // 前缀和技巧
    return 0;
}

    坑： - pre 初始化为 10（表示"没有上一位"），因为数字 0~9 里没有 10，不会误触发差值判断 - lead 前导零必须处理：00013 里的 0 只是占位，不能拿 0 当上一位去和 1 比差 - solve(0) 返回 1（数 0 本身），f(r) - f(l-1) 时 0 会被两边抵消，答案不受影响

    复杂度分析：状态 O(len × 11 × 2) ≈ 400 个，每个 10 种转移 → O(len × 10²)，无论 N 是 1e9 还是 1e18 都是瞬间出结果。手算验证：1~100 的 windy 数 = 9 个一位数 + 64 个两位数 = 73（100 的 |1-0|=1 < 2，不算；两位数十位 a 与个位 b 要 |a-b|≥2：a=1..8 各 7 个、a=9 有 8 个）。

    #include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// 统计 1 到 N 中数字 x 出现多少次（x = 0..9）
ll countDigit(ll n, int x) {
    if (n <= 0) return 0;
    ll ans = 0;
    for (ll base = 1; base <= n; base *= 10) {    // base = 当前位是 10 的几次幂（个位 1、十位 10…）
        ll higher = n / (base * 10);     // 高位部分（当前位左边）
        ll cur = (n / base) % 10;        // 当前位的数字
        ll lower = n % base;             // 低位部分（当前位右边）

        if (x == 0) {                    // 0 要特判：不能有前导零
            if (higher == 0) break;      // 最高位不可能是 0，再往上没有贡献了
            ans += (higher - 1) * base + (cur == 0 ? lower + 1 : base);
        } else {
            ans += higher * base;        // 高位取 0..higher-1 时，当前位取 x 都有 base 种
            if (cur > x) ans += base;    // 当前位 > x：高位取 higher 时也能凑满 base 种
            else if (cur == x) ans += lower + 1;   // 当前位 == x：低位只能取 0..lower
        }
    }
    return ans;
}

int main() {
    ll l, r;
    cin >> l >> r;
    for (int x = 0; x <= 9; x++)
        cout << countDigit(r, x) - countDigit(l - 1, x) << " ";
    cout << endl;
    return 0;
}

    坑：数字 0 的出现次数要单独处理前导零——higher == 0 直接 break（最高位不可能是 0），且公式用 higher - 1。如果直接套 x>0 的公式，0 会被多算一整个最高位。手算验证：1~10 中，0 出现 1 次（10 里的 0），1 出现 2 次（1 和 10），2~9 各出现 1 次（1~9 每个数本身就含一个）。

    复杂度分析：O(log₁₀ n) 逐位算，n=1e18 只需 19 轮，比数位 DP 模板还快。

    例 3：二进制 1 个数求和（ΣF(i)，视频例题）¶

    是什么：F(x) = x 在二进制下 1 的个数，求 0 到 N 所有 F 的和。

    为什么不能用公式：F 是"数位相关"的复杂函数（不是加减乘除能拆的），暴力枚举又不可能（N 可达 1e18）。这正是数位 DP 的主场：按二进制位填数字。

    思考路径（视频的核心教学）：填到第 pos 位时，这一位填 1 会影响后面所有情况（每个数都多一个 1）——"这个影响太复杂，我想不明白怎么办？把它塞进状态里"。这就是贯穿整个 DP 的思想：考虑不全的东西就设计成状态。这里把 cnt1（高位已经填了几个 1）塞进状态，到边界直接返回累计值。

    状态设计：dfs(pos, cnt1, limit)，边界 pos < 0 返回 cnt1（注意！返回的是累计的 1 个数，不是 1——这是"求和"题和"计数"题的区别）。

    #include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// 统计 0..N 中所有数字的二进制 1 个数之和（简单做法：把 sum 塞进状态）
// 例：N=7 → popcount(0..7) = 0+1+1+2+1+2+2+3 = 12

int digit[70];      // N 的二进制位（低位在前）
ll memo[70][70];    // memo[pos][cnt1]：只缓存 limit=0（limit=1 路径唯一，无需缓存）

// pos: 当前位；cnt1: 高位已填的 1 的个数；limit: 是否贴上界
ll dfs(int pos, int cnt1, bool limit) {
    if (pos < 0) return cnt1;   // 所有位填完，返回累计的 1 的个数（不是 1！）
    if (!limit && memo[pos][cnt1] != -1) return memo[pos][cnt1];
    int up = limit ? digit[pos] : 1;   // 二进制：这一位只能填 0 或 1
    ll res = 0;
    for (int d = 0; d <= up; d++)
        res += dfs(pos - 1, cnt1 + d, limit && d == up);   // 填 1 就把 cnt1 +1 传下去
    if (!limit) memo[pos][cnt] = res;
    return res;
}

ll solve(ll x) {
    if (x < 0) return 0;
    int len = 0;
    if (x == 0) { digit[0] = 0; len = 1; }        // x=0 也要占一位，否则 len=0 直接返回
    else while (x) { digit[len++] = x & 1; x >>= 1; }
    memset(memo, -1, sizeof(memo));
    return dfs(len - 1, 0, true);
}

int main() {
    ll n;
    cin >> n;
    cout << solve(n) << endl;
    return 0;
}

    坑： - 边界返回 cnt1（累计的 1 个数），计数题这里返回 1——把两个搞混答案直接翻车 - 二进制每位只有 0/1 两种选择，up 不是 9 - 答案可能超 long long：Σpopcount(0..1e18) ≈ 3×10¹⁹（实测 1e18 输出负数就是溢出），题目一般给模数或小范围（视频原话："如果太大你需要取模"）

    复杂度分析：状态 O(len × len)（cnt1 维度），转移 O(2)。len ≤ 60，瞬间出结果。

    例 4：数位互不相同（数位 DP × 状压 DP）¶

    是什么：统计 [1, N] 中"各位数字互不相同"的数的个数（比如 123 行、122 不行）。

    思考路径：如果只要求"相邻两位互不相同"，存 pre（上一位）就够了（windy 数那套）；但"所有位互不相同"意味着要知道整个已出现数字的集合——0~9 只有 10 个数字，用 10 位 mask 状压（06 章刚学的集合压缩）。这是数位 DP 和状压 DP 的经典结合。

    状态设计：dfs(pos, mask, limit, lead)，mask 的第 d 位 = 1 表示数字 d 已出现过。转移时：d 已出现过（mask >> d & 1）→ 跳过；否则 mask | (1 << d)。

    #include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// 统计 [1, N] 中"各位数字互不相同"的数的个数（数位 DP × 状压）
// 例：1..13 → 12（11 不行）；1..100 → 90（100 有重复 0）

int digit[20];
ll memo[20][1 << 10];  // memo[pos][mask]：只缓存 limit=0 && lead=0

// pos: 当前位；mask: 已出现的数字集合；limit: 贴上界；lead: 前导零阶段
ll dfs(int pos, int mask, bool limit, bool lead) {
    if (pos < 0) return 1;  // 填完了（含数 0，最后减掉）
    if (!limit && !lead && memo[pos][mask] != -1) return memo[pos][mask];
    int up = limit ? digit[pos] : 9;
    ll res = 0;
    for (int d = 0; d <= up; d++) {
        if (lead && d == 0) {
            // 前导零：0 只是占位，不进集合（0013 里的 0 不是真数字）
            res += dfs(pos - 1, mask, limit && d == up, true);
        } else {
            if (mask >> d & 1) continue;   // d 已经出现过了，重复！
            res += dfs(pos - 1, mask | (1 << d), limit && d == up, false);
        }
    }
    if (!limit && !lead) memo[pos][mask] = res;
    return res;
}

ll solve(ll x) {
    if (x <= 0) return 0;
    int len = 0;
    while (x) { digit[len++] = x % 10; x /= 10; }
    memset(memo, -1, sizeof(memo));
    return dfs(len - 1, 0, true, true) - 1;   // 减掉数 0（题目统计 [1, N]）
}

int main() {
    ll n;
    cin >> n;
    cout << solve(n) << endl;
    return 0;
}

    坑： - 前导零的 0 不能进集合：否则 10 会被误判为"0 重复出现"——0013 的 0 只是占位，10 的 0 才是真数字，两者用 lead 区分 - 记忆化只缓存 limit=0 && lead=0：前导零阶段每个前缀都不同，不能复用 - 统计 [1, N] 要减 1（数 0）；memo 大小 20 × 1024 × 2，很小

    复杂度分析：状态 O(len × 2^10 × 2) ≈ 2 万，转移 O(10)。n=1e18 秒出。

    进阶技巧一：一个状态转移两个值（cnt + sum）¶

    是什么：例 3 把 sum 塞进状态（状态多一维 cnt1）。更妙的写法：不塞 sum，让 dfs 返回 {方案数 cnt, 总和 sum} 两个值一起转移。

    为什么数位 DP 可以这样（视频重点）：普通 DP 一个状态通常只能转移一个数值，"想不清的数值就塞状态"；但数位 DP 里多个数值可以一起转移——因为填这一位 d 时，后面每种方案都多 d 个 1，于是：

    #include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// 统计 0..N 二进制 1 个数之和——"双值转移"写法（和例 3 答案一样，但状态少一维）
// 不把 sum 塞进状态，而是让 dfs 返回 {方案数 cnt, 1 的个数和 sum}
// 填 1 时：后面每种方案都多一个 1 → sum += 子状态的 cnt

struct Res { ll cnt, sum; };   // cnt = 方案数，sum = 这些方案里 1 的总个数

int digit[70];
Res memo[70];         // 只缓存 limit=0

Res dfs(int pos, bool limit) {
    if (pos < 0) return {1, 0};       // 一种填法，没有 1
    if (!limit && memo[pos].cnt != -1) return memo[pos];
    int up = limit ? digit[pos] : 1;
    Res res = {0, 0};
    for (int d = 0; d <= up; d++) {
        Res sub = dfs(pos - 1, limit && d == up);
        res.cnt += sub.cnt;
        res.sum += sub.sum + d * sub.cnt;   // 这一位填 1：每种方案都多 1 个
    }
    if (!limit) memo[pos] = res;
    return res;
}

ll solve(ll x) {
    if (x < 0) return 0;
    int len = 0;
    if (x == 0) { digit[0] = 0; len = 1; }
    else while (x) { digit[len++] = x & 1; x >>= 1; }
    for (int i = 0; i < 70; i++) memo[i] = {-1, -1};
    return dfs(len - 1, true).sum;
}

int main() {
    ll n;
    cin >> n;
    cout << solve(n) << endl;
    return 0;
}

    对比：例 3 状态 O(len × len)（cnt1 维度），双值版状态 O(len)——把"结果"从状态里挪到"返回值"里，维度就省下来了。这就是"结果导向"设计：结果需要什么就塞什么，不需要的就不塞。

    视频原话：其他 DP 里"一个状态转移两个值"经常是贪心想错了（伪 DP）；但数位 DP 里这是合法的——去年 CCPC 总决赛就有人用"转移两个状态的伪 DP"爆杀全场（当然那是真的会写）。

    进阶技巧二：处理进位（Σ F(i)·F(i+D)，压轴）¶

    是什么：求 Σ_{i=0}^{N} popcount(i) × popcount(i+D)。牛客题（视频：初期银牌题水准，做出基本稳拿银牌）。

    为什么进位难处理（视频核心）：数位 DP 从高到低枚举，但进位从低到高传播。从高到低填到某一位时，这一位收到的进位来自还没填的低位；而且一个进位会把前面记好的 1 全毁掉（视频例子：已经记了 3 个 1，第四位一个进位把前面三位全变了）。所以"1 的个数"根本没法顺着填维护。

    解法：把"预期进位"塞进状态。从高到低仍然可以，但要带两个进位参数：

    • c_in：这一位从低位流入的进位（预期值，由低一位的流出验证）
    • c_out_req：这一位流出的进位必须等于的值（高一位对它的要求）

    转移：枚举这一位 a，s = a + D_bit + c_in，b = s & 1（i+D 的这一位），c_out = s >> 1。要求 c_out == c_out_req（满足高一位的需求），然后枚举低一位的流入 c_low 递归——低一位的 c_out_req 设为当前位的 c_in，进位链就闭合了。

    要维护四个值（结果导向设计）：设 X = popcount(i)、Y = popcount(i+D)，求 ΣX·Y。当前位贡献 a（给 X）、b（给 Y），展开 Σ(X+a)(Y+b)：

    #include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// 压轴：求 Σ_{i=0}^{N} popcount(i) * popcount(i+D)
// 数位 DP 从高到低 + 枚举进位 + 同时维护四个值
// X = popcount(i)，Y = popcount(i+D)，求 ΣX·Y

struct Res { ll cnt, sx, sy, sxy; };

int bitN[70], bitD[70];   // N 和 D 的二进制位（低位在前）
Res memo[70][2][2];       // memo[pos][c_in][c_out_req]：只缓存 limit=0

// pos: 当前位；limit: i 是否贴上界 N
// c_in: 这一位从低位（pos-1 位）流入的进位（预期）
// c_out_req: 这一位流出的进位必须等于这个值（高一位对它的要求）
Res dfs(int pos, bool limit, int c_in, int c_out_req) {
    if (pos < 0) return {1, 0, 0, 0};   // 填完所有位：一种填法，X=Y=XY=0
    // 最低位没有更低位提供进位，流入必须为 0（漏掉会重复计数 2 倍）
    if (pos == 0 && c_in != 0) return {0, 0, 0, 0};
    if (!limit && memo[pos][c_in][c_out_req].cnt != -1)
        return memo[pos][c_in][c_out_req];
    int up = limit ? bitN[pos] : 1;   // i 的这一位：0 或 1
    Res res = {0, 0, 0, 0};
    for (int a = 0; a <= up; a++) {
        int s = a + bitD[pos] + c_in;   // i 的这位 + D 的这位 + 低位进位
        int b = s & 1;                  // i+D 的这一位
        int c_out = s >> 1;             // 这一位流向高位的进位
        if (c_out != c_out_req) continue;  // 必须满足高一位的需求，否则剪枝
        // 枚举低一位流入的进位；最低位的"低一位"不存在，流入固定 0
        for (int c_low = 0; c_low <= (pos == 0 ? 0 : 1); c_low++) {
            // 低一位的流出需求 = 当前位的流入 c_in（进位链闭合）
            Res sub = dfs(pos - 1, limit && a == up, c_low, c_in);
            if (sub.cnt == 0) continue;
            res.cnt += sub.cnt;
            res.sx += sub.sx + a * sub.cnt;       // Σ(X+a)
            res.sy += sub.sy + b * sub.cnt;       // Σ(Y+b)
            // Σ(X+a)(Y+b) = ΣXY + a·ΣY + b·ΣX + ab·cnt
            res.sxy += sub.sxy + a * sub.sy + b * sub.sx + (ll)a * b * sub.cnt;
        }
    }
    if (!limit) memo[pos][c_in][c_out_req] = res;
    return res;
}

ll solve(ll n, ll d) {
    int lenN = 0, lenD = 0;
    if (n == 0) { bitN[0] = 0; lenN = 1; } else while (n) { bitN[lenN++] = n & 1; n >>= 1; }
    if (d == 0) { bitD[0] = 0; lenD = 1; } else while (d) { bitD[lenD++] = d & 1; d >>= 1; }
    int L = max(lenN, lenD) + 1;   // i+D 最多 max+1 位，最高位流出进位必须为 0
    for (int i = 0; i < 70; i++)
        for (int a = 0; a < 2; a++)
            for (int b = 0; b < 2; b++)
                memo[i][a][b] = {-1, -1, -1, -1};
    // 最高位流入进位可能是 0 或 1（i+D 的溢出位），枚举两者相加
    return dfs(L - 1, true, 0, 0).sxy + dfs(L - 1, true, 1, 0).sxy;
}

int main() {
    ll n, d;
    cin >> n >> d;
    cout << solve(n, d) << endl;
    return 0;
}

    手算验证：N=3, D=1 → i=0..3 的 popcount(i)×popcount(i+1) = 0×1 + 1×1 + 1×2 + 2×1 = 5 ✓

    坑（全部实测踩过）： - 最低位的流入进位必须为 0，且最低位不要再枚举"低一位的流入"（低一位不存在）——漏掉会每个填法数两遍，答案正好 2 倍 - 位数上界：i+D 最多 max(lenN, lenD)+1 位，所以最高位的流出进位必须为 0（c_out_req = 0） - 最高位流入枚举 0/1 两个答案相加：每个填法的最高位流入是唯一值，两个调用恰好互不重叠地覆盖全部填法 - 四值聚合顺序：ΣXY' 里用的 ΣX、ΣY 是子状态的值，别用被当前位累加污染后的 res 值

    复杂度分析：状态 O(len × 2 × 2 × 2) ≈ 500，转移 4 分支——比前几题大不了多少。这题难在想明白，不在算得慢（视频原话：这种题才是区域赛真正会遇见的，做出基本银牌）。

    A. "归并"视角理解状态复用¶

    OI Wiki 的引入例子：从 7000 数到 7999、8000 数到 8999、9000 数到 9999，后三位都是 000→999 的完整循环，只有千位不同——所以计数过程可以归并，结果存进通用数组。

    这和视频的"前两位是 00 和 01 时后两位转移一样"是同一个性质的两个说法：高位的不同选择，可能通向完全相同的低位计数过程，这就是记忆化能复用的根源。

    B. st 状态不只是"上一位"（OI Wiki 的通用化总结）¶

    OI Wiki 用 f(i, st, op) 表示数位 DP（op = 是否贴上限），并强调 st（前缀状态）可以承载任何"当前位能取哪些数"所依赖的信息：

    题目 st 记录什么
    windy 数 上一位数字
    HDU 2089 不要 62 上一位是否是 6（只要 0/1 两种，不是 6 的情况视为同种）
    同类分布（P4127） 前缀数字和（或取模）
    Beautiful numbers（CF55D） 前缀数字的 lcm（或模 lcm 的余数）
    数位互不相同（例 4） 出现过的数字集合（状压）

    设计状态时反复问自己："这一位能取哪些数，取决于前面哪些信息？" 答案就是 st 的维度。

    C. 递推预处理写法（HDU 2089 不要 62）¶

    视频全程用记忆化搜索，OI Wiki 给了另一种经典写法：递推预处理 + 数位统计，不用 DFS。适合 st 信息很简单的题（只要"前一位是不是 6"）：

dp[i][1] = i 位不含 4/62、且末尾是 6 的个数

    #include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// HDU 2089 不要 62：统计 [L,R] 中不含 4 且不含连续 62 的数的个数
// OI Wiki 的递推预处理写法（区别于记忆化搜索）：
// dp[i][0] = i 位（允许前导零）不含 4/62、且末尾不是 6 的个数
// dp[i][1] = i 位不含 4/62、且末尾是 6 的个数
// dp[i][0] + dp[i][1] = i 位合法的总数

ll dp[20][2];

// 统计 [0, x] 中合法的数
ll count(ll x) {
    if (x < 0) return 0;
    int a[20], len = 0;
    while (x) { a[++len] = x % 10; x /= 10; }   // a[len] 是最高位
    ll ans = 0;
    int pre = 0;        // 前缀最后一位
    bool bad = false;   // 前缀是否已含 4 或 62
    for (int i = len; i >= 1; i--) {
        for (int d = 0; d < a[i]; d++) {   // 这一位取比 x 小的 d，后面随便填
            if (d == 4) continue;
            if (pre == 6 && d == 2) continue;
            if (i == 1) { ans++; continue; }   // 最后一位：直接算这一个数
            ll free = dp[i - 1][0] + dp[i - 1][1];   // 后面 i-1 位任意合法的总数
            if (d == 6) free -= dp[i - 2][0] + dp[i - 2][1];  // 下一位不能是 2（组成 62）
            ans += free;
        }
        // 前缀贴着 x 走
        if (a[i] == 4 || (pre == 6 && a[i] == 2)) { bad = true; break; }
        pre = a[i];
    }
    if (!bad) ans++;   // x 本身
    return ans;
}

int main() {
    dp[0][0] = 1;   // 0 位：空串，合法，不以 6 结尾
    for (int i = 1; i < 20; i++) {
        dp[i][1] = dp[i - 1][0] + dp[i - 1][1];       // 补 6
        dp[i][0] = dp[i - 1][0] * 8 + dp[i - 1][1] * 7;  // 补非 4 非 6（前一位 6 时还不能补 2）
    }
    int l, r;
    while (cin >> l >> r && (l || r)) {
        if (l > r) swap(l, r);
        cout << count(r) - count(l - 1) << endl;
    }
    return 0;
}

    什么时候用递推、什么时候用记忆化：st 信息简单（就一两个值）→ 递推常数更小、不用递归；st 复杂（mask、余数、进位、AC 自动机节点）→ 记忆化更好写。视频推荐新手一律记忆化，就是这个原因。

    D. 进阶方向一：高精度 + 回文（SPOJ MYQ10）¶

    题目：区间 [n, m]（n, m < 10^44，字符串输入）里"镜像后和原来一样"的数（只有 0/1/8 镜像是自己，且整体回文）有多少个。

    两个新技巧： - 高精度区间：不能 f(l-1)（字符串减 1 麻烦），改用 ans[1,m] - ans[1,n] + check(n)——单独判断 n 是否合法，加回来 - 回文数位 DP：前一半随便填（只要不超上限），后一半必须和对称位相等——用数组记录前半的值，超过一半长度时逐位比对

    E. 进阶方向二：AC 自动机 + 数位 DP（P3311 数数）¶

    题目：不大于 n 的数中，不包含模式串集合 S 中任何字符串作为子串的个数（S 总长 ≤ 1500）。

    把数字当字符串、多个模式串 → 多模匹配 = AC 自动机（04-字符串 会学）。数位 DP 的状态从"填了几位"变成"填了几位 + 停在 AC 自动机的哪个节点"：f(i, 节点, 0/1)，转移就是沿着自动机的边走，走到模式串结尾节点就剪掉。这是数位 DP × 字符串自动机的经典结合，学完 AC 自动机再回来看。
