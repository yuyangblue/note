    01 复杂度、枚举、模拟¶

    一、大白话引入¶

    算法竞赛里，写完代码最怕什么？超时。

    一道题给你 1 秒时间，你的代码能不能跑完？这就要靠时间复杂度来估算。

    而枚举和模拟是你最先掌握的两种基本功： - 枚举（暴力）：把所有可能的情况都试一遍 - 模拟：按题目说的步骤一步步做

    简单粗暴，但很多时候就是正解。

    二、核心讲解¶

    2.0 算法是什么（王卓《数据结构与算法基础》补充）¶

    整理自 B站《数据结构与算法基础（青岛大学-王卓）》（BV1nJ411V7bd）第6-9P：算法与算法分析

    算法的定义¶

    算法是对特定问题求解方法和步骤的一种描述，是指令的有限序列，其中每条指令表示一个或多个操作。

    简单说：算法就是"第一步干什么、第二步干什么、第三步干什么"列出来的步骤。

    算法和程序的区别： - 算法是解决问题的方法/过程，考虑怎么从输入变成输出 - 程序是用某种程序设计语言对算法的具体实现 - 经典公式：程序 = 数据结构 + 算法

    算法的描述方法¶

    方法 特点
    自然语言 中文/英文描述，易懂但啰嗦
    流程图 传统流程图（框图）或 NS 图，直观但占篇幅
    伪代码/类语言 类似编程语言但省略语法细节，教材常用
    程序代码 直接用 C++/Python 等写出来，可直接运行

    算法的 5 个重要特性¶

    特性 含义 反例
    有穷性 步骤必须有限，每步执行时间也有限 死循环不是算法
    确定性 每条指令有确切含义，无二义性；相同输入必得到相同输出 "大概处理一下"不是算法
    可行性 每步都能用已实现的基本操作完成 要求计算机"瞬间枚举无穷多种"不可行
    输入 有 0 个或多个输入 可以内部自带数据，不需要外部输入
    输出 有 1 个或多个输出 跑了半天没结果的不算算法

    好算法的 4 个要求¶

    1. 正确性：对精心选择的典型、苛刻的输入都能得到正确结果（不是所有输入都试一遍——那不可能）
    2. 可读性：算法主要是给人看的（计算机只执行程序），晦涩难懂的算法往往隐藏错误且难调试
    3. 健壮性（鲁棒性）：输入非法数据或意外情况时，能做出反应而不是死机或产生莫名其妙的结果
    4. 高效性：尽量少花时间、尽量少占内存

    时间效率 vs 空间效率¶

    • 时间效率：算法耗费的时间
    • 空间效率：算法执行过程中耗费的存储空间

    两者有时矛盾：想省时间往往要多占空间（如预处理、缓存），想省空间往往要多花时间（如重复计算）。根据实际问题综合平衡。

    怎么度量算法的时间效率¶

    两种方法：

    方法 做法 缺点
    事后统计 编好程序实际运行，测花了多少时间 必须先编程；受计算机软硬件环境影响大，可能掩盖算法本身优劣
    事前分析 不编程序，直接对算法耗费的资源进行估算 需掌握分析方法

    竞赛中用事前分析——不用写代码就能估算能不能过。

    语句频度与运行时间¶

    算法的运行时间 ≈ 所有语句的执行次数之和（假设每条语句执行时间相同，约去单位时间）。

    每条语句的执行次数叫语句频度。

    1
2
    运行时间 = Σ(语句频度 × 执行一次所需时间)
         ≈ Σ(语句频度)   （单位时间相同，约去）

    例子：矩阵乘法（n×n × n×n）

            c[i][j] += a[i][k]*b[k][j];  // 频度 n³
    总频度是一个关于 n 的多项式，最高次项是 n³。

    渐进时间复杂度（大 O 表示法）¶

    逐条数频度太麻烦。我们不比较具体执行次数，只比较数量级。

    定义： 如果存在辅助函数 f(n)，当 n→∞ 时，T(n)/f(n) 的极限是一个不等于零的常数，则称 f(n) 是 T(n) 的同量级函数，记作：

    \[T(n) = O(f(n))\]

    读作"T(n) 是 f(n) 数量级的"。大 O（Order）表示数量级。

    含义： 随着 n 增大，算法执行时间的增长率与 f(n) 的增长率相同。

    矩阵乘法的 T(n) 最高次是 n³，所以 T(n) = O(n³)。

    基本操作和问题规模¶

    • 基本操作：算法中对运行时间贡献最大的语句（执行次数最多的那个）。分析时只需要找基本操作的次数，不用数所有语句。
    • 问题规模 n：描述要处理的数据量的变量。不同问题中 n 含义不同：
    • 排序：n = 要排序的数据个数
    • 矩阵乘法：n = 矩阵的阶数
    • 图算法：n = 顶点数或边数
    • 多项式：n = 项数

    空间复杂度¶

    空间复杂度 S(n) = 算法执行过程中耗费的存储空间的数量级，同样用大 O 表示。

    • 算法本身的代码占用空间（固定，和 n 无关）
    • 输入数据占用空间（通常不计入，因为是题目给的）
    • 辅助空间：算法运行过程中额外需要的临时空间（这是空间复杂度主要衡量的）

    竞赛中常见：O(1) 辅助空间 = 原地算法（如冒泡排序）；O(n) 辅助空间 = 需要额外数组（如归并排序）。

    2.1 时间复杂度¶

    算法运行时间随数据规模增长的趋势。

    常见复杂度速查表¶

    复杂度 含义 秒内大致能跑的数据规模
    O(1) 常数时间 无限
    O(log n) 对数 宇宙那么大也没问题
    O(n) 线性 约 10⁷ ~ 10⁸
    O(n log n) 线性对数 约 10⁶ ~ 10⁷
    O(n²) 平方 约 10⁴
    O(n³) 立方 约 500
    O(2ⁿ) 指数 约 20~25
    O(n!) 阶乘 约 10~12

    判断方法： 看 C++ 代码里循环的嵌套层数 × 每层要跑多少遍。

    常见坑¶

    • 100 层循环不现实 —— 哪怕 n=10，100 层循环也是天文数字（10¹⁰⁰ 次）
    • O(2ⁿ) 不要对 n>25 跑 —— 比如枚举子集，n=30 就已经是 10 亿次
    • 看清楚输入规模 —— 题目说 n≤10⁵，你写 O(n²) 大概率超时，要想 O(n log n) 或者 O(n)

    2.2 枚举（暴力）¶

    枚举就是把所有可能性全试一遍。

    什么时候用枚举？¶

    • 数据范围很小（n ≤ 20 通常可以全排列枚举）
    • 想不到更好的算法（先写暴力拿部分分）
    • 做对拍：用暴力验证正解的正确性

    // 例子：两数之和 —— 找数组中两个数和为 target
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, target;
    int a[1005];
    cin >> n >> target;
    for (int i = 0; i < n; i++) cin >> a[i];

    // 双层循环枚举所有数对，O(n²)
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            if (a[i] + a[j] == target) {
                cout << i << " " << j << endl;
                return 0;
            }
        }
    }
    cout << "No solution" << endl;
    return 0;
}

    // 枚举一个数组的所有子集，O(2ⁿ)
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, a[20];
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];

    // 从 0 枚举到 2ⁿ-1，每个二进制位表示选不选
    for (int mask = 0; mask < (1 << n); mask++) {
        cout << "{ ";
        for (int i = 0; i < n; i++) {
            if (mask & (1 << i)) {
                cout << a[i] << " ";
            }
        }
        cout << "}" << endl;
    }
    return 0;
}

    ⚠️ 2²⁰ ≈ 10⁶，2³⁰ ≈ 10⁹ —— 所以 n≤20 才能用子集枚举。

    // 枚举所有排列，O(n!)
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> p(n);
    iota(p.begin(), p.end(), 1);  // 填入 1, 2, 3, ..., n

        for (int x : p) cout << x << " ";
        cout << endl;

    ⚠️ 10! ≈ 3.6×10⁶，11! ≈ 4×10⁷，12! ≈ 4.8×10⁸ —— 所以 n≤10 才用全排列枚举。

    2.3 模拟¶

    模拟就是按照题目的规则一步步走。

    算法竞赛里模拟题的套路： 1. 把题目规则读懂，理清流程 2. 用变量/数组/结构体表示状态 3. 按流程写代码，每次操作更新状态 4. 最后输出结果

    // n 个人围成一圈，从第一个人开始报数，数到 m 的人出列，问最后剩下谁
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;

    queue<int> q;           // 用队列模拟环
    for (int i = 1; i <= n; i++) q.push(i);

    int cnt = 1;
    while (q.size() > 1) {
        int cur = q.front();
        q.pop();
        if (cnt == m) {     // 数到 m，出列（不入队）
            cnt = 1;
        } else {            // 没数到 m，放回队尾继续
            q.push(cur);
            cnt++;
        }
    }
    cout << q.front() << endl;
    return 0;
}

    模拟注意事项¶

    • 注意边界——下标从 0 还是 1？循环条件要不要取等？
    • 别偷懒——模拟不需要技巧，但需要细心，一个符号错了就全错
    • 善用 STL——vector、queue、stack、set、map 能省很多事
    • 先想清楚再写——模拟题最容易写着写着就迷路了，画个流程图

    #include <bits/stdc++.h>
using namespace std;

// 检查三个三位数是否覆盖了 1~9 各一次
bool check(int a, int b, int c) {
    int used[10] = {0};         // 标记 1~9 是否出现过
    // 拆解 a
    used[a / 100] = 1;
    used[a / 10 % 10] = 1;
    used[a % 10] = 1;
    // 拆解 b
    used[b / 100] = 1;
    used[b / 10 % 10] = 1;
    used[b % 10] = 1;
    // 拆解 c
    used[c / 100] = 1;
    used[c / 10 % 10] = 1;
    used[c % 10] = 1;
    // 检查是否每个数字都恰好出现一次
    for (int i = 1; i <= 9; i++) {
        if (!used[i]) return false;
    }
    return true;
}

int main() {
    for (int a = 123; a <= 333; a++) {    // a 最小 123，最大 333（因为 3a ≤ 987）
        int b = a * 2;
        int c = a * 3;
        if (check(a, b, c)) {
            cout << a << " " << b << " " << c << endl;
        }
    }
    return 0;
}
