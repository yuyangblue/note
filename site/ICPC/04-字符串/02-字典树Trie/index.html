    02 字典树（Trie）¶

    Trie 把多个字符串的公共前缀共享在一条路径上，插入和查询都是 O(字符串长度)。是字符串前缀查询、自动补全、01异或最值的核心数据结构。

    目录¶

    1. 核心思想¶

    大白话引入¶

    字典里查单词：先翻到首字母所在页，再找第二个字母... Trie 就是这个思路——每个节点代表一个前缀，从根到某个节点的路径就是一个字符串。

    比如插入 "abc", "abd", "bcd"： 

    1
2
3
4
5
6
7
8
            根
       /   \
      a     b
     /       \
    b         c
   / \         \
  c   d         d
(abc)(abd)     (bcd)

    "abc" 和 "abd" 共享前缀 "ab"，不用重复存储。

    核心讲解¶

    Trie 的性质： - 根节点不代表任何字符（空前缀） - 从根到某个节点的路径上的字符连起来 = 该节点代表的字符串 - 每个节点的子节点对应不同的下一个字符 - 需要标记哪些节点是"单词结尾"（因为一个单词可能是另一个的前缀，如 "a" 和 "abc"）

    时间复杂度： 插入/查询都是 O(L)，L 是字符串长度，和总共有多少字符串无关。

    空间复杂度： O(总字符数)，最坏情况所有字符串没有公共前缀。

    2. Trie 的插入与查询¶

    思维启发¶

    每个节点需要存什么？ - 一个数组/指针，指向各个子节点（字符集大小决定，小写字母就是26个） - 一个标记，记录这个节点是不是某个单词的结尾

    插入：从根出发，逐个字符走，没有对应子节点就新建，走到最后标记结尾。 查询：从根出发，逐个字符走，走不到就是不存在；走到最后看有没有结尾标记。

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;  // 总字符数上限
const int CHARSET = 26;    // 小写字母

int trie[MAXN][CHARSET];  // trie[u][c] = 节点u的字符c子节点编号，0表示不存在
int cnt[MAXN];             // cnt[u] = 以节点u结尾的单词个数
int tot;                   // 已使用的节点数（0是根节点）

// 初始化
void init() {
    tot = 0;
    memset(trie, 0, sizeof(trie));
    memset(cnt, 0, sizeof(cnt));
}

// 插入一个字符串
void insert(const string& s) {
    int u = 0;  // 从根节点开始
    for (char c : s) {
        int v = c - 'a';  // 字符转成 0~25
        if (trie[u][v] == 0) {
            trie[u][v] = ++tot;  // 没有子节点就新建
        }
        u = trie[u][v];  // 走到子节点
    }
    cnt[u]++;  // 标记单词结尾
}

// 查询字符串是否存在，返回出现次数
int query(const string& s) {
    int u = 0;
    for (char c : s) {
        int v = c - 'a';
        if (trie[u][v] == 0) return 0;  // 走不到，不存在
        u = trie[u][v];
    }
    return cnt[u];  // 返回结尾标记的个数
}

// 查询是否有某个前缀
bool starts_with(const string& prefix) {
    int u = 0;
    for (char c : prefix) {
        int v = c - 'a';
        if (trie[u][v] == 0) return false;
        u = trie[u][v];
    }
    return true;  // 能走完前缀就存在
}

int main() {
    init();
    insert("abc");
    insert("abd");
    insert("abc");
    insert("bcd");

    cout << "query(abc): " << query("abc") << endl;   // 预期: 2
    cout << "query(abd): " << query("abd") << endl;   // 预期: 1
    cout << "query(ab): " << query("ab") << endl;     // 预期: 0（ab不是单词结尾）
    cout << "query(xyz): " << query("xyz") << endl;   // 预期: 0
    cout << "starts_with(ab): " << starts_with("ab") << endl;  // 预期: 1
    cout << "starts_with(abc): " << starts_with("abc") << endl; // 预期: 1
    cout << "starts_with(abe): " << starts_with("abe") << endl; // 预期: 0
    cout << "节点总数: " << tot << endl;  // 根0 + a(1) + b(2) + c(3) + d(4) + b(5) + c(6) + d(7) = 7

    return 0;
}

    坑： 数组模拟 Trie 的 MAXN 要开够（总字符数，不是字符串个数）。字符集大时（如大小写+数字=62）空间会膨胀，这时用 map<char,int> 或指针动态分配更省空间。cnt[u] 记录的是"以u结尾的单词数"，不是"经过u的单词数"——要统计前缀出现次数需要额外维护。

    3. 01 字典树（异或最值）¶

    大白话引入¶

    给你一个数组 a，求 max(a[i] XOR a[j])。暴力 O(n²)。

    01字典树：把每个数的二进制位（从高位到低位）插入 Trie，每个节点只有两个子节点（0和1）。查询时，从高位开始，贪心走和当前位相反的分支（因为异或要最大，每一位尽量是1），走不了相反就走相同。

    思维启发¶

    为什么贪心从高位开始？因为高位的权重大——最高位是1，比后面所有位都是1还大。所以每一步优先让当前位异或结果为1。

    比如数 5（101）和 3（011）： - 5 的二进制：1 0 1 - 3 的二进制：0 1 1 - 异或：1 1 0 = 6

    查询 5 的最大异或配对： - 最高位 1：想走 0 分支（1 XOR 0 = 1），有3的最高位是0，走0 - 下一位 0：想走 1 分支（0 XOR 1 = 1），3的下一位是1，走1 - 最低位 1：想走 0 分支，但3的最低位是1，只能走1（1 XOR 1 = 0） - 结果：110 = 6

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005 * 32;  // 每个数最多32位
const int BITS = 31;            // 从第30位到第0位（共31位，非负整数）

int trie[MAXN][2];  // 01字典树，只有0和1两个子节点
int tot;

void init() {
    tot = 0;
    memset(trie, 0, sizeof(trie));
}

// 插入一个数的二进制位（从高位到低位）
void insert(int x) {
    int u = 0;
    for (int i = BITS; i >= 0; i--) {
        int bit = (x >> i) & 1;  // 取第i位
        if (trie[u][bit] == 0) {
            trie[u][bit] = ++tot;
        }
        u = trie[u][bit];
    }
}

// 查询与 x 异或的最大值
int query_max_xor(int x) {
    int u = 0;
    int result = 0;
    for (int i = BITS; i >= 0; i--) {
        int bit = (x >> i) & 1;
        int want = 1 - bit;  // 想走相反的位，让异或结果为1
        if (trie[u][want] != 0) {
            // 能走相反位，这一位异或结果为1
            result |= (1 << i);
            u = trie[u][want];
        } else {
            // 只能走相同位，这一位异或结果为0
            u = trie[u][bit];
        }
    }
    return result;
}

int main() {
    init();
    int a[] = {3, 10, 5, 25, 2, 8};
    int n = 6;

    // 先插入所有数
    for (int i = 0; i < n; i++) {
        insert(a[i]);
    }

    // 对每个数查询最大异或，取全局最大
    int ans = 0;
    for (int i = 0; i < n; i++) {
        int cur = query_max_xor(a[i]);
        cout << a[i] << " 的最大异或: " << cur << endl;
        ans = max(ans, cur);
    }
    cout << "全局最大异或对: " << ans << endl;
    // 预期: 25 XOR 10 = 19 (11001 XOR 01010 = 10011 = 19)
    // 或 25 XOR 2 = 27 (11001 XOR 00010 = 11011 = 27)
    // 实际最大是 25 XOR 10... 让我们验证: 25=11001, 10=01010, XOR=10011=19
    // 25 XOR 2 = 11001 XOR 00010 = 11011 = 27
    // 25 XOR 8 = 11001 XOR 01000 = 10001 = 17
    // 10 XOR 5 = 01010 XOR 00101 = 01111 = 15
    // 所以最大是 27

    return 0;
}

    坑： 01字典树的位数要根据数据范围定：int 用 31 位（第30位到0位，不含符号位），long long 用 63 位。数组大小 = 数的个数 × 位数。查询时如果两个分支都不存在说明树为空（但通常先插入再查询）。求最小异或就把 want = 1-bit 改成 want = bit（优先走相同位）。

    4. 可持久化 Trie（简介）¶

    核心思想¶

    可持久化数据结构支持"查询历史版本"。可持久化 Trie 在每次插入时，只新建发生变化的节点，未变化的节点共享。这样可以保留每个版本的根节点，查询"第 l 到 r 个数中与 x 异或最大的值"。

    应用：区间异或最值、可持久化01字典树。

    实现要点： - 每次插入新建一条路径（最多 BITS 个新节点） - 未修改的子节点指针直接复制旧版本 - 维护每个版本的根节点 root[i] - 区间查询用 root[r] 和 root[l-1] 的节点计数差判断分支是否有元素

    可持久化 Trie 代码量较大，竞赛中属于进阶内容。理解普通 Trie 和 01 Trie 后再学可持久化。
