    1. 大白话引入¶

    想象你在一栋楼里找一个人（比如找"张三"）：

    • DFS（深度优先）：你从一楼进门，一条走廊走到黑，每个房间都进去翻一遍，翻完再退回来，去翻另一条走廊。走到底才回头——所以叫"深度"优先。
    • BFS（广度优先）：你一层一层找。先把一楼所有房间搜一遍，没人；再上二楼把所有房间搜一遍……因为人大概率就在附近楼层，所以叫"广度"优先。

    对应到算法： - DFS：一条路走到底，不行就回溯换路。用递归或栈实现 - BFS：一层层向外扩散。用队列实现

    2. 思维启发 & 思考流程¶

    拿到一道搜索题，怎么选 DFS 还是 BFS？

    问自己三个问题¶

    ① 我关心"到达终点"还是"所有可能方案"？ - 要求输出所有方案 / 所有排列（比如全排列、数独）→ DFS - 因为 DFS 会完整探索每一条路径，天然适合枚举 - 只求最短路径 / 最小步数（迷宫最短步数）→ BFS - 因为 BFS 按层扩展，第一次到达终点的层数一定是最短步数

    ② 状态空间大不大？ - 状态多但每个状态能走的方向少 → DFS（栈深但空间省） - 状态多且要避免重复 → BFS（逐层扩展方便判重）

    ③ 有没有"回溯"需求？ - 需要"走错了要回头重新选"（如八皇后、排列组合）→ DFS + 回溯 - 不需要回头，只要"最近的最优" → BFS

    看到搜索题 → 判断：
├─ 枚举所有方案 → DFS + 回溯
├─ 找最短路径 → BFS（层数 = 步数）
├─ 图/矩阵连通性 → DFS 或 BFS 都行（连通块计数）
└─ 有状态限制（走过不能再走）→ 加 visited 数组判重

    新手最容易踩的坑：BFS 忘了标记已访问 → 死循环；DFS 回溯时忘了恢复状态 → 方案重复或漏解。

    3. 核心讲解¶

    3.1 DFS（深度优先搜索）¶

    核心思想：一条路走到底，走不通就回溯，换另一条路。

    模板套路：

    1
2
3
4
5
6
7
8
9
    dfs(当前状态):
    if 到达边界/找到答案:
        记录答案
        return
    for 每一种可能的选择:
        if 选择合法:
            标记选择（占用）
            dfs(进入下一层)
            撤销标记（回溯）   ← 关键！

    三个要点： 1. 标记：进入某状态前，先标记"这个位置/这个数被用了" 2. 递归：进入下一层 3. 撤销：回来时把标记恢复，让其他分支能用

    撤销标记是 DFS 的灵魂——全排列里选过 1 之后，如果不撤销，后面的排列就再也没法用 1 了。

    3.2 BFS（广度优先搜索）¶

    核心思想：从起点出发，一层一层向外扩展，每一层离起点距离都相同。

    模板套路：

     1
 2
 3
 4
 5
 6
 7

10
11
    BFS(起点):
    队列 = [起点]
    标记起点已访问
    while 队列非空:
        取出队首 u
        for 从 u 能到达的每个 v:
            if v 未访问:
                标记 v 已访问
                记录 dist[v] = dist[u] + 1
                队列.push(v)          ← 关键！新状态入队
    return dist[终点]

    为什么 BFS 能找到最短路？ 因为 BFS 按"距离起点 0 层、1 层、2 层……"的顺序扩展，第一次遇到终点的层数就是最短步数。前提是每一步代价相同（比如迷宫每走一格算一步）。如果代价不同，要用 Dijkstra。

    3.3 DFS 与 BFS 对比¶

    DFS BFS
    实现方式 递归 / 栈 队列
    空间复杂度 与路径深度有关（省） 与分支数量有关（可能大）
    适合场景 枚举方案、回溯、连通性 最短路、最小步数、分层扩散
    是否保证最短 ❌ 不保证 ✅ 保证（等权图）
    典型问题 全排列、八皇后、数独 迷宫最短路、走迷宫最小步数

    #include <bits/stdc++.h>
using namespace std;

// 全排列：输出 1~n 的所有排列
// 例：n=3 → 123, 132, 213, 231, 312, 321
// 思路：第一个位置选一个数 → 第二个位置从剩下的选 → ...
// 用一个数组记录当前排列，一个 bool 数组标记哪些数被用过

int n;
int ans[15];          // 当前排列（最多 n 个位置）
bool used[15];        // used[i] = true 表示数字 i 已经被用了

// pos 表示当前要填第几个位置（0 开始）
void dfs(int pos) {
    // === 边界：所有位置都填完了 ===
    if (pos == n) {
        // 输出当前排列
        for (int i = 0; i < n; i++) cout << ans[i] << " \n"[i == n - 1];
        return;
    }

    // === 尝试每个数字 ===
    for (int i = 1; i <= n; i++) {
        if (used[i]) continue;   // i 已经被前面的位置用了，跳过
        used[i] = true;          // 标记占用
        ans[pos] = i;            // 填到当前位置
        dfs(pos + 1);            // 递归填下一个位置
        used[i] = false;         // ← 回溯！撤销占用，让其他分支能用 i
        // 注意 ans[pos] 不用撤销：下一轮会覆盖它
    }
}

int main() {
    cin >> n;
    dfs(0);
    return 0;
}

    如果忘了 used[i] = false 会怎样？ - 第一次递归会走出 123...n，但回溯时所有数字都"被用过"，后面的分支一个都走不出来 - 最终只会输出一个排列，而且后面几层直接全被 continue 跳过

    #include <bits/stdc++.h>
using namespace std;

// 迷宫最短路：n×m 迷宫，'#' 是墙，'.' 是路，求从 (1,1) 到 (n,m) 最少走几步
// BFS 保证第一次到达终点时的步数就是最短步数

const int MAXN = 105;
int n, m;
char maze[MAXN][MAXN];  // 迷宫地图
int dist[MAXN][MAXN];   // 记录到达每个格子的步数，-1 表示还没访问过

// 四个方向：上、下、左、右
// 用两个数组写死方向，比手写 4 个 if 更不易错
int dx[4] = {-1, 1, 0, 0};
int dy[4] = {0, 0, -1, 1};

int bfs(int sx, int sy) {
    // 队列存坐标，用 pair 打包
    queue<pair<int, int>> q;

    // 初始化：起点步数 0，标记已访问
    memset(dist, -1, sizeof(dist));
    dist[sx][sy] = 0;
    q.push({sx, sy});

    while (!q.empty()) {
        auto [x, y] = q.front(); q.pop();

        // 到达终点，直接返回步数
        // BFS 第一次到达的一定是最短的
        if (x == n && y == m) return dist[x][y];

        // 尝试四个方向
        for (int d = 0; d < 4; d++) {
            int nx = x + dx[d];
            int ny = y + dy[d];

            // 越界检查：超出地图范围就跳过
            if (nx < 1 || nx > n || ny < 1 || ny > m) continue;
            // 撞墙检查
            if (maze[nx][ny] == '#') continue;
            // 判重：已经访问过就不再用
            // 这里用 dist[nx][ny] != -1 判断，省一个 visited 数组
            if (dist[nx][ny] != -1) continue;

            // 新格子步数 = 当前格子步数 + 1
            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }
    // 走不到终点
    return -1;
}

int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            cin >> maze[i][j];
    cout << bfs(1, 1) << endl;
    return 0;
}

    为什么 BFS 这里不会死循环？ 每个格子被 dist 标记后就只会入队一次，所以队列最多处理 n×m 个格子，时间复杂度 O(n×m)。

    如果忘了判重会怎样？ 两个相邻格子会互相反复入队，队列无限膨胀，直到内存爆掉——这是 BFS 最经典的错误。

    #include <bits/stdc++.h>
using namespace std;

// 连通块计数：'#' 是陆地，'.' 是水，求有多少块连通的陆地
// 四个方向相邻的 '#' 算同一块
// 思路：遍历每个格子，遇到没访问过的 '#' 就启动一次 DFS，把整块都标记掉
// 启动 DFS 的次数就是连通块的数量

const int MAXN = 105;
int n, m;
char grid[MAXN][MAXN];
bool visited[MAXN][MAXN];

int dx[4] = {-1, 1, 0, 0};
int dy[4] = {0, 0, -1, 1};

void dfs(int x, int y) {
    // 标记当前格，防止重复访问
    visited[x][y] = true;

    // 向四个方向扩展
    for (int d = 0; d < 4; d++) {
        int nx = x + dx[d];
        int ny = y + dy[d];

        if (nx < 1 || nx > n || ny < 1 || ny > m) continue;  // 越界
        if (grid[nx][ny] != '#') continue;                    // 不是陆地
        if (visited[nx][ny]) continue;                        // 已访问

        dfs(nx, ny);   // 递归标记相邻的陆地
    }
}

int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            cin >> grid[i][j];

    int cnt = 0;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (grid[i][j] == '#' && !visited[i][j]) {
                cnt++;          // 发现一块新陆地
                dfs(i, j);      // 把这一整块都标记完
            }
        }
    }
    cout << cnt << endl;
    return 0;
}

    连通块计数的核心思想：DFS 在这里不是"找路"，而是"染色"——一次 DFS 把一整块区域全部标记，主循环数一下启动了几次 DFS。

    本节重点： - DFS：一条路走到底 + 回溯。递归实现，适合枚举方案。回溯时一定要恢复标记 - BFS：一层层扩展。队列实现，适合最短路。入队前一定要判重 - 判断用哪个：枚举方案 → DFS；最短步数 → BFS；连通性 → 都行 - 常见坑 1：BFS 忘记判重 → 死循环爆内存 - 常见坑 2：DFS 回溯忘记恢复标记 → 方案缺失或重复 - 常见坑 3：矩阵遍历时越界检查要放在访问数组之前，否则会越界访问出错
