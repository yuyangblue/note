    1. 最大公约数 gcd¶

    大白话引入¶

    两个数的最大公约数（gcd）就是能同时整除它们的最大整数。比如 gcd(12, 18) = 6。

    暴力做法：从 min(a,b) 往下试，第一个能同时整除 a 和 b 的就是答案。但 a,b 到 10¹⁸ 时暴力完全不可行。

    核心讲解：欧几里得算法¶

    核心公式：gcd(a, b) = gcd(b, a mod b)

    为什么？设 a = b·q + r（0 ≤ r < b），如果 d 整除 a 和 b，那么 d 也整除 r = a - b·q。反过来，如果 d 整除 b 和 r，那么 d 也整除 a = b·q + r。所以 (a,b) 和 (b,r) 的公约数完全相同，最大公约数也相同。

    不断递归，直到 b = 0，此时 a 就是答案。

    时间复杂度：O(log min(a,b))，因为每次至少减少一半（实际更紧，是 O(log) 级别的）。

    #include <bits/stdc++.h>
using namespace std;

// 递归版 gcd
long long gcd(long long a, long long b) {
    // 终止条件：b为0时，a就是最大公约数
    if (b == 0) return a;
    // 核心：gcd(a,b) = gcd(b, a%b)
    return gcd(b, a % b);
}

// 迭代版 gcd（避免递归栈溢出，竞赛更常用）
long long gcd_iter(long long a, long long b) {
    while (b != 0) {
        long long temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

// 最小公倍数 lcm = a / gcd(a,b) * b
// ⚠️ 先除后乘，防止 a*b 溢出
long long lcm(long long a, long long b) {
    return a / gcd(a, b) * b;
}

int main() {
    cout << gcd(12, 18) << endl;       // 预期: 6
    cout << gcd_iter(1071, 462) << endl; // 预期: 21
    cout << lcm(4, 6) << endl;         // 预期: 12
    cout << gcd(0, 5) << endl;         // 预期: 5（gcd(0,n)=n）
    return 0;
}

    坑： lcm 必须先除后乘！a * b / gcd 在 a,b 较大时会溢出 long long。C++17 有 std::gcd 和 std::lcm（在 <numeric> 中），但竞赛中手写更可控。

    2. 扩展欧几里得 exgcd¶

    大白话引入¶

    gcd 只能求出最大公约数，但有时候我们需要更多：找到整数 x, y，使得 a·x + b·y = gcd(a, b)。这就是扩展欧几里得。

    它的用途很广：求乘法逆元、解线性同余方程、中国剩余定理。

    思维启发¶

    从 gcd 的递归过程反推。当 b=0 时，gcd(a,0)=a，显然 a·1 + 0·0 = a，所以 x=1, y=0。

    回溯时，假设我们已经知道了 gcd(b, a mod b) 的解 x', y'，即 b·x' + (a mod b)·y' = gcd。

    因为 a mod b = a - ⌊a/b⌋·b，代入得： b·x' + (a - ⌊a/b⌋·b)·y' = gcd a·y' + b·(x' - ⌊a/b⌋·y') = gcd

    所以上一层的解：x = y'，y = x' - ⌊a/b⌋·y'。

    #include <bits/stdc++.h>
using namespace std;

// 扩展欧几里得：求 x,y 使得 a*x + b*y = gcd(a,b)
// 返回 gcd(a,b)，x,y 通过引用带回
long long exgcd(long long a, long long b, long long& x, long long& y) {
    if (b == 0) {
        // 终止：a*1 + 0*0 = a = gcd(a,0)
        x = 1;
        y = 0;
        return a;
    }
    long long x1, y1;
    long long g = exgcd(b, a % b, x1, y1);
    // 回溯：x = y1, y = x1 - (a/b)*y1
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}

// 解线性同余方程 a*x ≡ c (mod m)
// 有解条件：gcd(a,m) | c
// 返回 true 表示有解，解存在 x 中（最小非负解）
bool linear_equation(long long a, long long b, long long c, long long& x) {
    long long y;
    long long g = exgcd(a, b, x, y);
    if (c % g != 0) return false;  // 无解
    // 特解乘以 c/g
    x = x * (c / g);
    // 通解：x = x0 + (b/g)*t，取最小非负解
    long long mod = b / g;
    x = (x % mod + mod) % mod;
    return true;
}

int main() {
    long long x, y;
    long long g = exgcd(35, 15, x, y);
    cout << "gcd(35,15)=" << g << ", x=" << x << ", y=" << y << endl;
    // 验证：35*1 + 15*(-2) = 35-30 = 5 = gcd
    cout << "验证: 35*" << x << " + 15*" << y << " = " << 35*x + 15*y << endl;

    // 解 3x ≡ 2 (mod 7) → 3x + 7y = 2
    long long sol;
    if (linear_equation(3, 7, 2, sol)) {
        cout << "3x ≡ 2 (mod 7) 的最小非负解: x=" << sol << endl;
        // 验证：3*3=9 ≡ 2 (mod 7) ✓
    }
    return 0;
}

    坑： exgcd 求出的 x,y 可能是负数，使用时需要取模转正。通解形式是 x = x₀ + (b/g)·t，周期是 b/g。

    3. 素数筛¶

    大白话引入¶

    素数（质数）：大于1的自然数中，除了1和自身外不能被其他数整除的数。

    判断单个素数：试除法，O(√n)。但如果要找出 1~n 中所有素数，一个个判断太慢了。用筛法批量处理。

    3.1 埃氏筛（埃拉托斯特尼筛）¶

    思路： 从2开始，每个素数把它的所有倍数标记为合数。

    3.2 欧拉筛（线性筛）¶

    埃氏筛的问题：6 被 2 和 3 各标记一次，重复了。欧拉筛保证每个合数只被它的最小素因子标记一次。

    思路： 维护已找到的素数列表 primes。对每个数 i，遍历 primes 中的素数 p，标记 i·p 为合数；当 p 整除 i 时停止（因为 i 的最小素因子就是 p，再往后的素数不是 i·p 的最小素因子了）。

    时间复杂度：O(n)，真正的线性。

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 100;  // 演示用，实际可开到 1e7

// 埃氏筛
void sieve_eratosthenes(int n, vector<bool>& isPrime) {
    isPrime.assign(n + 1, true);
    isPrime[0] = isPrime[1] = false;
    for (int i = 2; i * i <= n; i++) {
        if (isPrime[i]) {
            // 从 i*i 开始标记，更小的倍数已被更小素数标记
            for (int j = i * i; j <= n; j += i) {
                isPrime[j] = false;
            }
        }
    }
}

// 欧拉筛（线性筛）
void sieve_euler(int n, vector<int>& primes, vector<bool>& isPrime) {
    isPrime.assign(n + 1, true);
    isPrime[0] = isPrime[1] = false;
    primes.clear();
    for (int i = 2; i <= n; i++) {
        if (isPrime[i]) {
            primes.push_back(i);  // i 是素数，加入列表
        }
        // 用已有的素数去筛 i 的倍数
        for (int p : primes) {
            if (1LL * i * p > n) break;
            isPrime[i * p] = false;
            if (i % p == 0) break;  // ⚠️ 关键：p是i的最小素因子，停止
        }
    }
}

int main() {
    // 埃氏筛测试
    vector<bool> isPrime1;
    sieve_eratosthenes(30, isPrime1);
    cout << "埃氏筛 1~30 的素数: ";
    for (int i = 2; i <= 30; i++) {
        if (isPrime1[i]) cout << i << " ";
    }
    cout << endl;

    // 欧拉筛测试
    vector<int> primes;
    vector<bool> isPrime2;
    sieve_euler(30, primes, isPrime2);
    cout << "欧拉筛 1~30 的素数: ";
    for (int p : primes) cout << p << " ";
    cout << endl;
    cout << "素数个数: " << primes.size() << endl;

    return 0;
}

    坑： 欧拉筛的 if (i % p == 0) break; 是灵魂——不写就退化成埃氏筛（有重复标记），写了才保证每个合数只被最小素因子筛一次。埃氏筛用 vector<bool> 最省空间（位压缩），但访问稍慢；欧拉筛需要同时维护素数列表。

    4. 快速幂¶

    大白话引入¶

    求 a^b mod p。暴力做法：乘 b 次，O(b)。b 到 10¹⁸ 时完全不可行。

    快速幂利用二进制分解：把 b 写成二进制，a^b = a(2k₁) × a(2k₂) × ...，每次把底数平方，指数右移一位。O(log b)。

    思维启发¶

    比如求 3^13： - 13 的二进制是 1101 = 8 + 4 + 1 - 3^13 = 3^8 × 3^4 × 3^1 - 我们不需要分别算 3^1, 3^4, 3^8，而是维护一个变量 base = 3，每次平方：3 → 9 → 81 → 6561 - 同时看 b 的二进制位，是1就把当前 base 乘进答案

    #include <bits/stdc++.h>
using namespace std;

const long long MOD = 1e9 + 7;

// 迭代版快速幂：求 (base^exp) % mod
long long qpow(long long base, long long exp, long long mod = MOD) {
    long long result = 1;
    base %= mod;  // 先取模，防止 base 本身就很大
    while (exp > 0) {
        if (exp & 1) {  // exp 的最低位是1
            result = result * base % mod;
        }
        base = base * base % mod;  // 底数平方
        exp >>= 1;  // 指数右移一位（除以2）
    }
    return result;
}

// 递归版快速幂（帮助理解，竞赛用迭代版）
long long qpow_rec(long long base, long long exp, long long mod = MOD) {
    if (exp == 0) return 1;
    long long half = qpow_rec(base, exp / 2, mod);
    if (exp % 2 == 0) {
        return half * half % mod;
    } else {
        return half * half % mod * base % mod;
    }
}

// 快速乘：求 (a*b) % mod，防止 a*b 溢出
// 原理和快速幂一样，把乘法拆成加法
long long qmul(long long a, long long b, long long mod = MOD) {
    long long result = 0;
    a %= mod;
    while (b > 0) {
        if (b & 1) {
            result = (result + a) % mod;
        }
        a = (a + a) % mod;
        b >>= 1;
    }
    return result;
}

int main() {
    cout << qpow(2, 10) << endl;        // 预期: 1024
    cout << qpow(3, 13, 1000) << endl;  // 3^13=1594323, mod 1000 = 323
    cout << qpow_rec(2, 10) << endl;     // 预期: 1024
    cout << qmul(123456789, 987654321) << endl; // 大整数乘法取模
    return 0;
}

    坑： 每一步乘法后都要取模，否则中间结果会溢出。result * base 在 mod=1e9+7 时最大约 1e18，刚好在 long long 范围内（9.2e18），但如果 mod 更大（如 1e18），就需要用 __int128 或快速乘。快速幂的 exp 必须是 long long，int 会溢出。

    5. 乘法逆元¶

    大白话引入¶

    在模运算中，除法不能直接做。(a / b) mod p 不等于 (a mod p) / (b mod p)。

    我们需要找到一个数 x，使得 b·x ≡ 1 (mod p)，这样 (a / b) mod p = (a · x) mod p。这个 x 就是 b 在模 p 下的乘法逆元，记作 b⁻¹。

    有逆元的条件： gcd(b, p) = 1（b 和 p 互质）。

    两种求法¶

    方法一：费马小定理（p 是素数时） - 费马小定理：如果 p 是素数且 gcd(b,p)=1，则 b^(p-1) ≡ 1 (mod p) - 所以 b^(p-2) ≡ b⁻¹ (mod p) - 用快速幂求 b^(p-2) mod p 即可

    方法二：扩展欧几里得（p 不是素数但 gcd(b,p)=1 时） - 解 b·x + p·y = 1，x 就是逆元 - 用 exgcd 求解

    #include <bits/stdc++.h>
using namespace std;

long long exgcd(long long a, long long b, long long& x, long long& y) {
    if (b == 0) { x = 1; y = 0; return a; }
    long long x1, y1;
    long long g = exgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}

long long qpow(long long base, long long exp, long long mod) {
    long long result = 1;
    base %= mod;
    while (exp > 0) {
        if (exp & 1) result = result * base % mod;
        base = base * base % mod;
        exp >>= 1;
    }
    return result;
}

// 方法一：费马小定理求逆元（p必须是素数）
long long inv_fermat(long long b, long long p) {
    return qpow(b, p - 2, p);
}

// 方法二：扩展gcd求逆元（p不要求是素数，但gcd(b,p)=1）
long long inv_exgcd(long long b, long long p) {
    long long x, y;
    long long g = exgcd(b, p, x, y);
    // g != 1 说明无逆元
    if (g != 1) return -1;
    // 取最小非负解
    return (x % p + p) % p;
}

// 线性递推求 1~n 的逆元（O(n)，p是素数）
// 公式：inv[i] = -(p/i) * inv[p%i] mod p
void inv_linear(int n, long long p, vector<long long>& inv) {
    inv.resize(n + 1);
    inv[1] = 1;
    for (int i = 2; i <= n; i++) {
        inv[i] = (p - p / i) * inv[p % i] % p;
    }
}

int main() {
    long long p = 7;  // 素数模数

    // 求 3 在模7下的逆元：3*5=15≡1(mod7)，所以逆元是5
    cout << "费马小定理: inv(3) mod 7 = " << inv_fermat(3, 7) << endl;  // 预期: 5
    cout << "扩展gcd:   inv(3) mod 7 = " << inv_exgcd(3, 7) << endl;    // 预期: 5

    // 验证：(6 / 3) mod 7 = 6 * inv(3) mod 7 = 6*5 mod 7 = 30 mod 7 = 2
    cout << "(6/3) mod 7 = " << 6 * inv_fermat(3, 7) % 7 << endl;  // 预期: 2

    // 线性递推求 1~6 的逆元
    vector<long long> inv;
    inv_linear(6, 7, inv);
    cout << "1~6 mod 7 的逆元: ";
    for (int i = 1; i <= 6; i++) cout << inv[i] << " ";
    cout << endl;
    // 验证：inv[2]=4 (2*4=8≡1), inv[3]=5, inv[4]=2 (4*2=8≡1), inv[5]=3, inv[6]=6

    return 0;
}

    坑： 费马小定理只在 p 是素数时成立。p 不是素数时用扩展gcd。线性递推 inv[i] = (p - p/i) * inv[p%i] % p 中的 p - p/i 是为了避免负数（等价于 -(p/i)），必须取模。

    6. 组合数¶

    大白话引入¶

    C(n, k) = n! / (k! · (n-k)!)，从 n 个元素中选 k 个的方案数。

    直接算阶乘会溢出，而且模运算中除法要转成乘逆元。竞赛中常见做法：预处理阶乘和阶乘的逆元，然后 O(1) 查询。

    核心讲解¶

    预处理： - fact[i] = i! mod p - inv_fact[i] = (i!)⁻¹ mod p = inv_fact[i+1] · (i+1) mod p（从后往前推，或用费马小定理求 inv_fact[n] = qpow(fact[n], p-2, p)）

    查询： - C(n, k) = fact[n] · inv_fact[k] · inv_fact[n-k] mod p - 边界：k < 0 或 k > n 时 C(n,k) = 0

    Lucas 定理（n 很大但 p 较小，p 是素数时）： - C(n, k) ≡ C(n mod p, k mod p) · C(⌊n/p⌋, ⌊k/p⌋) (mod p) - 递归求解，把 n,k 按 p 进制分解

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
const long long MOD = 1e9 + 7;

long long fact[MAXN];       // 阶乘
long long inv_fact[MAXN];   // 阶乘的逆元

long long qpow(long long base, long long exp, long long mod) {
    long long result = 1;
    base %= mod;
    while (exp > 0) {
        if (exp & 1) result = result * base % mod;
        base = base * base % mod;
        exp >>= 1;
    }
    return result;
}

// 预处理阶乘和阶乘逆元
void precompute(int n) {
    fact[0] = 1;
    for (int i = 1; i <= n; i++) {
        fact[i] = fact[i - 1] * i % MOD;
    }
    // 先求 n! 的逆元，再倒推
    inv_fact[n] = qpow(fact[n], MOD - 2, MOD);
    for (int i = n - 1; i >= 0; i--) {
        inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD;
    }
}

// 求 C(n, k) mod p
long long C(int n, int k) {
    if (k < 0 || k > n) return 0;
    return fact[n] * inv_fact[k] % MOD * inv_fact[n - k] % MOD;
}

// Lucas 定理：求 C(n, k) mod p（p是素数，n可以很大）
long long lucas(long long n, long long k, long long p) {
    if (k == 0) return 1;
    // C(n,k) ≡ C(n%p, k%p) * C(n/p, k/p) (mod p)
    return C(n % p, k % p) * lucas(n / p, k / p, p) % p;
}

int main() {
    precompute(20);

    // C(5,2) = 10
    cout << "C(5,2) = " << C(5, 2) << endl;   // 预期: 10
    // C(10,3) = 120
    cout << "C(10,3) = " << C(10, 3) << endl;  // 预期: 120
    // C(6,0) = 1
    cout << "C(6,0) = " << C(6, 0) << endl;    // 预期: 1
    // C(6,6) = 1
    cout << "C(6,6) = " << C(6, 6) << endl;    // 预期: 1
    // 边界：C(5,6) = 0
    cout << "C(5,6) = " << C(5, 6) << endl;    // 预期: 0

    // 杨辉三角验证
    cout << "\n杨辉三角前6行:" << endl;
    for (int n = 0; n < 6; n++) {
        for (int k = 0; k <= n; k++) {
            cout << C(n, k) << " ";
        }
        cout << endl;
    }

    return 0;
}

    坑： 预处理阶乘时数组要开够（n 的最大值+5）。inv_fact 从后往前推比逐个用快速幂求快得多（O(n) vs O(n log p)）。Lucas 定理中调用的 C(n%p, k%p) 需要 fact 数组预处理到 p-1，所以 p 不能太大（通常 p ≤ 1e5）。
