    1. 大白话引入¶

    想象你是医院急诊室的分诊护士，不断有病人进来，你需要每次把病情最重的病人先送进诊室。

    • 病人随时来（插入）
    • 每次诊室空了，你要找出当前最重的病人（取最大值）
    • 最重的病人送走后，从剩下的人里再找最重的（删除最大值后再取）

    如果用普通数组，每次找最大值要扫一遍 O(n)；如果排序维护，插入要 O(n)。堆就是为这种"动态插入 + 快速取最值"场景设计的：插入 O(log n)，取最值 O(1)，删除最值 O(log n)。

    堆也叫优先队列（Priority Queue）——不是按先来后到，而是按优先级（值的大小）出队。

    2. 思维启发：从"每次取最小"到堆¶

    朴素做法的问题¶

    需求：支持插入一个数、查询最小值、删除最小值。

    数据结构 插入 查最小 删最小
    普通数组（无序） O(1) O(n) O(n)
    有序数组 O(n) O(1) O(n)
    链表 O(1) O(n) O(1)
    堆 O(log n) O(1) O(log n)

    堆在三个操作上都很快，是"动态最值"问题的首选。

    堆的直觉¶

    如果把数排成一棵完全二叉树，并保证父节点 <= 孩子节点（最小堆），那么： - 最小值就是根节点（O(1) 直接取） - 插入时放到树的末尾，然后往上浮到合适位置（O(log n)，树高 log n） - 删除根节点时，把末尾元素放到根的位置，然后往下沉到合适位置（O(log n)）

    因为是完全二叉树，可以用数组存储，不需要指针——父节点 i 的左孩子是 2i，右孩子是 2i+1。

    3. 核心思想：二叉堆的结构与性质¶

    完全二叉树¶

    堆是一棵完全二叉树：除了最后一层，其他层都满，最后一层的节点从左到右排列。

    完全二叉树的好处：可以用数组紧凑存储，不需要指针。下标从 1 开始： - 节点 i 的左孩子：2 * i - 节点 i 的右孩子：2 * i + 1 - 节点 i 的父节点：i / 2（整数除法）

    堆的性质¶

    • 最小堆（小根堆）：每个父节点 <= 它的孩子节点。根节点是全局最小值。
    • 最大堆（大根堆）：每个父节点 >= 它的孩子节点。根节点是全局最大值。

    注意：堆只保证父节点和孩子节点之间的大小关系，不保证左右孩子之间的大小关系（左孩子不一定比右孩子小）。也不保证中序遍历有序（那是二叉搜索树，不是堆）。

    4. 基本操作：插入、删除堆顶、建堆¶

    以最小堆为例。

    插入（上浮 push_up）¶

    1. 把新元素放到数组末尾（堆的最后一个位置）
    2. 比较它和父节点：如果它比父节点小，就和父节点交换（违反了最小堆性质）
    3. 重复上一步，直到它 >= 父节点，或者它已经是根节点

    这个过程叫上浮（push_up / sift_up / percolate_up）。每次往上跳一层，最多 O(log n) 次。

    删除堆顶（下沉 push_down）¶

    1. 把堆顶（最小值）和数组末尾元素交换
    2. 堆大小减 1（相当于删掉了末尾的旧堆顶）
    3. 现在根节点是原来的末尾元素，可能违反堆性质。比较它和两个孩子，把它和最小的孩子交换
    4. 重复上一步，直到它 <= 两个孩子，或者它是叶子节点

    这个过程叫下沉（push_down / sift_down / percolate_down）。每次往下跳一层，最多 O(log n) 次。

    建堆（O(n) 批量构建）¶

    如果逐个插入 n 个元素，需要 O(n log n)。但可以O(n) 建堆：

    1. 先把所有元素随便放进数组（不保证堆性质）
    2. 从最后一个非叶子节点开始（下标 n/2），从后往前对每个节点执行下沉操作

    为什么是 O(n)？因为大部分节点在底层，下沉的层数少。数学上可以证明总操作数 < 2n。

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 1000005;
int heap[MAXN];  // 堆数组，下标从 1 开始
int sz = 0;      // 堆大小

// 上浮：把位置 x 的元素往上调到合适位置
void push_up(int x) {
    while (x > 1 && heap[x] < heap[x / 2]) {
        // 当前元素比父节点小，违反最小堆性质，交换
        swap(heap[x], heap[x / 2]);
        x /= 2;  // 继续往上看
    }
}

// 下沉：把位置 x 的元素往下调到合适位置
void push_down(int x) {
    while (x * 2 <= sz) {  // 有左孩子才需要下沉
        int child = x * 2;  // 左孩子
        // 如果右孩子存在且比左孩子更小，选右孩子（要和最小的孩子比）
        if (child + 1 <= sz && heap[child + 1] < heap[child]) {
            child++;
        }
        if (heap[x] <= heap[child]) {
            break;  // 已经比最小孩子小，堆性质满足
        }
        swap(heap[x], heap[child]);
        x = child;  // 继续往下看
    }
}

// 插入一个值
void push(int val) {
    heap[++sz] = val;  // 放到末尾
    push_up(sz);        // 上浮
}

// 删除堆顶（最小值）
void pop() {
    heap[1] = heap[sz--];  // 末尾元素放到堆顶，大小减 1
    push_down(1);            // 下沉
}

// 查询堆顶
int top() {
    return heap[1];
}

int main() {
    int n;
    scanf("%d", &n);
    while (n--) {
        int op;
        scanf("%d", &op);
        if (op == 1) {
            int x;
            scanf("%d", &x);
            push(x);
        } else if (op == 2) {
            printf("%d\n", top());
        } else {
            pop();
        }
    }
    return 0;
}

    关键点： - 数组下标从 1 开始，方便 2i / 2i+1 / i/2 的计算 - push_up：只要比父节点小就交换，直到根或满足性质 - push_down：每次选最小的孩子比较（最小堆），如果当前节点比最小孩子大就交换 - 插入 = 放末尾 + 上浮；删除堆顶 = 末尾移到堆顶 + 下沉 - 所有操作 O(log n)，查询堆顶 O(1)

    6. 堆排序¶

    堆排序利用最大堆的性质：根节点是最大值。每次把根节点和末尾交换（相当于把最大值放到末尾），然后对前面的元素重新建堆（下沉根节点），重复 n 次就得到升序数组。

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int a[MAXN];
int n;

// 最大堆的下沉操作（注意是最大堆，父节点 >= 孩子）
void push_down(int x, int len) {
    while (x * 2 <= len) {
        int child = x * 2;
        // 选更大的孩子
        if (child + 1 <= len && a[child + 1] > a[child]) {
            child++;
        }
        if (a[x] >= a[child]) {
            break;  // 已经比最大孩子大，满足最大堆性质
        }
        swap(a[x], a[child]);
        x = child;
    }
}

// 堆排序：升序输出
void heap_sort() {
    // 第一步：O(n) 建最大堆
    for (int i = n / 2; i >= 1; i--) {
        push_down(i, n);
    }
    // 第二步：每次把堆顶（最大值）和末尾交换，然后缩小堆范围
    for (int i = n; i >= 2; i--) {
        swap(a[1], a[i]);  // 最大值放到位置 i
        push_down(1, i - 1);  // 对前 i-1 个元素重新下沉
    }
}

int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
    }
    heap_sort();
    for (int i = 1; i <= n; i++) {
        printf("%d%c", a[i], i == n ? '\n' : ' ');
    }
    return 0;
}

    关键点： - 堆排序用最大堆（根是最大值），每次把最大值放到末尾，最终得到升序 - 建堆 O(n)，n 次下沉每次 O(log n)，总时间 O(n log n) - 空间 O(1)（原地排序），是不稳定排序 - 排序过程中 push_down 的第二个参数 len 表示当前堆的大小（每次减 1）

    • push(x)：插入
    • top()：取堆顶
    • pop()：删除堆顶
    • size() / empty()

    最小堆的声明比较长，记住三个参数：元素类型, 底层容器(默认vector), 比较函数(greater<T>表示最小堆)。

    经典应用：合并果子（P1090 / 哈夫曼树）¶

    题意：有 n 堆果子，每次合并两堆，消耗体力等于两堆果子数之和。求合并成一堆的最小体力消耗。

    思路：这是经典的哈夫曼树问题。每次选最小的两堆合并，合并后的新堆再放回去，重复直到只剩一堆。用最小堆维护所有堆的大小，每次取两个最小的。

    #include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    scanf("%d", &n);

    // 最小堆：每次取最小的两堆合并
    priority_queue<int, vector<int>, greater<int>> pq;

    for (int i = 1; i <= n; i++) {
        int x;
        scanf("%d", &x);
        pq.push(x);
    }

    long long ans = 0;  // 体力消耗可能超 int（n=1e4, 每堆1e4, 总和1e8, 累加可能超int）
    while (pq.size() > 1) {
        // 取最小的两堆
        int a = pq.top(); pq.pop();
        int b = pq.top(); pq.pop();
        ans += a + b;     // 合并消耗体力
        pq.push(a + b);   // 合并后的新堆放回去
    }

    printf("%lld\n", ans);
    return 0;
}

    关键点： - 用最小堆，每次取两个最小的合并（哈夫曼贪心策略） - 合并后的新堆要 push 回去，继续参与后续合并 - 体力消耗用 long long：n=1e4 时总和可能达 1e8，累加过程中可能超 int - 时间复杂度 O(n log n)：n 次合并，每次 push/pop O(log n)

    为什么每次选最小的两堆是最优的？ 这是哈夫曼树的性质：越小的数应该被累加越多的次数（在树的越深的位置，被加到根的路径上出现越多），所以先合并小的，让它们被多算几次，大的数晚合并、少被累加。这是贪心正确性的直觉。

    8. 堆的其他应用场景¶

    应用 思路
    Top K 求最大的 K 个数：维护大小为 K 的最小堆，新元素比堆顶大就替换
    Dijkstra 最短路 用最小堆维护"距离最小的未访问节点"，O((n+m)log n)
    Prim 最小生成树 用最小堆维护"连接到生成树的最小边"
    合并 K 个有序链表 最小堆维护每个链表的当前头，每次取最小的
    中位数维护 最大堆存前半部分，最小堆存后半部分，两个堆配合 O(log n) 插入 + O(1) 查询中位数
    事件模拟 按时间戳排序的事件队列，每次取最早发生的事件
