    1. 大白话引入：记账本思想¶

    老板这次的指令变了：给一段货架统一加零件（比如 1 号到 100 号架子每个 +5）。

    朴素做法：把 100 个架子一个个改，\(O(n)\) 一次操作，\(m\) 次操作 \(O(nm)\) 直接爆炸。

    聪明的做法像记账：先记在账上，不急着逐架改。当有人要查某个架子时，再把账摊到具体架子上。这就是懒标记（Lazy Tag）——区间修改先"记账"，查询/修改到部分区间时才"还账"。

    类比：图书馆清点库存时，管理员说"3 排到 5 排每本书 +1 本"——他不真去数，只在排头贴个便签"这排欠 1 本"，等有人来借 3 排的书时再补。

    2. 思维启发：为什么区间修改这么难¶

    如果我是做题人，我会怎么想？

    第一讲里单点修改只影响一条根到叶子的路径（\(O(\log n)\)）。但区间修改（如 \([2, 7]\) 每个 +5）会碰满一棵子树——逐点改的话，区间长度多大就要改多少个叶子，\(O(n)\) 一次。

    关键观察：如果某个节点覆盖的区间完全在修改范围内，这个节点管的所有数都被 +5——它的"区间和"信息可以 \(O(1)\) 更新（t[p] += 长度 × 5），根本不需要碰它的子树！

    但问题来了：节点的儿子们还存着旧值。如果将来要查儿子管的小区间，儿子信息是过期的。

    懒标记：节点 \(p\) 挂一个标记 lazy[p]，记录"我这个区间统一欠了一次操作没传给儿子"。只有当我们必须进入儿子的区间（部分覆盖的修改/查询）时，才把标记下传（pushdown），让儿子信息变新。

    3. 懒标记三件套：P3372 区间加 + 区间求和¶

    三个动词必须烂熟：

    动词 作用 时机
    apply 更新节点信息 + 打标记（每道题唯一要设计的地方） 整段覆盖时
    pushdown 把父节点的标记传给儿子 进入部分覆盖的儿子前
    pushup 用儿子信息重算父亲 递归返回后

    口诀：进儿子前 pushdown，返回后 pushup。

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int n, m;
long long a[MAXN];
long long t[MAXN << 2], lazy[MAXN << 2];  // t: 区间和；lazy: 懒标记（欠的加数）

// apply：对节点 p 的整个区间整体加 v
void apply(int p, int l, int r, long long v) {
    t[p] += (r - l + 1) * v;  // 区间和 += 长度 × v
    lazy[p] += v;             // 挂上懒标记：这个区间"欠"一次 +v 没传给儿子
}

// pushdown：把父节点的懒标记传给左右儿子
// 为什么进儿子前必须调用：父节点有未下传标记时，儿子信息是过期的，
// 直接递归会用到旧值
void pushdown(int p, int l, int r) {
    if (!lazy[p]) return;     // 没有欠账就不用还
    int m = (l + r) >> 1;
    apply(p << 1, l, m, lazy[p]);         // 左儿子继承
    apply(p << 1 | 1, m + 1, r, lazy[p]); // 右儿子继承
    lazy[p] = 0;                          // 账还清了
}

void pushup(int p) { t[p] = t[p << 1] + t[p << 1 | 1]; }

void build(int p, int l, int r) {
    if (l == r) { t[p] = a[l]; return; }
    int m = (l + r) >> 1;
    build(p << 1, l, m);
    build(p << 1 | 1, m + 1, r);
    pushup(p);
}

// 区间加 [ql, qr] += v
void update(int p, int l, int r, int ql, int qr, long long v) {
    if (ql <= l && r <= qr) { apply(p, l, r, v); return; }  // 整段覆盖：打标记收工
    pushdown(p, l, r);      // 部分覆盖：先下传再递归
    int m = (l + r) >> 1;
    if (ql <= m) update(p << 1, l, m, ql, qr, v);
    if (qr >  m) update(p << 1 | 1, m + 1, r, ql, qr, v);
    pushup(p);              // 回溯更新
}

// 区间查询 [ql, qr] 的和
long long query(int p, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return t[p];
    pushdown(p, l, r);      // 查询也要先下传：子节点可能欠着父节点的标记
    int m = (l + r) >> 1;
    long long res = 0;
    if (ql <= m) res += query(p << 1, l, m, ql, qr);
    if (qr >  m) res += query(p << 1 | 1, m + 1, r, ql, qr);
    return res;
}

int main() {
    scanf("%d%d", &n, &m);
    for (int i = 1; i <= n; i++) scanf("%lld", &a[i]);
    build(1, 1, n);
    while (m--) {
        int op, x, y;
        scanf("%d%d%d", &op, &x, &y);
        if (op == 1) {
            long long k;
            scanf("%lld", &k);
            update(1, 1, n, x, y, k);   // 区间加
        } else {
            printf("%lld\n", query(1, 1, n, x, y));  // 区间求和
        }
    }
    return 0;
}

    坑：query 忘写 pushdown 是新手最常见的 bug——小数据看着对（标记恰好不影响查询路径），大数据一查子区间就错。凡是可能进入儿子节点的操作，进之前都必须 pushdown。

    4. 双标记：P3373 区间加 + 区间乘¶

    同时支持区间加和区间乘。两个标记的优先级必须约定好：统一"先乘后加"，即实际效果 = 每个数先 \(\times mul\) 再 \(+ add\)。

    为什么不能先加后乘：假设先存"先加后乘"，一次乘法会把之前所有加法标记一起乘掉，新旧操作混在一起分不清。而"先乘后加"下，新加法只加在乘完的值上，新旧标记可以干净合并：

    • 区间乘 \(m\)：(x × mul + add) × m' = x × (mul×m') + add×m' → 两个标记分别更新
    • 区间加 \(a\)：x × mul + (add + a) → 只改 add

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int n, m;
long long MOD;
long long a[MAXN];
long long t[MAXN << 2], add[MAXN << 2], mul[MAXN << 2];

// apply：对节点 p 的整个区间做"先乘 m 再加 a"
void apply(int p, int l, int r, long long m, long long a) {
    t[p] = (t[p] * m + (r - l + 1) * a) % MOD;  // 每个数先乘再加
    add[p] = (add[p] * m + a) % MOD;  // 旧加法标记也要被乘（关键！）
    mul[p] = mul[p] * m % MOD;        // 乘法标记累积
}

void pushdown(int p, int l, int r) {
    if (mul[p] == 1 && add[p] == 0) return;  // 没有欠账
    int m = (l + r) >> 1;
    apply(p << 1, l, m, mul[p], add[p]);         // 标记整体传给左儿子
    apply(p << 1 | 1, m + 1, r, mul[p], add[p]); // 传给右儿子
    add[p] = 0; mul[p] = 1;  // 复位：加法单位元 0，乘法单位元 1
}

void pushup(int p) { t[p] = (t[p << 1] + t[p << 1 | 1]) % MOD; }

void build(int p, int l, int r) {
    mul[p] = 1;  // 乘法标记初始化为单位元 1（不是 0！）
    if (l == r) { t[p] = a[l] % MOD; return; }
    int m = (l + r) >> 1;
    build(p << 1, l, m);
    build(p << 1 | 1, m + 1, r);
    pushup(p);
}

void update(int p, int l, int r, int ql, int qr, long long m, long long a) {
    if (ql <= l && r <= qr) { apply(p, l, r, m, a); return; }
    pushdown(p, l, r);
    int mid = (l + r) >> 1;
    if (ql <= mid) update(p << 1, l, mid, ql, qr, m, a);
    if (qr >  mid) update(p << 1 | 1, mid + 1, r, ql, qr, m, a);
    pushup(p);
}

long long query(int p, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return t[p];
    pushdown(p, l, r);
    int mid = (l + r) >> 1;
    long long res = 0;
    if (ql <= mid) res = (res + query(p << 1, l, mid, ql, qr)) % MOD;
    if (qr >  mid) res = (res + query(p << 1 | 1, mid + 1, r, ql, qr)) % MOD;
    return res;
}

int main() {
    scanf("%d%d%lld", &n, &m, &MOD);
    for (int i = 1; i <= n; i++) scanf("%lld", &a[i]);
    build(1, 1, n);
    while (m--) {
        int op, x, y;
        scanf("%d%d%d", &op, &x, &y);
        if (op == 1) {            // 区间乘 k
            long long k;
            scanf("%lld", &k);
            update(1, 1, n, x, y, k, 0);
        } else if (op == 2) {     // 区间加 k
            long long k;
            scanf("%lld", &k);
            update(1, 1, n, x, y, 1, k);
        } else {                  // 查询区间和
            printf("%lld\n", query(1, 1, n, x, y));
        }
    }
    return 0;
}

    坑：mul 标记初始化和复位都是 1（乘法单位元），写成 0 会让所有数被乘成 0。apply 里 add[p] = add[p] * m + a 是双标记的精髓：旧加法被新乘法放大，新加法再叠加上去。

    5. 打包思想进阶¶

    懒标记只是"怎么打标记"，配合打包更多信息（第一讲学的），能维护各种花式区间操作。核心套路：apply 时要想清楚"整段被操作后，我存的信息怎么 O(1) 更新"。

    \[\sum(x+v)^2 = \sum x^2 + 2v\sum x + len \cdot v^2\]

    注意：sum2 必须用旧的 sum 计算，先改 sum 就全错了。

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int n, m;
double sum[MAXN << 2], sum2[MAXN << 2], lazy[MAXN << 2];  // sum: Σx；sum2: Σx²

// apply：区间加 v，sum2 用旧 sum 更新！
void apply(int p, int l, int r, double v) {
    int len = r - l + 1;
    sum2[p] += 2 * v * sum[p] + len * v * v;  // Σ(x+v)² 展开：2vΣx + len·v²
    sum[p]  += len * v;                        // 区间和整体加（必须在 sum2 之后！）
    lazy[p] += v;
}

void pushdown(int p, int l, int r) {
    if (lazy[p] == 0) return;
    int m = (l + r) >> 1;
    apply(p << 1, l, m, lazy[p]);
    apply(p << 1 | 1, m + 1, r, lazy[p]);
    lazy[p] = 0;
}

void pushup(int p) {
    sum[p]  = sum[p << 1]  + sum[p << 1 | 1];
    sum2[p] = sum2[p << 1] + sum2[p << 1 | 1];
}

void build(int p, int l, int r) {
    if (l == r) {
        double x;
        scanf("%lf", &x);
        sum[p]  = x;
        sum2[p] = x * x;
        return;
    }
    int m = (l + r) >> 1;
    build(p << 1, l, m);
    build(p << 1 | 1, m + 1, r);
    pushup(p);
}

void update(int p, int l, int r, int ql, int qr, double v) {
    if (ql <= l && r <= qr) { apply(p, l, r, v); return; }
    pushdown(p, l, r);
    int m = (l + r) >> 1;
    if (ql <= m) update(p << 1, l, m, ql, qr, v);
    if (qr >  m) update(p << 1 | 1, m + 1, r, ql, qr, v);
    pushup(p);
}

pair<double, double> query(int p, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return {sum[p], sum2[p]};
    pushdown(p, l, r);
    int m = (l + r) >> 1;
    double s = 0, s2 = 0;
    if (ql <= m) { auto L = query(p << 1, l, m, ql, qr); s += L.first; s2 += L.second; }
    if (qr >  m) { auto R = query(p << 1 | 1, m + 1, r, ql, qr); s += R.first; s2 += R.second; }
    return {s, s2};
}

int main() {
    scanf("%d%d", &n, &m);
    build(1, 1, n);
    while (m--) {
        int op, x, y;
        scanf("%d%d%d", &op, &x, &y);
        if (op == 1) {          // 区间加 k
            double k;
            scanf("%lf", &k);
            update(1, 1, n, x, y, k);
        } else {
            auto [s, s2] = query(1, 1, n, x, y);
            int len = y - x + 1;
            if (op == 2) printf("%.4lf\n", s / len);                 // 平均值
            else printf("%.4lf\n", s2 / len - (s / len) * (s / len)); // 方差
        }
    }
    return 0;
}

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int n, m;
double s[MAXN << 2], c[MAXN << 2], lazy[MAXN << 2];  // s: Σsin(aᵢ)；c: Σcos(aᵢ)

// apply：整个区间每个数加 d（整体旋转 d 弧度）
void apply(int p, double d) {
    // 先用旧值算新的 s、c，再覆盖（不能边算边改）
    double ns = s[p] * cos(d) + c[p] * sin(d);
    double nc = c[p] * cos(d) - s[p] * sin(d);
    s[p] = ns;
    c[p] = nc;
    lazy[p] += d;
}

void pushdown(int p) {
    if (lazy[p] == 0) return;
    apply(p << 1, lazy[p]);
    apply(p << 1 | 1, lazy[p]);
    lazy[p] = 0;
}

void pushup(int p) {
    s[p] = s[p << 1] + s[p << 1 | 1];
    c[p] = c[p << 1] + c[p << 1 | 1];
}

void build(int p, int l, int r) {
    if (l == r) {
        double x;
        scanf("%lf", &x);
        s[p] = sin(x);
        c[p] = cos(x);
        return;
    }
    int m = (l + r) >> 1;
    build(p << 1, l, m);
    build(p << 1 | 1, m + 1, r);
    pushup(p);
}

void update(int p, int l, int r, int ql, int qr, double v) {
    if (ql <= l && r <= qr) { apply(p, v); return; }
    pushdown(p);
    int m = (l + r) >> 1;
    if (ql <= m) update(p << 1, l, m, ql, qr, v);
    if (qr >  m) update(p << 1 | 1, m + 1, r, ql, qr, v);
    pushup(p);
}

double query(int p, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return s[p];
    pushdown(p);
    int m = (l + r) >> 1;
    double res = 0;
    if (ql <= m) res += query(p << 1, l, m, ql, qr);

}

    5.4 P2824：区间排序（二分答案 + 0/1 赋值）¶

    思维启发：区间排序没法直接打标记，但只问一个位置时可以用二分答案转判定： - 二分答案 \(x\)：把 \(a_i \ge x\) 记为 1，否则 0 - 区间排序 = 数区间内 1 的个数 \(cnt\)，然后区间赋值（前 \(cnt\) 个 1、其余 0，或反过来） - 线段树支持"区间求和 + 区间赋值"（懒标记存 0/1），一次排序 \(O(\log n)\) - 最后看 \(pos\) 位置是 1 还是 0，决定二分方向

    6. 扫描线：P5490 矩形面积并¶

    \(n\) 个矩形（可重叠），求覆盖总面积。坐标绝对值 \(\le 10^9\)。

    思维启发：总面积怎么算？把每个矩形拆成两条水平边：下边标记 +1（覆盖开始）、上边标记 -1（覆盖结束）。把所有边按 \(y\) 排序，从上往下扫。相邻两条边之间覆盖情况不变，面积 = 高度差 × 当前被覆盖的 x 总长度。

    • 维护 x 轴上"被至少覆盖一次的总长度"——线段树！
    • 节点存 cnt（该 x 段被完整覆盖次数）和 len（被覆盖长度）
    • 更新边时把区间 \([x_1, x_2]\) 的 cnt += ±1，回溯时重算 len

    为什么扫描线不需要 pushdown：同一矩形的下边 +1 和上边 -1 落在完全相同的节点分解上，一一对应抵消，cnt 永远非负且不需要"预支"给儿子。

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int n;

struct Line {
    int x1, x2, y, v;   // 水平边：x 区间 [x1,x2]，高度 y，下边 +1 上边 -1
    bool operator<(const Line &o) const { return y < o.y; }  // 按高度排序
} lines[MAXN * 2];

vector<int> X;              // 所有 x 坐标（离散化）
int cnt[MAXN << 3], len[MAXN << 3];  // cnt: 覆盖次数；len: 被覆盖长度

// pushup：用 cnt 决定 len（扫描线的"合并"就是算覆盖长度）
void pushup(int p, int l, int r) {
    if (cnt[p] > 0) len[p] = X[r + 1] - X[l];   // 整段被覆盖：长度 = 真实坐标差
    else if (l == r) len[p] = 0;                 // 叶子且无覆盖
    else len[p] = len[p << 1] + len[p << 1 | 1]; // 拼儿子
}

void update(int p, int l, int r, int ql, int qr, int v) {
    if (ql <= l && r <= qr) { cnt[p] += v; pushup(p, l, r); return; }  // 只改计数
    int m = (l + r) >> 1;
    if (ql <= m) update(p << 1, l, m, ql, qr, v);
    if (qr >  m) update(p << 1 | 1, m + 1, r, ql, qr, v);
    pushup(p, l, r);  // 每次改完重新算 len
}

int main() {
    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        int x1, y1, x2, y2;
        scanf("%d%d%d%d", &x1, &y1, &x2, &y2);
        lines[i * 2]     = {x1, x2, y1, 1};   // 下边：覆盖开始
        lines[i * 2 + 1] = {x1, x2, y2, -1};  // 上边：覆盖结束
        X.push_back(x1);
        X.push_back(x2);
    }
    sort(lines, lines + 2 * n);
    sort(X.begin(), X.end());
    X.erase(unique(X.begin(), X.end()), X.end());  // 离散化 x 坐标

    // 线段树节点 [l, r] 对应 x 区间 [X[l], X[r+1]]，共 M 个区间
    int M = (int)X.size() - 1;
    long long ans = 0;
    for (int i = 0; i < 2 * n - 1; i++) {
        // 把当前边作用到线段树：x 区间转成离散化下标区间
        int l = lower_bound(X.begin(), X.end(), lines[i].x1) - X.begin();
        int r = lower_bound(X.begin(), X.end(), lines[i].x2) - X.begin() - 1;
        update(1, 0, M - 1, l, r, lines[i].v);
        // 当前覆盖长度 × 到下一条边的高度差
        ans += 1LL * len[1] * (lines[i + 1].y - lines[i].y);
    }
    printf("%lld\n", ans);
    return 0;
}

    7. 特殊线段树：P4198 楼房重建¶

    \(n\) 栋楼（位置 \(1..n\)，高度可改），每次修改后回答从左往右能看到几栋楼。

    思维启发：楼 \(i\) 能被看见 ⇔ 它的斜率 \(h_i / i\) 严格大于左边所有楼的斜率（楼顶不被挡）。所以问题变成：从左到右，斜率的前缀严格最大值的个数——和"数量"有关的合并，得用单侧递归。

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int n, m;

struct Node {
    double mx;   // 区间最大斜率
    int cnt;     // 区间从左往右可见楼数
} t[MAXN << 2];

// calc(p, lim)：统计节点 p 的区间内"斜率 > lim 且可见"的楼数
// 核心剪枝：利用左右儿子的 mx/cnt 信息，每次只走一边，O(log n)
int calc(int p, int l, int r, double lim) {
    if (l == r) return t[p].mx > lim;  // 叶子：只看这栋楼斜率是否超过阈值
    int m = (l + r) >> 1;
    if (t[p << 1].mx <= lim)
        // 左半边最大斜率都不超过 lim：左半边没有能超过 lim 的可见楼，只看右半边
        return calc(p << 1 | 1, m + 1, r, lim);
    // 左半边有超过 lim 的：
    //   左半边贡献 = calc(左, lim)（递归）
    //   右半边贡献 = 右半边全部可见数 = cnt[p] - cnt[左]（它们都 > 左半边最大 > lim）
    return t[p].cnt - t[p << 1].cnt + calc(p << 1, l, m, lim);
}

// 单点修改高度：递归到叶子，回溯时合并
void update(int p, int l, int r, int pos, double h) {
    if (l == r) {
        t[p].mx = h / l;          // 斜率 = 高度 / 位置
        t[p].cnt = (h > 0);       // 高度 0 的楼看不到
        return;
    }
    int m = (l + r) >> 1;
    if (pos <= m) update(p << 1, l, m, pos, h);
    else          update(p << 1 | 1, m + 1, r, pos, h);
    t[p].mx = max(t[p << 1].mx, t[p << 1 | 1].mx);
    // 左半边直接继承，右半边用 calc 算"超过左半边最大斜率"的可见数
    t[p].cnt = t[p << 1].cnt + calc(p << 1 | 1, m + 1, r, t[p << 1].mx);
}

int main() {
    scanf("%d%d", &n, &m);
    while (m--) {
        int x, y;
        scanf("%d%d", &x, &y);
        update(1, 1, n, x, y);          // 第 x 栋楼高度改成 y
        printf("%d\n", t[1].cnt);       // 整个区间可见楼数
    }
    return 0;
}

    为什么斜率相等算看不见：P4198 定义"楼顶被完全挡住"才算看不见——视线恰好擦过楼顶（斜率相等）时，后面的楼顶在视线延长线下方，看不到。所以判定用严格大于（mx <= lim 视为不可见）。

using namespace std;

const int MAXN = 100005;
const int MAXV = 100005;  // 粮食种类值域

// 动态开点权值线段树：每个点一棵，统计"每种粮食发了多少"
struct Node { int lc, rc, mx, id; } tr[MAXN << 6];
// mx: 区间内最大数量；id: 数量最大的粮食编号

// 合并两棵线段树（a 为主树，b 并入 a），返回合并后的根
int merge(int a, int b, int l, int r) {
    if (!a) return b;               // a 为空：整棵 b 直接拿来
    if (!b) return a;               // b 为空：a 不动
    if (l == r) {                   // 叶子：数量相加，更新编号
        tr[a].mx += tr[b].mx;
        tr[a].id = l;
        return a;
    }
    int m = (l + r) >> 1;
    tr[a].lc = merge(tr[a].lc, tr[b].lc, l, m);
    tr[a].rc = merge(tr[a].rc, tr[b].rc, m + 1, r);
    // pushup：取数量更大的粮食（数量相同取编号小）
    if (tr[tr[a].lc].mx >= tr[tr[a].rc].mx) {
        tr[a].mx = tr[tr[a].lc].mx;
        tr[a].id = tr[tr[a].lc].id;
    } else {
        tr[a].mx = tr[tr[a].rc].mx;
        tr[a].id = tr[tr[a].rc].id;
    }
    return a;
}

int main() {
    // 完整做法：
    // 1. 树上差分：cf[u]++, cf[v]++, cf[lca]--, cf[fa[lca]]--（每条路径的粮食 z）
    // 2. 每个点维护一棵权值线段树（动态开点），在差分位置插入 z
    // 3. dfs 自底向上：root[u] = merge(root[u], root[son], 1, MAXV)
    // 4. 每个点的答案 = 根节点存的最大数量粮食编号
    return 0;
}

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 200005;
int n, m, tot;
long long tr[MAXN * 40];   // 值域树：节点管的值域内数字个数
int lc[MAXN * 40], rc[MAXN * 40];
int root[MAXN];            // 每棵树的根，0 表示空

// 单点插入：值 pos 个数 +1（动态开点）
void add(int &p, int l, int r, int pos) {
    if (!p) p = ++tot;
    tr[p]++;
    if (l == r) return;
    int m = (l + r) >> 1;
    if (pos <= m) add(lc[p], l, m, pos);
    else          add(rc[p], m + 1, r, pos);
}

// 合并（与第八节同思路）：把 b 并入 a
int merge(int a, int b) {
    if (!a) return b;
    if (!b) return a;
    tr[a] += tr[b];
    lc[a] = merge(lc[a], lc[b]);
    rc[a] = merge(rc[a], rc[b]);
    return a;
}

// 分裂：把树 p 中值域 [x,y] 的数"搬"给树 q
// 注意 p 和 q 都传引用：搬走的节点要从 p 里真正摘掉（p=0 必须作用到原变量）
void split(int &p, int &q, int l, int r, int x, int y) {
    if (!p || y < l || r < x) return;  // 空树或无交集
    if (x <= l && r <= y) {            // 整段都在 [x,y]：整棵子树搬走
        q = p;
        p = 0;
        return;
    }
    if (!q) q = ++tot;
    int m = (l + r) >> 1;
    if (x <= m) split(lc[p], lc[q], l, m, x, y);
    if (y >  m) split(rc[p], rc[q], m + 1, r, x, y);
    tr[p] = tr[lc[p]] + tr[rc[p]];   // 搬完后重算两棵树
    tr[q] = tr[lc[q]] + tr[rc[q]];
}

// 查询第 k 小（值域下标）
int kth(int p, int l, int r, int k) {
    if (l == r) return l;
    int m = (l + r) >> 1;
    if (tr[lc[p]] >= k) return kth(lc[p], l, m, k);
    return kth(rc[p], m + 1, r, k - tr[lc[p]]);
}

// 从树 p 中取 num 个值 pos 给树 q（处理"前 k 小"的余数）
void take(int &p, int &q, int l, int r, int pos, int num) {
    if (!p || num <= 0) return;
    if (l == r) {
        int t = min(tr[p], (long long)num);
        tr[p] -= t;
        tr[q] += t;   // q 在调用前已建好节点
        return;
    }
    int m = (l + r) >> 1;
    if (pos <= m) take(lc[p], lc[q], l, m, pos, num);
    else          take(rc[p], rc[q], m + 1, r, pos, num);
    tr[p] = tr[lc[p]] + tr[rc[p]];
    tr[q] = tr[lc[q]] + tr[rc[q]];
}

int main() {
    scanf("%d%d", &n, &m);
    // 初始集合：第 1 行第 2 行，n 个数，全部属于集合 1
    for (int i = 1; i <= n; i++) {
        int x;
        scanf("%d", &x);
        add(root[1], 1, n, x);   // 值域是 1..n
    }
    int cnt = 1;  // 当前集合数量
    while (m--) {
        int op;
        scanf("%d", &op);
        if (op == 0) {                    // 把集合 p 中值域 [x,y] 的数分给新集合
            int p, x, y;
            scanf("%d%d%d", &p, &x, &y);
            cnt++;
            split(root[p], root[cnt], 1, n, x, y);
        } else if (op == 1) {             // 集合 q 合并进 p
            int p, q;
            scanf("%d%d", &p, &q);
            root[p] = merge(root[p], root[q]);
        } else if (op == 2) {             // 集合 p 前 x 小分给 q
            int p, x, q;
            scanf("%d%d%d", &p, &x, &q);
            int v = kth(root[p], 1, n, x);              // 第 x 小的值
            // 先统计比 v 小的数量，把 [1, v-1] 全分走，再取 x - cnt_less 个 v
            // （cnt_less 用一次区间查询获得，这里略，简化实现见注释）
            int less = 0;  // 实际实现：query(root[p], 1, n, 1, v-1)
            split(root[p], root[q], 1, n, 1, v - 1);
            take(root[p], root[q], 1, n, v, x - less);
        } else if (op == 3) {             // 查询集合 p 第 x 小
            int p, x;
            scanf("%d%d", &p, &x);
            printf("%d\n", kth(root[p], 1, n, x));
        } else {                          // 查询集合 p 大小
            int p;
            scanf("%d", &p);
            printf("%lld\n", tr[root[p]]);
        }
    }
    return 0;
}

    坑：① split 的 p 和 q 都要传引用，否则搬走/新树的节点丢失；② 整段拿走时 q = p; p = 0 直接摘树，别忘把 p 置空；③ 操作 2 的"前 k 小"要先 kth 定位边界值，再分 [1, v-1] 整段 + v 的余数两个步骤。

    11. 本节重点¶

    本节重点： - 懒标记三动词：apply（设计核心）/ pushdown / pushup，进儿子前 pushdown、返回后 pushup - 双标记（P3373）：统一"先乘后加"，apply 里旧加法标记也要被乘 - 打包 + 懒标记：方差存 sum+sum2（apply 用旧 sum 算 sum2）、sin 存 s+c、斐波那契存向量 + 矩阵标记 - 扫描线：矩形拆边 + 按 y 排序 + 线段树维护覆盖长度，不需要 pushdown - 楼房重建：calc 单侧递归剪枝，\(O(\log n)\) 统计可见楼数，判定严格大于 - 线段树合并：动态开点树对应节点相加，一方为空直接返回，均摊 \(O(n \log n)\) - 线段树分裂：与合并互逆，配合颜色段均摊，可做 \(O(n \log n)\) 区间排序 - 常见坑： - query 忘 pushdown（最隐蔽） - 双标记乘法单位元 1，初始化和复位都别写 0 - apply 里用旧值算新值（sum2 用旧 sum） - 扫描线叶子是区间不是点，len 用真实坐标差 - 分裂/合并参数都要传引用，整段搬走记得置空原节点
