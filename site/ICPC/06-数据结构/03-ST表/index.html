    1. 大白话引入¶

    想象你是一个仓库管理员，老板随时问你："第 3 号货架到第 7 号货架之间，最贵的货物值多少钱？"

    货架有 n 个，老板问 q 次。你有几种做法：

    • 朴素做法：每次从 l 扫到 r 找最大值。O(n) 每次，q 次就是 O(n·q)，老板问得多了你就忙不过来。
    • 线段树：预处理 O(n)，每次查询 O(log n)，还支持修改。但代码长，常数稍大。
    • ST表：预处理 O(n log n)，每次查询 O(1)！代价是不支持修改（货物价格不能变），且只能求 max/min/gcd 这类"可重复贡献"的操作。

    如果老板只问不改，ST表就是最快的选择——查询只需要看两个数取个 max，连循环都不用。

    2. 思维启发：从朴素查询到倍增¶

    朴素做法的问题¶

    查询 [l, r] 的最大值，朴素要扫 r-l+1 个元素。能不能预处理一些区间的最大值，查询时直接用？

    第一步直觉：预处理所有区间？¶

    如果预处理 mx[l][r] = 区间 [l, r] 的最大值，查询就是 O(1)。但预处理要 O(n²)，n=1e5 时需要 1e10 的空间，直接爆内存。

    第二步：倍增思想¶

    不需要预处理所有区间，只预处理长度为 2 的幂的区间： - 长度 1（2⁰）的区间：就是每个元素本身 - 长度 2（2¹）的区间：每两个元素取 max - 长度 4（2²）的区间：每四个元素取 max - ... - 长度 2^k 的区间

    这样只需要 O(n log n) 的空间（n=1e5 时约 1e5 × 17 ≈ 1.7e6，完全没问题）。

    关键观察：任意区间 [l, r] 的长度 len = r-l+1，取 k = ⌊log₂(len)⌋，那么： - 从 l 开始长度为 2^k 的区间：[l, l+2^k-1] - 以 r 结尾长度为 2^k 的区间：[r-2^k+1, r]

    这两个区间一定覆盖 [l, r]（因为 2^k > len/2，两个半块拼起来覆盖整块），而且它们的并集就是 [l, r]。所以：

    1
    max([l,r]) = max( max([l, l+2^k-1]), max([r-2^k+1, r]) )

    这就是 ST表查询 O(1) 的原理——两个预处理好的区间取个 max 就行。

    为什么 max 可以这样"重叠覆盖"？因为 max 满足可重复贡献：一个元素被算两次不影响结果（max(a,a)=a）。sum 就不行（加两次会翻倍），所以 ST表不能做区间和。

    3. 核心思想：ST表的定义与预处理¶

    定义¶

    f[i][j] 表示从第 i 个位置开始，长度为 2^j 的区间的最大值。

    即 f[i][j] = max(a[i], a[i+1], ..., a[i + 2^j - 1])。

    预处理递推¶

    • 边界：f[i][0] = a[i]（长度为 1 的区间就是元素本身）
    • 递推：长度为 2^j 的区间，可以拆成两个长度为 2^(j-1) 的区间：
    1
    f[i][j] = max(f[i][j-1], f[i + 2^(j-1)][j-1])

    前半段从 i 开始，后半段从 i + 2^(j-1) 开始，两段拼起来正好是长度 2^j。

    预处理顺序¶

    外层 j 从小到大（因为 f[i][j] 依赖 f[i][j-1]），内层 i 从 1 到 n - 2^j + 1。

    1
2

    j=0: f[i][0] = a[i]
j=1: f[i][1] = max(f[i][0], f[i+1][0])    长度2
j=2: f[i][2] = max(f[i][1], f[i+2][1])    长度4
j=3: f[i][3] = max(f[i][2], f[i+4][2])    长度8
...

    手算小例子¶

    a = [9, 3, 1, 7, 5]（下标 1~5）

    f[i][j] j=0( len1 ) j=1( len2 ) j=2( len4 )
    i=1 9 max(9,3)=9 max(9,1,7,5)=9
    i=2 3 max(3,1)=3 max(3,1,7,5)=7
    i=3 1 max(1,7)=7 -（i+4-1=6>5）
    i=4 7 max(7,5)=7 -
    i=5 5 - -

    查询 [2,5]（元素 3,1,7,5）：len=4, k=2，max(f[2][2], f[2][2]) = max(7,7) = 7 ✓ 查询 [1,4]（元素 9,3,1,7）：len=4, k=2，max(f[1][2], f[1][2]) = 9 ✓ 查询 [2,4]（元素 3,1,7）：len=3, k=1（⌊log₂3⌋=1），max(f[2][1], f[3][1]) = max(3,7) = 7 ✓

    4. 查询操作：O(1) 区间最值¶

    查询公式¶

    对区间 [l, r]： 1. 计算长度 len = r - l + 1 2. 取 k = ⌊log₂(len)⌋ 3. 答案 = max(f[l][k], f[r - (1<<k) + 1][k])

    两个区间： - [l, l + 2^k - 1]：从左端开始的 2^k 长度 - [r - 2^k + 1, r]：以右端结尾的 2^k 长度

    它们的并集覆盖 [l, r]，且因为 2^k > len/2，一定有重叠——但 max 不怕重叠。

    log 的预处理¶

    每次查询算 log₂(len) 可以用 __lg(len)（GCC 内置函数，返回最高位的位置，即 ⌊log₂⌋），也可以预处理 lg[i] 数组（lg[1]=0; for (int i=2; i<=n; i++) lg[i]=lg[i/2]+1;）。预处理后查询就是纯 O(1)，连 __lg 的函数调用都省了。竞赛中两种都常用，__lg 更简洁。

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
const int LOG = 17;  // 2^17 = 131072 > 1e5

int a[MAXN];
int f[MAXN][LOG];  // f[i][j] = 从 i 开始长度 2^j 的区间最大值
int lg[MAXN];      // lg[i] = floor(log2(i))，预处理后查询 O(1)

int main() {
    int n, q;
    scanf("%d%d", &n, &q);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
        f[i][0] = a[i];  // 长度为 1 的区间就是元素本身
    }

    // 预处理 log2 数组：lg[i] = floor(log2(i))
    lg[1] = 0;
    for (int i = 2; i <= n; i++) {
        lg[i] = lg[i / 2] + 1;
    }

    // ST表预处理：外层 j（区间长度的指数），内层 i（起点）
    // f[i][j] = max(f[i][j-1], f[i + 2^(j-1)][j-1])
    for (int j = 1; j <= lg[n]; j++) {
        for (int i = 1; i + (1 << j) - 1 <= n; i++) {
            f[i][j] = max(f[i][j - 1], f[i + (1 << (j - 1))][j - 1]);
        }
    }

    // 查询：O(1)
    while (q--) {
        int l, r;
        scanf("%d%d", &l, &r);
        int len = r - l + 1;
        int k = lg[len];  // floor(log2(len))
        // 两个重叠区间取 max，覆盖 [l, r]
        int ans = max(f[l][k], f[r - (1 << k) + 1][k]);
        printf("%d\n", ans);
    }

    return 0;
}

    关键点： - f[i][0] = a[i] 是边界，长度 1 的区间最大值就是自己 - 预处理外层是 j（指数），内层是 i（起点），因为 f[i][j] 依赖 j-1 层 - i + (1 << j) - 1 <= n 保证区间不越界 - 查询用两个重叠区间：[l, l+2^k-1] 和 [r-2^k+1, r]，并集覆盖 [l,r] - lg[] 数组预处理后，查询是纯 O(1)（不用 __lg 函数调用） - 时间复杂度：预处理 O(n log n)，查询 O(1)；空间 O(n log n)

    复杂度分析：n=1e5 时，log₂n≈17，预处理约 1e5×17≈1.7e6 次操作，查询每次 1 次 max，q=1e6 也能轻松通过。

    6. 应用：同时求区间最大和最小（P2880）¶

    很多题目需要同时知道区间的最大值和最小值（如 Balanced Lineup 求最大最小差）。开两个 ST表就行——一个维护 max，一个维护 min，预处理和查询的逻辑完全一样，只是把 max 换成 min。

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 50005;
const int LOG = 16;  // 2^16 = 65536 > 5e4

int a[MAXN];
int mx[MAXN][LOG];  // 最大值 ST表
int mn[MAXN][LOG];  // 最小值 ST表
int lg[MAXN];

int main() {
    int n, q;
    scanf("%d%d", &n, &q);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
        mx[i][0] = a[i];
        mn[i][0] = a[i];
    }

    lg[1] = 0;
    for (int i = 2; i <= n; i++) {
        lg[i] = lg[i / 2] + 1;
    }

    // 同时预处理 max 和 min 两个 ST表
    for (int j = 1; j <= lg[n]; j++) {
        for (int i = 1; i + (1 << j) - 1 <= n; i++) {
            mx[i][j] = max(mx[i][j - 1], mx[i + (1 << (j - 1))][j - 1]);
            mn[i][j] = min(mn[i][j - 1], mn[i + (1 << (j - 1))][j - 1]);
        }
    }

    while (q--) {
        int l, r;
        scanf("%d%d", &l, &r);
        int k = lg[r - l + 1];
        int maxVal = max(mx[l][k], mx[r - (1 << k) + 1][k]);
        int minVal = min(mn[l][k], mn[r - (1 << k) + 1][k]);
        printf("%d\n", maxVal - minVal);
    }

    return 0;
}

    关键点： - 开两个 ST表 mx 和 mn，预处理逻辑完全一样，只是合并操作一个用 max、一个用 min - 查询时各查各的，然后做差 - 空间翻倍但仍然是 O(n log n)，完全可接受

    7. ST表的局限与变体¶

    局限¶

    1. 不支持修改：预处理后数组不能变。如果需要修改，用线段树或块状数组。
    2. 只能做"可重复贡献"的操作：max、min、gcd、lcm、按位与/或 都可以（重叠不影响结果）；sum 不行（重叠会重复计算），区间和用前缀和或线段树。
    3. 空间 O(n log n)：比线段树 O(n) 大，但 n=1e5 时约 1.7e6 个 int（约 7MB），完全没问题。

    常见变体¶

    • 二维 ST表：查询二维矩形区域的最值。f[i][j][k] 表示以 (i,j) 为左上角、边长 2^k 的正方形的最值。查询时拆成四个角。
    • ST表求区间 gcd：gcd 也满足可重复贡献（gcd(a,a)=a），把 max 换成 gcd 即可。
    • ST表 + 二分：某些问题需要找"最长的满足条件的区间"，可以二分长度 + ST表 O(1) 判断。

    ST表 vs 线段树 vs 单调栈/队列¶

    数据结构 预处理 查询 支持修改 适用场景
    ST表 O(n log n) O(1) ❌ 静态区间最值/gcd，查询极多
    线段树 O(n) O(log n) ✅ 需要修改的区间查询
    单调栈/队列 O(n) - - 离线的"下一个更大""滑动窗口"类问题

    选择原则：静态查询多 → ST表；需要修改 → 线段树；特定模式（滑动窗口/下一个更大）→ 单调栈/队列。
