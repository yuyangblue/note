    1. 大白话引入¶

    想象一棵树，有 N 个节点。现在给你 M 条路径（每条路径从 u 到 v），要求给每条路径上的所有点（或所有边）+1，最后问哪个点/边被覆盖得最多。

    暴力做法：对每条路径，沿着树爬一遍，逐个 +1。每条路径最坏 O(N)，M 条路径 O(NM)，N、M = 10^5 时直接超时。

    树上差分：类似一维差分的思想——不直接修改路径上的每个点，而是只在路径的端点和 LCA 处打标记，最后一次性 DFS 还原。把 O(NM) 降到 O(N + M log N)。

    2. 从一维差分到树上差分¶

    一维差分回顾¶

    数组 a[1..n]，对区间 [l, r] 整体 +1：

    1
2
    d[l] += 1
d[r+1] -= 1

    最后求前缀和还原：a[i] = d[1] + d[2] + ... + d[i]。

    核心思想：对 d[l] +1 的效果是 l 及以后全部 +1，对 d[r+1] -1 把 r+1 及以后抵消回去，最终只有 [l, r] 被加了 1。

    树上差分类比¶

    树上的"前缀和"不是线性的，而是从节点到根的路径和。

    对节点 u 打 +1 标记，还原时效果是 u 到根的路径上所有点都 +1。

    所以给路径 u→v 上所有点 +1，可以拆成： 1. 对 u 打 +1（u 到根全部 +1） 2. 对 v 打 +1（v 到根全部 +1） 3. 此时 u-v 路径上的点被加了 2 次，LCA 及以上也被加了 2 次 4. 对 LCA 打 -1（抵消一次） 5. 对 parent[LCA] 打 -1（防止蔓延到 LCA 以上）

    最终只有 u-v 路径上的点恰好被加了 1 次。

    3. 点差分¶

    目标：给 u-v 路径上所有点 +1。

    操作： 

    1
2
3
4
    diff[u] += 1
diff[v] += 1
diff[lca] -= 1
diff[parent[lca]] -= 1

    逐步推导（用容斥思想）：

    步骤 操作 u-v 路径上的点 LCA LCA 以上
    初始 — 0 0 0
    diff[u] += 1 u 到根全 +1 +1 +1 +1
    diff[v] += 1 v 到根全 +1 +2 +2 +2
    diff[lca] -= 1 LCA 到根全 -1 +1 +1 +1
    diff[parent[lca]] -= 1 parent[LCA] 到根全 -1 +1 +1 0

    最终：u-v 路径上的点 = +1 ✓，LCA = +1 ✓，LCA 以上 = 0 ✓。

    为什么 parent[lca] 要 -1：如果不做这步，LCA 的父节点也会被"u 到根"和"v 到根"两条路径各 +1 一次，diff[lca] -= 1 只能抵消 LCA 自己，抵消不了往上蔓延的部分。

    4. 边差分¶

    目标：给 u-v 路径上所有边 +1。

    关键：把边权记在深度深的端点上。节点 u 的 diff 值代表 u 到 parent[u] 这条边的权值。

    操作： 

    1
2
3
    diff[u] += 1
diff[v] += 1
diff[lca] -= 2

    推导：

    步骤 操作 u-v 路径上的边 LCA 到根的边
    diff[u] += 1 u 到根所有边 +1 +1 +1
    diff[v] += 1 v 到根所有边 +1 +2 +2
    diff[lca] -= 2 LCA 到根所有边 -2 0 0

    最终：u-v 路径上的边 = 0？不对，让我重新推。

    实际上"对 u 打 +1"的效果是 u 到根路径上所有边 +1（因为边权记在深度深的端点上，u 的 +1 会沿路径向上传递）。

    步骤 操作 u-v 路径上的边 LCA 的父边及以上
    diff[u] += 1 u→parent[u]→...→根 所有边 +1 +1 +1
    diff[v] += 1 v→parent[v]→...→根 所有边 +1 +2 +2
    diff[lca] -= 2 lca→parent[lca]→...→根 所有边 -2 0 0

    等等，这样 u-v 路径上的边变成 0 了？

    重新理解：边差分的还原方式和点差分不同。还原时 diff[u] 的累加方向是从叶子向根，diff[u] 代表的是 u 到 parent[u] 这条边被覆盖的次数。

    实际上： - diff[u] += 1：还原时，u 到根路径上每个节点的 diff 都会累加到这个 +1 - 所以 u 到根的所有边都 +1 - diff[v] += 1：同理，v 到根的所有边都 +1 - u-v 路径上的边被加了 2 次（从 u 侧 +1，从 v 侧 +1） - LCA 到根的边也被加了 2 次 - diff[lca] -= 2：LCA 到根的边 -2，抵消回去

    最终：u-v 路径上的边 = 2 - 0 = 不对...

    让我换一种方式理解：

    还原时，diff[u] 从叶子向根累加。对于节点 x，最终 cnt[x] = diff[x] + Σ cnt[child]，cnt[x] 代表 x 到 parent[x] 这条边被覆盖的次数。

    给 u 打 +1 标记后，还原时 u 的每个祖先 x 都会从 u 这个方向收到 +1，所以 u 到根路径上每条边的 cnt 都 +1。

    同理 v 打 +1 后，v 到根路径上每条边的 cnt 都 +1。

    u-v 路径上的边：从 u 侧收到 +1，从 v 侧收到 +1，共 +2。 LCA 到根的边：也从两侧各收到 +1，共 +2。

    diff[lca] -= 2：LCA 到根路径上每条边的 cnt 都 -2。

    最终： - u-v 路径上的边 = +2（不受 lca 的 -2 影响，因为这些边在 lca 下面） - LCA 到根的边 = +2 - 2 = 0

    等等，u-v 路径上的边被加了 2 次而不是 1 次？

    关键纠正：u-v 路径上的边，只有一侧会收到标记。具体来说：

    u 到 LCA 路径上的边：只有 u 的 +1 会经过它们（v 的 +1 走的是 v 到 LCA 的路径，不经过 u 侧）。所以这些边只被 +1 一次。

    同理 v 到 LCA 路径上的边：只被 v 的 +1 经过，+1 一次。

    LCA 到根的边：被 u 和 v 的 +1 都经过，+2 次。

    diff[lca] -= 2 后：LCA 到根的边 = +2 - 2 = 0 ✓。

    最终：u-v 路径上的边 = +1 ✓，其他边 = 0 ✓。

    点差分 vs 边差分的区别： - 点差分：LCA 本身是路径上的点，需要保留 +1，所以 diff[lca] -= 1 + diff[parent[lca]] -= 1 - 边差分：LCA 到 parent[lca] 的边不是路径上的边，需要清零，所以 diff[lca] -= 2（两侧各 -1）

    // dfs_sum 还原函数（需要配合上面的全局变量）
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
vector<int> g[MAXN];
int diff[MAXN];

void dfs_sum(int u, int p) {
    for (int v : g[u]) {
        if (v == p) continue;
        dfs_sum(v, u);
        diff[u] += diff[v];  // 孩子的覆盖数累加到 u
    }
    // 此时 diff[u] 就是 u（或 u 到 parent[u] 的边）被覆盖的次数
}

int main() { return 0; }  // 示意块

    为什么这样正确： - 对 u 打 +1 标记，还原时 u 的每个祖先都会从 u 方向收到 +1 - DFS 回溯时，先把孩子的 diff 累加到父亲，等价于"u 的 +1 向上传递" - 最终每个节点的 diff 值就是它被覆盖的次数

    #include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
const int LOG = 17;

vector<int> g[MAXN];
int depth[MAXN], fa[MAXN][LOG];
int diff[MAXN];
int n, m;

// ========== LCA 预处理（倍增） ==========
void dfs_lca(int u, int p, int d) {
    depth[u] = d;
    fa[u][0] = p;
    for (int k = 1; k < LOG; k++) {
        fa[u][k] = fa[fa[u][k-1]][k-1];
    }
    for (int v : g[u]) {
        if (v == p) continue;
        dfs_lca(v, u, d + 1);
    }
}

int lca(int u, int v) {
    if (depth[u] < depth[v]) swap(u, v);
    int d = depth[u] - depth[v];
    for (int k = 0; k < LOG; k++) {
        if (d >> k & 1) u = fa[u][k];
    }
    if (u == v) return u;
    for (int k = LOG - 1; k >= 0; k--) {
        if (fa[u][k] != fa[v][k]) {
            u = fa[u][k];
            v = fa[v][k];
        }
    }
    return fa[u][0];
}

// ========== 树上差分 ==========

// 点差分：给 u-v 路径上所有点 +1
void add_path_point(int u, int v) {
    int l = lca(u, v);
    diff[u]++;
    diff[v]++;
    diff[l]--;
    if (fa[l][0]) {  // parent[lca] 存在
        diff[fa[l][0]]--;
    }
}

// 边差分：给 u-v 路径上所有边 +1
void add_path_edge(int u, int v) {
    int l = lca(u, v);
    diff[u]++;
    diff[v]++;
    diff[l] -= 2;
}

// 还原：从叶子向根累加
void dfs_sum(int u, int p) {
    for (int v : g[u]) {
        if (v == p) continue;
        dfs_sum(v, u);
        diff[u] += diff[v];
    }
}

int main() {
    scanf("%d%d", &n, &m);
    for (int i = 1; i < n; i++) {
        int u, v;
        scanf("%d%d", &u, &v);
        g[u].push_back(v);
        g[v].push_back(u);
    }

    dfs_lca(1, 0, 0);  // 以 1 为根

    for (int i = 1; i <= m; i++) {
        int u, v;
        scanf("%d%d", &u, &v);
        add_path_point(u, v);  // 或 add_path_edge
    }

    dfs_sum(1, 0);  // 还原

    // 此时 diff[i] 就是节点 i 被覆盖的次数
    int ans = 0;
    for (int i = 1; i <= n; i++) {
        ans = max(ans, diff[i]);
    }
    printf("%d\n", ans);

    return 0;
}

    7. 例题详解¶

    P3128 [USACO15DEC] Max Flow¶

    题意：给定 N 个节点的树，K 条路径 (s, t)，给每条路径上所有点 +1，求最大覆盖次数。

    解法：点差分裸题。对每条路径调用 add_path_point(s, t)，DFS 还原后取最大值。

    复杂度：O(N log N + K log N)

    P2680 [NOIP2015] 运输计划¶

    题意：给定 N 个节点的树（边有权值），M 条运输路径。可以把一条边的权值改为 0，求最小化所有路径中的最大长度。

    分析： - "最小化最大值" → 二分答案 - 二分 mid：判断能否通过改一条边使所有路径长度 ≤ mid - 把所有长度 > mid 的路径找出来 - 这些路径必须共享至少一条公共边，且这条边的权值 ≥ 最大路径长度 - mid - 用边差分统计每条边被多少条超长路径覆盖 - 如果存在一条边被所有超长路径覆盖，且减去它后最大路径 ≤ mid → 可行

    复杂度：O((N + M) log N log(max_dist))
