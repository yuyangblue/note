    📖 第1部分：不变性与等变性（Invariance vs Equivariance）¶

    单元1：为什么要研究不变性？¶

    核心概念 - 不变性：模型输出不随输入的某种变换而改变 - 等变性：模型输出随输入的同种变换而改变 - 核心问题：深度学习模型需要"看穿"数据的表面变化，抓住本质特征

    详细讲解

    1. 生活中的类比
    2. 认识朋友：无论朋友穿什么颜色的衣服、站在哪里，你都能认出他（不变性）

    3. 看电影：演员向左走，镜头里他也向左走（等变性）

    4. 计算机视觉中的常见变换

    5. 平移（Translation）：物体在图像中移动位置
    6. 旋转（Rotation）：物体旋转一定角度
    7. 缩放（Scale）：物体变大或变小

    8. 遮挡（Occlusion）：部分区域被遮盖

    9. 为什么重要？

    10. 图像分类：我们关心"是什么"（不变性）
    11. 目标检测：我们关心"在哪里"（等变性）
    12. 语义分割：每个像素的类别（等变性）

    单元2：平移等变性与平移不变性¶

    核心概念 - 平移等变性（Translation Equivariance）： $\(\text{Conv}(T(x)) = T(\text{Conv}(x))\)$ 卷积操作后平移 = 平移后卷积

    • 平移不变性（Translation Invariance）： $\(\text{Pool}(T(x)) = \text{Pool}(x)\)$ 池化操作后，无论图像怎么平移，输出不变

    单元3：不同任务对不变性的需求¶

    核心概念 - 分类任务：需要输出类别 → 追求不变性 - 定位任务：需要输出位置 → 追求等变性 - 密集预测：每个像素都需要预测 → 追求等变性

    任务对比表

    任务类型 任务示例 位置信息 需要的性质 代表网络
    图像分类 ImageNet 不需要 不变性 AlexNet, VGG
    目标检测 COCO 需要 等变性 YOLO, Faster R-CNN
    语义分割 CityScapes 需要 等变性 DeconvNet, U-Net
    图像生成 GAN 需要 等变性 DCGAN, Pix2Pix

    理解要点

    🤔 常见误区：很多人认为CNN是"平移不变性"的，但实际上： - 单个卷积层是平移等变的 - 堆叠卷积+池化后，整体表现为近似不变 - 池化层的"模糊"效果越强，不变性越强

    单元4：一维卷积的数学定义¶

    核心概念 - 卷积核（Kernel/Filter）：长度为\(K\)的可学习权重向量 - 滑动窗口：卷积核在输入序列上逐位置滑动 - 内积操作：卷积核与对应位置元素相乘后求和

    数学公式

    \[z_i = \sum_{k=1}^{K} \omega_k \cdot x_{i+k-\lceil K/2 \rceil}\]

    其中： - \(z_i\)：输出序列的第\(i\)个元素 - \(\omega_k\)：卷积核的第\(k\)个权重（共有\(K\)个） - \(x_j\)：输入序列的第\(j\)个元素 - \(\lceil K/2 \rceil\)：使卷积核中心对齐的偏移量

    单元5：边界填充策略（Padding）¶

    核心概念 - 有效填充（Valid Padding）：不填充，输出变小 - 相同填充（Same Padding）：填充后输出=输入 - 填充值类型：零填充、常数填充、镜像填充、循环填充

    数学公式

    \[D_{out} = \lfloor \frac{D_{in} + 2P - K}{S} \rfloor + 1\]

    其中： - \(D_{in}\)：输入长度 - \(D_{out}\)：输出长度 - \(P\)：填充数量（每侧） - \(K\)：卷积核大小 - \(S\)：步长（Stride）

    import numpy as np

def conv1d_with_padding(x, kernel, padding=0, stride=1):
    """
    x: 输入序列 (length,)
    kernel: 卷积核 (kernel_size,)
    padding: 填充数量
    stride: 步长
    """
    D_in = len(x)
    K = len(kernel)

    # 边界填充
    if padding > 0:
        x_padded = np.pad(x, (padding, padding), mode='constant')
    else:
        x_padded = x

    # 计算输出长度
    D_out = (len(x_padded) - K) // stride + 1

    # 滑动窗口计算
    result = np.zeros(D_out)
    for i in range(D_out):
        start = i * stride
        result[i] = np.sum(kernel * x_padded[start:start+K])

    return result

# 示例

    单元8：感受野（Receptive Field）¶

    核心概念 - 感受野（Receptive Field）：输出特征对应输入数据的"视野范围" - 局部连接：每个输出只与局部输入相连 - 层次化感受野：深层网络的感受野逐层增大

    数学公式

    \[RF_l = RF_{l-1} + (K_l - 1) \times d_l \times \prod_{i=1}^{l-1} S_i\]

    其中： - \(RF_l\)：第\(l\)层的感受野 - \(K_l\)：第\(l\)层的卷积核边长 - \(d_l\)：第\(l\)层的空洞率（dilation，普通卷积 \(d=1\)） - \(S_i\)：第\(i\)层的步长

    公式推导

    核心思路：第 \(l\) 层的一个输出像素，在第 \(l-1\) 层"看到"了多大范围？每一层往上回溯，范围逐层扩大。

    Step 1：单层感受野

    第1层卷积，核大小 \(K_1\)，输出一个像素只看 \(K_1\) 个输入：

    \[RF_1 = K_1\]

    Step 2：第2层的感受野（最关键的一步）

    第2层输出一个像素，需要 \(K_2\) 个第1层的输出。但第1层的输出之间可能有间隔——

    • 如果第1层 stride=1，第1层输出是连续的，第2层每多看1个第1层输出，就多看1个原始输入
    • 如果第1层 stride=2，第1层输出之间隔了2个原始输入位置，第2层每多看1个第1层输出，就多看2个原始输入

    所以第2层每多看1个第1层输出，对应原始输入增加了 \(\prod_{i=1}^{1} S_i = S_1\) 个位置。

    第2层看了 \(K_2\) 个第1层输出，但第1个输出已经贡献了 \(RF_1\) 的范围，新增的范围是 \((K_2 - 1)\) 个"间隔"造成的：

    \[RF_2 = RF_1 + (K_2 - 1) \times S_1\]

    Step 3：加入空洞率

    如果第2层用了空洞卷积（\(d_2 > 1\)），等效核大小变成了 \((K_2 - 1)d_2 + 1\)，多出来的间隔从 \((K_2 - 1)\) 变成 \((K_2 - 1) \times d_2\)：

    \[RF_2 = RF_1 + (K_2 - 1) \times d_2 \times S_1\]

    Step 4：推广到第 \(l\) 层

    第 \(l\) 层每多看1个第 \(l-1\) 层的输出，对应原始输入增加了前面所有层步长的累乘 \(\prod_{i=1}^{l-1} S_i\)：

    \[\boxed{RF_l = RF_{l-1} + (K_l - 1) \times d_l \times \prod_{i=1}^{l-1} S_i}\]

    直觉拆解公式三部分：

    部分 含义
    \(RF_{l-1}\) 上一层已有的感受野
    \((K_l - 1) \times d_l\) 当前层核"新增的跨度"（核大小减1×空洞率）
    \(\prod_{i=1}^{l-1} S_i\) 前面所有层步长的累乘（回溯到输入的缩放因子）

    为什么是 \(\prod S_i\) 而不是 \(S_l\)？ 因为感受野是相对于原始输入定义的。第 \(l\) 层到第 \(l-1\) 层被放大了 \(S_{l-1}\) 倍，第 \(l-1\) 层到第 \(l-2\) 层又被放大了 \(S_{l-2}\) 倍……一路回溯到输入，总共放大了 \(\prod_{i=1}^{l-1} S_i\) 倍。

def calc_receptive_field(layers):
    """
    layers: list of (kernel_size, stride, dilation)
    """
    rf = 1  # 初始感受野
    stride_accum = 1  # 前面所有层步长的累乘

    def compute_rf(layers):
    """
    计算每层的感受野

    Args:
        layers: [(kernel_size, stride, dilation), ...]

    Returns:
        rf_list: 每层的感受野大小

    rf = 1

    for k, s, d in layers:
        rf = rf + (k - 1) * d * stride_accum
        stride_accum *= s
        rf_list.append(rf)

    import torch
import torch.nn as nn
import numpy as np

def conv2d_manual(image, kernel, stride=1, padding=0):
    """
    手动实现二维卷积

    Args:
        image: (H, W) 输入图像
        kernel: (K, K) 卷积核
        stride: 步长
        padding: 填充

    Returns:
        output: 输出特征图
    """
    # 边界填充
    if padding > 0:
        image = np.pad(image, padding, mode='constant')

    H, W = image.shape
    K = kernel.shape[0]

    # 计算输出尺寸
    out_H = (H - K) // stride + 1
    out_W = (W - K) // stride + 1

    output = np.zeros((out_H, out_W))

    # 滑动窗口计算
    for i in range(out_H):
        for j in range(out_W):
            h_start = i * stride
            w_start = j * stride
            window = image[h_start:h_start+K, w_start:w_start+K]
            output[i, j] = np.sum(window * kernel)

    return output

# 示例
image = np.array([
    [1, 2, 3, 4, 5],
    [5, 4, 3, 2, 1],
    [2, 3, 4, 5, 6],
    [6, 5, 4, 3, 2],
    [3, 4, 5, 6, 7]
], dtype=np.float32)

kernel = np.array([
    [1, 0, -1],
    [2, 0, -2],
    [1, 0, -1]
], dtype=np.float32)

output = conv2d_manual(image, kernel, stride=1, padding=0)

    def nearest_neighbor_upsample(x, scale_factor):
    """最近邻上采样"""
    H, W = x.shape
    out_H, out_W = H * scale_factor, W * scale_factor

    # 直接复制
    out = np.zeros((out_H, out_W))
    for i in range(H):
        for j in range(W):
            out[i*scale_factor:(i+1)*scale_factor, 
                j*scale_factor:(j+1)*scale_factor] = x[i, j]
    return out

    def bilinear_interpolation(image, out_height, out_width):
    """双线性插值上采样"""
    H, W = image.shape[:2]

    # 计算缩放比例
    scale_h = H / out_height
    scale_w = W / out_width

    out = np.zeros((out_height, out_width))

    for i in range(out_height):
        for j in range(out_width):
            # 映射到原图坐标
            src_i = i * scale_h
            src_j = j * scale_w

            # 取整得到左上角坐标（Q₁₁的位置）
            i0 = int(np.floor(src_i))
            j0 = int(np.floor(src_j))

            # 边界处理
            i1 = min(i0 + 1, H - 1)
            j1 = min(j0 + 1, W - 1)

            # 计算权重 α 和 β
            alpha = src_j - j0   # 偏右程度
            beta = src_i - i0    # 偏下程度

            # 双线性插值：四邻域加权
            out[i, j] = (1-alpha)*(1-beta)*image[i0, j0] + \   # Q₁₁
                            alpha*(1-beta)*image[i0, j1] + \   # Q₂₁
                        (1-alpha)*beta*image[i1, j0] + \       # Q₁₂
                            alpha*beta*image[i1, j1]            # Q₂₂

    return out

    名字的由来：为什么叫"转置"？

    来自矩阵视角的数学等价性，不是真的有一个"转置"的操作。

    • 普通卷积可以写成 y = W · x，W 是稀疏的卷积矩阵（Toeplitz矩阵）
    • 转置卷积就是把矩阵转置：y = W^T · x，方向反过来，小的进、大的出
    • 实际实现不用矩阵转置，用"插零+卷积"的几何方法，效果完全等价但快得多

    🧩 补充：output_padding —— 解决"多解"问题¶

    上面的公式有一个隐藏问题：标准卷积是"多对一"映射，因此它的逆向（转置卷积）天然是"一对多"——同一个 \(D_{in}\) 可能对应多个合法的 \(D_{out}\)。

    举个例子：标准卷积 \(K=3,\, S=2,\, P=1\) 时，

    \[D_{out}^{\text{conv}} = \left\lfloor \frac{D_{in} + 2P - K}{S} \right\rfloor + 1\]
    • 输入 \(7\) → 输出 \(\lfloor (7+2-3)/2 \rfloor + 1 = 4\)
    • 输入 \(\mathbf{8}\) → 输出 \(\lfloor (8+2-3)/2 \rfloor + 1 = 4\) ← 两个不同输入给出同一个输出！

    那么反过来做转置卷积时，给定输入 \(4\)，到底应该输出 \(7\) 还是 \(8\)？ 转置卷积公式 \((4-1)\times 2 - 2 + 3 = 7\) 只能给出其中一个。 为了能恢复到另一个尺寸，PyTorch 引入了 output_padding 参数。

    完整公式：

    \[\boxed{\;D_{out} \;=\; (D_{in}-1)\,S \;-\; 2P \;+\; K \;+\; O_p\;}\]

    其中 \(O_p\) 就是 output_padding，作用是在输出的右边/下边再补 \(O_p\) 行/列（注意：只补单边，不是两边）。

    约束条件：

    \[0 \;\le\; O_p \;<\; \max(S,\; \text{dilation})\]

    这是因为再大就和 \(S\) 的整数倍重复了，没有新的"自由度"。

    🔧 何时需要用 output_padding？¶

    场景 是否需要 原因
    \(S = 1\) ❌ 不需要 标准卷积是一一映射，无歧义
    \(S \ge 2\) 且要精确还原编码器尺寸 ✅ 通常需要 弥补下采样时的向下取整损失
    U-Net、DeconvNet 的解码器 ✅ 几乎必用 跳跃连接要求尺寸严格对齐
    GAN 生成器（如 DCGAN） ⚠️ 视设计而定 若严格设计 \(K, S, P\) 一般不用

    ⚠️ 常见踩坑¶

    1. padding=P 和 output_padding=O_p 不要混淆
    2. padding=P：从输出两边各裁掉 \(P\)（公式中 \(-2P\)）

    3. output_padding=O_p：在输出单边再补 \(O_p\)（公式中 \(+O_p\)）

    4. output_padding 不能 ≥ stride

    📋 转置卷积完整参数速查¶

    参数 含义 对公式的影响
    in_channels, out_channels 通道数 不影响空间尺寸

    # MobileNet: 深度可分离卷积 + 1×1逐点卷积
class DepthwiseSeparableConv(nn.Module):
    def __init__(self, in_ch, out_ch):
        super().__init__()
        # 深度卷积: 每个通道单独卷积
        self.depthwise = nn.Conv2d(in_ch, in_ch, 3, padding=1, groups=in_ch)
        # 逐点卷积: 通道混合
        self.pointwise = nn.Conv2d(in_ch, out_ch, 1)

    def forward(self, x):
        x = self.depthwise(x)
        x = self.pointwise(x)
        return x

    class Inception(nn.Module):
    def __init__(self, in_channels, ch1x1, ch3x3red, ch3x3, ch5x5red, ch5x5, pool_proj):
        super().__init__()

        # 分支1: 1×1卷积
        self.branch1 = nn.Sequential(
            nn.Conv2d(in_channels, ch1x1, kernel_size=1),
            nn.BatchNorm2d(ch1x1),
            nn.ReLU(inplace=True)
        )

        # 分支2: 1×1降维 → 3×3卷积
        self.branch2 = nn.Sequential(
            nn.Conv2d(in_channels, ch3x3red, kernel_size=1),
            nn.BatchNorm2d(ch3x3red),
            nn.ReLU(inplace=True),
            nn.Conv2d(ch3x3red, ch3x3, kernel_size=3, padding=1),
            nn.BatchNorm2d(ch3x3),
            nn.ReLU(inplace=True)
        )

        # 分支3: 1×1降维 → 5×5卷积
        self.branch3 = nn.Sequential(
            nn.Conv2d(in_channels, ch5x5red, kernel_size=1),
            nn.BatchNorm2d(ch5x5red),
            nn.ReLU(inplace=True),
            nn.Conv2d(ch5x5red, ch5x5, kernel_size=5, padding=2),
            nn.BatchNorm2d(ch5x5),
            nn.ReLU(inplace=True)
        )

        # 分支4: MaxPool → 1×1卷积
        self.branch4 = nn.Sequential(
            nn.MaxPool2d(kernel_size=3, stride=1, padding=1),
            nn.Conv2d(in_channels, pool_proj, kernel_size=1),
            nn.BatchNorm2d(pool_proj),
            nn.ReLU(inplace=True)
        )

    def forward(self, x):
        b1 = self.branch1(x)
        b2 = self.branch2(x)
        b3 = self.branch3(x)
        b4 = self.branch4(x)
        # 通道维度拼接
        return torch.cat([b1, b2, b3, b4], dim=1)

def nms(predictions, iou_threshold=0.5, conf_threshold=0.4):
    """非极大值抑制"""

    # 过滤低置信度框
    boxes = [b for b in predictions if b['conf'] > conf_threshold]

    # 按置信度排序
    boxes.sort(key=lambda x: x['conf'], reverse=True)

    keep = []
    while boxes:
        # 保留置信度最高的框
        best = boxes.pop(0)
        keep.append(best)

        # 移除与最高置信度框IoU过高的框
        boxes = [b for b in boxes if iou(best, b) < iou_threshold]

    return keep

def yolo_loss(pred, target, lambda_coord=5, lambda_noobj=0.5):
    """
    pred: (batch, S, S, 5*B + C) 预测
    target: (batch, S, S, 5*B + C) 标签
    """

    # 1. 坐标损失 (只有负责预测的框才计算)
    coord_loss = lambda_coord * sum([
        pred[i]['x'] - target[i]['x'],  # 中心位置
        pred[i]['y'] - target[i]['y'],
        sqrt(pred[i]['w']) - sqrt(target[i]['w']),  # 宽高 (开方平衡大小框)
        sqrt(pred[i]['h']) - sqrt(target[i]['h'])
    ])

    # 2. 置信度损失
    # 有目标的框
    obj_loss = sum([
        pred[i]['conf'] - target[i]['conf']  # 置信度
    ])

    # 无目标的框 (权重更低)
    noobj_loss = lambda_noobj * sum([
        pred[i]['conf']  # 无目标时conf应趋近0
    ])

    # 3. 分类损失 (只有网格有目标时才计算)
    class_loss = sum([
        cross_entropy(pred[i]['class'], target[i]['class'])
    ])

    total_loss = coord_loss + obj_loss + noobj_loss + class_loss

class DeconvBlock(nn.Module):
    def __init__(self, in_ch, out_ch):
        super().__init__()
        # 上池化 (记录位置)
        self.unpool = nn.MaxUnpool2d(kernel_size=2, stride=2)
        # 转置卷积 (可学习的上采样)
        self.deconv1 = nn.ConvTranspose2d(in_ch, out_ch, kernel_size=3, padding=1)
        self.deconv2 = nn.ConvTranspose2d(out_ch, out_ch, kernel_size=3, padding=1)
        self.bn = nn.BatchNorm2d(out_ch)

    def forward(self, x, max_idx):
        # x: 特征图
        # max_idx: 池化时保存的最大值索引
        x = self.unpool(x, max_idx)  # 上池化
        x = self.deconv1(x)
        x = self.bn(x)
        x = torch.relu(x)
        x = self.deconv2(x)
        x = self.bn(x)
        x = torch.relu(x)
        return x

def pixel_accuracy(pred, target):
    """像素准确率"""
    correct = (pred == target).sum()
    total = target.numel()
    return correct / total

def mean_iou(pred, target, num_classes):
    """平均IoU"""
    ious = []
    for cls in range(num_classes):
        pred_cls = (pred == cls)
        target_cls = (target == cls)

        intersection = (pred_cls & target_cls).sum()
        union = (pred_cls | target_cls).sum()

        if union == 0:
            ious.append(float('nan'))
        else:
            ious.append(intersection / union)

    return np.nanmean(ious)

def calc_receptive_field(layers):
    """
    layers: [(kernel_size, stride, dilation), ...]
    假设每层stride影响后续所有层
    """
    rf = 1
    stride_product = 1

    for i, (k, s, d) in enumerate(layers):
        rf = rf + (k - 1) * d * stride_product
        stride_product *= s
        print(f"Layer {i+1}: RF = {rf}")

    return rf
