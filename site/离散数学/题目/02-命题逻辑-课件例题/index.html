    1. 命题的判定¶

    课件第 8 页

    例 1.1 命题示例¶

    判断下列句子是否为命题：

    句子 类型 是否命题
    糖是碳水化合物 简单命题 ✓
    武汉大学是最美丽的大学 简单命题 ✓
    如果不下雨，就开运动会 复合命题 ✓

    三个都是具有确切真值的陈述句，因此都是命题。前两个是简单命题（不能再分解），第三个是复合命题（由"不下雨"和"开运动会"通过蕴含联结词组合）。

    例 1.2 非命题示例¶

    判断下列句子是否为命题：

    句子 类型 是否命题 原因
    现在几点？ 疑问句 ✗ 不是陈述句
    请不要讲话！ 祈使句 ✗ 不是陈述句
    \(x + y \leq 4\) 含未限定变量 ✗ 真值不确定（依赖 x, y 的取值）

    命题必须是具有确切真值的陈述句。疑问句和祈使句不是陈述句；含未限定变量的句子真值不确定，因此都不是命题。

    例 1.3 悖论示例¶

    "我正在说谎。"

    这是典型的说谎者悖论（Liar's Paradox）： - 如果这句话是真的，那么"我正在说谎"就是真的，说明这句话是假的——矛盾； - 如果这句话是假的，那么"我正在说谎"就是假的，说明我没说谎，这句话是真的——矛盾。

    无论假设为真还是为假，都会推出矛盾，因此无法确定真值，不是命题。

    课件配图：埃舍尔《Drawing Hands》——左手画右手，右手画左手，同样是自指悖论的视觉表达。

    2. 蕴含式理解¶

    课件第 12 页

    例 2.1 蕴含式的善意推定¶

    "如果上天再给一次重来机会，我一定要……"

    分析这个蕴含式的真值：

    情况 前件（上天给机会） 后件（我一定要…） 蕴含式真值
    1 真 真 真（说到做到）
    2 真 假 假（食言了）
    3 假 真 真（没机会但做到了）
    4 假 假 真（没机会也没做到）

    关键结论： - 若前件为真，后件为假，则该蕴含式不成立，即为假； - 若前件为假，后件为真或假，都为真（善意推定）。

    这就是蕴含的"善意推定"原则——只有"真→假"才是假，其余三种情况都为真。

    例 2.2 形式蕴含（语义无关）¶

    判断下列蕴含式的真值：

    蕴含式 分析 真值
    If today is Friday, then \(2 + 3 = 5\). 后件 \(2+3=5\) 恒为真，无论前件真假，蕴含式都为真 True
    If today is Friday, then \(2 + 3 = 6\). 后件 \(2+3=6\) 恒为假；当前件为真（今天是周五）时，蕴含式为假；当前件为假时，蕴含式为真 True, except for Friday

    形式蕴含的含义：由于简单命题在符号化为原子时，剥离了原子之间可能存在的语义关系，蕴含式的真假仅与条件和结论的真假有关，而与条件和结论是否有语意关联无关。

    "今天是周五"和"2+3=5"在语义上毫无关系，但在数理逻辑中，蕴含式的真值只由前后件的真假决定。

    3. 命题符号化¶

    课件第 13 页

    例 3.1 符号化完整过程¶

    原题："你可以上网，仅当你是计算机专业的学生或者你不是一年级的学生。"

    第一步：识别原子命题

    符号 原子命题
    \(A\) 你可以上网
    \(C\) 你是计算机专业的学生
    \(F\) 你是一年级的学生

    第二步：用联结词逐步合成

    1. "你不是一年级的学生" → \(\neg F\)
    2. "你是计算机专业的学生或者你不是一年级的学生" → \(C \lor \neg F\)
    3. "仅当"表示必要条件，对应蕴含：\(A \rightarrow (C \lor \neg F)\)

    最终结果：

    \[A \rightarrow (C \lor \neg F)\]

    关键点："仅当"表示后件是前件的必要条件——"A 仅当 B" 翻译为 \(A \rightarrow B\)（A 成立必须 B 成立）。不要与"当"混淆——"A 当 B" 翻译为 \(B \rightarrow A\)。

    4. 合式公式判定¶

    课件第 15 页

    例 4.1 证明某公式是合式公式¶

    题目：证明 \((A \rightarrow (C \lor (\neg F)))\) 是合式公式（WFF）。

    证明：

    步骤 公式 依据规则
    ① \(A, C, F\) 是公式 递归基础（变元是公式）
    ② \((\neg F)\) 是公式 ① + 递归规则（否定）
    ③ \((C \lor (\neg F))\) 是公式 ①② + 递归规则（析取）
    ④ \((A \rightarrow (C \lor (\neg F)))\) 是公式 ①③ + 递归规则（蕴含）

    \(\square\)（证毕）

    这是典型的构造性证明——按照形式文法的递归规则，从基础（变元）开始，一步步构造出目标公式。每一步都必须有明确的规则依据。

    例 4.2 判断非合式公式¶

    判断下列字符串是否为合式公式：

    字符串 是否公式 原因
    \(\rightarrow (C \lor \neg F)\) ✗ 没有生成 \((\rightarrow A)\) 的规则——蕴含是二元联结词，必须有左操作数
    \((A \Rightarrow (C \lor \neg F))\) ✗ \(\Rightarrow\) 不是联结词（字母表中只有 \(\neg, \land, \lor, \rightarrow, \leftrightarrow\)）

    常见错误： 1. 二元联结词缺少左操作数（如 \(\rightarrow A\)） 2. 使用了字母表以外的符号（如 \(\Rightarrow, \Leftrightarrow, \oplus\) 等——这些是元语言符号，不是对象语言的联结词） 3. 括号不匹配 4. 违反极小性条款（不是由规则在有限步生成的）

    5. 公式简化规则¶

    课件第 16 页

    例 5.1 公式简化¶

    利用简化规则（省略最外层括号、优先级、结合性）简化下列公式：

    原公式 简化后 简化依据
    \((A \rightarrow (C \lor (\neg F)))\) \(A \rightarrow C \lor \neg F\) 省略最外层括号；\(\neg\) 优先级高于 \(\lor\)，\(\lor\) 高于 \(\rightarrow\)
    \(((P \lor Q) \lor R)\) \(P \lor Q \lor R\) 省略最外层括号；\(\lor\) 满足结合律，可连续写

    例 5.2 注意：不能随意加括号¶

    表达式 等价于 不等价于 原因
    \(P \lor Q \land R\) \(P \lor (Q \land R)\) \((P \lor Q) \land R\) \(\land\) 优先级高于 \(\lor\)，先算 \(Q \land R\)
    \(P \rightarrow Q \rightarrow R\) \((P \rightarrow Q) \rightarrow R\) \(P \rightarrow (Q \rightarrow R)\) 同一二元运算符从左到右结合；蕴含不满足结合律

    关键提醒： - 优先级：括号 \(> \neg > \land > \lor > \rightarrow > \leftrightarrow\) - 结合性：同一二元运算符从左到右 - \(\land\) 和 \(\lor\) 不满足结合律的混用——\(P \lor Q \land R\) 不等于 \((P \lor Q) \land R\) - 蕴含 \(\rightarrow\) 不满足结合律——\((P \rightarrow Q) \rightarrow R\) 不等于 \(P \rightarrow (Q \rightarrow R)\)

    6. 指派枚举¶

    课件第 18 页

    例 6.1 列出公式的所有指派¶

    题目：列出公式 \(G(P, Q) = \neg((P \lor Q) \land P)\) 的所有指派。

    解答：

    公式含 2 个原子 \(P, Q\)，因此共有 \(2^2 = 4\) 个指派：

    指派编号 指派（二进制） \(P\) \(Q\)
    \(I_0\) \(00\) 0 0
    \(I_1\) \(01\) 0 1
    \(I_2\) \(10\) 1 0
    \(I_3\) \(11\) 1 1

    注意： - 含 \(n\) 个原子的公式共有 \(2^n\) 个不同的指派 - 指派的下标与对应指派间的关系：下标 \(i\) 的二进制表示就是指派（如 \(I_3 = 11\)） - 指派排列最好按二进制数从小到大的次序

    7. 真值表构造¶

    课件第 20 页

    例 7.1 构造公式的真值表¶

    题目：构造公式 \(G = \neg((P \lor Q) \land P)\) 的真值表。

    解答：

    按运算优先级从内向外逐步计算： 1. 先算 \(P \lor Q\)（析取） 2. 再算 \((P \lor Q) \land P\)（合取） 3. 最后算 \(\neg((P \lor Q) \land P)\)（否定）

    指派 \(P\) \(Q\) \(P \lor Q\) \((P \lor Q) \land P\) \(G\)
    \(I_0 = 00\) 0 0 0 0 1
    \(I_1 = 01\) 0 1 1 0 1
    \(I_2 = 10\) 1 0 1 1 0
    \(I_3 = 11\) 1 1 1 1 0

    分析： - 公式 \(G\) 在 \(I_0, I_1\) 下为真，在 \(I_2, I_3\) 下为假 - \(G\) 是可满足公式（有成真指派），但不是永真式 - 成真指派：\(00, 01\)；成假指派：\(10, 11\)

    真值表定义：公式 \(G(P_1, P_2, \dots, P_n)\) 在 \(2^n\) 个指派下的值所构成的表称为公式 \(G\) 的真值表。

    构造要点： 1. 变元列按二进制顺序排列（\(00\cdots0\) 到 \(11\cdots1\)），不重不漏 2. 中间列按运算优先级从内向外逐步计算 3. 最后一列是公式的最终真值 4. 不要跳步——多写一列中间结果，就多一分正确
