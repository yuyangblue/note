    1. 等价关系¶

    1.1 定义¶

    设 \(R\) 是非空集合 \(A\) 上的关系，如果 \(R\) 同时满足： - 自反性：\(\forall x \in A, \langle x, x \rangle \in R\) - 对称性：\(\forall x,y \in A, \langle x,y \rangle \in R \Rightarrow \langle y,x \rangle \in R\) - 传递性：\(\forall x,y,z \in A, \langle x,y \rangle \in R \land \langle y,z \rangle \in R \Rightarrow \langle x,z \rangle \in R\)

    则称 \(R\) 为 \(A\) 上的等价关系。三个性质缺一不可。

    1.2 典型例子¶

    关系 是否等价 原因
    同姓关系 ✓ 自反+对称+传递
    实数上的 \(=\) ✓ 自反+对称+传递
    英文单词长度相同 ✓ 自反+对称+传递
    颜色相同 ✓ 自反+对称+传递
    模 \(n\) 同余关系 ✓ 见下方证明
    朋友关系 ✗ 不传递（A的朋友的朋友不一定是A的朋友）
    集合包含关系 \(\subseteq\) ✗ 不对称

    1.3 模 \(n\) 同余关系¶

    整数集上的模 \(n\) 同余关系：\(R = \{\langle x, y \rangle \mid n \mid (x - y)\}\)，记为 \(x \equiv y \pmod{n}\)。

    证明是等价关系： - 自反：\(x - x = 0\)，\(n \mid 0\) ✓ - 对称：若 \(n \mid (x-y)\)，则 \(n \mid (y-x) = -(x-y)\) ✓ - 传递：若 \(n \mid (x-y)\) 且 \(n \mid (y-z)\)，则 \(n \mid (x-z) = (x-y)+(y-z)\) ✓

    模 \(n\) 同余将整数集分成 \(n\) 个等价类（余数 \(0, 1, \dots, n-1\)）。

    2. 等价类与商集¶

    图1 模 3 同余的等价类（自绘）：整数被分成余数为 0、1、2 的 3 个等价类，两两不交、并集覆盖全集；商集 \(\mathbb{Z}/R=\{[0],[1],[2]\}\) 是"集合的集合"。

    2.1 等价类¶

    设 \(R\) 是 \(A\) 上的等价关系，对任意 \(x \in A\)，称集合

    \[[x]_R = \{y \in A \mid \langle x, y \rangle \in R\}\]

    为 \(x\) 关于 \(R\) 的等价类，\(x\) 称为该等价类的代表元。

    2.2 等价类的性质¶

    设 \(R\) 是 \(A\) 上的等价关系： 1. 非空性：\(\forall x \in A, [x]_R \neq \varnothing\)（至少含 \(x\) 自身） 2. 要么相同要么不交：\(\forall x,y \in A\)，若 \(y \in [x]_R\) 则 \([x]_R = [y]_R\)；否则 \([x]_R \cap [y]_R = \varnothing\) 3. 覆盖性：\(\bigcup_{x \in A} [x]_R = A\)

    2.3 商集¶

    由 \(R\) 确定的所有等价类构成的集合称为 \(A\) 关于 \(R\) 的商集，记作 \(A/R\)：

    \[A/R = \{[x]_R \mid x \in A\}\]

    商集是"集合的集合"。求商集的方法：任选一个元素求等价类，去掉已覆盖的元素，再选下一个，直到所有元素都被覆盖。

    3. 集合的划分¶

    3.1 定义¶

    给定非空集合 \(A\)，若集合 \(\pi = \{S_1, S_2, \dots, S_m\}\) 满足： 1. \(S_i \subseteq A\) 且 \(S_i \neq \varnothing\)（每个块非空） 2. \(S_i \cap S_j = \varnothing\)（\(i \neq j\)，两两不交） 3. \(\bigcup_{i=1}^{m} S_i = A\)（并集为 \(A\)）

    则称 \(\pi\) 为 \(A\) 的一个划分，\(S_i\) 称为划分的块或类。

    3.2 等价关系与划分的一一对应¶

    • 等价关系 → 划分：等价关系 \(R\) 的商集 \(A/R\) 就是 \(A\) 的一个划分，称为由 \(R\) 导出的等价划分
    • 划分 → 等价关系：设 \(\pi = \{S_1, \dots, S_m\}\) 是 \(A\) 的划分，则
    \[R = \bigcup_{i=1}^{m} (S_i \times S_i)\]

    是 \(A\) 上的等价关系，称为由划分 \(\pi\) 导出的等价关系

    每个划分块内部是全关系，块之间没有关系。

    图2 划分 \(\pi=\{\{1,3\},\{2\},\{4\}\}\) 与它导出的等价关系（自绘）：关系矩阵呈"对角分块"结构——块内全 1、块间全 0。

    3.3 应用：求所有等价关系¶

    直接枚举 \(A\) 上所有关系再判断是否等价很繁琐（\(|A|=n\) 时有 \(2^{n^2}\) 个关系）。利用一一对应关系：先求所有划分，再由划分导出等价关系。

    例：\(A=\{1,2,3\}\) 有5种划分（1块/2块×3种/3块），对应5个等价关系。

    4. 偏序关系¶

    4.1 定义¶

    设 \(R\) 是集合 \(A\) 上的关系，如果 \(R\) 同时满足： - 自反性 - 反对称性 - 传递性

    则称 \(R\) 为 \(A\) 上的偏序关系，记作 \(\preceq\)（读作"小于等于"，但不限于数值大小）。

    4.2 偏序 vs 等价¶

    性质 等价关系 偏序关系
    自反性 ✓ ✓
    对称性 ✓ ✗
    反对称性 ✗ ✓
    传递性 ✓ ✓
    对应问题 分类 排序

    4.3 典型偏序关系¶

    偏序关系 \(\preceq\) 的含义
    实数上的 \(\leq\) 数值小于等于
    实数上的 \(\geq\) 数值大于等于（也是偏序！）
    集合上的 \(\subseteq\) 包含关系
    正整数上的整除 \(a\) 整除 \(b\)
    恒等关系 \(I_A\) 只有自身相关

    \(\leq\) 符号是通用记法，具体含义取决于偏序关系本身。当 \(a \preceq b\) 且 \(a \neq b\) 时，记为 \(a \prec b\)。

    5. 可比与覆盖¶

    设 \(\preceq\) 是 \(A\) 上的偏序关系，\(x, y \in A\)：

    • 可比：若 \(x \preceq y\) 或 \(y \preceq x\)，则称 \(x\) 与 \(y\) 可比
    • 不可比：若 \(x \not\preceq y\) 且 \(y \not\preceq x\)，则称 \(x\) 与 \(y\) 不可比
    • 覆盖：若 \(x \prec y\) 且不存在 \(z\) 使得 \(x \prec z \prec y\)，则称 \(y\) 覆盖 \(x\)

    例（整除关系）：在 \(\{2,3,4,6,8,12\}\) 中，4覆盖2（中间无元素），但8不覆盖2（中间有4）。

    6. 字典排序¶

    设 \(\Sigma\) 是有限字母表，\(\Sigma^*\) 是 \(\Sigma\) 上所有字（含空字）的集合。定义字典次序关系 \(L\)：

    对 \(X = x_1 x_2 \dots x_n\) 和 \(Y = y_1 y_2 \dots y_m\)： 1. 找到第一个不同位置 \(k\)（\(k \leq \min(n,m)\)），若 \(x_k \preceq y_k\) 则 \(XLY\) 2. 若前 \(\min(n,m)\) 个字母全相同，则短字 \(\preceq\) 长字

    字典排序是偏序关系（自反+反对称+传递），且实际上是全序关系（任意两字可比）。

    C语言 strcmp 函数就是基于字典排序实现的。

    7. 哈斯图¶

    7.1 画法¶

    偏序关系的关系图可以通过三步简化为哈斯图： 1. 去自环：自反性保证每个节点都有自环，省略不画 2. 去传递边：若 \(x \to y\) 和 \(y \to z\) 存在，则 \(x \to z\) 由传递性保证，省略 3. 箭头向上去箭头：重新排列节点使所有边方向向上，去掉箭头（小元素在下，大元素在上）

    7.2 特点¶

    图3 从关系图到哈斯图的三步简化（自绘，以整除偏序 \(\{1,2,3,4,6,12\}\) 为例）：去自环 → 去传递边 → 箭头向上并去掉箭头；保留的边恰好是覆盖关系。

    • 哈斯图中保留的边恰好是覆盖关系
    • 从哈斯图可以恢复完整的偏序关系（自反+传递闭包）
    • 大大简化关系图，便于寻找特殊元素

    8. 偏序集中的特殊元素¶

    设 \(\langle A, \preceq \rangle\) 是偏序集，\(B \subseteq A\)。

    图4 特殊元素总览（自绘，整除偏序，\(B=\{2,3,6\}\) 红色高亮）：最大/极大元在 \(B\) 内找，上/下界在 \(A\) 中找；本例 \(B\) 有极大元 6 但无最小元（2、3 不可比），上界 \(\{6,12\}\)、上确界 6。

    8.1 最大元与最小元（在 \(B\) 中找）¶

    元素 定义 存在性
    最大元 \(\exists b \in B, \forall x \in B, x \preceq b\) 不一定存在，存在则唯一
    最小元 \(\exists b \in B, \forall x \in B, b \preceq x\) 不一定存在，存在则唯一

    最大元要求与 \(B\) 中所有元素可比且都比它小。

    8.2 极大元与极小元（在 \(B\) 中找）¶

    元素 定义 存在性
    极大元 \(\exists b \in B, \forall x \in B, b \preceq x \Rightarrow x = b\) 一定存在（有限集），可能不唯一
    极小元 \(\exists b \in B, \forall x \in B, x \preceq b \Rightarrow x = b\) 一定存在（有限集），可能不唯一

    极大元 = \(B\) 中没有比它更大的元素（允许有不可比的元素）。

    8.3 上界与上确界（在 \(A\) 中找）¶

    元素 定义 存在性
    上界 \(\exists a \in A, \forall x \in B, x \preceq a\) 不一定存在，可能多个
    上确界 所有上界中最小的那个 不一定存在，存在则唯一

    8.4 下界与下确界（在 \(A\) 中找）¶

    元素 定义 存在性
    下界 \(\exists a \in A, \forall x \in B, a \preceq x\) 不一定存在，可能多个
    下确界 所有下界中最大的那个 不一定存在，存在则唯一

    8.5 关键对比¶

    对比项 最大元 极大元 上界 上确界
    寻找范围 \(B\) 中 \(B\) 中 \(A\) 中 \(A\) 中
    要求可比 与所有元素可比 不要求 与所有元素可比 与所有元素可比
    唯一性 存在则唯一 可能多个 可能多个 存在则唯一
    有界则有确界？ — — 有上界不一定有上确界（上界间可能不可比） —

    有上界不一定有上确界：如果多个上界之间不可比，就找不到最小的上界。下界同理。

    9. 拟序关系¶

    9.1 定义¶

    设 \(R\) 是 \(A\) 上的关系，若 \(R\) 满足反自反性和传递性，则称 \(R\) 为 \(A\) 上的拟序关系，记作 \(\prec\)。

    9.2 拟序必反对称¶

    定理：拟序关系一定是反对称的。

    证明（反证）：若存在 \(x \neq y\) 使 \(\langle x,y \rangle \in R\) 且 \(\langle y,x \rangle \in R\)，由传递性得 \(\langle x,x \rangle \in R\)，与反自反矛盾。

    9.3 拟序与偏序的转换¶

    • 若 \(R\) 是偏序关系，则 \(R - I_A\) 是拟序关系（去掉自环）
    • 若 \(S\) 是拟序关系，则 \(S \cup I_A\) 是偏序关系（加上自环）

    典型拟序：实数上的 \(<\)、集合上的真包含 \(\subset\)。

    10. 全序关系¶

    10.1 定义¶

    设 \(\preceq\) 是 \(A\) 上的偏序关系，若对任意 \(x, y \in A\)，\(x\) 与 \(y\) 都可比（即 \(x \preceq y\) 或 \(y \preceq x\)），则称 \(\preceq\) 为全序关系（又称线性序、链）。

    10.2 例子¶

    关系 是否全序
    实数上的 \(\leq\) ✓
    字典排序 ✓
    \(\{1,2,4,8\}\) 上的整除 ✓（两两可比）
    正整数上的整除 ✗（2和3不可比）
    $ A

    全序关系的哈斯图是一条链（所有节点排成一条线）。

    11. 良序关系¶

    11.1 定义¶

    设 \(\preceq\) 是 \(A\) 上的全序关系，若 \(A\) 的任意非空子集都有最小元，则称 \(\preceq\) 为良序关系。

    11.2 例子¶

    关系 是否良序
    正整数上的 \(\leq\) ✓（任意非空子集有最小正整数）
    整数上的 \(\leq\) ✗（负整数子集无最小元）
    实数上的 \(\leq\) ✗（开区间 \((0,1)\) 无最小元）
    有限全序集 ✓（有限集总能找到最小元）

    11.3 三种次序关系的包含关系¶

    \[\text{良序} \subset \text{全序} \subset \text{偏序}\]
    • 良序一定是全序，全序不一定是良序
    • 全序一定是偏序，偏序不一定是全序
    • 有限全序集一定是良序集

    11.4 良序定理¶

    良序定理：每个集合都可以被良序化（存在一种排序使所有非空子集有最小元）。

    • 策梅洛证明了良序定理等价于 ZFC 中的选择公理
    • 意义：确保所有集合可使用超限归纳法（数学归纳法的推广）
    • 争议：实数集能否被良序化至今存在分歧

    12. 本节重点¶

    本节重点： - 要点1：等价关系 = 自反 + 对称 + 传递；对应分类问题。模 \(n\) 同余是典型等价关系 - 要点2：等价类 \([x]_R\) 性质：非空、要么相同要么不交、并集覆盖全集。商集 \(A/R\) 是所有等价类的集合 - 要点3：集合划分三条件：非空、两两不交、并集=A。等价关系与划分一一对应：\(R = \bigcup (S_i \times S_i)\) - 要点4：偏序关系 = 自反 + 反对称 + 传递；对应排序问题。与等价关系的唯一区别是对称 vs 反对称 - 要点5：哈斯图画法：去自环 → 去传递边 → 箭头向上去箭头。保留的边恰好是覆盖关系 - 要点6：八个特殊元素分两组：最大/最小/极大/极小（在B中找），上界/上确界/下界/下确界（在A中找）。确界存在则唯一，界可能多个 - 要点7：最大元要求与所有元素可比；极大元只要求没有更大的（允许不可比）。有上界不一定有上确界 - 要点8：拟序 = 反自反 + 传递（必反对称）；偏序去 \(I_A\) 得拟序，拟序并 \(I_A\) 得偏序 - 要点9：全序 = 偏序 + 任意两元素可比，哈斯图是一条链。良序 = 全序 + 任意非空子集有最小元 - 要点10：包含关系：良序 \(\subset\) 全序 \(\subset\) 偏序。有限全序集必为良序集 - 常见坑：极大元可能不唯一但一定存在（有限集）；最大元存在则唯一但不一定存在；上确界是"最小的上界"，多个上界不可比时上确界不存在
