    《概率论与数理统计》第3章 总结 多维随机变量及其分布¶

    本章总结：多维随机变量及其分布（对应视频 p18-p32）。 包含：联合分布函数、二维离散型概率分布、边缘分布、条件分布、独立性判定、两个随机变量函数的分布、max/min 分布。

    一、 本章知识地图（一张表串起全章）¶

    全章只回答一个问题：两个随机变量绑在一起，怎么描述、怎么拆开、怎么判断它们有没有关系、怎么拿它们造新变量。 下面一张表把整条主线串起来：

    主线步骤 要回答的问题 离散型工具（表上操作） 连续型工具（积分操作） 一句话口诀
    1. 联合分布 两个变量"一起"长什么样？ 联合分布律 \(p_{ij}\)（表中间的"芯"） 联合密度 \(f(x,y)\) 先画出"联合"这棵大树
    2. 边缘分布 只单独看其中一个？ 行和 / 列和 对另一个变量积分 求谁，就把"别人"拍扁 / 积掉
    3. 条件分布 已知一个取值，另一个怎么变？ 芯 ÷ 边 联合密度 ÷ 边缘密度 样本空间缩小再归一化
    4. 独立性 两个互不影响吗？ 芯 = 边 × 边 \(f=f_X f_Y\) 能不能"掰开"
    5. 函数的分布 造个新变量 \(Z=g(X,Y)\)？ 列表代入 + 合并相同值 先 \(F\) 后 \(f\)（或卷积） 枚举 or 求导
    6. max/min 取最大 / 取最小？ 逐格取 \(\max\) / \(\min\) 再合并 \(F_XF_Y\) / 对立事件 串联取 min、并联取 max

    （"表上操作"的完整套路见 p26 总结【二维离散型随机变量知识点】；连续型全套积分操作见 p27、p28。本文是全章总结，离散、连续都覆盖。）

    二、 各节要点回顾¶

    3.1 联合分布（p18-p19）¶

    • 联合分布函数 \(F(x,y)=P\{X\le x,\ Y\le y\}\)，二元函数，几何上等于"点落在 \((x,y)\) 左下角"的概率（含边界、实线）。五条性质里最常考两条：边界值 \(F(+\infty,+\infty)=1\)（用来求参数）和矩形概率公式。（详见 p18 3.1 X与Y的联合分布函数）
    • 二维离散型改用联合分布律 \(p_{ij}=P\{X=x_i,\ Y=y_j\}\) 列表表达，满足非负性 + 归一性 \(\sum_i\sum_j p_{ij}=1\)。画表约定：\(X\) 在行（左）、\(Y\) 在列（上）。（详见 p19 3.1 二维离散型(X,Y)的概率分布）

    3.2 边缘分布（p20-p22）¶

    • 边缘分布函数：\(F_X(x)=F(x,+\infty)\)，求谁就把"另一个变量推向 \(+\infty\)"。（详见 p20 3.2 边缘分布函数）
    • 离散边缘分布律 = 行和 / 列和（"把表拍扁"）。（详见 p21 3.2 二维离散型随机变量(X,Y)的边缘分布律）
    • 连续边缘密度 = 对另一个变量积分，几何是"切蛋糕的横截面面积"。圆域均匀分布的边缘不均匀，矩形均匀分布的边缘仍均匀。（详见 p22 3.2 二维连续型随机变量的边缘密度）

    3.3 条件分布（p23-p24）¶

    • 离散条件分布律 = 芯 ÷ 边（\(p_{ij}/p_{\cdot j}\) 或 \(p_{ij}/p_{i\cdot}\)），即"样本空间缩小后重新归一化"。（详见 p23 3.3 离散型随机变量的条件分布）
    • 连续条件密度 = 联合密度 ÷ 边缘密度，分母（给定那一方）必须 \(>0\)。（详见 p24 3.3 连续型随机变量的条件密度）
    • 三密度关系：联合 → 边缘（求和/积分，能求）；边缘 → 联合（求不出）；边缘 × 条件 → 联合（乘法公式）。

    3.4 独立性判定（p25-p28）¶

    • 离散：每个格子满足"芯 = 边 × 边"，全对才独立。（详见 p25 3.4 离散型随机变量X与Y相互独立的判定）
    • 连续：\(f(x,y)=f_X(x)f_Y(y)\)，看联合密度能否"掰开"成只含 \(x\) × 只含 \(y\)。（详见 p27 3.4 连续型随机变量X与Y相互独立的判定【1】）
    • 重要结论：独立 ⟹ 条件分布 = 边缘分布；二维正态里"独立 ⟺ \(\rho=0\)"；矩形均匀独立、圆域均匀不独立；独立变量的一元连续函数仍独立。（详见 p28 3.4 连续型随机变量X与Y相互独立的判定【2】）

    3.5 两个随机变量函数的分布（p29-p32）¶

    • 离散型：在联合表上逐个代入 \(g(X,Y)\)，再把相同取值合并概率。（详见 p29 3.5 两个随机变量函数的分布（离散型））
    • 连续型通用法：先求分布函数 \(F_Z(z)=\iint_{g(x,y)\le z}f\,dx\,dy\) 再求导；\(Z=X+Y\) 有专用卷积公式。（详见 p30 3.5 两个随机变量函数的分布（连续型））
    • 混合型（一离散一连续）：全概率按离散取值拆开 \(F_Z(z)=\sum_i p_i\,F_Y(z-x_i)\)。（详见 p31 3.5 两个随机变量函数的分布（离散型+连续型））
    • max/min：\(F_M=F_XF_Y\)，\(F_N=1-(1-F_X)(1-F_Y)\)；串联 = min、并联 = max。（详见 p32 3.5 max{X,Y} min{X,Y}的分布）

    三、 离散型 vs 连续型对照表¶

    同一个概念，离散型"表上算"、连续型"积分算"，一一对应：

    概念 离散型（联合分布律表） 连续型（联合密度） 白话记忆
    联合分布 \(P\{X=x_i,Y=y_j\}=p_{ij}\)（填表） 联合密度 \(f(x,y)\ge0\) 离散是一张"概率表"，连续是一块"概率曲面"
    归一性 \(\sum_i\sum_j p_{ij}=1\) \(\iint f(x,y)\,dx\,dy=1\) 所有可能加起来等于 1
    边缘分布 行和 \(p_{i\cdot}=\sum_j p_{ij}\)；列和 \(p_{\cdot j}=\sum_i p_{ij}\) \(f_X(x)=\int f(x,y)\,dy\)；\(f_Y(y)=\int f(x,y)\,dx\) "求谁，把别人拍扁 / 积掉"
    条件分布 \(P\{X=x_i \mid Y=y_j\}=\frac{p_{ij}}{p_{\cdot j}}\) \(f_{X\mid Y}(x\mid y)=\frac{f(x,y)}{f_Y(y)}\) 芯 ÷ 边 = 联合 ÷ 边缘，缩样本空间再归一化
    独立性判定 每个格子 \(p_{ij}=p_{i\cdot}\cdot p_{\cdot j}\) \(f(x,y)=f_X(x)f_Y(y)\) 芯 = 边 × 边 ↔ 密度能掰成"只含 x × 只含 y"
    \(Z=X+Y\) 逐格算 \(x_i+y_j\)，相同值合并 \(f_Z(z)=\int f(x,z-x)\,dx\) 枚举合并 ↔ 卷积积分
    一般 \(Z=g(X,Y)\) 逐格代入 \(g\) 再合并 \(F_Z(z)=\iint_{g(x,y)\le z}f\,dx\,dy\) 再求导 离散"枚举"，连续"先 F 后 f"
    max/min 逐格取 \(\max\)/\(\min\) 再合并 \(F_M=F_XF_Y\)，\(F_N=1-(1-F_X)(1-F_Y)\) 表上枚举 ↔ 分布函数公式

    四、 核心公式速查表¶

    1. 联合分布函数与矩形概率（p18）¶

    \[F(x,y)=P\{X\le x,\ Y\le y\}\]

    矩形区域概率（左开右闭）：

    \[P\{x_1<X\le x_2,\ y_1<Y\le y_2\}=F(x_2,y_2)-F(x_2,y_1)-F(x_1,y_2)+F(x_1,y_1)\]

    白话：先取右上角整块，剪掉"下面一条"、剪掉"左边一条"，再补回被剪两次的左下小角（容斥）。符号 \(+,-,-,+\)。左端 \(>\) 是虚线（不含）、右端 \(\le\) 是实线（含）。

    2. 边缘分布（p20-p22）¶

    \[F_X(x)=F(x,+\infty)=\lim_{y\to+\infty}F(x,y),\qquad F_Y(y)=F(+\infty,y)=\lim_{x\to+\infty}F(x,y)\]

    离散（行和 / 列和）：

    \[p_{i\cdot}=\sum_{j}p_{ij},\qquad p_{\cdot j}=\sum_{i}p_{ij}\]

    连续（对另一个变量积分）：

    \[f_X(x)=\int_{-\infty}^{+\infty}f(x,y)\,dy,\qquad f_Y(y)=\int_{-\infty}^{+\infty}f(x,y)\,dx\]

    白话：求谁的边缘，就把"别人"推向 \(+\infty\)（分布函数）或积掉（密度）。求 \(X\) 对 \(y\) 积分、求 \(Y\) 对 \(x\) 积分，方向别反。

    3. 条件分布（p23-p24）¶

    离散：

    \[P\{X=x_i \mid Y=y_j\}=\frac{p_{ij}}{p_{\cdot j}},\qquad P\{Y=y_j \mid X=x_i\}=\frac{p_{ij}}{p_{i\cdot}}\]

    连续：

    \[f_{X\mid Y}(x\mid y)=\frac{f(x,y)}{f_Y(y)},\qquad f_{Y\mid X}(y\mid x)=\frac{f(x,y)}{f_X(x)}\]

    乘法公式（边缘 × 条件 = 联合）：

    \[f(x,y)=f_X(x)\,f_{Y\mid X}(y\mid x)=f_Y(y)\,f_{X\mid Y}(x\mid y)\]

    白话：给定谁，就除以谁的那一方（列和 / 边缘密度），且分母要 \(>0\)。

    4. 独立性判定（p25-p28）¶

    离散（对每一个格子）：

    \[P\{X=x_i,\ Y=y_j\}=P\{X=x_i\}\cdot P\{Y=y_j\}\quad\Longleftrightarrow\quad p_{ij}=p_{i\cdot}\,p_{\cdot j}\]

    连续（几乎处处）：

    \[f(x,y)=f_X(x)\,f_Y(y)\]

    分布函数形式：

    \[F(x,y)=F_X(x)\,F_Y(y)\]

    白话：独立就是"互不影响、可以掰开"。已知独立 + 边缘分布，还能反推出联合分布（这是"边缘 → 联合"唯一能反推的情形）。独立的重要推论：条件分布 = 边缘分布，即 \(f_{X\mid Y}(x\mid y)=f_X(x)\)、\(P\{X=x_i\mid Y=y_j\}=P\{X=x_i\}\)。

    5. Z = X+Y 卷积公式（p30，仅"和"专用）¶

    \[f_Z(z)=\int_{-\infty}^{+\infty}f(x,\,z-x)\,dx=\int_{-\infty}^{+\infty}f(z-y,\,y)\,dy\]

    \(X\)、\(Y\) 独立时：

    \[f_Z(z)=\int_{-\infty}^{+\infty}f_X(x)\,f_Y(z-x)\,dx=\int_{-\infty}^{+\infty}f_X(z-y)\,f_Y(y)\,dy\]

    白话：固定 \(x\)，\(y\) 必须取 \(z-x\) 才能凑出 \(z\)；独立时把 \(Y\) 的自变量换成 \(z-x\)。⚠️ 只适用于"和"——\(X\cdot Y\)、\(X/Y\)、\(2X+5Y\) 不能直接套，要回到通用法。

    6. 离散 + 连续混合（p31）¶

    \[F_Z(z)=\sum_i p_i\,F_Y(z-x_i),\qquad f_Z(z)=\sum_i p_i\,f_Y(z-x_i)\]

    白话：离散变量负责"平移 + 加权"，连续变量负责贡献 \(F_Y\)；分段点取各 \(F_Y\) 换段点平移后的并集，中间的"空档段"密度为 0。

    7. max/min 分布（p32，\(X,Y\) 独立）¶

    \[F_M(z)=F_X(z)\,F_Y(z),\qquad M=\max\{X,Y\}\]
    \[F_N(z)=1-\big[1-F_X(z)\big]\big[1-F_Y(z)\big],\qquad N=\min\{X,Y\}\]

    独立同分布 \(n\) 个：

    \[F_M(z)=\big[F(z)\big]^{n},\qquad F_N(z)=1-\big[1-F(z)\big]^{n}\]

    密度形式（对分布函数求导）：

    \[f_M(z)=f_X(z)F_Y(z)+F_X(z)f_Y(z)\]
    \[f_N(z)=f_X(z)\big[1-F_Y(z)\big]+f_Y(z)\big[1-F_X(z)\big]\]

    白话：max 用"都 \(\le z\)"直接相乘；min 不能照抄，走对立事件"都 \(>z\)"再取反。串联系统寿命 = min、并联 = max。

    8. 可加性结论（p29-p30，填空最爱）¶

    \[X_1+\cdots+X_n \sim B(n,p)\]
    \[B(n,p)+B(m,p)\sim B(n+m,p)\]
    \[P(\lambda_1)+P(\lambda_2)\sim P(\lambda_1+\lambda_2)\]
    \[N(\mu_1,\sigma_1^2)\pm N(\mu_2,\sigma_2^2)\sim N(\mu_1\pm\mu_2,\ \sigma_1^2+\sigma_2^2)\]
    \[aX\pm bY\sim N(a\mu_1\pm b\mu_2,\ a^2\sigma_1^2+b^2\sigma_2^2)\]

    白话：均值跟着加减，方差永远相加（减号也加），系数进方差要平方。二项可加性要求两个 \(p\) 相同；0-1 之和要独立且同参数 \(p\)。

    五、 常考题型与易错点¶

    常考题型¶

    1. 由联合分布律求 \(F(x,y)\) 或某概率（p19、p26）："圈格子 + 加概率"。注意 \(X\le x\) 且 \(Y\le y\) 是"左下角矩形"里的全部格子，不是单格。
    2. 求边缘分布（p21、p22）：离散行和 / 列和；连续积分，先画图定积分上下限（求 \(f_X\) 用上下曲线、求 \(f_Y\) 用左右曲线）。
    3. 求条件分布（p23、p24）：芯 ÷ 边 / 联合 ÷ 边缘。
    4. 独立性判定 / 已知独立反求参数（p25、p28）：芯 = 边 × 边（每个格子）/ \(f=f_Xf_Y\)；已知独立可反推联合分布或未知概率。
    5. 均匀分布求概率（p22、p27）：常数密度 × 面积（几何法）。
    6. 连续型求 \(Z=g(X,Y)\) 分布（p30）：先 \(F\) 后 \(f\)，按 \(z\) 分段讨论积分区域；\(Z=X+Y\) 用卷积。
    7. 混合型 \(Z=X+Y\)（p31）：全概率按离散取值拆开，分段点取并集，注意"空档段"密度为 0。
    8. max/min 分布（p32）：套公式 + 分段 + 求导。
    9. 可加性填空（p29、p30）：二项 / 泊松 / 正态参数直接相加。

    易错点（坑合集）¶

    • 联合分布函数边界：\(F\) 对应左下角区域含边界（\(\le\) 实线）；用 \(F\) 加减时被减项会把边界"擦掉"变虚线；矩形公式符号 \(+,-,-,+\) 别漏别反。
    • 求参数：用 \(F(+\infty,+\infty)=1\)，别用 \(F(x,-\infty)=0\)（恒等式会吞掉参数）。
    • 画表：\(X\) 行、\(Y\) 列位置别放反；离散取值可以无限（写省略号）。
    • 不放回抽样：分母逐次变小（\(5\to4\)），别忘。
    • 边缘密度方向：求 \(X\) 对 \(y\) 积分、求 \(Y\) 对 \(x\) 积分；圆域积分上下限是 \(\pm\sqrt{R^2-x^2}\)，不是 \(\pm R\)。
    • 条件分布：分母别除错（给定 \(Y\) 除 \(f_Y\)/列和）；条件只在边缘 \(>0\) 处有定义。
    • 独立判定：必须每个格子 / 处处验证，一个不对就判不独立；别只验一个格子就下"独立"结论。
    • 连续独立：别忘了写"其余为 0"分段；\(\rho=0\) ⟹ 独立只在二维正态成立，一般情形不成立。
    • 卷积：只适用于 \(Z=X+Y\)；\(X\cdot Y\)、\(X/Y\)、\(2X+5Y\) 不能直接套。
    • 极坐标 / 求导：换元忘乘 \(r\)（\(dx\,dy=r\,dr\,d\theta\)）；求导漏复合函数系数。
    • 正态可加性：方差永远相加（减号也加），系数进方差要平方。
    • 混合型：忘乘权重 \(p_i\)；分段点取并集；中间空档段密度为 0。
    • max/min：min 不能照抄 max（走对立事件"都 \(>z\)"）；分段点取并集；自变量统一成 \(z\)；指数参数 \(\lambda\) 别弄反；乘积求导别漏。

    六、 补充¶

    • 二维正态两个结论（p22、p28）：① \((X,Y)\) 二维正态 ⟹ \(X\)、\(Y\) 边缘都是正态；② 反过来不成立——\(X\)、\(Y\) 各自正态 ≠ 二维正态，除非它们独立（此时 \(\rho=0\)）。
    • 圆域均匀 vs 矩形均匀（p22、p28）：矩形均匀 ⟹ 独立、边缘仍均匀；圆域均匀 ⟹ 不独立、边缘不再均匀（\(f_X(x)=\frac{2}{\pi R^2}\sqrt{R^2-x^2}\)）。
    • 独立"会遗传"（p28）：\(X\)、\(Y\) 独立，\(g_1\)、\(g_2\) 一元连续函数，则 \(g_1(X)\)、\(g_2(Y)\) 仍独立（如 \(X^2\) 与 \(Y^2\)、\(aX+b\) 与 \(cY+d\)）。
    • 串联 / 并联（p32）：串联系统（一个坏全坏）寿命 \(=\min\{X_1,\dots,X_n\}\)；并联系统（至少一个好）寿命 \(=\max\{X_1,\dots,X_n\}\)。

    本章重点¶

    要点 - 全章一条主线：联合 → 边缘 → 条件 → 独立 → 造新变量，两条腿并行——离散在"表上操作"，连续在"积分操作"。 - 联合分布函数 + 矩形概率公式（\(+,-,-,+\)）。 - 边缘 = 行和 / 列和 ↔ 对另一变量积分；条件 = 芯 ÷ 边 ↔ 联合 ÷ 边缘。 - 独立 = 芯 = 边 × 边 ↔ \(f=f_Xf_Y\)；独立 ⟹ 条件分布 = 边缘分布。 - \(Z=X+Y\)：离散枚举合并、连续卷积、混合全概率；max/min：\(F_M=F_XF_Y\)、\(F_N=1-(1-F_X)(1-F_Y)\)。 - 可加性：0-1 → 二项、二项加二项（同 \(p\)）、泊松加泊松、正态加减 / 线性组合。

    常见坑 - 边缘 / 条件"方向"搞反（求 \(X\) 却对 \(x\) 积分、除以 \(f_X\)）。 - 独立只验一个格子就下结论；或把"\(\rho=0\) ⟹ 独立"当普遍结论。 - 卷积公式乱套到 \(X\cdot Y\)、\(2X+5Y\)；极坐标忘乘 \(r\)；求导漏系数。 - 正态方差做减法写成 \(\sigma_1^2-\sigma_2^2\)；max/min 里 min 照抄 max 公式。
