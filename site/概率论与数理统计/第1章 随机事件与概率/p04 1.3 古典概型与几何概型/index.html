    古典概型 (Classical Probability Model)¶

    古典概型，也称为等可能概率模型，是我们高中阶段学习的概率基础。

    定义与两个基本条件： 1. 有限性：样本空间 Ω 中的样本点总数是有限的。 * 例如：抛硬币（正、反，2个样本点）、掷骰子（1, 2, 3, 4, 5, 6，6个样本点）。 * 反例：电话呼叫次数、线段上的点（可以是无限多个）不属于古典概型。 2. 等可能性：每个样本点出现的概率是相等的。 * 例如：公平硬币正反面概率均为 1/2；公平骰子每个点数出现的概率均为 1/6。

    古典概型公式与示例¶

    概率计算公式： 对于事件 A，其概率为： $\(P(A) = \frac{M}{N}\)$ 其中： * \(N\) 是样本空间 Ω 中所有可能结果的总数（分母）。 * \(M\) 是事件 A 包含的样本点的个数（分子）。 * 理解要点：公式无需死记，解题时只需明确“所有情况数”和“你所要求的事件的情况数”。

    示例：掷骰子，事件 A = “出现奇数点”。 * 样本空间 Ω = {1, 2, 3, 4, 5, 6}，N = 6。 * 事件 A = {1, 3, 5}，M = 3。 * 因此， \(P(A) = \frac{3}{6} = \frac{1}{2}\)。

    古典概型典型例题¶

    例一：从 0~9 十个数字中随机取一个数，求取到偶数的概率。 * 总数 N = 10。 * 偶数 A = {0, 2, 4, 6, 8}，M = 5。 * \(P(A) = \frac{5}{10} = \frac{1}{2}\)。

    例二：从 1~1000 中随机取一个数，求以下事件概率： 1. 事件A：能被6整除 * \(N = 1000\)。 * \(1000 \div 6 \approx 166.67\)，所以有 166 个数能被6整除，即 \(M = 166\)。 * \(P(A) = \frac{166}{1000} = 0.166\)。 2. 事件B：能被8整除 * \(1000 \div 8 = 125\)，所以有 125 个数能被8整除，即 \(M = 125\)。 * \(P(B) = \frac{125}{1000} = 0.125\)。 3. 事件C：既不能被6也不能被8整除 * 这是事件“能被6或8整除”的对立事件。设 \(D\) = “能被6或8整除”。 * 利用概率的加法公式： \(P(D) = P(A) + P(B) - P(AB)\)。 * 其中，\(AB\) 表示既能被6整除也能被8整除，即能被 LCM(6,8)=24 整除。 * \(1000 \div 24 \approx 41.67\)，所以有 41 个，即 \(P(AB) = \frac{41}{1000}\)。 * \(P(D) = 0.166 + 0.125 - 0.041 = 0.25\)。 * 因此，\(P(C) = 1 - P(D) = 1 - 0.25 = 0.75\)。

    例三（房间问题）：有 N 个房间，n 个人 (n ≤ N) 随机选择房间入住。 * 总样本数：每个人有 N 种选择，n 个人独立选择，总数为 \(N^n\)。 * 第一问：某指定的 n 个房间各有一人。 * 第一个人有 n 种选择，第二个人有 n-1 种，...，第 n 个人有 1 种。 * 情况数为 \(n!\)。 * 概率 \(P = \frac{n!}{N^n}\)。 * 第二问：恰好有 n 个房间各有一人（房间未指定）。 * 先从 N 个房间中选出 n 个房间，有 \(C_N^n\) 种选法。 * 然后 n 个人在这 n 个房间中进行全排列，有 \(n!\) 种。 * 概率 \(P = \frac{C_N^n \cdot n!}{N^n} = \frac{P_N^n}{N^n}\)。 * 第三问：某指定的一间房内恰有 k 个人。 * 先从 n 个人中选出 k 个人住进指定房间，有 \(C_n^k\) 种。 * 剩下的 n-k 个人在剩下的 N-1 个房间中任意选择，每人有 N-1 种选择，共 \((N-1)^{n-k}\) 种。 * 概率 \(P = \frac{C_n^k \cdot (N-1)^{n-k}}{N^n}\)。 * 第四问 (N=n)：恰好有一间房空着。 * 总数仍为 \(N^N\)。 * 思路：一间房空着，则其余 N-1 间房需容纳 N 个人，必然有一间房住2人，其他 N-2 间房各住1人。 * 步骤： 1. 选出空房：\(C_N^1\) 种。 2. 选出住2人的那间房：\(C_{N-1}^1\) 种。 3. 从 N 个人中选出2人住进该房间：\(C_N^2\) 种（两人无顺序）。 4. 剩下的 N-2 个人进行全排列，住进剩下的 N-2 个房间：\((N-2)!\) 种。 * 概率 \(P = \frac{C_N^1 \cdot C_{N-1}^1 \cdot C_N^2 \cdot (N-2)!}{N^N}\)。

    例四（生日问题）：一年365天，求班级中至少有两人生日相同的概率。 * 模型：将365天看作365个“房间”，N 个人看作“人”随机入住。 * 求解思路：先求对立事件“所有人生日都不相同”的概率 \(P_1\)，再用 \(1-P_1\)。 * 计算： * 第一个人有365种选择，第二个人有364种（不能与第一人相同），...，第N个人有 \(365-N+1\) 种。 * \(P_1 = \frac{P_{365}^N}{365^N} = \frac{365 \times 364 \times \cdots \times (365-N+1)}{365^N}\)。 * 所求概率 \(P = 1 - P_1\)。 * 结论：当班级人数 N=55 时，至少有两人生日相同的概率高达 0.99。

    例五（抽签公平性）：10张考签（4难6易），甲乙丙依次不放回抽取。 * 核心结论：抽签的顺序不影响每个人抽到难签的概率，对每个人都是公平的。 * 证明（以甲为例）： * 总排列数：\(10 \times 9 \times 8\)。 * 甲抽到难签的情况：甲有4种选法，乙有9种，丙有8种，共 \(4 \times 9 \times 8\)。 * \(P(\text{甲难}) = \frac{4 \times 9 \times 8}{10 \times 9 \times 8} = \frac{4}{10}\)。 * 推广（例六）：有 \(\alpha\) 张易卷和 \(\beta\) 张难卷，王某是第 k 个抽签者。 * 总排列数：\((\alpha+\beta)!\)。 * 王某抽到易卷的情况：先从 \(\alpha\) 张易卷中取1张给王某，剩下卷子全排列。 * \(P = \frac{C_\alpha^1 \cdot (\alpha+\beta-1)!}{(\alpha+\beta)!} = \frac{\alpha}{\alpha+\beta}\)。 * 结论：概率仅取决于他会的卷子占总数的比例，与抽签次序 k 无关。

    例七（产品抽检）：50件产品（6次品，44合格品），任取3件（不放回）。 * 本质是组合问题（“一把抓”，不考虑顺序）。 * 总情况数：\(C_{50}^3\)。 * 各种情况概率： 1. 恰有1件次品： \(P = \frac{C_6^1 \cdot C_{44}^2}{C_{50}^3}\)。 2. 恰有2件次品： \(P = \frac{C_6^2 \cdot C_{44}^1}{C_{50}^3}\)。 3. 3件均次品： \(P = \frac{C_6^3}{C_{50}^3}\)。 4. 3件均合格品： \(P = \frac{C_{44}^3}{C_{50}^3}\)。

    例八（排队问题）：6人随机坐成一排。 * 总情况数：全排列 \(6!\)。 * 第一问：甲乙两人必须相邻。 * 使用 “捆绑法”：将甲乙视为一个整体，内部有 \(2!\) 种排法。 * 整体与其余4人共5个元素全排列：\(5!\)。 * \(P = \frac{2! \cdot 5!}{6!} = \frac{1}{3}\)。 * 第二问：甲乙两人之间恰有一人。 * “插空法” 或分步： 1. 从其余4人中选1人插入甲乙之间：\(C_4^1\)。 2. 甲乙两人在两端位置全排列：\(2!\)。 3. 将这3人视为一个整体，与剩余3人全排列：\(4!\)。 * \(P = \frac{C_4^1 \cdot 2! \cdot 4!}{6!}\)。

    例九（配对问题）：5双不同的鞋（共10只），任取4只。 * 求“至少有一双成对”的概率。 * 方法一（对立事件）： * 对立事件 \(A^c\) = “4只鞋全是单只，均不成对”。 * 从5双中选4双：\(C_5^4\)。 * 从每双中选1只（左或右）：\(2^4\)。 * \(P(A^c) = \frac{C_5^4 \cdot 2^4}{C_{10}^4} = \frac{8}{21}\)。 * \(P(A) = 1 - \frac{8}{21} = \frac{13}{21}\)。 * 方法二（直接计算）： * \(A\) 包含两种情况：① 恰有一双成对，另2只单；② 恰有两双成对。 * 情况①：选1双成对的：\(C_5^1\)；从剩下4双中选2双，并从每双中选1只：\(C_4^2 \cdot 2^2\)。 * 情况②：直接选2双成对的：\(C_5^2\)。 * \(P(A) = \frac{C_5^1 \cdot C_4^2 \cdot 2^2 + C_5^2}{C_{10}^4} = \frac{13}{21}\)。

    几何概型 (Geometric Probability Model)¶

    当样本空间是一个可度量的几何区域（如线段、平面区域、立体图形），且样本点的分布是均匀的，就构成了几何概型。

    核心思想：事件的概率等于构成事件 A 的区域长度（面积或体积） 与样本空间 Ω 的总长度（面积或体积） 之比。 $\(P(A) = \frac{\mu(A)}{\mu(\Omega)}\)$ 其中 \(\mu\) 代表几何测度（长度、面积、体积），具体取决于问题背景。

    关键：通过画图将问题转化为几何图形的测度比计算。

    几何概型典型例题¶

    例十（等车问题）：公交车每5分钟一班，乘客随机到达车站，求等车时间不超过2分钟的概率。 * 建模：乘客到达时间 \(X\) 在 \([0, 5]\) 分钟内均匀分布。 * 事件 A：等车时间 ≤ 2 分钟，即乘客需在发车前的2分钟内到达。 * 若发车时刻为0和5，则乘客需在区间 \([3, 5]\) 内到达。 * 计算：\(P(A) = \frac{\text{区间}[3,5]\text{的长度}}{\text{区间}[0,5]\text{的长度}} = \frac{2}{5}\)。

    例十一（约会问题）：两人约定在7点到8点间见面，先到者等15分钟，等不到则离去。求两人能见面的概率。 * 建模：设甲到达时间为 \(x\)，乙到达时间为 \(y\)，\(x, y \in [0, 60]\)（分钟）。 * 样本空间 Ω 是边长为60的正方形，面积 \(S_\Omega = 60^2\)。 * 事件 A（能见面）的条件：两人到达时间差的绝对值不超过15分钟，即 \(|x - y| \leq 15\)。 * 这等价于 \(-15 \leq x - y \leq 15\)。 * 几何表示： 1. 画出直线 \(y = x\)（对角线）。 2. \(x - y \leq 15\) 对应直线 \(y = x - 15\) 的上方区域。 3. \(x - y \geq -15\) 对应直线 \(y = x + 15\) 的下方区域。 4. 事件 A 的区域是正方形内夹在两条平行直线之间的带状区域（阴影部分）。 * 面积计算： * 阴影部分面积 \(S_A = S_\Omega - 2 \times (\text{两个白色直角三角形的面积})\)。 * 每个白色三角形是等腰直角三角形，直角边长为 \(60-15=45\)。 * \(S_A = 60^2 - 2 \times \frac{1}{2} \times 45 \times 45 = 3600 - 2025 = 1575\)。 * 最终概率：\(P(A) = \frac{S_A}{S_\Omega} = \frac{1575}{3600} = \frac{7}{16}\)。

    学习要点总结： * 古典概型的关键是有限和等可能，概率计算是计数之比。难点在于运用排列组合知识准确计算 \(N\) 和 \(M\)，并灵活运用对立事件、捆绑法、插空法等技巧。 * 几何概型的关键是将概率问题转化为几何测度比，并通过画图直观求解，尤其要注意建立正确的数学模型。

    本节重点： - 古典概型 = 样本空间有限 + 等可能，概率是计数之比 \(P(A)=\frac{M}{N}\)；计数时"一把抓"用组合、有顺序用排列。 - 几何概型 = 概率是测度比 \(P(A)=\frac{\mu(A)}{\mu(\Omega)}\)（长度/面积/体积），核心是画图建模。 - 常用技巧：对立事件（"至少……"）、捆绑法（相邻）、插空法（隔人）。 - 常见坑：① 无限样本空间（等车、线段取点）不能套古典概型；② 房间/生日问题先分清"指定"还是"不指定"；③ 约会问题画图别把区域画错，\(|x-y|\le15\) 是正方形内夹在两条平行线之间的带状区域。
