    1. 条件概率的概念与直观理解¶

    条件概率描述的是在某个事件已经发生的前提下，另一个事件发生的概率。

    核心思想： 样本空间在条件概率中发生了变化。已知条件事件A发生，意味着我们仅在A构成的缩小样本空间内考虑另一事件B发生的概率。

    通俗例子： * 妈妈漂亮，那么生的女儿漂亮的概率会比较大（遗传因素）。 * 两个孩子的家庭，已知至少有一个男孩，问另一个也是男孩的概率。

    2. 条件概率的定义与公式¶

    2.1 定义¶

    设实验E的样本空间为 \(\Omega\)，A, B为两个事件，且 \(P(A)>0\)。称 $\(P(B|A) = \frac{P(AB)}{P(A)}\)$ 为在事件A发生的条件下事件B发生的条件概率，也称为B对A的条件概率。

    2.2 公式推导（以“学生”例题为例）¶

    例：某校1000名学生，男生800人，女生200人。北京学生共200人，其中男生120人，女生80人。设事件A为“是男生”，事件B为“是北京人”。 * \(P(A)=0.8\) * \(P(B)=0.2\) * \(P(AB)=0.12\) * \(P(A|B) = \frac{120}{200}=0.6\) (样本空间变为200名北京学生) * \(P(B|A) = \frac{120}{800}=0.15\) (样本空间变为800名男生)

    由此可得： $\(P(A|B) = \frac{P(AB)}{P(B)}\)$ $\(P(B|A) = \frac{P(AB)}{P(A)}\)$ 前提： \(P(A)>0\) 或 \(P(B)>0\)。

    3. 条件概率的性质¶

    条件概率 \(P(\cdot|A)\) 满足概率的所有公理： 1. 非负性：对于任意事件B，\(P(B|A) \ge 0\)。 2. 规范性：\(P(\Omega|A)=1\)。 3. 可列可加性：若 \(B_1, B_2, \dots\) 两两互不相容，则 $\(P(\bigcup_{i=1}^{\infty} B_i | A) = \sum_{i=1}^{\infty} P(B_i|A)\)$

    常用性质： * \(P(\varnothing|A)=0\) * \(P(B_1 \cup B_2 | A) = P(B_1|A) + P(B_2|A) - P(B_1B_2|A)\) * 特别地，若 \(B_1, B_2\) 互不相容，则 \(P(B_1 \cup B_2 | A) = P(B_1|A) + P(B_2|A)\) * \(P(B|A) + P(\overline{B}|A) = 1\)

    4. 乘法公式¶

    由条件概率公式直接变形可得乘法公式： $\(P(AB) = P(A)P(B|A) \quad (P(A)>0)\)$ $\(P(AB) = P(B)P(A|B) \quad (P(B)>0)\)$

    意义： 两个事件A与B同时发生的概率，等于先发生A的概率乘以在A已发生的条件下再发生B的概率。

    推广到三个事件： 若 \(P(AB)>0\)，则 $\(P(ABC) = P(A)P(B|A)P(C|AB)\)$

    5. 例题解析¶

    例1：条件概率计算¶

    （同上“学生”例题） 已知 \(P(A)=0.8\), \(P(B)=0.2\), \(P(AB)=0.12\)。 * 求 \(P(\overline{B}|A)\)： $\(P(\overline{B}|A) = 1 - P(B|A) = 1 - \frac{P(AB)}{P(A)} = 1 - \frac{0.12}{0.8} = 0.85\)$

    例2：古典概型与条件概率（不放回抽样）¶

    盒中有4个产品，其中3个一等品，1个二等品。不放回地取两次。 设事件A为“第一次取到一等品”，事件B为“第二次取到一等品”。 * \(P(A)=3/4\) * 求 \(P(B|A)\)：已知第一次取走一个一等品，剩余2个一等品，1个二等品。 $\(P(B|A)=\frac{2}{3}\)$ * 用公式计算： $\(P(B|A)=\frac{P(AB)}{P(A)}\)$ \(P(AB)\)：两次都取到一等品的概率。总取法：\(4 \times 3\)。有利取法：\(3 \times 2\)。 $\(P(AB)=\frac{3 \times 2}{4 \times 3}=\frac{6}{12}=0.5\)$ $\(P(B|A)=\frac{0.5}{0.75}=\frac{2}{3}\)$

    例3：乘法公式应用（抽签问题）¶

    10张考签，4张难签，6张易签。甲、乙、丙不放回依次抽取。设A, B, C分别为甲、乙、丙抽到难签。 * 问1： 甲难乙易的概率 \(P(A\overline{B})\)。 $\(P(A\overline{B}) = P(A)P(\overline{B}|A) = \frac{4}{10} \times \frac{6}{9} = \frac{4}{15}\)$ * 问2： 甲易乙难的概率 \(P(\overline{A}B)\)。 $\(P(\overline{A}B) = P(\overline{A})P(B|\overline{A}) = \frac{6}{10} \times \frac{4}{9} = \frac{4}{15}\)$ * 问3： 甲乙都难的概率 \(P(AB)\)。 $\(P(AB) = P(A)P(B|A) = \frac{4}{10} \times \frac{3}{9} = \frac{2}{15}\)$ * 问4： 甲乙丙都难的概率 \(P(ABC)\)。 $\(P(ABC) = P(A)P(B|A)P(C|AB) = \frac{4}{10} \times \frac{3}{9} \times \frac{2}{8} = \frac{1}{30}\)$ (以上问题均可通过古典概型直接计算验证)

    例4：乘法公式的实际应用（玻璃破碎）¶

    一块玻璃，第一次落下未破的概率为0.5；第一次未破则第二次落下未破的概率为0.3；前两次未破则第三次落下未破的概率为0.1。求落下三次未破的概率。 设 \(A_i\) 为“第 \(i\) 次落下未破”。已知 \(P(A_1)=0.5\), \(P(A_2|\overline{A_1})\)? 注意：题目条件为“第一次未破，第二次破”的概率为0.7，因此 \(P(A_2|A_1)=0.3\)。同理，\(P(A_3|A_1A_2)=0.1\)。 求 \(P(A_1A_2A_3)\)。 $\(P(A_1A_2A_3) = P(A_1)P(A_2|A_1)P(A_3|A_1A_2) = 0.5 \times 0.3 \times 0.1 = 0.015\)$

    例5：条件概率与乘法公式的辨析（不放回抽样）¶

    盒中有5件合格品，3件次品。不放回取3件。 设 \(A_i\) 为“第 \(i\) 件取到合格品”。 * 问1： 前两次是次品，第三次是合格品的概率。 即求 \(P(A_3 | \overline{A_1}\overline{A_2})\)。已知前两次取出两件次品，剩余3件产品中只有1件次品，故： $\(P(A_3 | \overline{A_1}\overline{A_2}) = \frac{5}{6}\)$ * 问2： 第三次取到合格品的概率。 即求 \(P(\overline{A_1}\overline{A_2}A_3)\)。 $\(P(\overline{A_1}\overline{A_2}A_3) = P(\overline{A_1})P(\overline{A_2}|\overline{A_1})P(A_3|\overline{A_1}\overline{A_2}) = \frac{3}{8} \times \frac{2}{7} \times \frac{5}{6} = \frac{5}{56}\)$ (注意：问题1是条件概率，问题2是事件交的概率，描述不同。)

    例6：公式综合应用¶

    已知 \(P(A)=0.5\), \(P(B)=0.4\), \(P(B|A)=0.6\)。 1. 求 \(P(AB)\)：\(P(AB)=P(A)P(B|A)=0.5 \times 0.6=0.3\) 2. 求 \(P(A \cup B)\)：\(P(A \cup B)=P(A)+P(B)-P(AB)=0.5+0.4-0.3=0.6\) 3. 求 \(P(A|B)\)：\(P(A|B)=\frac{P(AB)}{P(B)}=\frac{0.3}{0.4}=0.75\)

    例7：逆推求未知概率¶

    已知 \(P(A)=\frac{1}{3}\), \(P(A|B)=\frac{2}{3}\), \(P(\overline{B}|A)=\frac{3}{5}\)。求 \(P(B)\)。 1. 由 \(P(\overline{B}|A)=\frac{3}{5}\) 得 \(P(B|A)=1 - \frac{3}{5}=\frac{2}{5}\)。 2. 由乘法公式 \(P(AB)=P(A)P(B|A)=\frac{1}{3} \times \frac{2}{5}=\frac{2}{15}\)。 3. 再由条件概率公式 \(P(A|B)=\frac{P(AB)}{P(B)}\)，得 \(P(B)=\frac{P(AB)}{P(A|B)}=\frac{2/15}{2/3}=\frac{1}{5}\)。

    本节重点： - 条件概率 \(P(B|A) = \frac{P(AB)}{P(A)}\)，本质是缩小样本空间 - 乘法公式 \(P(AB) = P(A)P(B|A)\)，可推广到多个事件：\(P(ABC) = P(A)P(B|A)P(C|AB)\) - 常见坑：条件概率 \(P(B|A)\) 和联合概率 \(P(AB)\) 是两回事。\(P(B|A)\) 是"已知 A 发生的情况下 B 的概率"，\(P(AB)\) 是"A 和 B 同时发生的概率"
