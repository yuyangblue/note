    1. 频率的定义¶

    1.1 频数与频率¶

    在相同条件下进行 \(n\) 次重复试验，考察事件 \(A\) 是否发生。

    • 频数：\(n\) 次试验中事件 \(A\) 发生的次数，记为 \(n_A\)（或 \(f_n\)）。
    • 频率：事件 \(A\) 发生的次数与试验总次数的比值，记为 \(f_n(A)\)： $$ f_n(A) = \frac{n_A}{n} $$

    示例：抛一枚硬币 100 次，正面朝上出现 52 次。 - 频数 \(n_A = 52\) - 频率 \(f_n(A) = \frac{52}{100} = 0.52\)

    1.2 频率的直观理解¶

    频率反映了事件 \(A\) 在 \(n\) 次试验中出现的"频繁程度"。它是一个试验后才能确定的量，依赖于具体的试验结果，因此带有随机性。

    2. 频率的性质¶

    频率具有以下基本性质：

    1. 非负性：\(0 \leq f_n(A) \leq 1\)

    2. 因为 \(0 \leq n_A \leq n\)，所以比值在 0 和 1 之间。

    3. 规范性：\(f_n(\Omega) = 1\)，\(f_n(\emptyset) = 0\)

    4. 必然事件每次试验都会发生，所以 \(n_\Omega = n\)，\(f_n(\Omega) = 1\)。

    5. 不可能事件每次试验都不会发生，所以 \(n_\emptyset = 0\)，\(f_n(\emptyset) = 0\)。

    6. 可加性：若事件 \(A\) 与 \(B\) 互不相容（\(AB = \emptyset\)），则 $$ f_n(A \cup B) = f_n(A) + f_n(B) $$

    7. 因为 \(A\) 和 \(B\) 不会同时发生，所以 \(A \cup B\) 发生的次数等于 \(A\) 发生的次数加上 \(B\) 发生的次数。

    3. 频率的稳定性¶

    3.1 大量试验下的规律¶

    虽然单次试验的频率有随机性，但大量重复试验中，频率会呈现出一种稳定的趋势——它会在某个常数附近摆动，且随着试验次数 \(n\) 的增大，摆动幅度越来越小。

    这就是频率的稳定性，它是概率论赖以建立的客观基础。

    3.2 经典抛硬币试验¶

    历史上多位学者做过抛硬币试验，数据有力地说明了频率的稳定性：

    试验者 抛掷次数 \(n\) 正面次数 \(n_A\) 正面频率
    蒲丰 (Buffon) 4040 2048 0.5069
    皮尔逊 (K. Pearson) 12000 6019 0.5016
    皮尔逊 (K. Pearson) 24000 12012 0.5005

    可以看到，随着 \(n\) 增大，正面频率越来越接近 \(0.5\)。

    3.3 伯努利大数定律（直观理解）¶

    数学家伯努利从理论上证明了这一现象：当试验次数 \(n\) 足够大时，事件 \(A\) 的频率 \(f_n(A)\) 依概率收敛于事件 \(A\) 的概率 \(P(A)\)。

    用数学语言（不要求证明，理解思想即可）： $$ \lim_{n \to \infty} P\left{ \left| \frac{n_A}{n} - P(A) \right| < \varepsilon \right} = 1 \quad (\text{对任意 } \varepsilon > 0) $$

    通俗理解：只要试验次数足够多，频率几乎一定会在概率附近波动，且波动范围越来越小。

    4. 概率的统计定义¶

    4.1 统计定义¶

    在大量重复试验中，如果事件 \(A\) 的频率 \(f_n(A)\) 稳定地在某个常数 \(p\) 附近摆动，则称常数 \(p\) 为事件 \(A\) 的概率，记为 \(P(A) = p\)。

    4.2 统计定义的局限性¶

    这个定义比较直观，但存在一些问题： 1. 不严格："稳定地摆动"不是精确的数学语言。 2. 依赖试验：需要做大量试验才能得到概率的近似值。 3. 循环定义：定义中隐含了"概率"的概念（大数定律本身需要概率来表述）。

    因此，现代概率论采用公理化定义来解决这些问题。

    5. 概率的公理化定义¶

    1933年，苏联数学家柯尔莫哥洛夫 (Kolmogorov) 提出了概率的公理化体系，奠定了现代概率论的基础。

    5.1 定义¶

    设 \(E\) 是随机试验，\(\Omega\) 是样本空间。对于 \(E\) 的每一个事件 \(A\)（即 \(\Omega\) 的子集），赋予一个实数 \(P(A)\)，称为事件 \(A\) 的概率。若 \(P(A)\) 满足以下三条公理：

    1. 非负性：对任意事件 \(A\)，有 \(P(A) \geq 0\)。
    2. 规范性：\(P(\Omega) = 1\)（必然事件的概率为 1）。
    3. 可列可加性：对两两互不相容的事件 \(A_1, A_2, \dots\)（即 \(A_i A_j = \emptyset, i \neq j\)），有 $$ P\left( \bigcup_{i=1}^{\infty} A_i \right) = \sum_{i=1}^{\infty} P(A_i) $$

    5.2 与频率性质的对比¶

    概率的三条公理与频率的三条性质一一对应，说明公理化定义正是从频率的客观性质中抽象出来的：

    频率的性质 概率的公理
    \(0 \leq f_n(A) \leq 1\) \(P(A) \geq 0\)
    \(f_n(\Omega) = 1\) \(P(\Omega) = 1\)
    \(f_n(A \cup B) = f_n(A) + f_n(B)\)（有限可加） \(P(\bigcup_{i=1}^\infty A_i) = \sum_{i=1}^\infty P(A_i)\)（可列可加）

    6. 概率的基本性质¶

    由公理可以推导出概率的一系列常用性质：

    1. 不可能事件的概率为零： $\(P(\emptyset) = 0\)$

    2. 有限可加性：若 \(A_1, A_2, \dots, A_n\) 两两互不相容，则 $\(P\left( \bigcup_{i=1}^{n} A_i \right) = \sum_{i=1}^{n} P(A_i)\)$

    3. 对立事件的概率： $\(P(\bar{A}) = 1 - P(A)\)$

    4. 减法公式：若 \(A \subseteq B\)，则 $\(P(B - A) = P(B) - P(A)\)$

    5. 加法公式（两个事件）： $\(P(A \cup B) = P(A) + P(B) - P(AB)\)$

    6. 当 \(A\) 与 \(B\) 互不相容时，\(P(AB) = 0\)，退化为 \(P(A \cup B) = P(A) + P(B)\)。

    7. 加法公式（三个事件）： $\(P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(AB) - P(AC) - P(BC) + P(ABC)\)$

    7. 频率与概率的关系总结¶

    频率 概率
    定义基础 试验结果 公理体系
    确定性 随试验结果变化（随机） 客观常数（确定）
    与试验的关系 依赖具体试验 不依赖试验
    关系 试验次数 \(n \to \infty\) 时趋近于概率 频率的稳定值

    一句话：频率是概率的"估计值"，概率是频率的"极限值"。

    8. 补充：零概率事件¶

    以下内容来自视频中关于"概率为零的事件"的讨论，属于对概率性质的深入理解，初学可跳过。

    8.1 什么是零概率事件¶

    概率为零的事件称为零概率事件。数学上表示为 \(P(A) = 0\)。

    8.2 零概率 ≠ 不可能事件¶

    这是一个容易混淆的概念：

    • 不可能事件 (\(\emptyset\))：试验中绝对不会发生的事件。\(P(\emptyset) = 0\)。
    • 零概率事件：概率测度为 0 的事件。它可能发生，尤其在样本空间为无穷集合时。

    关系：所有不可能事件都是零概率事件，但零概率事件不一定是不可能事件。

    数学表述：\(A = \emptyset \Rightarrow P(A) = 0\)，但 \(P(A) = 0\) 不能推出 \(A = \emptyset\)。

    8.3 典型例子¶

    例：几何概型中的单点 向区间 \([0, 1]\) 上均匀随机投点，事件 \(A\) = "落点恰好是 0.5"。 - 该事件可能发生（点 0.5 确实存在）。 - 但区间 \([0, 1]\) 的长度为 1，单个点的长度为 0： $$ P(A) = \frac{0}{1} = 0 $$ - 因此这是一个可能发生但概率为零的事件。

    8.4 对连续型随机变量的重要推论¶

    对于连续型随机变量 \(X\)，取任意特定单点的概率为 0： $\(P(X = x_0) = 0\)$

    由此可得，区间端点是否包含不影响概率值： $\(P(a < X < b) = P(a \leq X \leq b) = P(a \leq X < b) = P(a < X \leq b)\)$

    这将在 2.4 节连续型随机变量中详细讨论（详见 p13 2.4 连续型随机变量及其密度函数）。

    本节重点： - 频率 \(f_n(A) = n_A/n\)，具有非负性、规范性、可加性 - 频率的稳定性是概率存在的基础，伯努利大数定律给出了理论保证 - 概率的公理化定义（三条公理）解决了统计定义的不严格问题 - 概率的加法公式是计算复杂事件概率的基础工具 - 常见坑：零概率事件 ≠ 不可能事件，这在连续型随机变量中尤为关键
