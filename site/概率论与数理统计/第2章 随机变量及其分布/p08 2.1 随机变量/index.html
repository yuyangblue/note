    1. 为什么引入随机变量¶

    • 我们之前讨论的所有随机实验，其结果可以分为两类：
      • 定量的：结果是具体的数值。
        • 例如：掷骰子出现的点数（1, 2, 3, 4, 5, 6）；120服务台一晚接收的电话次数（0, 1, 2, 3, 4...）。
      • 定性的：结果不是数值，而是某种状态或类别。
        • 例如：抛硬币的“正面”或“反面”；一次射击的“命中”或“未命中”；摸球的“黑球”或“白球”。
    • 为了方便进行数学处理和研究，我们需要将定性的结果转化为定量的描述。引入随机变量就是为了实现这一转换。

    2. 随机变量的定义¶

    • 如果随机实验的样本空间为 \(\Omega\)，对于 \(\Omega\) 中的每一个样本点 \(\omega\)，都有一个实数 \(X(\omega)\) 与之对应，则称 \(X\) 为随机变量。
    • 核心理解：
      • 随机变量 \(X\) 本质上是一个定义在样本空间 \(\Omega\) 上的实值函数。
      • 它的自变量是样本点 \(\omega\)（实验结果），因变量 \(X(\omega)\) 是一个实数。
      • 通常用大写字母 \(X, Y, Z\) 或 \(X_1, X_2, X_3\) 等表示随机变量。
      • 本节内容重点在于理解其思想，定义本身理解即可。

    3. 随机变量的表示与事件¶

    • 随机变量的取值对应着一个具体的事件。
    • 事件的表示：使用大括号 { }。
      • 例如，{X = 1} 表示“随机变量 \(X\) 取值为1”这一事件。
    • 事件的概率：在事件符号前加上概率符号 \(P\)。
      • 例如，\(P(\{X = 1\})\) 表示事件“\(X=1\)”发生的概率。
    • 更一般地，\(P(\{X \le x\})\) 表示事件“随机变量 \(X\) 的值小于等于某个实数 \(x\)”发生的概率。这里需要区分大写 \(X\) 和小写 \(x\)。

    4. 示例解析¶

    • 例1：掷骰子
      • 随机变量定义：设 \(X\) 表示掷骰子出现的点数。
      • 取值与事件对应：
        • \(X = 1\) 对应事件 “出现1点”。
        • \(X = 2\) 对应事件 “出现2点”。
        • ...以此类推，\(X = 6\) 对应事件 “出现6点”。
    • 例2：抛硬币
      • 随机变量定义：设 \(X\) 表示抛一次硬币的结果。
      • 取值定义：我们可以规定：
        • \(X = 1\) 表示“正面朝上”。
        • \(X = 0\) 表示“反面朝上”。
    • 例3：射击
      • 随机变量定义：设 \(X\) 表示射击一次命中的次数（只射击一次）。
      • 取值定义：
        • \(X = 1\) 表示“命中”。
        • \(X = 0\) 表示“未命中”。
    • 例4：灯泡寿命
      • 随机变量定义：设 \(X\) 表示一个灯泡的寿命（单位：小时）。
      • 取值范围：\(X\) 的取值范围是 \([0, +\infty)\)。
      • 事件概率：事件“灯泡寿命大于2000小时”可以表示为 \(\{X > 2000\}\)，其概率为 \(P(\{X > 2000\})\)。
    • 例5：候车时间
      • 问题：公交车每隔5分钟一班，求乘客候车时间在1到3分钟之间的概率。
      • 随机变量定义：设 \(X\) 表示乘客的候车时间（单位：分钟）。
      • 取值范围：由于发车间隔为5分钟，\(X\) 的取值范围是 \([0, 5]\)。
      • 所求事件：候车时间在1到3分钟之间，即 \(\{1 \leq X \leq 3\}\)。
      • 概率计算（几何概率）：候车总可能时长为5分钟，满足条件的时长为 \(3-1=2\) 分钟。因此概率为： $\(P(\{1 \leq X \leq 3\}) = \frac{2}{5} = 0.4\)$

    5. 核心概念辨析：大写 X 与小写 x¶

    • 在概率表达式 \(P(\{X \leq x\})\) 中，\(X\) 和 \(x\) 代表不同的含义，这是初学时常有的困惑。
    • 随机变量 \(X\)（大写）：
      • 是一个变量，其具体取值具有随机性，由实验结果决定。
      • 它是一个函数，映射关系为：样本点 \(\omega \rightarrow X(\omega)\)。
    • 实数 \(x\)（小写）：
      • 在表达式 \(P(\{X \leq x\})\) 中，\(x\) 是一个可变的实数，通常作为分界点或阈值。
      • 在讨论某一个具体概率值时，\(x\) 可以被固定为一个具体的常数。
      • 此时，\(\{X \leq x\}\) 就成为一个确定的事件。

    • 类比理解：

      • 这个概念类似于高数中的变上限积分函数 \(\Phi(x) = \int_{a}^{x} f(t) dt\)。
      • 在这个函数中：
        • 积分上限 \(x\) 是一个变量，当它取定某个值时，整个积分表达式成为一个确定的数值。
        • 被积函数中的变量 \(t\) 是积分变量，它的范围是从固定的下限 \(a\) 到变化的上限 \(x\)。
      • 类比到概率中：
        • 小写 \(x\) 就像积分上限 \(x\)，是一个变量，但可以取定。
        • 大写 \(X\) 就像积分变量 \(t\)，在 \(\{X \leq x\}\) 这个事件中，\(X\) 代表所有可能小于等于 \(x\) 的随机取值。

      本节重点： - 随机变量 \(X\) 是定义在样本空间 \(\Omega\) 上的实值函数：\(\omega \mapsto X(\omega)\) - 用随机变量可以将定性结果（正/反）定量化（\(1/0\)） - 区分大写 \(X\) (随机变量) 和小写 \(x\) (实数阈值)：\(\{X \leq x\}\) 是一个事件，\(P(\{X \leq x\})\) 是该事件的概率 - 随机变量分为离散型（取值有限或可列个）和连续型（充满某个区间）两类
