    1. 常见的连续型随机变量：均匀分布¶

    1.1 定义与概率密度函数¶

    如果连续型随机变量 \(X\) 具有如下形式的概率密度函数： $$ f(x) = \begin{cases} \frac{1}{b-a}, & a \leq x \leq b \ 0, & \text{其他} \end{cases} $$ 则称 \(X\) 在区间 \([a, b]\) 上服从均匀分布，记作 \(X \sim U[a, b]\)。

    • 关键点：概率密度函数在区间 \([a, b]\) 上的取值为常数 \(\frac{1}{b-a}\)，该值正好是区间长度的倒数。
    • 图形理解：密度函数 \(f(x)\) 的图形是在区间 \([a, b]\) 上的一条水平线段，高度为 \(\frac{1}{b-a}\)，在其他地方为0。由于概率密度函数的积分（面积）必须为1，而区间 \([a, b]\) 的长度为 \(b-a\)，因此其高度（高）乘以长度（底）必须等于1，所以高为 \(\frac{1}{b-a}\)。

    1.2 分布函数及其图形¶

    均匀分布的分布函数 \(F(x) = P\{X \leq x\}\) 可以通过积分求得： $$ F(x) = \int_{-\infty}^{x} f(t) dt = \begin{cases} 0, & x < a \ \frac{x-a}{b-a}, & a \leq x < b \ 1, & x \geq b \end{cases} $$ * 推导过程： * 当 \(x < a\) 时，\(F(x) = 0\)。 * 当 \(a \leq x < b\) 时，\(F(x) = \int_{a}^{x} \frac{1}{b-a} dt = \frac{1}{b-a} \cdot (x-a) = \frac{x-a}{b-a}\)。 * 当 \(x \geq b\) 时，\(F(x) = \int_{a}^{b} \frac{1}{b-a} dt + \int_{b}^{x} 0 dt = 1\)。 * 图形理解： * \(F(x)\) 的图形是一个分段函数。 * 在区间 \((-\infty, a)\) 上为0。 * 在区间 \([a, b]\) 上是一条从点 \((a, 0)\) 到点 \((b, 1)\) 的斜线段，斜率为 \(\frac{1}{b-a}\)。 * 在区间 \((b, +\infty)\) 上恒为1。 * 重要性质：\(F(x)\) 是一个连续且单调不减的函数。

    1.3 区间概率计算¶

    若 \(X \sim U[a, b]\)，且区间 \([c, d] \subseteq [a, b]\)，则事件 \(\{c \leq X \leq d\}\) 的概率为： $$ P{c \leq X \leq d} = \int_{c}^{d} f(x) dx = \frac{d-c}{b-a} $$ * 理解与计算技巧：这个概率等于所求区间 \([c, d]\) 的长度 \(d-c\) 除以总区间 \([a, b]\) 的长度 \(b-a\)。这就是几何概型的思想，在均匀分布中，概率就是长度的比值。因此，可以直接计算长度比，无需死记公式。 * 注：对于连续型随机变量，在计算概率时，区间端点是否包含（取“=”）不影响结果。

    1.4 例题讲解¶

    【例7】 设 \(X\) 在区间 \([0, \frac{1}{2}]\) 上服从均匀分布，求密度函数 \(f(x)\) 与分布函数 \(F(x)\)。

    • 解：
      1. 由题意，\(X \sim U[0, \frac{1}{2}]\)，区间长度 \(b-a = \frac{1}{2} - 0 = \frac{1}{2}\)。
      2. 密度函数为： $$ f(x) = \begin{cases} \frac{1}{1/2} = 2, & 0 \leq x \leq \frac{1}{2} \ 0, & \text{其他} \end{cases} $$
      3. 分布函数 \(F(x)\) 的推导：
        • 当 \(x < 0\) 时，\(F(x) = 0\)。
        • 当 \(0 \leq x < \frac{1}{2}\) 时，\(F(x) = \int_{0}^{x} 2 dt = 2x\)。
        • 当 \(x \geq \frac{1}{2}\) 时，\(F(x) = 1\)。 因此： $$ F(x) = \begin{cases} 0, & x < 0 \ 2x, & 0 \leq x < \frac{1}{2} \ 1, & x \geq \frac{1}{2} \end{cases} $$

    【例8】 某公共汽车站每隔5分钟有一辆汽车通过，乘客在5分钟内任一时刻到达车站是等可能的，求乘客候车时间在1~3分钟内的概率。

    • 分析：乘客到达时刻 \(X\) 服从 \([0, 5]\) 上的均匀分布，即 \(X \sim U[0, 5]\)。问题求 \(P\{1 \leq X \leq 3\}\)。
    • 解法一（利用密度函数积分）： $$ P{1 \leq X \leq 3} = \int_{1}^{3} \frac{1}{5} dx = \frac{1}{5} \cdot (3-1) = \frac{2}{5} = 0.4 $$
    • 解法二（利用分布函数差）： 首先求出 \(X \sim U[0, 5]\) 的分布函数 \(F(x) = \begin{cases} 0, & x<0 \\ \frac{x}{5}, & 0\leq x<5 \\ 1, & x\geq5 \end{cases}\)。 $$ P{1 \leq X \leq 3} = F(3) - F(1) = \frac{3}{5} - \frac{1}{5} = \frac{2}{5} $$
    • 解法三（利用几何概型/长度比）： 总区间长度为5分钟，所求候车时间（即到达时刻）的区间 \([1, 3]\) 长度为2分钟。 $$ P{1 \leq X \leq 3} = \frac{\text{长度}(1,3)}{\text{长度}(0,5)} = \frac{3-1}{5-0} = \frac{2}{5} $$ 此法最简单直接。

    2. 常见的连续型随机变量：指数分布¶

    2.1 定义与概率密度函数¶

    如果连续型随机变量 \(X\) 具有如下形式的概率密度函数： $$ f(x) = \begin{cases} \lambda e^{-\lambda x}, & x > 0 \ 0, & x \leq 0 \end{cases} $$ 其中 \(\lambda > 0\) 为常数，则称 \(X\) 服从参数为 \(\lambda\) 的指数分布，记作 \(X \sim E(\lambda)\)。

    • 应用背景：指数分布通常用于描述电子元件的使用寿命、等待时间等。
    • 图形理解：由于 \(\lambda > 0\)，当 \(x > 0\) 时，\(f(x) = \lambda e^{-\lambda x}\) 是一个指数衰减函数，图形从 \((0, \lambda)\) 点开始单调下降，并趋近于0。
    • 参数λ的意义：\(\lambda\) 的作用是保证概率密度函数在 \((0, +\infty)\) 上的积分为1，即 \(\int_{0}^{+\infty} \lambda e^{-\lambda x} dx = 1\)。

    2.2 分布函数及其图形¶

    指数分布的分布函数为： $$ F(x) = \begin{cases} 0, & x \leq 0 \ 1 - e^{-\lambda x}, & x > 0 \end{cases} $$ * 推导过程（当 \(x > 0\) 时）： $$ F(x) = \int_{-\infty}^{x} f(t) dt = \int_{0}^{x} \lambda e^{-\lambda t} dt = \lambda \cdot \left[ \frac{e^{-\lambda t}}{-\lambda} \right]_{0}^{x} = - (e^{-\lambda x} - 1) = 1 - e^{-\lambda x} $$ * 图形理解： * 在区间 \((-\infty, 0]\) 上为0。 * 在区间 \((0, +\infty)\) 上，\(F(x) = 1 - e^{-\lambda x}\) 是一个从0开始单调增加并无限趋近于1的曲线。

    2.3 例题讲解¶

    【例9】 设某电子元件的使用寿命 \(X\) 服从 \(\lambda = \frac{1}{1000}\) 的指数分布（单位：小时）。 (1) 写出概率密度 \(f(x)\) 与分布函数 \(F(x)\)； (2) 求一个元件寿命超过1000小时的概率； (3) 若一台仪器装有3个这种元件，其中一个元件损坏，整个仪器停止工作，求该仪器工作1000小时以上的概率。

    • 解： (1) 直接代入 \(\lambda = \frac{1}{1000}\)。 * 概率密度函数：\(f(x) = \begin{cases} \frac{1}{1000} e^{-\frac{x}{1000}}, & x > 0 \\ 0, & x \leq 0 \end{cases}\) * 分布函数：\(F(x) = \begin{cases} 0, & x \leq 0 \\ 1 - e^{-\frac{x}{1000}}, & x > 0 \end{cases}\) (2) 元件寿命超过1000小时，即 \(X > 1000\)。对于连续型随机变量，\(P\{X > 1000\} = P\{X \geq 1000\}\)。 * 方法一（利用密度函数积分）： $$ P{X > 1000} = \int_{1000}^{+\infty} \frac{1}{1000} e^{-\frac{x}{1000}} dx = \left[ -e^{-\frac{x}{1000}} \right]_{1000}^{+\infty} = 0 - (-e^{-1}) = e^{-1} $$ * 方法二（利用分布函数）： $$ P{X > 1000} = 1 - P{X \leq 1000} = 1 - F(1000) = 1 - (1 - e^{-1}) = e^{-1} $$ (3) 仪器由3个元件串联组成，只有当所有3个元件都正常工作超过1000小时时，仪器才能工作超过1000小时。 * 每个元件寿命超过1000小时的概率为 \(e^{-1}\)（见第(2)问）。 * 假设元件寿命相互独立，则3个元件都超过1000小时的概率为： $$ P = (e^{-1}) \times (e^{-1}) \times (e^{-1}) = (e{-1})3 = e^{-3} $$

    2.4 指数分布的无记忆性¶

    【例10】 设 \(X \sim E(\lambda)\)，证明对任意的 \(s > 0\)，\(t > 0\)，有 $$ P{X > s + t | X > s} = P{X > t} $$

    • 证明：

      1. 根据条件概率的定义： $$ P{X > s + t | X > s} = \frac{P{X > s + t \cap X > s}}{P{X > s}} $$
      2. 分析分子中的事件：\(\{X > s + t\} \cap \{X > s\}\) 表示 \(X\) 既要大于 \(s\)，又要大于 \(s+t\)。由于 \(s, t > 0\)，所以 \(s+t > s\)，因此该交集等价于 \(\{X > s + t\}\)。
      3. 所以， $$ P{X > s + t | X > s} = \frac{P{X > s + t}}{P{X > s}} $$
      4. 利用分布函数计算概率：
        • \(P\{X > s + t\} = 1 - F(s + t) = 1 - (1 - e^{-\lambda(s+t)}) = e^{-\lambda(s+t)}\)
        • \(P\{X > s\} = 1 - F(s) = 1 - (1 - e^{-\lambda s}) = e^{-\lambda s}\)
      5. 代入上式： $$ P{X > s + t | X > s} = \frac{e{-\lambda(s+t)}}{e $$}} = e^{-\lambda t
      6. 而 \(P\{X > t\} = e^{-\lambda t}\)。
      7. 因此，\(P\{X > s + t | X > s\} = P\{X > t\}\)。证毕。

    • 无记忆性的直观解释：

      • 这个性质称为指数分布的无记忆性。
      • 它可以这样理解：假设 \(X\) 代表电子元件的寿命。
        • \(P\{X > t\}\) 表示一个全新的元件能使用超过 \(t\) 小时的概率。
        • \(P\{X > s + t | X > s\}\) 表示一个已经使用了 \(s\) 小时且仍正常工作的元件，再继续使用超过 \(t\) 小时（即总寿命超过 \(s+t\) 小时）的概率。
      • 无记忆性告诉我们，这两个概率是相等的。也就是说，一个已经工作了 \(s\) 小时的老元件，它未来能再工作超过 \(t\) 小时的概率，与一个全新的元件能直接工作超过 \(t\) 小时的概率一样。这就像元件“忘记”了它已经工作过 \(s\) 小时。
      • 因此，宋浩老师形象地比喻指数分布是“永远年轻的函数”，具有“无记忆性”。

    本节重点： - 均匀分布 \(X \sim U[a,b]\)：\(f(x)=\frac{1}{b-a}\)，概率 = 长度比，简单直接 - 指数分布 \(X \sim E(\lambda)\)：\(f(x)=\lambda e^{-\lambda x}\ (x>0)\)，常用于寿命/等待时间 - 无记忆性：\(P\{X > s+t \mid X > s\} = P\{X > t\}\)，指数分布是唯一具有无记忆性的连续型分布 - 常见坑：指数分布的参数 \(\lambda\) 是"率"（单位时间发生次数），均值是 \(1/\lambda\)，不是 \(\lambda\)。\(\lambda\) 越大，寿命期望越短
