    1. 引言：为什么研究线性方程组¶

    在自然科学和工程技术中，很多问题的解决最终都归结为解线性代数方程组，例如：电学中的网络问题、船体数学放样中建立三次样条函数问题、用最小二乘法求实验数据的曲线拟合问题、解非线性方程组问题、用差分法或有限元法解常微分/偏微分方程边值问题等。

    课堂口头（方法总览的动机）：线性方程组是"线性问题"的核心。后面最小二乘、优化问题都会落到它身上，所以这一章是整门课的地基。

    系数矩阵大致分两种：

    类型 特征 适用方法
    低阶稠密矩阵 阶数不高（约 ≤150），零元素极少，无特殊结构 直接法
    大型稀疏矩阵 阶数很高（几万、几十万甚至几百万），零元素占绝大多数，非零元集中于对角线附近 迭代法为主

    B 站视频（p012）补充：低阶稠密方程组通常指阶数 <100、零元素很少的类型；大型稀疏方程组阶数可达几万至几百万，但非零元占比很低，且往往分布在对角线附近（带状结构）。

    数值解法分两大类：

    类别 思想 特点
    直接法 有限步算术运算求得精确解（若计算过程中没有舍入误差） 实际有舍入误差，只能得到近似解；是解低阶稠密方程组及部分大型带状方程组的有效方法
    迭代法 从某个近似解出发，用极限过程构造向量序列逐步逼近精确解 存储少、程序简单、系数矩阵始终不变，但存在收敛性及收敛速度问题；是解大型稀疏方程组的重要方法（见第 6 章）

    课堂口头：直接法的"精确"是理论意义上的——不考虑舍入误差时有限步得到精确解；机器上跑出来一定是近似解。

    2. Cramer 法则为什么不可行：\(n!\) 量级运算量¶

    线性代数中的经典方法：\(x_i = \dfrac{\det(A_i)}{\det(A)}\)，其中 \(A_i\) 是把 \(A\) 的第 \(i\) 列换成 \(b\)。

    按定义展开行列式：\(n \times n\) 行列式是 \(n!\) 项之和（每行取一个不同列的元素），每一项约 \(n-1\) 次乘法，总运算量 \(\approx n!\) 量级。

    课堂口头（量级直觉）： - \(n = 8\)：约 \(10^6\) 次运算，勉强能忍； - \(n = 25\)：约 \(10^{25}\) 次，实际完全不可行（虽然方程在一页纸上写得下）。

    B 站视频（p012）补充（定量对比）：以 100 阶方程组为例，假设计算机执行一次乘除法约需 \(3.8 \times 10^{-10}\) 秒，则 - 高斯消去法：约 \(1.30 \times 10^{4}\) 秒（几小时量级）； - Cramer 法则 + 行列式定义：需要的时间是"庞大的天文数字"。

    教训："理论上能解" ≠ "实际可解"。必须关心算法的运算量——这也是本课程每讲一个算法都要分析运算量的原因。

    3. 向量和矩阵预备知识（课本 §5.1.2）¶

    用 \(\mathbb{R}^{m \times n}\) 表示全部 \(m \times n\) 实矩阵的向量空间，\(\mathbb{C}^{m \times n}\) 表示复矩阵空间。\(n\) 维列向量 \(x \in \mathbb{R}^n\)；矩阵 \(A = (a_{ij})\) 可按列 \(A = (a_1, a_2, \dots, a_n)\) 或按行表示。

    基本运算：

    1. 矩阵加法：\(C = A + B\)，\(c_{ij} = a_{ij} + b_{ij}\)；
    2. 矩阵与标量乘法：\(C = \alpha A\)，\(c_{ij} = \alpha a_{ij}\)；
    3. 矩阵乘法：\(C = AB\)，\(c_{ij} = \sum_k a_{ik} b_{kj}\)（\(A \in \mathbb{R}^{m \times p}\)，\(B \in \mathbb{R}^{p \times n}\)，\(C \in \mathbb{R}^{m \times n}\)）；
    4. 转置：\(C = A^T\)，\(c_{ij} = a_{ji}\)；
    5. 单位矩阵：\(I = (e_1, e_2, \dots, e_n)\)，\(e_i\) 为第 \(i\) 个坐标向量；
    6. 非奇异矩阵：若 \(AB = BA = I\) 则 \(B = A^{-1}\)；\((A^{-1})^T = (A^T)^{-1}\)；\((AB)^{-1} = B^{-1}A^{-1}\)；
    7. 行列式：按任一行（列）展开 \(A_{ij} = (-1)^{i+j} M_{ij}\)（代数余子式），性质：
    \[ \det(AB) = \det A \cdot \det B, \qquad \det(A^T) = \det A, \qquad \det(cA) = c^n \det A \]
    \[ \det A \ne 0 \iff A \text{ 是非奇异矩阵} \]

    4. 矩阵的特征值与谱半径（课本 §5.1.3）¶

    定义 1 设 \(A = (a_{ij}) \in \mathbb{R}^{n \times n}\)，若存在数 \(\lambda\)（实数或复数）和非零向量 \(x = (x_1, \dots, x_n)^T \in \mathbb{R}^n\)，使

    \[ Ax = \lambda x \]

    则称 \(\lambda\) 为 \(A\) 的特征值，\(x\) 为 \(A\) 对应 \(\lambda\) 的特征向量。\(A\) 的全体特征值称为 \(A\) 的谱，记作 \(\sigma(A) = \{\lambda_1, \lambda_2, \dots, \lambda_n\}\)。

    定义谱半径：

    \[ \rho(A) = \max_{1 \le i \le n}|\lambda_i| \]

    由 \(Ax = \lambda x\) 知 \(\lambda\) 使齐次方程组 \((\lambda I - A)x = 0\) 有非零解，故 \(\det(\lambda I - A) = 0\)，即特征方程：

    \[ p(\lambda) = \lambda^n + c_1 \lambda^{n-1} + \cdots + c_{n-1}\lambda + c_n = 0 \]

    \(p(\lambda)\) 称为特征多项式。由代数基本定理，\(n\) 次代数方程在复数域有 \(n\) 个根 \(\lambda_1, \dots, \lambda_n\)。展开行列式可得：

    \[ \det A = \lambda_1 \lambda_2 \cdots \lambda_n \]
    \[ \text{tr}A = \lambda_1 + \lambda_2 + \cdots + \lambda_n \quad (\text{tr}A \text{ 为 } A \text{ 的迹}) \]

    特征值、特征向量的基本性质：

    1. \(A^T\) 与 \(A\) 有相同的特征值；
    2. 若 \(A\) 非奇异，则 \(A^{-1}\) 的特征值为 \(\lambda^{-1}\)，特征向量仍为 \(x\)；
    3. 相似矩阵 \(B = S^{-1}AS\) 有相同的特征多项式。

    例 1（课本例 1）求某 3 阶矩阵 \(A\) 的特征值及谱半径，已知其特征方程为

    \[ \det(\lambda I - A) = (\lambda - 2)^2(\lambda + 7) = 0 \]

    解 故 \(A\) 的特征值为 \(\lambda_1 = \lambda_2 = 2\)，\(\lambda_3 = -7\)，谱半径 \(\rho(A) = \max\{|2|, |-7|\} = 7\)。

    说明：谱半径 \(\rho(A)\) 是第 5 章范数、迭代法收敛性分析的核心工具（见 5.4、第 6 章），这里先打好记号基础。

    5. 特殊矩阵（课本 §5.1.4）¶

    设 \(A = (a_{ij}) \in \mathbb{R}^{n \times n}\)：

    类型 定义
    对角矩阵 \(i \ne j\) 时 \(a_{ij} = 0\)
    三对角矩阵 \(\|i - j\| > 1\) 时 \(a_{ij} = 0\)
    上三角矩阵 \(i > j\) 时 \(a_{ij} = 0\)
    上 Hessenberg 阵 \(i > j + 1\) 时 \(a_{ij} = 0\)
    对称矩阵 \(A^T = A\)
    Hermite 矩阵 \(A^H = \bar{A}^T = A\)
    对称正定矩阵 \(A^T = A\) 且对任意非零 \(x \in \mathbb{R}^n\)，\(x^T A x > 0\)
    正交矩阵 \(A^{-1} = A^T\)
    酉矩阵 \(A^{-1} = A^H\)
    初等置换阵 单位阵 \(I\) 交换第 \(i\) 行与第 \(j\) 行（或列）得到的矩阵 \(I_{ij}\)
    置换阵 初等置换阵的乘积

    初等置换阵的作用：\(I_{ij}A\) = 交换 \(A\) 的第 \(i\)、\(j\) 行；\(AI_{ij}\) = 交换第 \(i\)、\(j\) 列。

    定理 1 设 \(A \in \mathbb{R}^{n \times n}\)，下述命题等价：

    1. 对任何 \(b \in \mathbb{R}^n\)，方程组 \(Ax = b\) 有唯一解；
    2. 齐次方程组 \(Ax = 0\) 只有零解 \(x = 0\)；
    3. \(\det A \ne 0\)；
    4. \(A^{-1}\) 存在；
    5. \(\text{rank}(A) = n\)。

    定理 2 设 \(A \in \mathbb{R}^{n \times n}\) 为对称正定矩阵，则

    1. \(A\) 非奇异，且 \(A^{-1}\) 亦对称正定；
    2. \(A\) 的顺序主子阵 \(A_k\)（\(k = 1, 2, \dots, n\)）亦对称正定；
    3. \(A\) 的特征值 \(\lambda_i > 0\)（\(i = 1, \dots, n\)）；
    4. \(A\) 的顺序主子式 \(\det(A_k) > 0\)（\(k = 1, 2, \dots, n\)）。

    定理 3 设 \(A\) 为对称矩阵。若 \(\det(A_k) > 0\)（\(k = 1, 2, \dots, n\)），或 \(A\) 的特征值 \(\lambda_i > 0\)（\(i = 1, \dots, n\)），则 \(A\) 为对称正定矩阵。

    定理 2 与定理 3 是 5.3.2 平方根法 / 改进平方根法的理论基础：顺序主子式全正 ⇔ 对称正定，而顺序主子式又决定了 LU 分解能否进行（见 5.2 定理 6）。

    选读：一般 \(n\) 阶矩阵在相似变换下可化为若尔当（Jordan）标准形（课本定理 4）；若所有若尔当块均为一阶，则化为对角矩阵。本章直接法不依赖该结论，可暂不深入。
