    损失函数¶

    张晓平老师，武汉大学数学与统计学院，神经网络与深度学习课程

    1 最大似然：从概率视角构建损失函数¶

    1.1 核心思想转变¶

    前三章建立的神经网络模型，本质是"输入 x → 输出 y 的确定性映射"。本章的关键转变：

    不再将神经网络视为直接预测 y 的映射工具，而是定义为"计算输出空间上概率分布 \(Pr(y|\theta)\) 的参数 \(\theta\) 的载体"。

    这一转变为损失函数的构建提供了原则性方法。

    1.2 计算输出分布¶

    如何让神经网络输出概率分布？分两步：

    1. 选定参数化概率分布：根据任务选择定义在输出域 \(y\) 上的分布 \(Pr(y|\theta)\)（如高斯分布由 \(\mu, \sigma^2\) 决定）
    2. 神经网络预测分布参数：用模型 \(f(x,\phi)\) 预测 \(\theta\) 中的一个或多个，建立输入与分布参数的映射
    \[\theta = f(x,\phi) \Longrightarrow Pr(y|\theta) = Pr(y|f(x,\phi))\]

    例子：回归任务中，选正态分布，模型预测均值 \(\mu = f(x,\phi)\)，方差 \(\sigma^2\) 可固定或同步学习。

    1.3 最大似然准则¶

    训练时，模型为每个输入 \(x_i\) 预测分布参数 \(\theta_i = f(x_i, \phi)\)。核心目标：选择 \(\phi\)，最大化所有训练数据的联合概率（似然）：

    \[\hat{\phi} = \arg\max_\phi \prod_{i=1}^{I} Pr(y_i | f(x_i, \phi))\]

    i.i.d. 假设——似然分解的前提： - 同分布：所有 \(y_i\) 服从相同形式的参数化分布（仅参数 \(\theta_i\) 不同） - 独立：给定 \(x_i\) 时，各 \(y_i\) 的条件分布相互独立

    因此联合似然可分解为乘积：

    \[Pr(y_1, y_2, \ldots, y_I | x_1, x_2, \ldots, x_I) = \prod_{i=1}^{I} Pr(y_i | x_i)\]

    1.4 最大对数似然——解决数值下溢¶

    问题：单个 \(Pr(y_i|f(x_i,\phi))\) 通常是极小值，多个相乘迅速趋近于0 → 数值下溢。

    解法：取对数。\(\log\) 单调递增，最大值位置不变，且乘积变求和：

    \[\hat{\phi} = \arg\max_\phi \prod_{i=1}^{I} Pr(y_i|f(x_i,\phi)) = \arg\max_\phi \sum_{i=1}^{I} \log Pr(y_i|f(x_i,\phi))\]

    为什么对数不影响优化？ 因为 \(\log(x)\) 随 \(x\) 单调递增，所以 \(g(z)\) 和 \(\log g(z)\) 在同一位置取最大值。这就像用对数刻度看数据，最高点还是最高点。

    1.5 最小化负对数似然——转化为损失函数¶

    机器学习习惯"最小化损失函数"，所以加个负号翻转方向：

    \[\hat{\phi} = \arg\min_\phi \left[-\sum_{i=1}^{I} \log Pr(y_i|f(x_i,\phi))\right] := \arg\min_\phi L(\phi)\]

    \(L(\phi)\) 就是负对数似然损失函数，值越小 → 模型预测分布越贴合真实数据。

    ⁉️⁉️⁉️1.6 推断——从概率分布到预测结果¶

    模型不直接输出 \(y\)，而是预测分布参数 \(\theta\)。实际需要一个明确预测值：

    \[\hat{y} = \arg\max_y Pr(y|f(x,\phi))\]
    分布类型 预测值
    高斯分布（回归） 均值 \(\hat{y} = \mu\)
    Categorical 分布（多分类） 概率最高的类别 \(\hat{y} = \arg\max_c Pr(y=cx)\)

    2 损失函数的构造方法（三步法）¶

    基于最大似然法构造损失函数，可统一为三个步骤：

    步骤 操作 说明
    1 选概率分布 根据输出域特性选 \(Pr(y\theta)\)（连续→正态，离散→Categorical，...）
    2 设计模型 \(f(x,\phi)\) 预测分布参数 \(\theta\)，建立 \(x → \theta\) 的映射
    3 最小化NLL \(L(\phi) = -\sum_{i=1}^I \log Pr(y_if(x_i,\phi))\)

    推断时：返回完整分布 \(Pr(y|f(x,\hat\phi))\) 或其众数/均值。

    3 单变量回归¶

    3.1 正态分布假设¶

    输出 \(y \in \mathbb{R}\)，假设服从正态分布：

    \[Pr(y|\mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left[-\frac{(y-\mu)^2}{2\sigma^2}\right]\]
    • 均值 \(\mu\)：分布中心，概率密度峰值位置
    • 方差 \(\sigma^2\)：离散程度，\(\sigma^2\) 越小分布越"尖"
    • 注意：概率密度积分恒为1，方差减小 → 峰更高、范围更窄

    模型设置：\(f(x,\phi)\) 预测均值 \(\mu\)，方差 \(\sigma^2\) 暂设为固定值：

    \[Pr(y|f(x,\phi), \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left[-\frac{(y-f(x,\phi))^2}{2\sigma^2}\right]\]

    3.2 最小二乘损失函数的推导（重点！）¶

    将正态分布代入负对数似然，化简：

    \[\begin{aligned} L(\phi) &= -\sum_{i=1}^{I} \log\left[\frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y_i-f(x_i,\phi))^2}{2\sigma^2}\right)\right] \\ &= -\sum_{i=1}^{I} \left[\log\frac{1}{\sqrt{2\pi\sigma^2}} + \left(-\frac{(y_i-f(x_i,\phi))^2}{2\sigma^2}\right)\right] \\ &= -\sum_{i=1}^{I} \log\frac{1}{\sqrt{2\pi\sigma^2}} + \sum_{i=1}^{I} \frac{(y_i-f(x_i,\phi))^2}{2\sigma^2} \end{aligned}\]
    • 第一项 \(\log\frac{1}{\sqrt{2\pi\sigma^2}}\) 与 \(\phi\) 无关，是常数，去掉
    • \(\frac{1}{2\sigma^2}\) 也是常数，去掉

    最终得到：

    \[\boxed{L(\phi) = \sum_{i=1}^{I} [y_i - f(x_i, \phi)]^2}\]

    核心结论：最小二乘损失不是独立发明的准则，而是"正态分布假设 + 负对数似然"的自然结果！

    延伸理解：MSE 也是交叉熵

    交叉熵不是分类任务的专利。只要你假设了数据服从某种分布，那么负对数似然 = 交叉熵（差一个常数）。

    对于回归任务： - 真实分布 \(P\)：以真实值 \(y_i\) 为均值的高斯分布（方差为 \(\sigma^2\)） - 模型分布 \(Q\)：以预测值 \(f(x_i,\phi)\) 为均值的高斯分布（同方差）

    两个高斯分布的交叉熵化简后，就是均方误差 MSE。

    所以：二分类用伯努利分布→交叉熵，回归用高斯分布→MSE，本质上都是交叉熵，只是分布假设不同。

    推导前提假设： 1. 独立性：各样本预测误差相互独立 2. 正态性：预测误差服从均值为 \(f(x_i,\phi)\) 的正态分布

    3.3 最小二乘的直觉¶

    - 拟合好：预测值（绿线）与真实值（橙点）偏差小，平方和小 → 对应每个 \(y_i\) 处的条件概率 \(Pr(y_i|x_i)\) 高 - 拟合差：偏差大，平方和大 → 各点条件概率都低

    拟合好 = 数据点处的概率密度高 = 似然大 = 损失小。三个视角说的是同一件事。

    3.4 方差估计——预测不确定性¶

    固定 \(\sigma^2\) 太死板，能否让模型也学习方差？可以！

    让模型同时预测均值和方差：

    \[\mu = f_1(x,\phi), \quad \sigma^2 = f_2(x,\phi)\]

    此时负对数似然不能丢掉 \(\sigma^2\) 相关项了（因为 \(\sigma^2\) 也依赖 \(\phi\)），损失函数为：

    \[L(\phi) = \sum_{i=1}^{I} \left[\frac{(y_i - f_1(x_i,\phi))^2}{2f_2(x_i,\phi)^2} + \frac{1}{2}\log f_2(x_i,\phi)^2\right]\]

    直觉：模型不仅要预测"均值在哪"（\(f_1\)），还要预测"不确定度多大"（\(f_2\)）。不确定度大的地方，模型对偏差更宽容（第一项除以大 \(\sigma^2\) 后变小）。

    3.5 异方差回归¶

    • 同方差：\(\sigma^2\) 对所有 \(x\) 相同（传统最小二乘）
    • 异方差：\(\sigma^2\) 随 \(x\) 变化（更贴近现实）

    建模：双输出网络，分别预测均值 \(f_1(x,\phi)\) 和方差 \(f_2(x,\phi)^2\)

    \[\sigma^2 = f_2(x,\phi)^2\]

    为什么要用平方？ 因为方差必须非负，用 \(f_2^2\) 自动保证这一点。

    4 二分类问题建模¶

    4.1 Bernoulli 分布 + Sigmoid 激活¶

    概率建模：输出 \(y \in \{0,1\}\)，用 Bernoulli 分布：

    \[Pr(y|\lambda) = \lambda^y (1-\lambda)^{1-y}\]
    • \(y=1\) 时 \(Pr = \lambda\)（正类概率）
    • \(y=0\) 时 \(Pr = 1-\lambda\)（负类概率）

    Sigmoid 函数：将网络输出 \(z \in \mathbb{R}\) 映射到 \([0,1]\)：

    \[\lambda = \sigma(z) = \frac{1}{1+\exp(-z)}\]
    \(z\) 值 \(\sigma(z)\) 含义
    \(z \to +\infty\) \(\to 1\) 强烈预测正类
    \(z = 0\) \(= 0.5\) 不确定
    \(z \to -\infty\) \(\to 0\) 强烈预测负类

    4.2 二分类交叉熵损失的推导¶

    将 Bernoulli + Sigmoid 代入 NLL：

    \[\begin{aligned} L(\phi) &= -\sum_{i=1}^{I} \log Pr(y_i|\sigma(f(x_i,\phi))) \\ &= -\sum_{i=1}^{I} \log[\sigma(f(x_i,\phi))^{y_i} \cdot (1-\sigma(f(x_i,\phi)))^{1-y_i}] \\ &= -\sum_{i=1}^{I} [y_i \log\sigma(f(x_i,\phi)) + (1-y_i)\log(1-\sigma(f(x_i,\phi)))] \end{aligned}\]
    \[\boxed{L(\phi) = -\sum_{i=1}^{I} [y_i \log\sigma(f(x_i,\phi)) + (1-y_i)\log(1-\sigma(f(x_i,\phi)))]}\]

    直觉理解： - 当 \(y_i=1\)（正样本），只有 \(\log\sigma(\cdot)\) 项起作用，\(\sigma\) 越接近1损失越小 - 当 \(y_i=0\)（负样本），只有 \(\log(1-\sigma(\cdot))\) 项起作用，\(\sigma\) 越接近0损失越小 - 本质：让模型对正确类别的预测概率尽可能高

    4.2.2 双视角解读：为什么它既是NLL又是交叉熵？¶

    你可能会疑惑：这个公式明明是从伯努利分布推出来的，为什么叫"交叉熵损失"？

    答案是：这不是巧合——负对数似然（NLL）和交叉熵，本质上是同一个东西的两个名字。

    视角A：概率视角（NLL）——我们刚才的推导¶
    \[L = -\log Pr(y|\lambda) = -[y \log \lambda + (1-y) \log (1-\lambda)]\]

    出发点：最大化观测数据出现的概率。

    视角B：信息论视角（交叉熵）¶

    交叉熵的定义：两个分布 \(P\) 和 \(Q\) 的交叉熵衡量"用 \(Q\) 来编码服从 \(P\) 的样本，平均需要多少比特"。

    \[H(P, Q) = -\sum_x P(x) \log Q(x)\]

    对于二分类问题： - 真实分布 \(P\)：标签是 \(y\)，所以 \(P(1)=y,\ P(0)=1-y\)（这是一个确定的伯努利分布） - 预测分布 \(Q\)：模型输出是 \(\sigma(z)\)，所以 \(Q(1)=\sigma(z),\ Q(0)=1-\sigma(z)\)

    代入交叉熵定义： $$ \begin{aligned} H(P, Q) &= -P(1)\log Q(1) - P(0)\log Q(0) \ &= -y \log \sigma(z) - (1-y) \log (1-\sigma(z)) \end{aligned} $$

    和NLL的结果完全一样！

    为什么叫"交叉"熵？

    熵 \(H(P) = -\sum P(x)\log P(x)\) 是"用真实分布P自己编码自己"的最短码长。

    交叉熵 \(H(P, Q) = -\sum P(x)\log Q(x)\) 是"用Q的编码去描述P的数据"的码长——P和Q交叉了，所以叫交叉熵。

    因为Q≠P，所以交叉熵总是 ≥ 熵（多出的部分就是KL散度）。

    两个视角的关系¶
    \[ \underbrace{-\log p_{\text{model}}(y|x)}_{\text{负对数似然 NLL}} = \underbrace{H(p_{\text{data}}, p_{\text{model}})}_{\text{交叉熵}} - \underbrace{H(p_{\text{data}})}_{\text{常数（真实分布的熵）}} \]

    去掉那个和模型无关的常数项，两者就完全等价。

    大白话： - 似然视角："模型参数取什么值时，观测到这些数据的概率最大？" - 交叉熵视角："模型预测的分布和真实分布差多少？" - 答案是同一个——最小化交叉熵 = 最大化似然

    4.2.3 交叉熵损失的梯度推导（重点！）¶

    我们来推导单个样本的损失对网络输出 \(z = f(x,\phi)\) 的梯度。

    已知条件： - Sigmoid 的导数：\(\sigma'(z) = \sigma(z)(1-\sigma(z))\) - 单个样本损失：\(L = -y\log\sigma(z) - (1-y)\log(1-\sigma(z))\)

    求导过程：

    \[ \begin{aligned} \frac{\partial L}{\partial z} &= -y \cdot \frac{\sigma'(z)}{\sigma(z)} - (1-y) \cdot \frac{-\sigma'(z)}{1-\sigma(z)} \\ &= -y \cdot \frac{\sigma(z)(1-\sigma(z))}{\sigma(z)} + (1-y) \cdot \frac{\sigma(z)(1-\sigma(z))}{1-\sigma(z)} \\ &= -y \cdot (1-\sigma(z)) + (1-y) \cdot \sigma(z) \\ &= -y + y\sigma(z) + \sigma(z) - y\sigma(z) \\ &= \sigma(z) - y \end{aligned} \]
    \[ \boxed{\frac{\partial L}{\partial z} = \sigma(z) - y} \]

    这个结论非常重要！

    • 形式简洁：梯度就是"预测概率 - 真实标签"
    • 物理意义明确：预测值和真实值差多少，梯度就有多大
    • 避免梯度消失：如果用 MSE 损失 + Sigmoid，梯度会包含 \(\sigma'(z)\)，当 z 很大或很小时，\(\sigma'(z) \to 0\)，梯度消失，训练不动。而交叉熵损失的梯度里 \(\sigma'(z)\) 被约掉了，没有这个问题！

    这就是为什么分类任务用交叉熵而不用MSE的核心原因之一。

    4.3 决策规则¶

    \[\hat{y} = \mathbb{I}[f(x,\phi) \geq 0]\]
    • \(\sigma(z) = 0.5\) 对应 \(z = 0\)
    • 所以决策阈值在 \(z=0\)，简化为直接判定网络输出的符号

    4.4 Sigmoid 的拟合特性¶

    理想状态下： - 正样本区域（\(y_i=1\)）对应高 \(\lambda\) 值 - 负样本区域（\(y_i=0\)）对应低 \(\lambda\) 值 - 正类概率 \(\lambda\)（实线）与负类概率 \(1-\lambda\)（虚线）之和恒为1

    5 多分类问题建模¶

    5.1 Categorical 分布 + Softmax 激活¶

    概率建模：输出 \(y \in \{1,2,\ldots,K\}\)，用 Categorical 分布：

    \[Pr(y=k) = \lambda_k, \quad k=1,\ldots,K\]

    约束：\(\lambda_k \in [0,1]\)，\(\sum_{k=1}^K \lambda_k = 1\)。

    Softmax 函数：将 \(K\) 维任意实数向量映射为概率分布：

    \[\text{softmax}_k(z) = \frac{\exp(z_k)}{\sum_{k'=1}^{K} \exp(z_{k'})}\]

    Softmax 的关键性质： - 所有输出 \(\in (0,1)\) - 所有输出之和 = 1 - \(\exp\) 保证非负，分母归一化 - 最大的 \(z_k\) 对应最大的概率（保序性）

    5.2 多分类交叉熵损失¶

    \[\boxed{L(\phi) = -\sum_{i=1}^{I} \left[f_{y_i}(x_i,\phi) - \log\sum_{k'=1}^{K} \exp[f_{k'}(x_i,\phi)]\right]}\]

    解读： - \(f_{y_i}(x_i,\phi)\)：网络对真实类别 \(y_i\) 的输出值 → 这个越大越好（第一项是正的） - \(\log\sum \exp[f_{k'}]\)：log-sum-exp 项，是所有类别输出的"软最大值" → 这个越小越好（前面有负号） - 两者之差 = 真实类别的输出比其他类别高出多少 → 差越大损失越小

    5.3 Softmax 函数的导数¶

    Softmax 函数 \(s_i = \frac{e^{z_i}}{\sum_j e^{z_j}}\) 对输入 \(z_j\) 的偏导：

    \[\boxed{\frac{\partial s_i}{\partial z_j} = s_i(\delta_{ij} - s_j)}\]

    其中 \(\delta_{ij}\) 是克罗内克函数（\(i=j\) 时为1，否则为0）。

    分情况理解： - \(i = j\)（对自身求导）：\(\frac{\partial s_i}{\partial z_i} = s_i(1 - s_i)\)，和 Sigmoid 导数形式一致 - \(i \neq j\)（对其他分量求导）：\(\frac{\partial s_i}{\partial z_j} = -s_i s_j < 0\)，\(z_j\) 增大会让其他类别的概率下降

    直觉：Softmax 是零和博弈——\(z_j\) 变大，\(s_j\) 变大，其他所有 \(s_i\) 都必须变小（因为总和=1）。

    5.4 多分类交叉熵损失的梯度推导（重点！）¶

    单个样本的交叉熵损失（\(y_k\) 是 one-hot 标签）： $\(L = -\sum_{k=1}^K y_k \log s_k\)$

    对第 \(j\) 个 logit \(z_j\) 求梯度，链式法则展开： $$ \frac{\partial L}{\partial z_j} = \sum_{i=1}^K \frac{\partial L}{\partial s_i} \cdot \frac{\partial s_i}{\partial z_j} $$

    第一步：\(\frac{\partial L}{\partial s_i} = -\frac{y_i}{s_i}\)

    第二步：代入 Softmax 导数 \(s_i(\delta_{ij} - s_j)\)： $$ \begin{aligned} \frac{\partial L}{\partial z_j} &= \sum_{i=1}^K \left(-\frac{y_i}{s_i}\right) \cdot s_i(\delta_{ij} - s_j) \ &= -\sum_{i=1}^K y_i(\delta_{ij} - s_j) \ &= -y_j + s_j \sum_{i=1}^K y_i \ &= s_j - y_j \end{aligned} $$

    最后一步因为 one-hot 标签满足 \(\sum_{i=1}^K y_i = 1\)。

    \[\boxed{\frac{\partial L}{\partial z_j} = s_j - y_j}\]

    和二分类的完美统一：

    任务 损失 对 logit 的梯度
    二分类 \(-y\log\sigma - (1-y)\log(1-\sigma)\) \(\sigma(z) - y\)
    多分类 \(-\sum y_k \log s_k\) \(s_j - y_j\)

    形式完全一致：梯度 = 预测概率 − 真实标签。

    这不是巧合——交叉熵损失 + (Sigmoid/Softmax) 的组合，对数求导和激活函数导数恰好约掉，得到极其简洁的结果。同时这也解释了为什么分类任务用交叉熵不用MSE：MSE的梯度里会保留激活函数导数，两端饱和时梯度消失。

    5.5 决策规则¶

    \[\hat{y} = \arg\max_k Pr(y=k|f(x,\hat\phi))\]

    选择概率最大的类别。由于 Softmax 保序，等价于 \(\hat{y} = \arg\max_k f_k(x,\hat\phi)\)。

    6 多输出预测建模¶

    6.1 任务定义¶

    模型同时预测多个目标值 \(y = [y_1, y_2, \ldots, y_D]^T\)。

    例子： - 分子性质预测：同时预测熔点和沸点 - 图像分割：逐像素分类

    6.2 独立性假设¶

    多变量联合分布复杂，实际中假设各输出分量独立：

    \[Pr(y|f(x_i,\phi)) = \prod_{d=1}^{D} Pr(y_d|f_d(x_i,\phi))\]

    每个分量 \(f_d(x_i,\phi)\) 专门预测第 \(d\) 个目标的分布参数。

    6.3 损失函数¶

    \[L(\phi) = -\sum_{i=1}^{I} \sum_{d=1}^{D} \log Pr(y_{id}|f_d(x_i,\phi))\]

    各分量独立 → 总损失 = 各分量 NLL 之和。简单加法，没有交叉项。

    6.4 混合类型多输出¶

    实际场景中不同输出分量类型可能不同。例如气象预测：

    输出 定义域 分布
    风向 \(y \in (-\pi, \pi]\) von Mises 分布
    风速 \(y \in \mathbb{R}^+\) 指数分布

    损失函数（2个分量为例）：

    \[L(\phi) = -\sum_{i=1}^{I} [\log Pr(y_{i1}|f_1(x_i,\phi)) + \log Pr(y_{i2}|f_2(x_i,\phi))]\]

    核心逻辑：各分量选各自的分布，NLL 分别算，最后加起来。

    7 交叉熵与 KL 散度¶

    7.1 KL 散度¶

    度量两个概率分布 \(q\)（真实/经验分布）和 \(p\)（模型分布）的差异：

    \[KL(q\|p) = \int_{-\infty}^{\infty} q(z) \log\frac{q(z)}{p(z)} dz = \mathbb{E}_{z\sim q}\left[\log\frac{q(z)}{p(z)}\right]\]

    三大核心性质：

    性质 含义 直觉
    非负性 \(KL(q\|p) \geq 0\) 差异不可能为负
    不对称性 \(KL(q\|p) \neq KL(p\|q)\) "用 \(p\) 近似 \(q\)" 和 "用 \(q\) 近似 \(p\)" 是不同的事
    零差异 \(q=p\) 时 \(KL=0\) 完全一致则无差异

    7.2 经验分布¶

    训练数据的经验分布用 Dirac delta 函数表示：

    \[q(y) = \frac{1}{I}\sum_{i=1}^{I} \delta(y - y_i)\]

    Dirac delta 函数：仅在 \(y=y_i\) 处取无穷大，其余为0，积分为1。直观理解就是"数据只出现在观测点处"。

    7.3 交叉熵的定义与推导¶

    目标：最小化 \(KL(q\|Pr)\)

    \[\begin{aligned} \hat\theta &= \arg\min_\theta KL(q\|Pr) \\ &= \arg\min_\theta \left[\int q(y)\log q(y) dy - \int q(y)\log Pr(y|\theta) dy\right] \\ &= \arg\min_\theta \left[-\int q(y)\log Pr(y|\theta) dy\right] \end{aligned}\]

    第一项 \(\int q(y)\log q(y) dy\) 仅与经验分布有关，与模型参数 \(\theta\) 无关，去掉。

    第二项就是交叉熵：

    \[\boxed{H(q, Pr) = -\mathbb{E}_{y\sim q}[\log Pr(y|\theta)]}\]

    信息论直觉：交叉熵 = 用模型分布描述真实数据所需的"最小额外信息量"。信息量越小 → 两个分布越接近 → 拟合越好。

    7.4 核心定理：最小化交叉熵 = 最小化负对数似然¶

    证明：

    \[\begin{aligned} \hat\theta &= \arg\min_\theta H(q, Pr) = \arg\min_\theta \left[-\int q(y)\log Pr(y|\theta) dy\right] \\ &= \arg\min_\theta \left[-\int \left(\frac{1}{I}\sum_{i=1}^{I}\delta(y-y_i)\right)\log Pr(y|\theta) dy\right] \\ &= \arg\min_\theta \left[-\frac{1}{I}\sum_{i=1}^{I}\log Pr(y_i|\theta)\right] \\ &= \arg\min_\theta \left[-\sum_{i=1}^{I}\log Pr(y_i|\theta)\right] \end{aligned}\]

    最后一步去掉了 \(1/I\)（常数不影响优化），结果就是负对数似然！\(\square\)

    🔑 关键步骤详解：Dirac δ 的筛选性质（Sifting Property）¶

    上面推导中第 2 → 第 3 行是怎么从积分变成求和的？这一步用到了 Dirac δ 函数最核心的性质：

    \[ \boxed{\int_{-\infty}^{+\infty} f(y)\,\delta(y - y_i)\,dy = f(y_i)} \]

    直观理解：δ 函数只在 \(y = y_i\) 这一点"有质量"，所以积分会把被积函数 \(f(y)\) 在该点的取值"挑出来（sift out）"，其余位置全部归零。

    逐步还原推导：

    Step 1 —— 把求和提到积分外（积分和求和都是线性运算，可以交换顺序）：

    \[ -\int \left(\frac{1}{I}\sum_{i=1}^{I}\delta(y-y_i)\right)\log Pr(y|\theta)\, dy = -\frac{1}{I}\sum_{i=1}^{I}\int \delta(y-y_i)\log Pr(y|\theta)\, dy \]

    Step 2 —— 对每一项使用筛选性质，令 \(f(y) = \log Pr(y|\theta)\)：

    \[ \int \delta(y-y_i)\log Pr(y|\theta)\, dy = \log Pr(y_i|\theta) \]

    Step 3 —— 代回原式：

    \[ = -\frac{1}{I}\sum_{i=1}^{I}\log Pr(y_i|\theta) \]

    ✅ 积分形式塌缩成了求和形式。

    💡 为什么会"塌缩"？¶

    因为经验分布 \(q(y) = \frac{1}{I}\sum_i \delta(y-y_i)\) 的全部"质量"都集中在 \(I\) 个观测点上，其余位置概率为 0。所以对 \(y\) 做的连续积分，等价于只在这 \(I\) 个观测点上求和——这正是 "连续期望 → 样本平均" 的数学根基。

    一句话总结：利用 δ 函数的筛选性质，把交叉熵的积分形式"积掉"，自然得到训练样本上的负对数似然。这就是 最小化交叉熵 ⟺ 最大化对数似然 在数学上严格等价的根源。

    注意：实际中 \(\theta\) 由模型 \(f(x_i,\phi)\) 计算，所以优化目标为：

    \[\hat\phi = \arg\min_\phi \left[-\sum_{i=1}^{I}\log Pr(y_i|f(x_i,\phi))\right]\]

    7.5 交叉熵的分解关系¶

    \[H(q, p) = H(q) + KL(q\|p)\]
    • \(H(q) = -\int q(y)\log q(y) dy\)：真实分布的熵，数据固有不确定性，与模型无关
    • \(KL(q\|p)\)：用 \(p\) 近似 \(q\) 的信息损失

    等价性总结：\(H(q)\) 是常数 → 最小化 \(H(q,p)\) ⟺ 最小化 \(KL(q\|p)\) ⟺ 最小化NLL ⟺ 最大化似然

    一句话串联四个等价目标：

    \[\text{最小化交叉熵} = \text{最小化KL散度} = \text{最小化负对数似然} = \text{最大化似然}\]

    7.6 扩展：其他分布度量¶

    度量 特点 适用场景
    KL 散度 不对称，\(q\to p\) 和 \(p\to q\) 不同 MLE/交叉熵的理论基础
    JS 散度 对称版KL，解决不对称问题 GAN的早期损失
    Wasserstein 距离 度量分布间"搬运代价"，分布重叠少时仍有梯度 WGAN，分布差异大的场景

    为什么需要 Wasserstein？ 当两个分布没有重叠时（如一条直线和一条平行线），KL散度=无穷大，梯度消失无法训练。Wasserstein距离即使不重叠也能给出有意义的梯度。

    9 核心总结¶

    三条主线¶

    1. 统一框架：所有损失函数都可从最大似然推导 → 选分布 → 预测参数 → 最小化NLL
    2. 最小二乘不是独立准则：它只是"正态假设 + NLL"的化简结果
    3. 交叉熵的理论支撑：最小化交叉熵 ⟺ 最小化NLL ⟺ 最大化似然 ⟺ 最小化KL散度

    损失函数速查——交叉熵统一视角¶

    核心洞察：所有基于最大似然的损失函数，本质上都是两个分布之间的交叉熵，只是分布假设不同。交叉熵不是某一个具体公式，而是一类损失的统一名字。

    任务 分布假设 激活函数 损失函数 交叉熵视角 常用名
    回归 正态分布 无（线性输出） \(\sum(y_i - f)^2\) 两个高斯分布的交叉熵 MSE
    二分类 Bernoulli Sigmoid \(-\sum[y_i\log\sigma + (1-y_i)\log(1-\sigma)]\) 两个伯努利分布的交叉熵 二分类交叉熵
    多分类 Categorical Softmax \(-\sum[f_{y_i} - \log\sum\exp(f_{k'})]\) 两个多项分布的交叉熵 交叉熵
    多输出 各分量独立 各分量各自选 各分量NLL之和 各分量交叉熵之和 混合损失

    交叉熵 vs KL散度 关系： $\(H(P, Q) = H(P) + KL(P\|Q)\)$ - 交叉熵 = 真实分布的熵 + KL散度 - 训练时 \(H(P)\) 是常数 → 最小化交叉熵 完全等价于 最小化KL散度
