## 练习 1｜$\|A\| < 1$ 时 $I \pm A$ 可逆

设矩阵 $A$ 对某个算子范数满足 $\|A\| < 1$，证明：

1. $I \pm A$ 可逆；
2. $\dfrac{1}{1 + \|A\|} \le \|(I \pm A)^{-1}\| \le \dfrac{1}{1 - \|A\|}$

> 提示（课堂口头）：$\|A\| < 1$ 意味着 $A$ 离零矩阵"不远"，从而 $I + A$ 离单位阵不远，可保证可逆，且 $\|(I+A)^{-1}\|$ 有界估计——这个性质后续**迭代法**中会用到。

**分步提示：**
1. 先想数的版本：$|a| < 1$ 时 $\dfrac{1}{1-a} = 1 + a + a^2 + \cdots$ 级数收敛。矩阵版就是把几何级数推广成 **Neumann 级数** $(I+A)^{-1} = \sum_{k=0}^{\infty}(-A)^k$。
2. 级数收敛靠范数保证：$\|(-A)^k\| \le \|A\|^k$，而 $\sum_{k=0}^{\infty}\|A\|^k = \dfrac{1}{1-\|A\|}$ 是收敛的等比级数——这同时说明 $(I+A)^{-1}$ 存在（级数和就是逆）。
3. **上界**：$\|(I+A)^{-1}\| = \left\|\sum_{k=0}^{\infty}(-A)^k\right\| \le \sum_{k=0}^{\infty}\|A\|^k = \dfrac{1}{1-\|A\|}$。
4. **下界**：从恒等式 $I = (I+A)^{-1}(I+A)$ 出发，两边取范数并连续用三角/乘性不等式：$1 = \|I\| \le \|(I+A)^{-1}\| \cdot \|I+A\| \le \|(I+A)^{-1}\| \cdot (1 + \|A\|)$，移项即得下界。
5. $I - A$ 完全同理：$(I-A)^{-1} = \sum_{k=0}^{\infty}A^k$，上/下界证明一字不差地照搬。

## 练习 2｜相容矩阵范数 ⇒ 存在相容向量范数

证明：对 $\mathbb{R}^{n \times n}$ 上任意一个相容的矩阵范数 $\|\cdot\|$，必存在 $\mathbb{R}^n$ 上与它相容的向量范数。

**分步提示：**
1. 思路：不能用现成的向量范数，而是用**已有的矩阵范数"造"一个向量范数**。工具是把向量拼成矩阵。
2. 固定一个非零向量 $e$（取最简单的 $e = (1,0,\dots,0)^T$ 即可），定义 $\|x\|_v := \|x e^T\|$（把 $n \times 1$ 向量 $x$ 与 $1 \times n$ 行向量 $e^T$ 相乘，得到秩 1 矩阵，用矩阵范数量它）。
3. 验证三条公理：非负、齐次、三角不等式直接继承矩阵范数的对应性质；正定性靠 $x \neq 0 \Rightarrow x e^T \neq 0 \Rightarrow \|x e^T\| > 0$。
4. 验证**相容性**（关键一步）：$\|Ax\|_v = \|A x e^T\| \le \|A\| \cdot \|x e^T\| = \|A\| \cdot \|x\|_v$——这里用的正是矩阵乘法相容性 $\|AB\| \le \|A\|\|B\|$（把 $A$ 和 $x e^T$ 相乘）。
5. 四步齐了，$\|\cdot\|_v$ 就是要求的向量范数。

## 练习 3｜F-范数的两个不等式

证明：

1. $\|A\vec{x}\|_2 \le \|A\|_F \|\vec{x}\|_2$
2. $\|AB\|_F \le \|A\|_F \|B\|_F$

**分步提示：**
1. ① 先平方再展开：$\|Ax\|_2^2 = \sum_{i=1}^{n}\left(\sum_{j=1}^{n}a_{ij}x_j\right)^2$。
2. 对每个 $i$ 用 **Cauchy–Schwarz** 不等式：$\left(\sum_j a_{ij}x_j\right)^2 \le \left(\sum_j a_{ij}^2\right)\left(\sum_j x_j^2\right)$。
3. 对 $i$ 求和，提取公因子 $\sum_j x_j^2 = \|x\|_2^2$，得 $\|Ax\|_2^2 \le \|A\|_F^2 \|x\|_2^2$，开方即得 ①。
4. ② 用**列向量视角**：设 $b_j$ 是 $B$ 的第 $j$ 列，则 $(AB)$ 的第 $j$ 列是 $A b_j$，于是 $\|AB\|_F^2 = \sum_j \|A b_j\|_2^2$。
5. 对每个 $j$ 套用 ① 的结论：$\|A b_j\|_2 \le \|A\|_F \|b_j\|_2$，平方后对 $j$ 求和，右边提出 $\|A\|_F^2$ 得 $\|A\|_F^2 \sum_j \|b_j\|_2^2 = \|A\|_F^2 \|B\|_F^2$，开方即得 ②。
