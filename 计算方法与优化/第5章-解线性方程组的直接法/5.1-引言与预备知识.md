## 1. 引言：为什么研究线性方程组

在自然科学和工程技术中，很多问题的解决最终都归结为**解线性代数方程组**，例如：电学中的网络问题、船体数学放样中建立三次样条函数问题、用最小二乘法求实验数据的曲线拟合问题、解非线性方程组问题、用差分法或有限元法解常微分/偏微分方程边值问题等。

线性方程组是"线性问题"的核心——后面的最小二乘、优化问题都会落到它身上，所以这一章是整门课的地基。

系数矩阵大致分两种：

| 类型     | 特征                                     | 适用方法  |
| ------ | -------------------------------------- | ----- |
| 低阶稠密矩阵 | 阶数不高（约 ≤150），零元素极少，无特殊结构               | 直接法   |
| 大型稀疏矩阵 | 阶数很高（几万、几十万甚至几百万），零元素占绝大多数，非零元集中于对角线附近 | 迭代法为主 |

更具体地说，低阶稠密方程组通常指阶数 <100、零元素很少的类型；大型稀疏方程组阶数可达几万至几百万，但非零元占比很低，且往往分布在对角线附近（带状结构）。

数值解法分两大类：

| 类别      | 思想                          | 特点                                                     |
| ------- | --------------------------- | ------------------------------------------------------ |
| **直接法** | 有限步算术运算求得精确解（若计算过程中没有舍入误差）  | 实际有舍入误差，只能得到近似解；是解低阶稠密方程组及部分大型带状方程组的有效方法               |
| **迭代法** | 从某个近似解出发，用极限过程构造向量序列逐步逼近精确解 | 存储少、程序简单、系数矩阵始终不变，但存在收敛性及收敛速度问题；是解大型稀疏方程组的重要方法（见第 6 章） |

注意直接法的"精确"是理论意义上的——不考虑舍入误差时有限步得到精确解，机器上跑出来一定是近似解。

## 2. Cramer 法则为什么不可行：$n!$ 量级运算量

线性代数中的经典方法：$x_i = \dfrac{\det(A_i)}{\det(A)}$，其中 $A_i$ 是把 $A$ 的第 $i$ 列换成 $b$。

按定义展开行列式：$n \times n$ 行列式是 $n!$ 项之和（每行取一个不同列的元素），每一项约 $n-1$ 次乘法，总运算量 $\approx n!$ 量级。

课件 P2 给出精确运算量公式：每个行列式由 $n!$ 项相加、每项含 $n$ 个因子相乘，乘法运算次数为 $(n-1)n!$。计算解向量需算 $n+1$ 个行列式和 $n$ 次除法，故乘（除）法总次数为

$$
N = (n+1)(n-1)n! + n
$$

代入具体数字：$n = 8 \Rightarrow N \approx 2 \times 10^6$；$n = 20 \Rightarrow N \approx 9.7 \times 10^{20}$——即使 $n$ 不大，$n!$ 的爆炸也完全不可行。

**教训**："理论上能解" ≠ "实际可解"。必须关心算法的运算量——这也是本课程每讲一个算法都要分析运算量的原因。

## 3. 向量和矩阵预备知识（课本 §5.1.2）

用 $\mathbb{R}^{m \times n}$ 表示全部 $m \times n$ 实矩阵的向量空间，$\mathbb{C}^{m \times n}$ 表示复矩阵空间。$n$ 维列向量 $x \in \mathbb{R}^n$；矩阵 $A = (a_{ij})$ 可按列 $A = (a_1, a_2, \dots, a_n)$ 或按行表示。

基本运算：

1. 矩阵加法：$C = A + B$，$c_{ij} = a_{ij} + b_{ij}$；
2. 矩阵与标量乘法：$C = \alpha A$，$c_{ij} = \alpha a_{ij}$；
3. 矩阵乘法：$C = AB$，$c_{ij} = \sum_k a_{ik} b_{kj}$（$A \in \mathbb{R}^{m \times p}$，$B \in \mathbb{R}^{p \times n}$，$C \in \mathbb{R}^{m \times n}$）；
4. 转置：$C = A^T$，$c_{ij} = a_{ji}$；
5. 单位矩阵：$I = (e_1, e_2, \dots, e_n)$，$e_i$ 为第 $i$ 个坐标向量；
6. 非奇异矩阵：若 $AB = BA = I$ 则 $B = A^{-1}$；$(A^{-1})^T = (A^T)^{-1}$；$(AB)^{-1} = B^{-1}A^{-1}$；
7. 行列式：按任一行（列）展开 $A_{ij} = (-1)^{i+j} M_{ij}$（代数余子式），性质：

$$
\det(AB) = \det A \cdot \det B, \qquad \det(A^T) = \det A, \qquad \det(cA) = c^n \det A
$$

$$
\det A \ne 0 \iff A \text{ 是非奇异矩阵}
$$

**概念**：非奇异就是可逆，$A^{-1}$ 存在。$\det A \ne 0$、$\operatorname{rank}(A) = n$、$A\vec x = \vec 0$ 只有零解、对任意 $\vec b$ 有唯一解、特征值全非零——这些说的都是同一件事，完整清单见 §4 定理 1。

本课程后面反复以它为前提：定理 8（列主元三角分解 $PA = LU$）要 $A$ 非奇异才保证这样的排列矩阵 $P$ 存在，第 6 章的迭代法也要它保证解唯一。但要分清它管到哪一步——**非奇异只保证解存在且唯一，不保证消元过程不用换行**（$A = \begin{pmatrix}0&1\\1&0\end{pmatrix}$ 非奇异，$a_{11}$ 却是零，见 5.2 §4），也**不保证算得准**。

$\det A$ 的大小因此不能拿来衡量"离奇异有多近"：它随阶数指数缩放，也随行向量的尺度变。$10$ 阶的 $0.1I$，$\det = 10^{-10}$，条件数却是 $1$；$\begin{pmatrix}1&1\\1&1+10^{-8}\end{pmatrix}$ 的 $\det = 10^{-8}$，条件数 $4\times10^{8}$，已几乎不可解；$5$ 阶 Hilbert 矩阵 $h_{ij} = 1/(i+j-1)$ 的 $\det \approx 3.7\times10^{-12}$，条件数 $4.8\times10^{5}$。三者的 $\det$ 同在 $10^{-8}\sim10^{-12}$ 这一带，条件数却从 $1$ 横跨到 $4\times10^{8}$——判"接近奇异"要看第 6 章的条件数，不看行列式。

## 4. 矩阵的特征值与谱半径（课本 §5.1.3）

**定义 1** 设 $A = (a_{ij}) \in \mathbb{R}^{n \times n}$，若存在数 $\lambda$（实数或复数）和非零向量 $x = (x_1, \dots, x_n)^T \in \mathbb{R}^n$，使

$$
Ax = \lambda x
$$

则称 $\lambda$ 为 $A$ 的特征值，$x$ 为 $A$ 对应 $\lambda$ 的特征向量。$A$ 的全体特征值称为 $A$ 的**谱**，记作 $\sigma(A) = \{\lambda_1, \lambda_2, \dots, \lambda_n\}$。

定义**谱半径**：

$$
\rho(A) = \max_{1 \le i \le n}|\lambda_i|
$$

由 $Ax = \lambda x$ 知 $\lambda$ 使齐次方程组 $(\lambda I - A)x = 0$ 有非零解，故 $\det(\lambda I - A) = 0$，即特征方程：

$$
p(\lambda) = \lambda^n + c_1 \lambda^{n-1} + \cdots + c_{n-1}\lambda + c_n = 0
$$

$p(\lambda)$ 称为特征多项式。由代数基本定理，$n$ 次代数方程在复数域有 $n$ 个根 $\lambda_1, \dots, \lambda_n$。展开行列式可得：

$$
\det A = \lambda_1 \lambda_2 \cdots \lambda_n
$$

$$
\text{tr}A = \lambda_1 + \lambda_2 + \cdots + \lambda_n \quad (\text{tr}A \text{ 为 } A \text{ 的迹})
$$

特征值、特征向量的基本性质：

1. $A^T$ 与 $A$ 有相同的特征值；
2. 若 $A$ 非奇异，则 $A^{-1}$ 的特征值为 $\lambda^{-1}$，特征向量仍为 $x$；
3. 相似矩阵 $B = S^{-1}AS$ 有相同的特征多项式。

**例 1**（课本例 1）求某 3 阶矩阵 $A$ 的特征值及谱半径，已知其特征方程为

$$
\det(\lambda I - A) = (\lambda - 2)^2(\lambda + 7) = 0
$$

解 故 $A$ 的特征值为 $\lambda_1 = \lambda_2 = 2$，$\lambda_3 = -7$，谱半径 $\rho(A) = \max\{|2|, |-7|\} = 7$。

谱半径 $\rho(A)$ 是第 5 章范数、迭代法收敛性分析的核心工具（见 5.4、第 6 章），这里先打好记号基础。

## 5. 特殊矩阵（课本 §5.1.4）

设 $A = (a_{ij}) \in \mathbb{R}^{n \times n}$：

| 类型             | 定义                                                  |
| -------------- | --------------------------------------------------- |
| 对角矩阵           | $i \ne j$ 时 $a_{ij} = 0$                            |
| 三对角矩阵          | $\lVert i - j \rVert > 1$ 时 $a_{ij} = 0$            |
| 上三角矩阵          | $i > j$ 时 $a_{ij} = 0$                              |
| 上 Hessenberg 阵 | $i > j + 1$ 时 $a_{ij} = 0$                          |
| 对称矩阵           | $A^T = A$                                           |
| Hermite 矩阵     | $A^H = \bar{A}^T = A$                               |
| 对称正定矩阵         | $A^T = A$ 且对任意非零 $x \in \mathbb{R}^n$，$x^T A x > 0$ |
| 正交矩阵           | $A^{-1} = A^T$                                      |
| 酉矩阵            | $A^{-1} = A^H$                                      |
| 初等置换阵          | 单位阵 $I$ 交换第 $i$ 行与第 $j$ 行（或列）得到的矩阵 $I_{ij}$         |
| 置换阵            | 初等置换阵的乘积                                            |

初等置换阵的作用：$I_{ij}A$ = 交换 $A$ 的第 $i$、$j$ 行；$AI_{ij}$ = 交换第 $i$、$j$ 列。

**定理 1** 设 $A \in \mathbb{R}^{n \times n}$，下述命题等价：

1. 对任何 $b \in \mathbb{R}^n$，方程组 $Ax = b$ 有唯一解；
2. 齐次方程组 $Ax = 0$ 只有零解 $x = 0$；
3. $\det A \ne 0$；
4. $A^{-1}$ 存在；
5. $\text{rank}(A) = n$。

**定理 2** 设 $A \in \mathbb{R}^{n \times n}$ 为对称正定矩阵，则

1. $A$ 非奇异，且 $A^{-1}$ 亦对称正定；
2. $A$ 的顺序主子阵 $A_k$（$k = 1, 2, \dots, n$）亦对称正定；
3. $A$ 的特征值 $\lambda_i > 0$（$i = 1, \dots, n$）；
4. $A$ 的顺序主子式 $\det(A_k) > 0$（$k = 1, 2, \dots, n$）。

**定理 2 第 1 条：$A^{-1}$ 为什么也对称正定。** 对称这一步与正定性无关，只用到「转置与求逆可交换」：

$$
\left(A^{-1}\right)^T = \left(A^T\right)^{-1} = A^{-1}.
$$

正定靠换元。取任意 $\vec x \ne \vec 0$，令 $\vec y = A^{-1}\vec x$——$A^{-1}$ 可逆，所以 $\vec y \ne \vec 0$——则 $\vec x = A\vec y$，

$$
\vec x^T A^{-1}\vec x = (A\vec y)^T A^{-1}(A\vec y) = \vec y^T A^T \vec y = \vec y^T A \vec y > 0 ,
$$

末一步同时用了 $A^T = A$ 与 $A$ 正定。右端对任意非零 $\vec y$ 为正，即 $A^{-1}$ 正定。

两条等价看法：**特征值**——$A$ 与 $A^{-1}$ 特征向量相同、特征值互为倒数，故 $\lambda_i > 0 \Rightarrow \lambda_i^{-1} > 0$，顺带 $\kappa_2(A^{-1}) = \kappa_2(A)$；**平方根法**——$A = LL^T$ 时 $A^{-1} = L^{-T}L^{-1} = (L^{-1})^T(L^{-1})$，仍是「下三角乘自己的转置」的形状。

注意：这里需要「正定」的只有第二条。**任何**非奇异对称矩阵的逆都对称，上式两等号只用了 $A^T = A$ 与可逆；正定只是保证逆的特征值仍为正。反过来，两个对称正定矩阵之积**一般不对称**——$AB$ 对称等价于 $AB = BA$，而 $AB = BA$ 并不自动成立。

**定理 3** 设 $A$ 为对称矩阵。若 $\det(A_k) > 0$（$k = 1, 2, \dots, n$），或 $A$ 的特征值 $\lambda_i > 0$（$i = 1, \dots, n$），则 $A$ 为对称正定矩阵。

定理 2 与定理 3 是 5.3.2 平方根法 / 改进平方根法的理论基础：**顺序主子式全正 ⇔ 对称正定**，而顺序主子式又决定了 LU 分解能否进行（见 5.2 定理 6）。

**怎么证明一个矩阵对称正定**：第一步先确认 $A^T = A$，这一步不过关，下面的判据一个也不能用——顺序主子式判据**只对对称矩阵成立**（反例见后）。之后按「手里有什么」挑路：

1. **定义**。证对任意 $\vec x \ne \vec 0$ 有 $\vec x^TA\vec x > 0$。最根本，适合结构已知的矩阵：$A = B^TB$ 且 $B$ 列满秩时，$\vec x^TA\vec x = \lVert B\vec x\rVert_2^2 > 0$——因为 $B\vec x = \vec 0$ 只有零解。差分阵、刚度阵这类离散算子多走这条。
2. **特征值**。算出全部 $\lambda_i$，全正即可（定理 3）。理论上最直白，实际最难算：手算只适合 $2 \times 2$、$3 \times 3$，或结构已知的三对角阵——$a$ 主对角、$b$ 次对角的 $n$ 阶矩阵，特征值是 $a + 2b\cos\dfrac{k\pi}{n+1}$。
3. **顺序主子式**。$D_1, \dots, D_n$ 全正（定理 3，Sylvester 判据）。中小矩阵手算最常用，逐步递推即可，不必碰特征值；也是 5.3 平方根法能做的充要条件。
4. **严格对角占优**。若每个 $i$ 都有 $a_{ii} > \sum_{j \ne i}|a_{ij}|$ 且 $a_{ii} > 0$，则 $A$ 对称正定。理由是圆盘定理：$A$ 的特征值全落在以 $a_{ii}$ 为心、以该行非对角元绝对值之和为半径的圆盘里（见 8.1），圆盘整体位于右半平面。**充分不必要**，但常常一眼可判。
5. **Cholesky / 合同于 $I$**。能写出 $A = LL^T$（$L$ 对角元为正的下三角）就是正定，反之亦然（5.3 定理 10 及其逆）。等价说法：存在可逆 $C$ 使 $C^TAC = I$。
6. **分块（Schur 补）**。把 $A$ 分成 $\begin{pmatrix}B&C\\C^T&D\end{pmatrix}$，$B$ 取前 $k$ 行 $k$ 列。$A$ 正定等价于 $B$ 与 $S = D - C^TB^{-1}C$ 都正定：$B$ 是顺序主子阵（定理 2 第 2 条，正定故可逆，$S$ 才有定义），$S$ 是块消元之后剩下的那块。适合「一小块已证正定、要往大矩阵拼」的场合，有限元拼装刚度阵即此；推导与对应的分块消元见 5.3 §2.5。

拿一道题把其中四条对照一遍。取

$$
A = \begin{pmatrix}4&1&0\\1&4&1\\0&1&4\end{pmatrix} :
$$

顺序主子式 $4,\,15,\,56$ 全正；特征值 $4 + 2\cos\dfrac{k\pi}{4} = 5.4142,\,4,\,2.5858$ 全正；对角元 $4$ 都大于该行非对角元绝对值之和（$1,\,2,\,1$），严格对角占优；Cholesky 因子

$$
L = \begin{pmatrix}2&0&0\\0.5&1.9365&0\\0&0.5164&1.9322\end{pmatrix},\qquad LL^T = A .
$$

四条全通。反过来，实战里挑一条最省事的就够，不必都走一遍。

**判据用错地方的两个反例。** 其一，**非对称时顺序主子式失效**。$M = \begin{pmatrix}1&3\\1&4\end{pmatrix}$ 的 $D_1 = 1$、$D_2 = 1$ 都为正，但它不正定：

$$
\vec x^TM\vec x = x_1^2 + 4x_1x_2 + 4x_2^2 = (x_1 + 2x_2)^2 ,
$$

取 $\vec x = (2,-1)^T$ 得 $0$——半正定而已（$\vec x^TM\vec x$ 只依赖对称部分 $(M + M^T)/2 = \begin{pmatrix}1&2\\2&4\end{pmatrix}$，它的行列式为零）。所以「先看对称」不是客套。

其二，**对角占优只是充分条件**。$C = \begin{pmatrix}1&2\\2&5\end{pmatrix}$ 的特征值是 $0.1716$ 与 $5.8284$，正定，可 $|c_{11}| = 1 < |c_{12}| = 2$。不满足对角占优**不能**用来断定不正定。

**选读**：一般 $n$ 阶矩阵在相似变换下可化为若尔当（Jordan）标准形（课本定理 4）；若所有若尔当块均为一阶，则化为对角矩阵。本章直接法不依赖该结论，可暂不深入。
