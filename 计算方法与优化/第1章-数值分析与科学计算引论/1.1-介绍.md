## 2. 算法：定义与两个效率例子

> 课件 P15：算法**不是单纯的数学公式**，而是"由基本运算和运算顺序的规定所组成的整个求解方案和步骤"；可以通过流程图直观描述；选择合适算法是数值计算中非常重要的环节，不同算法有不同的优势及劣势。

**例 A：多项式计算（秦九韶/Horner）**（课件 P16）

$$P_n(x) = a_nx^n + a_{n-1}x^{n-1} + \dots + a_2x^2 + a_1x + a_0$$

- 方法一（直接）：逐项计算 $a_i x^i$ 再相加 → 乘法 $1+2+\dots+n = \dfrac{n(n+1)}{2}$ 次，加法 $n$ 次
- 方法二（秦九韶 1247 / Horner 1819）：嵌套形式

$$P_n(x) = ((((a_nx + a_{n-1})x + a_{n-2})x + a_{n-3})x + \dots + a_1)x + a_0$$

递归：$b_n = a_n$，$b_i = b_{i+1}x + a_i\ (i=n-1,\dots,0)$，$P_n(x)=b_0$ → **乘法 $n$ 次、加法 $n$ 次**

同一个问题，算法不同计算量差一个数量级（$O(n^2) \to O(n)$）。

**例 B：Basel 问题**（课件 P17–18）

$$\sum_{k=1}^{\infty}\frac{1}{k^2} = \frac{\pi^2}{6}$$

用部分和 $P_n = \sum_{k=1}^n \frac{1}{k^2}$ 逼近，截断误差：

$$\frac{1}{n+1} = \sum_{k=n+1}^{\infty}\frac{1}{k(k+1)} < \sum_{k=n+1}^{\infty}\frac{1}{k^2} < \sum_{k=n+1}^{\infty}\frac{1}{k(k-1)} = \frac{1}{n}$$

更精巧的做法：利用 $\sum_{k=1}^{\infty}\frac{1}{k(k+1)} = 1$ 与 $\frac{1}{k^2} - \frac{1}{k(k+1)} = \frac{1}{k^2(k+1)}$，得

$$\sum_{k=1}^{\infty}\frac{1}{k^2} = 1 + \sum_{k=1}^{\infty}\frac{1}{k^2(k+1)} \approx 1 + \sum_{k=1}^{n}\frac{1}{k^2(k+1)}$$

余项 $\sum_{k=n+1}^{\infty}\frac{1}{k^2(k+1)} < \frac{1}{n}\sum_{k=n+1}^{\infty}\frac{1}{k(k+1)} < \frac{1}{n^2}$——**换一种展开方式，收敛快得多**（误差 $O(1/n) \to O(1/n^2)$）。

**算法重要性的两条理由**（课件 P19）：① 算法优劣直接影响计算速度和效率——小问题无所谓，复杂大型问题起决定性作用；② 不合适的算法会因计算近似性和误差的传播、积累影响结果精度，甚至决定计算成败。

## 5. 矩阵乘法与算法复杂度（课件 P29–31）

**问题**：给定 $A,B \in M_n$，计算 $AB$。常规做法 $c_{ij}=\sum_{k=1}^{n}a_{ik}b_{kj}$ 共需 **$n^3$ 次数字乘法**。

- 两个 $10^5$ 维矩阵相乘：$10^{15}$ 次乘法；按每秒 $10^9$ 次乘法算，需 $10^6$ 秒 ≈ **11.6 天**
- **Strassen 算法**（1969）：把矩阵分块，用 7 次块乘法代替 8 次（$M_1$–$M_7$ 组合），复杂度降到 $O(n^{\log_2 7}) \approx O(n^{2.807})$

**矩阵乘法指数** $\omega$：两个 $n\times n$ 矩阵相乘可在 $O(n^\omega)$ 次域运算内完成的最小指数。

主要历史进展：

| 年份 | 算法 | ω |
|------|------|-----|
| 1900 | 朴素算法（学校算法） | 3 |
| 1969 | Strassen | $\log_2 7 \approx 2.807$ |
| 1978 | Pan | ≈ 2.796 |
| 1986 | Coppersmith–Winograd（张量方法） | ≈ 2.376 |
| 2010 | Williams | ≈ 2.373 |
| 2014 | Le Gall | ≈ 2.3728639 |
| 2023 | Alman–Vassilevska Williams（当前最好） | ≈ 2.371866 |

**开放问题**：能否达到 $\omega = 2$？

> ω 每改进一点，大规模计算收益巨大：$n=10^5$ 时 $n^3 \approx 10^{15}$，而 $n^{2.372} \approx 10^{11.86}$，相差约 **3000 倍**。

## 6. 线性方程组求解：需要显式求 $A^{-1}$ 吗（课件 P32）

线性方程组求解：$Ax = b \Rightarrow x = A^{-1}b$，其中 $A \in \mathbb{R}^{n\times n}, b \in \mathbb{R}^n$。

1. **求逆与矩阵乘法复杂度相同**：都通常需要 $O(n^3)$ 次浮点运算；但求逆常数更大，且通常**没有必要**显式求出 $A^{-1}$。
2. **实际做法**：直接求解 $Ax=b$。常用方法：
   - 高斯消元（LU 分解）：$A=LU$
   - Cholesky 分解（$A$ 对称正定时）
   - QR 分解
   - 迭代法（Jacobi、Gauss–Seidel、共轭梯度等）
   
   直接求解更高效、稳定，且只需一个解而无需整个 $A^{-1}$。
3. **若 $A$ 或 $b$ 被噪声干扰，解还可靠吗？不一定**——取决于条件数 $\kappa(A) = \|A\|\|A^{-1}\|$：$\kappa(A)$ 大（病态）时微小扰动导致解的巨大误差；$\kappa(A)$ 小（良态）时解相对稳定。**不仅要关心"是否有解"，还要关心"解能否被可靠地计算出来"**（详见 [5.5-线性方程组的性态与误差分析](../第5章-解线性方程组的直接法/5.5-线性方程组的性态与误差分析.md)）。

## 7. 最小二乘：求解—逼近—学习

线性方程组求解：$Ax = b \Rightarrow x = A^{-1}b$

**问题引入**：如果方程的未知量个数远小于方程的个数，怎么找到最"合适"的解？（对应监督学习：给定带标签数据集，找到分类器并预测新数据标签）

五个递进模块：

1. **线性方程组：精确求解**
   给定 $Ax = b$，如 $\begin{pmatrix}2&1\\1&3\end{pmatrix}\begin{pmatrix}x_1\\x_2\end{pmatrix}=\begin{pmatrix}5\\7\end{pmatrix}$，解 $x = A^{-1}b$ 或用更高效的数值方法（LU 分解、迭代法等）。
   *问题*：如何高效、稳定地求解大规模线性方程组？

2. **超定方程组：通常无解**
   更多方程、少量未知数：$Ax = b,\quad m > n$，无法精确满足所有方程。
   *问题*：如何找到"最好的近似解"？

3. **最小二乘：最佳逼近**
   寻找使残差最小的解：$\min\limits_{x}\|Ax - b\|_2^2$
   一阶最优性条件（法方程）：$A^TAx = A^Tb$
   *问题*：如何高效、稳定地求解最小二乘问题？（如 QR 分解、SVD）

4. **线性回归：监督学习的起点**
   用线性模型拟合数据：$f(x) = w^Tx + b$
   训练数据：$(x_i, y_i)_{i=1}^m$；训练目标：$\min\limits_{w,b}\sum\limits_{i=1}^m (y_i - w^Tx_i - b)^2$
   这就是最简单的监督学习问题：从带标签的数据中学习一个函数去预测新样本。

5. **更一般的模型：从线性到非线性**
   将线性模型推广为更复杂的函数族（多项式、神经网络等）：$f_\theta(x)$
   训练目标（经验风险最小化）：$\min\limits_{\theta}\frac{1}{m}\sum\limits_{i=1}^m \ell(f_\theta(x_i), y_i)$
   - 回归任务：$\ell(\hat{y}, y) = (\hat{y} - y)^2$
   - 分类任务：$\ell(\hat{y}, y) = -y\log\hat{y} + \dots$

> **核心思想**：用数学模型描述问题，用高效、稳定的算法求解，用数据驱动的方法改进模型。线性方程组、最小二乘、监督学习，都是在寻找一个能够解释数据的解。（求解 → 逼近 → 学习）

## 8. 神经网络：从输入到预测（课件 P34）

> 动机：真实的规律很复杂，线性模型太简单 → 引入神经网络。

五个环节：**输入数据 → 神经网络模型 → 损失函数 → 优化求解 → 输出预测**

- **输入数据**：$x \in \mathbb{R}^d$（特征向量：图像、文本、表格数据等）
- **神经网络模型**（多层感知机）：

$$h^{(l)} = \sigma(W^{(l)}h^{(l-1)} + b^{(l)}),\quad l = 1,\dots,L$$

$$f_\theta(x) = W^{(L)}h^{(L-1)} + b^{(L)},\quad \hat{y} = f_\theta(x)$$

- **损失函数**：$L(\theta) = \dfrac{1}{m}\sum_{i=1}^{m}\ell(f_\theta(x_i), y_i)$；回归用平方损失 $\ell(\hat y, y)=(\hat y-y)^2$，分类用交叉熵 $\ell(\hat y, y) = -y\log\hat y$
- **优化求解**：梯度下降 $\theta_{k+1} = \theta_k - \eta\nabla L(\theta_k)$；常用 SGD / Mini-batch SGD、Momentum、Adam
- **输出预测**：$\hat{y} = f_{\theta^*}(x)$，用于回归（连续值）或分类（类别）
