## 1. 核心概念

### 1.1 经典（频率学派）统计框架
经典统计把未知参数 $\theta$ 当作**固定常数**，而不是随机变量——这是它与贝叶斯框架的根本区别。观测 $X_1,\dots,X_n$ i.i.d. 来自分布族 $f_\theta$，目标是设计一个估计量 $\hat\Theta = g(X_1,\dots,X_n)$，即数据的函数。

**估计器 vs 估计值**：估计器 $\hat\Theta_n$ 是数据的函数——数据随机，估计器本身也是随机变量（用大写）；拿到具体数据 $x$ 后算出的数字 $\hat\theta_n$ 叫估计值（用小写）。

**分号记号**：经典统计里写作 $f_X(x;\theta)$，用分号不用竖线——因为 $\theta$ 不是随机变量，这不是条件分布，而是"一族分布"，每个 $\theta$ 对应一个候选模型。

**经典统计没有唯一最优解**：贝叶斯框架下贝叶斯法则是唯一推理方式，但经典统计没有唯一答案。不同人可以对同一问题提出不同估计器，"什么叫好"本身就有多种定义，这是一门艺术。

### 1.2 三种常用估计
- **样本均值** $\hat\mu = \bar X = \frac{1}{n}\sum_{i=1}^n X_i$；
- **样本方差** $S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar X)^2$（$n-1$ 修正为无偏估计）；
- **极大似然估计（MLE）** $\hat\theta_{MLE} = \arg\max_\theta L(\theta)$，其中似然 $L(\theta) = \prod_{i=1}^n f_\theta(x_i)$。

### 1.3 置信区间
点估计只给一个数，置信区间用数据给出"大概率包含 $\theta$"的区间：

$$P\big(\theta \in [\hat\theta - \delta,\ \hat\theta + \delta]\big) \approx 1 - \alpha$$

区间半宽 $\delta$ 由数据和置信水平 $1-\alpha$ 决定，随样本量 $n$ 增大而变窄。

## 2. 公式与定义

### 2.1 估计量的评价：MSE 分解
均方误差定义为

$$\text{MSE}(\hat\theta) = E\big[(\hat\theta - \theta)^2\big]$$

其中 bias $= E[\hat\theta] - \theta$。

**推导：MSE = 方差 + bias²。** 把偏差拆成"波动部分"和"固定偏移"两部分：

$$\hat\theta - \theta = \big(\hat\theta - E[\hat\theta]\big) + \big(E[\hat\theta] - \theta\big)$$

记 $\tilde\theta = \hat\theta - E[\hat\theta]$，则 $E[\tilde\theta]=0$。平方展开：

$$(\hat\theta - \theta)^2 = \tilde\theta^2 + 2\tilde\theta\,(E[\hat\theta] - \theta) + (E[\hat\theta] - \theta)^2$$

两边取期望。交叉项为 $2(E[\hat\theta]-\theta)\,E[\tilde\theta] = 0$，因为 $E[\tilde\theta]=0$。剩下：

$$E[(\hat\theta - \theta)^2] = E[\tilde\theta^2] + (E[\hat\theta] - \theta)^2 = \text{var}(\hat\theta) + \text{bias}^2$$

- 无偏：bias $= 0$；有效：方差小；
- 有时有偏但方差更小（如收缩估计），整体 MSE 反而更优——MSE 同时惩罚偏差和波动。

### 2.2 样本均值的无偏性与方差
**推导。** 设 $X_1,\dots,X_n$ i.i.d.，$E[X_i]=\mu$，$\text{var}(X_i)=\sigma^2$。

无偏性：

$$E[\bar X] = E\!\left[\frac{1}{n}\sum_{i=1}^n X_i\right] = \frac{1}{n}\sum_{i=1}^n E[X_i] = \frac{1}{n}\cdot n\mu = \mu$$

方差（独立性使协方差为零）：

$$\text{var}(\bar X) = \text{var}\!\left(\frac{1}{n}\sum_{i=1}^n X_i\right) = \frac{1}{n^2}\sum_{i=1}^n \text{var}(X_i) = \frac{n\sigma^2}{n^2} = \frac{\sigma^2}{n}$$

所以样本均值是 $\mu$ 的无偏估计，标准误为 $\sigma/\sqrt n$。

### 2.3 样本方差的 $n-1$ 修正
为什么样本方差分母是 $n-1$ 而不是 $n$？因为样本均值 $\bar X$ 已经从数据里估出来了，离均差 $\sum(X_i-\bar X)$ 自动加和为零，损失了一个自由度。

**推导：$S^2 = \frac{1}{n-1}\sum(X_i-\bar X)^2$ 是 $\sigma^2$ 的无偏估计。** 展开平方和：

$$\sum_{i=1}^n (X_i - \bar X)^2 = \sum_{i=1}^n \big[(X_i - \mu) - (\bar X - \mu)\big]^2$$

$$= \sum_{i=1}^n (X_i - \mu)^2 - 2(\bar X - \mu)\sum_{i=1}^n (X_i - \mu) + n(\bar X - \mu)^2$$

注意 $\sum_{i=1}^n (X_i - \mu) = n(\bar X - \mu)$，代入交叉项：

$$\sum_{i=1}^n (X_i - \bar X)^2 = \sum_{i=1}^n (X_i - \mu)^2 - n(\bar X - \mu)^2$$

两边取期望：

$$E\!\left[\sum_{i=1}^n (X_i - \mu)^2\right] = n\sigma^2$$

$$E\!\left[n(\bar X - \mu)^2\right] = n\cdot \text{var}(\bar X) = n\cdot \frac{\sigma^2}{n} = \sigma^2$$

所以

$$E\!\left[\sum_{i=1}^n (X_i - \bar X)^2\right] = n\sigma^2 - \sigma^2 = (n-1)\sigma^2$$

即

$$E\!\left[\frac{1}{n-1}\sum_{i=1}^n (X_i - \bar X)^2\right] = \sigma^2$$

分母用 $n$ 的估计 $\frac{1}{n}\sum(X_i-\bar X)^2$ 期望为 $\frac{n-1}{n}\sigma^2$，系统性偏小，正是 MLE 的那个有偏版本。

### 2.4 均值的置信区间（方差已知）
由中心极限定理，$\bar X \approx N(\mu, \sigma^2/n)$。构造枢轴量（pivot）：

$$Z = \frac{\bar X - \mu}{\sigma/\sqrt n} \sim N(0,1)$$

它是数据和 $\mu$ 的函数，但分布不依赖 $\mu$——这是反解置信区间的关键。

**推导置信区间。** 对标准正态取双侧 $\alpha/2$ 分位点 $z_{\alpha/2}$，即 $P(|Z|\le z_{\alpha/2})=1-\alpha$，则

$$P\!\left(-z_{\alpha/2} \le \frac{\bar X - \mu}{\sigma/\sqrt n} \le z_{\alpha/2}\right) = 1-\alpha$$

把不等式中间的 $\mu$ 解出来：

$$\bar X - z_{\alpha/2}\frac{\sigma}{\sqrt n} \le \mu \le \bar X + z_{\alpha/2}\frac{\sigma}{\sqrt n}$$

得到 $\mu$ 的 $(1-\alpha)$ 置信区间

$$\left[\bar X - z_{\alpha/2}\frac{\sigma}{\sqrt n},\ \bar X + z_{\alpha/2}\frac{\sigma}{\sqrt n}\right]$$

$z_{\alpha/2}$ 的来源：标准正态上 $\alpha/2$ 上分位点，95% 置信时 $\alpha=0.05$、$\alpha/2=0.025$，$z_{0.025}\approx 1.96$。

### 2.5 方差未知时的置信区间与 $t$ 分布
实际中 $\sigma$ 常未知，用样本标准差 $s$ 替代。若直接把 pivot 里的 $\sigma$ 换成 $s$，得到

$$\frac{\bar X - \mu}{S/\sqrt n}$$

这个量不再服从标准正态——因为 $S$ 本身也是随机的，它带来额外波动，分布尾部比正态更厚。

**$t$ 分布引入动机**：当数据本身正态时，可证

$$\frac{\bar X - \mu}{S/\sqrt n} \sim t_{n-1}$$

自由度为 $n-1$ 的 $t$ 分布。小样本时 $t_{n-1}$ 比 $N(0,1)$ 尾部更宽，对应更宽的置信区间：

$$\left[\bar X - t_{n-1,\alpha/2}\frac{s}{\sqrt n},\ \bar X + t_{n-1,\alpha/2}\frac{s}{\sqrt n}\right]$$

大 $n$ 时 $S$ 趋于稳定，$t_{n-1}\approx N(0,1)$，两式重合。

**三种近似方法**（讲义）：方差未知时有三条路——① 用 $\sigma$ 的上界，如伯努利 $\sigma\le 1/2$；② 用 $\hat\sigma=\sqrt{\hat p(1-\hat p)}$（伯努利专用）；③ 用样本标准差 $s$ 并配 $t$ 分布修正。这里叠了两层近似：CLT（正态近似）+ 用 $s$ 代替 $\sigma$，$t$ 表就是对第二层近似的小样本修正。

### 2.6 极大似然估计
似然函数

$$L(\theta) = \prod_{i=1}^n f_\theta(x_i)$$

连续为 PDF、离散为 PMF。乘积求导麻烦，改用对数似然

$$\ell(\theta) = \sum_{i=1}^n \ln f_\theta(x_i)$$

**为什么取对数不改变最优解？** 因为 $\ln(\cdot)$ 是严格单调递增函数：若 $\theta_1<\theta_2$ 则 $\ln L(\theta_1)<\ln L(\theta_2)$，所以 $\arg\max L = \arg\max \ln L$。对数把乘积变求和，求导方便，且不影响最大值位置。

MLE 就是 $\hat\theta = \arg\max \ell(\theta)$（求导置零 + 验证最大值）。

MLE 的直观理解：找"让我观测到的数据**最有可能发生**的那个 $\theta$"。两个候选 $\theta_1,\theta_2$ 二选一，若在 $\theta_1$ 下数据几乎不可能出现、在 $\theta_2$ 下数据出现概率可观，就选后者。

**与贝叶斯的对照**：贝叶斯最大化后验 $f_{\Theta|X}(\theta\mid x)$（$\Theta$ 是随机变量、有先验）；经典 MLE 最大化 $f_X(x;\theta)$（$\theta$ 是常数）。形式上取平坦先验（常数）时后验最大 = 似然最大，两者长得一样，但哲学不同：一个说"$\theta$ 最可能取哪个值"，另一个说"哪个 $\theta$ 让数据最可能发生"。

## 3. 关键性质

### 3.1 常用 MLE 推导

**伯努利试验。** $X_i\sim\text{Bernoulli}(p)$，PMF $p(x_i)=p^{x_i}(1-p)^{1-x_i}$，$x_i\in\{0,1\}$。对数似然：

$$\ell(p) = \sum_{i=1}^n \big[x_i\ln p + (1-x_i)\ln(1-p)\big] = n\bar x\ln p + n(1-\bar x)\ln(1-p)$$

求导置零：

$$\frac{d\ell}{dp} = \frac{n\bar x}{p} - \frac{n(1-\bar x)}{1-p} = 0$$

$$\frac{\bar x}{p} = \frac{1-\bar x}{1-p} \;\Rightarrow\; \hat p = \bar x$$

即成功频率。

**正态分布。** $X_i\sim N(\mu,\sigma^2)$，PDF

$$f(x_i;\mu,\sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}}\exp\!\left(-\frac{(x_i-\mu)^2}{2\sigma^2}\right)$$

对数似然：

$$\ell(\mu,\sigma^2) = -\frac{n}{2}\ln(2\pi) - \frac{n}{2}\ln\sigma^2 - \frac{1}{2\sigma^2}\sum_{i=1}^n (x_i-\mu)^2$$

对 $\mu$ 求偏导置零：

$$\frac{\partial \ell}{\partial \mu} = \frac{1}{\sigma^2}\sum_{i=1}^n (x_i-\mu) = 0 \;\Rightarrow\; \sum_{i=1}^n (x_i-\mu)=0 \;\Rightarrow\; \hat\mu = \bar x$$

把 $\hat\mu=\bar x$ 代入，对 $\sigma^2$ 求偏导置零：

$$\frac{\partial \ell}{\partial \sigma^2} = -\frac{n}{2\sigma^2} + \frac{1}{2\sigma^4}\sum_{i=1}^n (x_i-\bar x)^2 = 0$$

解得

$$\hat\sigma^2 = \frac{1}{n}\sum_{i=1}^n (x_i-\bar x)^2$$

注意分母是 $n$ 不是 $n-1$——MLE 版本有偏，无偏样本方差在它基础上乘 $n/(n-1)$。

**均匀分布 $U[0,\theta]$。** PDF 为 $f(x;\theta)=1/\theta$ 当 $0\le x\le\theta$，否则为 0。似然函数的"支撑集"依赖 $\theta$：必须 $\theta\ge \max_i x_i$，否则似然为 0。在支撑集内

$$L(\theta) = \prod_{i=1}^n \frac{1}{\theta} = \frac{1}{\theta^n}$$

它关于 $\theta$ 单调递减，所以最大化要求 $\theta$ 取支撑集下界：

$$\hat\theta = \max_i x_i$$

这里不能求导——似然在 $\theta=\max x_i$ 处有个跳变，导数方法失效，必须盯住支撑集。

### 3.2 MLE 的渐近性质
- **相合性**：$n\to\infty$ 时 $\hat\theta_{MLE}\xrightarrow{P}\theta$；
- **渐近正态**：$\hat\theta_{MLE}\approx N(\theta,\ \text{CRLB}/n)$，渐近达到 Cramér–Rao 下界，效率最优；
- **不变性**：$\widehat{g(\theta)}_{MLE} = g(\hat\theta_{MLE})$，参数的函数直接代入估计值即可。

### 3.3 频率学派置信区间的解读
反复抽样中，约 $1-\alpha$ 比例的区间会包含真实 $\theta$——这叫"覆盖概率"。它**不是**"$\theta$ 落在这个区间的概率是 95%"——那是贝叶斯可信区间的语言。

严格地说：区间上下界是随机量（大写字母），随机性在于区间本身；$\theta$ 是常数，区间生成后"要么在里面要么在外面"，没有概率可言。

## 4. 例题

### 例 1：正态均值的置信区间（方差已知）
$n=25$，$\bar x=10$，$\sigma=2$。95% 置信区间：

$$10 \pm 1.96\cdot\frac{2}{\sqrt{25}} = 10 \pm 0.784 = [9.216,\ 10.784]$$

### 例 2：方差未知
同例但 $s=2.2$，$n=25$，查 $t_{24,0.025}\approx 2.064$：

$$10 \pm 2.064\cdot\frac{2.2}{5} = 10 \pm 0.908 = [9.092,\ 10.908]$$

略宽于方差已知的区间——因为 $s$ 本身不确定。

### 例 3：伯努利 MLE
观测 7 次成功、3 次失败：$\ell(p)=7\ln p+3\ln(1-p)$，求导

$$\frac{d\ell}{dp} = \frac{7}{p} - \frac{3}{1-p} = 0 \;\Rightarrow\; 7(1-p)=3p \;\Rightarrow\; \hat p=0.7$$

### 例 4：均匀 MLE
$U[0,\theta]$，观测 0.3、0.8、0.5。支撑集要求 $\theta\ge 0.8$，在此范围内 $L(\theta)=1/\theta^3$ 随 $\theta$ 递减，故 $\hat\theta=0.8=\max x_i$。

## 5. 本节重点

- **经典估计三件套**：样本均值 $\bar X$（无偏，方差 $\sigma^2/n$）、样本方差 $S^2$（$n-1$ 分母，无偏）、MLE（渐近有效）。
- **MSE 分解**：$\text{MSE}=\text{var}+\text{bias}^2$，无偏不等于 MSE 最小。
- **置信区间**：方差已知用 $z_{\alpha/2}\sigma/\sqrt n$，方差未知用 $t_{n-1,\alpha/2}s/\sqrt n$；宽度 $\propto 1/\sqrt n$。
- **MLE 三大算例**：伯努利 $\hat p=\bar x$、正态 $\hat\mu=\bar x$ 且 $\hat\sigma^2=\frac1n\sum(x_i-\bar x)^2$、均匀 $\hat\theta=\max x_i$（盯住支撑集）。
- **频率学派解读**：置信区间是随机区间，覆盖概率 $1-\alpha$；不是"$\theta$ 落在区间里的概率"。

**常见坑**：
1. 样本方差分母 $n$ vs $n-1$ 搞混——无偏估计用 $n-1$，MLE 用 $n$；
2. 方差未知时仍查 $z$ 表——小样本应查 $t$ 表；
3. 把置信区间当贝叶斯可信区间解读（"$\theta$ 有 95% 概率在区间里"是错的）；
4. 均匀 MLE 求导——必须看支撑集，$\hat\theta=\max x_i$ 不可求导得到。
