## 1. 核心概念

### 1.1 场景与模型
用变量 $X$（如 SAT 分数）预测 $Y$（如大学绩点）。收集 $n$ 对数据 $(x_i,y_i)$ 画散点图，假设存在线性关系：

$$Y = \theta_0 + \theta_1 X + W$$

其中 $W$ 是噪声，代表除 $X$ 外其他因素造成的波动。

### 1.2 最小二乘准则
选 $\theta_0,\theta_1$ 使预测误差平方和最小：

$$\min_{\theta_0,\theta_1}\ \sum_{i=1}^n \big(y_i - (\theta_0 + \theta_1 x_i)\big)^2$$

直观上，对每个样本，模型预测值是直线上的点，真实值偏离多少算一个误差；把误差平方加起来，找让总和最小的那条直线。

## 2. 公式与定义

### 2.1 最小二乘 = 正态噪声下的 MLE
给拟合一个概率模型：对固定 $X=x_i$，假设

$$Y_i = \theta_0 + \theta_1 x_i + W_i, \qquad W_i \overset{iid}{\sim} N(0,\sigma^2)$$

则 $Y_i\mid X_i=x_i\sim N(\theta_0+\theta_1 x_i,\ \sigma^2)$，单个密度为

$$f(y_i;x_i,\theta_0,\theta_1,\sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}}\exp\!\left(-\frac{(y_i-\theta_0-\theta_1 x_i)^2}{2\sigma^2}\right)$$

独立观测似然相乘，取对数：

$$\ell = -\frac{n}{2}\ln(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^n (y_i-\theta_0-\theta_1 x_i)^2$$

第一项不含 $\theta_0,\theta_1$，第二项前面有负号——最大化 $\ell$ 等价于最小化

$$\sum_{i=1}^n (y_i-\theta_0-\theta_1 x_i)^2$$

即最小二乘。结论：最小二乘不是拍脑袋，它正是"噪声 i.i.d. 正态、同方差"这一概率模型下的 MLE。

### 2.2 闭式解推导
**推导。** 记残差平方和

$$Q(\theta_0,\theta_1) = \sum_{i=1}^n (y_i-\theta_0-\theta_1 x_i)^2$$

对 $\theta_0,\theta_1$ 分别求偏导置零。

对 $\theta_0$：

$$\frac{\partial Q}{\partial \theta_0} = -2\sum_{i=1}^n (y_i-\theta_0-\theta_1 x_i) = 0$$

$$\sum_{i=1}^n (y_i-\theta_0-\theta_1 x_i) = 0 \;\Rightarrow\; \bar y - \theta_0 - \theta_1\bar x = 0$$

即

$$\hat\theta_0 = \bar y - \hat\theta_1\bar x$$

回归线必过样本重心 $(\bar x,\bar y)$。

对 $\theta_1$：

$$\frac{\partial Q}{\partial \theta_1} = -2\sum_{i=1}^n (y_i-\theta_0-\theta_1 x_i)x_i = 0$$

把 $\theta_0=\bar y-\theta_1\bar x$ 代入，中心化 $x_i-\bar x$、$y_i-\bar y$：

$$\sum_{i=1}^n \big[(y_i-\bar y) - \theta_1(x_i-\bar x)\big](x_i-\bar x) = 0$$

$$\sum_{i=1}^n (y_i-\bar y)(x_i-\bar x) = \theta_1\sum_{i=1}^n (x_i-\bar x)^2$$

解得

$$\hat\theta_1 = \frac{\sum_{i=1}^n (x_i-\bar x)(y_i-\bar y)}{\sum_{i=1}^n (x_i-\bar x)^2} = \frac{\widehat{\text{cov}}(X,Y)}{\widehat{\text{var}}(X)}$$

$$\hat\theta_0 = \bar y - \hat\theta_1\bar x$$

### 2.3 概率直觉
从 $E[Y]=\theta_0+\theta_1 E[X]$（$W$ 零均值）出发，用样本平均估计期望。若 $W$ 与 $X$ 独立且零均值，把 $Y=\theta_0+\theta_1 X+W$ 两边乘 $X$ 再取期望：

$$E[XY] = \theta_1 E[X^2] + E[XW] = \theta_1 E[X^2]$$

故零均值时 $\theta_1=E[XY]/E[X^2]$，一般情形就是协方差除以方差——与上面闭式解一致。

## 3. 关键性质

### 3.1 多元回归、多项式回归与过拟合
- **多元回归**：$Y=\theta_0+\theta_1 X_1+\theta_2 X_2+\dots$（如 GPA ~ SAT + 家庭收入 + …），求偏导置零得到线性方程组，交给计算机解即可；
- **多项式回归**：把 $h(X)=X^2$（或其他函数）当新的解释变量，仍是"关于 $\theta$ 线性"的模型；数据弯了就试二次项；
- **过拟合警告**：10 个数据点配 10 个参数（10 次多项式）能完美穿过所有点，但预测毫无意义——"参数太多、数据太少"是首要避免的错误。

### 3.2 标准误差与 $R^2$
- **标准误差**：估计噪声方差 $\sigma^2$，即 $Y$ 里除线性关系外剩下的随机性。它限制预测精度上限——即使 $\theta_0,\theta_1$ 全对，噪声大预测误差也大；
- **$R^2$（解释方差比例）**：比较"知道 $X$ 后 $Y$ 还剩多少方差"与"完全不知道 $X$ 时 $Y$ 的总方差"。形式上

$$R^2 = 1 - \frac{\sum_{i=1}^n (y_i-\hat y_i)^2}{\sum_{i=1}^n (y_i-\bar y)^2}$$

如"60% 的绩点差异可由家庭收入解释" = 建模后剩余方差占总方差 40%。$R^2$ 越接近 1，线性关系越强。

### 3.3 线性回归的三大陷阱
1. **异方差（heteroskedasticity）**：噪声方差随 $X$ 变化（$X$ 小时数据整齐、$X$ 大时很散）。最小二乘会"迁就"误差最大的区域，把模型拉向最噪的数据点，系数虽仍无偏但标准误估计失真；
2. **多重共线性**：两个解释变量高度相关（如 SAT 第一次和第二次成绩）时，设计矩阵接近奇异，估计出的系数对数据微小变动极其敏感，标准误巨大，不可靠；
3. **相关 ≠ 因果**：回归只发现"关联"（知道 $X$ 能更好预测 $Y$），完全不能说明是 $Y$ 引起 $X$、$X$ 引起 $Y$，还是第三个变量同时导致两者。回归本身不告诉你任何底层机制。

## 4. 例题

### 例：由样本矩估斜率
设 $\bar x=600$，$\bar y=3.5$，$\sum(x_i-\bar x)(y_i-\bar y)=1200$，$\sum(x_i-\bar x)^2=10000$。则

$$\hat\theta_1 = \frac{1200}{10000} = 0.12$$

$$\hat\theta_0 = 3.5 - 0.12\times 600 = 3.5 - 72 = -68.5$$

截距外推到 $x=0$ 区，物理意义需谨慎解释——样本只覆盖 $x$ 在 600 附近的范围。

## 5. 本节重点

- **模型**：$Y=\theta_0+\theta_1 X+W$，$W\sim N(0,\sigma^2)$ i.i.d.；
- **最小二乘 = 正态噪声 MLE**：负对数似然 = 残差平方和 + 常数；
- **闭式解**：$\hat\theta_1=\widehat{\text{cov}}/\widehat{\text{var}}$，$\hat\theta_0=\bar y-\hat\theta_1\bar x$，回归线过 $(\bar x,\bar y)$；
- **诊断量**：标准误 $\hat\sigma$ 限制预测精度，$R^2$ 度量被解释的方差比例；
- **三大陷阱**：异方差、多重共线性、相关 ≠ 因果。

**常见坑**：把回归系数解释成因果效应；用高次多项式硬凑样本内拟合；忽略异方差导致标准误失真。
