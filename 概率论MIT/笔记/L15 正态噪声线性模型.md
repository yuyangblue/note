## 1. 核心概念

### 1.1 模型
观测 = 未知量 + 噪声：
$$X = \Theta + W, \qquad W \sim N(0, \sigma_W^2), \quad \Theta \text{ 与 } W \text{ 独立}$$
- 连续参数 $\Theta$ 先验取正态：$\Theta \sim N(\mu_0, \sigma_0^2)$；
- 目标是给定观测 $X = x$ 推断 $\Theta$。

### 1.2 为什么正态-正态可闭合
正态先验 × 正态似然 = 正态后验（共轭），后验可以闭式写出，这是本讲所有计算的根基。

---

## 2. 公式与定义

### 2.1 单个观测的后验（关键公式）
$$f_{\Theta \mid X}(\theta \mid x) = N(\hat\theta, \sigma^2)$$

$$\hat\theta = \frac{\frac{\mu_0}{\sigma_0^2} + \frac{x}{\sigma_W^2}}{\frac{1}{\sigma_0^2} + \frac{1}{\sigma_W^2}}$$

$$\frac{1}{\sigma^2} = \frac{1}{\sigma_0^2} + \frac{1}{\sigma_W^2}$$
- 后验均值 = **先验均值与观测的精度加权平均**（权重 = 精度 $1/\sigma^2$）；
- 后验方差 = 先验方差与噪声方差的"并联"（精度相加）。

### 2.2 多个观测
$X_i = \Theta + W_i$，$W_i$ i.i.d. $N(0,\sigma_W^2)$：
$$\hat\theta = \frac{\frac{\mu_0}{\sigma_0^2} + \frac{n\bar x}{\sigma_W^2}}{\frac{1}{\sigma_0^2} + \frac{n}{\sigma_W^2}}$$

$$\frac{1}{\sigma^2} = \frac{1}{\sigma_0^2} + \frac{n}{\sigma_W^2}$$
- $n$ 个观测等价于把样本均值 $\bar x$ 以 $n/\sigma_W^2$ 的精度并入；
- $n \to \infty$：$\hat\theta \to \bar x$（数据主导，先验被淹没）。

### 2.3 线性正态模型（轨迹估计）
观测多个时刻：$X_j = \Theta_0 + \Theta_1 t_j + W_j$（$W_j$ i.i.d. 正态）：
- 未知向量 $(\Theta_0, \Theta_1)$ 的联合后验是二维正态；
- 条件于观测，后验均值是数据的线性函数（最小二乘/贝叶斯线性回归的雏形）。

---

## 3. 关键性质

### 3.1 均方误差（MSE）视角
- 估计 $\hat\Theta$ 的 MSE：$E[(\hat\Theta - \Theta)^2]$；
- 给定观测时，使 MSE 最小的估计是后验均值 $E[\Theta \mid X=x]$（见 L16 的 LMS）；
- 本节后验均值 $\hat\theta$ 就是 LMS 估计；后验方差即条件 MSE。

### 3.2 精度（precision）语言
- 精度 = $1/\sigma^2$，越小方差越准；
- 后验精度 = 先验精度 + 观测精度（可加性非常优雅）；
- 每个观测贡献精度 $1/\sigma_W^2$；$n$ 个观测贡献 $n/\sigma_W^2$。

### 3.3 先验 vs 数据的权衡
- 数据充足（$n$ 大）或噪声小（$\sigma_W^2$ 小）⇒ 数据主导；
- 先验信息强（$\sigma_0^2$ 小）⇒ 先验主导；
- 两者以**精度**为权重线性折中，形式简单、直觉清晰。

## 4. 例题

### 例 1：单次观测
- $\Theta \sim N(0,1)$（$\mu_0=0,\sigma_0^2=1$），$W \sim N(0,4)$（$\sigma_W^2=4$），观测 $X = 3$：
- 精度：$1/\sigma^2 = 1 + 1/4 = 5/4$ ⇒ $\sigma^2 = 0.8$；
- $\hat\theta = \frac{0/1 + 3/4}{5/4} = 0.6$；
- 后验 $\Theta \mid X \sim N(0.6, 0.8)$。

### 例 2：多个观测（均值合并）
- $\Theta \sim N(1, 9)$，4 个观测样本均值 $\bar x = 2.5$，$\sigma_W^2 = 4$：
- 先验精度 $1/9$，观测精度 $4/4 = 1$；
- $\hat\theta = \frac{1/9\cdot1 + 1\cdot2.5}{1/9 + 1} = \frac{1/9 + 2.5}{10/9} = \frac{2.611}{1.111} \approx 2.35$；
- 后验精度 $= 10/9$ ⇒ 方差 $0.9$——比单个观测（$\sigma^2=4\cdot\frac{9}{13}\approx2.77$）更尖。

### 例 3：轨迹估计
- 观测位置 $X_j$ 随时间 $t_j$ 变化，模型 $X_j = \Theta_0 + \Theta_1 t_j + W_j$；
- 贝叶斯更新后：后验中心在最小二乘拟合直线上，后验椭圆反映参数不确定性；
- 数据点越多、噪声越小，后验椭圆越扁（参数更确定）。

---

## 5. 本节重点

> **本节重点**：
> - 正态先验 + 正态噪声 ⇒ 正态后验；后验均值 = 先验均值与观测的**精度加权平均**，后验精度 = 两者之和。
> - 多观测：用样本均值 $\bar x$ 与精度 $n/\sigma_W^2$ 一键合并；$n\to\infty$ 后验 → 数据。
> - 后验均值即 LMS/MSE 最优估计（预告 L16）；后验方差 = 条件 MSE。
> - **常见坑**：① 权重用方差而不是精度（权重比反了）；② 忘记噪声与 $\Theta$ 独立的前提；③ 多观测时把每个 $x_i$ 当独立精度相加而忘了用 $\bar x$ 简化。
