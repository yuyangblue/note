## 1. 核心概念

### 1.1 为什么需要 LLMS
LMS（条件期望）在一般情况下可能很复杂（需要算整个条件分布）。**LLMS 限制估计器为观测的线性函数**：
$$\hat\Theta = aX + b$$
只求最优的斜率 $a$ 与截距 $b$——永远有闭式解，只需要均值、方差、协方差，**不需要联合分布**。

> 老师的动机（p172）："LMS 的最优估计器可能是非线性的分段曲线（如 L16 那个 U[4,10]+均匀噪声例）。非线性虽然最优但麻烦。如果退一步，只允许画一条直线，最优直线是什么？"——这就是 LLMS。

### 1.2 LLMS 是最佳"线性"猜测
在所有形如 $aX+b$ 的估计器中，LLMS 使 MSE 最小；若 $\Theta$ 与 $X$ 联合正态，LLMS 恰好等于 LMS（条件期望）。

> 老师强调（p172）："如果条件期望本身已经是 $X$ 的线性函数，那它在线性类里也是最优的——这时候 LLMS = LMS。硬币偏置例就是这种巧合。"

## 2. 公式与定义

### 2.1 最优解
$$\hat\Theta = E[\Theta] + \frac{\text{cov}(\Theta, X)}{\text{var}(X)} \big(X - E[X]\big)$$
即
$$a = \frac{\text{cov}(\Theta, X)}{\text{var}(X)} = \rho \frac{\sigma_\Theta}{\sigma_X}, \qquad b = E[\Theta] - a E[X]$$

> **两阶段推导**（p173）：① 固定 $a$，最优 $b = E[\Theta - aX] = E[\Theta] - aE[X]$（无观测常数估计的结论）；② 代入后 MSE 变为 $\text{var}(\Theta - aX)$，对 $a$ 求导令零：$2a\,\text{var}(X) - 2\,\text{cov}(\Theta,X) = 0$，得 $a = \text{cov}(\Theta,X)/\text{var}(X)$。

### 2.2 误差方差（性能）
$$\text{LLMS 的 MSE} = \text{var}(\Theta) - \frac{\text{cov}(\Theta,X)^2}{\text{var}(X)} = \text{var}(\Theta)\,(1 - \rho^2)$$
- $\rho = \pm1$：完美线性关系，MSE = 0；
- $\rho = 0$：观测无线性信息，估计回到 $E[\Theta]$，MSE = var$(\Theta)$。

> 老师的解释（p174）："$\rho^2$ 是观测 $X$ 能解释的 $\Theta$ 方差比例。$\rho=0$ 时观测什么用都没有；$\rho=\pm1$ 时完全确定。中间的 $\rho$ 决定了能削掉多少不确定性。"

### 2.3 多个观测（线性组合）
$$\hat\Theta = E[\Theta] + \sum_i a_i (X_i - E[X_i])$$
系数 $a_i$ 由**正规方程**决定（求梯度为零），可用矩阵表示：
$$\mathbf a = \Sigma_{XX}^{-1} \Sigma_{X\Theta}$$

> **只需一阶二阶矩**（p177）：老师反复强调——"LLMS 只需要均值、方差、协方差，不需要知道完整分布。"这意味着只要矩相同，不管分布是正态还是非正态，LLMS 解都一样（p178）。

## 3. 关键性质

### 3.1 LLMS vs LMS
- LMS：$E[\Theta \mid X]$，MSE 最小（所有函数中）；
- LLMS：限制线性函数，MSE ≥ LMS；联合正态时两者相等；
- LLMS 是"投影"：把条件期望投影到由 $1, X$ 张成的线性空间。

### 3.2 数据的表示影响 LLMS（重要警示）
- LLMS 对 $X$ 做线性变换后仍是 LLMS（形式不变）；
- 但对 $X$ 做**非线性**变换（如 $\ln X$、$X^2$）再线性估计，结果可能**不同**且可能更好；
- 例：$\Theta = X^2$ 时，直接用 $X$ 的 LLMS 无法捕捉二次关系，改用 $X^2$ 作输入则完全捕捉；
- 直觉：LLMS 的"线性"取决于你喂给它的特征；选择好特征（表示）可以显著改善估计。

> 老师的深入讨论（p179）："LMS 里用 $X$ 还是 $X^3$ 无所谓——知道 $X$ 就知道 $X^3$，条件期望一样。但 LLMS 里就不一样了：$aX+b$ 和 $aX^3+b$ 是两个不同的函数类，最优解也不同。你还可以用 $a_1 X + a_2 X^2 + a_3 X^3 + b$——这在系数上是线性的，只是在 $X$ 上是非线性的。这已经从数学变成了艺术：选什么特征看你的领域知识。"

### 3.3 相关系数的角色
斜率 $a = \rho \frac{\sigma_\Theta}{\sigma_X}$：相关性越强，观测每变化一单位时估计移动越多；MSE 缩减比例恰为 $1-\rho^2$。

> **直觉解释**（p174）："从先验均值 $E[\Theta]$ 出发，如果观测 $X$ 比预期大，且 $\Theta$ 和 $X$ 正相关，就把估计往上调；调多少由协方差/方差决定。$\rho<0$ 时方向反过来。$\rho=0$ 时无信息可利用，估计停在先验均值。"

## 4. 例题

### 例 1：U[4,10] + 均匀噪声的 LLMS（p175）
- $\Theta \sim U[4,10]$，$X = \Theta + U$，$U \sim U[-1,1]$，独立；
- $E[\Theta] = 7$，$\text{var}(\Theta) = 36/12 = 3$；
- $E[U] = 0$，$\text{var}(U) = 4/12 = 1/3$；
- $E[X] = 7$，$\text{var}(X) = 3 + 1/3 = 10/3$；
- $\text{cov}(\Theta,X) = \text{cov}(\Theta, \Theta+U) = \text{var}(\Theta) = 3$；
- $a = 3/(10/3) = 9/10$，$b = 7 - (9/10)\cdot 7 = 0.7$；
- **LLMS**: $\hat\Theta = 7 + \frac{9}{10}(X - 7) = 0.9X + 0.7$。

> 老师对比（p175）："这条红色直线是 LMS（蓝色分段曲线）的线性近似。斜率 0.9 而不是 1——因为有噪声，观测打了折。"

### 例 2：正态-正态（LLMS = LMS）
- $\Theta \sim N(1,4)$、$W \sim N(0,9)$、$X = \Theta + W$：
- $\text{cov}(\Theta,X) = \text{var}(\Theta) = 4$，$\text{var}(X) = 4+9 = 13$；
- $\hat\Theta = 1 + \frac{4}{13}(X - 1) = \frac{4}{13}X + \frac{9}{13}$；
- MSE $= 4(1 - 16/52) = 4 \cdot \frac{36}{52} \approx 2.77$（与 L16 条件 MSE 一致，因正态 LLMS=LMS）。

### 例 3：硬币偏置的 LLMS（p176-p178，讲义 p6-8）
- $\Theta \sim U[0,1]$，$X \mid \Theta \sim \text{Binomial}(n,\Theta)$：
- $E[\Theta] = 1/2$，$\text{var}(\Theta) = 1/12$，$E[\Theta^2] = 1/3$；
- $E[X] = n/2$；
- $\text{cov}(\Theta,X) = n/12$；
- $\text{var}(X) = n(n+2)/12$；
- 斜率 $a = \dfrac{n/12}{n(n+2)/12} = \dfrac{1}{n+2}$，故
$$\hat\Theta_{LLMS} = \frac12 + \frac{1}{n+2}\Big(X-\frac n2\Big) = \frac{X+1}{n+2}$$
- 本例中后验均值 $E[\Theta\mid X] = (X+1)/(n+2)$ 恰好是 $X$ 的线性函数，所以 **LLMS = LMS**（讲义第 6 页明确标注二者相等）。

> **多观测加权平均**（p178）：$\Theta \sim N(\mu, \sigma_0^2)$，$X_i = \Theta + W_i$，$W_i \sim N(0, \sigma_i^2)$ 独立。LLMS 解 = 先验均值与各观测的精度加权平均：
$$\hat\Theta = \frac{\frac{\mu}{\sigma_0^2} + \sum_i \frac{X_i}{\sigma_i^2}}{\frac{1}{\sigma_0^2} + \sum_i \frac{1}{\sigma_i^2}}$$
老师强调："即使把正态假设去掉，只要均值方差相同，LLMS 解完全一样——因为 LLMS 只看二阶矩。"

### 例 4：表示的重要性
- 数据 $X$ 与 $\Theta = X^2$ 的关系：
- 用 $X$ 做 LLMS：$a = \text{cov}(X, X^2)/\text{var}(X)$，若 $X$ 对称（$E[X^3]=E[X]=0$），$a=0$，估计退化为常数，MSE 很大；
- 改用 $X^2$：$\hat\Theta = E[X^2] + a'(X^2 - E[X^2])$，$a'=1$，MSE = 0——特征选择改变一切。

## 5. 本节重点

> **本节重点**：
> - LLMS：$\hat\Theta = E[\Theta] + \frac{\text{cov}(\Theta,X)}{\text{var}(X)}(X - E[X])$；只要一阶二阶矩，永远闭式。
> - 误差方差 = $\text{var}(\Theta)(1-\rho^2)$；相关性越强估计越好。
> - LLMS 是线性限制下的最优；联合正态时 = LMS。
> - **数据表示决定 LLMS 质量**：非线性变换（特征工程）能显著提升线性估计。
> - **常见坑**：① 用 $\rho\frac{\sigma_\Theta}{\sigma_X}$ 时把 $\sigma_X$ 与 $\sigma_\Theta$ 放反；② 多观测时忘了正规方程；③ 以为 LLMS 对所有 $X$ 的表示都等价（错，非线性特征会改变结果）；④ 以为 LLMS 需要知道完整分布（错，只需一阶二阶矩）。
