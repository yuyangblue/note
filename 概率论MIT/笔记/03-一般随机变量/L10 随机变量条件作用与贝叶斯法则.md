## 1. 核心概念

### 1.1 条件 PDF（连续对连续）
$$f_{X \mid Y}(x \mid y) = \frac{f_{X,Y}(x,y)}{f_Y(y)}, \qquad f_Y(y) > 0$$
- **切片图像（p102 / lec09 尾）**：把 $y$ 钉死，$f_{X,Y}(\cdot,y)$ 就是联合密度在 $y$ 处的一个纵切片，形状不变；但切片下的面积是 $f_Y(y)$ 而非 1，所以要除以 $f_Y(y)$ 重新归一化，使每条切片下面积 = 1。
- **微妙之处**：连续型里 $P(Y=y)=0$，严格说不能对 $Y=y$ 取条件。形式上应理解为"$Y$ 无限接近 $y$"，再取极限；用的时候直接当 $Y=y$ 即可。
- 乘法法则：$f_{X,Y}(x,y) = f_Y(y)f_{X \mid Y}(x \mid y) = f_X(x)f_{Y \mid X}(y \mid x)$。

#### 推导："切片归一化"论证
严格定义不能直接用零概率事件 $\{Y=y\}$，改用小区间 $\{y\le Y\le y+\delta\}$ 取极限。固定 $x$，考虑事件 $\{x\le X\le x+\delta'\}$ 在 $\{y\le Y\le y+\delta\}$ 下的条件概率：

$$P(x\le X\le x+\delta'\mid y\le Y\le y+\delta)=\frac{P(x\le X\le x+\delta',\ y\le Y\le y+\delta)}{P(y\le Y\le y+\delta)}.$$

分子用联合密度在小矩形上积分：$\approx f_{X,Y}(x,y)\,\delta'\delta$；分母用边缘密度：$\approx f_Y(y)\,\delta$。代入约去 $\delta$：

$$P(x\le X\le x+\delta'\mid y\le Y\le y+\delta)\approx\frac{f_{X,Y}(x,y)\,\delta'\delta}{f_Y(y)\,\delta}=\frac{f_{X,Y}(x,y)}{f_Y(y)}\,\delta'.$$

令 $\delta,\delta'\to 0$，左边正是条件密度乘小区间长 $\delta'$，于是

$$f_{X\mid Y}(x\mid y)=\frac{f_{X,Y}(x,y)}{f_Y(y)}.$$

**归一化验证**：$\int f_{X\mid Y}(x\mid y)\,dx=\frac{1}{f_Y(y)}\int f_{X,Y}(x,y)\,dx=\frac{f_Y(y)}{f_Y(y)}=1$。这就是"切片先除以 $f_Y(y)$ 再用"的原因——$f_{X,Y}(\cdot,y)$ 本身只是未归一的高度曲线。

### 1.2 连续版全概率 / 全期望
$$f_X(x) = \int f_Y(y) f_{X \mid Y}(x \mid y)\, dy, \qquad E[X] = \int f_Y(y) E[X \mid Y=y]\, dy$$

#### 推导：连续全概率与全期望
把乘法法则 $f_{X,Y}(x,y)=f_Y(y)f_{X\mid Y}(x\mid y)$ 代入边缘公式 $f_X(x)=\int f_{X,Y}(x,y)\,dy$，直接得

$$f_X(x)=\int f_{X,Y}(x,y)\,dy=\int f_Y(y)f_{X\mid Y}(x\mid y)\,dy.$$

这是离散全概率 $p_X(x)=\sum_y p_Y(y)p_{X\mid Y}(x\mid y)$ 的积分版（和→积分）。直觉：$X$ 的密度由无数条"在 $Y=y$ 切片上的条件密度"按切片权重 $f_Y(y)dy$ 叠加而成。

**全期望推导**：用期望定义与乘法法则，

$$E[X]=\int x f_X(x)\,dx=\int x\left[\int f_Y(y)f_{X\mid Y}(x\mid y)\,dy\right]dx=\int f_Y(y)\left[\int x f_{X\mid Y}(x\mid y)\,dx\right]dy.$$

内层括号就是条件期望 $E[X\mid Y=y]$，故

$$E[X]=\int f_Y(y)E[X\mid Y=y]\,dy.$$

### 1.3 连续随机变量的独立
$$f_{X,Y}(x,y) = f_X(x)f_Y(y), \quad \forall x,y$$
等价于 $f_{X \mid Y}(x \mid y) = f_X(x)$（对所有 $f_Y(y)>0$ 的 $y$）——报出 $Y$ 不改变对 $X$ 的信念。
独立时：$E[XY]=E[X]E[Y]$、$\text{var}(X+Y)=\text{var}(X)+\text{var}(Y)$、$g(X)$ 与 $h(Y)$ 独立。

### 1.4 推断的"黑箱"框架（p107）
- 未知量 $X$（先验分布 $p_X$ 或 $f_X$）→ 测量装置/噪声（模型 $p_{Y\mid X}$ 或 $f_{Y\mid X}$）→ 观测 $Y=y$；
- 推断问题的输出 = **给定观测后未知量的分布** $p_{X\mid Y}(\cdot\mid y)$（即后验）；
- 一切都来自乘法法则：$p_X(x)p_{Y\mid X}(y\mid x) = p_Y(y)p_{X\mid Y}(x\mid y)$，把 $p_Y(y)$ 挪到分母。
- **口诀**：后验 $\propto$ 先验 $\times$ 似然；分母只是归一化常数。当先验均匀时，后验形状直接由似然决定，两个候选的后验之比 = 似然之比（odds）。

## 2. 公式与定义

### 2.1 贝叶斯法则的四种变体

| 情形 | 公式 |
|---|---|
| 离散-离散 | $p_{X \mid Y}(x \mid y) = \dfrac{p_X(x) p_{Y \mid X}(y \mid x)}{p_Y(y)}$，$p_Y(y) = \sum_{x'} p_X(x')p_{Y\mid X}(y \mid x')$ |
| 连续-连续 | $f_{X \mid Y}(x \mid y) = \dfrac{f_X(x) f_{Y \mid X}(y \mid x)}{f_Y(y)}$，$f_Y(y) = \int f_X(x')f_{Y\mid X}(y\mid x')dx'$ |
| 离散-连续 | $p_{K \mid Y}(k \mid y) = \dfrac{p_K(k) f_{Y \mid K}(y \mid k)}{f_Y(y)}$，$f_Y(y) = \sum_{k'} p_K(k') f_{Y \mid K}(y \mid k')$ |
| 连续-离散 | $f_{Y \mid K}(y \mid k) = \dfrac{f_Y(y) p_{K \mid Y}(k \mid y)}{p_K(k)}$，$p_K(k) = \int f_Y(y') p_{K \mid Y}(k \mid y') dy'$ |

#### 推导：混合情形用 $P(K=k,\ y\le Y\le y+\delta)$ 双展开
教材（3.6 节）处理"未知量 $K$ 离散、观测 $Y$ 连续"时，不能直接写 $P(K=k\mid Y=y)$（因 $P(Y=y)=0$），改用小条 $\{y\le Y\le y+\delta\}$：

$$P(K=k,\ y\le Y\le y+\delta).$$

**第一种展开（先验 × 似然）**：先以概率 $p_K(k)$ 选 $K=k$，再在 $K=k$ 条件下 $Y$ 落入小区间——连续密度近似 $f_{Y\mid K}(y\mid k)\delta$：

$$P(K=k,\ y\le Y\le y+\delta)=p_K(k)\cdot f_{Y\mid K}(y\mid k)\,\delta.$$

**第二种展开（边缘 × 后验）**：先看 $Y$ 落入小区间（边缘概率 $f_Y(y)\delta$），再在该条件下取 $K=k$（条件概率 $p_{K\mid Y}(k\mid y)$）：

$$P(K=k,\ y\le Y\le y+\delta)=f_Y(y)\,\delta\cdot p_{K\mid Y}(k\mid y).$$

两式相等：$p_K(k)f_{Y\mid K}(y\mid k)\delta=f_Y(y)\delta\,p_{K\mid Y}(k\mid y)$。约去小量 $\delta$（$\delta>0$ 可约），令 $\delta\to0$ 得

$$p_{K\mid Y}(k\mid y)=\frac{p_K(k)f_{Y\mid K}(y\mid k)}{f_Y(y)}.$$

分母 $f_Y(y)$ 再用全概率（对 $K$ 的所有取值求和）：

$$f_Y(y)=\sum_{k'}p_K(k')f_{Y\mid K}(y\mid k').$$

这就是离散-连续变体。连续-离散变体（未知量连续 $X$、观测 $K$ 离散）完全对称：把上面的 $p_K$ 与 $f_Y$ 角色互换，用 $P(x\le X\le x+\delta,\ K=k)$ 双展开即得。

- **混合情形怎么来的（lec10）**：写 $P(K=k,\ y\le Y\le y+\delta)$，按乘法法则拆两种方式：$p_K(k)\cdot f_{Y\mid K}(y\mid k)\delta$ 和 $f_Y(y)\delta\cdot p_{K\mid Y}(k\mid y)$；约去小量 $\delta$ 即得 PMF 与 PDF 的桥梁公式。
- 口诀：分子 = 先验 × 似然；分母 = 归一化（对可能的原因求和/积分）。

### 2.2 独立正态的联合密度
$X \sim N(0,1)$、$Y \sim N(0,1)$ 独立：
$$f_{X,Y}(x,y) = \frac{1}{2\pi} e^{-(x^2+y^2)/2}$$
一般独立正态：$f_{X,Y} = \frac{1}{2\pi\sigma_x\sigma_y}\exp\left\{-\frac{(x-\mu_x)^2}{2\sigma_x^2}-\frac{(y-\mu_y)^2}{2\sigma_y^2}\right\}$（等高线为椭圆；$\sigma_x=\sigma_y$ 时为圆，旋转对称）。

#### 推导：独立 ⇒ 边缘乘积
由独立性定义，联合事件可拆成边缘事件之积：$P(X\in A,\ Y\in B)=P(X\in A)P(Y\in B)$。写成积分：

$$\int_{A}\int_B f_{X,Y}(x,y)\,dy\,dx=\left(\int_A f_X(x)\,dx\right)\left(\int_B f_Y(y)\,dy\right)=\int_A\int_B f_X(x)f_Y(y)\,dy\,dx.$$

等式对一切矩形 $A\times B$ 成立，比较被积函数即得

$$f_{X,Y}(x,y)=f_X(x)f_Y(y).$$

代入 $X\sim N(\mu_x,\sigma_x^2)$、$Y\sim N(\mu_y,\sigma_y^2)$ 的边缘 PDF：

$$f_{X,Y}(x,y)=\frac{1}{\sqrt{2\pi}\sigma_x}e^{-\frac{(x-\mu_x)^2}{2\sigma_x^2}}\cdot\frac{1}{\sqrt{2\pi}\sigma_y}e^{-\frac{(y-\mu_y)^2}{2\sigma_y^2}}=\frac{1}{2\pi\sigma_x\sigma_y}e^{-\frac{(x-\mu_x)^2}{2\sigma_x^2}-\frac{(y-\mu_y)^2}{2\sigma_y^2}}.$$

对零均值标准正态 $(\mu_x=\mu_y=0,\sigma_x=\sigma_y=1)$ 化简为 $\frac{1}{2\pi}e^{-(x^2+y^2)/2}$。指数里是两个独立二次型相加，故等高线（令指数 = 常数）在 $\sigma_x=\sigma_y$ 时是圆 $x^2+y^2=C$（旋转对称），一般情形是椭圆。

## 3. 关键性质

### 3.1 断棒问题（条件作用链，p105）
- 木棒长 $\ell$，先在 $X \sim U[0,\ell]$ 处折，再在 $Y \sim U[0,X]$ 处折：
- $f_{X,Y}(x,y) = f_X(x)f_{Y \mid X}(y \mid x) = \frac{1}{\ell}\cdot\frac{1}{x}$，定义域 $0 \le y \le x \le \ell$（其余为 0）；
- 联合密度形状像一张靠近 $x=0$ 处高高吹起的帆（$1/x$ 发散，但积分仍有限）；
- 条件期望：$E[Y\mid X=x] = \int_0^x y\cdot\frac{1}{x}\,dy = x/2$（条件宇宙内 $Y$ 均匀，均值即中点）；
- 边缘 $f_Y(y)$：对 $x$ 从 $y$ 到 $\ell$ 积分（注意只在联合非零区域积）：$f_Y(y) = \int_y^\ell \frac{1}{\ell x}dx = \frac{1}{\ell}\ln\frac{\ell}{y}$；
- 由全期望：$E[Y] = \int f_X(x)E[Y \mid X=x]dx = \int_0^\ell \frac1\ell \cdot \frac{x}{2} dx = \frac{\ell}{4}$。
- **老师的提醒（lec10）**：答案 $\ell/4$ 简单得像"每折一次剩一半，折两次剩 1/4"。这种"按平均推理"在此恰好对，但**不要滥用**——平均的函数不等于函数的平均。

#### 推导：断棒问题的完整计算链
**第一步：联合密度**。$X\sim U[0,\ell]$，$f_X(x)=1/\ell$（$0\le x\le\ell$）。给定 $X=x$，$Y\sim U[0,x]$，$f_{Y\mid X}(y\mid x)=1/x$（$0\le y\le x$）。由乘法法则：

$$f_{X,Y}(x,y)=\frac{1}{\ell}\cdot\frac{1}{x},\quad 0\le y\le x\le\ell.$$

归一化验证：$\int_0^\ell\!\!\int_0^x\frac{1}{\ell x}\,dy\,dx=\int_0^\ell\frac{1}{\ell x}\cdot x\,dx=\int_0^\ell\frac{1}{\ell}\,dx=1$。

**第二步：条件期望**。在固定 $X=x$ 的条件宇宙内，$Y$ 在 $[0,x]$ 均匀，故

$$E[Y\mid X=x]=\frac{0+x}{2}=\frac{x}{2}.$$

**第三步：边缘 $f_Y(y)$**。注意联合非零区域是三角形 $0\le y\le x\le\ell$，对 $x$ 积分时下限必须是 $y$（不是 0）：

$$f_Y(y)=\int_y^\ell\frac{1}{\ell x}\,dx=\frac{1}{\ell}\big[\ln x\big]_y^\ell=\frac{1}{\ell}\ln\frac{\ell}{y},\quad 0<y\le\ell.$$

**第四步：全期望**。用 $E[Y]=\int f_X(x)E[Y\mid X=x]\,dx$ 比直接积分 $f_Y$ 简单：

$$E[Y]=\int_0^\ell\frac{1}{\ell}\cdot\frac{x}{2}\,dx=\frac{1}{2\ell}\cdot\frac{\ell^2}{2}=\frac{\ell}{4}.$$

### 3.2 贝叶斯推断：二元信号检测（p109）
- 未知量 $K$ 等可能为 $-1$ 或 $+1$；测量 $Y = K + W$，$W \sim N(0,1)$；
- $p_K(\pm1) = 1/2$；$f_{Y \mid K}(y \mid k) = \frac{1}{\sqrt{2\pi}}e^{-(y-k)^2/2}$；
- $f_Y(y) = \frac12 \frac{1}{\sqrt{2\pi}}[e^{-(y-1)^2/2} + e^{-(y+1)^2/2}]$；
- $p_{K \mid Y}(1 \mid y) = \dfrac{e^{-(y-1)^2/2}}{e^{-(y-1)^2/2} + e^{-(y+1)^2/2}}$；
- 直觉：$y > 0$ 时更可能是 $K=+1$；$y$ 离 0 越远，后验越有把握。当先验等权时，后验 odds 就是两个似然高度之比。

#### 推导：后验逐步推导
这是离散-连续变体：未知量 $K\in\{-1,+1\}$（离散），观测 $Y$（连续）。

**先验**：$p_K(1)=p_K(-1)=1/2$。

**似然**：给定 $K=k$，$Y=k+W$，$W\sim N(0,1)$，故 $Y\mid K=k\sim N(k,1)$：

$$f_{Y\mid K}(y\mid k)=\frac{1}{\sqrt{2\pi}}e^{-(y-k)^2/2}.$$

**边缘（分母）**：用连续全概率对 $K$ 求和，

$$f_Y(y)=\sum_{k=\pm1}p_K(k)f_{Y\mid K}(y\mid k)=\frac{1}{2\sqrt{2\pi}}\big[e^{-(y-1)^2/2}+e^{-(y+1)^2/2}\big].$$

**后验**：

$$p_{K\mid Y}(1\mid y)=\frac{p_K(1)f_{Y\mid K}(y\mid 1)}{f_Y(y)}=\frac{\frac{1}{2\sqrt{2\pi}}e^{-(y-1)^2/2}}{\frac{1}{2\sqrt{2\pi}}[e^{-(y-1)^2/2}+e^{-(y+1)^2/2}]}=\frac{e^{-(y-1)^2/2}}{e^{-(y-1)^2/2}+e^{-(y+1)^2/2}}.$$

公共因子 $1/(2\sqrt{2\pi})$ 全部约掉——这正是"分母只是归一化常数"的体现。

**化简（教材 Example 3.20）**：分子分母同乘 $e^{(y^2+1)/2}$，指数差

$$-(y-1)^2/2+(y^2+1)/2=y,\qquad -(y+1)^2/2+(y^2+1)/2=-y,$$

故 $p_{K\mid Y}(1\mid y)=\frac{e^{y}}{e^{y}+e^{-y}}$。$y\to+\infty$ 时趋于 1（确信发了 $+1$），$y\to-\infty$ 时趋于 0，$y=0$ 时恰为 $1/2$——与直觉一致。

## 4. 例题

### 例 1：连续未知量 + 离散观测（p110）
- $Y \sim U[0,1]$（未知偏置），$K \sim \text{Bernoulli}(Y)$（观测）；
- $f_Y(y) = 1$；$p_{K \mid Y}(1 \mid y) = y$；
- $p_K(1) = \int_0^1 1\cdot y\, dy = 1/2$；
- $f_{Y \mid K}(y \mid 1) = \dfrac{1\cdot y}{1/2} = 2y$——观测到成功会"抬高"对 $y$ 的信念（贝塔分布雏形，见 L14）。

### 例 2：离散未知量 + 连续测量（见 3.2 计算）
- 观测 $Y = 0.5$：$p_{K \mid Y}(1 \mid 0.5) = \frac{e^{-0.125}}{e^{-0.125}+e^{-1.125}} \approx 0.73$——$K=+1$ 更可能。

### 例 3：独立正态联合密度形状
- 独立标准正态联合密度是旋转对称的钟形；等高线是圆；
- 若 $\sigma_x \ne \sigma_y$，等高线为椭圆（$\sigma$ 大的方向更扁长）。

### 例 4：连续未知 + 离散测量的现实原型（lec10）
- 发光器件由连续电流 $X$ 驱动（未知），观测是 1 秒内数到的光子数 $K$（离散）；
- 用"连续-离散"变体：$f_{X\mid K}(x\mid k) = \frac{f_X(x)p_{K\mid X}(k\mid x)}{p_K(k)}$，$p_K(k) = \int f_X(x')p_{K\mid X}(k\mid x')dx'$。

## 5. 本节重点

> **本节重点**：
> - 条件 PDF = 联合密度切片再归一化（$\delta$ 矩形论证）；严格含义是"$Y$ 无限接近 $y$"。
> - 连续全概率 $f_X=\int f_Y f_{X\mid Y}$ 与全期望 $E[X]=\int f_Y E[X\mid Y]$；独立 ⇔ 联合处处可拆 ⇔ 条件 = 边缘。
> - 推断黑箱：后验 $\propto$ 先验 × 似然；贝叶斯四种变体按"未知量/观测各是离散还是连续"对号入座；混合情形靠 $P(K=k,\ y\le Y\le y+\delta)$ 双展开、约去 $\delta$ 搭桥。
> - 断棒问题：链式条件 $f=f_X\cdot f_{Y\mid X}$，边缘 $f_Y(y)=\frac1\ell\ln(\ell/y)$，全期望求 $E[Y]=\ell/4$；注意积分区域只在联合非零处。
> - 二元信号检测：后验 $\propto$ 两个高斯似然高度之比，化简为 $\frac{e^y}{e^y+e^{-y}}$。
> - 独立正态联合密度 = 两个边缘正态相乘，等高线为圆/椭圆。
> - **常见坑**：① 分母 $f_Y(y)$ 忘记对可能原因求和/积分（没归一化）；② 离散-连续混合情形用错公式变体；③ 把条件密度切片当成已归一化的 $f_{X\mid Y}$（其实还要除以 $f_Y(y)$）；④ 断棒问题求边缘时积分上下限写成 $0$ 到 $\ell$（应为 $y$ 到 $\ell$）；⑤ 写联合 PDF 漏了定义域限制（如断棒要求 $y\le x$）。
