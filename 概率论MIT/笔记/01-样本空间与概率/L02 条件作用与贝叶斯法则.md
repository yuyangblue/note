## 1. 核心概念

### 1.1 条件作用的思想
拿到新信息后要**修正模型**：不是重新构造概率空间，而是在"已知 $B$ 发生"的新世界里重新分配概率——样本空间收缩为 $B$，概率按比例放大。

> **衔接上节课的"$1=0$ 悖论"**（p022 开场复习）：把单位正方形写成"所有单点集合的并"，若对它误用可数可加性——每个单点面积为 0，于是"并集概率 = 0+0+... = 0"，却又等于 $P(\Omega)=1$，得到 $1=0$。错误出在哪？可数可加性只对**能排成序列**的不相交事件列成立；单位正方形里的点**不可数**（详见 **S01.8 可数与不可数**），这种"全部点的并"不是可数并，公理不适用。这也引出两条连续模型的直觉：
> - **零概率 ≠ 不可能**：飞镖落在某个精确点的概率为 0，但实验做完后它确实落在某个点上——连续模型里"真正发生的事"全是零概率事件。老师的 bumper sticker：**always expect the unexpected**。
> - **概率 1 ≠ 必然**：$P((x,y)\ne(0,0))=1$（挖掉一个点），但 $(0,0)$ 仍可能发生；概率 1 只是"本质确定"。

### 1.2 条件概率
$P(A \mid B)$ 读作"给定 $B$ 发生的条件下 $A$ 的概率"，定义为
$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}, \qquad P(B) > 0$$
直觉：只看 $B$ 这块"新样本空间"，$A$ 在其中占的比例。

> **怎么"按比例放大"**（老师的数值演示，p023）：设 $\Omega$ 中三块概率分别为 $3/6, 2/6, 1/6$，被告知 $B$ 发生（其中含 $2/6+1/6=3/6$）。原来 $B$ 内部两块的比例是 $2:1$；条件化后**保持这个比例**，但要归一到 1，于是变成 $2/3$ 和 $1/3$。这正是定义 $P(A\mid B)=\frac{P(A\cap B)}{P(B)}$ 的直觉来源——新分布 = 在 $B$ 内部保持旧比例、整体归一。
> 技术细节：若 $P(B)=0$，分母为 0，$P(A\mid B)$ 无定义（本课程只在 $P(B)>0$ 时谈条件概率）。

#### 推导：条件概率定义的动机与"重新归一化"
设想原始概率律 $P$ 在整个 $\Omega$ 上分配权重。一旦被告知"$B$ 已发生"，$\Omega$ 中落在 $B^c$ 里的结果全部被排除，我们只剩 $B$ 这一块。一个自然的要求是：**$B$ 内部各结果之间的相对概率不能因为这条信息而改变**——信息只告诉我们"实验落在 $B$ 里"，没有提供 $B$ 内部哪一块更可能的新线索。于是对任意事件 $A$，它在新世界里的概率 $P(A\mid B)$ 应当正比于它在旧世界里落在 $B$ 内的那部分权重 $P(A\cap B)$，即 $P(A\mid B) = c\cdot P(A\cap B)$。

待定常数 $c$ 由归一性确定：新世界必须满足 $P(\Omega\mid B)=1$，而在新世界里 $\Omega$ 对应的正是 $B$ 本身，故
$$1 = P(B\mid B) = c\cdot P(B\cap B) = c\cdot P(B) \;\Longrightarrow\; c = \frac{1}{P(B)}$$
代回即得定义 $P(A\mid B)=P(A\cap B)/P(B)$。这就是"重新归一化"四个字的全部含义：**把 $B$ 内部的旧概率全部除以 $P(B)$，让它们加起来重新等于 1**。

顺带可直接验证条件律满足概率三公理（与 3.1 呼应）：非负性显然；归一性 $P(B\mid B)=P(B)/P(B)=1$；可加性——若 $C\cap D=\varnothing$，则 $(C\cap B)\cap(D\cap B)=\varnothing$，故 $P(C\cup D\mid B)=P((C\cup D)\cap B)/P(B)=[P(C\cap B)+P(D\cap B)]/P(B)=P(C\mid B)+P(D\mid B)$。

### 1.3 三个基本工具
1. **乘法法则**：从条件概率反解联合概率；
2. **全概率定理**：用"分情景 + 各情景内概率"合成总概率；
3. **贝叶斯法则**：把条件方向反过来——由"原因 → 观测"的概率推出"观测 → 原因"的概率，这是**推断**（贝叶斯推断）的起点。

## 2. 公式与定义

### 2.1 乘法法则
$$P(A \cap B) = P(B) \, P(A \mid B) = P(A) \, P(B \mid A)$$
多事件链式版本：
$$P(A \cap B \cap C) = P(A) \, P(B \mid A) \, P(C \mid A \cap B)$$

#### 推导：乘法法则的由来
它不是新公理，只是条件概率定义的**移项**。由定义 $P(A\mid B)=P(A\cap B)/P(B)$，两边同乘 $P(B)>0$，立刻得 $P(A\cap B)=P(B)P(A\mid B)$；把 $A,B$ 对调写一次即得对称形式 $P(A\cap B)=P(A)P(B\mid A)$。

链式版本靠反复套定义、加括号推出：
$$P(A\cap B\cap C) = \underbrace{P((A\cap B)\cap C)}_{\text{把 }A\cap B\text{ 看成一个事件}} = P(A\cap B)\,P(C\mid A\cap B) = P(A)\,P(B\mid A)\,P(C\mid A\cap B)$$
每一步都是"先联合、再补一个条件因子"。$n$ 个事件以此类推，得到沿事件链的连乘。

> **频率解释**：反复做实验，$B$ 发生的频率是 $P(B)$；在 $B$ 发生的那些次里 $A$ 也发生的比例是 $P(A\mid B)$；两者相乘 = "$A,B$ 同时发生"的频率 = $P(A\cap B)$。
> **树解释**（老师的核心画面，p027）：把模型画成事件树，每个节点表示"已经发生了哪些事件"，每条边标上该条件下的概率；从根到某片叶子把沿途条件概率**相乘**，就得到该叶子（最终结果）的概率。链式法则就是"沿树边走边乘"。

### 2.2 全概率定理
设 $A_1, A_2, \dots, A_n$ 是样本空间的一个**划分**（两两不相交且并为 $\Omega$），则对任意事件 $B$：
$$P(B) = \sum_i P(A_i) \, P(B \mid A_i)$$
直觉：把 $B$ 拆成"落在各情景 $A_i$ 里的 $B$"，各块概率相加。

#### 推导：把 $B$ 写成不相交并再套公理
因为 $A_1,\dots,A_n$ 划分 $\Omega$，每个结果恰好属于一个 $A_i$。事件 $B$ 中的结果自然也按"落在哪个 $A_i$ 里"被切成 $n$ 块：
$$B = (B\cap A_1)\ \cup\ (B\cap A_2)\ \cup\ \cdots\ \cup\ (B\cap A_n)$$
这 $n$ 块两两不相交（来自不相交的 $A_i$），由概率的**有限可加性公理**：
$$P(B) = P(B\cap A_1) + P(B\cap A_2) + \cdots + P(B\cap A_n)$$
对每一项用乘法法则 $P(B\cap A_i)=P(A_i)P(B\mid A_i)$，即得
$$P(B) = \sum_{i=1}^n P(A_i)\,P(B\mid A_i)$$
这就是教材图 1.13 的画面：$B$ 被划分线切成若干不相交小条，每条概率 = 条宽 $P(A_i)$ × 该条内 $B$ 所占比例 $P(B\mid A_i)$，再求和。

> **加权平均视角**（p028）：$P(B) = \sum_i P(A_i)P(B\mid A_i)$ 是 $P(B\mid A_i)$ 在不同情景下取值的**加权平均**，权重就是先验 $P(A_i)$（且 $\sum_i P(A_i)=1$）。若各情景等可能（$P(A_i)=1/n$），就退化为普通算术平均。
> 适用范围：划分个数有限即可；有限/无限样本空间都成立；无限划分版本留作章末习题。

### 2.3 贝叶斯法则
$$P(A_i \mid B) = \frac{P(A_i) \, P(B \mid A_i)}{\sum_j P(A_j) \, P(B \mid A_j)}$$
- $P(A_i)$：先验信念（初始）；
- $P(B \mid A_i)$：情景 $A_i$ 下的模型（似然）；
- $P(A_i \mid B)$：后验信念（观察到 $B$ 后修正）。

#### 推导：分子用乘法法则、分母用全概率
贝叶斯法则只是把条件方向反过来，两步推出。

第一步（分子）：对任意固定的 $i$，由乘法法则
$$P(A_i\cap B) = P(B)\,P(A_i\mid B) = P(A_i)\,P(B\mid A_i)$$
把中间量 $P(A_i\cap B)$ 两头连起来：$P(B)\,P(A_i\mid B)=P(A_i)\,P(B\mid A_i)$，于是
$$P(A_i\mid B) = \frac{P(A_i)\,P(B\mid A_i)}{P(B)}$$

第二步（分母）：$P(B)$ 本身用全概率定理（2.2）按划分 $A_1,\dots,A_n$ 展开：
$$P(B) = \sum_{j=1}^n P(A_j)\,P(B\mid A_j)$$

代入即得
$$P(A_i \mid B) = \frac{P(A_i) \, P(B \mid A_i)}{\sum_j P(A_j) \, P(B \mid A_j)}$$
整个公式没有新概率，只是"乘法法则给分子、全概率给分母"。分母 $\sum_j P(A_j)P(B\mid A_j)$ 是一个与 $i$ 无关的归一化常数——它保证所有后验 $P(A_i\mid B)$ 加起来等于 1。

#### 推导：odds 形式（后验比 = 先验比 × 似然比）
把两个情景 $A_i$ 与 $A_k$ 的后验相除，归一化常数立刻约掉：
$$\frac{P(A_i\mid B)}{P(A_k\mid B)} = \frac{P(A_i)P(B\mid A_i)/P(B)}{P(A_k)P(B\mid A_k)/P(B)} = \frac{P(A_i)}{P(A_k)}\cdot\frac{P(B\mid A_i)}{P(B\mid A_k)}$$
读作：
$$\text{后验比} = \text{先验比} \times \text{似然比}$$
即"观测到 $B$ 之后，两个原因的赔率"等于"原先的赔率"乘以"$B$ 在两个原因下出现可能性的比值"。似然比 $P(B\mid A_i)/P(B\mid A_k)>1$ 表示观测 $B$ 对 $A_i$ 比对 $A_k$ 更有说服力，它会把先验赔率往 $A_i$ 方向放大；$<1$ 则往相反方向压。这条形式在诊断、雷达、假设检验里比直接算后验更省事——只需比较"各条路走通的概率"之比。

## 3. 关键性质

### 3.1 条件概率满足普通概率的三条公理（在 $B$ 的条件下）
- $P(A \mid B) \ge 0$；
- $P(\Omega \mid B) = 1$（样本空间归一化）——特别地 $P(B \mid B) = 1$；
- 若 $A \cap C = \varnothing$，则 $P(A \cup C \mid B) = P(A \mid B) + P(C \mid B)$。

因此条件概率可以像普通概率一样使用容斥、互补等所有性质，只是所有概率都换成条件概率。

### 3.2 雷达示例的意义（三类工具串起来的典型场景）
- 事件 $A$：飞机在上方；事件 $B$：雷达显示信号；
- 先验 $P(A) = 0.05$，$P(A^c) = 0.95$；
- 似然：$P(B \mid A) = 0.99$（真目标探测率）、$P(B \mid A^c) = 0.10$（虚警率）；
- 计算：
  - $P(A \cap B) = P(A)P(B \mid A) = 0.05 \times 0.99 = 0.0495$；
  - $P(B) = P(A)P(B \mid A) + P(A^c)P(B \mid A^c) = 0.0495 + 0.095 = 0.1445$；
  - $P(A \mid B) = 0.0495 / 0.1445 \approx 0.34$。
- **重要直觉**：即使探测率高达 0.99，由于先验很小（0.05）且虚警率不低（0.10），看到信号后飞机真实存在的概率也只有约 1/3——"先验小 + 虚警高"会压制后验。

> **为什么 0.34 感觉低**（老师追问，p026）：雷达规格其实不错——有飞机时 99% 探测到，没飞机时 90% 正确不报警。但看到信号后真实概率只有 34%。原因在**相对赔率**：真实探测这条路概率 $\approx 0.05\times0.99=0.0495$，虚警这条路 $\approx 0.95\times0.10=0.095$——虚警几乎是真探测的两倍！所以信号出现时，它更可能来自"虚警"而非"真飞机"。
> 同类故事（医学检验）：某病若已绝迹，哪怕检测很准，阳性结果也不能断定你有病——"先验小 + 假阳性率不低"会严重压制后验，医生也常在此犯错。

### 3.3 贝叶斯推断框架
- 初始信念 $P(A_i)$（各可能情景/原因的先验）；
- 每个情景下的世界模型 $P(B \mid A_i)$（原因 → 观测）；
- 观察到 $B$ 后，用贝叶斯法则算出 $P(A_i \mid B)$（观测 → 原因），得到修正后的信念。

> 历史注记：Thomas Bayes（约 1701–1761），长老会牧师，"贝叶斯定理"在其去世后才发表，是系统性整合新证据、从经验中学习的数学方法，构成贝叶斯推断分支。

## 4. 例题

### 例 1：掷两次四面骰子（条件概率计算）
- 样本空间 16 个等可能结果；令 $B$ = {$\min(X,Y) = 2$}；
- $B$ 中的结果：$(2,2),(2,3),(2,4),(3,2),(4,2)$ 共 5 个，$P(B) = 5/16$；
- 令 $M = \max(X,Y)$：
  - $P(M = 1 \mid B)$：$B$ 中无任何 $M=1$ 结果，故为 0；
  - $P(M = 3 \mid B)$：$B$ 中 $M=3$ 的结果为 $(2,3),(3,2)$ 共 2 个，故为 $2/5$。

> **快速解法**：$B$ 的 5 个结果在原均匀模型中等概率，条件化后仍等概率（**均匀律在条件化下保持**——只是样本空间缩小到 $B$）。所以直接数：$M=3$ 在 $B$ 中有 2 个，答案 $2/5$，不必套定义。这是离散均匀问题的常用捷径。

### 例 2：12 等可能结果的图示
- $\Omega$ 划分：$A$ 独有 $3/12$、$A \cap B$ 为 $2/12$、$B$ 独有 $4/12$、其余 $3/12$；
- $P(A) = 5/12$，$P(B) = 6/12$；
- 已知 $B$ 发生时：$P(A \mid B) = P(A \cap B)/P(B) = (2/12)/(6/12) = 1/3$，而 $P(B \mid B) = 1$。

### 例 3：贝叶斯法则求后验
沿用雷达示例：$P(A_1 \mid B) = \dfrac{0.05 \times 0.99}{0.05\times0.99 + 0.95\times0.10} \approx 0.343$，即看到信号后飞机在上的概率约 34%。

### 例 4：诊断测试——患病率低时阳性后验仍很小
设某病患病率（先验）$P(D)=0.001$，即 1000 人里约 1 人患病。检测指标：真阳性率 $P(+\mid D)=0.99$（99% 的病人会被检出），假阳性率 $P(+\mid D^c)=0.05$（5% 的健康人会误报）。问：检测阳性时真的患病的概率 $P(D\mid +)$ 是多少？

按贝叶斯法则一步步算：

- 分子（病人且阳性）：$P(D)P(+\mid D)=0.001\times0.99=0.00099$；
- 分母中"健康且阳性"那条路：$P(D^c)P(+\mid D^c)=0.999\times0.05=0.04995$；
- 全概率：$P(+)=0.00099+0.04995=0.05094$；
- 后验：
$$P(D\mid +)=\frac{0.00099}{0.05094}\approx 0.0194 \approx 1.9\%$$

**结论**：尽管检测"准确率"看起来很高（99% 检出、95% 不误报），一次阳性之后真患病的概率只有约 2%。用 odds 形式看更清楚：先验比 $P(D)/P(D^c)=0.001/0.999\approx 1/1000$；似然比 $P(+\mid D)/P(+\mid D^c)=0.99/0.05\approx 20$；后验比 $\approx (1/1000)\times20=1/50$，即后验概率 $1/(1+50)\approx 1/51\approx 2\%$。患病率太低时，健康人基数巨大，5% 的假阳性积累起来远超过真正的病人——这就是"基础率谬误"：忽略先验、只看检测准确率会严重高估阳性结果的意义。

## 5. 本节重点

> **本节重点**：
> - 条件概率 $P(A \mid B) = P(A \cap B)/P(B)$：新世界 = 收缩到 $B$、内部按旧比例重新归一到 1；条件概率本身满足全部概率公理。
> - 乘法法则（链式）、全概率定理（把 $B$ 按划分拆成不相交并再套可加性）、贝叶斯法则（分子乘法、分母全概率）三件套要能熟练互推。
> - 贝叶斯法则 = 先验 × 似然 / 归一化常数；odds 形式：后验比 = 先验比 × 似然比。
> - **常见坑**：① $P(A \mid B)$ 与 $P(B \mid A)$ 混淆（方向完全相反）；② 全概率定理忘记乘 $P(A_i)$；③ 忽略先验太小或假阳性太高对后验的压制（基础率谬误）——患病率低时，哪怕检测很准，阳性后验仍可能很小。
