## 1. 核心概念

### 1.1 在随机变量 $Y$ 上的条件作用
与"给定事件"相比，这里条件对象是另一个随机变量的取值 $Y = y$：
$$p_{X \mid Y}(x \mid y) = \frac{p_{X,Y}(x,y)}{p_Y(y)}, \qquad p_Y(y) > 0$$
对固定的 $y$，$\sum_x p_{X \mid Y}(x \mid y) = 1$——它是对每个 $y$ 都成立的合法 PMF。

### 1.2 随机变量的独立性
$X$ 与 $Y$ 独立当且仅当联合 PMF 处处等于边缘乘积：
$$p_{X,Y}(x,y) = p_X(x) p_Y(y), \quad \forall x, y$$

## 2. 公式与定义

### 2.1 条件期望与全期望（随机变量版）
- $E[X \mid Y = y] = \sum_x x p_{X \mid Y}(x \mid y)$；
- $E[g(X) \mid Y = y] = \sum_x g(x) p_{X \mid Y}(x \mid y)$；
- 全概率/全期望（对 $Y$ 求和）：
$$p_X(x) = \sum_y p_Y(y) p_{X \mid Y}(x \mid y), \qquad E[X] = \sum_y p_Y(y) E[X \mid Y = y]$$
（$Y$ 在无限集取值时也成立，只要 $E[|X|] < \infty$。）

### 2.2 乘法法则（链式，多于两个变量）
$$p_{X,Y,Z}(x,y,z) = p_X(x) p_{Y \mid X}(y \mid x) p_{Z \mid X,Y}(z \mid x,y)$$

### 2.3 独立性的层次
- 事件独立：$P(A \cap B) = P(A)P(B)$；
- 随机变量与事件独立：$P(X=x \cap A) = P(X=x)P(A)$，$\forall x$；
- 两随机变量独立：$p_{X,Y}(x,y) = p_X(x)p_Y(y)$；
- 三元独立：$p_{X,Y,Z} = p_X p_Y p_Z$ 对所有 $(x,y,z)$ 成立（强于两两独立）。

### 2.4 独立 ⇒ 期望/方差拆开
- $E[XY] = E[X]E[Y]$（独立时）；
- $g(X)$ 与 $h(Y)$ 独立 ⇒ $E[g(X)h(Y)] = E[g(X)]E[h(Y)]$；
- $X,Y$ 独立 ⇒ $\text{var}(X+Y) = \text{var}(X) + \text{var}(Y)$。

## 3. 关键性质

### 3.1 二项分布方差（指示变量求和）
- $X = X_1 + \cdots + X_n$（$X_i$ 独立指示变量，$E[X_i] = p$）；
- $X_i$ 独立 ⇒ $\text{var}(X) = \sum_i \text{var}(X_i) = n p(1-p)$。

### 3.2 帽子问题（经典对称性技巧）
- $n$ 人把帽子放入盒中随机各取一顶，$X$ = 拿到自己帽子的人数；
- $X_i$：第 $i$ 人拿回自己的帽子（指示变量）；
- $E[X_i] = P(\text{第 } i \text{ 人拿回自己帽子}) = 1/n$（对称性），故 $E[X] = n \cdot \frac1n = 1$；
- 方差：$\text{var}(X) = E[X^2] - (E[X])^2$；
  - $X^2 = \sum_i X_i^2 + \sum_{i \ne j} X_i X_j$；
  - $E[X_i^2] = E[X_i] = 1/n$；
  - $i \ne j$：$E[X_i X_j] = P(i \text{ 和 } j \text{ 都拿回自己帽子}) = \frac{1}{n(n-1)}$（先给 $i$，再给 $j$）；
  - $E[X^2] = n \cdot \frac1n + n(n-1) \cdot \frac{1}{n(n-1)} = 1 + 1 = 2$；
  - $\text{var}(X) = 2 - 1 = 1$。

## 5. 本节重点

> **本节重点**：
> - 条件 PMF $p_{X \mid Y}(x \mid y) = p_{X,Y}(x,y)/p_Y(y)$；条件期望、全期望（对 $y$ 求和）三件套。
> - 独立 = 联合处处可拆；独立时 $E[XY]$、$\text{var}(X+Y)$ 都能拆。
> - 二项方差 $np(1-p)$：指示变量 + 线性/独立拆方差。
> - 帽子问题：$E[X]=1$、$\text{var}(X)=1$，靠对称性与指示变量，不靠硬算排列。
> - **常见坑**：① 条件 PMF 定义域要求 $p_Y(y)>0$；② 把"两两独立"当"独立"；③ 帽子问题中 $E[X_iX_j]$ 算成 $1/n^2$（应为 $1/(n(n-1))$）。
