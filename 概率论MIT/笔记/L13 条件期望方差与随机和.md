## 1. 核心概念

### 1.1 条件期望是随机变量
$E[X \mid Y]$ 不是数，而是 $Y$ 的函数（因为 $E[X \mid Y = y]$ 随 $y$ 变）。它本身是随机变量，可以再求期望、方差。

### 1.2 重期望法则（迭代期望）
$$E[E[X \mid Y]] = E[X]$$
"分两步平均" = "一步平均"。

### 1.3 全方差法则
$$\text{var}(X) = E[\text{var}(X \mid Y)] + \text{var}(E[X \mid Y])$$
解读：总方差 = 组内方差的平均 + 组间均值的方差。

---

## 2. 公式与定义

### 2.1 条件方差
$$\text{var}(X \mid Y = y) = E[(X - E[X \mid Y=y])^2 \mid Y = y]$$
也可写成 $\text{var}(X \mid Y) = E[X^2 \mid Y] - (E[X \mid Y])^2$。

### 2.2 全方差法则推导要点
$$\text{var}(X) = E[X^2] - (E[X])^2 = E\big[E[X^2 \mid Y]\big] - \big(E[E[X \mid Y]]\big)^2 = E[\text{var}(X\mid Y)] + \text{var}(E[X \mid Y])$$

### 2.3 随机个随机变量之和
$N$ 随机（取非负整数），$X_i$ i.i.d.（与 $N$ 独立），$S = X_1 + \cdots + X_N$：
$$E[S] = E[N] \, E[X]$$
$$\text{var}(S) = E[N] \text{var}(X) + (E[X])^2 \text{var}(N)$$

---

## 3. 关键性质

- **预测解释**：$E[X \mid Y]$ 是给定 $Y$ 时对 $X$ 的最优预测（最小二乘意义，见 L16）；
- **分组公式**（用于数据分组）：总体均值 = 各组均值按人数加权；总体方差 = 组内方差均值 + 组均值间方差——这是"方差分解"（ANOVA 雏形）；
- 条件期望满足期望的所有性质（线性、期望值法则等），在条件世界内照常使用。

## 4. 例题

### 例 1：两阶段随机和的均值与方差（保险/队列模型）
- $N \sim \text{Poisson}(\lambda)$ 或 $N \sim \text{Geom}(p)$，$X_i$ i.i.d. 均值 $\mu$、方差 $\sigma^2$：
- $E[S] = E[N]\mu$；$\text{var}(S) = E[N]\sigma^2 + \mu^2\text{var}(N)$；
- 例：$N \sim \text{Poisson}(\lambda)$，$\text{var}(S) = \lambda\sigma^2 + \lambda\mu^2 = \lambda(\mu^2+\sigma^2) = \lambda E[X^2]$。

### 例 2：方差分解
- 两个班级：1 班（20 人）均值 70、方差 100；2 班（30 人）均值 80、方差 121；
- $E[X] = \frac{20\cdot70 + 30\cdot80}{50} = 76$；
- $E[\text{var}(X\mid Y)] = \frac{20\cdot100 + 30\cdot121}{50} = 112.6$；
- $\text{var}(E[X \mid Y]) = \frac{20(70-76)^2 + 30(80-76)^2}{50} = \frac{20\cdot36 + 30\cdot16}{50} = 24$；
- $\text{var}(X) = 112.6 + 24 = 136.6$。

### 例 3：分步求条件期望
- $Y \sim U[0,1]$，给定 $Y=y$ 时 $X \sim \text{Bernoulli}(y)$：
- $E[X \mid Y] = Y$，故 $E[X] = E[Y] = 1/2$；
- $\text{var}(X \mid Y) = Y(1-Y)$；$E[\text{var}(X\mid Y)] = E[Y] - E[Y^2] = \frac12 - \frac13 = \frac16$；
- $\text{var}(E[X\mid Y]) = \text{var}(Y) = \frac{1}{12}$；
- $\text{var}(X) = \frac16 + \frac{1}{12} = \frac14 = p(1-p)$ 验证伯努利方差公式。

---

## 5. 本节重点

> **本节重点**：
> - $E[X \mid Y]$ 是 $Y$ 的随机函数；重期望 $E[E[X\mid Y]] = E[X]$。
> - 全方差：$\text{var}(X) = E[\text{var}(X\mid Y)] + \text{var}(E[X \mid Y])$（组内+组间）。
> - 随机个独立同分布之和：$E[S] = E[N]E[X]$，$\text{var}(S) = E[N]\text{var}(X) + (E[X])^2\text{var}(N)$。
> - **常见坑**：① 把 $E[X\mid Y]$ 当常数；② 全方差只写一半（只写组内或只写组间）；③ 随机个数之和的方差漏掉 $(E[X])^2\text{var}(N)$ 项。
