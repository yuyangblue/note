## 1. 核心概念

### 1.1 条件期望作为随机变量（p134）
- 固定 $Y=y$ 时，$E[X \mid Y=y]$ 是一个**数**（条件宇宙内的均值）；
- 但 $Y$ 本身是随机的，所以把 $g(y)=E[X \mid Y=y]$ 中的 $y$ 换成随机变量 $Y$，得到 $g(Y)=E[X \mid Y]$——一个**随机变量**，是 $Y$ 的函数；
- 它有自己的分布、期望、方差；当实验揭示 $Y$ 的取值后，它才"落地"成一个数。
- **直觉（p143 预测修订）**：年初对二月销量 $X$ 的预测是 $E[X]$；一月末获得新信息 $Y$ 后，修订预测为 $E[X \mid Y]$。全期望定理说：所有可能修订值的平均 = 原预测——预测不会系统性地偏高或偏低。

### 1.2 条件方差作为随机变量
- 固定 $Y=y$：$\text{var}(X \mid Y=y) = E[(X - E[X \mid Y=y])^2 \mid Y=y]$（条件宇宙内的方差，数）；
- 抽象成随机变量 $\text{var}(X \mid Y)$：揭示 $Y$ 取值后才变成数。

## 2. 公式与定义

### 2.1 迭代期望律
$$E[E[X \mid Y]] = E[X]$$
- 证明：$E[g(Y)] = \sum_y p_Y(y) g(y) = \sum_y p_Y(y) E[X \mid Y=y] = E[X]$（离散）；连续换积分。
- 这就是全期望定理的抽象写法。

### 2.2 全方差律
$$\text{var}(X) = E[\text{var}(X \mid Y)] + \text{var}(E[X \mid Y])$$
- 证明（4 步代数，讲义 p7）：
  1. 对条件宇宙用通用方差公式：$\text{var}(X \mid Y=y) = E[X^2 \mid Y=y] - (E[X \mid Y=y])^2$；
  2. 两边取期望：$E[\text{var}(X \mid Y)] = E[X^2] - E[(E[X \mid Y])^2]$；
  3. 对随机变量 $E[X \mid Y]$ 用方差公式：$\text{var}(E[X \mid Y]) = E[(E[X \mid Y])^2] - (E[E[X \mid Y]])^2 = E[(E[X \mid Y])^2] - (E[X])^2$；
  4. 两式相加，中间项抵消，剩 $E[X^2] - (E[X])^2 = \text{var}(X)$。

### 2.3 随机个独立随机变量之和（p141）
- $N$：非负整数随机变量（去几家店）；
- $X_i$：独立同分布（在店 $i$ 花的钱），且 $X_i$ 与 $N$ 独立；
- $Y = X_1 + \cdots + X_N$。
- 条件固定 $N=n$ 时：$E[Y \mid N=n] = n E[X]$，$\text{var}(Y \mid N=n) = n\text{var}(X)$；
- **期望**：
$$E[Y] = E[E[Y \mid N]] = E[N E[X]] = E[N]\, E[X]$$
- **方差**（用全方差律）：
$$\text{var}(Y) = E[\text{var}(Y \mid N)] + \text{var}(E[Y \mid N]) = E[N]\, \text{var}(X) + (E[X])^2 \text{var}(N)$$

## 3. 关键性质

### 3.1 全方差律的两块直觉（p138 课堂例子）
- **$E[\text{var}(X \mid Y)$：组内波动**——各"条件宇宙"内部的平均离散度（如各班级内部分数散布）；
- **$\text{var}(E[X \mid Y])$：组间波动**——各条件宇宙的均值之间差多远（如各班级平均分之间的差异）；
- 总波动 = 组内 + 组间。两者叠加：即使每个班内部分数都很集中（组内小），若班与班均分差很大（组间大），全班总方差仍然大。

### 3.2 随机和方差的两项解释
- $E[N]\,\text{var}(X)$："进店花多少钱"本身是随机的（每家店内部波动），去 $N$ 家就累积 $N$ 份；
- $(E[X])^2\text{var}(N)$："去几家店"本身随机——去的店数越多总花费越高，这种"店数随机"带来的波动被单次均值 $E[X]$ 平方放大；
- 两项缺一不可：只算第一项会漏掉"店数随机"这一最大的风险源。

## 4. 例题

### 例 1：断棒问题
- $Y \sim U[0,\ell]$，$X \mid Y=y \sim U[0,y]$；
- $E[X \mid Y=y] = y/2$，故 $E[X \mid Y] = Y/2$；
- $E[X] = E[Y/2] = \ell/4$（与 L10 长积分结果一致）。

### 例 2：课堂测验（两个班）
- 班 1：10 人，均分 90，班内方差 10；班 2：20 人，均分 60，班内方差 20；随机抽一名学生；
- $E[X] = (10\cdot90+20\cdot60)/30 = 70$；
- $E[X \mid Y]$：以 $1/3$ 取 90、以 $2/3$ 取 60；验证 $E[E[X \mid Y]] = \frac13\cdot90+\frac23\cdot60 = 70$；
- 组间方差 $\text{var}(E[X \mid Y]) = \frac13(90-70)^2+\frac23(60-70)^2 = 200$；
- 组内均值 $E[\text{var}(X \mid Y)] = \frac13\cdot10+\frac23\cdot20 = 50/3$；
- 总方差 $\text{var}(X) = 50/3 + 200 \approx 216.7$。

### 例 3：分段均匀密度（连续版）
- $X$ 以 $1/3$ 概率在 $[0,1]$ 均匀、以 $2/3$ 概率在 $[1,2]$ 均匀；
- $E[X \mid Y=1]=1/2$、$E[X \mid Y=2]=3/2$；$E[X]=7/6$；
- 两段都是单位长度均匀，故条件方差恒为 $1/12$；
- 组间方差 $\text{var}(E[X \mid Y]) = \frac13(1/2-7/6)^2+\frac23(3/2-7/6)^2 = 2/9$；
- 总方差 $\text{var}(X) = 1/12 + 2/9 = 11/36$（直接用 $E[X^2]=5/3$ 验证一致）。

### 例 4：随机和（买书）
- $N$ = 进的书店数（均值 5、方差 4）；$X_i$ = 每店花费（均值 30、方差 25，元）；
- $E[Y] = 5 \times 30 = 150$ 元；
- $\text{var}(Y) = 5 \times 25 + 30^2 \times 4 = 125 + 3600 = 3725$，标准差约 61 元。
- 解读：店数随机这一项贡献了绝大部分方差——"去几家店"的不确定性主导了总花费的波动。

## 5. 本节重点

> **本节重点**：
> - 条件期望 $E[X \mid Y]$、条件方差 $\text{var}(X \mid Y)$ 都是**随机变量**（$Y$ 的函数），揭示 $Y$ 后才落地为数；它们有自己的期望和方差。
> - 迭代期望律 $E[E[X \mid Y]] = E[X]$（全期望定理的抽象形式）。
> - 全方差律 $\text{var}(X) = E[\text{var}(X \mid Y)] + \text{var}(E[X \mid Y])$：总波动 = 组内 + 组间。
> - 随机和：$E[Y] = E[N]E[X]$；$\text{var}(Y) = E[N]\text{var}(X) + (E[X])^2\text{var}(N)$。
> - **常见坑**：① 把 $E[X \mid Y]$ 当一个常数（它是随机变量，要再取期望）；② 算随机和方差时漏掉 $(E[X])^2\text{var}(N)$ 这一项；③ 全方差律中把两项相加搞成相减；④ 以为条件方差的期望等于无条件方差（其实还要加"均值之间差异"那一项）。
