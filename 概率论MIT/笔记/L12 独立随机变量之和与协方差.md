## 1. 核心概念

### 1.1 独立随机变量之和
$Z = X + Y$（$X,Y$ 独立）：
- 离散：**卷积** $p_Z(z) = \sum_x p_X(x) p_Y(z-x)$；
- 连续：**卷积积分** $f_Z(z) = \int f_X(x) f_Y(z-x)\, dx$；
- 直观：$Z = z$ 时 $Y$ 必须恰好等于 $z - X$，对 $X$ 的所有可能值加权求和/积分。
- **机械画法（p122，讲义 p3）**：把 $p_Y$ 水平翻转、对齐到 $p_X$ 下方、按 $z$ 右移，对应项相乘再相加；对每个 $z$ 重复一次。连续情形把"翻转-平移-相乘-相加"换成"翻转-平移-相乘-积分"。

### 1.2 协方差：衡量"一起变化"
$$\text{cov}(X,Y) = E[(X - E[X])(Y - E[Y])] = E[XY] - E[X]E[Y]$$
- 正：$X$ 大时 $Y$ 也偏大（散点落在一、三象限为主）；负：反向；0：无线性关系（**不**等价于独立）。
- 原点理解（lec11）：中心化后看"$X$ 偏高时 $Y$ 是否也偏高"，乘积的期望就是系统同向/反向的程度。

### 1.3 相关系数：归一化的协方差
$$\rho = \frac{\text{cov}(X,Y)}{\sigma_X \sigma_Y} \in [-1, 1]$$
- 协方差带"$X$ 单位 × $Y$ 单位"，不方便比较；各自除以标准差后得到无量纲的 $\rho$。
- $\rho$ 对仿射变换不变：$\rho(aX+b,\ cY+d) = \text{sign}(ac)\rho(X,Y)$（缩放/平移不改线性相关程度）。

## 2. 公式与定义

### 2.1 独立同分布求和（卷积的性质）
- 独立正态之和：$X \sim N(\mu_1,\sigma_1^2)$、$Y \sim N(\mu_2,\sigma_2^2)$ 独立 ⇒ $X+Y \sim N(\mu_1+\mu_2,\ \sigma_1^2+\sigma_2^2)$；
- 一般情形：均值相加、方差相加（独立时），分布由卷积决定。
- **正态之和仍正态**：把两个正态密度做卷积积分，指数配平方后仍是高斯形式——这是卷积最漂亮的特例。

### 2.2 协方差性质
- $\text{cov}(X,X) = \text{var}(X)$；
- 对称：$\text{cov}(X,Y) = \text{cov}(Y,X)$；
- 双线性：$\text{cov}(aX+b,\ cY+d) = ac\,\text{cov}(X,Y)$；$\text{cov}(X+Y, Z) = \text{cov}(X,Z) + \text{cov}(Y,Z)$；
- 快捷公式：$\text{cov}(X,Y) = E[XY] - E[X]E[Y]$（由展开定义式、用期望线性性得到）；
- $X,Y$ 独立 ⇒ $\text{cov}(X,Y) = 0$（反之不成立！）；
- $|\text{cov}(X,Y)| \le \sigma_X\sigma_Y$（柯西-施瓦茨）。

### 2.3 和的方差
$$\text{var}(X+Y) = \text{var}(X) + \text{var}(Y) + 2\text{cov}(X,Y)$$
一般化：
$$\text{var}\left(\sum_i X_i\right) = \sum_i \text{var}(X_i) + \sum_{i \ne j} \text{cov}(X_i, X_j)$$
独立时协方差项为 0，只剩方差和。（展开 $(X_1+\cdots+X_n)^2$ 的平方项 + 交叉项即得。）

### 2.4 相关系数的含义
- $\rho = \pm 1$ ⇔ $X, Y$ 互为（非随机）线性函数：$X - E[X] = c(Y - E[Y])$（$c$ 符号决定正负）；散点全部落在一条直线上。
- $|\rho|$ 接近 1：强线性关系；接近 0：线性关系弱（可能有强非线性关系）。
- $\rho(X,X)=1$。

## 3. 关键性质

### 3.1 相关系数的几何解释
- 把随机变量看作向量空间中的元素：相关系数 = 两"向量"夹角的余弦；
- $\rho = \cos\theta$，$\theta \in [0,\pi]$；$\rho=1$ 共线同向、$\rho=-1$ 共线反向、$\rho=0$ 正交。

### 3.2 相关系数 ≠ 因果关系
- 相关性只度量**线性关联**，两个变量可能因共同原因（如季节、共同隐因子）相关；
- 讲义例子（p12）：$X$ = 数学能力、$Y$ = 音乐能力，$\rho>0$ 不代表"学音乐提高数学"。模型：$X=Z+V$、$Y=Z+W$，$Z,V,W$ 独立零均值单位方差，则 $\text{cov}(X,Y)=\text{var}(Z)=1$，$\sigma_X=\sigma_Y=\sqrt2$，故 $\rho=1/2$——共同隐因子 $Z$（如一般智力）制造了相关。
- $\rho = 0$ 不排除强非线性依赖（如 $Y = X^2$ 且 $X$ 对称分布）。

### 3.3 相关性影响和的方差（投资组合直觉）
- 若 $X,Y$ 正相关，$\text{var}(X+Y)$ 更大（风险叠加）；
- 若负相关，方差变小（对冲）；这就是分散化降低风险的数学基础。

## 4. 例题

### 例 1：两枚骰子之和
- $X, Y \sim U\{1,\dots,6\}$ 独立，$Z = X+Y$；
- $p_Z(z)$ 呈三角形：$p_Z(7) = 6/36 = 1/6$（最大），两端 $p_Z(2) = p_Z(12) = 1/36$；
- $E[Z] = 7$；$\text{var}(Z) = 2 \cdot \frac{35}{12} = \frac{35}{6}$。

### 例 2：协方差示例（联合表）
- 表 $p_{X,Y}$：$X \in \{0,1\}$、$Y \in \{0,1\}$；
- 算 $E[XY]$、$E[X]$、$E[Y]$ 代入 $\text{cov} = E[XY] - E[X]E[Y]$；
- 若表对称（$p_{X,Y}=p_Xp_Y$ 不成立但边缘乘积成立），$\text{cov} \ne 0$ 但 $X,Y$ 不独立——举例说明"协方差为 0 推不出独立"。

### 例 3：独立正态之和
- $X \sim N(1,4)$、$Y \sim N(2,9)$ 独立 ⇒ $X+Y \sim N(3,13)$；
- $E[X+Y] = 3$，$\text{var}(X+Y) = 13$（直接相加）。

### 例 4：房地产投资组合（p131，讲义 p13）
- 某公司在 10 个州各投 10M 元，州 $i$ 的回报率 $X_i$ 均值 1、标准差 1.3（百万）；
- 若各州独立（不相关）：$\text{var}(\sum X_i) = 10 \times 1.3^2 = 16.9$，总标准差 $\approx 4.11$；
- 若任意两州 $\rho(X_i,X_j)=0.9$（同涨同跌）：$\text{cov}(X_i,X_j)=0.9\times1.3^2=1.521$，共 $10\times9=90$ 个有序对，
$$\text{var}\!\left(\sum X_i\right) = 16.9 + 90\times1.521 \approx 153.8$$
总标准差 $\approx 12.4$。
- 解读：高度相关时分散化几乎不降低风险（总波动从 4.1 暴涨到 12.4）；这就是"不要把鸡蛋放在高度相关的篮子里"。

## 5. 本节重点

> **本节重点**：
> - 独立和 = 卷积（离散求和/连续积分）；机械法 = 翻转 $Y$、平移 $z$、对应相乘相加；独立正态和仍是正态（参数相加）。
> - 协方差 = $E[XY]-E[X]E[Y]$，双线性；相关系数 = $\text{cov}/(\sigma_X\sigma_Y) \in [-1,1]$，无量纲、对仿射变换不变。
> - $\text{var}(X+Y) = \text{var}(X)+\text{var}(Y)+2\text{cov}(X,Y)$；独立时协方差项消失。
> - $|\rho|=1$ ⇔ 严格线性关系；$\rho=0$ 只表示无线性关系。
> - **常见坑**：① 协方差为 0 ≠ 独立（非线性依赖可能躲过协方差）；② 相关系数只度量线性关系，不等于因果，共同隐因子可制造相关；③ 独立和的方差直接相加没问题，但不独立时漏掉 $2\text{cov}$ 项；④ 算 $n$ 个变量的交叉协方差时漏了"有序对 $i\ne j$ 共 $n(n-1)$ 个"。
