## 1. 核心概念

### 1.1 经典（频率学派）统计框架
- 未知参数 $\theta$ 是**固定常数**（不是随机变量，区别于贝叶斯）；
- 观测 $X_1,\dots,X_n$ i.i.d. 来自分布族 $f_\theta$；
- 目标是设计**估计量** $\hat\Theta = g(X_1,\dots,X_n)$（数据的函数）。

### 1.2 三种常用估计
- **样本均值** $\hat\mu = \bar X = \frac{1}{n}\sum X_i$；
- **样本方差** $S^2 = \frac{1}{n-1}\sum (X_i - \bar X)^2$（$n-1$ 修正无偏性）；
- **极大似然估计（MLE）** $\hat\theta_{MLE} = \arg\max_\theta L(\theta)$，$L(\theta) = \prod_i f_\theta(x_i)$。

### 1.3 置信区间
用数据给出"大概率包含 $\theta$"的区间：
$$P(\theta \in [\hat\theta - \delta, \hat\theta + \delta]) \approx 1 - \alpha$$

## 2. 公式与定义

### 2.1 估计量的评价
$$\text{MSE}(\hat\theta) = E[(\hat\theta - \theta)^2] = \text{var}(\hat\theta) + \text{bias}(\hat\theta)^2$$
其中 bias $= E[\hat\theta] - \theta$。
- 无偏：bias = 0；有效：方差小；
- 有时有偏但方差更小（如收缩估计）整体 MSE 更优。

### 2.2 均值的置信区间（方差已知）
- $\bar X \approx N(\mu, \sigma^2/n)$（CLT）；
- $\mu$ 的 $(1-\alpha)$ 置信区间：
$$\left[\bar X - z_{\alpha/2}\frac{\sigma}{\sqrt n},\ \bar X + z_{\alpha/2}\frac{\sigma}{\sqrt n}\right]$$
- $z_{\alpha/2}$ 是标准正态 $\alpha/2$ 上分位点（95% 时 ≈ 1.96）。

### 2.3 方差未知时的置信区间
- 用样本标准差 $s$ 替代 $\sigma$，且用 $t$ 分布：
$$\left[\bar X - t_{n-1,\alpha/2}\frac{s}{\sqrt n},\ \bar X + t_{n-1,\alpha/2}\frac{s}{\sqrt n}\right]$$
- 大 $n$ 时 $t_{n-1} \approx N(0,1)$；小样本重尾更宽。

### 2.4 极大似然
- 似然函数：$L(\theta) = \prod_{i=1}^n f_\theta(x_i)$（连续为 PDF、离散为 PMF）；
- 对数似然 $\ell(\theta) = \sum_i \ln f_\theta(x_i)$（乘积变求和，单调同解）；
- MLE：$\hat\theta = \arg\max \ell(\theta)$（求导置零 + 验证）。

## 3. 关键性质

### 3.1 常用 MLE
- 伯努利/二项 $p$：$\hat p = \bar x$（成功比例）；
- 正态 $\mu$：$\hat\mu = \bar x$；正态 $\sigma^2$：$\hat\sigma^2 = \frac{1}{n}\sum(x_i-\bar x)^2$（注意是 $n$ 不是 $n-1$，MLE 有偏）；
- 均匀 $U[0,\theta]$：$\hat\theta = \max_i x_i$（极大次序统计量；有偏但渐近无偏）。

### 3.2 MLE 渐近性质
- 相合性：$n \to \infty$ 时 $\hat\theta_{MLE} \to \theta$（依概率）；
- 渐近正态：$\hat\theta_{MLE} \approx N(\theta,\ \text{CRLB}/n)$（效率最优）；
- 不变性：$\hat{g(\theta)}_{MLE} = g(\hat\theta_{MLE})$（参数函数直接代）。

### 3.3 频率学派置信区间的解读
- 反复抽样中，约 $1-\alpha$ 比例的区间包含真实 $\theta$（"覆盖概率"）；
- **不是**"$\theta$ 落在这个区间的概率是 95%"（那是贝叶斯可信区间语言）。

## 4. 例题

### 例 1：正态均值的置信区间
- $n = 25$，$\bar x = 10$，$\sigma = 2$：95% CI = $10 \pm 1.96\cdot\frac{2}{5} = [9.216, 10.784]$。

### 例 2：方差未知
- 同例但 $s = 2.2$，$n=25$：查 $t_{24,0.025} \approx 2.064$：$10 \pm 2.064\cdot\frac{2.2}{5} = [9.092, 10.908]$（略宽于方差已知）。

### 例 3：伯努利 MLE
- 观测 7 次成功、3 次失败：$\ell(p) = 7\ln p + 3\ln(1-p)$；
- $\frac{d\ell}{dp} = \frac{7}{p} - \frac{3}{1-p} = 0 \Rightarrow p = 0.7$。

### 例 4：均匀 MLE
- $U[0,\theta]$，观测 0.3、0.8、0.5：$L(\theta) = 1/\theta^3$（$\theta \ge 0.8$），$\theta$ 越小似然越大 ⇒ $\hat\theta = 0.8 = \max x_i$。

## 5. 本节重点

> **本节重点**：
> - 经典估计三件套：样本均值、样本方差（$n-1$）、MLE；MSE = 方差 + bias²。
> - 置信区间：已知方差用正态 $z$、未知方差用 $t_{n-1}$；宽度 ∝ $1/\sqrt n$。
> - MLE = 最大化（对数）似然；常用结果：$p \to \bar x$、$\mu\to\bar x$、均匀 → $\max x_i$。
> - 区间解读是"覆盖概率"，不是"参数概率"。
> - **常见坑**：① 样本方差用 $n$ 还是 $n-1$ 分不清（$n-1$ 无偏、MLE 用 $n$）；② 方差未知时用 $z$ 表；③ 置信区间当贝叶斯可信区间解读。
