## 1. 核心概念

### 1.1 估计问题的最优准则
用 $\hat\Theta$ 估计 $\Theta$，误差 $\hat\Theta - \Theta$。衡量"好坏"用**均方误差**：
$$E[(\hat\Theta - \Theta)^2]$$
准则：让 MSE 尽量小。

### 1.2 无观测时：常数估计
没有数据时只能选常数 $\hat\Theta = c$：
$$E[(\Theta - c)^2] = \text{var}(\Theta) + (E[\Theta]-c)^2$$
最小值在 $c = E[\Theta]$ 取得，最小 MSE = $\text{var}(\Theta)$。

### 1.3 有观测时：条件期望估计（LMS）
给定 $X = x$，MSE 最优估计是**后验条件均值**：
$$\hat\Theta = E[\Theta \mid X = x]$$
- 这是"给定信息 $X$ 后对 $\Theta$ 的最佳猜测"；
- 对应的条件 MSE：$\text{var}(\Theta \mid X = x)$。

## 2. 公式与定义

### 2.1 LMS 估计量（函数形式）
$$\hat\Theta = g(X) = E[\Theta \mid X]$$
（把 $E[\Theta \mid X=x]$ 对所有 $x$ 拼成一个函数 $g$。）

### 2.2 LMS 性能
$$E[(\Theta - g(X))^2] = E[\text{var}(\Theta \mid X)] = \text{var}(\Theta) - \text{var}(E[\Theta \mid X])$$
（由全方差法则：观测 $X$ 把不确定性从 $\text{var}(\Theta)$ 降到 $E[\text{var}(\Theta \mid X)]$。）

### 2.3 多个观测 / 多个未知量
- 多个观测：$g(x_1,\dots,x_n) = E[\Theta \mid X_1=x_1,\dots,X_n=x_n]$；
- 多个未知量：对每个 $\Theta_i$ 分别用 $E[\Theta_i \mid X]$（逐分量最优）。

### 2.4 正态-正态闭式（承 L15）
$\Theta \sim N(\mu_0,\sigma_0^2)$、$X = \Theta + W$、$W \sim N(0,\sigma_W^2)$：
$$\text{LMS: } \hat\theta = \frac{\frac{\mu_0}{\sigma_0^2} + \frac{x}{\sigma_W^2}}{\frac{1}{\sigma_0^2} + \frac{1}{\sigma_W^2}}, \qquad \text{条件MSE} = \frac{1}{\frac{1}{\sigma_0^2} + \frac{1}{\sigma_W^2}}$$

## 3. 关键性质

### 3.1 为什么条件期望最优（直观）
对任意函数 $g$：
$$E[(\Theta - g(X))^2] = E[(\Theta - E[\Theta \mid X])^2] + E[(E[\Theta \mid X] - g(X))^2] \ge E[\text{var}(\Theta \mid X)]$$
第一项是"信息极限"，第二项是偏离条件均值的额外代价（非负）。

### 3.2 估计误差的性质
- 误差 $\epsilon = \Theta - E[\Theta \mid X]$ 满足 $E[\epsilon] = 0$（无偏）；
- $E[\epsilon \cdot h(X)] = 0$ 对任意 $h$（误差与"数据能看到的一切"正交）；
- 误差方差 = 条件 MSE = $E[\text{var}(\Theta \mid X)]$。

### 3.3 观测的边际价值
- 观测只会降低（或不改变）MSE：$\text{var}(\Theta) \ge E[\text{var}(\Theta \mid X)]$；
- 完全不相关的 $X$：$E[\Theta \mid X] = E[\Theta]$，观测无增益。

## 4. 例题

### 例 1：无观测（常数估计）
- $\Theta \sim N(3, 16)$：最优常数估计 $\hat\Theta = 3$，MSE = 16。

### 例 2：离散例
- 联合表 $p_{\Theta,X}$：$\Theta \in \{1,2\}$、$X \in \{0,1\}$（以图/表概率为准）；
- $g(0) = E[\Theta \mid X=0] = 1\cdot p_{\Theta\mid X}(1\mid0) + 2\cdot p_{\Theta\mid X}(2\mid0)$，$g(1)$ 同理；
- LMS 估计器：观测到 0 就猜 $g(0)$，观测到 1 就猜 $g(1)$；
- 性能：$E[\text{var}(\Theta\mid X)]$ 逐 $x$ 加权。

### 例 3：正态-正态
- $\Theta \sim N(1, 4)$，$W \sim N(0, 9)$，$X = \Theta + W$，观测 $X = 4$：
- $\hat\theta = \frac{1/4\cdot1 + 1/9\cdot4}{1/4 + 1/9} = \frac{0.25 + 0.444}{0.361} \approx 1.92$；
- 条件 MSE $= \frac{1}{1/4 + 1/9} = \frac{36}{13} \approx 2.77$。

---

## 5. 本节重点

> **本节重点**：
> - LMS = 后验条件均值 $E[\Theta \mid X]$；MSE 意义下不可超越。
> - 无观测最优 = $E[\Theta]$（MSE = 方差）；有观测条件 MSE = $E[\text{var}(\Theta \mid X)]$（全方差分解）。
> - 误差零均值、与数据正交；观测永不增加 MSE。
> - 正态-正态：LMS 闭式为精度加权平均（L15 公式复用）。
> - **常见坑**：① 用后验众数（MAP）代替后验均值；② 把条件 MSE 算成 $\text{var}(\Theta\mid X)$ 对 $x$ 求平均时漏权重 $p_X(x)$；③ 忘记 LMS 是针对"平方损失"的最优——换损失函数最优估计不同。
