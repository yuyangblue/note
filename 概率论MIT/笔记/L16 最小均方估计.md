## 1. 核心概念

### 1.1 估计问题的最优准则
用 $\hat\Theta$ 估计 $\Theta$，误差 $\hat\Theta - \Theta$。衡量"好坏"用**均方误差**：
$$E[(\hat\Theta - \Theta)^2]$$
准则：让 MSE 尽量小。

> 老师强调（p164）：LMS 只适用于**估计**问题（连续未知量），不适用于假设检验——后者的目标是最小化错误概率，不是 MSE。

### 1.2 无观测时：常数估计
没有数据时只能选常数 $\hat\Theta = c$：
$$E[(\Theta - c)^2] = \text{var}(\Theta) + (E[\Theta]-c)^2$$
最小值在 $c = E[\Theta]$ 取得，最小 MSE = $\text{var}(\Theta)$。

> **两种推导**（p164）：① 微积分法：展开 $E[(\Theta-c)^2] = E[\Theta^2] - 2cE[\Theta] + c^2$，对 $c$ 求导令零得 $c = E[\Theta]$；② 方差分解法：$E[(\Theta-c)^2] = \text{var}(\Theta) + (E[\Theta]-c)^2$，第一项与 $c$ 无关，第二项在 $c = E[\Theta]$ 时为零。
>
> 老师的热身例：$\Theta \sim U[4,10]$。MAP 在均匀分布上不唯一（整个区间都是平的），但 LMS 唯一给出 $c = 7$（中点）。最小 MSE = var = $6^2/12 = 3$。

### 1.3 有观测时：条件期望估计（LMS）
给定 $X = x$，MSE 最优估计是**后验条件均值**：
$$\hat\Theta = E[\Theta \mid X = x]$$
- 这是"给定信息 $X$ 后对 $\Theta$ 的最佳猜测"；
- 对应的条件 MSE：$\text{var}(\Theta \mid X = x)$。

> 老师的核心论证（p165）："条件概率和普通概率没有本质区别，只是换了个宇宙。在'已知 $X=x$'的新宇宙里，无观测时的结论原样搬过来——最优估计就是新宇宙里的均值，即条件期望。"然后用迭代期望定律从逐点最优推出全局最优：对每个 $x$ 都最优 ⇒ 对所有 $x$ 的加权平均也最优。

## 2. 公式与定义

### 2.1 LMS 估计量（函数形式）
$$\hat\Theta = g(X) = E[\Theta \mid X]$$
（把 $E[\Theta \mid X=x]$ 对所有 $x$ 拼成一个函数 $g$。）

### 2.2 LMS 性能
$$E[(\Theta - g(X))^2] = E[\text{var}(\Theta \mid X)] = \text{var}(\Theta) - \text{var}(E[\Theta \mid X])$$
（由全方差法则：观测 $X$ 把不确定性从 $\text{var}(\Theta)$ 降到 $E[\text{var}(\Theta \mid X)]$。）

> 老师的解释（p166）："如果你给老板报方案性能（还没拿到数据），报的是 $E[\text{var}(\Theta \mid X)]$——对所有可能 $x$ 的条件方差求平均。如果你已经拿到了具体数据 $x$，报的是 $\text{var}(\Theta \mid X=x)$——这就是那个具体观测值下的剩余不确定性。"

### 2.3 多个观测 / 多个未知量
- 多个观测：$g(x_1,\dots,x_n) = E[\Theta \mid X_1=x_1,\dots,X_n=x_n]$；
- 多个未知量：对每个 $\Theta_i$ 分别用 $E[\Theta_i \mid X]$（逐分量最优）。

> **实际困难**（p169）：老师警告——LMS 理论上完美，但实际计算时要算高维积分（贝叶斯分母 + 条件期望），"多维积分可能根本算不动"。这正是 L17 线性 LMS 的动机：退一步，只在线性函数类里找最优。

### 2.4 正态-正态闭式（承 L15）
$\Theta \sim N(\mu_0,\sigma_0^2)$、$X = \Theta + W$、$W \sim N(0,\sigma_W^2)$：
$$\text{LMS: } \hat\theta = \frac{\frac{\mu_0}{\sigma_0^2} + \frac{x}{\sigma_W^2}}{\frac{1}{\sigma_0^2} + \frac{1}{\sigma_W^2}}, \qquad \text{条件MSE} = \frac{1}{\frac{1}{\sigma_0^2} + \frac{1}{\sigma_W^2}}$$

> **MAP = LMS 的条件**（p166）：当后验分布单峰且关于均值对称时（如正态后验），MAP 和 LMS 重合。这就是为什么 L15 线性正态模型里两个估计器相同。

## 3. 关键性质

### 3.1 为什么条件期望最优（直观）
对任意函数 $g$：
$$E[(\Theta - g(X))^2] = E[(\Theta - E[\Theta \mid X])^2] + E[(E[\Theta \mid X] - g(X))^2] \ge E[\text{var}(\Theta \mid X)]$$
第一项是"信息极限"，第二项是偏离条件均值的额外代价（非负）。

### 3.2 估计误差的性质
- 误差 $\tilde\Theta = \Theta - E[\Theta \mid X]$ 满足 $E[\tilde\Theta] = 0$（无偏）；
- **更强**：$E[\tilde\Theta \mid X] = 0$——不仅整体无偏，对每个具体观测 $x$ 条件误差均值都是零（p170）；
- $E[\tilde\Theta \cdot h(X)] = 0$ 对任意 $h$（误差与"数据能看到的一切"正交）；
- 误差方差 = 条件 MSE = $E[\text{var}(\Theta \mid X)]$。

> 老师的推导（p170）：已知 $X=x$ 时 $\hat\Theta = E[\Theta \mid X=x]$ 是常数，所以 $E[\hat\Theta - \Theta \mid X=x] = \hat\Theta - E[\Theta \mid X=x] = 0$。然后对任意 $h(X)$，$E[(\hat\Theta - \Theta)h(X)] = E[E[(\hat\Theta - \Theta)h(X) \mid X]] = E[h(X) \cdot 0] = 0$。
>
> **方差分解**（p170）：$\Theta = \hat\Theta - \tilde\Theta$，且 $\hat\Theta$ 与 $\tilde\Theta$ 不相关（协方差为零），所以 $\text{var}(\Theta) = \text{var}(\hat\Theta) + \text{var}(\tilde\Theta)$。老师："这就是全方差法则的另一种写法——估计量吸收了多少不确定性，就有多大方差；剩下的就是误差。"

### 3.3 观测的边际价值
- 观测只会降低（或不改变）MSE：$\text{var}(\Theta) \ge E[\text{var}(\Theta \mid X)]$；
- 完全不相关的 $X$：$E[\Theta \mid X] = E[\Theta]$，观测无增益。

## 4. 例题

### 例 1：无观测（常数估计）
- $\Theta \sim U[4,10]$：最优常数估计 $\hat\Theta = 7$（中点），MSE = var = $6^2/12 = 3$。
- 对比 MAP：均匀分布上 MAP 不唯一，LMS 给出唯一答案。

### 例 2：U[4,10] + 均匀噪声（讲义 p8-9，p167-p168）
- $\Theta \sim U[4,10]$，$X = \Theta + U$，$U \sim U[-1,1]$，$\Theta$ 与 $U$ 独立；
- 联合 PDF 在 $\theta \in [4,10]$ 且 $\theta-1 \le x \le \theta+1$ 的区域上为常数 $1/12$（面积 = 12）；
- 给定 $X=x$，$\Theta$ 的后验在区间 $[\max(4,x-1), \min(10,x+1)]$ 上均匀分布；
- **LMS 估计** = 该区间中点，是一段**分段线性**函数（不是一条直线！）；
- **条件 MSE** = 均匀分布方差 = $L^2/12$：
  - $5 \le x \le 9$：区间长 2，方差 = $4/12 = 1/3$（常数）；
  - $x = 3$ 或 $x = 11$：区间长 0，方差 = 0（观测极端值反而完全确定 $\Theta$）；
  - $3 < x < 5$ 或 $9 < x < 11$：方差从 0 二次增长到 $1/3$。

> 老师强调（p168）："这个例子和正态模型形成对比——正态模型里条件 MSE 与 $x$ 无关，但这里某些观测值（如 $x=3$）比另一些（如 $x=6$）信息量大得多。有些 $x$ 让你完全确定 $\Theta$，有些 $x$ 留下很多不确定性。"

### 例 3：正态-正态
- $\Theta \sim N(1, 4)$，$W \sim N(0, 9)$，$X = \Theta + W$，观测 $X = 4$：
- $\hat\theta = \frac{1/4\cdot1 + 1/9\cdot4}{1/4 + 1/9} = \frac{0.25 + 0.444}{0.361} \approx 1.92$；
- 条件 MSE $= \frac{1}{1/4 + 1/9} = \frac{36}{13} \approx 2.77$。

## 5. 本节重点

> **本节重点**：
> - LMS = 后验条件均值 $E[\Theta \mid X]$；MSE 意义下不可超越。
> - 无观测最优 = $E[\Theta]$（MSE = 方差）；有观测条件 MSE = $E[\text{var}(\Theta \mid X)]$（全方差分解）。
> - 误差零均值（条件于每个 $x$ 都是零）、与数据正交；观测永不增加 MSE。
> - 正态-正态：LMS 闭式为精度加权平均（L15 公式复用）；MAP = LMS 当后验对称单峰。
> - **常见坑**：① 用后验众数（MAP）代替后验均值；② 把条件 MSE 算成 $\text{var}(\Theta\mid X)$ 对 $x$ 求平均时漏权重 $p_X(x)$；③ 忘记 LMS 是针对"平方损失"的最优——换损失函数最优估计不同；④ 以为 LMS 估计一定是线性的——一般是非线性分段函数（如例 2）。
