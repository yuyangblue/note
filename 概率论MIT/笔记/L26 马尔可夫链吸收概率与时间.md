## 1. 核心概念

### 1.1 吸收链
存在**吸收态**（$p_{aa}=1$），一旦进入永不离开。关注两件事：
1. **吸收概率**：从某个暂态出发，最终被吸收到各吸收态的概率；
2. **期望吸收时间**：从暂态出发到被吸收所需的平均步数。

### 1.2 方法：一步条件（首步分解）
对"吸收概率"和"期望吸收时间"都使用"看第一步"的递归方程——条件于第一步去了哪，把问题化为更小的问题。

---

## 2. 公式与定义

### 2.1 吸收概率（一维）
设 $a_i$ = 从状态 $i$ 出发最终被吸收到目标吸收态的概率：
$$a_i = \sum_j p_{ij} a_j, \qquad a_{\text{目标吸收态}} = 1, \quad a_{\text{其他吸收态}} = 0$$
解线性方程组即得。

### 2.2 期望吸收时间（一维）
设 $\mu_i$ = 从状态 $i$ 出发到吸收的期望步数：
$$\mu_i = 1 + \sum_{j \ne \text{吸收}} p_{ij} \mu_j, \qquad \mu_{\text{吸收态}} = 0$$
解线性方程组即得。

### 2.3 电话系统设计（多维示例）
- 多个中继线（状态 = 占用线数，$0,1,\dots,M$）：
- 到达率 $\lambda$、服务率 $\mu$（生灭链，$M$ 条线）：
  - 转移：$i \to i+1$（$\lambda$，$i<M$）、$i \to i-1$（$i\mu$ 或 $\mu$，$i\ge1$）；
  - 平稳分布 $\pi_i$（生灭公式）；
  - **阻塞概率** = $P(\text{全部 } M \text{ 线忙}) = \pi_M$（呼叫被拒）；
- 设计问题：给定可接受阻塞率（如 <2%），求最少线数 $M$。

## 3. 关键性质

### 3.1 平均首达时间（mean first passage time）
- 从状态 $i$ 首次到达状态 $j$ 的期望步数 $m_{ij}$：
$$m_{ij} = 1 + \sum_{k \ne j} p_{ik} m_{kj}, \qquad m_{jj} = 0$$
- 与平稳分布的关系：$m_{jj} = 1/\pi_j$（常返链返回自身的平均时间 = 平稳概率倒数）。

### 3.2 赌徒破产（经典吸收问题）
- 赌徒有 $i$ 元，每次以 $p$ 赢 1 元、$q=1-p$ 输 1 元；破产（0）或到 $N$ 停止；
- 吸收概率 $a_i = P(\text{先到 } N \text{ 而非 } 0)$：
$$a_i = \frac{1 - (q/p)^i}{1 - (q/p)^N}, \quad p \ne q; \qquad a_i = \frac{i}{N}, \quad p = q$$
- 期望吸收时间：
$$\mu_i = \begin{cases} \dfrac{i}{q-p} - \dfrac{N}{q-p}\cdot\dfrac{1-(q/p)^i}{1-(q/p)^N}, & p \ne q \\ i(N-i), & p = q \end{cases}$$

### 3.3 结论（重要警示）
- 公平游戏（$p = q = 1/2$）：破产概率 $1 - i/N$，期望吸收时间 $i(N-i)$——即使公平，久赌也几乎必然破产；
- 轻微不利（$p < q$）：破产概率迅速趋近 1；
- 这就是"赌场永远不会亏"的概率论根源。

## 4. 例题

### 例 1：吸收概率（两吸收态）
- 状态 0（吸收）、1、2、3（吸收），转移：从 1 以 0.5 去 0、0.5 去 2；从 2 以 0.5 去 1、0.5 去 3：
- $a_1 = 0.5\cdot1 + 0.5 a_2$，$a_2 = 0.5 a_1 + 0.5\cdot1$；
- 解得 $a_1 = a_2 = 1$（最终必然到 3 或 0 之一，这里到 0 概率各为 1/2？——实际 $a_1$=到 0 的概率：$a_1 = 0.5 + 0.5(0.5a_1 + 0.5\cdot0)$ ⇒ $a_1 = 2/3$）。

### 例 2：期望吸收时间
- 续上例：$\mu_1 = 1 + 0.5\mu_2$，$\mu_2 = 1 + 0.5\mu_1$ ⇒ $\mu_1 = \mu_2 = 2$ 步。

### 例 3：赌徒破产
- $i = 10, N = 20, p = 0.5$：赢到 20 的概率 $10/20 = 0.5$；期望时间 $10\cdot10 = 100$ 步；
- $p = 0.49$：$q/p \approx 1.0204$，$a_i = \frac{1 - 1.0204^{10}}{1 - 1.0204^{20}} \approx 0.381$——仅 1% 劣势就把赢面从 0.5 压到 0.38。

### 例 4：电话系统
- 10 条线、$\lambda/\mu = 0.9$：Erlang 损失公式给阻塞率 $\approx 0.005$（<1%）；
- 若阻塞率要求 <2%，可计算最少线数；加线降低阻塞但增加成本（权衡）。

## 5. 本节重点

> **本节重点**：
> - 吸收概率/期望吸收时间：**首步分解 + 线性方程组**，边界条件（吸收态=1 或 0）。
> - 平均首达时间 $m_{jj} = 1/\pi_j$。
> - 赌徒破产闭式：$a_i = \frac{1-(q/p)^i}{1-(q/p)^N}$（$p\ne q$）、$i/N$（$p=q$）；公平赌局期望时间 $i(N-i)$。
> - 电话系统：生灭 + 阻塞概率 $\pi_M$，用平稳分布做容量设计。
> - **常见坑**：① 方程组边界条件写错（吸收态的 $\mu=0$、$a=1/0$）；② $p=q$ 的 $q/p$ 退化情形要单列；③ 忘记"吸收概率三件事一起解"（每个吸收目标一组方程）。
