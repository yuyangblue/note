## 1. 核心概念

### 1.1 吸收链
存在**吸收态**（$p_{aa}=1$），一旦进入永不离开。关注两件事：
1. **吸收概率**：从某个暂态出发，最终被吸收到各吸收态的概率；
2. **期望吸收时间**：从暂态出发到被吸收所需的平均步数。

### 1.2 方法：一步条件（首步分解）
对"吸收概率"和"期望吸收时间"都使用"看第一步"的递归方程——条件于第一步去了哪，把问题化为更小的问题（全概率/全期望定理）。

### 1.3 平稳近似的使用与混合时间
- 单常返类 + 非周期时，$X_n$ 与 $X_0$ 在 $n\to\infty$ 时近似独立：$P(X_{100}=1,X_{200}=1\mid X_0=1)\approx\pi_1\cdot\pi_1$。
- 但只有 $n$ 大到"起点被遗忘"才好用：若自环概率极小（如 0.001），平均要 ~1000 步才离开该态，混合很慢，需 $n\sim10^4$ 才能套平稳近似。

## 2. 公式与定义

### 2.1 吸收概率（一维）
设 $a_i$ = 从状态 $i$ 出发最终被吸收到目标吸收态的概率：
$$a_i=\sum_j p_{ij}a_j,\qquad a_{\text{目标吸收态}}=1,\quad a_{\text{其他吸收态}}=0$$
- 边界：从目标吸收态出发 $a=1$；从别的吸收态出发 $a=0$。
- 若吸收"团块"含多个状态，把整个团块合并成一个吸收态（把进入团块的概率相加）。
- 解线性方程组即得，唯一解。

### 2.2 期望吸收时间（一维）
设 $\mu_i$ = 从状态 $i$ 出发到吸收的期望步数：
$$\mu_i=1+\sum_{j\ne\text{吸收}}p_{ij}\mu_j,\qquad \mu_{\text{吸收态}}=0$$
- 多出的"1"是第一步本身要花的那一步。
- 多个吸收态时，把它们合并成一个"已吸收"态再套上式。

### 2.3 电话系统设计（Erlang，多维生灭）
- 模型：呼叫按泊松过程 $\lambda$ 到达，通话时长 $\sim\mathrm{Exp}(\mu)$；离散化到 $\delta$ 微槽。状态 = 忙线数 $0,1,\dots,B$。
- 转移：上行（新呼叫）概率 $\lambda\delta$；下行（某条通话结束）$i$ 条忙线 ⇒ $i\mu\delta$。这是生灭链。
- 局部平衡切边：$\lambda\delta\,\pi(i-1)=i\mu\delta\,\pi(i)$，消去 $\delta$ 得
$$\pi(i)=\pi(0)\frac{(\lambda/\mu)^i}{i!},\qquad \pi(0)=\left(\sum_{i=0}^{B}\frac{(\lambda/\mu)^i}{i!}\right)^{-1}$$
- **阻塞概率** = $P(\text{全部 }B\text{ 线忙})=\pi(B)$，即 **Erlang B 公式**（呼叫被拒）。
- 设计问题：给定可接受阻塞率（如 <1%），求最少线数 $B$。Erlang 在马尔可夫链发明前就从第一性原理解出了它。

## 3. 关键性质

### 3.1 平均首达时间与回归时间
- **首达时间**：从状态 $i$ 首次到达指定态 $s$ 的期望步数 $m_{is}$。把 $s$ 的出边改成自环（变吸收态）后，用吸收时间公式算：$m_{is}=1+\sum_{k\ne s}p_{ik}m_{ks}$，$m_{ss}=0$。
- **回归时间**：从 $s$ 出发首次回到 $s$ 的期望。注意它 $m_{ss}\ne0$（至少要走一步）。
- 与平稳分布的关系：常返链中 $m_{ss}=1/\pi_s$（返回自身的平均时间 = 平稳概率倒数）。

### 3.2 赌徒破产（经典吸收问题）
- 赌徒有 $i$ 元，每次以 $p$ 赢 1 元、$q=1-p$ 输 1 元；破产（0）或到 $N$ 停止；
- 吸收概率 $a_i=P(\text{先到 }N\text{ 而非 }0)$：
$$a_i=\frac{1-(q/p)^i}{1-(q/p)^N},\quad p\ne q;\qquad a_i=\frac{i}{N},\quad p=q$$
- 期望吸收时间：
$$\mu_i=\begin{cases}\dfrac{i}{q-p}-\dfrac{N}{q-p}\cdot\dfrac{1-(q/p)^i}{1-(q/p)^N},&p\ne q\\ i(N-i),&p=q\end{cases}$$

### 3.3 结论（重要警示）
- 公平游戏（$p=q=1/2$）：破产概率 $1-i/N$，期望吸收时间 $i(N-i)$——即使公平，久赌也几乎必然破产；
- 轻微不利（$p<q$）：破产概率迅速趋近 1；
- 这就是"赌场永远不会亏"的概率论根源。

## 4. 例题

### 例 1：吸收概率（两吸收态）
- 状态 0（吸收）、1、2、3（吸收），转移：从 1 以 0.5 去 0、0.5 去 2；从 2 以 0.5 去 1、0.5 去 3；
- 求最终被吸收到状态 0 的概率（$a_i$ = 从 $i$ 出发最终到 0 的概率）：
$$a_1=0.5\cdot1+0.5a_2,\qquad a_2=0.5a_1+0.5\cdot0$$
- 代入解得 $a_1=2/3$、$a_2=1/3$——从状态 1 出发最终到 0 的概率 2/3（到 3 的概率 1/3）。

### 例 2：期望吸收时间
- 续上例：$\mu_1=1+0.5\mu_2$，$\mu_2=1+0.5\mu_1$ ⇒ $\mu_1=\mu_2=2$ 步。

### 例 3：赌徒破产
- $i=10,\ N=20,\ p=0.5$：赢到 20 的概率 $10/20=0.5$；期望时间 $10\cdot10=100$ 步；
- $p=0.49$：$q/p\approx1.0408$，$a_i=\dfrac{1-1.0408^{10}}{1-1.0408^{20}}\approx0.40$——仅 1% 劣势就把赢面从 0.5 压到 0.40。

### 例 4：电话系统（Erlang B）
- $\lambda=30/\text{min}$、$\mu=1/3/\text{min}$（平均通话 3 分钟）：平均忙线数 $=\lambda\cdot(1/\mu)=90$；
- 但为防随机波动，把阻塞率压到 ~1% 需约 $B=106$ 条线（比平均 90 留出余量）；
- 加线降低阻塞但增加成本（权衡）。

## 6. 扩展：连续时间马尔可夫链（依据教材第 7.5 节；视频 L26 未讲，超出 6.041SC 范围）

- **定义**：状态 $i$ 的**停留时间**服从指数分布 $\text{Exp}(\nu_i)$（参数只依赖当前状态），离开后以概率 $p_{ij}$ 跳到状态 $j$；指数分布的无记忆性保证"未来只依赖当前状态"，即马尔可夫性在连续时间下成立。
- **速率描述（等价形式）**：给定当前状态 $i$，$\delta$ 时间后处于 $j$（$j\ne i$）的概率为 $q_{ij}\delta+o(\delta)$，其中 $q_{ij}=\nu_i p_{ij}$ 称为**转移速率**；$\nu_i=\sum_{j\ne i}q_{ij}$。
- **稳态方程（与离散链类比）**：单回归类时，稳态概率 $\pi_j$ 满足"流出速率 = 流入速率"：
$$\pi_j\sum_{k\ne j}q_{jk}=\sum_{k\ne j}\pi_k q_{kj},\qquad \sum_{k=1}^m\pi_k=1$$
暂态状态 $\pi_j=0$，回归状态 $\pi_j>0$。离散链的平衡方程 $\pi_j=\sum_k\pi_k p_{kj}$ 对应这里的"速率平衡"版本。
- **应用**：排队系统（服务台忙/闲）、电话线路占用数、生灭过程都常用 CTMC 建模——L26 例 4 的 Erlang 公式正是这类模型的产物。

## 5. 本节重点

> **本节重点**：
> - 吸收概率/期望吸收时间：**首步分解 + 线性方程组**，边界条件（吸收态 $a=1/0$、$\mu=0$）；多吸收态先合并。
> - 平均首达时间 $m_{ss}=1/\pi_s$；回归时间 $m_{ss}\ne0$。
> - 赌徒破产闭式：$a_i=\frac{1-(q/p)^i}{1-(q/p)^N}$（$p\ne q$）、$i/N$（$p=q$）；公平赌局期望时间 $i(N-i)$。
> - 电话系统：生灭 + Erlang B 阻塞概率 $\pi(B)=\pi(0)(\lambda/\mu)^B/B!$，用平稳分布做容量设计。
> - **常见坑**：① 方程组边界条件写错（吸收态的 $\mu=0$、$a=1/0$）；② $p=q$ 的 $q/p$ 退化情形要单列；③ 忘记"吸收概率每个吸收目标一组方程"；④ 用平稳近似时忽略混合时间是否足够长。
