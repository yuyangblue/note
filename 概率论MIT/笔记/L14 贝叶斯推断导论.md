## 1. 核心概念

### 1.1 推断问题的两类任务
- **估计**：根据观测数据推断未知参数的值（点估计/区间估计）；
- **假设检验**：在多个可能假设之间做选择。

### 1.2 贝叶斯推断框架
把未知参数当作**随机变量** $\Theta$：
1. **先验** $p_\Theta(\theta)$ 或 $f_\Theta(\theta)$：观测前对参数的信念；
2. **观测模型** $p_{X \mid \Theta}$ 或 $f_{X \mid \Theta}$：给定参数下数据如何产生；
3. **后验** $p_{\Theta \mid X}(\theta \mid x)$：观测后更新信念——由贝叶斯法则计算。

### 1.3 点估计的常用选择
- **最大后验（MAP）**：使后验最大的 $\theta$；
- **条件期望估计（LMS）**：$E[\Theta \mid X = x]$（后验均值，最小均方误差，见 L16）。

## 2. 公式与定义

### 2.1 贝叶斯法则（推断形式）
$$p_{\Theta \mid X}(\theta \mid x) = \frac{p_\Theta(\theta) p_{X \mid \Theta}(x \mid \theta)}{p_X(x)}, \qquad p_X(x) = \sum_\theta p_\Theta(\theta) p_{X \mid \Theta}(x \mid \theta)$$
连续参数版本把求和换积分、PMF 换 PDF。

### 2.2 贝塔分布（硬币偏置的共轭先验）
$$\text{Beta}(a,b): \quad f_\Theta(\theta) = c\, \theta^{a-1}(1-\theta)^{b-1}, \quad 0 \le \theta \le 1$$
- 归一化常数 $c = \frac{\Gamma(a+b)}{\Gamma(a)\Gamma(b)}$；
- 均值 $E[\Theta] = \frac{a}{a+b}$；
- 特例：$a=b=1$ 即 $U[0,1]$（无信息先验）。

### 2.3 推断硬币偏置（核心示例）
- $\Theta \sim U[0,1]$（先验），$X \mid \Theta \sim \text{Binomial}(n,\Theta)$；
- 观测到 $k$ 次正面后，后验：
$$f_{\Theta \mid X}(\theta \mid k) = c'\, \theta^{k}(1-\theta)^{n-k} \sim \text{Beta}(k+1,\ n-k+1)$$
- 后验均值 $E[\Theta \mid X=k] = \frac{k+1}{n+2}$（拉普拉斯"加一"平滑）；
- MAP 估计：$\hat\theta = k/n$（后验众数，与极大似然一致）。

## 3. 关键性质

### 3.1 后验 = 先验 × 似然（归一化）
- 分母 $p_X(x)$ 只负责归一化，不依赖 $\theta$——比较不同 $\theta$ 时可忽略；
- 数据越多，后验越"尖"（集中在真实参数附近），先验的影响越小。

### 3.2 共轭先验
先验选 Beta 时，后验仍是 Beta，只是参数更新为（成功数 + a，失败数 + b）——计算闭合、解释直观。

### 3.3 贝叶斯 vs 频率学派（本节背景）
- 贝叶斯：参数随机，输出后验分布（信念区间）；
- 经典频率学派：参数固定未知，用置信区间/假设检验（见 L20 经典统计）；
- 两者处理"不确定性"的语言不同，但公式常可互证。

## 4. 例题

### 例 1：离散参数 + 离散观测
- $\Theta \in \{0.3, 0.6\}$ 等先验；$X \mid \Theta \sim \text{Binomial}(10, \Theta)$；
- 观测 $X = 4$：$p_X(4) = \frac12 \binom{10}{4}0.3^4 0.7^6 + \frac12\binom{10}{4}0.6^4 0.4^6$；
- 后验 $p_{\Theta \mid X}(0.3 \mid 4) = \dfrac{0.5 \cdot 0.3^4 0.7^6}{0.5\cdot0.3^4 0.7^6 + 0.5\cdot0.6^4 0.4^6} \approx 0.57$，观测结果更支持$\Theta = 0.3$。

### 例 2：离散参数 + 连续观测
- $\Theta \in \{-1, +1\}$，$X = \Theta + W$，$W \sim N(0,1)$（信号检测）；
- 后验 $p_{\Theta \mid X}(+1 \mid x) = \dfrac{e^{-(x-1)^2/2}}{e^{-(x-1)^2/2}+e^{-(x+1)^2/2}}$（与 L10 相同）。

### 例 3：连续参数 + 连续观测
- $\Theta \sim U[0,1]$，$X \mid \Theta \sim U[0,\Theta]$：
- $f_{\Theta \mid X}(\theta \mid x) = \dfrac{1\cdot \frac1\theta}{\int_x^1 \frac1\theta d\theta} = \frac{1}{\theta \ln(1/x)}$（$x \le \theta \le 1$）；
- 观测 $x$ 之后，$\theta \ge x$ 且更偏爱小 $\theta$。

### 例 4：硬币偏置点估计
- $n=10, k=7$：后验 $\text{Beta}(8,4)$；
- MAP：$\hat\theta = 0.7$；后验均值 $E[\Theta \mid X] = 8/12 \approx 0.667$。

## 5. 本节重点

> **本节重点**：
> - 贝叶斯推断三要素：先验、似然、后验；后验 ∝ 先验 × 似然。
> - 四种（离散/连续）参数-观测组合都能用贝叶斯法则，记住"分子先验×似然、分母归一化"。
> - Beta 分布是"硬币偏置"的共轭先验：观测 $k/n$ 后更新为 $\text{Beta}(k+a, n-k+b)$；后验均值 $(k+1)/(n+2)$、MAP $= k/n$。
> - **常见坑**：① 把先验当后验直接输出；② 归一化分母算错（离散求和 vs 连续积分）；③ 混淆 MAP（众数）与后验均值（LMS）。
