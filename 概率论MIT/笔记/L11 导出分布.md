## 1. 核心概念

### 1.1 问题
已知 $X$ 的分布，求 $Y = g(X)$ 的分布。核心思想：**通过 $X$ 的事件反推 $Y$ 的事件**，把 $Y$ 的概率翻译成 $X$ 的概率。

### 1.2 两条路线
- 离散：直接对原像求和 $p_Y(y) = \sum_{x: g(x)=y} p_X(x)$；
- 连续：两步法——先求 CDF $F_Y(y) = P(g(X) \le y)$，再求导 $f_Y(y) = F_Y'(y)$。

---

## 2. 公式与定义

### 2.1 离散线性函数
$Y = aX + b$：
$$p_Y(y) = p_X\left(\frac{y-b}{a}\right)$$

### 2.2 连续线性函数
$Y = aX + b$（$a \ne 0$）：
$$f_Y(y) = \frac{1}{|a|} f_X\left(\frac{y-b}{a}\right)$$
直观：拉伸 $|a|$ 倍，密度压缩 $1/|a|$ 倍（概率守恒）。

### 2.3 正态的线性性
$X \sim N(\mu,\sigma^2)$ ⇒ $aX + b \sim N(a\mu+b,\ a^2\sigma^2)$。

### 2.4 单调情形的通用公式
$g$ 严格单调、可微，反函数 $h = g^{-1}$：
$$f_Y(y) = f_X(h(y)) \left|\frac{dh}{dy}(y)\right|$$
直觉：$\delta_2 \approx |g'(x)|\delta_1$，密度按雅可比倒数缩放。

### 2.5 多元函数
$Z = g(X,Y)$：同样先求 CDF $F_Z(z) = P(g(X,Y) \le z)$，再求导。

---

## 3. 关键性质

- **两步法万能**：CDF → 求导，适用于任意（分段）函数；
- 单调公式本质是"变量替换"：$f_Y(y)dy = f_X(x)dx$；
- 非单调函数（如 $Y = X^2$）：把原像分成多个单调区间分别处理再相加；
- 连续线性变换的 $1/|a|$ 因子：$a$ 的符号不影响（用绝对值），因为 PDF 非负。

## 4. 例题

### 例 1：$Y = X^3$，$X \sim U[0,2]$
- $F_Y(y) = P(X^3 \le y) = P(X \le y^{1/3}) = \frac{y^{1/3}}{2}$（$0 \le y \le 8$）；
- $f_Y(y) = \frac{1}{6}y^{-2/3}$（$0 \le y \le 8$）。

### 例 2：$Y = a/X$（跑步机问题）
- 速度 $X \sim U[5,10]$，跑完 10 km 用时 $Y = 10/X$；
- $F_Y(y) = P(10/X \le y) = P(X \ge 10/y) = \frac{10 - 10/y}{5}$（$1 \le y \le 2$）；
- $f_Y(y) = \frac{2}{y^2}$（$1 \le y \le 2$）。

### 例 3：$Y = X^2$，$X \sim U[0,1]$
- 单调（$X\ge0$）可套公式：$h(y) = \sqrt y$，$f_Y(y) = \frac{1}{2\sqrt y}$（$0 \le y \le 1$）；
- 若 $X \sim U[-1,1]$（非单调）：$F_Y(y) = P(-\sqrt y \le X \le \sqrt y) = \sqrt y$，$f_Y(y) = \frac{1}{2\sqrt y}$（$0\le y\le1$），两个区间各贡献一半。

### 例 4：$Z = Y/X$（$X,Y$ 独立 $U[0,1]$）
- $F_Z(z) = P(Y \le zX)$：在单位正方形内求直线 $y = zx$ 下方面积；
- $0 \le z \le 1$ 时：$F_Z(z) = \int_0^1 zx\,dx = z/2$，$f_Z(z) = 1/2$。

## 5. 补充：模拟（S11.1，p120）

- **目的**：当 $g(X_1, \dots, X_n)$ 的导出分布解析求不出时，生成服从已知分布的随机样本、评估 $g$、画直方图，用频率了解统计特性。
- **离散情形（区间法）**：把 $[0,1]$ 按概率质量切成与 $p_i$ 等长的区间，$U \sim U(0,1)$ 落在哪个区间就输出对应取值——输出的变量有正确的 PMF。图形上等价于"取 $U$，在 CDF 的跳跃处对齐，报告对应的 $x$"。
- **连续情形（逆变换采样）**：设 $F$ 连续且严格单调，令
$$X = F^{-1}(U), \qquad U \sim U(0,1)$$
则 $X$ 的 CDF 恰为 $F$。验证：$P(X \le c) = P(F^{-1}(U) \le c) = P(U \le F(c)) = F(c)$（均匀变量的 CDF 是 $u$ 本身）。
- **图形直觉**：从 $y$ 轴取 $U \in (0,1)$，水平走到 CDF 曲线，再垂直落到 $x$ 轴，读出的 $x$ 就是样本。
- **例（指数分布）**：$F(x) = 1 - e^{-x}$（参数 1），解 $u = 1 - e^{-x}$ 得 $x = -\ln(1-u)$，即 $X = -\ln(1-U) \sim \text{Exp}(1)$——计算机生成指数随机变量的标准做法（随机数生成器通常只给均匀分布）。

---

## 5. 本节重点

> **本节重点**：
> - 导出分布三件套：离散求和原像、连续两步法（CDF→导数）、单调公式 $f_Y(y) = f_X(h(y))|h'(y)|$。
> - 线性变换 $f_Y(y) = \frac{1}{|a|}f_X(\frac{y-b}{a})$；正态线性保持正态。
> - 非单调：分区间反解，别忘了把各区间的密度相加。
> - **常见坑**：① 忘记 $1/|a|$ 因子；② 非单调函数只取一个原像分支；③ 求 CDF 时不等式方向反（$g$ 递减时 $P(g(X)\le y)$ 要变号）。
