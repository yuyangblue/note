## 1. 核心概念

### 1.1 中心极限定理
$X_1,\dots,X_n$ i.i.d.，均值 $\mu$、方差 $\sigma^2$；令 $S_n=X_1+\cdots+X_n$，定义标准化和

$$Z_n=\frac{S_n-n\mu}{\sigma\sqrt n}$$

则 $Z_n$ 的 CDF 收敛到标准正态 CDF：

$$\lim_{n\to\infty}P(Z_n\le z)=\Phi(z),\qquad\forall z\in\mathbb{R}$$

即 $Z_n\xrightarrow{d}N(0,1)$。只要 $E[X_i^2]<\infty$，不管原始分布是离散、连续还是混合，大 $n$ 时标准化和都像正态。

**为什么标度是 $\sqrt n$（而不是 $n$ 或 $1$）**。三种缩放视角：

1. $S_n$ 本身：$E[S_n]=n\mu$，$\text{var}(S_n)=n\sigma^2$，标准差 $\sigma\sqrt n\to\infty$，分布越来越宽，没有稳定极限；
2. 样本均值 $M_n=S_n/n$：方差 $\sigma^2/n\to 0$，收缩到 $\mu$（这是 WLLN，只说"缩到哪"，不问形状）；
3. 去中心化后除以 $\sigma\sqrt n$：$E[Z_n]=0$，$\text{var}(Z_n)=\text{var}(S_n)/(\sigma^2 n)=n\sigma^2/(n\sigma^2)=1$——方差保持为 1 不变，分布形状稳定。CLT 问的就是"这个形状趋向什么"，答案是标准正态。

$\sqrt n$ 来自方差相加：独立和的方差相加得 $n\sigma^2$，自然标度是标准差 $\sigma\sqrt n$。除以它相当于把"单位"统一成一个标准差。

### 1.2 含义
大量独立微小随机因素叠加 $\Rightarrow$ 总量近似正态，这是"钟形曲线"无处不在的原因。凡是多个独立小噪声叠加的系统，正态都是好模型，这解释了正态分布在物理、工程、社会科学中的广泛应用。

## 2. 公式与定义

### 2.1 正态近似的两种写法
由正态在线性变换下封闭，treat $S_n$ 为正态：

- 对和：$S_n\approx N(n\mu,\ n\sigma^2)$；
- 对样本均值：$M_n\approx N(\mu,\ \sigma^2/n)$。

计算步骤：① 算均值 $n\mu$、方差 $n\sigma^2$；② 标准化 $z=(c-n\mu)/(\sigma\sqrt n)$；③ $P(S_n\le c)\approx\Phi(z)$。

### 2.2 二项分布的正态近似（De Moivre-Laplace）
**推导**。$X\sim\text{Bin}(n,p)$ 可写成 $n$ 个独立 Bernoulli$(p)$ 之和：$X=X_1+\cdots+X_n$，$X_i\in\{0,1\}$。单个 $X_i$ 的均值与方差为

$$E[X_i]=p,\qquad\text{var}(X_i)=p(1-p)$$

代入 CLT：$S_n$ 的均值 $np$、方差 $np(1-p)$、标准差 $\sqrt{np(1-p)}$，故

$$X=S_n\approx N(np,\ np(1-p))$$

即

$$\frac{X-np}{\sqrt{np(1-p)}}\xrightarrow{d}N(0,1)$$

### 2.3 连续性修正
二项 PMF 是"柱子"：整数 $k$ 的概率 $P(X=k)$ 占据连续区间 $[k-0.5,\ k+0.5]$。直接用连续正态 $P(X\le k)\approx\Phi((k-np)/\sqrt{np(1-p)})$ 会少算半根柱子（$k$ 那根柱子的右半边没盖住）。把边界外推 0.5 即可覆盖完整柱子：

$$P(X\le k)\approx\Phi\!\left(\frac{k+0.5-np}{\sqrt{np(1-p)}}\right)$$

一般区间 $[a,b]$（$a,b$ 为整数）：

$$P(a\le X\le b)\approx\Phi\!\left(\frac{b+0.5-np}{\sqrt{np(1-p)}}\right)-\Phi\!\left(\frac{a-0.5-np}{\sqrt{np(1-p)}}\right)$$

单个概率 $P(X=k)$ 用区间 $[k-0.5,\ k+0.5]$ 的正态面积。

### 2.4 近似质量
- 中心附近好、尾部差；$n$ 越大越好；
- 二项对称（$p$ 接近 $1/2$）时小 $n$ 也凑合；$p$ 极端（接近 0 或 1）时需要大 $n$；
- 经验规则：$np\ge 5$ 且 $n(1-p)\ge 5$ 时可用（粗略）；教材指出 $p$ 接近 $1/2$ 时 $n=40\sim 50$ 就很好。

## 3. 关键性质

### 3.1 CLT 与 WLLN 的关系
- WLLN：$M_n\xrightarrow{P}\mu$（点估计，宽度收缩为 $1/\sqrt n$ 量级）；
- CLT：给出 $M_n$ 的波动幅度与形状（若干标准差内的概率可查正态表算出）；
- 民调：$P(|\hat p-p|\le\epsilon)\approx 2\Phi(\epsilon\sqrt{n}/\sqrt{p(1-p)})-1$。

### 3.2 泊松 vs 正态近似
- $np$ 适中（如 5–20）且希望精确：泊松近似更优；
- $np$ 大（如 >30）：正态近似好且简单（泊松本身也趋近正态）；
- 规则：二项 $\to$ $np$ 小用泊松、$np$ 大用正态。

### 3.3 CLT 的推广与证明思路
- 不要求同分布——只要各方差满足 Lindeberg 条件；
- 不要求完全独立——"弱相关"情形仍有 CLT；
- 证明思路用矩母函数/特征函数：把标准化和的矩母函数 $E[e^{sZ_n}]$ 与标准正态的矩母函数 $e^{s^2/2}$ 对比，大 $n$ 时二者趋同。本课程不严格证。
- 极端尾部需要大偏差理论，CLT 在中心附近最可靠。

## 4. 例题

### 例 1：完整正态近似计算演示（教材 Example 5.9，含查表）
飞机装 100 个包裹，每个重量独立且服从 $U[5,50]$ 磅。求总重超过 3000 磅的概率。

**步骤**：

1. 单个包裹 $X_i\sim U[5,50]$：$\mu=(5+50)/2=27.5$，$\sigma^2=(50-5)^2/12=168.75$，$\sigma=\sqrt{168.75}\approx 12.99$。
2. $S_{100}=\sum X_i$，CLT 近似 $S_{100}\approx N(100\cdot 27.5,\ 100\cdot 168.75)=N(2750,\ 16875)$，标准差 $\sqrt{16875}\approx 129.9$。
3. 标准化阈值：$z=(3000-2750)/129.9=250/129.9\approx 1.92$。
4. 查标准正态表：$\Phi(1.92)=0.9726$（表中 1.9 行、0.02 列）。
5. $P(S_{100}\le 3000)\approx 0.9726$，故 $P(S_{100}>3000)\approx 1-0.9726=0.0274$。

结论：总重超 3000 磅的概率约 2.7%。这道题若硬算 100 个均匀变量和的 CDF 几乎不可能，CLT 三步给出答案。

### 例 2：大量独立收益之和
单次游戏收益均值 2、方差 25，玩 100 次：$S_{100}\approx N(200,2500)$（$\sigma=50$）。$P(S_{100}\ge 250)\approx P(Z\ge 1)=1-\Phi(1)\approx 0.1587$。

### 例 3：包裹重量四问（讲义 p9-12）
$X_i\sim\text{Exp}(\lambda=1/2)$（$\mu=2,\sigma=2$），容器装 $n$ 个包裹：

- 问概率（$n=100$，求 $P(S_n>210)$）：$Z=(210-200)/20=0.5$，$P(Z>0.5)=1-\Phi(0.5)\approx 0.3085$；
- 问容量（$n=100$，要求 $P(S_n>a)=0.05$）：$\Phi^{-1}(0.95)\approx 1.645$，$a=200+1.645\times 20\approx 232.9$；
- 问 $n$（容量 210，要求 $P(S_n>210)=0.05$）：$(210-2n)/(2\sqrt n)=1.645$，解二次方程得 $n\approx 89$；
- 问停止时包裹数（容量 210，求 $P(N>100)$）：$N>100$ 等价于"前 100 个没超 210"，即 $P(S_{100}\le 210)=\Phi(0.5)\approx 0.6915$。

四种题型本质一样——把事件用标准化 $Z_n$ 表示，查正态表，关键是把文字描述翻译成不等式。

### 例 4：二项 + 连续性修正（教材 Example 5.12）
抛 36 次公平硬币，$P(S_n\le 21)$：$np=18$，$\sqrt{np(1-p)}=3$。

- 无修正：$\Phi((21-18)/3)=\Phi(1)=0.8413$（真实值 0.8785，差 4%）；
- 修正：$\Phi((21.5-18)/3)=\Phi(1.17)\approx 0.879$（几乎精确）。

单个概率 $P(S_n=19)$：用区间 $[18.5,19.5]$，$P(0.17\le Z\le 0.5)\approx 0.6915-0.5675=0.124$（精确值 0.1251）。

### 例 5：民调再访（教材 Example 5.11）
$n=10000$，真实 $p$ 未知，用最坏情况 $\sigma=0.5$（$p=0.5$ 时方差最大）。

- $P(|\hat p-p|>0.01)\le 2(1-\Phi(0.01\sqrt{10000}/0.5))=2(1-\Phi(2))\approx 0.046$；
- 要求误差概率 $\le 5\%$：$0.02\sqrt n=1.96\Rightarrow n=9604$（比切比雪夫的 50000 少得多）；
- 报纸上 $\pm 3\%$ 民调只需约 1000 人。

切比雪夫说需要 50000 人，CLT 说只要约 10000 人——差 5 倍，这就是 CLT 利用正态形状信息后给出更紧估计的价值。

## 5. 本节重点

- CLT：标准化和 $(S_n-n\mu)/(\sigma\sqrt n)\xrightarrow{d}N(0,1)$；$M_n\approx N(\mu,\sigma^2/n)$。标度 $\sqrt n$ 来自独立和方差相加 $n\sigma^2$。
- 二项正态近似：$X\sim\text{Bin}(n,p)\approx N(np,np(1-p))$，必须做连续性修正 $\pm 0.5$。
- 与 WLLN 互补：WLLN 说"收敛到哪"，CLT 说"有多准"。
- 泊松 vs 正态：$np$ 小用泊松、$np$ 大用正态。
- **常见坑**：① 忘了连续性修正，尤其离散 $\to$ 连续时；② 标准化分母用错，应为 $\sigma\sqrt n$ 而不是 $\sigma$ 或 $\sqrt n$；③ 对重尾分布（方差无穷）乱用 CLT；④ 把 CDF 收敛当成 PMF 逐点相等；⑤ 在极端尾部套用中心近似，那里 CLT 精度差。
