## 1. 核心概念

### 1.1 两个不等式：不需要知道分布就能界住"尾部"
- **马尔可夫不等式**：用均值控制大值的概率；
- **切比雪夫不等式**：用方差控制偏离均值的概率。

> 老师的动机（p181）："我们经常不知道完整分布，只知道均值或方差。能不能仅凭这点信息就对极端事件概率做个估计？马尔可夫和切比雪夫回答了这个问题——界可能松，但完全不用假设分布形状。"

### 1.2 弱大数定律（WLLN）
样本均值 $M_n = \frac{1}{n}\sum_{i=1}^n X_i$（$X_i$ i.i.d.，均值 $\mu$、方差有限）随 $n$ 增大**依概率收敛**到 $\mu$：
$$P(|M_n - \mu| \ge \epsilon) \to 0, \quad \forall \epsilon > 0$$

> 老师的两种解释（p183）：① **测量噪声**视角：$X_i = \mu + W_i$，$E[W_i]=0$，独立噪声平均后互相抵消；② **频率解释**视角：$X_i$ 是事件 $A$ 的指示变量，样本均值 = 经验频率，WLLN 说经验频率收敛到真实概率 $p$——"这正是概率的频率解释的数学基础。"

### 1.3 依概率收敛
$Y_n \xrightarrow{P} c$：对任意 $\epsilon > 0$，$P(|Y_n - c| \ge \epsilon) \to 0$——"随着 $n$ 增大，偏离目标的可能性趋于零"。

> 老师对比普通收敛（p185）："数列收敛要求最终'永远停在' $a$ 附近；依概率收敛不要求永远——只要求'大部分概率质量'在 $a$ 附近，偶尔跑出去的概率趋于零。"

## 2. 公式与定义

### 2.1 马尔可夫不等式
$$X \ge 0, \quad a > 0: \qquad P(X \ge a) \le \frac{E[X]}{a}$$

> **推导**（p181）：方法一（积分）：

$$E[X] = \int_0^\infty x f(x) dx \ge \int_a^\infty x f(x) dx \ge a \int_a^\infty f(x) dx = a P(X \ge a)$$

> 方法二（示性函数）：定义 $Y = a \cdot \mathbb{1}_{\{X \ge a\}}$，则 $Y \le X$，取期望得 $a P(X \ge a) \le E[X]$。
>
> **直觉**：均值小 ⇒ 大值概率有限。老师强调："这是对非负随机变量的纯量纲论证——不需要知道分布形状。"

### 2.2 切比雪夫不等式
$$P(|X - \mu| \ge c) \le \frac{\text{var}(X)}{c^2}$$

> **推导**（p182）：对 $Y = (X-\mu)^2$ 用马尔可夫（$Y \ge 0$）：$P((X-\mu)^2 \ge c^2) \le E[(X-\mu)^2]/c^2 = \text{var}(X)/c^2$。
>
> **用标准差表述**：$P(|X-\mu| \ge k\sigma) \le 1/k^2$。例如 $k=3$：偏离均值 3 个标准差以上的概率 ≤ 1/9——无论什么分布都成立。
>
> 老师对比（p182）："对指数分布（均值 1），马尔可夫给 $P(X \ge a) \le 1/a$，切比雪夫给 $P(|X-1| \ge a-1) \le 1/(a-1)^2$——大 $a$ 时切比雪夫快得多（$1/a^2$ vs $1/a$），因为它多利用了方差信息。"

### 2.3 弱大数定律证明（切比雪夫版）
- $E[M_n] = \mu$，$\text{var}(M_n) = \sigma^2/n$（$X_i$ 独立）；
- 切比雪夫：$P(|M_n - \mu| \ge \epsilon) \le \frac{\sigma^2}{n\epsilon^2} \to 0$。

### 2.4 民调应用
调查 $n$ 人支持率 $p$ 的估计 $\hat p = M_n$（每人支持与否的指示变量）：
- $E[\hat p] = p$，$\text{var}(\hat p) = \frac{p(1-p)}{n} \le \frac{1}{4n}$（$p(1-p)$ 在 $p=1/2$ 取最大值 $1/4$）；
- 切比雪夫：$P(|\hat p - p| \ge \epsilon) \le \frac{1}{4n\epsilon^2}$——$n = \frac{1}{4\delta\epsilon^2}$ 保证以高概率落在 $\pm\epsilon$。

> **民调算例**（p184）：要求误差 ±0.01、大误差概率 ≤ 0.05：$n \ge 1/(4 \cdot 0.05 \cdot 0.0001) = 50000$。老师："5 万人听起来很多，但报纸上的民调通常只要 ±3% 误差——这就只需要几千人。而且切比雪夫很保守，用正态近似（CLT）实际只要几千就够了。"

## 3. 关键性质

### 3.1 相关不等式（补充）
- **Jensen**：$g$ 凸 ⇒ $E[g(X)] \ge g(E[X])$（$X^2$、$e^X$ 的界）；
- **Hoeffding**（独立有界和）：$X_i \in [a_i,b_i]$ 独立，$S_n = \sum(X_i - E[X_i])$：
$$P(S_n \ge t) \le \exp\left(-\frac{2t^2}{\sum_i (b_i-a_i)^2}\right)$$
比切比雪夫指数级更紧（集中不等式）。

### 3.2 收敛概念谱系
- 依概率收敛（本讲）：$P(|Y_n-c|\ge\epsilon)\to0$；
- 几乎必然收敛（更强）：$P(Y_n \to c) = 1$；
- 分布收敛（弱收敛，L19 CLT 用）：CDF 逐点收敛；
- WLLN 用依概率收敛；强大数定律（SLLN）用几乎必然收敛。

> **依概率收敛的运算性质**（p185）：若 $X_n \xrightarrow{P} a$、$Y_n \xrightarrow{P} b$，则 ① $g(X_n) \xrightarrow{P} g(a)$（$g$ 连续）；② $X_n + Y_n \xrightarrow{P} a+b$。**但** $E[X_n]$ 不一定收敛到 $a$（见例 1）。

### 3.3 方差不存在的反例
- WLLN 需要 $\text{var}(X) < \infty$；重尾分布（如 Cauchy）样本均值不收敛——均值本身不存在。

## 4. 例题

### 例 1：马尔可夫
- 平均每天通勤 50 分钟：$P(\text{某天} \ge 100) \le 50/100 = 1/2$（不能更紧，除非有额外信息）。
- $X \sim \text{Exp}(1)$：$P(X \ge a) \le 1/a$，真实值 $e^{-a}$——界比真实值松很多（$1/a$ vs 指数衰减）。

### 例 2：切比雪夫
- $X$ 均值 100、方差 25（$\sigma=5$）：
- $P(|X-100| \ge 15) \le 25/225 = 1/9$；
- 即"落在 85–115 之外"的概率 ≤ 1/9（真实分布可能远小于此）。

### 例 3：民调样本量
- 要求误差 $\pm 0.03$、概率至少 0.95：
- 切比雪夫：$\frac{1}{4n(0.03)^2} \le 0.05 \Rightarrow n \ge \frac{1}{4\cdot0.05\cdot0.0009} \approx 5556$；
- （CLT/正态近似只需约 1068——切比雪夫保守但不需要分布假设，L19 再见。）

### 例 4：依概率收敛但期望不收敛（讲义 p12，p186）
- $Y_n = 0$（概率 $1 - 1/n$），$Y_n = n^2$（概率 $1/n$）；
- $P(|Y_n| \ge \epsilon) = 1/n \to 0$，故 $Y_n \xrightarrow{P} 0$；
- 但 $E[Y_n] = (1/n) \cdot n^2 = n \to \infty$。
- **教训**：依概率收敛只要求尾部概率小，但期望对尾部敏感——小概率 × 超大值仍可让期望爆炸。

### 例 5：最小值收敛（讲义 p13，p186）
- $X_1, \ldots, X_n$ i.i.d. $U[0,1]$，$Y_n = \min(X_1, \ldots, X_n)$；
- $P(Y_n \ge \epsilon) = P(\text{所有 } X_i \ge \epsilon) = (1-\epsilon)^n \to 0$（对任意 $\epsilon > 0$）；
- 故 $Y_n \xrightarrow{P} 0$——"样本越多，越容易抽到接近 0 的值。"

## 5. 本节重点

> **本节重点**：
> - 马尔可夫：$P(X\ge a) \le E[X]/a$（$X\ge0$）；切比雪夫：$P(|X-\mu|\ge c) \le \text{var}(X)/c^2$。
> - WLLN：$M_n \xrightarrow{P} \mu$，证明 = 均值/方差计算 + 切比雪夫。
> - 民调：$\text{var}(\hat p) \le 1/(4n)$，$n$ 足够大误差可控。
> - 依概率收敛：$P(|Y_n-c|\ge\epsilon)\to0$；连续函数和加法保持收敛；但期望不一定收敛。
> - 拓展：Hoeffding（指数界）、Jensen（凸函数）、依概率 vs 几乎必然收敛。
> - **常见坑**：① 马尔可夫要求 $X \ge 0$；② 切比雪夫里 $c$ 与标准差 $\sigma$ 混用；③ 把"依概率收敛"当成"几乎必然收敛"；④ 以为依概率收敛就一定有期望收敛（反例：小概率大值）。
