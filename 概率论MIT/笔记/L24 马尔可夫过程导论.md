## 1. 核心概念

### 1.1 马尔可夫性（无记忆的"状态"版）
给定当前状态，未来与过去独立：
$$P(X_{n+1} = j \mid X_n = i, X_{n-1}, \dots) = P(X_{n+1} = j \mid X_n = i)$$
"昨天发生什么不重要，重要的是今天在哪。"

### 1.2 离散时间有限状态马尔可夫链
- 状态空间有限 $\{1,\dots,m\}$；
- 转移概率 $p_{ij} = P(X_{n+1} = j \mid X_n = i)$；
- 转移矩阵 $P = [p_{ij}]$（每行和为 1）；
- 时齐：转移概率不随时间变化。

## 2. 公式与定义

### 2.1 $n$ 步转移概率
$$r_{ij}(n) = P(X_n = j \mid X_0 = i)$$
- 计算：$r_{ij}(n) = \sum_k r_{ik}(n-1) p_{kj}$；
- 矩阵形式：$R(n) = P^n$（转移矩阵的 $n$ 次幂）；
- **查普曼-科尔莫戈罗夫方程**：$r_{ij}(m+n) = \sum_k r_{ik}(m) r_{kj}(n)$。

### 2.2 状态分类

| 类型 | 定义 | 直觉 |
|---|---|---|
| 可达/相通 | $i \to j$、$j \to i$（相通） | 能从一边到另一边 |
| 常返（recurrent） | 从 $i$ 出发，回到 $i$ 的概率为 1 | 一定会回来 |
| 暂态（transient） | 回到 $i$ 的概率 < 1 | 可能一去不回 |
| 吸收态 | $p_{ii} = 1$ | 进去出不来 |
| 闭集 | 从集合内无法离开 | 一族状态互相锁定 |

### 2.3 收敛性问题（预告 L25）
- 从任意起点出发，$r_{ij}(n)$ 是否收敛到平稳分布 $\pi_j$？
- 需要：不可约（全状态相通）、非周期、常返（有限链自动满足部分条件）；
- 平稳分布满足 $\pi_j = \sum_i \pi_i p_{ij}$ 且 $\sum_j \pi_j = 1$（$\pi P = \pi$）。

## 3. 关键性质

### 3.1 有限状态链的常返-暂态结构
- 有限状态：至少存在一个常返类；暂态态最终进入某个常返类；
- 常返类内部相通且闭。

### 3.2 数值示例模式（收银台/排队）
- 状态 = 队列长度（0,1,2,...）；每步以 $p$ 来客、$q$ 服务完（到达/服务概率）；
- 转移：$i \to i+1$（到达）、$i \to i-1$（服务）、$i \to i$（都不发生/都发生）；
- 这类"生-死"链是 L25 的样板。

### 3.3 谱直觉
- 转移矩阵 $P$ 的特征值 ≤ 1；平稳分布对应特征值 1 的左特征向量；
- 收敛速度由第二特征值决定（本课不深究，但解释"多久才平稳"）。

## 4. 例题

### 例 1：两态链
- 状态 0/1，$p_{00}=0.9, p_{01}=0.1, p_{10}=0.5, p_{11}=0.5$：
- $r_{00}(2) = p_{00}^2 + p_{01}p_{10} = 0.81 + 0.05 = 0.86$；
- $P^2$ 各元素可类似算出（矩阵乘法）。

### 例 2：收银台（队列）
- 每时隙：以 0.3 来一人、以 0.4 服务完一人（服务需人在）：
- 转移：$i\ge1$ 时 $p_{i,i+1}=0.3$、$p_{i,i-1}=0.4$、$p_{i,i}=0.3$；$p_{0,1}=0.3, p_{0,0}=0.7$；
- 问题：队列会无限增长吗？（取决于 $\lambda < \mu$，此处 0.3 < 0.4 趋于平稳。）

### 例 3：数值示例（天气预报）
- 晴/雨两态链，转移矩阵已知：用 $P^n$ 求"两天后下雨"概率；
- 通过迭代 $r(n+1) = r(n)P$ 逐步推进。

## 5. 本节重点

> **本节重点**：
> - 马尔可夫性：未来只依赖当前状态；转移矩阵每行和为 1。
> - $n$ 步转移概率 = $P^n$；查普曼-科尔莫戈罗夫方程。
> - 状态分类：常返（必回）、暂态（可能不回）、吸收（不出）、闭集。
> - 有限链必有常返类；收敛到平稳分布需不可约 + 非周期。
> - **常见坑**：① 把 $P(X_{n+1} \mid X_n)$ 与 $P(X_{n+1} \mid X_0)$ 混用；② 转移矩阵行/列方向写反（行和 = 1）；③ 忘记验证"相通"就断言收敛。
