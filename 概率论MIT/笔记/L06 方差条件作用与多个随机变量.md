## 1. 核心概念

### 1.1 方差：离散程度的度量
均值 $\mu = E[X]$ 描述"中心"，方差描述"离中心有多散"：
$$\text{var}(X) = E[(X-\mu)^2]$$
标准差 $\sigma_X = \sqrt{\text{var}(X)}$ 与 $X$ 同量纲。

### 1.2 给定事件的条件作用
把"已知事件 $A$ 发生"当作新世界：PMF、期望、方差全部换成条件版本 $p_{X \mid A}$、$E[X \mid A]$、$\text{var}(X \mid A)$。

### 1.3 多个随机变量
联合 PMF $p_{X,Y}(x,y)$ 描述两个随机变量的联合分布；边缘 PMF 由联合对另一个变量求和得到。

## 2. 公式与定义

### 2.1 方差
$$\text{var}(X) = E[X^2] - (E[X])^2 = \sum_x (x-\mu)^2 p_X(x)$$
$$\text{var}(aX + b) = a^2 \text{var}(X)$$
（平移 $b$ 不变，缩放 $a$ 平方放大。）

### 2.2 常见分布的方差
- 伯努利（参数 $p$）：$\text{var}(X) = p(1-p)$；
- $0,1,\dots,n$ 上均匀：$\text{var}(X) = \dfrac{n(n+2)}{12}$；
- $a,\dots,b$ 上均匀（共 $b-a+1$ 个点）：$\text{var}(X) = \dfrac{1}{12}(b-a)(b-a+2)$；
- 几何（参数 $p$）：$\text{var}(X) = \dfrac{1-p}{p^2}$。

### 2.3 给定事件的条件 PMF/期望
- $p_{X \mid A}(x) = P(X = x \mid A)$，$\sum_x p_{X \mid A}(x) = 1$；
- $E[X \mid A] = \sum_x x p_{X \mid A}(x)$；
- $E[g(X) \mid A] = \sum_x g(x) p_{X \mid A}(x)$；
- $\text{var}(X \mid A) = E[(X - E[X \mid A])^2 \mid A]$。

### 2.4 全期望定理（划分版本）
设 $A_1,\dots,A_n$ 是 $\Omega$ 的划分：
$$p_X(x) = \sum_i P(A_i) p_{X \mid A_i}(x), \qquad E[X] = \sum_i P(A_i) E[X \mid A_i]$$

### 2.5 联合与边缘 PMF
- $p_{X,Y}(x,y) = P(X=x, Y=y)$，$\sum_x\sum_y p_{X,Y}(x,y) = 1$；
- 边缘：$p_X(x) = \sum_y p_{X,Y}(x,y)$，$p_Y(y) = \sum_x p_{X,Y}(x,y)$；
- 三元：$p_X(x) = \sum_y\sum_z p_{X,Y,Z}(x,y,z)$；
- 期望值法则（多元）：$E[g(X,Y)] = \sum_x\sum_y g(x,y) p_{X,Y}(x,y)$。

### 2.6 期望的线性（不要求独立！）
$$E[X_1 + \cdots + X_n] = E[X_1] + \cdots + E[X_n]$$

## 3. 关键性质

### 3.1 几何分布的无记忆性（核心直觉）
- $X$：首次正面所需抛掷次数，$p_X(k) = (1-p)^{k-1}p$；
- 在 $X > n$ 的条件下，$X - n$ 仍服从参数为 $p$ 的几何分布；
- 意义：已经等了 $n$ 次没成功，"剩余等待时间"分布与从未等待时完全一样——过去不提供任何信息（无"老化"）；
- 由无记忆性 + 全期望（**首步分解**）可直接推出 $E[X] = 1/p$。按第一次试验结果划分，设 $H_1$ = 第一次就成功（$P(H_1)=p$）、$H_1^c$ = 第一次失败（$P(H_1^c)=1-p$），由全期望定理：

$$E[X] = P(H_1)E[X \mid H_1] + P(H_1^c)E[X \mid H_1^c]$$

- 第一次成功 ⇒ $X=1$，故 $E[X \mid H_1] = 1$；第一次失败 ⇒ 已花掉 1 次，剩下的等待次数 $X'$ 与原来的 $X$ **同分布**（几何无记忆性 / fresh start），故 $E[X \mid H_1^c] = 1 + E[X]$。代入：

$$E[X] = p\cdot1 + (1-p)(1+E[X]) = 1 + (1-p)E[X] \;\Rightarrow\; p\,E[X] = 1 \;\Rightarrow\; E[X] = \frac{1}{p}$$

- （板书简写 $E[X] = 1 + E[X-1]$ 就是"先花掉 1 次、再重新开始"这一步的缩写。）

### 3.2 二项均值（指示变量技巧）
- $X = X_1 + \cdots + X_n$（$X_i$ 第 $i$ 次成功与否的指示变量）；
- $E[X_i] = p$，由线性：$E[X] = np$；
- 这个技巧避免了对 $\sum k\binom{n}{k}p^k(1-p)^{n-k}$ 做代数求和，体现"线性性不要求独立"的力量。

## 4. 例题

### 例 1：条件作用示例
- 设 $p_X(1)=p_X(2)=p_X(3)=p_X(4)=1/4$（以图示为准），$A = \{X \ge 2\}$；
- $E[X] = (1+2+3+4)/4 = 2.5$；
- $P(A) = 3/4$，$p_{X \mid A}(2)=p_{X \mid A}(3)=p_{X \mid A}(4)=1/3$；
- $E[X \mid A] = (2+3+4)/3 = 3$（条件把世界收缩到 $\{2,3,4\}$，均值随之变大）；
- $\text{var}(X \mid A)$ 用 $E[X^2 \mid A] - (E[X \mid A])^2$ 计算：$E[X^2 \mid A] = (4+9+16)/3 = 29/3$，$\text{var}(X \mid A) = 29/3 - 9 = 2/3$。

### 例 2：全期望示例
- 设 $P(X=x)=1/9$（$x=0,1,2$），$P(X=x)=2/9$（$x=6,7,8$）；
- 分组：$A_1=\{X\le2\}$（概率 1/3），$A_2=\{X\ge6\}$（概率 2/3）；
- $E[X \mid A_1] = 1$，$E[X \mid A_2] = 7$；
- $E[X] = \tfrac13\cdot1 + \tfrac23\cdot7 = 5$；
- 直接算也一致：$0\cdot\tfrac19+1\cdot\tfrac19+2\cdot\tfrac19+6\cdot\tfrac29+7\cdot\tfrac29+8\cdot\tfrac29 = 5$。

### 例 3：二项均值
$X \sim \text{Binomial}(n,p)$，$E[X] = np$；例如 $n=10, p=0.3$ 时 $E[X] = 3$。

## 5. 本节重点

> **本节重点**：
> - 方差 = $E[X^2] - (E[X])^2$；$\text{var}(aX+b) = a^2\text{var}(X)$；伯努利 $p(1-p)$、几何 $(1-p)/p^2$。
> - 给定事件：一切换条件版本（PMF/期望/方差）；全期望定理 $E[X] = \sum P(A_i)E[X\mid A_i]$。
> - 几何分布无记忆性：$X-n \mid X>n$ 仍是几何；由此 $E[X] = 1/p$。
> - 联合 PMF → 边缘 PMF（求和）；$E[X+Y] = E[X]+E[Y]$ **不需要独立**；二项均值用指示变量 + 线性 = $np$。
> - **常见坑**：① 以为 $E[X+Y]=E[X]+E[Y]$ 需要独立（不需要）；② 条件 PMF 忘记重新归一化（$\sum_x p_{X\mid A}(x)=1$）；③ 用 $\text{var}(X)$ 公式时算错 $E[X^2]$。
