## 1. 核心概念

### 1.1 给定事件的条件 PDF
条件 PDF 与条件 PMF 完全平行：
$$f_{X \mid A}(x) \cdot \delta \approx P(x \le X \le x+\delta \mid A)$$
特别地，给定 $A = \{X \in S\}$ 时，条件 PDF 是把原 PDF 限制在 $S$ 上再归一化：
$$f_{X \mid X \in S}(x) = \begin{cases} 0, & x \notin S \\ \dfrac{f_X(x)}{P(S)}, & x \in S \end{cases}$$

### 1.2 混合随机变量
随机变量可以是"部分离散 + 部分连续"（混合）：如 $X$ 以概率 $1/2$ 在 $[0,2]$ 均匀、以概率 $1/2$ 取常数 1。CDF 此时既有跳跃又有连续段。

### 1.3 联合连续与联合 PDF
两个随机变量联合连续：存在 $f_{X,Y}(x,y) \ge 0$ 使得
$$P((X,Y) \in B) = \iint_{(x,y)\in B} f_{X,Y}(x,y)\, dx\,dy$$
- $f_{X,Y}(x,y)\delta^2 \approx P(x \le X \le x+\delta, y \le Y \le y+\delta)$；
- 单位面积上的概率 = $f_{X,Y}$。

## 2. 公式与定义

### 2.1 条件版本的期望与期望值法则
$$E[X \mid A] = \int x f_{X \mid A}(x)\, dx, \qquad E[g(X) \mid A] = \int g(x) f_{X \mid A}(x)\, dx$$

### 2.2 全概率 / 全期望（事件划分）
$$f_X(x) = \sum_i P(A_i) f_{X \mid A_i}(x), \qquad E[X] = \sum_i P(A_i) E[X \mid A_i]$$

### 2.3 混合分布
$X = \begin{cases} Y \text{（离散）}, & \text{w.p. } p \\ Z \text{（连续）}, & \text{w.p. } 1-p \end{cases}$：
- $F_X(x) = p F_Y(x) + (1-p) F_Z(x)$；
- $E[X] = p E[Y] + (1-p) E[Z]$。

### 2.4 边缘 PDF 与联合 CDF
- $f_X(x) = \int f_{X,Y}(x,y)\, dy$，$f_Y(y) = \int f_{X,Y}(x,y)\, dx$；
- 联合 CDF：$F_{X,Y}(x,y) = P(X \le x, Y \le y)$，$f_{X,Y}(x,y) = \dfrac{\partial^2 F_{X,Y}}{\partial x \partial y}(x,y)$；
- 集合 $S$ 上的均匀联合 PDF：$f_{X,Y}(x,y) = 1/\text{area}(S)$（$(x,y)\in S$）。

### 2.5 期望值法则与线性（多元）
$$E[g(X,Y)] = \iint g(x,y) f_{X,Y}(x,y)\, dx\, dy$$
$$E[X+Y] = E[X] + E[Y] \quad \text{（不要求独立）}$$

## 3. 关键性质

### 3.1 指数分布的无记忆性（本节核心直觉）
- 灯泡寿命 $T \sim$ 指数$(\lambda)$：$P(T > x) = e^{-\lambda x}$；
- 已知 $T > t$ 时，剩余寿命 $X$：$P(X > x \mid T > t) = e^{-\lambda x}$——剩余寿命仍是指数分布，与 $t$ 无关；
- 类比独立抛硬币：每个 $\delta$ 时间步内"坏掉"概率 $\approx \lambda\delta$，互不相关。

### 3.2 联合 PDF 的可视化
- 三维曲面：$f_{X,Y}$ 是"山"，体积 = 概率；
- 切片 $y$ 固定 ⇒ 条件密度的形状（未归一化）；
- 面积为零的集合（如单点、曲线）概率为 0。

## 4. 例题

### 例 1：条件 PDF 的均值
- $X$ 在 $[a,b]$ 上均匀，$A = \{\frac{a+b}{2} \le X \le b\}$：
- $P(A) = 1/2$，条件 PDF 在 $[\frac{a+b}{2}, b]$ 上均匀密度 $= \frac{1}{b-\frac{a+b}{2}} = \frac{2}{b-a}$；
- $E[X \mid A] = \frac{\frac{a+b}{2} + b}{2} = \frac{a+3b}{4}$。

### 例 2：混合随机变量
- $X$ 以 $1/2$ 概率在 $[0,2]$ 均匀、以 $1/2$ 概率取 1：
- $F_X(x)$：在 $x<1$ 时 $=\frac12 \cdot \frac{x}{2}$（均匀部分）；$x=1$ 处跳跃 $\frac12$；$x>1$ 时 $=\frac12 + \frac12\cdot\frac{x}{2}$；
- $E[X] = \frac12\cdot1 + \frac12\cdot1 = 1$（两部分均值都是 1）；
- 注意：$X$ 既非纯离散也非纯连续。

### 例 3：十字形区域上的均匀联合 PDF
- $S$ 为两个交叉矩形（总面积可由图读出，例如 4 个单位）；
- $f_{X,Y}(x,y) = 1/4$ 在 $S$ 上；
- 边缘 $f_X(x)$：对 $y$ 积分得到阶梯函数（窄条处 1/2、宽条处 3/4 等，以面积比为准）。

## 5. 补充：Buffon 针与蒙特卡洛模拟（S09.1，p99）

- **问题（几何概率的著名开端，18 世纪 Buffon 伯爵）**：平面上画间距 $d$ 的平行线，随机投掷一根长 $l$（$l < d$）的针，求针与某条线相交的概率。
- **建模**：$X$ = 针心到最近线的垂直距离，$X \sim U(0, d/2)$；$\Theta$ = 针与线的夹角（取锐角），$\Theta \sim U(0, \pi/2)$；假设 $X, \Theta$ 独立，联合 PDF $f(x, \theta) = \frac{2}{d} \cdot \frac{2}{\pi} = \frac{4}{\pi d}$（均匀性 = "完全随机"）。
- **相交条件**：针的垂直延伸 $\frac{l}{2} \sin\theta$ 超过距离 $x$，即 $x \le \frac{l}{2} \sin\theta$。
- **计算**：
$$P = \int_0^{\pi/2} \int_0^{(l/2)\sin\theta} \frac{4}{\pi d}\, dx\, d\theta = \frac{4}{\pi d} \cdot \frac{l}{2} \int_0^{\pi/2} \sin\theta\, d\theta = \frac{2l}{\pi d}$$
- **蒙特卡洛应用**：若不知 $\pi$，随机投针 $N$ 次、统计相交频率 $\hat p$，由 $\pi \approx \frac{2l}{d \hat p}$ 反推 $\pi$——这是"用随机模拟估计难算的量"的经典例子。推广：在 $n$ 维单位立方体内均匀投点，落入复杂子集的比例 ≈ 子集体积（体积 = 概率 × 总体积），是工程/物理中难以解析积分时的标准手段。

## 5. 本节重点

> **本节重点**：
> - 条件 PDF = 原 PDF 在条件事件上归一化；全概率/全期望（划分版）用于连续。
> - 混合随机变量：CDF 有跳跃也有连续段，期望按分量加权。
> - 联合 PDF：概率 = 体积；边缘 = 对另一变量积分；$E[g(X,Y)] = \iint g f$。
> - 指数无记忆性：$P(X>x \mid T>t) = e^{-\lambda x}$，等价"每个 $\delta$ 步独立成败"。
> - **常见坑**：① 给单点/曲线赋正概率（连续情形应为 0）；② 边缘 PDF 忘记对全部 $y$ 积分；③ 混合变量当纯离散或纯连续处理。
