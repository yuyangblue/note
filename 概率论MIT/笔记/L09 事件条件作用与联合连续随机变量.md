## 1. 核心概念

### 1.1 给定事件的条件 PDF
条件 PDF 与条件 PMF 完全平行（讲义 p2 的左右对照）：
$$f_{X \mid A}(x) \cdot \delta \approx P(x \le X \le x+\delta \mid A), \qquad \int f_{X \mid A}(x)\, dx = 1$$
特别地，给定 $A = \{X \in S\}$ 时，条件 PDF 是把原 PDF 限制在 $S$ 上再归一化：
$$f_{X \mid X \in S}(x) = \begin{cases} 0, & x \notin S \\ \dfrac{f_X(x)}{P(S)}, & x \in S \end{cases}$$
- 归一性：$\int_S f_X(x)/P(S)\, dx = P(S)/P(S) = 1$。
- 条件期望同理换积分：$E[X \mid A] = \int x f_{X \mid A}(x)\, dx$；条件版期望值法则 $E[g(X)\mid A] = \int g(x) f_{X \mid A}(x)\, dx$。

### 1.2 混合随机变量
随机变量可以是"部分离散 + 部分连续"（混合）：如 $X$ 以概率 $1/2$ 在 $[0,2]$ 均匀、以概率 $1/2$ 取常数 1。CDF 此时既有跳跃又有连续段。一般形式 $X = Y$（离散）w.p. $p$、$Z$（连续）w.p. $1-p$：
$$F_X(x) = p F_Y(x) + (1-p) F_Z(x), \qquad E[X] = p E[Y] + (1-p) E[Z]$$

### 1.3 联合连续与联合 PDF
两个随机变量联合连续：存在 $f_{X,Y}(x,y) \ge 0$ 使得
$$P((X,Y) \in B) = \iint_{(x,y)\in B} f_{X,Y}(x,y)\, dx\,dy$$
- **几何图像（p97 / lec09）**：$f_{X,Y}$ 是铺在 $xy$ 平面上的一座"山"，落在集合 $B$ 的概率 = 山在 $B$ 上方的**体积**；整座山总体积 = 1。
- $f_{X,Y}(x,y)\delta^2 \approx P(x \le X \le x+\delta,\ y \le Y \le y+\delta)$——单位面积上的概率，"概率/单位面积"。
- **关键推论**：$\text{area}(B)=0$（单点、曲线）⇒ $P((X,Y)\in B)=0$。

## 2. 公式与定义

### 2.1 条件版本的期望与期望值法则
$$E[X \mid A] = \int x f_{X \mid A}(x)\, dx, \qquad E[g(X) \mid A] = \int g(x) f_{X \mid A}(x)\, dx$$

### 2.2 全概率 / 全期望（事件划分）
$A_1,\dots,A_n$ 是样本空间的划分：
$$f_X(x) = \sum_i P(A_i) f_{X \mid A_i}(x), \qquad E[X] = \sum_i P(A_i) E[X \mid A_i]$$

### 2.3 边缘 PDF 与联合 CDF
- $f_X(x) = \int f_{X,Y}(x,y)\, dy$，$f_Y(y) = \int f_{X,Y}(x,y)\, dx$；
  - **strip 推导（p96）**：$P(x \le X \le x+\delta)$ 联合视角下是 $xy$ 平面上一条竖带的体积；对该带积分，$x$ 方向窄到 $\delta$ 时内层积分 ≈ $\delta\, f_{X,Y}(x,y)$，再对 $y$ 积分约去 $\delta$ 即得上式——与离散版"对 $y$ 求和"完全平行（和→积分）。
- 联合 CDF：$F_{X,Y}(x,y) = P(X \le x,\ Y \le y)$，$f_{X,Y}(x,y) = \dfrac{\partial^2 F_{X,Y}}{\partial x \partial y}(x,y)$；
- 集合 $S$ 上的均匀联合 PDF：$f_{X,Y}(x,y) = 1/\text{area}(S)$（$(x,y)\in S$）。
- **多于两个变量（讲义 p17）**：$f_{X,Y,Z}$ 对余下变量连续积分两次得 $f_X$；先积 $z$ 得 $f_{X,Y}$。

### 2.4 期望值法则与线性（多元）
$$E[g(X,Y)] = \iint g(x,y) f_{X,Y}(x,y)\, dx\, dy$$
$$E[X+Y] = E[X] + E[Y] \quad \text{（不要求独立）}$$

## 3. 关键性质

### 3.1 指数分布的无记忆性（本节核心直觉，p92）
- 灯泡寿命 $T \sim$ 指数$(\lambda)$：$P(T > x) = e^{-\lambda x}$；
- 已知 $T > t$ 时，剩余寿命 $X = T - t$：
$$P(X > x \mid T > t) = \frac{P(T > t+x)}{P(T > t)} = \frac{e^{-\lambda(t+x)}}{e^{-\lambda t}} = e^{-\lambda x}$$
剩余寿命仍是指数分布，与 $t$ 无关。
- **老师的比喻（讲义 p6）**："你愿意要用过的还是全新的'指数'灯泡？概率上完全一样！"——已用 $t$ 小时的灯和新灯有相同的剩余寿命分布。
- **类比独立抛硬币（讲义 p7）**：每个 $\delta$ 时间步内"坏掉"概率 $\approx \lambda\delta$，互不相关——指数分布是连续版的"无记忆伯努利过程"。

### 3.2 联合 PDF 的可视化（p97）
- 三维曲面：$f_{X,Y}$ 是"山"，体积 = 概率；
- 切片 $y$ 固定 ⇒ 条件密度的形状（未归一化）；
- 面积为零的集合（如单点、曲线）概率为 0。

## 4. 例题

### 例 1：条件 PDF 的均值
- $X$ 在 $[a,b]$ 上均匀，$A = \{\frac{a+b}{2} \le X \le b\}$：
- $P(A) = 1/2$，条件 PDF 在 $[\frac{a+b}{2}, b]$ 上均匀密度 $= \frac{1}{b-\frac{a+b}{2}} = \frac{2}{b-a}$；
- $E[X \mid A] = \frac{\frac{a+b}{2} + b}{2} = \frac{a+3b}{4}$（条件宇宙内仍是均匀，均值即中点）。

### 例 2：混合随机变量
- $X$ 以 $1/2$ 概率在 $[0,2]$ 均匀、以 $1/2$ 概率取 1：
- $F_X(x)$：在 $x<1$ 时 $=\frac12 \cdot \frac{x}{2}$（均匀部分）；$x=1$ 处跳跃 $\frac12$；$x>1$ 时 $=\frac12 + \frac12\cdot\frac{x}{2}$；
- $E[X] = \frac12\cdot1 + \frac12\cdot1 = 1$（两部分均值都是 1）；
- 注意：$X$ 既非纯离散也非纯连续。

### 例 3：全概率定理——Bill 去超市（讲义 p9）
- Bill 有 $1/3$ 概率"很快"出门，出发时刻 $U_1 \sim U[0,2]$（小时）；有 $2/3$ 概率"晚些"出门，出发时刻 $U_2 \sim U[6,8]$；
- 则 $X$ 的 PDF 是两段均匀的混合：
$$f_X(x) = \frac13 \cdot \frac12 \mathbf{1}_{[0,2]}(x) + \frac23 \cdot \frac12 \mathbf{1}_{[6,8]}(x)$$
即 $[0,2]$ 上高 $1/6$、$[6,8]$ 上高 $1/3$，其余为 0；总面积 $\frac16\cdot2 + \frac13\cdot2 = 1$。
- $E[X] = \frac13 E[U_1] + \frac23 E[U_2] = \frac13\cdot1 + \frac23\cdot7 = 5$（小时）。

### 例 4：十字形区域上的均匀联合 PDF
- $S$ 为两个交叉矩形（总面积可由图读出，例如 4 个单位）；
- $f_{X,Y}(x,y) = 1/4$ 在 $S$ 上；
- 边缘 $f_X(x)$：对 $y$ 积分得到阶梯函数（窄条处 $1/2$、宽条处 $3/4$ 等，以面积比为准）。

## 5. 补充：Buffon 针与蒙特卡洛模拟（S09.1，p99）

- **问题（几何概率的著名开端，18 世纪 Buffon 伯爵）**：平面上画间距 $d$ 的平行线，随机投掷一根长 $l$（$l < d$）的针，求针与某条线相交的概率。针短，最多碰一条线。
- **四步法（lec09 强调的标准流程）**：
  1. **设样本空间/变量**：$X$ = 针心到最近线的垂直距离，$X \in [0, d/2]$；$\Theta$ = 针与线的锐角夹角，$\Theta \in [0, \pi/2]$；
  2. **建概率模型（"完全随机"的数学化）**：无任何偏好 ⇒ $X \sim U(0,d/2)$、$\Theta \sim U(0,\pi/2)$，且位置与朝向无关 ⇒ $X,\Theta$ 独立；
  3. **写出联合密度**：$f_X = 2/d$、$f_\Theta = 2/\pi$，独立故 $f(x,\theta) = \frac{2}{d}\cdot\frac{2}{\pi} = \frac{4}{\pi d}$；
  4. **识别事件并积分**：相交条件为针的垂直延伸 $\frac{l}{2}\sin\theta$ 超过距离 $x$，即 $x \le \frac{l}{2}\sin\theta$。
$$P = \int_0^{\pi/2} \int_0^{(l/2)\sin\theta} \frac{4}{\pi d}\, dx\, d\theta = \frac{4}{\pi d} \cdot \frac{l}{2} \int_0^{\pi/2} \sin\theta\, d\theta = \frac{2l}{\pi d}$$
- **课堂演示（lec09）**：取 $d = 2l$，则 $P = 1/\pi$。教授用 3.1 cm 的回形针代替针，投 8 次中 4 次 ⇒ $\hat p = 1/2$ ⇒ $\hat\pi = 2$——"工程近似范围内，方向是对的"。（南北战争伤兵病房投针的轶事仅为传说。）
- **蒙特卡洛应用**：若不知 $\pi$，随机投针 $N$ 次、统计相交频率 $\hat p$，由 $\pi \approx \frac{2l}{d \hat p}$ 反推 $\pi$。推广：在 $n$ 维单位立方体内均匀投点，落入复杂子集的比例 ≈ 子集体积。当积分维数很高（100 个随机变量 ⇒ 100 重积分）解析算不动时，把积分解释成概率、用随机模拟估计概率，是物理/统计/工程中标准的**蒙特卡洛方法**。

## 6. 本节重点

> **本节重点**：
> - 条件 PDF = 原 PDF 在条件事件上归一化（$\int f_{X|A}=1$）；全概率/全期望（划分版）用于连续。
> - 混合随机变量：CDF 有跳跃也有连续段，期望按分量加权。
> - 联合 PDF：概率 = 体积；边缘 = 对另一变量积分（strip 推导）；面积为零 ⇒ 概率为 0；$E[g(X,Y)] = \iint g f$。
> - 指数无记忆性：$P(T>t+x\mid T>t)=e^{-\lambda x}$，等价"每个 $\delta$ 步独立成败"；用过的灯泡与新灯泡概率相同。
> - **常见坑**：① 给单点/曲线赋正概率（连续情形应为 0）；② 边缘 PDF 忘记对全部 $y$ 积分，或忘记只在联合非零区域内积分；③ 混合变量当纯离散或纯连续处理；④ 联合 CDF 反推 PDF 时漏了"二阶混合偏导"。
