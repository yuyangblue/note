## 1. 核心概念

### 1.1 平稳分布
$$\pi_j=\sum_i \pi_i p_{ij},\qquad \sum_j \pi_j=1\qquad(\pi P=\pi)$$
- $\pi$ 是"如果初始分布是 $\pi$，则永远保持 $\pi$"的不变分布；
- 直观（频率解释）：长期看链在各状态上停留的时间比例。

### 1.2 收敛定理（本讲核心结论）
若链**只有一个常返类（不可约）**且**非周期**，则对任意初始分布：
$$\lim_{n\to\infty} r_{ij}(n)=\pi_j\quad\text{（不依赖 }i\text{）}$$
- 直觉：取两条从不同起点出发的链，只要单常返类 + 非周期，随机性足够大，某时刻两条轨迹会**撞到同一状态**；撞在一起后未来概率行为完全相同 ⇒ 起点被遗忘。
- 不证明（教材章末习题给出证明思路）。

### 1.3 生灭过程
状态 = 队列长度（$0,1,\dots,m$）；转移只发生在相邻状态或原地：
- $p_i$：从 $i$ 出生（+1）概率；
- $q_{i+1}$：从 $i$ 死亡（−1）概率；
- 其余概率留在原处。模型来源：收银台、电话呼叫数、传染病患病人数。

## 2. 公式与定义

### 2.1 路径概率
- 一条具体轨迹 $i_0\to i_1\to\cdots\to i_k$ 的概率 = 沿路径转移概率连乘：$p_{i_0 i_1}p_{i_1 i_2}\cdots p_{i_{k-1}i_k}$（马尔可夫性：每步只依赖当前状态）。
- 算 $n$ 步后某状态概率：暴力枚举所有路径（数量随 $n$ 指数爆炸）⇒ 改用 C-K 递推（计算量随 $n$ 线性）。

### 2.2 周期与不可约
- **周期（分簇定义）**：状态能分成 $d$ 个簇，每步必从当前簇跳到下一簇 ⇒ 周期 $d$。从某簇出发，$d$ 的倍数步后必回该簇。
- **非周期**：$d=1$。**只要存在一个自环 $p_{ii}>0$，立刻非周期**（因为下一步可能留在本簇）——最常用的判据。
- **不可约（单常返类）**：任意两状态相通，全链只有一个常返类。

### 2.3 平稳分布（平衡方程）的解法
- $\pi P=\pi$ 给出 $m$ 个方程，但**方程组奇异**（全零解也满足），不唯一；必须加上 $\sum_j\pi_j=1$ 才唯一可解。
- 频率解释：长期在状态 $j$ 的时间比例 $\pi_j$ = "最后一步是进 $j$"的频率 = $\sum_i\pi_i p_{ij}$。

### 2.4 生灭过程的平稳分布（局部平衡）
在相邻状态 $i$ 与 $i+1$ 之间"切一刀"：长期向上穿过该切痕的频率 = 向下穿过的频率（否则净漂移会累积），故
$$\pi_i p_i=\pi_{i+1}q_{i+1}\quad\Longrightarrow\quad \pi_{i+1}=\pi_i\frac{p_i}{q_{i+1}},\qquad \pi_i=\pi_0\prod_{k=0}^{i-1}\frac{p_k}{q_{k+1}}$$
$\pi_0$ 由 $\sum\pi_i=1$ 归一化。这比解全局线性方程组快得多。

### 2.5 访频解释
平稳分布 $\pi_j$ = 长期访问状态 $j$ 的时间比例（遍历定理）：
$$\pi_j=\lim_{n\to\infty}\frac{\text{前 }n\text{ 步中处于 }j\text{ 的步数}}{n}$$

## 3. 关键性质

### 3.1 收敛的条件
- **有限链**：单常返类 + 非周期 ⇒ 存在唯一平稳分布且 $r_{ij}(n)\to\pi_j$（与起点无关）；
- 不可约但**周期**（分簇交替）：$r_{ij}(n)$ 振荡，不收敛；
- **多常返类**：极限存在但依赖起点（掉进哪个常返类就困在哪个）；
- 无限链且出生率太高（$\rho\ge1$）：无平稳分布（队列爆炸）。

### 3.2 解平稳方程的两种方法
1. **全局方程**：$\pi P=\pi$ + 归一化，解线性方程组（适合小链/计算机）；
2. **局部平衡**（生灭链专用）：$\pi_i p_i=\pi_{i+1}q_{i+1}$ 递推（快且直观）。

### 3.3 常系数生灭链（$p_i=p,\ q_i=q$）
令负载因子 $\rho=p/q$：
- $\pi_i=\pi_0\rho^i$；
- **$\rho=1$（对称随机游走）**：所有状态等概，$\pi_i=1/(m+1)$；
- **$\rho<1$ 且 $m\to\infty$**：几何级数收敛，$\pi_0=1-\rho$，$\pi_i=(1-\rho)\rho^i$（移位几何），平均队列 $E[N]=\rho/(1-\rho)$；
- **$\rho>1$**：漂移向上，队列无限增长，无平稳分布；
- $\rho$ 接近 1（如 0.99）即使稳定，平均队列也很大——这是排队论的入门结果。

## 4. 例题

### 例 1：两态链的平稳分布
- $p_{00}=0.9,p_{01}=0.1,p_{10}=0.5,p_{11}=0.5$：
- $\pi_0=0.9\pi_0+0.5\pi_1$，$\pi_0+\pi_1=1$ ⇒ $0.1\pi_0=0.5\pi_1$ ⇒ $\pi=(5/6,1/6)$；
- 长期 5/6 时间在状态 0。（注意两方程线性相关，必须靠归一化定解。）

### 例 2：讲义两态链（收敛到 2/7）
- $p_{11}=0.5,p_{12}=0.5,p_{21}=0.2,p_{22}=0.8$：平衡方程 $0.5\pi_1=0.2\pi_2$，加 $\pi_1+\pi_2=1$ ⇒ $\pi=(2/7,5/7)$；从任一起点出发 $r_{i1}(n)\to2/7$。

### 例 3：生灭链（队列）
- $p_i=0.3,\ q_i=0.4$（$i\ge1$）：$\rho=0.75<1$；
- $\pi_i=\pi_0(0.75)^i$，$\pi_0=1-0.75=0.25$；
- 平均队列长度 $E[N]=\rho/(1-\rho)=0.75/0.25=3$ 人。

### 例 4：周期链反例
- 两态确定交替（$p_{01}=p_{10}=1$）：$r_{00}(n)$ 在 1 与 0 之间振荡，不收敛——虽然 $\pi=(1/2,1/2)$ 满足 $\pi P=\pi$，但收敛定理因周期不适用。
- 对比：只要链中有任一自环（$p_{ii}>0$），就自动非周期。

## 5. 本节重点

> **本节重点**：
> - 平稳分布：$\pi=\pi P$、$\sum\pi=1$（方程组奇异，必加归一化）；收敛需单常返类 + 非周期，极限不依赖起点。
> - 访频解释：$\pi_j$ = 长期停留比例；平衡方程 = "进 $j$ 频率 = 出 $j$ 频率"。
> - 生灭链局部平衡：$\pi_{i+1}=\pi_i p_i/q_{i+1}$；常系数时 $\pi_i=\pi_0\rho^i$，稳定条件 $\rho=p/q<1$，$\pi_0=1-\rho$，$E[N]=\rho/(1-\rho)$。
> - 周期链收敛失败（振荡）、多常返类依赖起点，是两大反例；有自环即非周期。
> - **常见坑**：① 忘记归一化 $\pi$；② 周期链或多常返类直接套收敛定理；③ 生灭链里 $q_0=0$（状态 0 不能"死"），递推从 $i=0$ 开始；④ $\rho\ge1$ 仍硬套 $\pi_0=1-\rho$。
