## 1. 核心概念

### 1.1 平稳分布
$$\pi_j = \sum_i \pi_i p_{ij}, \quad \sum_j \pi_j = 1 \qquad (\pi P = \pi)$$
- $\pi$ 是"如果初始分布是 $\pi$，则永远保持 $\pi$"的不变分布；
- 直观：长期看链在各状态上停留的时间比例。

### 1.2 收敛定理（本讲核心结论）
若链**不可约**（所有状态相通）且**非周期**，则对任意初始分布：
$$\lim_{n\to\infty} r_{ij}(n) = \pi_j \quad \text{（不依赖 } i \text{）}$$
即从任何起点出发，$n$ 步后处于状态 $j$ 的概率都趋于 $\pi_j$。

### 1.3 生灭过程
状态 = 队列长度；转移只发生在相邻状态：
- $b_i$：从 $i$ 出生（+1）概率；
- $d_i$：从 $i$ 死亡（-1）概率；
- 其余概率留在原处。

## 2. 公式与定义

### 2.1 周期与不可约
- **周期**：从状态 $i$ 出发回到 $i$ 的步数集合的最大公约数（>1 为周期态）；全链周期相同；
- **非周期**：gcd = 1（常见于有"停留"概率 $p_{ii}>0$ 的链）；
- **不可约**：任意两状态相通。

### 2.2 生灭过程的平稳分布（局部平衡）
令 $\rho_i = b_i/d_{i+1}$（出生率/死亡率之比），则有
$$\pi_{i+1} = \pi_i \frac{b_i}{d_{i+1}}, \qquad \pi_i = \pi_0 \prod_{k=0}^{i-1} \frac{b_k}{d_{k+1}}$$
$\pi_0$ 由 $\sum \pi_i = 1$ 归一化。直觉：相邻状态间的"净流量"为 0（平衡方程 $\pi_i b_i = \pi_{i+1}d_{i+1}$）。

### 2.3 访频解释
平稳分布 $\pi_j$ = 长期访问状态 $j$ 的时间比例（遍历定理）：
$$\pi_j = \lim_{n\to\infty} \frac{\text{前 } n \text{ 步中处于 } j \text{ 的步数}}{n}$$

## 3. 关键性质

### 3.1 收敛的必要条件
- 有限链：不可约 + 非周期 ⇒ 存在唯一平稳分布且收敛；
- 若不可约但周期（如确定性两态交替）：$r_{ij}(n)$ 振荡，不收敛到 $\pi$；
- 若不可约但暂态（无限链、出生率太高）：无平稳分布（队列爆炸）。

### 3.2 解平稳方程的两种方法
1. **全局方程**：$\pi P = \pi$ 直接解线性方程组（适合小链）；
2. **局部平衡**（生灭链专用）：$\pi_i b_i = \pi_{i+1} d_{i+1}$ 递推（快且直观）。

### 3.3 数值示例（Part I / Part II）
- 收银台链：$b_i = b$（有客）、$d_i = d$（服务，$i\ge1$）：
  - $\pi_i = \pi_0 (b/d)^i$（几何衰减）；
  - 归一化：$\pi_0 = 1 - \rho$（$\rho = b/d < 1$ 时）——$\rho<1$ 是队列稳定的条件；
- 生灭过程一般形式同理，只是每步的比例可不同。

## 4. 例题

### 例 1：两态链的平稳分布
- $p_{00}=0.9, p_{01}=0.1, p_{10}=0.5, p_{11}=0.5$：
- $\pi_0 = 0.9\pi_0 + 0.5\pi_1$，$\pi_0+\pi_1 = 1$ ⇒ $0.1\pi_0 = 0.5\pi_1$ ⇒ $\pi = (5/6, 1/6)$；
- 长期 5/6 时间在状态 0。

### 例 2：数值示例 Part I
- 状态 1–3 链（以讲义矩阵为准）：解 $\pi P = \pi$ 得 $\pi$；验证 $\sum \pi = 1$；$n$ 大步时 $r_{ij}(n) \to \pi_j$。

### 例 3：生灭链（队列）
- $b_i = 0.3, d_i = 0.4$（$i\ge1$）：$\rho = 0.75$；
- $\pi_i = \pi_0(0.75)^i$，$\pi_0 = 0.25$；
- 平均队列长度 $E[N] = \frac{\rho}{1-\rho} = 3$ 人。

### 例 4：周期链反例
- 两态确定交替（$p_{01}=p_{10}=1$）：$r_{00}(n)$ 在 1 与 0 之间振荡，不收敛——虽然 $\pi = (1/2,1/2)$ 满足 $\pi P = \pi$，但收敛定理因周期不适用。

---

## 5. 本节重点

> **本节重点**：
> - 平稳分布：$\pi = \pi P$、$\sum\pi=1$；收敛需不可约 + 非周期，极限不依赖起点。
> - 访频解释：$\pi_j$ = 长期停留比例。
> - 生灭链局部平衡：$\pi_{i+1} = \pi_i b_i/d_{i+1}$；稳定条件 $\rho = b/d < 1$。
> - 周期链收敛失败（振荡）是重要反例。
> - **常见坑**：① 忘记归一化 $\pi$；② 周期链直接套收敛定理；③ 生灭链里 $d_0 = 0$（状态 0 不能"死"），递推从 $i=0$ 开始。
