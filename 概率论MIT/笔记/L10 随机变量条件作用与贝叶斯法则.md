## 1. 核心概念

### 1.1 条件 PDF（连续对连续）
$$f_{X \mid Y}(x \mid y) = \frac{f_{X,Y}(x,y)}{f_Y(y)}, \qquad f_Y(y) > 0$$
- **切片图像（p102 / lec09 尾）**：把 $y$ 钉死，$f_{X,Y}(\cdot,y)$ 就是联合密度在 $y$ 处的一个纵切片，形状不变；但切片下的面积是 $f_Y(y)$ 而非 1，所以要除以 $f_Y(y)$ 重新归一化，使每条切片下面积 = 1。
- **微妙之处**：连续型里 $P(Y=y)=0$，严格说不能对 $Y=y$ 取条件。形式上应理解为"$Y$ 无限接近 $y$"，再取极限；用的时候直接当 $Y=y$ 即可。
- 乘法法则：$f_{X,Y}(x,y) = f_Y(y)f_{X \mid Y}(x \mid y) = f_X(x)f_{Y \mid X}(y \mid x)$。

### 1.2 连续版全概率 / 全期望
$$f_X(x) = \int f_Y(y) f_{X \mid Y}(x \mid y)\, dy, \qquad E[X] = \int f_Y(y) E[X \mid Y=y]\, dy$$

### 1.3 连续随机变量的独立
$$f_{X,Y}(x,y) = f_X(x)f_Y(y), \quad \forall x,y$$
等价于 $f_{X \mid Y}(x \mid y) = f_X(x)$（对所有 $f_Y(y)>0$ 的 $y$）——报出 $Y$ 不改变对 $X$ 的信念。
独立时：$E[XY]=E[X]E[Y]$、$\text{var}(X+Y)=\text{var}(X)+\text{var}(Y)$、$g(X)$ 与 $h(Y)$ 独立。

### 1.4 推断的"黑箱"框架（p107）
- 未知量 $X$（先验分布 $p_X$ 或 $f_X$）→ 测量装置/噪声（模型 $p_{Y\mid X}$ 或 $f_{Y\mid X}$）→ 观测 $Y=y$；
- 推断问题的输出 = **给定观测后未知量的分布** $p_{X\mid Y}(\cdot\mid y)$（即后验）；
- 一切都来自乘法法则：$p_X(x)p_{Y\mid X}(y\mid x) = p_Y(y)p_{X\mid Y}(x\mid y)$，把 $p_Y(y)$ 挪到分母。
- **口诀**：后验 $\propto$ 先验 $\times$ 似然；分母只是归一化常数。当先验均匀时，后验形状直接由似然决定，两个候选的后验之比 = 似然之比（odds）。

## 2. 公式与定义

### 2.1 贝叶斯法则的四种变体

| 情形 | 公式 |
|---|---|
| 离散-离散 | $p_{X \mid Y}(x \mid y) = \dfrac{p_X(x) p_{Y \mid X}(y \mid x)}{p_Y(y)}$，$p_Y(y) = \sum_{x'} p_X(x')p_{Y\mid X}(y \mid x')$ |
| 连续-连续 | $f_{X \mid Y}(x \mid y) = \dfrac{f_X(x) f_{Y \mid X}(y \mid x)}{f_Y(y)}$，$f_Y(y) = \int f_X(x')f_{Y\mid X}(y\mid x')dx'$ |
| 离散-连续 | $p_{K \mid Y}(k \mid y) = \dfrac{p_K(k) f_{Y \mid K}(y \mid k)}{f_Y(y)}$，$f_Y(y) = \sum_{k'} p_K(k') f_{Y \mid K}(y \mid k')$ |
| 连续-离散 | $f_{Y \mid K}(y \mid k) = \dfrac{f_Y(y) p_{K \mid Y}(k \mid y)}{p_K(k)}$，$p_K(k) = \int f_Y(y') p_{K \mid Y}(k \mid y') dy'$ |

- **混合情形怎么来的（lec10）**：写 $P(K=k,\ y\le Y\le y+\delta)$，按乘法法则拆两种方式：$p_K(k)\cdot f_{Y\mid K}(y\mid k)\delta$ 和 $f_Y(y)\delta\cdot p_{K\mid Y}(k\mid y)$；约去小量 $\delta$ 即得 PMF 与 PDF 的桥梁公式。
- 口诀：分子 = 先验 × 似然；分母 = 归一化（对可能的原因求和/积分）。

### 2.2 独立正态的联合密度
$X \sim N(0,1)$、$Y \sim N(0,1)$ 独立：
$$f_{X,Y}(x,y) = \frac{1}{2\pi} e^{-(x^2+y^2)/2}$$
一般独立正态：$f_{X,Y} = \frac{1}{2\pi\sigma_x\sigma_y}\exp\left\{-\frac{(x-\mu_x)^2}{2\sigma_x^2}-\frac{(y-\mu_y)^2}{2\sigma_y^2}\right\}$（等高线为椭圆；$\sigma_x=\sigma_y$ 时为圆，旋转对称）。

## 3. 关键性质

### 3.1 断棒问题（条件作用链，p105）
- 木棒长 $\ell$，先在 $X \sim U[0,\ell]$ 处折，再在 $Y \sim U[0,X]$ 处折：
- $f_{X,Y}(x,y) = f_X(x)f_{Y \mid X}(y \mid x) = \frac{1}{\ell}\cdot\frac{1}{x}$，定义域 $0 \le y \le x \le \ell$（其余为 0）；
- 联合密度形状像一张靠近 $x=0$ 处高高吹起的帆（$1/x$ 发散，但积分仍有限）；
- 条件期望：$E[Y\mid X=x] = \int_0^x y\cdot\frac{1}{x}\,dy = x/2$（条件宇宙内 $Y$ 均匀，均值即中点）；
- 边缘 $f_Y(y)$：对 $x$ 从 $y$ 到 $\ell$ 积分（注意只在联合非零区域积）：$f_Y(y) = \int_y^\ell \frac{1}{\ell x}dx = \frac{1}{\ell}\ln\frac{\ell}{y}$；
- 由全期望：$E[Y] = \int f_X(x)E[Y \mid X=x]dx = \int_0^\ell \frac1\ell \cdot \frac{x}{2} dx = \frac{\ell}{4}$。
- **老师的提醒（lec10）**：答案 $\ell/4$ 简单得像"每折一次剩一半，折两次剩 1/4"。这种"按平均推理"在此恰好对，但**不要滥用**——平均的函数不等于函数的平均。

### 3.2 贝叶斯推断：二元信号检测（p109）
- 未知量 $K$ 等可能为 $-1$ 或 $+1$；测量 $Y = K + W$，$W \sim N(0,1)$；
- $p_K(\pm1) = 1/2$；$f_{Y \mid K}(y \mid k) = \frac{1}{\sqrt{2\pi}}e^{-(y-k)^2/2}$；
- $f_Y(y) = \frac12 \frac{1}{\sqrt{2\pi}}[e^{-(y-1)^2/2} + e^{-(y+1)^2/2}]$；
- $p_{K \mid Y}(1 \mid y) = \dfrac{e^{-(y-1)^2/2}}{e^{-(y-1)^2/2} + e^{-(y+1)^2/2}}$；
- 直觉：$y > 0$ 时更可能是 $K=+1$；$y$ 离 0 越远，后验越有把握。当先验等权时，后验 odds 就是两个似然高度之比。

## 4. 例题

### 例 1：连续未知量 + 离散观测（p110）
- $Y \sim U[0,1]$（未知偏置），$K \sim \text{Bernoulli}(Y)$（观测）；
- $f_Y(y) = 1$；$p_{K \mid Y}(1 \mid y) = y$；
- $p_K(1) = \int_0^1 1\cdot y\, dy = 1/2$；
- $f_{Y \mid K}(y \mid 1) = \dfrac{1\cdot y}{1/2} = 2y$——观测到成功会"抬高"对 $y$ 的信念（贝塔分布雏形，见 L14）。

### 例 2：离散未知量 + 连续测量（见 3.2 计算）
- 观测 $Y = 0.5$：$p_{K \mid Y}(1 \mid 0.5) = \frac{e^{-0.125}}{e^{-0.125}+e^{-1.125}} \approx 0.73$——$K=+1$ 更可能。

### 例 3：独立正态联合密度形状
- 独立标准正态联合密度是旋转对称的钟形；等高线是圆；
- 若 $\sigma_x \ne \sigma_y$，等高线为椭圆（$\sigma$ 大的方向更扁长）。

### 例 4：连续未知 + 离散测量的现实原型（lec10）
- 发光器件由连续电流 $X$ 驱动（未知），观测是 1 秒内数到的光子数 $K$（离散）；
- 用"连续-离散"变体：$f_{X\mid K}(x\mid k) = \frac{f_X(x)p_{K\mid X}(k\mid x)}{p_K(k)}$，$p_K(k) = \int f_X(x')p_{K\mid X}(k\mid x')dx'$。

## 5. 本节重点

> **本节重点**：
> - 条件 PDF = 联合密度切片再归一化；严格含义是"$Y$ 无限接近 $y$"。
> - 连续全概率/全期望；独立 ⇔ 联合处处可拆 ⇔ 条件 = 边缘。
> - 推断黑箱：后验 $\propto$ 先验 × 似然；贝叶斯四种变体按"未知量/观测各是离散还是连续"对号入座。
> - 断棒问题：链式条件 $f=f_X\cdot f_{Y\mid X}$，全期望求 $E[Y]=\ell/4$；注意积分区域只在联合非零处。
> - **常见坑**：① 分母 $f_Y(y)$ 忘记对可能原因求和/积分（没归一化）；② 离散-连续混合情形用错公式变体；③ 把条件密度切片当成已归一化的 $f_{X\mid Y}$（其实还要除以 $f_Y(y)$）；④ 断棒问题求边缘时积分上下限写成 $0$ 到 $\ell$（应为 $y$ 到 $\ell$）。
