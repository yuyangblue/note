## 第 3 页

**方差的性质**

- 记号：$\mu = E[X]$
- 令 $Y = X + b$
- 令 $Y = aX$
- $\text{var}(aX + b) = a^2 \text{var}(X)$
- 一个有用的公式：$\text{var}(X) = E[X^2] - (E[X])^2$

## 第 4 页

**伯努利的方差**

- $X = \begin{cases} 1, & \text{以概率 } p \\ 0, & \text{以概率 } 1-p \end{cases}$
- $\text{var}(X) = \sum_x (x - E[X])^2 p_X(x)$
- $\text{var}(X) = E[X^2] - (E[X])^2$

## 第 6 页

**给定事件的条件 PMF 与期望**

- 对事件 $A$ 取条件 ⇒ 使用条件概率
- $p_X(x) = P(X = x)$ ｜ $p_{X|A}(x) = P(X = x \mid A)$
- $\sum_x p_X(x) = 1$ ｜ $\sum_x p_{X|A}(x) = 1$
- $E[X] = \sum_x x p_X(x)$ ｜ $E[X \mid A] = \sum_x x p_{X|A}(x)$
- $E[g(X)] = \sum_x g(x) p_X(x)$ ｜ $E[g(X) \mid A] = \sum_x g(x) p_{X|A}(x)$

## 第 15 页

**多于两个随机变量**

- $p_{X,Y,Z}(x, y, z) = P(X = x \text{ 且 } Y = y \text{ 且 } Z = z)$
- $\sum_x \sum_y \sum_z p_{X,Y,Z}(x, y, z) = 1$
- $p_X(x) = \sum_y \sum_z p_{X,Y,Z}(x, y, z)$
- $p_{X,Y}(x, y) = \sum_z p_{X,Y,Z}(x, y, z)$

## 第 16 页

**多个随机变量的函数**

- $Z = g(X, Y)$
- PMF：$p_Z(z) = P(Z = z) = P(g(X, Y) = z)$
- 期望值法则：$E[g(X, Y)] = \sum_x \sum_y g(x, y) p_{X,Y}(x, y)$

## 第 18 页

**二项分布的均值**

- $X$：参数为 $n, p$ 的二项随机变量
  - $n$ 次独立试验中的成功次数
- $X_i = 1$ 若第 $i$ 次试验成功；$X_i = 0$ 否则（指示变量）
- $X = X_1 + \dots + X_n$
- $E[X] = \sum_{k=0}^{n} k \binom{n}{k} p^k (1-p)^{n-k}$
- $E[X] = np$
