## 第 1 页

**LECTURE 19：中心极限定理（CLT）**

- WLLN：$\dfrac{X_1 + \dots + X_n}{n} \to E[X]$
- CLT：$X_1 + \dots + X_n \approx$ 正态
  - 精确表述
  - 普适性、实用性
  - 许多示例
  - 离散随机变量的改进
  - 应用于民意调查

## 第 2 页

**独立同分布随机变量之和的不同缩放**

- $X_1, \dots, X_n$ 独立同分布，有限均值 $\mu$ 和方差 $\sigma^2$
- $S_n = X_1 + \dots + X_n$
  - 方差：$n\sigma^2$
- $M_n = \dfrac{S_n}{n} = \dfrac{X_1 + \dots + X_n}{n}$
  - 方差：$\dfrac{\sigma^2}{n}$
- $\dfrac{S_n}{\sqrt{n}} = \dfrac{X_1 + \dots + X_n}{\sqrt{n}}$
  - 方差：$\sigma^2$

## 第 3 页

**中心极限定理（CLT）**

- $X_1, \dots, X_n$ 独立同分布，有限均值 $\mu$ 和方差 $\sigma^2$
- $S_n = X_1 + \dots + X_n$ ｜ 方差：$n\sigma^2$
- $\dfrac{S_n}{\sqrt{n}} = \dfrac{X_1 + \dots + X_n}{\sqrt{n}}$ ｜ 方差：$\sigma^2$
- $Z_n = \dfrac{S_n - n\mu}{\sqrt{n}\sigma}$ ｜ $E[Z_n] = $（讲义留白）｜ $\text{var}(Z_n) = $（讲义留白）
- 令 $Z$ 为标准正态随机变量（零均值、单位方差）
- 中心极限定理：对每个 $z$：$\lim_{n \to \infty} P(Z_n \le z) = P(Z \le z)$
- $P(Z \le z)$ 是标准正态 CDF $\Phi(z)$，可从正态表中查得

## 第 4 页

**CLT 的实用性**

- $S_n = X_1 + \dots + X_n$ ｜ $Z_n = \dfrac{S_n - n\mu}{\sqrt{n}\sigma}$ ｜ $Z \sim N(0,1)$
- 中心极限定理：对每个 $z$：$\lim_{n \to \infty} P(Z_n \le z) = P(Z \le z)$
- 普适且易于应用；只有均值、方差起作用
- 相当精确的计算捷径
- 正态模型的依据

## 第 5 页

**CLT 究竟说了什么？——理论**

- $S_n = X_1 + \dots + X_n$ ｜ $Z_n = \dfrac{S_n - n\mu}{\sqrt{n}\sigma}$ ｜ $Z \sim N(0,1)$
- 中心极限定理：对每个 $z$：$\lim_{n \to \infty} P(Z_n \le z) = P(Z \le z)$
- $Z_n$ 的 CDF 收敛到正态 CDF
- 关于 PDF 或 PMF 收敛的结果（在更多假设下）
- 不假设 $X_i$ 同分布的结果
- "弱相依"下的结果
- 证明：使用"变换"：$E[e^{sZ_n}] \to E[e^{sZ}]$，对所有 $s$

## 第 6 页

**CLT 究竟说了什么？——实践**

- $S_n = X_1 + \dots + X_n$ ｜ $Z_n = \dfrac{S_n - n\mu}{\sqrt{n}\sigma}$ ｜ $Z \sim N(0,1)$
- 中心极限定理：对每个 $z$：$\lim_{n \to \infty} P(Z_n \le z) = P(Z \le z)$
- 正态近似的实践：
  - 把 $Z_n$ 当作正态来处理
  - 因此把 $S_n$ 当作正态来处理：$\mathcal{N}(n\mu, n\sigma^2)$
- 当 $n$ 是"中等大小"时能用 CLT 吗？
  - 通常，能
  - 对称性和单峰性有帮助

## 第 13 页

**二项分布的正态近似**

- $X_i$：独立，Bernoulli($p$)；$0 < p < 1$
- $S_n = X_1 + \dots + X_n$：Binomial($n, p$)
  - 均值 $np$，方差 $np(1-p)$
- $\dfrac{S_n - np}{\sqrt{np(1-p)}}$ 的 CDF $\to$ 标准正态
- $n = 36$，$p = 0.5$；求 $P(S_n \le 21)$
  - $np = 18$
  - $\sqrt{np(1-p)} = 3$
  - $\sum_{k=0}^{21} \binom{36}{k}\left(\dfrac{1}{2}\right)^{36} = 0.8785$

（图示：右侧为标准正态 CDF 数值表，行 $z$ 从 0.0 到 1.4，列从 .00 到 .09，单元格为 $\Phi(z)$ 值）

## 第 16 页

**再访民意调查者的问题**

- $p$：公投中会投"赞成"票的人口比例
- 第 $i$ 个（随机选取的）受访者：
  - $X_i = \begin{cases} 1, & \text{若投赞成} \\ 0, & \text{若投反对} \end{cases}$
- $M_n = (X_1 + \dots + X_n)/n$：我们样本中"赞成"的比例
- 希望"误差小"，如：$|M_n - p| < 0.01$
- $P(|M_n - p| \ge .01)$（讲义留白）
- $Z_n = \dfrac{S_n - n\mu}{\sqrt{n}\sigma}$
