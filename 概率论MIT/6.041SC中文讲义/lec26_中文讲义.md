**稳态行为复习**

（图示：右侧为两个状态转移图，第一个含节点 9, 3, 4, 5, 1, 2；第二个在其基础上新增 6, 7, 8 及相应转移）

- 具有单一常返状态类、非周期、且含部分瞬态的马尔可夫链，则：
  - $\lim_{n \to \infty} r_{ij}(n) = \lim_{n \to \infty} P(X_n = j \mid X_0 = i) = \pi_j, \quad \forall i$

  - $\pi_j = \sum_{k} \pi_k p_{kj}, \quad j = 1, \dots, m,$
  - 连同 $\sum_{j} \pi_j = 1$

## 第 4 页

**电话系统的设计**

- 呼叫以泊松过程发起，速率 $\lambda$
- 每次呼叫的时长是指数分布（参数 $\mu$）
- 需要决定线路数量 $B$？

（图示：右上手绘村庄（人群）与线路（lines）及 B? 示意；下方时间轴上的呼叫到达与持续示意；右为 Erlang(2, 2/3) 与 Exponential(1/$\mu$) 的概率分布曲线对比）

- 对时长 $\delta$ 的小时间槽：
  - $P(\text{来一个新呼叫}) \approx \lambda\delta$
  - 若有 $i$ 个活跃呼叫，则 $P(\text{一个呼叫结束}) \approx i\mu\delta$

## 第 5 页

**电话系统的设计，离散时间近似**

（图示：左上时间轴示意；右上村庄（人群）、线路与 B?；下方三个状态转移示意，分别对应状态 0–1、$i-1$–$i$、$B-1$–$B$，标注 $\lambda\delta$、$i\mu\delta$）

- 近似：时长（很小的）$\delta$ 的离散时间槽
  - $P(1 \text{ 个新呼叫}) \approx \lambda\delta$；$P(1 \text{ 个呼叫结束} \mid i \text{ 个忙}) \approx i\mu\delta$
- 平衡方程
  - $\lambda\pi_{i-1} = i\mu\pi_i$
  - $\pi_i = \pi_0 (\lambda^i/\mu^i i!)$
  - $\pi_0 = 1 / \sum_{i=0}^{B} (\lambda^i/\mu^i i!)$
- $P(\text{到达的顾客发现系统忙})$ 是 $\pi_B$

## 第 8 页

**平均首达时间与平均返回时间**

（图示：右侧为三张相同的状态转移图，其中第二张图中状态 0 被红色圆圈标注，含状态 9, 5, 3, 1, 2, 4 及各转移概率）

- 具有单一常返类的链
- 从 $i$ 到 $s$ 的平均首达时间：
  - $t_i = E[\min\{n \ge 0 \text{ 使得 } X_n = s\} \mid X_0 = i]$
  - 唯一解：
    - $t_s = 0$，
    - $t_i = 1 + \sum_{j} p_{ij}t_j$，对所有 $i \neq s$
- $s$ 的平均返回时间：
  - $t_s^* = E[\min\{n \ge 1 \text{ 使得 } X_n = s\} \mid X_0 = s]$
  - 解：
    - $t_s^* = 1 + \sum_{j} p_{sj}t_j$
