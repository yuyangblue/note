## 第 6 页

**概率公理**

- 事件：样本空间的子集
  - 概率被赋予给事件
- 公理：
  - 非负性：$P(A) \ge 0$
  - 归一化：$P(\Omega) = 1$
  - （有限）可加性：（稍后加强）
    - 若 $A \cap B = \varnothing$，则 $P(A \cup B) = P(A) + P(B)$

## 第 7 页

**公理的一些简单推论**

| 公理 | 推论 |
|---|---|
| $P(A) \ge 0$ | $P(A) \le 1$ |
| $P(\Omega) = 1$ | $P(\varnothing) = 0$ |
| 对互斥事件：$P(A \cup B) = P(A) + P(B)$ | $P(A) + P(A^c) = 1$ |
| | $P(A \cup B \cup C) = P(A) + P(B) + P(C)$ |
| | 对 $k$ 个互斥事件同理 |
| | $P(\{s_1, s_2, \dots, s_k\}) = P(\{s_1\}) + \dots + P(\{s_k\})$ |
| | $= P(s_1) + \dots + P(s_k)$ |

## 第 10 页

**公理的更多推论**

- 若 $A \subset B$，则 $P(A) \le P(B)$
- $P(A \cup B) = P(A) + P(B) - P(A \cap B)$
- $P(A \cup B) \le P(A) + P(B)$

## 第 17 页

**可数可加性公理**

- 加强有限可加性公理

**可数可加性公理：**

> 若 $A_1, A_2, A_3, \dots$ 是互斥事件的无限序列，
> 则 $P(A_1 \cup A_2 \cup A_3 \cup \cdots) = P(A_1) + P(A_2) + P(A_3) + \cdots$

---

## 第 18 页

**数学上的微妙之处**

- 可数可加性公理（同上框内内容）
- 可加性只对事件的"可数"序列成立
- 单位正方形（类似地，实数轴等）不可数（其元素无法排成序列）
- "面积"是单位正方形上的合法概率律，只要我们不试图给"非常奇怪"的集合赋予概率/面积

---

## 第 19 页

**概率理论的解释**

- 狭义观点：数学的一个分支
  - 公理 ⇒ 定理
  - "定理：事件 $A$ 的'频率'就是 $P(A)$"
- 概率是频率吗？
  - $P(\text{掷硬币出现正面}) = 1/2$
  - $P(\text{某总统将连任}) = 0.7$
- 概率常被解释为：
  - 信念的描述
  - 投注偏好
