## 第 2 页

**概率密度函数（PDF）**

（图示：左为离散随机变量的 PMF 柱状图，右为连续随机变量的 PDF 曲线，区间 $[a, b]$ 下的阴影面积标注为 $P(a \le X \le b)$）

- $P(a \le X \le b) = \sum_{x: a \le x \le b} p_X(x)$ ｜ $P(a \le X \le b) = \int_a^b f_X(x) dx$
- $p_X(x) \ge 0$；$\sum_x p_X(x) = 1$ ｜ $f_X(x) \ge 0$；$\int_{-\infty}^{\infty} f_X(x) dx = 1$
- 定义：若一个随机变量可以由一个 PDF 描述，则称其为连续的

## 第 3 页

**概率密度函数（PDF）**

（图示：PDF 曲线，区间 $[a, b]$ 下阴影面积为 $P(a \le X \le b)$）

- $P(a \le X \le a + \delta) \approx f_X(a) \cdot \delta$
- $P(X = a) = 0$
- $P(a \le X \le b) = \int_a^b f_X(x) dx$
- $f_X(x) \ge 0$；$\int_{-\infty}^{\infty} f_X(x) dx = 1$

## 第 5 页

**连续随机变量的期望（均值）**

（图示：左为离散 PMF 柱状图，右为连续 PDF 曲线，区间 $[a, b]$ 下阴影面积标注为 $P(a \le X \le b)$）

- $E[X] = \sum_x x p_X(x)$ ｜ $E[X] = \int_{-\infty}^{\infty} x f_X(x) dx$
- 解释：在大量独立重复实验中的平均值
- 小字（适用范围）：假设 $\int_{-\infty}^{\infty} |x| f_X(x) dx < \infty$

## 第 6 页

**期望的性质**

- 若 $X \ge 0$，则 $E[X] \ge 0$
- 若 $a \le X \le b$，则 $a \le E[X] \le b$
- 期望值法则：$E[g(X)] = \sum_x g(x) p_X(x)$ ｜ $E[g(X)] = \int_{-\infty}^{\infty} g(x) f_X(x) dx$
- 线性：$E[aX + b] = aE[X] + b$

## 第 12 页

**通用 CDF 性质**
