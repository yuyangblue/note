## 第 3 页

**离散时间有限状态马尔可夫链**

（图示：右上为时间轴 0 1 2 3 4 5 6 7 8 … n n+1；右下为状态转移示意图，节点 1, 2, 3, 4, 5, m, j 及箭头）

- $X_n$：$n$ 次转移后的状态
  - 属于有限集合
  - 初始状态 $X_0$ 要么给定，要么随机
  - 转移概率：
    - $p_{ij} = P(X_1 = j \mid X_0 = i) = P(X_{n+1} = j \mid X_n = i)$
- 马尔可夫性质/假设：
  - "给定当前状态，过去无关紧要"
  - $p_{ij} = P(X_{n+1} = j \mid X_n = i) = P(X_{n+1} = j \mid X_n = i, X_{n-1}, \dots, X_0)$
- 模型规范：确定状态、转移和转移概率

## 第 4 页

**n 步转移概率**

（图示：右侧为状态转移图，Time 0 的节点 $i$ 经 Time n-1 的节点 1, k, m（概率 $r_{i1}(n-1), r_{ik}(n-1), r_{im}(n-1)$）到 Time n 的节点 $j$（概率 $p_{1j}, p_{kj}, p_{mj}$））

- 给定初始状态 $i$ 的状态概率：
  - $r_{ij}(n) = P(X_n = j \mid X_0 = i) = P(X_{n+s} = j \mid X_s = i)$
  - 关键递推：$r_{ij}(n) = \sum_{k=1}^{m} r_{ik}(n-1)p_{kj}$
- 随机初始状态：
  - $P(X_n = j) = \sum_{i=1}^{m} P(X_0 = i)r_{ij}(n)$

## 第 7 页

**常返态与瞬态**

- 状态 $i$ 是常返的，如果"从 $i$ 出发，且从你能到达的任何地方出发，都存在返回 $i$ 的路径"
  - 若非如此，称为瞬态

（图示：状态转移图，节点 1–8：5 有自环且指向 1；1 与 3、2 相互连接；2 与 4、6 相连；6、7、8 彼此互联且有自环）

- 常返类：仅彼此之间互通的一组常返态构成的集合
