## 1. 核心概念

> **开场定调（p69 / lec07）**：Tsitsiklis 反复强调，"离散随机变量这一章很大程度上只是记号的练习"——概率、联合发生、条件概率这些概念你早已熟悉，这里只是把它们换一套记号（PMF）重写一遍。理解了这一点，后面所有公式都是"老朋友穿新衣服"。

### 1.1 在随机变量 $Y$ 上的条件作用
与"给定事件"相比，这里条件对象是另一个随机变量的取值 $Y = y$：
$$p_{X \mid Y}(x \mid y) = \frac{p_{X,Y}(x,y)}{p_Y(y)}, \qquad p_Y(y) > 0$$
- **把 $y$ 看作固定量（p70）**：老师提醒"把小写 $y$ 钉死，再把上式看成 $x$ 的函数"。给定 $Y=y$ 就等于"我们被告知住进了一个新宇宙"，在这个新宇宙里考察 $X$ 的各种取值及其概率。
- 对固定的 $y$，$\sum_x p_{X \mid Y}(x \mid y) = 1$——它是对每个 $y$ 都成立的合法 PMF（归一性来自分母 $p_Y(y) = \sum_x p_{X,Y}(x,y)$）。
- **乘法法则**：$p_{X,Y}(x,y) = p_Y(y)\,p_{X \mid Y}(x \mid y) = p_X(x)\,p_{Y \mid X}(y \mid x)$，就是第一章 $P(A\cap B)=P(A)P(B\mid A)$ 的记号版，毫无新东西。

### 1.2 随机变量的独立性
$X$ 与 $Y$ 独立当且仅当联合 PMF 处处等于边缘乘积：
$$p_{X,Y}(x,y) = p_X(x) p_Y(y), \quad \forall x, y$$
- **为什么用"处处可拆"而不用 $p_{X\mid Y}=p_X$ 当定义（p72）**：后者只在 $p_Y(y)>0$ 时才有定义，我们无法对零概率事件取条件。所以教材把"对所有 $(x,y)$ 乘积成立"作为正式定义。
- **直观内容**："知道了一部分随机变量的实现值，不会改变你对其余随机变量取值可能性的信念。"——老师说，靠这个直观常常**不用算公式**就能判断独立性（看表中"报出 $Y$ 的值会不会缩小 $X$ 的可能范围"）。
- 三元独立：$p_{X,Y,Z}(x,y,z) = p_X(x)p_Y(y)p_Z(z)$ 对**所有**三元组成立。虽然形式上只有一个等式，但它要求对无穷多 $(x,y,z)$ 同时成立，所以实质是一大堆条件——比事件的"两两独立"强得多。

## 2. 公式与定义

### 2.1 条件期望与全期望（随机变量版）
- $E[X \mid Y = y] = \sum_x x p_{X \mid Y}(x \mid y)$；
- 期望值法则的条件版：$E[g(X) \mid Y = y] = \sum_x g(x) p_{X \mid Y}(x \mid y)$；
- 全概率/全期望（对 $Y$ 求和）：
$$p_X(x) = \sum_y p_Y(y) p_{X \mid Y}(x \mid y), \qquad E[X] = \sum_y p_Y(y) E[X \mid Y = y]$$
- **讲义小字（L07 p5）**：$Y$ 在无限集取值时也成立，只要 $E[|X|] < \infty$。
- **划分版同时存在**：若 $A_1,\dots,A_n$ 是样本空间的划分，则 $E[X] = \sum_i P(A_i)E[X\mid A_i]$——和对 $Y$ 求和版是同一件事的两种写法（事件划分 vs 随机变量取值划分）。

### 2.2 乘法法则（链式，多于两个变量）
$$p_{X,Y,Z}(x,y,z) = p_X(x)\,p_{Y \mid X}(y \mid x)\,p_{Z \mid X,Y}(z \mid x,y)$$
即第一章 $P(A\cap B\cap C)=P(A)P(B\mid A)P(C\mid A\cap B)$ 的 PMF 翻译。讲义还列出自明记号 $p_{X\mid Y,Z}(x\mid y,z)$、$p_{X,Y\mid Z}(x,y\mid z)$，读的时候"按顺序补条件"即可。

### 2.3 独立性的层次
- 事件独立：$P(A \cap B) = P(A)P(B)$；
- 随机变量与事件独立：$P(X=x \cap A) = P(X=x)P(A)$，$\forall x$；
- 两随机变量独立：$p_{X,Y}(x,y) = p_X(x)p_Y(y)$；
- 三元独立：$p_{X,Y,Z} = p_X p_Y p_Z$ 对所有 $(x,y,z)$ 成立（强于两两独立）。

### 2.4 独立 ⇒ 期望/方差拆开
- **一般情况（p74）**：$E[g(X,Y)] \ne g(E[X],E[Y])$——"平均的函数不等于函数的平均"。两个重要例外：
  1. **线性函数**：$E[aX+b]=aE[X]+b$；以及期望对加法天然线性 $E[X+Y+Z]=E[X]+E[Y]+E[Z]$（SAT 三段分数的例子：分别平均再加总 = 总分后再平均）。**这条不要求独立**。
  2. **独立时乘积拆开**：$E[XY] = E[X]E[Y]$。
- $X,Y$ 独立 ⇒ $g(X)$ 与 $h(Y)$ 也独立，从而 $E[g(X)h(Y)] = E[g(X)]E[h(Y)]$。
  - **概念性论证（p74，老师强调比代数更重要）**：若 $X$ 不透露任何关于 $Y$ 的信息，那它也不会透露任何关于 $Y^3$、$h(Y)$ 的信息；$g(X)$ 自然也不会透露 $h(Y)$。所以独立在"施加函数"下保持。
- $X,Y$ 独立 ⇒ $\text{var}(X+Y) = \text{var}(X) + \text{var}(Y)$。

## 3. 关键性质

### 3.1 方差的两条恒等式与两条极端反例（p75 / L07 p9）
- 恒成立：$\text{var}(aX) = a^2\text{var}(X)$（缩放 $a$ 倍，宽度平方地变）；$\text{var}(X+a) = \text{var}(X)$（加常数只是平移，不改分布宽度）。
- **$\text{var}(X+Y)$ 一般不等于 $\text{var}(X)+\text{var}(Y)$**，两个极端反例：
  - $X = Y$：则 $X+Y=2X$，$\text{var}=4\text{var}(X)$，而 $\text{var}(X)+\text{var}(Y)=2\text{var}(X)$——差一倍。
  - $X = -Y$：则 $X+Y=0$（常数），方差为 $0$。
  - 这两个例子里 $X,Y$ 极度依赖（知道一个就完全知道另一个），所以方差不能拆。
- **速算演练**：若 $X,Y$ 独立，求 $\text{var}(X-3Y)$。论证：$X$ 不知道 $Y$，就不知道 $-Y$，也就不知道 $-3Y$，故 $X$ 与 $-3Y$ 独立；于是 $\text{var}(X-3Y)=\text{var}(X)+\text{var}(-3Y)=\text{var}(X)+9\text{var}(Y)$。**注意最后永远是加号**——负号在平方里消失。

### 3.2 二项分布方差（指示变量求和，p75）
- $X = X_1 + \cdots + X_n$（$X_i$ 独立指示变量，$E[X_i] = p$）；
- $\text{var}(X_i) = E[X_i^2]-(E[X_i])^2 = p - p^2 = p(1-p)$（用 $X_i^2=X_i$ 巧算）；
- $X_i$ 独立 ⇒ $\text{var}(X) = \sum_i \text{var}(X_i) = n p(1-p)$。
- **直觉（p75）**：把 $p(1-p)$ 看成 $p$ 的函数，是开口向下的抛物线，峰值在 $p=1/2$。这意味着"抛硬币的不确定性在硬币公平（$p=1/2$）时最大"；若硬币极偏（$p\approx1$），结果几乎总是正面，方差小、可预测性高。

### 3.3 帽子问题（经典对称性技巧，p76）
- $n$ 人把帽子放入盒中随机各取一顶（等价于任意置换等可能），$X$ = 拿到自己帽子的人数；
- $X_i$：第 $i$ 人拿回自己的帽子（指示变量）。
- **关键观察：$X_i$ 并不独立**——老师用反例说明："若 10 人中有 9 人拿回了自己的帽子，第 10 人必然也拿回了自己的帽子"，所以知道一部分 $X_i$ 会透露其余的信息。**但这不影响求期望**：期望的线性性不需要独立。
- $E[X_i] = P(\text{第 } i \text{ 人拿回自己帽子}) = 1/n$（对称性：$n$ 顶帽子里没有哪一顶更特殊），故 $E[X] = n \cdot \frac1n = 1$。
- 方差：$\text{var}(X) = E[X^2] - (E[X])^2$；
  - $X^2 = \sum_i X_i^2 + \sum_{i \ne j} X_i X_j$；
  - $E[X_i^2] = E[X_i] = 1/n$；
  - $i \ne j$：$E[X_i X_j] = P(i \text{ 和 } j \text{ 都拿回自己帽子}) = \frac{1}{n}\cdot\frac{1}{n-1} = \frac{1}{n(n-1)}$（先给 $i$ 自己的帽，剩下 $n-1$ 顶里 $j$ 再取到自己那顶）；
  - 交叉项共 $n^2-n$ 个；
  - $E[X^2] = n \cdot \frac1n + n(n-1) \cdot \frac{1}{n(n-1)} = 1 + 1 = 2$；
  - $\text{var}(X) = 2 - 1 = 1$。
- **"像魔术"**：$E[X]=\text{var}(X)=1$。老师说更深的原因要等几章后用泊松近似才能解释（错排/泊松分布的均值方差相等）。

## 4. 例题

### 例 1：联合 PMF 表的条件计算（p73，完整数值版）
讲义 p7 给出的联合 PMF（行 = $y$，列 = $x$，分母 20；空项为 0）：

| $y \backslash x$ | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| 4 | 1/20 | 2/20 | 2/20 | 0 |
| 3 | 2/20 | 4/20 | 1/20 | 2/20 |
| 2 | 1/20 | 3/20 | 1/20 | 0 |
| 1 | 0 | 1/20 | 0 | 0 |

- **独立吗？一眼判断（p73）**：若告诉你 $Y=1$，则 $X$ 只能是 2；若告诉你 $Y=3$，$X$ 却可能是 1,2,3,4。报出 $Y$ 直接改变了 $X$ 的可能范围 ⇒ **不独立**。
- 边缘 $p_Y(y)$：对行求和（$y=4:5/20$，$y=3:9/20$，$y=2:5/20$，$y=1:1/20$）；
- 条件 $p_{X \mid Y}(x \mid 2)$：取 $p_{X,Y}(x,2)/p_Y(2)$；
- 独立性检验：逐格比较 $p_{X,Y}(x,y)$ 与 $p_X(x)p_Y(y)$。

### 例 2：条件独立（p73，完整数值版）
给定事件 $A=\{X\le 2,\ Y\ge 3\}$，落在 $A$ 里的四个格子及原始概率为
$(1,4):1/20$、$(2,4):2/20$、$(1,3):2/20$、$(2,3):4/20$，合计 $9/20$。
把这四个数除以 $9/20$ 得条件联合 PMF：

| $y \backslash x$ | 1 | 2 |
|---|---|---|
| 4 | 1/9 | 2/9 |
| 3 | 2/9 | 4/9 |

- 新宇宙内 $X$ 的边缘：$x=1$ 为 $1/9+2/9=1/3$，$x=2$ 为 $2/9+4/9=2/3$；
- $Y$ 的边缘：$y=4$ 为 $1/3$，$y=3$ 为 $2/3$；
- 逐格验证：$1/3\cdot1/3=1/9$、$2/3\cdot1/3=2/9$、$1/3\cdot2/3=2/9$、$2/3\cdot2/3=4/9$，全部等于联合 ⇒ **在 $A$ 的条件宇宙内 $X,Y$ 变得独立了**。
- 教训：条件作用会改变独立结构——原世界不独立，条件后可能独立，必须在新表里逐格重检。

### 例 3：帽子问题
- $n=4$：$E[X] = 1$，$\text{var}(X) = 1$；
- 直觉：平均恰好 1 人拿回自己帽子；方差为 1 说明"平均偏差 1 人"（标准差 $\sigma_X = 1$）。

## 5. 补充：容斥公式、几何方差、事件独立 vs 变量独立（S07.1–S07.3，p77–p79）

### 5.1 容斥公式（S07.1，p77）
两事件并集（"加法多了，减回交集"）：
$$P(A_1 \cup A_2) = P(A_1) + P(A_2) - P(A_1 \cap A_2)$$
三事件（两两交减多了，加回三交）：
$$P(A_1 \cup A_2 \cup A_3) = \sum_i P(A_i) - \sum_{i<j} P(A_i \cap A_j) + P(A_1 \cap A_2 \cap A_3)$$
一般形式（符号交替）：
$$P\left(\bigcup_{i=1}^n A_i\right) = \sum_i P(A_i) - \sum_{i<j} P(A_i \cap A_j) + \sum_{i<j<k} P(A_i \cap A_j \cap A_k) - \cdots + (-1)^{n-1} P\left(\bigcap_{i=1}^n A_i\right)$$
- **推导（指示函数法，老师称之为"优美技巧"）**：$\mathbf{1}_{A^c} = 1 - \mathbf{1}_A$，$\mathbf{1}_{A \cap B} = \mathbf{1}_A \mathbf{1}_B$，De Morgan 律给
$$\mathbf{1}_{\cup_i A_i} = 1 - \prod_{i=1}^n (1 - \mathbf{1}_{A_i})$$
两边取期望，利用 $E[\mathbf{1}_A] = P(A)$、$E[\mathbf{1}_{A_i}\mathbf{1}_{A_j}] = P(A_i \cap A_j)$，展开即得容斥公式。
- **意义**：计算"至少一个事件发生"的概率，从并集上界升级为**精确**公式；帽子问题中"无人拿到自己帽子"等错排计数也源于它。

### 5.2 几何分布方差（S07.2，p78）
$X \sim \text{Geom}(p)$（直到首次正面所需抛掷次数）。用**无记忆性 + 总期望定理**解出二阶矩：
$$E[X^2] = p \cdot 1 + (1-p) \cdot E[(X+1)^2] = p + (1-p)\big(E[X^2] + 2E[X] + 1\big)$$
代入 $E[X] = 1/p$，解方程得 $E[X^2] = \dfrac{2}{p^2} - \dfrac{1}{p}$，于是
$$\text{var}(X) = E[X^2] - (E[X])^2 = \frac{1-p}{p^2}$$
- **直觉**：$X \ge 1$ 时"浪费的一次抛掷 + 重新开始的几何变量"在平方意义下也成立（$(X \mid X>1) \sim 1 + X$），所以二阶矩也能用首步分解。
- 验证：$p = 1/2$ 时 $\text{var}(X) = 2$，与"均值 2、几何分布比较分散"的印象一致。

### 5.3 事件独立 vs 随机变量独立（S07.3，p79）
- **桥梁**：事件 $A$ 的指示变量 $\mathbf{1}_A$（$A$ 发生时取 1，否则取 0）。
- **等价性**：事件 $A, B$ 独立 $\iff$ 指示变量 $\mathbf{1}_A, \mathbf{1}_B$ 独立；一般地，$n$ 个事件独立 $\iff$ $n$ 个指示变量独立。
- **证明思路（两事件）**：$\Rightarrow$ 方向直接看 $(1,1)$ 组合：$P(\mathbf{1}_A = 1, \mathbf{1}_B = 1) = P(A \cap B) = P(A)P(B)$；$\Leftarrow$ 方向要补足 $(1,0)$、$(0,1)$、$(0,0)$ 三个组合，用"独立事件的补集也独立"（L03.4）逐个完成。
- **意义**：两种独立性是同一件事的两种说法，哪个方便用哪个——算期望用变量视角（可拆 $E[XY]$），说人话用事件视角（"知道 $A$ 发生不会改变对 $B$ 的信念"）。

## 6. 本节重点

> **本节重点**：
> - 条件 PMF $p_{X \mid Y}(x \mid y) = p_{X,Y}(x,y)/p_Y(y)$；把 $y$ 钉死当新宇宙；条件期望、全期望（对 $y$ 求和）三件套。
> - 独立 = 联合处处可拆（直觉："报出部分变量不改变对其余的信念"）；独立时 $E[XY]$、$\text{var}(X+Y)$ 都能拆，但期望线性本身不需要独立。
> - 二项方差 $np(1-p)$：指示变量 + 线性/独立拆方差；$p=1/2$ 时不确定性最大。
> - 帽子问题：$X_i$ 虽不独立，$E[X]=1$（线性性不管独立）；$\text{var}(X)=1$ 靠 $E[X_iX_j]=1/(n(n-1))$。
> - **常见坑**：① 条件 PMF 定义域要求 $p_Y(y)>0$；② 把"两两独立"当"独立"；③ 帽子问题中 $E[X_iX_j]$ 算成 $1/n^2$（应为 $1/(n(n-1))$）；④ 算 $\text{var}(aX+bY)$ 时把负号当减号（应为 $a^2\text{var}(X)+b^2\text{var}(Y)$）。
