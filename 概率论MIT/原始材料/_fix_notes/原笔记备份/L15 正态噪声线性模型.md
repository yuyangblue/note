## 1. 核心概念

### 1.1 模型
观测 = 未知量 + 噪声：
$$X = \Theta + W, \qquad W \sim N(0, \sigma_W^2), \quad \Theta \text{ 与 } W \text{ 独立}$$
- 连续参数 $\Theta$ 先验取正态：$\Theta \sim N(\mu_0, \sigma_0^2)$；
- 目标是给定观测 $X = x$ 推断 $\Theta$。

> 讲义 p1 的一般形式：$X_i = \sum_j a_{ij}\Theta_j + W_i$，所有 $\Theta_j$ 和 $W_i$ 都是独立正态。老师强调："这是最常用的统计模型类别"（p161）。

### 1.2 为什么正态-正态可闭合
正态先验 × 正态似然 = 正态后验（共轭），后验可以闭式写出，这是本讲所有计算的根基。

> 老师的识别技巧（p156, L15.2）：任何形如 $f(x) = c \cdot e^{-(ax^2 + \beta x + \gamma)}$（$a > 0$）的 PDF 都是正态分布。用**配方法**把指数写成 $-\frac{(x-\mu)^2}{2\sigma^2}$ 的形式，即可读出 $\mu = -\beta/(2a)$，$\sigma^2 = 1/(2a)$。无需完整推导——一旦确认是正态，均值就在 PDF 峰值处。

### 1.3 为什么用正态
老师强调（p157）："只要所有变量都是正态、关系是线性的，后验还是正态，MAP 和 LMS 恰好重合，估计量还是观测的线性函数——三个性质同时满足，这就是线性正态模型如此流行的原因。"

## 2. 公式与定义

### 2.1 单个观测的后验（关键公式）
$$f_{\Theta \mid X}(\theta \mid x) = N(\hat\theta, \sigma^2)$$

$$\hat\theta = \frac{\frac{\mu_0}{\sigma_0^2} + \frac{x}{\sigma_W^2}}{\frac{1}{\sigma_0^2} + \frac{1}{\sigma_W^2}}$$

$$\frac{1}{\sigma^2} = \frac{1}{\sigma_0^2} + \frac{1}{\sigma_W^2}$$
- 后验均值 = **先验均值与观测的精度加权平均**（权重 = 精度 $1/\sigma^2$）；
- 后验方差 = 先验方差与噪声方差的"并联"（精度相加）。

> **标准特例**（p157）：$\Theta \sim N(0,1)$，$W \sim N(0,1)$，观测 $X = x$。后验指数为 $-\frac{\theta^2}{2} - \frac{(\theta-x)^2}{2}$，对 $\theta$ 求导令零得 $\theta + (\theta - x) = 0$，即 $\hat\theta = x/2$。老师的直觉解释："先验说 $\Theta$ 平均为 0，观测说 $X = x$，两者折中取中间——由于先验和噪声精度相同，正好取一半。"

### 2.2 多个观测
$X_i = \Theta + W_i$，$W_i$ i.i.d. $N(0,\sigma_W^2)$：
$$\hat\theta = \frac{\frac{\mu_0}{\sigma_0^2} + \frac{n\bar x}{\sigma_W^2}}{\frac{1}{\sigma_0^2} + \frac{n}{\sigma_W^2}}$$

$$\frac{1}{\sigma^2} = \frac{1}{\sigma_0^2} + \frac{n}{\sigma_W^2}$$
- $n$ 个观测等价于把样本均值 $\bar x$ 以 $n/\sigma_W^2$ 的精度并入；
- $n \to \infty$：$\hat\theta \to \bar x$（数据主导，先验被淹没）。

> **加权平均视角**（p158）：把先验均值 $\mu_0$ 当作"第 0 个观测"，权重为 $1/\sigma_0^2$；每个实际观测 $x_i$ 的权重为 $1/\sigma_i^2$。老师强调："先验均值被当作另一个数据点对待——噪声大的观测权重小，噪声小的观测权重大。"

### 2.3 线性正态模型（轨迹估计）
观测多个时刻：$X_j = \Theta_0 + \Theta_1 t_j + \Theta_2 t_j^2 + W_j$（$W_j$ i.i.d. 正态）：
- 未知向量 $(\Theta_0, \Theta_1, \Theta_2)$ 的联合后验是多维正态；
- 条件于观测，后验均值是数据的线性函数（最小二乘/贝叶斯线性回归的雏形）；
- MAP 估计 = 最小化二次型 $\sum_j \frac{(X_j - \Theta_0 - \Theta_1 t_j - \Theta_2 t_j^2)^2}{2\sigma_j^2}$，对各 $\Theta_i$ 求导得线性方程组。

> **一般线性正态模型**（p161）：$\Theta_j$ 和 $X_i$ 都是独立正态变量的线性组合。关键结论：
> - 后验 PDF 形如 $c(x) \exp\{-\text{quadratic}(\theta_1, \ldots, \theta_m)\}$；
> - MAP 估计 = 后验均值 = 观测的线性函数；
> - 每个参数的**边缘**后验也是正态，且边缘 MAP = 联合 MAP；
> - 条件 MSE 对所有 $x$ 相同。

## 3. 关键性质

### 3.1 均方误差（MSE）视角
- 估计 $\hat\Theta$ 的 MSE：$E[(\hat\Theta - \Theta)^2]$；
- 给定观测时，使 MSE 最小的估计是后验均值 $E[\Theta \mid X=x]$（见 L16 的 LMS）；
- 本节后验均值 $\hat\theta$ 就是 LMS 估计；后验方差即条件 MSE。

> **关键性质：条件 MSE 不依赖于 $x$**（p159）。在正态线性模型中，后验方差 $\sigma^2 = \left(\frac{1}{\sigma_0^2} + \sum_i \frac{1}{\sigma_i^2}\right)^{-1}$ 只与各方差有关，与具体观测值 $x_i$ 无关。老师强调："这意味着无论你观测到什么，剩余不确定性都一样——你只需报告一个数字就能概括估计器性能。"这在非正态模型中通常不成立。

### 3.2 精度（precision）语言
- 精度 = $1/\sigma^2$，越小方差越准；
- 后验精度 = 先验精度 + 观测精度（可加性非常优雅）；
- 每个观测贡献精度 $1/\sigma_W^2$；$n$ 个观测贡献 $n/\sigma_W^2$。

> 等方差特例（p159）：若 $\sigma_0^2 = \sigma_1^2 = \cdots = \sigma_n^2 = \sigma^2$，则后验方差 $= \sigma^2/(n+1)$。老师："随着观测次数增加，误差按 $1/n$ 下降——很合理。"

### 3.3 先验 vs 数据的权衡
- 数据充足（$n$ 大）或噪声小（$\sigma_W^2$ 小）⇒ 数据主导；
- 先验信息强（$\sigma_0^2$ 小）⇒ 先验主导；
- 两者以**精度**为权重线性折中，形式简单、直觉清晰。

## 4. 例题

### 例 1：单次观测（标准特例）
- $\Theta \sim N(0,1)$（$\mu_0=0,\sigma_0^2=1$），$W \sim N(0,1)$（$\sigma_W^2=1$），观测 $X = 3$：
- 精度：$1/\sigma^2 = 1 + 1 = 2$ ⇒ $\sigma^2 = 0.5$；
- $\hat\theta = \frac{0/1 + 3/1}{2} = 1.5$（即 $x/2$）；
- 后验 $\Theta \mid X \sim N(1.5, 0.5)$。

> 老师的图形解释（p159）：先验是 $N(0,1)$ 的宽曲线；观测 $X=3$ 后后验变为 $N(1.5, 0.5)$——又窄又偏移到 1.5。无论观测到哪个 $x$，后验方差永远是 0.5，只是中心随 $x$ 移动。

### 例 2：多个观测（均值合并）
- $\Theta \sim N(1, 9)$，4 个观测样本均值 $\bar x = 2.5$，$\sigma_W^2 = 4$：
- 先验精度 $1/9$，观测精度 $4/4 = 1$；
- $\hat\theta = \frac{1/9\cdot1 + 1\cdot2.5}{1/9 + 1} = \frac{1/9 + 2.5}{10/9} = \frac{2.611}{1.111} \approx 2.35$；
- 后验精度 $= 10/9$ ⇒ 方差 $0.9$——比单个观测（$\sigma^2=4\cdot\frac{9}{13}\approx2.77$）更尖。

### 例 3：轨迹估计（抛球）
- 物体垂直运动：$Z(t) = \Theta_0 + \Theta_1 t + \frac12 \Theta_2 t^2$，其中 $\Theta_2/2 = -g/2$（重力，已知常数 $g=9.81$）；
- 测量时刻 $t_1, \ldots, t_n$，观测 $X_i = Z(t_i) + W_i$；
- 先验：$\Theta_0 \sim N(200, \sigma^2)$，$\Theta_1 \sim N(50, \sigma^2)$；
- MAP 估计 = 最小化 $(\Theta_0 - 200)^2 + (\Theta_1 - 50)^2 + \sum_i (X_i - \Theta_0 - \Theta_1 t_i + 4.905 t_i^2)^2$；
- 老师演示（p162）：所有测量挤在初始时刻附近 → 速度 $\Theta_1$ 估不准；把测量分散到不同时刻 → 估计轨迹与真实轨迹几乎重合。

> **贝叶斯置信区间**（p162）：后验是正态分布，所以任意时刻 $t$ 的位置后验也是正态。取 $\pm 2\sigma$ 即得约 95% 置信带。老师："除了给出一条估计轨迹线，还要给出置信带——告诉老板你有多确定。"

## 5. 本节重点

> **本节重点**：
> - 正态先验 + 正态噪声 ⇒ 正态后验；后验均值 = 先验均值与观测的**精度加权平均**，后验精度 = 两者之和。
> - 多观测：用样本均值 $\bar x$ 与精度 $n/\sigma_W^2$ 一键合并；$n\to\infty$ 后验 → 数据。
> - 后验均值即 LMS/MSE 最优估计（预告 L16）；后验方差 = 条件 MSE。
> - 线性正态模型三大性质：后验正态、MAP = LMS、估计量是观测的线性函数；条件 MSE 与观测值无关。
> - **常见坑**：① 权重用方差而不是精度（权重比反了）；② 忘记噪声与 $\Theta$ 独立的前提；③ 多观测时把每个 $x_i$ 当独立精度相加而忘了用 $\bar x$ 简化；④ 认为观测异常值会增加不确定性——正态模型中条件 MSE 与 $x$ 无关。
