## 1. 核心概念

### 1.1 推断在整个概率体系中的位置
概率理论的方向是：给定模型 → 计算预测（分析）。推断/统计的方向恰好相反：观测数据 → 反推模型。老师用一张图概括：现实世界产生数据 → 推断/统计建立模型 → 概率理论做预测和决策（p144, L14.1；讲义 p2）。

老师强调："这次讲座不涉及新数学内容，仅几个定义、几个新术语及贝叶斯公式的应用"（p144）。推断问题之所以重要，是因为应用场景极其广泛：
- **实验设计与民意调查**：选举民调（2012 年 Obama vs Romney 选举人票预测）；
- **推荐系统**：Netflix 竞赛——部分填充的评分表，推测未知评分；
- **金融**：标普 500 指数时间序列建模；
- **信号处理**：通信系统、语音/图像处理、GPS 定位、异常事件检测；
- **生命科学**：基因组学、系统生物学通路建模。

老师的提醒（p145）："统计可以被严重滥用。太多人直接上 Wikipedia 找个统计测试套数字就出结论，要理解方法背后的假设和保证。"

### 1.2 推断问题的两类任务
- **假设检验**：未知量只能取少数几个离散值（如"有飞机/没飞机"），目标是最小化错误决策概率；
- **估计**：未知量是连续数值，目标是让估计值"尽量接近"真实值。

老师进一步区分了两个子方向（p146, L14.3）：
- **模型构建**（system identification）：已知信号 $S$，观测 $X = AS + W$，反推介质参数 $A$；
- **未知变量推断**：已知介质 $A$，反推发送的信号 $S$。

> 老师指出：这两类问题在数学结构上完全相同——都是线性方程里"已知一个、求另一个"，所以方法论可以统一处理。

### 1.3 贝叶斯推断框架
把未知参数当作**随机变量** $\Theta$：
1. **先验** $p_\Theta(\theta)$ 或 $f_\Theta(\theta)$：观测前对参数的信念；
2. **观测模型** $p_{X \mid \Theta}$ 或 $f_{X \mid \Theta}$：给定参数下数据如何产生；
3. **后验** $p_{\Theta \mid X}(\theta \mid x)$：观测后更新信念——由贝叶斯法则计算。

老师强调（p147, L14.4）："未知量被当作随机变量，这是贝叶斯框架与经典框架的根本区别。"先验的来源有四种：
- **对称性**：无理由认为某值更可能 → 均匀先验；
- **已知范围**：参数取值有物理边界 → 范围外置零；
- **先前研究**：已有实验结果 → 作为新观测的先验；
- **主观/任意**：纯粹反映主观信念。

> 老师的哲学比喻：电子质量其实不是随机的，但我"不知道"它，就把我的不确定信念建模成先验分布。这不是说大自然随机，而是用分布来描述我自己的认知状态（lec21 逐字稿）。

### 1.4 点估计的常用选择
完整答案是整个后验分布，但老板要一个数字。两种常用点估计：
- **最大后验（MAP）**：使后验最大的 $\theta$；
- **条件期望估计（LMS）**：$E[\Theta \mid X = x]$（后验均值，最小均方误差，见 L16）。

老师强调术语区分（p147）：
- **估计值**（estimate）：$g(x)$，数据取具体值后的一个数字；
- **估计器**（estimator）：$g(X)$，数据随机时的随机变量。

## 2. 公式与定义

### 2.1 贝叶斯法则（推断形式）
$$p_{\Theta \mid X}(\theta \mid x) = \frac{p_\Theta(\theta) p_{X \mid \Theta}(x \mid \theta)}{p_X(x)}, \qquad p_X(x) = \sum_\theta p_\Theta(\theta) p_{X \mid \Theta}(x \mid \theta)$$
连续参数版本把求和换积分、PMF 换 PDF。

> 老师强调：分母 $p_X(x)$ 只负责归一化，不依赖 $\theta$——比较不同 $\theta$ 时可忽略（p147）。

四种组合（p148–p150）：
- 离散 $\Theta$ + 离散 $X$：PMF 版本，$\Theta$ 的各取值即各假设；
- 离散 $\Theta$ + 连续 $X$：信号检测 $X = \Theta + W$，$W \sim N(0, \sigma^2)$；
- 连续 $\Theta$ + 连续 $X$：线性正态模型（详见 L15）；
- 连续 $\Theta$ + 离散 $X$：硬币偏置（见 2.3）。

### 2.2 贝塔分布（硬币偏置的共轭先验）
$$\text{Beta}(a,b): \quad f_\Theta(\theta) = c\, \theta^{a-1}(1-\theta)^{b-1}, \quad 0 \le \theta \le 1$$
- 归一化常数 $c = \frac{\Gamma(a+b)}{\Gamma(a)\Gamma(b)}$；
- 均值 $E[\Theta] = \frac{a}{a+b}$；
- 特例：$a=b=1$ 即 $U[0,1]$（无信息先验）。

> S14.1（p154）给出了贝塔归一化常数的**概率论推导**：取 $\alpha+\beta+1$ 个独立 $U[0,1]$ 随机变量，考虑"按特定顺序排列"事件，用对称性 + 全概率定理两种算法对比，直接得到 $\int_0^1 \theta^\alpha(1-\theta)^\beta d\theta = \frac{\alpha! \beta!}{(\alpha+\beta+1)!}$。老师评价："有些公式用微积分推很烦，用概率解释反而很干净。"

### 2.3 推断硬币偏置（核心示例）
- $\Theta \sim U[0,1]$（先验），$X \mid \Theta \sim \text{Binomial}(n,\Theta)$；
- 观测到 $k$ 次正面后，后验：
$$f_{\Theta \mid X}(\theta \mid k) = c'\, \theta^{k}(1-\theta)^{n-k} \sim \text{Beta}(k+1,\ n-k+1)$$
- 后验均值 $E[\Theta \mid X=k] = \frac{k+1}{n+2}$（拉普拉斯"加一"平滑）；
- MAP 估计：$\hat\theta = k/n$（后验众数，与极大似然一致）。

> 老师的推导细节（p152）：MAP 通过最大化对数后验求解——$\frac{d}{d\theta}[k\ln\theta + (n-k)\ln(1-\theta)] = \frac{k}{\theta} - \frac{n-k}{1-\theta} = 0$，解得 $\theta = k/n$。

## 3. 关键性质

### 3.1 后验 = 先验 × 似然（归一化）
- 分母 $p_X(x)$ 只负责归一化，不依赖 $\theta$——比较不同 $\theta$ 时可忽略；
- 数据越多，后验越"尖"（集中在真实参数附近），先验的影响越小。

### 3.2 共轭先验
先验选 Beta 时，后验仍是 Beta，只是参数更新为（成功数 + a，失败数 + b）——计算闭合、解释直观。

> 老师强调（p151）：共轭性的一个实际好处是**递归更新**——来一批新数据就把参数累加，不用从头算。

### 3.3 贝叶斯 vs 频率学派（本节背景）
- 贝叶斯：参数随机，输出后验分布（信念区间）；
- 经典频率学派：参数固定未知，用置信区间/假设检验（见 L20 经典统计）；
- 两者处理"不确定性"的语言不同，但公式常可互证。

> 老师的历史评论（lec21）："统计学家为贝叶斯 vs 频率之争吵了 100 年，潮汐来回。近些年贝叶斯方法越来越流行。"

### 3.4 MAP 的最优性
对于假设检验问题（离散 $\Theta$），MAP 规则对每一个观测值 $x$ 都使条件错误概率最小，因此也使整体错误概率最小（p148）。这是 MAP 在假设检验场景下的严格最优性。

## 4. 例题

### 例 1：离散参数 + 离散观测
- $\Theta \in \{0.3, 0.6\}$ 等先验；$X \mid \Theta \sim \text{Binomial}(10, \Theta)$；
- 观测 $X = 4$：$p_X(4) = \frac12 \binom{10}{4}0.3^4 0.7^6 + \frac12\binom{10}{4}0.6^4 0.4^6$；
- 后验 $p_{\Theta \mid X}(0.3 \mid 4) = \frac{0.3^4 0.7^6}{0.3^4 0.7^6 + 0.6^4 0.4^6} \approx 0.64$（先验等可能，$\binom{10}{4}$ 与 $0.5$ 在比值中约掉），观测结果更支持 $\Theta = 0.3$——$X=4$ 次正面在"真实 $p=0.3$"下比在"$p=0.6$"下更可能出现。

> 讲义 p15 的一般形式：$\Theta \in \{1,2,3\}$ 先验 $P_\Theta = \{0.6, 0.3, 0.1\}$，观测 $X$ 后取 MAP = 后验最大的那个值。条件错误概率 = 1 − 后验最大概率；整体错误概率用全概率定理：$\sum_x P(\hat\Theta \neq \Theta \mid X=x) p_X(x)$ 或 $\sum_\theta P(\hat\Theta \neq \Theta \mid \Theta=\theta) p_\Theta(\theta)$。

### 例 2：离散参数 + 连续观测（信号检测）
- $\Theta \in \{-1, +1\}$，$X = \Theta + W$，$W \sim N(0,1)$（信号检测）；
- 后验 $p_{\Theta \mid X}(+1 \mid x) = \dfrac{e^{-(x-1)^2/2}}{e^{-(x-1)^2/2}+e^{-(x+1)^2/2}}$（与 L10 相同）。

> 讲义 p16 的标准例：$\Theta \in \{1,2,3\}$，$X = \Theta + W$，$W \sim N(0,\sigma^2)$。条件 PDF $f_{X \mid \Theta}(x \mid \theta) = f_W(x-\theta)$——只是把噪声 PDF 平移 $\theta$。MAP 规则、条件错误概率、整体错误概率的计算与离散观测情形完全平行，唯一区别是求和换积分（p149）。

### 例 3：连续参数 + 连续观测
- $\Theta \sim U[0,1]$，$X \mid \Theta \sim U[0,\Theta]$：
- $f_{\Theta \mid X}(\theta \mid x) = \dfrac{1\cdot \frac1\theta}{\int_x^1 \frac1\theta d\theta} = \frac{1}{\theta \ln(1/x)}$（$x \le \theta \le 1$）；
- 观测 $x$ 之后，$\theta \ge x$ 且更偏爱小 $\theta$。

> 讲义 p17 指出这属于"估计均匀分布参数"的经典例，与"线性正态模型"并列为本讲两大连续-连续推断模型。线性正态模型将在 L15 详讲。

### 例 4：硬币偏置点估计
- $n=10, k=7$：后验 $\text{Beta}(8,4)$；
- MAP：$\hat\theta = 0.7$；后验均值 $E[\Theta \mid X] = 8/12 \approx 0.667$。

> 老师的对比（p152）：MAP 和后验均值很像但不相同。当 $n$ 很大时，$\frac{k+1}{n+2} \approx \frac{k}{n}$，两者几乎重合——数据越多，先验的"加一"修正越微不足道。

## 5. 本节重点

> **本节重点**：
> - 贝叶斯推断三要素：先验、似然、后验；后验 ∝ 先验 × 似然。
> - 四种（离散/连续）参数-观测组合都能用贝叶斯法则，记住"分子先验×似然、分母归一化"。
> - Beta 分布是"硬币偏置"的共轭先验：观测 $k/n$ 后更新为 $\text{Beta}(k+a, n-k+b)$；后验均值 $(k+1)/(n+2)$、MAP $= k/n$。
> - MAP 在假设检验中使条件错误概率最小；LMS（条件期望）使均方误差最小（详见 L16）。
> - **常见坑**：① 把先验当后验直接输出；② 归一化分母算错（离散求和 vs 连续积分）；③ 混淆 MAP（众数）与后验均值（LMS）；④ 混淆估计值（数字）与估计器（随机变量）。
